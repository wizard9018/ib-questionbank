# AA1365

**Maximum mark: 6**

A particle moves along a straight line. 

Its displacement, $s$ metres, from a fixed origin O at time $t$ seconds is given by $s(t) = 3\cos(e^t), \text{ where } 0 \leq t \leq 2$.

1.    Find the initial displacement of the particle. [2 marks]

2.    Find the times when the particle changes direction. [4 marks]

---

    s(0)&= 1.62 \text{ m} \tag*{\textbf{A1}}

    \end{aligned}

    $$
