# AA1367

**Maximum mark: 7**

A factory bottles cold-brew coffee. The masses, $W$ (in grams), of the filled bottles are normally distributed with mean $150\,$g and a standard deviation of $\sigma \,$g.

It is known that the interquartile range of $W$ is $10.2\,\text{g}$.

1.    Show that $\sigma=7.561\,$g to $4$ significant figures. [4 marks]

A bottle is deemed under-filled if its mass is less than $140\,$g. 

Bottles are packed into cartons of 15. 

A carton is rejected at dispatch if it contains three or more under-filled bottles.

2.    Find the probability a carton is rejected at dispatch. [3 marks]

---

## 评分标准 / Mark scheme

1. First let's use the formula for the $\textbf{interquartile range (4.2)}$ to write

    $$

    \begin{aligned}

    IQR&=Q_3-Q_1\\[6pt]

    10.2&=Q_3-Q_1

    \end{aligned}

    $$

    We can show this on a normal distribution curve.

    ![AA1367a](images/AA1367a.JPEG)

    As a normal distribution curve is symmetrical about the mean we can say that

    $$

    \begin{aligned}

    Q_1&=150-\frac{10.2}{2}\tag*{\textbf{{M1}}}\\[6pt]

    &=144.9\tag*{\textbf{A1}}

    \end{aligned}

    $$

    Recall, $Q_1$ is the 25th percentile of $W$.

    However, we can't use the inverse normal function directly as $\sigma$ is unknown.

    We need to use the $\textbf{standardized normal variable (4.12)}$ formula

    $$

    \begin{aligned}

    z&=\frac{x-\mu}{\sigma}

    \end{aligned}

    $$

    We can then use the distribution $Z \sim \mathrm{N}(0,1^2)$ to find the $z$-value, $z_1$, which corresponds to $Q_1$.

    Using the G.D.C., we get

    $$

    \begin{aligned}

    z_1 &= \text{invNorm}(0.25,0,1) \\[6pt]

    &= -0.6744...\tag*{\textbf{A1}}

    \end{aligned}

    $$

    Substituting this value, along with $Q_1=144.9$, into $\bm{4.12}$ we get

    $$

    \begin{aligned}

    -0.6744...&=\frac{Q_1-150}{\sigma}\\[6pt]

    -0.6744...&=\frac{144.9-150}{\sigma}\tag*{\textbf{{M1}}}\\[6pt]

    \sigma&=7.5612...\\[6pt]

    &=7.561\hspace{0.5em}\text{ ... as required.} \tag*{\textbf{{AG}}}

    \end{aligned}

    $$

2. First, we need to find the probability that a single bottle is under-filled.

    Using our answer from part (a) we can define the distribution for the mass as $W \sim \mathrm{N}(150,7.5612...^2)$.

    A bottle is under-filled if $W < 140$. Using the G.D.C. we get

    $$

    \begin{aligned}

    \mathrm{P}(W < 140) &= \text{normCdf}(-\infty,140,150,7.5612...) \\[12pt]

    &= 0.09299...\tag*{\textbf{{A1}}}

    \end{aligned}

    $$

    Next, we can define a new random variable $X$ such that it is the number of under-filled bottles in a carton of 15.

    Considering this situation we have

    -   A fixed probability $(p=0.09299...)$

    -   A set number of trials $(n=15)$

    -   Two possible outcomes (under-filled or not under-filled)

    -   Constant probability (having one under-filled bottle does not impact the probability of the other bottles)

    We have fulfilled the conditions for $X$ to be binomially distributed. Hence we can say that $X \sim \mathrm{B}(15, 0.09299...)$.

    

    We are told that a carton is rejected if $X \geq 3$. Hence using a G.D.C. we get

    $$

    \begin{aligned}

    \mathrm{P}(X \geq 3) &=  \text{binomCdf}(15, 0.09299..., 3,15) \tag*{\textbf{{(M1)}}}\\[6pt]

    &= 0.1577... \\[6pt]

    &=0.158\tag*{\textbf{{A1}}}

    \end{aligned}

    $$
