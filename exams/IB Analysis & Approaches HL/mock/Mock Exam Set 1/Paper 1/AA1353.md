# AA1353

**Maximum mark: 5**

The following diagram shows the graph of $y=f(x)$, for $ -3\leq x \leq 7 $.

![AA1353q](images/AA1353q.JPEG)

1.    State the range of $f$. [1 mark]

2.    Write down the value of $f^{-1}(6)$. [1 mark]

Consider another function $g(x)$, defined on the domain of integers from 1 to 4 inclusive.

$\\[1em]$

| $x$ | $\hspace{0.5em}1\hspace{0.5em}$ | $\hspace{0.5em}2\hspace{0.5em}$ | $\hspace{0.5em}3\hspace{0.5em}$ | $\hspace{0.5em}4\hspace{0.5em}$ |

| --- | --- | --- | --- | --- |

| $\hspace{0.5em}g(x)\hspace{0.5em}$ | $\hspace{0.5em}-3\hspace{0.5em}$ | $\hspace{0.5em}5\hspace{0.5em}$ | $\hspace{0.5em}-2\hspace{0.5em}$ | $\hspace{0.5em}1\hspace{0.5em}$ |

3.    Evaluate $(g \circ f)(3)$. [1 mark]

4.    Solve $(f \circ g)(x)=1$. [2 marks]

---

## 评分标准 / Mark scheme

1. To determine the range of $f$, we identify the possible $y$-values (outputs).

    The lowest $y$-value is at point $C\,(7,\,-2)$ so the smallest $y$-value is $-2$.

    The highest $y$-value is at point $A\,(-3,\,7)$ so the greatest $y=7$.

    Therefore the range of $f$ is $-2\leq y\leq 7$.

    $\\[-2.8em]$

    $$

    \begin{aligned}

    \tag*{\textbf{\textcolor{black}{A1}}}

    \end{aligned}

    $$

2. Recall that when $y=f(x)$ then $f^{-1}(y)=x$.

    For $f^{-1}(6)$, this means we need to find the $x$ value when $y=6$.

    The intersection of our graph with the line $\textcolor{RVRed}{y=6}$ happens when $\textcolor{RVGreen}{x=-1}$ as shown in the diagram.

    ![AA1353b](images/AA1353b.JPEG)

    Therefore $f^{-1}(6)=-1$.

    $\\[-2.8em]$

    $$

    \begin{aligned}

    \tag*{\textbf{\textcolor{black}{A1}}}

    \end{aligned}

    $$

3. First let's rewrite the composite function.

    $$

    \begin{aligned}

    (g \circ f)(3)=g(f(3))

    \end{aligned}

    $$

    We first evaluate $f(3)$ and then substitute this result into $g$.

    Using the graph we can see that $f(3)=4$.

    ![AA1353c](images/AA1353c.JPEG)

    We then substitute this result into $g$. Using the table,

    | $x$ | $1$ | $2$ | $3$ | $\textcolor{#039855}{4}$ |

    | --- | --- | --- | --- | --- |

    | $\hspace{0.5em}g(x)\hspace{0.5em}$ | $\hspace{0.5em}-3\hspace{0.5em}$ | $\hspace{0.5em}5\hspace{0.5em}$ | $\hspace{0.5em}-2\hspace{0.5em}$ | $\hspace{0.5em}\textcolor{#b52209}{1}\hspace{0.5em}$ |

    we see that $g(4)=1$.

    Therefore $(g \circ f)(3)=1$.

    $\\[-2.8em]$

    $$

    \begin{aligned}

    \tag*{\textbf{\textcolor{black}{A1}}}

    \end{aligned}

    $$

4. As in part c, let's rewrite the L.H.S. of the equation.

    $$

    \begin{aligned}

    (f \circ g)(x)&=1\\[6pt]

    f(g(x))&=1

    \end{aligned}

    $$

    The outer function is $f$ and the output is 1.

    Using the graph

    ![AA1353d](images/AA1353d.JPEG)

    we can see that the input required must be $5$.

    $\\[-2.8em]$

    $$

    \begin{aligned}

    \tag*{\textbf{\textcolor{black}{A1}}}

    \end{aligned}

    Therefore as $f(5)=1$ we must solve $g(x)=5$.

    Using the table

    | $\hspace{0.5em}g(x)\hspace{0.5em}$ | $\hspace{0.5em}-3\hspace{0.5em}$ | $\hspace{0.5em}\textcolor{#b52209}{5}\hspace{0.5em}$ | $\hspace{0.5em}-2\hspace{0.5em}$ | $\hspace{0.5em}1\hspace{0.5em}$ |

    we can see that $x=2$.

    

    Hence $x=2$.
