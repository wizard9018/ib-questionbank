# PH0412

The variation of terminal potential difference $V$ across an electric cell with current $I$ coming out of the cell is shown in the graph.

![PH0412](images/PH0412.png)
$\footnotesize{\textrm{[Source: Created with GeoGebra, - https://www.geogebra.org/graphing?lang=en]}}$]

What are the values of the emf $\varepsilon$ and internal resistance $r$ of the electric cell used in this circuit?

$\\$

| |$\varepsilon$ / $V$| $r\, /\, \Omega$ |
| :-- | :-: | :-: |
| A.$\hspace{1em}$ | $\enskip$ $9$ $\enskip$ | $\enskip$ $2.0\, $ $\enskip$ |
| B. | $8$| $0.5\, $ |
| C. | $8$ | $2.0\, $ |
| D. | $9$ | $0.5\, $ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The terminal potential difference $V$,

- $V=\varepsilon-Ir$

This is a linear relation, where $\varepsilon$ is the $y$-intercept and -$r$ is the gradient.

So extrapolating the graph to to the vertical axis to find the intercept gives,

- $\varepsilon=9$ V

And,

- $r=-\dfrac{8-3}{2-12}=0.5\, \Omega $
