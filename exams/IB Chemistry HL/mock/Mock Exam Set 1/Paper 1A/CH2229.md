# CH2229

For the following reaction, identify the Bronsted$\text{--}$Lowry acid$\text{--}$base conjugate pairs.

$\ce{CH3NH2(aq) + H2PO4-(aq) <=> CH3NH3+(aq) + HPO4^2-(aq)}$

-   :::tableoptions{col1="hide"}
    | | Bronsted$\text{--}$Lowry Acid | Conjugate Base |
    | :- | :-: | :-: |
    | A.$\hspace{1em}$ | $\ce{CH3NH2}$ | $\ce{CH3NH3+}$ |
    | B. | $\ce{H2PO4-}$ | $\ce{HPO4^2-}$ |
    | C. | $\ce{CH3NH2}$ | $\ce{HPO4^2-}$ |
    | D. | $\ce{H2PO4-}$ | $\ce{CH3NH3+}$ |

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
A Bronsted$\text{--}$Lowry acid is a species that donates a proton, while a base accepts a proton. In the reaction given, methanamine gains a proton to form methylammonium ion. This makes $\ce{CH3NH2}$ a base and $\ce{CH3NH3+}$ its conjugate acid. Simultaneously, dihydrogen phosphate donates a proton to become hydrogen phosphate.  This makes $\ce{H2PO4-}$ an acid and $\ce{HPO4^2-}$ its conjugate base.

$\ce{\underset{\normalsize base}{CH3NH2(aq)} + \underset{\normalsize acid}{H2PO4-(aq)} <=> \underset{\normalsize conjugate acid}{CH3NH3+(aq)} + \underset{\normalsize conjugate base}{HPO4^2-(aq)}}$

When the reverse reaction is considered, the conjugate base (hydrogen phosphate) accepts a proton to reform the acid (dihydrogen phosphate) and the conjugate acid (methyl ammonium ion) donates a proton to reform the base (methanamine).
