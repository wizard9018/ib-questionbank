# CH2197

The simplified $\ce{^1 H}$ NMR spectrum of a compound is shown below.

![ CH2197spec](<images/ CH2197spec.png>)

Which compound is most consistent with the spectrum?

-   A. $\hspace{1em}\text{pentane--2,4--diol}$

-   B. $\hspace{1em}\text{pentane}$

-   C. $\hspace{1em}\text{pentane--1,5--diol}$

-   D. $\hspace{1em}\text{pentan--3--ol}$

---

## 评分标准 / Mark scheme

**答案：A**

$\textrm{\underline{Explanation:}}$

The number of unique signals in an NMR spectrum reflects the number of distinct proton environments in the molecule. The relative area (integration) under each signal indicates how many hydrogens are present in that environment. The splitting pattern of each signal reveals information about neighboring protons through the $n+1$ rule, a proton with $n$ equivalent neighboring protons will be split into $n+1$ peaks.

Using these principles: number of environments, integration, and splitting, the observed spectrum can be matched to the correct molecular structure. For the spectrum here, using the height of each peak to determine its relative area, gives:

| chemical shift $\\$ (ppm) | splitting | intensity | number of H |
| :-: | :-: | :-: | :-: |
| 1.2 | doublet | 2000 | 6 |
| 1.6 | triplet | 670 | 2 |
| 3.5 | singlet | 670 | 2 |
| 4.1 | sextet | 670 | 2 |

For each of the options, the number of chemical environments, integration, and expected splitting patterns are listed.

| ![CH2194-pentane-2,4-diol](images/CH2194-pentane-2,4-diol.png) $\\$ $\text{pentane--2,4--diol}$ | $\text{1 - 6H doublet} \\ \text{2 - 2H multiplet} \\ \text{3 - 2H singlet} \\ \text{4 - 2H triplet}$ |
| :-: | :-: |
| ![CH2197pentane](images/CH2197pentane.png) $\\$ pentane | 1 - 6H triplet $\\$ 2 - 4H multiplet $\\$ 3 - 2H quintet |
| ![CH2197pentane-1,5-diol](images/CH2197pentane-1,5-diol.png) $\\$ pentane-1,5-diol| 1 - 2H singlet $\\$ 2 - 4H triplet $\\$ 3 - 4H multiplet $\\$ 4 - 2H quintet |
| ![CH2197pentan-3-ol](images/CH2197pentan-3-ol.png)$\\$ pentan-3-ol | 1 - 6H triplet $\\$ 2 - 4H multiplet $\\$ 3 - 1H quintet $\\$ 4 - 1H singlet |

The molecule is $\text{pentane--2,4--diol}$ with four distinct chemical environments with a $6:2:2:2$ ratio and a splitting pattern that matches the one observed.
