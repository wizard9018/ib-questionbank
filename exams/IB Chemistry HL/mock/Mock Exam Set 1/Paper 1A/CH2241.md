# CH2241

The table below shows the number of protons and electrons for three nuclides: J$-$32, X$-$52, and Z$-$54.

Element|Protons|Electrons
:-:|:-:|:-:
J$-$32 |  16 | 18
X$-$52 |  23 | 20
Z$-$54 |  24 | 24

Which of the following correctly shows chemical symbol for each species?

-   A.$\hspace{1.em}\ce{^{32}_{16}J^{2-}},\ce{^{52}_{23}X^{3+}},\ce{^{54}_{24}Z}$

-   B.$\hspace{1.em}\ce{^{16}_{32}J^{2-}},\ce{^{29}_{52}X^{3+}},\ce{^{30}_{54}Z}$

-   C.$\hspace{1.em}\ce{^{32}_{16}J^{2+}},\ce{^{52}_{23}X^{3-}},\ce{^{54}_{24}Z}$

-   D.$\hspace{1.em}\ce{^{16}_{16}J^{2-}},\ce{^{29}_{23}X^{3+}},\ce{^{30}_{24}Z}$

---

## 评分标准 / Mark scheme

**答案：A**

$\textrm{\underline{Explanation:}}$\
To write correct nuclear symbols, we need to understand the nuclear notation format and determine the charge for each species.

Nuclear symbols are written as $\ce{_Z^A X^{q}},$ where $A$ is the mass number or number of nucleons, $Z$ is the atomic number or number of protons, X is the element symbol, and $q$ is the charge.   The charge is calculated using the relationship: charge = protons $-$ electrons.

For J$-$32: With 16 protons and 18 electrons, the species has 2 more electrons than protons, giving it a $2-$ charge. The mass number is 32, and the atomic number is 16. This is written as $\ce{^{32}_{16}J^{2-}}.$

For X$-$52: With 23 protons and 20 electrons, the species has 3 fewer electrons than protons, giving it a $3+$ charge. This is written as $\ce{^{52}_{23}X^{3+}}.$

For Z$-$54: With equal numbers of protons and electrons, this is a neutral atom with no charge, written as $\ce{^{54}_{24}Z}.$
