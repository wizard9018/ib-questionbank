# CH2187

What is the correct IUPAC name of this compound?

![CH2187](images/CH2187.png)

-   A. $\hspace{1em}1,2,2\text{--}$trimethylpentane

-   B. $\hspace{1em}1\text{--}$ethyl$\text{--1--}$dimethylbutane

-   C. $\hspace{1em}3,3\text{--}$dimethylhexane

-   D. $\hspace{1em}1,1,2\text{--}$propylpentane

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$

To determine the correct IUPAC name of a hydrocarbon, begin by identifying the longest continuous carbon chain. In this case, the longest chain has six carbon atoms, so the base name is hexane.

![CH2187ans](images/CH2187ans.png)

Next, locate and name the substituents. There are two methyl groups attached to the same carbon on the main chain. To assign correct positions, number the carbon chain from the end closest to the substituents. Both methyl groups are bonded to carbon number 3. The presence of two identical groups is indicated by the prefix di, and both their positions are listed. Therefore, the correct name is :answer[**3,3$\textbf{--}$dimethylhexane**].
