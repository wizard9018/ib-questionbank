# CH2188

Which of the following lists the oxidation number of oxygen in each compound in increasing order?

-   A. $\hspace{1em}\ce{Na2O} < \ce{O3} < \ce{OF2}$

-   B. $\hspace{1em}\ce{Na2O} < \ce{OF2} < \ce{O3}$

-   C. $\hspace{1em}\ce{OF2}\approx \ce{Na2O} < \ce{O3}$

-   D. $\hspace{1em}\ce{O3} < \ce{Na2O}\approx \ce{OF2}$

---

## 评分标准 / Mark scheme

**答案：A**

$\textrm{\underline{Explanation:}}$

The oxidation number of oxygen in each compound can be determined using the standard rules. The rules are listed in order of decreasing importance: Rule 1 is always followed but Rule 4 would be invalid in a compound like NaH where Rules 1 and 2 take priority so hydrogen has an oxidation number of $-1.$

-   $\text{1.}\hspace{1em}$The sum of the oxidation numbers of each atom is equal to the overall charge.
-   $\textcolor{white}{1.\hspace{1em}}$All elements have oxidation numbers of 0.
-   $\text{2.}\hspace{1em}$Group 1 metal atoms have an oxidation number of $+1$.
-   $\textcolor{white}{2.\hspace{1em}}$Group 2 metal atoms have an oxidation state of $+2.$
-   $\textcolor{white}{2.\hspace{1em}}$Group 13 metals have an oxidation number of $+3.$
-   $\text{3.}\hspace{1em}$Fluorine has an oxidation number of $-1.$
-   $\text{4.}\hspace{1em}$Hydrogen has an oxidation number of $+1.$
-   $\text{5.}\hspace{1em}$Oxygen has an oxidation number of $-2.$
-   $\text{6.}\hspace{1em}$Group 17 atoms have an oxidation number of $-1.$
-   $\text{7.}\hspace{1em}$Group 16 atoms have an oxidation state of $-2.$
-    $\textcolor{white}{2.\hspace{1.em}}$Group 15 atoms have an oxidation state of $-3.$

Applying these rules to the compounds here will allow the ranking.

$\ce{Na2O}:$ The sum of the oxidation numbers is 0 and sodium has an oxidation number of $+1.$  Using $x$ for the oxidation number of  oxygen:

$2(+1) + x = 0\ ; \quad x = -2$

$\ce{O3}:$ Oxygen is in an elemental form, so its oxidation number is 0

$\ce{OF2}:$ The sum of the oxidation numbers is 0 and fluorine has an oxidation number of $-1.$  Using $x$ for the oxidation number of oxygen,

$x+2(-1) = 0\ ; \quad x = +2$

Now arrange in increasing order:

**答案：$\ce{Na2O}<\ce{O3}<\ce{OF2}$**
