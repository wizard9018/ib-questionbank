# CH2230

A $0.050\text{ mol dm}^{-3}$ solution of a $2,4,5\text{--}$trichlorophenol establishes the following equilibrium in water:

$\ce{C6H2Cl3OH(aq) + H2O(l) <=> C6H2Cl3O-(aq) + H3O+(aq)}\qquad K = 2.0\times 10^{-7}$

What is the pH of this solution?

-   A.$\hspace{1em}2.00$

-   B.$\hspace{1em}4.00$

-   C.$\hspace{1em}5.00$

-   D.$\hspace{1em}6.70$

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
To solve this problem, we need to calculate the pH of a weak acid solution. The acid, $2,4,5\text{--}$trichlorophenol, partially dissociates in water and establishes an equilibrium.

The initial concentration of the acid is $0.050\text{ mol dm}^{-3}.$ To organize our thinking about the equilibrium concentrations, we can use a RICE table:

| R    | $\ce{C6H2Cl3OH(aq)}$ | $\ce{+}$ | $\ce{H2O(l)}$ | $\ce{<=>}$ | $\ce{C6H2Cl3O-(aq)}$ | $\ce{+}$ | $\ce{H3O+(l)}$ |
| :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| $\textbf{I}$ | 0.050 | | | | 0 | | 0 |
| $\textbf{C}$ | $-x\textcolor{white}{-}$ | | | | $+x\textcolor{white}{+}$ | | $+x\textcolor{white}{+}$ |
| $\textbf{E}$ | $0.050-x$ | | | | $x$ | | $x$ |

We now substitute these values into the equilibrium constant expression:

$K = \dfrac{[\ce{C6H2Cl3O-}][\ce{H3O+}]}{[\ce{C6H2Cl3OH}]} = \dfrac{x^2}{0.050 - x} =  2.0\times 10^{-7}$

Because $K$ is small, we assume that $x \ll 0.050,$ allowing us to approximate the denominator:

$\dfrac{x^2}{0.050}\approx 2.0\times 10^{-7}$

Solving for $x:$

$x^2 = 2.0\times 10^{-7}\times 0.050 = 1.0\times 10^{-8}$

$x = 1.0\times 10^{-4}$

This gives the equilibrium concentration of $\ce{H3O+}$ as:

$[\ce{H3O+}] = 1.0\times 10^{-4}\text{ mol dm}^{-3}$

Finally, calculate the pH using:

$\text{pH} = -\log_{10}[\ce{H3O+}] = -\log_{10}(1.0\times 10^{-4}) = 4.00$
