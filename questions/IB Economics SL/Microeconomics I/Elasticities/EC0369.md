# EC0369

**Table 1- Economic data for Ireland**

| | 2016 | 2020 |

| --- | :-: | :-: |

| Real GNI per capita (US\$) | 51 740 | 66 010 |

| Population (millions) | 4.76 | 4.99 |

From 2016 to 2020, Ireland’s demand for new automobiles increased by nearly 38\%.

[$\text{\textquotedblleft}$Ireland .$\text{\textquotedblright}$ World Bank Open Data, data.worldbank.org/country/ireland. Accessed 28 Apr. 2024.]

Sketch an Engel curve for new automobiles in Ireland and identify Ireland’s location on the Engel curve for new automobiles in 2020. [3 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample Answer}}$:

![EC0369 fig1](<images/EC0369 fig1.png>)

$\underline{\textrm{Solution}}$:

    

YED = $\dfrac{\%\Delta Qd}{\%\Delta Y}$

$\%\Delta Q_d = 38\%$

$\%\Delta Y = \dfrac{2020\ GNI\ per\ capita - 2016\ GNI\ per\ capita}{2016\ GNI\ per\ capita} \times 100$

$\%\Delta Y = \dfrac{66\ 010 - 51\ 740}{51\ 740} \times 100 = 27.5\%$ ($\checkmark$)

YED = $\dfrac{38}{27.5}$ = 1.38 

A YED value of 1.38 signifies that automobiles are an income-elastic (luxury) good. 

![EC0369 fig2](<images/EC0369 fig2.png>)

For an **accurately labelled** Engel curve with 2 of the following features ($\checkmark$$\checkmark$)

When income increases

-   YED is income elastic$-$the curve is less than 45 degrees.

-   YED is income inelastic$-$the curve is greater than 45 degrees.

-   there is no change in quantity demanded$-$the curve is vertical

-   YED is negative$-$the curve is negatively sloped

For identifying the income elastic portion of the Engel curve as the position of Ireland in 2020 ($\checkmark$)

Note: the Engel curve can be drawn with the axes switched, in which case the above is reversed
