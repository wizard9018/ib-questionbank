## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{E}$    [1 mark]

* This question is correct because the text says: $\text{\textquotedblleft}$Ibiza es una isla en Espa$\text{\~{n}}$a" ($\text{\textquotedblleft}$Ibiza is an island in Spain"). This sentence clearly answers the question $\text{\textquotedblleft}\text{¿D\'{o}nde}$ est$\text{\'{a}}$?” ($\text{\textquotedblleft}$Where is it?").:br

* *Opci$\textit{\'{o}}$n incorrecta:* B

* **B**: $\text{\textquotedblleft}\text{¿Cu\'{a}ntas}$ personas tiene Ibiza? ($\text{\textquotedblleft}$How many people does Ibiza have?") is not correct because the paragraph does not mention population. It only describes the island and its beaches.

$2.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* This question is correct because the text says: $\text{\textquotedblleft}$Puedes nadar, tomar el sol y pasear por la playa" ($\text{\textquotedblleft}$You can swim, sunbathe and walk along the beach"). These are activities tourists can do, so it answers $\text{\textquotedblleft}\text{¿Qu\'{e}}$ actividades hay?” ($\text{\textquotedblleft}$What activities are they?").:br

* *Opci$\textit{\'{o}}$n incorrecta:* F

* **F**: $\text{\textquotedblleft}\text{¿D\'{o}nde}$ puedes comprar recuerdos?" ($\text{\textquotedblleft}$Where can you buy souvenirs?") is not correct because the paragraph talks about activities like swimming and relaxing, not shopping.

$3.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

* This question is correct because paragraph 3 says: $\text{\textquotedblleft}$Hay restaurantes con comida local e internacional" ($\text{\textquotedblleft}$There are restaurants with local and international food"). This sentence answers $\text{\textquotedblleft}\text{¿qu\'{e}}$ puedes comer” ($\text{\textquotedblleft}$what can you eat?").:br

* *Opci$\textit{\'{o}}$n incorrecta:* C

* **C**: $\text{\textquotedblleft}$¿A qu$\text{\'{e}}$ hora abren los restaurantes?" ($\text{\textquotedblleft}$What time do the restaurants open?") is not correct because the paragraph mentions types of food, not opening times.

$4.$ $\hspace{1em}$ $\textrm{m\'{u}sica y fiesta}$[1 mark]

* The question says: $\text{\textquotedblleft}$Al final del d$\text{\'{\i}}$a hay...” ($\text{\textquotedblleft}$At the end of the day there is..."). The text says: $\text{\textquotedblleft}$Por la noche, hay m$\text{\'{u}}$sica y fiesta" ($\text{\textquotedblleft}$At night, there is music and party"). This directly answers what there is at the end of the day.

$5.$ $\hspace{1em}$ $\textrm{para vacaciones divertidas}$    [1 mark]

* The question says: $\text{\textquotedblleft}$Ibiza es un lugar ideal...” ($\text{\textquotedblleft}$Ibiza is an ideal place..."). The text says: $\text{\textquotedblleft}$¡Ibiza es una isla perfecta para vacaciones divertidas!" ($\text{\textquotedblleft}$Ibiza is a perfect island for fun holidays!"). This shows what Ibiza is ideal for.
