# SA0296

**Complete each sentence with the correct pronoun: *me*, *te* or *le*.**

$1.$ $\hspace{1em}$A Sara no **[-1-]** interesan los museos de arte.    [1 mark]

$2.$ $\hspace{1em}$A mí **[-2-]** encanta viajar a otros países.    [1 mark]

$3.$ $\hspace{1em}$¿A ti **[-3-]** interesan las culturas diferentes?    [1 mark]

**Match each sentence to the correct pronoun and verb form. There are more options than sentences.** [3 marks]

|Sentence|Options|

|:--|:--|

|A mí **[-4-]** conocer lugares nuevos.|A.$\hspace{1em}$le interesan|

|¿A ti **[-5-]** las excursiones culturales?|B.$\hspace{1em}$me encanta|

|A mi hermana **[-6-]** aprender sobre otras culturas.$\hspace{3em}$|C.$\hspace{1em}$te gustan|

| |D.$\hspace{1em}$me interesan|

| |E.$\hspace{1em}$te encanta|

| |F.$\hspace{1em}$le gusta|

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{le}$    [1 mark]

- *A Sara* refers to (*ella*), so the correct pronoun is *le*. *Los museos de arte* is plural, so the verb is *interesan*.

$2.$ $\hspace{1em}$ $\textrm{me}$    [1 mark]

- *A mí* refers to (*yo*), so the correct pronoun is *me*.

$3.$ $\hspace{1em}$ $\textrm{te}$    [1 mark]

- *A ti* refers to (*tú*), so the correct pronoun is *te*.

$4.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

- *Me encanta* is correct. *A mí* requires *me*. The singular form *encanta* is used before the infinitive *conocer*.

- **Respuestas incorrectas:** A, C, D, E, F

- **A**: *Le interesan* is incorrect because the sentence uses *a mí*, so the pronoun must be *me*, not *le*.

- **C**: *Te gustan* is incorrect because the sentence uses *a mí*, so the pronoun must be *me*, not *te*.

- **D**: *Me interesan* uses the correct pronoun, but the infinitive *conocer* requires the singular form *interesa*.

- **E**: *Te encanta* is incorrect because the sentence uses *a mí*, so the pronoun must be *me*, not *te*.

- **F**: *Le gusta* is incorrect because the sentence uses *a mí*, so the pronoun must be *me*, not *le*.

$5.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

- *Te gustan* is correct because *a ti* refers to (*tú*), so the correct pronoun is *te*. The plural form *gustan* agrees with *las excursiones culturales*.

- **Respuestas incorrectas:** A, B, D, E, F

- **A**: *Le interesan* is incorrect because the sentence uses *a ti*, so the pronoun must be *te*, not *le*.

- **B**: *Me encanta* is incorrect because the sentence uses *a ti*, so the pronoun must be *te*, not *me*. The singular form *encanta* also does not agree with *las excursiones culturales*.

- **D**: *Me interesan* is incorrect because the sentence uses *a ti*, so the pronoun must be *te*, not *me*.

- **E**: *Te encanta* uses the correct pronoun, but the singular form *encanta* does not agree with *las excursiones culturales*.

- **F**: *Le gusta* is incorrect because the sentence uses *a ti*, so the pronoun must be *te*, not *le*. The singular form *gusta* also does not agree with *las excursiones culturales*.

$6.$ $\hspace{1em}$ $\textrm{F}$    [1 mark]

- *Le gusta* is correct because *a mi hermana* refers to (*ella*), so the correct pronoun is *le*. The singular form *gusta* is used before the infinitive *aprender*.

- **Respuestas incorrectas:** A, B, C, D, E

- **A**: *Le interesan* uses the correct pronoun, but the infinitive *aprender* requires the singular form *interesa*.

- **B**: *Me encanta* is incorrect because *a mi hermana* needs *le*, not *me*.

- **C**: *Te gustan* is incorrect because *a mi hermana* needs *le*, not *te*.

- **D**: *Me interesan* is incorrect because *a mi hermana* needs *le*, not *me*.

- **E**: *Te encanta* is incorrect because *a mi hermana* needs *le*, not *te*.

**Grammar reminder:**

In Spanish, *gustar*, *encantar* and *interesar* are used with the pronouns *me*, *te*, *le*, *nos*, *os* and *les*. The pronoun changes depending on the person who experiences the feeling.

|Person|Pronoun|

|:--|:--|

|(*a mí*)|*me*|

|(*a ti*)|*te*|

|(*a él*, *a ella*, *a usted*)|*le*|

|(*a nosotros/as*)|*nos*|

|(*a vosotros/as*)|*os*|

|(*a ellos/as*, *a ustedes*)|*les*|

The verb is singular before an infinitive or a singular noun, and plural before a plural noun.

|Verb form|Used before|Example|

|:--|:--|:--|

|*gusta* / *encanta* / *interesa*|an infinitive|*Me gusta correr.*|

|*gusta* / *encanta* / *interesa*|a singular noun|*Le encanta la natación.*|

|*gustan* / *encantan* / *interesan*|a plural noun|*Nos interesan los deportes.*|
