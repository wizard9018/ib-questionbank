# SA0368

**Choose the correct present perfect verb form.**

$\hspace{1em}$Esta $\text{ma\~{n}ana}$, yo **\[-1-]** el museo del pueblo.    [1 mark]

* A.$\hspace{1em}$ha visitado

* B.$\hspace{1em}$he visitar

* C.$\hspace{1em}$he visitado

* D.$\hspace{1em}$he visitando

$\hspace{1em}$Hoy, mis padres **\[-2-]** una $\text{excursi\'{o}n}$.    [1 mark]

* A.$\hspace{1em}$han hecho

* B.$\hspace{1em}$han hacido

* C.$\hspace{1em}$hemos hecho

* D.$\hspace{1em}$han hacer

**Complete each sentence. Use the correct option in brackets.** [3 marks]

Durante estas vacaciones, $\text{t\'{u}}$ **\[-3-]** muchas fotos. (has sacado / ha sacado)

Esta semana, mi hermana y yo **\[-4-]** varios platos $\text{t\'{\i}picos}$. (han probado / hemos probado)

Hoy, $\text{Luc\'{\i}a}$ **\[-5-]** el mercado del pueblo. (ha visto / ha $\text{ve\'{\i}do}$)

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* The subject is *yo*, so use *he*. The participle of *visitar* is *visitado*: *he visitado*.

* *Opciones incorrectas:* A, B, D

* **A**: *Ha visitado* is the *$\textit{\'{e}l/ella/usted}$* form, but the subject is *yo*.

* **B**: *Visitar* is the infinitive. After *he*, use the participle *visitado*.

* **D**: *Visitando* is not the participle. Use *visitado*.

$2.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* *Mis padres* refers to *ellos*, so use *han*. The irregular participle of *hacer* is *hecho*: *han hecho*.

* *Opciones incorrectas:* B, C, D

* **B**: *Hacido* is incorrect. The participle of *hacer* is *hecho*.

* **C**: *Hemos hecho*is the *nosotros/as* form, but *mis padres* refers to *ellos*.

* **D**: Hacer is the infinitive. After han, use hecho.

$3.$ $\hspace{1em}$ $\textrm{has sacado}$    [1 mark]

* The subject is *$\textit{t\'{u}}$*, so use *has*. The participle of *sacar* is *sacado*.

* *Opciones incorrectas:*

* *Ha sacado* is the *$\textit{\'{e}l/ella/usted}$* form, but the subject is *$\textit{t\'{u}}$*.

$4.$ $\hspace{1em}$ $\textrm{hemos probado}$    [1 mark]

* *Mi hermana y yo* refers to *nosotros/as*, so use *hemos*. The participle of *probar* is *probado*.

* *Opciones incorrectas:*

* *Han probado* is the *ellos/ellas/ustedes* form, but *mi hermana y yo* includes the speaker and therefore refers to *nosotros/as*.

$5.$ $\hspace{1em}$ $\textrm{ha visto}$    [1 mark]

* $\text{Luc\'{\i}a}$ refers to *ella*, so use *ha*. The irregular participle of *ver* is *visto*.

* *Opciones incorrectas:*

* *Ha $\textit{ve\'{\i}do}$* uses an incorrect participle. Use *visto*.

**Grammar reminder**

The present perfect describes past actions connected to the present, often with *hoy, esta semana* or *estas vacaciones*. Use **haber + past participle**.

| Rule | Forms / Examples |

| :- | :- |

| $\hspace{1em}$Choose *haber* to match the subject. | $\hspace{1em}$*(yo) he; ($\textit{t\'{u}}$) has; ($\textit{\'{e}l/ella/usted}$) ha; (nosotros/as) hemos; (vosotros/as) $\textit{hab\'{e}is}$; (ellos/ellas/ustedes) han.* |

| $\hspace{1em}$Regular participles: replace *-ar* with *-ado*, and *-er* / -ir with -ido. | $\hspace{1em}$*visitar: visitado; comer: comido; salir: salido* |

| $\hspace{1em}$Common irregular participles | $\hspace{1em}$*hacer: hecho; ver: visto; escribir: escrito; volver: vuelto; abrir: abierto; poner: puesto; decir: dicho; romper: roto; descubrir: descubierto; resolver: resuelto* |

| $\hspace{1em}$With reflexive verbs, put the pronoun before *haber*. | $\hspace{1em}$*Me he duchado. Se ha despertado. Nos hemos acostado.* |

**Common mistake**: changing the participle for gender or number. It stays unchanged after *haber*. *Mis $\textit{t\'{\i}as}$ han comprado flores*, not *han compradas*.
