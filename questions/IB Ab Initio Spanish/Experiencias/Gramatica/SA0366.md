# SA0366

**Write a complete sentence using the words given. Conjugate the verbs in brackets in the pretérito indefinido or the imperfecto.** 

$1.$ $\hspace{1em}$yo / (dormir) / cuando / (sonar) / el teléfono    [1 mark]

$2.$ $\hspace{1em}$el año pasado / mis primos / (visitar) / Londres / tres veces    [1 mark]

$3.$ $\hspace{1em}$de niño / Pablo / (ser) / muy tímido / y / no / (hablar) / mucho    [1 mark]

**Complete the paragraph with the correct form of the verb in brackets. Use the pretérito indefinido or the imperfecto.** [4 marks]

El verano pasado fui a México con mi familia. Cuando llegamos, **[-4-]** (hacer) mucho calor y la ciudad **[-5-]** (estar) llena de turistas. Por la mañana visitamos un mercado y por la tarde mi padre **[-6-]** (comprar) un sombrero. Por la noche, mientras cenábamos en un restaurante, unos músicos **[-7-]** (empezar) a tocar.

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{Yo dormía cuando sonó el teléfono.}$    [1 mark]

- *Cuando sonó el teléfono, yo dormía.* is also correct. The clause *cuando sonó el teléfono* can appear before or after the main clause.\

*Dormía* is correct because the imperfecto describes the action in progress. *Sonó* is correct because the pretérito indefinido describes the event that interrupted it.

- *Opción incorrecta:* 

- *Dormí* is incorrect because it presents sleeping as a completed action, not as the action in progress. *Sonaba* is incorrect because it presents the phone ringing as background, but it is the event that interrupted the sleep.

$2.$ $\hspace{1em}$ $\textrm{El año pasado mis primos visitaron Londres tres veces.}$    [1 mark]

- *Mis primos visitaron Londres tres veces el año pasado.* is also correct. The time expression *el año pasado* can appear at the beginning or at the end of the sentence.\

*Visitaron* is correct because *tres veces* counts the visits and *el año pasado* closes the period. Repeated actions that are counted use the pretérito indefinido; the imperfecto is used for *habits* that are not counted (*visitaban Londres todos los años*). *Visitaron* is the *ellos* form, matching *mis primos*.

$3.$ $\hspace{1em}$ $\textrm{De niño, Pablo era muy tímido y no hablaba mucho.}$    [1 mark]

- *Pablo era muy tímido de niño y no hablaba mucho.* is also correct. The expression *de niño* can appear at the beginning or after muy tímido.\

*Era* is correct because personality in the past is a description, which requires the imperfecto. *Hablaba* is correct because *de niño* describes how Pablo usually behaved, which is a habit.

- *Opción incorrecta:* 

- *Fue* is incorrect because the pretérito indefinido presents a completed event, but *muy tímido* describes Pablo's personality as a child.\

*Habló* is incorrect because the pretérito indefinido presents a single completed action, but *no hablaba mucho* describes how Pablo usually behaved.

$4.$ $\hspace{1em}$ $\textrm{hacía}$    [1 mark]

- *Hacía* is correct because the weather is described as the situation when the family arrived (*cuando llegamos*), which requires the imperfecto.

$5.$ $\hspace{1em}$ $\textrm{estaba}$    [1 mark]

- *Estaba* is correct because it describes what the city was like on arrival, which requires the imperfecto. *Estaba* is the *ella* form, matching *la ciudad*.

$6.$ $\hspace{1em}$ $\textrm{compró}$    [1 mark]

- *Compró* is correct because *por la mañana... por la tarde* presents a sequence of completed actions, which requires the pretérito indefinido. *Compró* is the *él* form, matching *mi padre*.

$7.$ $\hspace{1em}$ $\textrm{empezaron}$    [1 mark]

- *Empezaron* is correct because the musicians starting to play is an event that happened during the action in progress (*mientras cenábamos*), which requires the pretérito indefinido. *Empezaron* is the *ellos* form, matching *unos músicos*.\

\

**Model answer**: El verano pasado fui a México con mi familia. Cuando llegamos, hacía mucho calor y la ciudad estaba llena de turistas. Por la mañana visitamos un mercado y por la tarde mi padre compró un sombrero. Por la noche, mientras cenábamos en un restaurante, unos músicos empezaron a tocar.
