# SA0270

**Each sentence contains $\underline{\textbf{one}}$ error with the present tense form of *estar*. Find the error and write the correct form.**

$1.$ $\hspace{1em}$Usted estás muy contento porque el viernes viaja a Chile y puede practicar su español.    [1 mark]

$2.$ $\hspace{1em}$Tú están en Uruguay esta semana, ¿verdad?    [1 mark]

**Complete the paragraph with the correct present tense form of *estar*.** [3 marks]

Hoy mi esposa y yo viajamos a Madrid y por eso **[-3-]** muy entusiasmados. Nuestros amigos ya **[-4-]** en el aeropuerto para empezar esta experiencia con nosotros. La ciudad de destino **[-5-]** preparada para recibir a muchos turistas este verano.

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{est\'{a}}$    [1 mark]

- *Estás* is the (*tú*) form, but the subject is (*usted*), so the correct form is *está*. *Usted* uses the same verb form as *él* and *ella*. We use *estar* to express how someone feels.\

\

**Model answer**: Usted está muy contento porque el viernes viaja a Chile y puede practicar su español.

$2.$ $\hspace{1em}$ $\textrm{est\'{a}s}$    [1 mark]

- *Están* is the (*ellos/ellas/ustedes*) form, but the subject is (*tú*), so the correct form is *estás*. We use *estar* to express location.\

\

**Model answer**: Tú estás en Uruguay esta semana, ¿verdad?

$3.$ $\hspace{1em}$ $\textrm{estamos}$    [1 mark]

- *Mi esposa y yo* includes the speaker and refers to (*nosotros*), so the correct form is *estamos*. We use *estar* to express how someone feels.

$4.$ $\hspace{1em}$ $\textrm{est\'{a}n}$    [1 mark]

- *Nuestros amigos* refers to (*ellos*), so the correct form is *están*. We use *estar* to express location.

$5.$ $\hspace{1em}$ $\textrm{est\'{a}}$    [1 mark]

- *La ciudad de destino* refers to (*ella*), so the correct form is *está*. We use *estar* to express a state or condition.\

\

**Model answer**: Hoy mi esposa y yo viajamos a Madrid y por eso estamos muy entusiasmados. Nuestros amigos ya están en el aeropuerto para empezar esta experiencia con nosotros. La ciudad de destino está preparada para recibir a muchos turistas este verano.
