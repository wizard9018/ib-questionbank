# SA0297

**Choose the correct pronoun and form of *gustar*, *encantar* or *interesar*.**

$\hspace{1em}$A mi padre **\[-1-]** visitar lugares $\text{hist\'{o}ricos}$.    [1 mark]

* A.$\hspace{1em}$me interesa

* B.$\hspace{1em}$te interesan

* C.$\hspace{1em}$le interesa

* D.$\hspace{1em}$le interesan

$\hspace{1em}$A mis hermanos **\[-2-]** las experiencias nuevas.    [1 mark]

* A.$\hspace{1em}$les encantan

* B.$\hspace{1em}$le encanta

* C.$\hspace{1em}$me encantan

* D.$\hspace{1em}$les encanta

**Put the words in the correct order. Write the complete sentence.**

$3.$ $\hspace{1em}$gusta / A / viajar / me / $\text{m\'{\i}}$ / en tren    [1 mark]

$4.$ $\hspace{1em}$interesan / fiestas / A / tradicionales / las / Sara / le    [1 mark]

$5.$ $\hspace{1em}$ti / los / ¿A / encantan / aventura / viajes / te / de?    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* *Le interesa* is correct because *a mi padre* refers to (*$\textit{\'{e}l}$*) and requires *le*. The singular form *interesa* is used before the infinitive *visitar*.

* **Respuestas incorrectas:** A, B, D

* **A**: *Me interesa* uses *me*, but *a mi padre* requires *le*.

* **B**: *Te interesan* uses *te*, but *a mi padre* requires *le*. The infinitive *visitar* also requires the singular form *interesa*.

* **D**: *Le interesan* uses the correct pronoun, but the infinitive *visitar* requires the singular form *interesa*.

$2.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* *Les encantan* is correct because *a mis hermanos* refers to (*ellos*), so the correct pronoun is *les*. The plural form *encantan* agrees with *las experiencias nuevas*.

* **Respuestas incorrectas:** B, C, D

* **B**: *Le encanta* uses *le*, but *a mis hermanos* requires *les*. The singular form *encanta* also does not agree with *las experiencias nuevas*.

* **C**: *Me encantan* uses *me*, but *a mis hermanos* requires *les*. The verb form *encantan* is correct, but the pronoun is wrong.

* **D**: *Les encanta* uses the correct pronoun, but the singular form *encanta* does not agree with *las experiencias nuevas*.

$3.$ $\hspace{1em}$ $\textrm{A m\'{\i} me gusta viajar en tren.}$    [1 mark]

* *A $\textit{m\'{\i}}$* refers to (*yo*), so the correct pronoun is *me*. The infinitive *viajar* takes the singular form *gusta*.

$4.$ $\hspace{1em}$ $\textrm{A Sara le interesan las fiestas tradicionales.}$    [1 mark]

* *A Sara* refers to (*ella*), so the correct pronoun is *le*. *Las fiestas tradicionales* is plural, so the verb is *interesan*.

$5.$ $\hspace{1em}$ $\textrm{¿A ti te encantan los viajes de aventura?}$    [1 mark]

* *A ti* refers to (*$\textit{t\'{u}}$*), so the correct pronoun is *te*. *Los viajes de aventura* is plural, so the verb is *encantan*.
