# SA0037

\[Puntaje m$\text{\'{a}}$ximo: 6]:br

**Inti Raymi**

Estoy en Cusco y hoy voy a una celebraci$\text{\'{o}}$n muy especial. Se llama Inti Raymi y tiene lugar en junio.

**\[-1-]**\

Las personas celebran una tradici$\text{\'{o}}$n antigua de Per$\text{\'{u}}$ de origen inca que tiene relaci$\text{\'{o}}$n con el sol.

**\[-2-]**\

Muchas personas llevan ropa tradicional y se divierten. Hay m$\text{\'{u}}$sica, bailes y comida t$\text{\'{\i}}$pica, y tambi$\text{\'{e}}$n muchos turistas. La atm$\text{\'{o}}$sfera es muy animada y colorida.

**\[-3-]**\

Me gusta mucho porque es diferente y as$\text{\'{\i}}$ puedo conocer mejor la cultura de Per$\text{\'{u}}$.

**Elige de la lista el subt$\textbf{\'{\i}}$tulo apropiado para completar cada espacio del texto.** [3 marks]

* A.$\hspace{1em}$Gente diferente

* B.$\hspace{1em}\text{Valoraci\'{o}n}$ del festival

* C.$\hspace{1em}$La duraci$\text{\'{o}}$n

* D.$\hspace{1em}$Una costumbre antigua

* E.$\hspace{1em}\text{Cr\'{\i}ticas}$

* F.$\hspace{1em}$El ambiente

* A.$\hspace{1em}$Inti Raymi es una fiesta extraordinaria.

* B.$\hspace{1em}$Inti Raymi se celebra en primavera.

* C.$\hspace{1em}$La gente se viste con ropa t$\text{\'{\i}}$pica.

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

- *Una costumbre antigua* (*an ancient tradition*) is correct. The answer is found when the text says: $\text{\textquotedblleft}$Las personas celebran una tradición antigua de Perú de origen inca...” ($\text{\textquotedblleft}$People celebrate an ancient tradition of Peru of Inca origin"). This clearly describes an old tradition.

- *Opción incorrecta:* A

- **A**: *Gente diferente* (*different people*) is not correct because the paragraph does not describe types of people, but the origin of the celebration.

$2.$ $\hspace{1em}$ $\textrm{F}$    [1 mark]

- *El ambiente* (*the atmosphere*) is correct. The answer is found in the text when it says: $\text{\textquotedblleft}$Hay música, bailes... La atmósfera es muy animada y colorida.” ($\text{\textquotedblleft}$There is music, dancing... The atmosphere is very lively and colorful"). This describes the environment of the festival.

- *Opción incorrecta:* C

- **C**: *La duración* (*duration*) is not correct because the paragraph does not mention how long the festival lasts.

$3.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

- *Valoración del festival* (*evaluation of the festival*) is correct. The answer is found when the text says: $\text{\textquotedblleft}$Me gusta mucho porque es diferente...” ($\text{\textquotedblleft}$I like it a lot because it is different"). This expresses a personal opinion.

- *Opción incorrecta:* E

- **E**: *Críticas* (*criticism*) is not correct because the text is positive, not negative.

$4 - 6.$ $\hspace{1em}$

*Las respuestas pueden estar en cualquier orden.*  

- $\hspace{1em}$ $\textrm{A, C, E}$        [3 marks]

- **A**: The option says: $\text{\textquotedblleft}$Inti Raymi es una fiesta extraordinaria" ($\text{\textquotedblleft}$Inti Raymi is an extraordinary festival"). The text says: $\text{\textquotedblleft}$una celebración muy especial" ($\text{\textquotedblleft}$a very special celebration"). *Muy especial* and *extraordinaria* share the same meaning in this context.

- **C**: The option says: $\text{\textquotedblleft}$La gente se viste con ropa típica" ($\text{\textquotedblleft}$People wear traditional clothes"). The text says: $\text{\textquotedblleft}$Muchas personas llevan ropa tradicional" ($\text{\textquotedblleft}$Many people wear traditional clothes"). This matches the statement.

- **E**: The option says: $\text{\textquotedblleft}$Puedo saber más sobre la cultura peruana" ($\text{\textquotedblleft}$I can learn more about Peruvian culture"). The text says: $\text{\textquotedblleft}$puedo conocer mejor la cultura de Perú" ($\text{\textquotedblleft}$I can know Peruvian culture better"). This confirms the idea.

- *Opciones Incorrectas:*  B, D, F

- **B**: The option says: $\text{\textquotedblleft}$Inti Raymi se celebra en primavera" ($\text{\textquotedblleft}$Inti Raymi is celebrated in spring"). This is not correct because the text says: $\text{\textquotedblleft}$tiene lugar en junio" ($\text{\textquotedblleft}$it happens in June"), not in spring.

- **D**: The option says: $\text{\textquotedblleft}$Es una fiesta bastante aburrida" ($\text{\textquotedblleft}$It is quite boring"). This is not correct because the text says: $\text{\textquotedblleft}$muy animada y colorida" ($\text{\textquotedblleft}$very lively and colorful").

- **F**: The option says: $\text{\textquotedblleft}$Odio Inti Raymi porque es distinto" ($\text{\textquotedblleft}$I hate Inti Raymi because it is different"). This is not correct because the text says: $\text{\textquotedblleft}$Me gusta mucho porque es diferente" ($\text{\textquotedblleft}$I like it very much because it is different").
