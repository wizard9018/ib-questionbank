# SA0279

**Complete the paragraph with the correct form of the adjectives in brackets.** [3 marks]

En mi familia somos muy diferentes. Mis padres nacieron en Guadalajara y son **[-1-]** (*mexicano*). Mi hermana tiene dos perros muy **[-2-]** (*juguetón*) y mis abuelos son personas muy **[-3-]** (*cariñoso*).

**The paragraph contains $\underline{\textbf{three}}$ errors in adjective agreement. Find the errors and write the correct forms in the order in which they appear.** [3 marks]

Mi tío lleva una chaqueta negro y unos pantalones blancas. También tiene unas gafas azul que le gustan mucho.

**Complete the second sentence with the plural forms of the adjectives in the first sentence.** [2 marks]

Laura es una chica simpática y trabajadora.

Laura y Marta son dos chicas **[-7-]** y **[-8-]**.

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{mexicanos}$    [1 mark]

- *Mis padres* is masculine plural, so the adjective must also be masculine plural. *Mexicano* changes to *mexicanos*.

$2.$ $\hspace{1em}$ $\textrm{juguetones}$    [1 mark]

- *Dos perros* is masculine plural, so the adjective must also be masculine plural. Adjectives ending in a consonant add *-es* for the plural, so *juguetón* changes to *juguetones*.

- In the plural, *juguetón* loses its written accent: the correct spelling is *juguetones*. The mark is not lost for an accent error, but it is important to learn the correct spelling.

$3.$ $\hspace{1em}$ $\textrm{cari\~{n}osas}$    [1 mark]

- The adjective describes *personas*, which is feminine plural, so the correct form is *cariñosas*. *Persona* is always feminine, even when it refers to men, so the adjective agrees with *personas*, not with *mis abuelos*.\

\

**Model answer**: En mi familia somos muy diferentes. Mis padres nacieron en Guadalajara y son mexicanos. Mi hermana tiene dos perros muy juguetones y mis abuelos son personas muy cariñosas.

$4.$ $\hspace{1em}$ $\textrm{negra}$    [1 mark]

- *Negro* is masculine singular, but it describes *una chaqueta*, which is feminine singular, so the correct form is *negra*. The adjective agrees with *chaqueta*, not with *mi tío*.

$5.$ $\hspace{1em}$ $\textrm{blancos}$    [1 mark]

- *Blancas* is feminine plural, but it describes *unos pantalones*, which is masculine plural, so the correct form is *blancos*.

$6.$ $\hspace{1em}$ $\textrm{azules}$    [1 mark]

- *Azul* is singular, but it describes *unas gafas*, which is plural, so the correct form is *azules*. Adjectives ending in a consonant add *-es* for the plural. *Azul* has the same form for masculine and feminine.\

\

**Model answer**: Mi tío lleva una chaqueta negra y unos pantalones blancos. También tiene unas gafas azules que le gustan mucho.

$7.$ $\hspace{1em}$ $\textrm{simp\'{a}ticas}$    [1 mark]

- *Laura y Marta* are two girls, so the adjective must be feminine plural. *Simpática* changes to *simpáticas*.

- - The correct spelling is *simpáticas*, with an accent on the *á*. The mark is not lost for an accent error, but it is important to learn the correct spelling.

$8.$ $\hspace{1em}$ $\textrm{trabajadoras}$    [1 mark]

- *Laura y Marta* are two girls, so the adjective must be feminine plural. *Trabajadora* changes to *trabajadoras*.\

\

**Model answer**: Laura y Marta son dos chicas simpáticas y trabajadoras.
