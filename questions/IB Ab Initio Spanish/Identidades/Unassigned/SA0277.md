# SA0277

**Choose the correct form of the adjective.**

$\hspace{1em}$Mi abuelo es un taxista muy **[-1-]**.    [1 mark]

- A.$\hspace{1em}$trabajador

- B.$\hspace{1em}$trabajadora

- C.$\hspace{1em}$trabajadores

- D.$\hspace{1em}$trabajadoras

**Complete each sentence with the correct form of the adjective in brackets.**

$\hspace{1em}$Las chicas $\text{est\'{a}n}$ **[-2-]** (*enfermo*).    [1 mark]

$\hspace{1em}$Sus $\text{compa\~{n}eros}$ son muy **[-3-]** (*interesante*).    [1 mark]

**Each sentence contains $\underline{\textbf{one}}$ error in adjective agreement. Find the error and write the correct form of the adjective.**

$4.$ $\hspace{1em}$Mi hermana es bastante honesto.    [1 mark]

$5.$ $\hspace{1em}$Mi profesora es muy pacientes.    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

- *Trabajador* is correct because *un taxista* refers to *mi abuelo*, who is masculine singular. *Taxista* ends in *-a*, but it is used for both men and women. Here, *un* shows that it is masculine.

- **Respuestas incorrectas:** B, C, D

- **B**: *Trabajadora* is feminine singular, but *un taxista* refers to *mi abuelo*, who is masculine.

- **C**: *Trabajadores* is masculine plural, but *mi abuelo* refers to one person.

- **D**: *Trabajadoras* is feminine plural, but *mi abuelo* is masculine singular.

$2.$ $\hspace{1em}$ $\textrm{enfermas}$    [1 mark]

- *Las chicas* is feminine plural, so the adjective must also be feminine plural. *Enfermo* changes to *enfermas*.

$3.$ $\hspace{1em}$ $\textrm{interesantes}$    [1 mark]

- *Sus compañeros* is plural, so the adjective must also be plural. Adjectives ending in *-e* have the same form for masculine and feminine. We only add *-s* for the plural.

$4.$ $\hspace{1em}$ $\textrm{honesta}$    [1 mark]

- *Honesto* is masculine singular, but *mi hermana* is feminine singular, so the correct form is *honesta*.\

\

**Model answer**: Mi hermana es bastante honesta.

$5.$ $\hspace{1em}$ $\textrm{paciente}$    [1 mark]

- *Pacientes* is plural, but *mi profesora* refers to one person, so the correct form is *paciente*. Adjectives ending in *-e* do not change for feminine.\

\

**Model answer**: Mi profesora es muy paciente.
