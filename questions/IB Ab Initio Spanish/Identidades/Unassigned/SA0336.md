# SA0336

**Choose the correct possessive adjective.** 

$\hspace{1em}$Yo tengo una hermana. **[-1-]** hermana se llama Elena.    [1 mark]

- A.$\hspace{1em}$mi

- B.$\hspace{1em}$mis

- C.$\hspace{1em}$su

- D.$\hspace{1em}$sus

$\hspace{1em}$Tú tienes dos hermanos. **[-2-]** hermanos estudian aquí.    [1 mark]

- A.$\hspace{1em}$tu

- B.$\hspace{1em}$tus

- C.$\hspace{1em}$su

- D.$\hspace{1em}$sus

**Match each description to the correct possessive adjective. There are more options than descriptions.**    [3 marks]

|:--|:--|

|$\hspace{1em}$ |$\hspace{1em}$D.$\hspace{1em}$tus |

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

- *Mi* is correct because the owner is *yo* and *hermana* is one person. With *yo* and one thing, the possessive is *mi*.

- *Respuestas incorrectas:*

- B. *Mis* is used with *yo* when there is more than one thing, but *hermana* is singular.

- C. *Su* is used when the owner is *él*, *ella*, *usted*, *ellos*, *ellas* or *ustedes*, but the owner here is *yo*.

- D. *Sus* is plural and is used with the same owners as *su*, not with *yo*.

$2.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

- *Tus* is correct because the owner is *tú* and *hermanos* is plural. With *tú* and more than one thing, the possessive is *tus*.

- *Respuestas incorrectas:*

- A. *Tu* is used with *tú* when there is only one thing, but *hermanos* is plural.

- C. *Su* is singular and is used when the owner is *él*, *ella*, *usted*, *ellos*, *ellas* or *ustedes*, not *tú*.

- D. *Sus* has the correct plural form for *hermanos*, but it is used with *él*, *ella*, *usted*, *ellos*, *ellas* or *ustedes*, not *tú*.

$3.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

- *Mis* is correct because the owner is *yo* and *primas* is plural. With *yo* and more than one thing, the possessive is *mis*.

- *Respuestas incorrectas:*

- A. *Su* is used when the owner is *él*, *ella*, *usted*, *ellos*, *ellas* or *ustedes*, not *yo*, and only with one thing.

- C. *Tu* is used when the owner is *tú*, and only with one thing.

- D. *Tus* is plural, but it is used when the owner is *tú*, not *yo*.

- E. *Nuestro* is used when the owner is *nosotros/as*, and only with one masculine thing.

- F. *Nuestra* is used when the owner is *nosotros/as*, and only with one feminine thing.

$4.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

- *Tu* is correct because the owner is *tú* and *amiga* is one person. With *tú* and one thing, the possessive is *tu*.

- *Respuestas incorrectas:*

- A. *Su* is singular like *amiga*, but it is used when the owner is *él*, *ella*, *usted*, *ellos*, *ellas* or *ustedes*, not *tú*.

- B. *Mis* is used when the owner is *yo*, and only with more than one thing.

- D. *Tus* is used with *tú*, but *amiga* is singular, so the plural form is incorrect.

- E. *Nuestro* is used when the owner is *nosotros/as*, and it is masculine, but *amiga* is feminine.

- F. *Nuestra* is feminine singular like *amiga*, but it is used when the owner is *nosotros/as*, not *tú*.

$5.$ $\hspace{1em}$ $\textrm{F}$    [1 mark]

- *Nuestra* is correct because *Lucía y yo* includes the speaker (*nosotras*), and *abuela* is feminine and singular. With *nosotros/as*, the possessive changes for gender and number, so the form is *nuestra*.

- *Respuestas incorrectas:*

- A. *Su* is singular like *abuela*, but it is used when the owner is *él*, *ella*, *usted*, *ellos*, *ellas* or *ustedes*. *Lucía y yo* includes the speaker, so the owner is *nosotras*.

- B. *Mis* is used when the owner is *yo*, and only with more than one thing.

- C. *Tu* is used when the owner is *tú*, not *Lucía y yo*.

- D. *Tus* is used when the owner is *tú*, and only with more than one thing.

- E. *Nuestro* is used with *nosotros/as*, but it is masculine, and *abuela* is feminine.

**Grammar reminder:**

Possessive adjectives show who something belongs to. They always go before the noun. They agree with the thing owned, not with the owner.

| **Owner** | **One thing** | **More than one thing** |

|:--|:--|:--|

| *yo* | *mi* | *mis* |

| *tú* | *tu* | *tus* |

| *él / ella / usted* | *su* | *sus* |

| *nosotros / nosotras* | *nuestro / nuestra* | *nuestros / nuestras* |

| *vosotros / vosotras* | *vuestro / vuestra* | *vuestros / vuestras* |

| *ellos / ellas / ustedes* | *su* | *sus* |

| **Owner** | **Example** |

|:--|:--|

| *yo* | *Mi padre es muy alto.* |

| *tú* | *Tus tíos viven en Chile.* |

| *nosotros / nosotras* | *Nuestra profesora es simpática.* |

| *ellos / ellas* | *Sus vecinos son muy amables.* |

Only *nuestro* and *vuestro* change for masculine and feminine. All the other forms change only for singular and plural.

Common mistake: using *sus* because there are two owners. *Mis padres tienen una casa* gives *su casa*, not *sus casa*, because there is only one *casa*.
