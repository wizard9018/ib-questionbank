# SA0265

**Complete the sentences. Use the correct present tense form of *ser*.** [4 marks]

Yo **[-1-]** una persona amable.

Mi hermana **[-2-]** una persona $\text{incre\'{\i}ble}$.

Nosotros **[-3-]** de la $\text{Rep\'{u}blica}$ Dominicana.

Mis padres **[-4-]** muy trabajadores.

**Put the words in the correct order. Write the full sentence.**

$5.$ $\hspace{1em}$generoso / Mi / muy / primo / es    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{soy}$    [1 mark]

- The subject is (*yo*), so the correct form is *soy*. We use *ser* to describe a person.

$2.$ $\hspace{1em}$ $\textrm{es}$    [1 mark]

- *Mi hermana* refers to (*ella*), so the correct form is *es*. We use *ser* to describe a person.

$3.$ $\hspace{1em}$ $\textrm{somos}$    [1 mark]

- The subject is (*nosotros*), so the correct form is *somos*. We use *ser* with *de* to express origin.

$4.$ $\hspace{1em}$ $\textrm{son}$    [1 mark]

- *Mis padres* refers to (*ellos*), so the correct form is *son*. We use *ser* to describe people.

$5.$ $\hspace{1em}$ $\textrm{Mi primo es muy generoso.}$    [1 mark]

- *Mi primo* is the subject and *es* is the verb. The description *muy generoso* comes after the verb.
