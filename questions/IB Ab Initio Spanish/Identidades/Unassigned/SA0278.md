# SA0278

**Complete the paragraph with the correct form of the adjectives in brackets.** [2 marks]

Mi prima lleva una camiseta **[-1-]** (*rojo*) y unos zapatos **[-2-]** (*blanco*). Le gusta llevar ropa de colores vivos.

**Each sentence contains $\underline{\textbf{one}}$ error in adjective agreement. Find the error and rewrite the complete sentence correctly.**

$3.$ $\hspace{1em}$Mi hermano tiene una bicicleta nuevo.    [1 mark]

$4.$ $\hspace{1em}$Las profesoras que trabajan en el colegio son muy inteligente.    [1 mark]

$5.$ $\hspace{1em}$Mis primas tienen unos perros pequeño.    [1 mark]

$6.$ $\hspace{1em}$Mi vecino es una persona muy generosos.    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{roja}$    [1 mark]

- *Una camiseta* is feminine singular, so the adjective must also be feminine singular. *Rojo* changes to *roja*.

$2.$ $\hspace{1em}$ $\textrm{blancos}$    [1 mark]

- *Unos zapatos* is masculine plural, so the adjective must also be masculine plural. *Blanco* changes to *blancos*.\

\

**Model answer**: Mi prima lleva una camiseta roja y unos zapatos blancos. Le gusta llevar ropa de colores vivos.

$3.$ $\hspace{1em}$ $\textrm{Mi hermano tiene una bicicleta nueva.}$    [1 mark]

- *Nuevo* is masculine singular, but it describes *una bicicleta*, which is feminine singular, so the correct form is *nueva*. The adjective agrees with *bicicleta*, not with *mi hermano*.

$4.$ $\hspace{1em}$ $\textrm{Las profesoras que trabajan en el colegio son muy inteligentes.}$    [1 mark]

- *Inteligente* is singular, but it describes *las profesoras*, which is plural, so the correct form is *inteligentes*. Adjectives ending in *-e* have the same form for masculine and feminine. We only add *-s* for the plural.

$5.$ $\hspace{1em}$ $\textrm{Mis primas tienen unos perros peque\~{n}os.}$    [1 mark]

- *Pequeño* is masculine singular, but it describes *unos perros*, which is masculine plural, so the correct form is *pequeños*. The adjective agrees with *perros*, not with *mis primas*.

$6.$ $\hspace{1em}$ $\textrm{Mi vecino es una persona muy generosa.}$    [1 mark]

- *Generosos* is masculine plural, but it describes *una persona*, which is feminine singular, so the correct form is *generosa*. *Persona* is always feminine, even when it refers to a man, so the adjective agrees with *persona*, not with *mi vecino*.
