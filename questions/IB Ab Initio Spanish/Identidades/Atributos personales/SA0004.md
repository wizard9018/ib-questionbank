No es necesario tener experiencia como modelo, pero es importante sentirse c$\text{\'{o}}$moda delante de la c$\text{\'{a}}$mara. Si eres una persona positiva y te gusta la moda, ¡escr$\text{\'{\i}}$benos para participar!

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* *atractiva* is correct because in the text the expression is *sonrisa bonita*. *Bonita* here describes something pleasant and nice to look at, and *atractiva* has a similar meaning in this context.

* *Opci$\textit{\'{o}}$n incorrecta:* A

* **A**: *elegante* is not correct because it describes a style of clothing or appearance. In the text, *bonita* describes *sonrisa*, so *atractiva* is a better synonym.

$2.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* *amable* is correct because *simp$\textit{\'{a}}$tica* refers to a person who is kind and pleasant with other people. In the text, the model should be friendly and nice, so *amable* matches this idea.

* *Opci$\textit{\'{o}}$n incorrecta:* D

* **D**: *antip$\textit{\'{a}}$tica* is not correct because it is the opposite of *simp$\textit{\'{a}}$tica*. The text says the model should be friendly, not unfriendly.

$3.$ $\hspace{1em}$ $\textrm{E}$    [1 mark]

* *calmada* is correct because *tranquila* describes a person who is relaxed and not stressed. In the text, they want someone calm, so *calmada* is the best option.

* *Opci$\textit{\'{o}}$n incorrecta:* F

* **F**: *nerviosa* is not correct because it is the opposite of *tranquila*. The text describes the model as calm, not anxious.

$4.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* The answer is found in the text: $\text{\textquotedblleft}$Buscamos una modelo para una campa$\text{\~{n}}$a de ropa juvenil" and $\text{\textquotedblleft}\text{¡escr\'{\i}benos}$ para participar!"*An advertisement* (*un anuncio*) typically seeks something from the reader and invites them to take action; both elements are present here.

* *Opciones incorrectas:* A, B, D

* **A**: *Un folleto* (*brochure*) is not correct because a brochure usually gives general information about a place, service, or event. This text is looking for a person.

* **B**: *Una nota* (*note*) is not correct because a note usually gives short information or instructions. This text is inviting people to participate in a casting.

* **D**: *Un informe* (*report*) is not correct because a report is usually formal and presents detailed information or analysis.

$5.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

* The answer is found in the text: $\text{\textquotedblleft}$Buscamos una modelo para una campa$\text{\~{n}}$a de ropa juvenil.” The text clearly says they are looking for a model.:br

* *Opciones incorrectas:* A, B, C

* **A**: *Informar sobre las $\textit{\'{u}}$ltimas tendencias* (*to inform about the latest trends*) is not correct because the text does not talk about fashion trends.

* **B**: *Anunciar una marca de ropa* (*to advertise a clothing brand*) is not correct because the text does not mention a specific brand.

* **C**: *Apoyar a dise$\textit{\~{n}}$adores de moda* (*to support fashion designers*) is not correct because the text only explains that they want to find a model.
