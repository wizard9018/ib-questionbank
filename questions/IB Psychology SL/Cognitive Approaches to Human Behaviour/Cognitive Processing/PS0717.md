# PS0717

Outline three main premises or features of the multi-store model of memory.
[3 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:\

Memory consists of separate storage systems. (:span$\color{red}\checkmark$)

The three memory storage systems are sensory memory, short-term memory (STM) and long-term memory (LTM).  (:span$\color{red}\checkmark$) 

Memories move in fixed sequential order from one store to the next. (:span$\color{red}\checkmark$) 

Each storage system has a specific capacity and duration. (:span$\color{red}\checkmark$)
