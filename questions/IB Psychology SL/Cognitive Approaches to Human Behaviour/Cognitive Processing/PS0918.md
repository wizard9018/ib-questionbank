# PS0918

Describe the Working Memory Model with reference to one study.

[9 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample Answer}}$: 

Baddley & Hitch's Working Memory Model (1974) is a hypothetical representation of how our memory encodes, stores, and retrieves information. It focuses entirely on short-term memory, known as working memory. According to the model, our working memory has a limited capacity and is responsible for holding and manipulating information in our conscious awareness at any given time.  The model separates short-term memory into three separate stores: the visuospatial sketchpad for the processing of visual information, the phonological loop for processing auditory information, as well as the episodic buffer that acts as a temporary storage system connecting short-term memories to long-term memories. These separate stores are referred to as slave systems, and the Central Executive is a control system that regulates the flow of information between each of these different slave systems. One major premise of the model is that If two tasks make use of the same component of working memory, they cannot be performed successfully together. This is due to their limited capacity and because rehearsal needs to take place for short-term memories to be retained. If one of the stores is trying to process competing information, articulatory suppression, the disruption of information encoding, can occur. Landry & Bartling's (2011) study can be used to support the Working Memory Model.

Landry and Bartling aimed to investigate the effects of articulatory suppression on short-term memory performance. 34 undergraduate students were presented with a list of letters to remember. Participants were divided into two groups: the experimental group engaged in articulatory suppression by repeating the numbers $\text{\textquotedblleft}$1" and $\text{\textquotedblleft}$2" while trying to recall the letters, while the control group repeated nothing. After a brief presentation of the letters, participants were asked to recall them in the correct order. Results revealed that those in the articulatory suppression condition recalled significantly fewer letters than those in the control group. The study concluded that articulatory suppression negatively affects short-term memory performance by disrupting the rehearsal process crucial for encoding and recalling information in working memory.

This study evidences the working memory's separate stores by showing what happens when two tasks simultaneously engage the same subsystem (here, the phonological loop for letter and number repetition). This leads to interference, whereas tasks using different subsystems (*eg., visual and verbal*) do not. By attempting tasks that both use the phonological loop, that aspect of the working memory becomes overloaded, and encoding is disrupted. The fact that we are able to multitask using separate stores but not the same one, as is shown in Landry & Bartling (2011), supports Baddeley & Hitch's Working Memory Model.

$\textcolor{#C34A2C}{\underline{\textrm{Possible ideas \& key terms:}}}$

Working Memory Model: The central executive - controls the slave systems and directs our attention. Slave systems: visuospatial sketchpad, phonological loop, and episodic buffer. Articulatory suppression - when one of the working memory stores is reaching capacity and function is being disrupted due to overload. 

Multi-Store Model: Memory consists of 3 separate storage systems (sensory, STM, & LTM), each with a specific capacity and duration. Information linearly moves through each store.

$\textcolor{#056608}{\underline{\textrm{Possible key studies:}}}$

Glanzer & Kunitz (1966) investigated the serial position effect as evidence for two separate stores of memory: short-term and long-term. 

Baddeley et al. (1973) utilised a dual task activity to investigate the separate stores of the phonological loop and the visuo-spatial sketchpad. 

Baddeley et al. (1975) investigated how word length effect would affect recall in order to explore how articulatory suppression affects working memory due to capacity restraints.
