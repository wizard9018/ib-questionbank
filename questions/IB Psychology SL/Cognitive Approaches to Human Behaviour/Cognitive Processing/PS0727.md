# PS0727

Describe two (2) strengths and two (2) limitations of the multi-store model.
[4 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:

**Strengths**

- The model was groundbreaking at the time and many memory models since have been based on this model. (:span$\color{red}\checkmark$)

- It was the first model to make the clear distinction between short-term memory and long-term memory. (:span$\color{red}\checkmark$)

- Several research studies provide support for elements of the model. (:span$\color{red}\checkmark$)

**Limitations**

- The model is overly simplistic memory is likely more complex than the model suggests. (:span$\color{red}\checkmark$)

- The working memory model suggests that STM is far more complex than the model suggests.  (:span$\color{red}\checkmark$)

- It does not differentiate between different types of LTM. (:span$\color{red}\checkmark$) Evidence suggests that there are different types.

- It does not differentiate between different types of rehearsal. Likely, basic repetition is not sufficient to transfer information to the LTM. (:span$\color{red}\checkmark$) Meaningful rehearsal is likely to be important.

- It cannot explain why we forget things, even though we have rehearsed them to great lengths. (:span$\color{red}\checkmark$)

- Memory is not observable, therefore, elements of the model cannot be verified. (:span$\color{red}\checkmark$)

- The model does not explain why we can remember things in the long term that have never been rehearsed. (:span$\color{red}\checkmark$)
