# PS0731

Describe three (3) features or functions of the central executive subsystem in the Working Memory Model.
[4 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:

- It is a control system that regulates information flow between the different slave systems (:span$\color{red}\checkmark$) 

- It allocates the necessary resources to each slave system (:span$\color{red}\checkmark$) 

- It has limited capacity (:span$\color{red}\checkmark$) 

- It is modality-free and can accept information in a variety of formats (:span$\color{red}\checkmark$)
