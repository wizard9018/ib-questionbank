# PS0971

Describe the multi-store model of memory with reference to one study.

[9 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:

The multi-store model of memory suggests that memory consists of 3 separate storage systems: sensory memory, short-term memory (STM) and long-term memory (LTM), and that information moves in a fixed sequential order from one store to the next. 

Sensory memory temporarily stores all sensory information that is received by our senses in its raw original form. It holds sensory information long enough for it to be transferred to short-term memory if needed. Sensory memory has a duration of approximately a fraction of a second and an unlimited capacity. If information in sensory memory is attended to, it moves into short-term memory (STM); however, if it is not attended to, it is permanently lost.

STM has a capacity of 7 plus or minus two pieces of information, and it can hold things for a duration of approximately 18-20 seconds. The function of STM is to temporarily hold a limited amount of information in our conscious awareness long enough for us to be able to manipulate it to perform everyday functions such as problem-solving and decision-making. We can extend the duration of STM by repeating or rehearsing information, and we can extend the capacity of STM by chunking information into meaningful groups. If information is repeated or rehearsed enough in STM, it will be moved to LTM.

LTM is our permanent memory store, with potentially unlimited capacity and duration. When we need to access information from our LTM, it is temporarily transferred back to our STM. The theory suggests that in LTM, forgetting often occurs due to retrieval failure.

One study that supports elements of the Multi-Store Model is Glanzer and Cunitz. The aim was to test the idea that our memory has separate storage systems. Using an independent groups design, 240 army enlisted men were assigned to different conditions. All participants heard the same list of words and were asked to recall them either immediately or after a 30-second delay, which included a distraction task. In the immediate recall condition, participants showed a primacy effect (strong recall of words towards the start of the list) and a recency effect (strong recall of words at the end of the list). In the delayed recall condition, the recency effect disappeared, while the primacy effect remained. This is because the words at the start of the list had been rehearsed long enough to enter LTM, and the words at the end were still in STM. Without rehearsal, 30 seconds exceeds the duration of STM.

The study supports some elements of the multi-store model. In particular, it suggests that STM and LTM are separate storage systems and STM has a limited duration. It also supports the idea that rehearsal helps move information into LTM.

 - Peterson and Peterson (1959): This study demonstrates that STM has limited duration without rehearsal.
