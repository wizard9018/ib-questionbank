# PS0601

Discuss one or more models of memory using one or more studies.

[22 marks]

$\underline{\textrm{Sample Answer}}$:\

Memory is the process by which we manipulate, encode, store and recall information. $\textcolor{#C34A2C}{[\textbf{KT}]}$ Models of memory attempt to explain this process. Memory is an essential component of learning and is closely linked with intelligence. Investigating models of memory and how this essential cognitive process works can play an important role in improving memory and in diagnosing memory disorders. $\textcolor{#000000}{[\textbf{F}]}$ The levels of processing and working memory models can be discussed with reference to research studies conducted by Robbins et al., (1996) and Craik $\&$ Tulving. (1975)

$\textcolor{#000000}{[\textbf{F}]}$ 

The Working Memory Model primarily explains short-term memory. $\textcolor{#000000}{[\textbf{F}]}$ Our working memory has limited capacity and allows us to hold $\&$ manipulate information in our conscious awareness. Working memory is made up of separate subsystems. The first being the central executive, which is the control system. The three slave systems are known as the visuospatial sketchpad, the phonological loop and the episodic buffer. The visuospatial sketchpad deals with visual information and spatial awareness. The phonological loop deals with auditory information and is made up of the phonological store and the articulatory process. Finally, the episodic buffer is a temporary back-up storage for chunks of integrated visual and auditory information. A key assumption behind the Working Memory Model is that if two working memory tasks make use of two separate slave systems we should be able to effectively engage with each at the same time. However, if they both require the use of the same ecomponent, we will have diminished performance.  $\textcolor{#C34A2C}{[\textbf{KT}]}$ 

Robbins et al., (1996) aimed to examine the effect of simultaneously engaging in two tasks that either utilize the same or different parts of working memory. 20 male chess players (of mixed ability) sat between two chessboards, with a partition between each. Chess pieces were positioned on one of the boards (out of view). The partition was removed, and participants were given 10 seconds to memorise the position of the pieces before the partition was reinstated. Participants had to recreate the cheese pieces on the other board (a visio-spatial sketchpad task) while completing either a visio-spatial interference task (typing a series of predetermined numbers into a keyboard) or a phonological loop interference task (verbally repeating the word ‘the' in time to a metronome). Results showed poorer performance on both tasks when they required the same parts of working memory. These results lend support to the Working Memory Model  by emphasising the unique role and limited capacity of each separate slave system. If there was only one system of working memory then the ability to rearrange the chess pieces into the correct position should be equally affected regardless of the type of interference. The fact that visuo-spatial interference had a far greater detrimental effect on a visuo-spatial task suggests that there are different short-term working memory systems for processing different information. $\textcolor{#056608}{[\textbf{S}]}$ $\textcolor{#000000}{[\textbf{F}]}$ 

While this study provides support for some of the key elements of the working memory model, it is important to evaluate the study in order to determine the extent to which it can be used in support of the working memory model. $\textcolor{#4472C4}{[\textbf{CT}]}$ $\textcolor{#000000}{[\textbf{F}]}$ 

One strength is that it was a true experiment. The researchers manipulated an independent variable (visuospatial sketchpad or phonological loop interference task) in order to assess the impact on performance. Participants were also randomly allocated to conditions, therefore, a cause and effect relationship could be established. A further strength is that researchers could tightly control variables (such as using identical chess tasks) across each condition. $\textcolor{#4472C4}{[\textbf{CT}]}$

There were, however, potential extraneous variables that could reduce internal validity. The researchers had no way of controlling whether those in the visuo-spatial interference condition activated their inner voice (articulatory process) whilst they were completing the task. $\textcolor{#4472C4}{[\textbf{CT}]}$

A further limitation is that participants were all male chess players from Cambridge, meaning they may not be representative of your average person, limiting the potential for generalisation.$\textcolor{#4472C4}{[\textbf{CT}]}$

The Levels of Processing Model is an alternative memory model $\textcolor{#000000}{[\textbf{F}]}$ that is not limited to short-term memory. The model suggests that memory should be viewed as a process, where the strength of a memory is dependent on how deeply we have engaged with, or processed information. With in-depth engagement or processing resulting in strong memory traces and superficial processing producing weak memory traces. In-depth processing could involve considering the meaning of something, whereas shallow or superficial processing might focus on the structure of a word. Medium levels of processing which would fall somewhere between the two.$\textcolor{#C34A2C}{[\textbf{KT}]}$ 

Craik and Tulving's experiment (1975) aimed to investigate whether more in depth processing would lead to greater recall. The study used a repeated measures design with counterbalancing. 30 participants were shown a series of words and answered a question about each word. The type of questions asked varied from in depth (focusing on meaning) to superficial (focusing) on structural aspects of each word. The dependent variable was the number of words remembered and this was measured via a surprise recognition test. Results were as expected, with participants recognising the most words from the in-depth processing condition and the least from the superficial or shallow processing condition. Thus providing support for the model. $\textcolor{#056608}{[\textbf{S}]}$ $\textcolor{#000000}{[\textbf{F}]}$ 

As this study was also an experiment, many of the evaluation points are similar to that of Robbins et al, with researchers establishing a cause and effect relationship between depth of processing and recall.$\textcolor{#4472C4}{[\textbf{CT}]}$ 

Both models have research support yet we cannot be certain with regard to the claims made by either model. This is because cognitive processes such as memory cannot be observed directly and as such, researchers are left to make inferences based on the data. The levels of the processing model can effectively explain why we can remember things that we may not actively rehearse, however, it is somewhat simplistic in that it doesn't distinguish between varying types of long-term memories. The working memory model provides an in-depth overview of working memory and can explain some real world memory phenomena. However, both models are insufficient as they cannot explain the biological processes that underpin the formation of a memory trace.$\textcolor{#4472C4}{[\textbf{CT}]}$ $\textcolor{#000000}{[\textbf{F}]}$
