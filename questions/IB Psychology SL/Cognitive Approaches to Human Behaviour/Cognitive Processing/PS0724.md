# PS0724

According to the multi-store model, outline one way in which we can extend the duration of short-term memory (STM) and one way in which we can extend the capacity of STM.
[2 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:\

We can extend the duration of STM by repeating or rehearsing information. (:span$\color{red}\checkmark$)

We can extend the capacity of STM by chunking information into meaningful groups. (:span$\color{red}\checkmark$)
