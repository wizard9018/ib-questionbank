# PS0735

Describe three features or functions of the episodic buffer according to the working memory model.
[3 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:\

Any **three** of the following would be acceptable:

It is a temporary backup store within working memory. (:span$\color{red}\checkmark$)

It holds chunks of multi-model information (e.g., visual and auditory). (:span$\color{red}\checkmark$)

It combines different types of information (e.g., visual and auditory) so that it can be easily comprehended as a whole. (:span$\color{red}\checkmark$)

It communicates with working memory and long-term memory. (:span$\color{red}\checkmark$)

It allows information to pass in both directions between working memory and long-term memory. (:span$\color{red}\checkmark$)

It has a limited capacity. (:span$\color{red}\checkmark$)
