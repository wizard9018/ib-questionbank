# SB0435

\[Puntaje m$\text{\'{a}}$ximo: 5]

|                    | Vivir en una megaciudad: ¿progreso o problema?                                                                                                                                                                                                                                                                                                                                                                         |

| :----------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| :br                |                                                                                                                                                                                                                                                                                                                                                                                                                        |

| 1.$\hspace{1.8em}$ | Vivir en una megaciudad latinoamericana es convivir con contradicciones permanentes. Por un lado, la ciudad promete modernidad: rascacielos, universidades, centros culturales y oportunidades laborales. Por otro, millones de ciudadanos se enfrentan a una infraestructura deficiente, transporte colapsado y barrios enteros sin servicios b$\text{\'{a}}$sicos.                                                  |

|                    |                                                                                                                                                                                                                                                                                                                                                                                                                        |

| 2.$\hspace{1.8em}$ | Muchos sostienen que la urbanizaci$\text{\'{o}}$n acelerada representa desarrollo econ$\text{\'{o}}$mico. Sin embargo, yo me pregunto si puede llamarse desarrollo a un modelo que profundiza la brecha social y expone a los m$\text{\'{a}}$s vulnerables a condiciones indignas.                                                                                                                                  |

|                    |                                                                                                                                                                                                                                                                                                                                                                                                                        |

| 3.$\hspace{1.8em}$ | Lo urbano deber$\text{\'{\i}}$a ser sin$\text{\'{o}}$nimo de progreso colectivo, pero en nuestras megaciudades prevalece una realidad desigual: mientras algunos gozan de lujos, otros sobreviven en la periferia. Esta contradicci$\text{\'{o}}$n exige pol$\text{\'{\i}}$ticas p$\text{\'{u}}$blicas responsables que planifiquen el territorio, fomenten la movilidad sostenible y reduzcan las desigualdades. |

|                    |                                                                                                                                                                                                                                                                                                                                                                                                                        |

| 4.$\hspace{1.8em}$ | Creo que el verdadero desaf$\text{\'{\i}}$o $\text{\'{e}}$tico no es solo construir m$\text{\'{a}}$s, sino decidir para qui$\text{\'{e}}$n se construye. Sin esa reflexi$\text{\'{o}}$n, la megaciudad corre el riesgo de convertirse en un espacio ca$\text{\'{o}}$tico e injusto, incapaz de ofrecer calidad de vida a todos sus habitantes.                                                                   |

**Contesta a la siguiente pregunta.**

$1.$ $\hspace{1em}\text{¿Cu\'{a}les}$ son *dos* consecuencias negativas del r$\text{\'{a}}$pido crecimiento de las ciudades?[2 marks]

**Encuentra la palabra o expresi$\textbf{\'{o}}$n en p$\textbf{\'{a}}$rrafos 3 y 4 que signifiquen lo siguiente.**

$2.$ $\hspace{1em}$suburbios    [1 mark]

$3.$ $\hspace{1em}$zona    [1 mark]

$4.$ $\hspace{1em}$peligro    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$*se acepta cualquiera de las siguientes respuestas:*

* $\textrm{profundiza la brecha social}$    [1 mark]

* $\textrm{expone a los m\'{a}s vulnerables a condiciones indignas}$[1 mark]

* Es correcto porque el texto menciona exactamente estas dos consecuencias negativas.

$2.$ $\hspace{1em}$ $\textrm{periferia}$   [1 mark]

* Es correcto porque *periferia* significa la zona alejada de la ciudad, lo mismo que *suburbios*.

$3.$ $\hspace{1em}$ $\textrm{territorio}$   [1 mark]

* Es correcto porque *territorio* y *zona* se refieren a un espacio geogr$\text{\'{a}}$fico determinado.

$4.$ $\hspace{1em}$ $\textrm{riesgo}$   [1 mark]

* Es correcto porque *riesgo* y *peligro* significan lo mismo: la posibilidad de que ocurra un da$\text{\~{n}}$o.
