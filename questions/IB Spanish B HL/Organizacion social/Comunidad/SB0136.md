## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{E}$   [1 mark]

- El texto menciona que el objetivo es $\text{\textquotedblleft}$que puedas entender la importancia de este tipo de trabajo". *Entender* significa *comprender* algo, lo que encaja perfectamente en este contexto.

$2.$ $\hspace{1em}$ $\textrm{D}$   [1 mark]

- Se menciona *trabajar de manera altruista*, lo que significa realizar un esfuerzo sin esperar nada a cambio. *Trabajar* es la palabra que mejor describe esta acción.

$3.$ $\hspace{1em}$ $\textrm{C}$   [1 mark]

- El texto dice: $\text{\textquotedblleft}$Si te preguntan... puedes responder". Aquí se necesita *responder* porque se refiere a contestar preguntas.<ENTER>

- *Opciones Incorrectas:*  A, B, F

- **A**: *Viajar* no tiene relación con el contexto del texto, ya que no se menciona como parte del voluntariado.

- **B**: *Comentar* no es lo mismo que *responder*. *Responder* implica *contestar* una pregunta directamente, mientras que *comentar* es hablar de un tema general.

- **F**: *Visualizar* es el distractor para *entender*. *Visualizar* se refiere a *imaginar*, pero *entender* significa *comprender*. Son ideas diferentes.

$4.$ $\hspace{1em}$ $\textrm{este tipo de trabajo}$   [1 mark]

- *Habría que crear$\underline{\textrm{lo}}$* se refiere a *este trabajo*. *Lo* se refiere a un sustantivo o nombre masculino mencionado con anterioridad, en este caso *este tipo de trabajo*.

$5.$ $\hspace{1em}$ $\textrm{explicaciones}$   [1 mark]

- Siempre es conveniente leer la frase anterior. La palabra que buscas está antes del pronombre. Recuerda que se quiere evitar la repetición.

- “no $\underline{\textrm{las}}$ merecen” se refiere a *explicaciones*. *Las* se refiere a un sustantivo plural y femenino mencionado con anterioridad, en este caso *las explicaciones*.
