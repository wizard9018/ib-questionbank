# SB0194

[Puntaje máximo: 5\]

**Vas a escuchar un podcast sobre ética y acceso a recursos básicos en Bolivia.**

:audio{#fd18cbda-6bda-4f5e-acbb-27170c2da20d aid="fd18cbda-6bda-4f5e-acbb-27170c2da20d"}

**Contesta a las siguientes preguntas.**

$1.$ $\hspace{1em}$¿Qué hacen las organizaciones éticas en el altiplano boliviano para ayudar a las familias que no tienen agua potable?    [1 mark]

$2.$ $\hspace{1em}$¿Qué reflexión propone el programa sobre el acceso al agua potable?    [1 mark]

**Elige la respuesta correcta.**

$3.$ $\hspace{1em}$¿Qué solución se ha desarrollado para que las familias en el altiplano boliviano puedan acceder al agua potable?    [1 mark]

- A.$\hspace{1em}$Sistemas para recolectar agua de lluvia.

- B.$\hspace{1em}$Programas de educación sobre el uso del agua.

- C.$\hspace{1em}$Usar agua reciclada.

$4.$ $\hspace{1em}$¿Qué aspecto cultural se considera en las soluciones aplicadas en el altiplano boliviano?    [1 mark]

- A.$\hspace{1em}$La celebración de rituales tradicionales con agua.

- B.$\hspace{1em}$El respeto por las costumbres de las comunidades locales.

- C.$\hspace{1em}$La construcción de infraestructuras modernas en las comunidades.

$5.$ $\hspace{1em}$¿Qué mensaje principal quiere transmitir el programa sobre el acceso al agua?    [1 mark]

- A.$\hspace{1em}$Garantizar el acceso al agua es una cuestión de justicia y acción.

- B.$\hspace{1em}$La falta de acceso al agua se debe únicamente a problemas climáticos.

- C.$\hspace{1em}$Es necesario desarrollar nuevas tecnologías para resolver este problema.

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\text{\textquotedblleft}$Las organizaciones éticas han creado sistemas de captación de agua de lluvia, respetando las tradiciones locales."    [1 mark]

- Esta respuesta proviene directamente del guión y describe claramente la acción concreta de las organizaciones. No se mencionan otras actividades, por lo que no hay opciones alternativas a considerar.

$2.$ $\hspace{1em}$ $\text{\textquotedblleft}$Reflexionemos: ¿es ético que algo tan esencial como el agua no esté garantizado para todos?"   [1 mark]

- El guión plantea esta pregunta como reflexión principal del programa, resaltando la importancia ética del acceso universal al agua. No se hacen otras reflexiones en el texto.

$3.$ $\hspace{1em}$ $\textrm{A}$   [1 mark]

- El texto menciona que se han implementado sistemas de captación de agua de lluvia.

- *Opciones Incorrectas:* B, C

- **B**: No se habla de programas educativos.

- **C**: El reciclaje de agua no aparece en el texto.

$4.$ $\hspace{1em}$ $\textrm{B}$   [1 mark]

- El guión destaca que las soluciones respetan las tradiciones locales, reconociendo la importancia cultural en la implementación de estas iniciativas.

- *Opciones Incorrectas:* A, C

- **A**: No se menciona la celebración de rituales.

- **C**: Aunque se habla de captación de agua, no se relaciona con infraestructuras modernas.

$5.$ $\hspace{1em}$ $\textrm{A}$   [1 mark]

- El guión concluye con la frase $\text{\textquotedblleft}$Compartir el planeta es un compromiso que exige justicia y acción," lo cual resume el mensaje principal del programa.

- *Opciones Incorrectas:* B, C

- **B**: No se atribuye la falta de agua únicamente a problemas climáticos.

- **C**: Aunque se mencionan soluciones, no se enfatiza el desarrollo de nuevas tecnologías como el enfoque principal.
