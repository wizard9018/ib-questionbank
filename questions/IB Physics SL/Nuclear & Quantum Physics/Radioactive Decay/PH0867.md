# PH0867

The count rate is measured at a point near a radioactive sample. The average background count rate is constant throughout. The graph below shows how the count rate varies with time.

![Screenshot 2026-04-06 at 8.01.12 AM](<images/Screenshot 2026-04-06 at 8.01.12 AM.png>)

Which row correctly shows the half-life of the radioactive sample and the background count rate?

$\\$

| | $\hspace{1em}$ Half-life of sample / s $\hspace{1em}$ | $\hspace{1em}$ Background count rate / s$^{-1}$ $\hspace{1em}$
| :-: | :-: | :-: |
$\hspace{1.5em}$A.$\hspace{1.5em}$ | 0.4 | 0.5
$\hspace{1.5em}$B.$\hspace{1.5em}$ | 0.4 | 0.75
$\hspace{1.5em}$C.$\hspace{1.5em}$ | 0.8 | 0.5
$\hspace{1.5em}$D.$\hspace{1.5em}$ | 0.8 | 0.75

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The graph trends towards the background rate as the count rate from the sample decays exponentially. The graph levels out at 0.5 s$^{-1}$, therefore the background count rate is 0.5 s$^{-1}$.

The half-life of the sample is independent of the background count rate. To find the initial count rate of the sample we must subtract the background count rate from the total initial count rate: $1.5-0.5=1\, \ce{s}^{-1}$.

After one half-life the count rate of the sample will have halved $\text{\textendash}$ so the sample count rate will be 0.5 s$^{-1}$ $\text{\textendash}$ the background count rate is constant so will still be 0.5 s$^{-1}$.

Therefore the total count rate after one half-life is 1 s$^{-1}$.

Using the graph, we can see that when the count rate is 1 s$^{-1}$ the time is 0.4 s so the half-life is 0.4 s.

The answer is **A**.
