1. 1. $\beta^-$/Beta minus **AND** antineutrino $\checkmark$

        Allow electron / $e^-$

        $\underline{\textrm{Further Explanation}}$: \
        During this decay the nucleon number stays the same while the proton number increases by 1. This means that the neutron has decayed into a proton.

        During this process a $\beta^-$ particle (a fast-moving electron) is emitted from the nucleus, conserving electric charge.

        Whenever a $\beta^-$ particle is produced, an antineutrino is also produced.

        The full equation for $\beta^-$ decay includes the emission of a neutral electron antineutrino:

        - $\ce{^{1}_{0}n}\rightarrow\ce{^{1}_{1}p}+\ce{^{0}_{-1}\beta}+\ce{^{0}_{0}\bar{\nu}}$

    2. One correct equation for background count e.g.,

        - 8.5 = background count + initial count from source

        - 1.5 = background count + final count from source

        **OR**

        - Initial count rate from the source = 8 Bq

        **OR**

        - Final count rate from source = 1 Bq $\checkmark$

        - Background count rate = :answer[0.5 Bq] $\checkmark$

        $\underline{\textrm{Further Explanation}}$: \
        The count total rate of the detector $C_T$ is the sum of the count rate due to background radiation $C_B$ and the count rate due to the radioactive source $C_S$:

        - $C_T=C_B+C_S$

        $C_B$ remains constant while $C_S$ varies with time. Specifically, $C_S$ will half with each half life.

        If we let the initial count rate from the source be $C_S$, then the count rate after 3 half lives is given by:

        - $C_S\left(\dfrac{1}{2}\right)\left(\dfrac{1}{2}\right)\left(\dfrac{1}{2}\right)=C_S\left(\dfrac{1}{8}\right)=\dfrac{C_S}{8}$

        The initial total count rate is given by:

        - $8.5=C_B+C_S$

        The total count rate after 3 half lives is given by:

        - $1.5=C_B+\dfrac{C_S}{8}$

        Taking these equations away from each other, we have:

        - $8.5-1.5=C_B-C_B+C_S-\dfrac{C_S}{8}$

        - $7=\dfrac{7}{8}C_S$

        Therefore, the original rate emitted by the source is:

        - $C_S=8$ Bq

        Background count rate is therefore:

        - $C_B=8.5-8=0.5$ Bq
