# PH0963

$\ce{^{10}_{6}C}$ decays according to the equation

$\ce{^{10}_{6}C}\rarr \ce{X} + \ce{^{0}_{1}\beta}^+ + \ce{Y} $

Which row correctly identifies X and Y?

$\\$

| | $\hspace{1.5em}$ X $\hspace{1.5em}$ | $\hspace{1.5em}$ Y $\hspace{1.5em}$ |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| $\ce{^{10}_{5}B}$ | ${\nu}_e$ |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | $\ce{^{10}_{5}B}$ | $\overline{{\nu}_e}$ |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | $\ce{^{10}_{7}N}$ | ${\nu}_e$ |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | $\ce{^{10}_{7}N}$ | $\overline{{\nu}_e}$ |

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

Charge is conserved so 6 = Proton number of element X + 1.
Proton number of element X = 5. Element X must be $\ce{^{10}_{5}B}$.

Lepton number is conserved. ${\beta}^+$ has a lepton number  of $-1$ and both nuclei have a lepton number of 0 so. $0 = -1 +$ lepton number of neutrino. Lepton number of neutrino = 1 so neutrino is an electron neutrino (${\nu}_e$).

${\beta}^+$ decay involves a proton inside the nucleus decaying into a neutron, a positron (${\beta}^+$) and an electron neutrino.
