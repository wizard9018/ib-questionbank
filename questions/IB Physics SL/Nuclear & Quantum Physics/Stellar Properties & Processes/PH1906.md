# PH1906

In 1928, Harold L. Aiden measured Proxima Centauri to have a parallax angle of approximately 0.783 arcseconds.

Which of the following best describes the distance to Proxima Centauri?

- A. $\hspace{1em}$ 2.55 ly

- B. $\hspace{1em}$ 4.16 ly

- C. $\hspace{1em}$ 13.8 ly

- D. $\hspace{1em}$ 16.1 ly

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

To calculate the distance from the Earth to Proxima Centauri we can use the equation from the Data Booklet as follows:

- $d(\textrm{parsec})=\dfrac{1}{p(\textrm{arcsecond})}$

- $d=\dfrac{1}{0.783\textrm{ arcsecond}}\approx1.277$ pc

This distance can now be converted to ly using the unit conversions provided in the Data Booklet:

- $d=1.277\textrm{ pc}\times\dfrac{3.26\textrm{ ly}}{1\textrm{ pc}}=4.16$ ly
