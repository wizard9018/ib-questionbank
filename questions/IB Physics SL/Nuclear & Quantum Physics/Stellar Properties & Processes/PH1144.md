# PH1144

The parallax angle for the star Proxima Centauri is 0.772 arcsec.

Which of the following best describes the distance to this star?

- A. $\hspace{1em}  $ 1.30 ly

- B. $\hspace{1em}  $ 2.32 ly

- C. $\hspace{1em}  $ 3.81 ly

- D. $\hspace{1em}  $ 4.22 ly

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

- $d=\dfrac{1}{p(\textrm{arc seconds})}$

- $d=\dfrac{1}{0.772}=1.295$

The calculated value corresponds to the distance in parsecs (pc). We now need to convert this value:

- $d=1.295\,\ce{pc}\times\dfrac{3.26\,\ce{ly}}{1\,\ce{pc}}=4.22\,\ce{ly}$
