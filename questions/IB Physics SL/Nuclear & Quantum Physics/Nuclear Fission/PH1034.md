# PH1034

Which of the following conditions is/are necessary to sustain a chain reaction in a nuclear reactor?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | The number of neutrons released from reactions per second is less than the number of neutrons absorbed by control rods per second.   |
  | II. | The number of neutrons released from reactions per second is equal to the number of neutrons absorbed by control rods per second. |
  | III. | The number of neutrons released from reactions per second is more than the number of neutrons absorbed by control rods per second. |

- A. $\hspace{1em}  $ Only I and II

- B. $\hspace{1em}  $ Only I and III

- C. $\hspace{1em}  $ Only II and III

- D. $\hspace{1em}  $ Only III

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

A self-sustaining chain reaction in nuclear fission requires the release of neutrons that can initiate subsequent fission events. For each fission, two to three neutrons are released. If at least one neutron is not absorbed or escapes, it can trigger another fission, maintaining the chain reaction. The only option that satisfies this requirement is statement III, so option D is correct.
