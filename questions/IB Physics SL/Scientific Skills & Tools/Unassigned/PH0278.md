# PH0278

A student is using the equation $pV = nRT$ to solve for $n$ with the following percentage uncertainties in the measurements. 

| $\hspace{1em}$ Quantity $\hspace{1em}$ | $\hspace{1em}$ Uncertainty $\hspace{1em}$ |

| :-: | :-: |

| P | $\pm\,2\,\%$ |

| V | $\pm\,6\,\%$ |

| T | $\pm\,1\,\%$ |

What is the percentage uncertainty in the calculated value of n?

- A. $\hspace{1em}$ 3 %

- B. $\hspace{1em}$ 7 %

- C. $\hspace{1em}$ 9 %

- D. $\hspace{1em}$ 12 %

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: 

To calculate $n$, the student would rearrange the formula to get

- $n=\dfrac{PV}{RT}$

In both operations, the percentage uncertainty must be added, therefore the correct answer is C (2 \% + 6 \% + 1 \% = 9 \%)
