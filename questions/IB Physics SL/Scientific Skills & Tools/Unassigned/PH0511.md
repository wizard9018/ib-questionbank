# PH0511

**Maximum mark: 12**

In an experiment, the free-fall of a ball bearing is used to measure the acceleration due to gravity. The ball bearing is suspended with an electromagnet. Then it is released from a height of $h$ above a table.

![PH0511_A](images/PH0511_A.png)
$\footnotesize{\textrm{[Source: Created with chemix - https:// chemix.org/]}}$

The time *t* needed for the ball bearing to reach the ground after release is measured. The experiment is repeated for different values of $h$. The theoretically predicted relationship between time *t* and *h* is

$t^2=\dfrac{2h}{g}$

1.   State why there is a need to collect data for a range of values of $h$ to verify this relationship. [1 mark]

2.  The experimental data for $t^2$ and *h* are plotted on the graph below.

    ![Screenshot 2025-04-16 at 9.01.00 AM](<images/Screenshot 2025-04-16 at 9.01.00 AM.png>)

    1. Draw the line of best fit for the plotted data on the graph. [1 mark]

    2. Suggest whether the data is consistent with the theoretical prediction. [2 marks]

    3.     By using the line of best fit, determine a value for *g* and state the units. [4 marks]

3. 1.     Compare the experimental result to the accepted value of *g* and suggest a reason for the discrepancy. [2 marks]

    2. State and explain whether the source of error in (c)(i) is a systematic or random error. [2 marks]

    **OR**

    to reduce random error $\checkmark$

    $\underline{\textrm{Further Explanation}}$: \
    To prove a relationship, one piece of data is not enough. The relationship can be generalized by using a graph where multiple points can reveal a trend. More data allows for drawing a graph that can support the relationship. Additionally, using more data and taking the average of them reduces the amount of random error.

    3. Rearrangement of the formula to solve for $g$

        - $g=2\dfrac{h}{t^2}$ $\checkmark$

        Using a correct  data point on the line

        **OR**

        Correct calculation of  the gradient $\checkmark$

        *g* is between :answer[9.0 and 9.5] $\checkmark$

        $\ce{m s}^{-2}$ $\checkmark$

        $\underline{\textrm{Further Explanation}}$: \
        The given formula is

        - $t^2=\dfrac{2h}{g}$

        The gradient is therefore equal to $\dfrac{2}{g}$.

        Finding the gradient gives

        - gradient = $\dfrac{0.19}{0.9}=0.21$

        Solving for $g$:

        - $0.21 = \dfrac{2}{g}$

        - $g=\dfrac{2}{0.21}=9.5\ \ce{m s}^{-2}$
