    1. $\ll$ According to the theory $\gg$, *a* is proportional to $b$ / $a\propto b$ $\checkmark$

        A best-fit line that is a straight line that passes through the origin and pass through all uncertainty bars can be drawn $\checkmark$

        $\ll$ therefore, yes, the data agrees with the theory $\gg$

        $\underline{\textrm{Further Explanation}}$: \
        According to the predicted relationship;

        $a\propto\ b$

        This relationship suggests that the graph should be a straight line which passes through the origin. According to plotted data, that kind of straight line can be drawn.

    2. Correct calculation of percentage uncertainties of *a* and *b* $\checkmark$

        - $\ll \dfrac{\Delta a}{a} \times 100\% = \dfrac{0.1}{3.0}\times 100 \% = 3.3\% \gg$

        - $\ll \dfrac{\Delta b}{b} \times 100 \% = \dfrac{0.1}{1.8} \times 100 \% = 5.6 \% \gg$

        The percentage error of n = $\ll 3.3 \% + 5.6 \% \gg = 8.9\%$

        - $n=\ll\dfrac{3.0}{1.8}=1.67=\gg1.7$ $\checkmark$

        - $\Delta n = \ll \dfrac{3.0}{1.8} \times 0.089 = 0.148 = 0.15$ (0.1 and 0.2 also accepted here) $\checkmark$

        Giving

        - $n=1.67\pm 0.15$ **OR**  $   n =1.7\pm 0.2 $  **OR**  $n=1.7 \pm 0.1   $ $\checkmark$

        Note that precision (decimal places) on n and ∆n must match

        $\underline{\textrm{Further Explanation}}$: \
        According to the graph, values of *a* and *b* with their absolute uncertainties;

        - $a=3.0\pm0.1\ $cm \
$b=1.8\pm0.1\ $cm

        Solving for the percentage uncertainties of *a* and *b*:

        - $\dfrac{\Delta a}{a} \times 100\% = \dfrac{0.1}{3.0}\times 100 \% = 3.3\%$

        - $\dfrac{\Delta b}{b} \times 100 \% = \dfrac{0.1}{1.8} \times 100 \% = 5.6 \%$

        By using the rules of propagation of percentage uncertainties, the percentage uncertainties are added in multiplication or division operations.

        - % $n=3.3\%+5.6\%=8.9\%$

        The value of *n*:

        - $n=\dfrac{3.0}{1.8} = 1.67$

        - $n=1.67\pm (1.67\times 8.9\%) =1.67\pm0.148$

        The uncertainty should be expressed to one significant figure, or two significant figures if the first digit is 1 which is the case here. So the best answer is

        - $n=1.67±0.15$

        But $n=1.7±0.1$  **OR** $n=1.7±0.2$ are also accepted here
