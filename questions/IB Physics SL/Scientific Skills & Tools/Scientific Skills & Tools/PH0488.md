# PH0488

How many significant figures are there in 0.000017000?

- A.$\hspace{1em}$ 2

- B.$\hspace{1em}$ 5

- C.$\hspace{1em}$ 6

- D. $\hspace{1em}$9

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

In a decimal number, the zeroes to the left are not counted as significant figures, but the zeroes to the right are counted.

Therefore, the number of significant figures is 5 as only the bold part will be considered.

0.0000$\bf{17000}$
