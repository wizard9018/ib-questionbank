# PH0485

Which of the following gives the unit for work in fundamental SI units?

- A.$\hspace{1em} \ce{m^2\,s^2}$

- B.$\hspace{1em} \ce{kg\,m\,s^{-1}}$

- C.$\hspace{1em} \ce{kg\,m^2\,s^{-1}}$

- D.$\hspace{1em} \ce{kg\,m^2\,s^{-2}}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Since   $W=Fs$,

The unit of work is equivalent to Nm.

Because, $F=ma$

Therefore the newton is equivalent to  $\ce{kg\, m \,s^{-2}}$

Then, the unit of work is $\ce{kg\, m^2\, s^{-2}}$
