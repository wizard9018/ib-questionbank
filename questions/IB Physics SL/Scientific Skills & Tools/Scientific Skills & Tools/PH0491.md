# PH0491

Vector $d$ makes an angle $\theta$ with the horizontal as shown. Its magnitude is $5\,m$ and the magnitude of its horizontal component $d_x$ is $3\,m$.

![PH0491](images/PH0491.png)

Which of the following is correct about the magnitude and direction of its vertical component?

$\\$

| | $\hspace{1em}$ Magnitude $\hspace{1em}$ | $\hspace{1em}$ Direction $\hspace{1em}$ |

| :-: | :-: | :-: |

| $\hspace{1.5em}$ A. $\hspace{1.5em}$ | 4 $m$ | Up |

| $\hspace{1.5em}$ B. $\hspace{1.5em}$ | $\sqrt{34}\,m$ | Up |

| $\hspace{1.5em}$ C. $\hspace{1.5em}$ | $\sqrt{34}\,m$ | Down |

| $\hspace{1.5em}$ D. $\hspace{1.5em}$ | 4 $m$ | Down |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

To calculate the magnitude of the vertical component of vector $d$

$d_y=\sqrt{d^2 - d_x\textrm{}^2} = \sqrt{5^2 - 3^2}=4 \,m$

Its direction is vertically downwards, since the vector $d$ is below the horizontal.
