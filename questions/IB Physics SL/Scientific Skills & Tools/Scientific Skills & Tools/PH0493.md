# PH0493

Which of the following is a vector quantity?

- A. $\hspace{1em}$ Speed

- B. $\hspace{1em}$ Electric force

- C. $\hspace{1em}$ Electric current

- D. $\hspace{1em}$ Temperature

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: 

For any force, the direction is an essential aspect of the quantity. All other options here are scalar quantities.
