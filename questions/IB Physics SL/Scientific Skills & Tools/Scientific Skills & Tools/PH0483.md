# PH0483

Which of the following is **not** a fundamental SI unit?

- A. $\hspace{1em}$ampere

- B.$\hspace{1em}$ kelvin

- C. $\hspace{1em}$newton

- D.$\hspace{1em}$ mole

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The seven fundamental SI units are the ampere, mole, kelvin, kilogram, second, meter and candela. All others are considered derived units.
