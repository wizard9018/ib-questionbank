# PH0327

An object starting from rest travels a distance $d$ after a time $t$. If $d = (20\,\pm\,1)$ m, and the time is measured as $t = (2.0\,\pm\,0.4)$ s. Which of the following gives the correct values of the fractional and absolute uncertainties of acceleration?

Assume constant acceleration.

$\\$

| | $\hspace{1em}$ Fractional $\hspace{1em}$ | $\hspace{1em}$ Absolute $\bf{/m\,s^{-2}}$ $\hspace{1em}$ |

| :-: | :-: | :-: |

| $\hspace{1.5em}$ A. $\hspace{1.5em}$ | 0.25 | $\pm$ 2.5 |

| $\hspace{1.5em}$ B. $\hspace{1.5em}$ | 0.30 | $\pm$ 3.0 |

| $\hspace{1.5em}$ C. $\hspace{1.5em}$ | 0.45 | $\pm$ 4.5 |

| $\hspace{1.5em}$ D. $\hspace{1.5em}$ | 1.4 | $\pm$ 14 |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: 

Acceleration is calculated from rearranging the equation

$d = \dfrac{1}{2} at^2$ to get $a = \dfrac{2d}{t^2}$

Therefore $a = \dfrac{2(20)}{2^2} = 10\,\ce{m\,s^{-2}}$

Fractional uncertainty of $t$; $\dfrac{\Delta t}{t}=\dfrac{0.4}{2.0}= 0.2$

Fractional uncertainty of $d$; $\dfrac{\Delta d}{d}=\dfrac{1}{20}= 0.05$

In this calculation, the  fractional uncertainties are added

For the fractional uncertainty of $a$; $\dfrac{\Delta d}{d}+ 2(\dfrac{\Delta t}{t}=0.05\%+ 2(0.2) =0.45$

For the absolute uncertainty of $a$; $\Delta a=0.45(10)= 4.5\,\ce{m\,s^{-2}}$
