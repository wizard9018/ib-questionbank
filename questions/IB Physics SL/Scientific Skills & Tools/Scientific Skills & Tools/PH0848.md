# PH0848

A box moves a distance of ($5.0 \pm 0.5)\ \ce{m}$ due to a horizontal force of ($20 \pm 1)\ \ce{N}$.

What is the percentage uncertainty in the work done on the box?

- A. $\hspace{1em}$ $0.5\%$

- B. $\hspace{1em}$ $1.5\%$

- C. $\hspace{1em}$ $9\%$

- D. $\hspace{1em}$ $15\%$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The work done on the box is given by

$\hspace{1em}$ $W=Fs$

The fractional uncertainty in the work done is

$\hspace{1em}$ $\dfrac{\Delta W}{W_0} = \dfrac{\Delta F}{F_0} + \dfrac{\Delta s}{s_0} = \dfrac{1}{20} + \dfrac{0.5}{5}= \dfrac{1}{20} + \dfrac{1}{10} = \dfrac{3}{20}$

The percentage uncertainty in the work done is

$\hspace{1em}$ Percentage uncertainty = $\dfrac{\Delta W}{W_0} \times 100= \dfrac{3}{20} \times 100 =15\%$
