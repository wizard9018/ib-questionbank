# PH0937

A three-dimensional $\lq$L' shaped object lies on a flat surface and exerts a pressure $P$ on the surface. The diagrams below show the view from above and from an angle.

| | | | | |
| --- | --- | ---| ---| ---|
| |    |  |   ||
| | ![image](images/image.png) |  |  |![image](images/image.png)|

Which of the following is the correct expression for the mass of the object?

- A. $\hspace{1em}  $ $\dfrac{Pd}{g}(x+y)$

- B. $\hspace{1em}  $ $\dfrac{Pg}{d}(x+y)$

- C. $\hspace{1em}  $ $Pdh(x+y)$

- D. $\hspace{1em}  $ $\dfrac{P}{dh}(x+y)$

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

- $P=\dfrac{F}{A}$

Force is the weight of the object $=mg$

Area of the shape is $xd+yd=d(x+y)$

![image](images/image.png)

- $P=\dfrac{mg}{d(x+y)}$

- $Pd(x+y)=mg $

- $m=\dfrac{Pd}{g}(x+y)$
