# PH0274

An inflated balloon containing an ideal gas at temperature $T$ in degrees Celsius floats in a room where the atmospheric pressure is $P$. The volume remains constant at $V$. If the balloon contains $M$ moles of the gas, which of the following is true?

- A. $\hspace{1em}$ $M = \dfrac{PV}{R(T+273)}$

- B. $\hspace{1em}$ $M = \dfrac{R(T+273)}{PV}$

- C. $\hspace{1em}$ $M = \dfrac{k_b P}{RV}$

- D. $\hspace{1em}$ $M = \dfrac{PV}{k_b (T-273)}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

The question gives $T$ in celsius. In kelvin, the temperature would be $T + 273$. 

Using the equation $PV=nRT$, we get number of moles = $\dfrac{PV}{RT}$. Since $M$ represents the number of moles, it will substitute into the equation for $n$ and $(T + 273)$ will substitute as temperature in the equation giving

$M=\dfrac{PV}{R(T+273)}$ which is answer A
