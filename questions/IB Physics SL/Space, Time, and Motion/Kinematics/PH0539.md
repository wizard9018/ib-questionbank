# PH0539

An object is moving in a straight line. The graph shows the variation of the velocity $v$ of the object with time $t$.

![Screenshot 2025-10-24 at 7.55.44 AM](<images/Screenshot 2025-10-24 at 7.55.44 AM.png>)

Consider the following statements about the graph:

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | At point A, the object changes its direction. |
  | II. | At point C the object is at rest. |
  | III. | The magnitude of the acceleration at point D is greater than at point B. |

Which of the statements is/are correct?

- A. I only

- B. II only

- C. I and II only

- D. II and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The slope of the velocity time graph gives the acceleration of the object. Therefore, at points A and D, there is no acceleration due to zero gradient. At point B, there is a negative acceleration.

Additionally, the velocity of the object at point C is zero as it aligns with the horizontal axis where $v=0$.

Hence, the answer is B.
