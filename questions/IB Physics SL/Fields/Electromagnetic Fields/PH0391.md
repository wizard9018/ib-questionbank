# PH0391

Which of the following is equivalent to the unit of electric potential difference?

- A. $\hspace{1em}$    N m $\ce{C^{-1}}$

- B. $\hspace{1em}$    N  $\ce{m^{-1}} \, \ce{C^{-1}}$

- C. $\hspace{1em}$    J C

- D. $\hspace{1em}$    J $\ce{m^{-1}} \, \ce{C^{-1}}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The unit of electric potential is V.

It is equivalent to J $\ce{C^{-1}}$ since it is defined as the work done per unit charge.

Work = (force)(displacement), so $1\,\ce{J} = 1\,\ce{N} \,\ce{m}$

Therefore $1\, \ce{V} = 1\,\ce{J}\, \ce{C^{-1}} = 1\,\ce{N} \,\ce{m} \,\ce{C^{-1}}$
