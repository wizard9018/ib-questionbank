# PH0801

Two parallel wires A and B are separated by a distance, $d$ and carry currents in opposite directions. The current in wire B is ten times greater than the current in wire A.

![PH0801xxx](images/PH0801xxx.png)

Which graph correctly identifies how the magnetic flux density, B varies with displacement traveling away from A towards B?

|C. |   |   | D.  ||

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

The wires carry current in opposite directions. Using the right-hand rule tells us that the fields of A and B are always pointing in the same direction along the line connecting the wires. Therefore, there is no change in the sign of the magnetic field so C and D can be disregarded.

Wire B has a greater current, so we expect a greater magnetic field close to B (compared with magnetic field close to A).

Therefore, the correct graph is A.

Note: C shows what the graph would look like if the current in wire B were reversed.
