# PH0595

A proton and another object with charge +e exert electrical and gravitational forces on one another. To the nearest order of magnitude, what mass must the object have to be so that the net force acting on it is zero?

![PH0595A](images/PH0595A.png)

- A. $\hspace{1em}   10^1\,$kg

- B. $\hspace{1em}  10^3\,$kg

- C. $\hspace{1em}   10^6\,$kg

- D. $\hspace{1em}   10^9\,$kg

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Equate $F=G\dfrac{Mm}{r^2}$ and $F=k\dfrac{q_1q_2}{r^2}$ from the data booklet so that

- $GMm_p=k\left(e\right)\left(e\right)$

Solving for M,

- $M=\dfrac{ke^2}{Gm_p}$

Substituting in for the known values,

- $M=\dfrac{(8.99\times{10}^9)(1.6\times{10}^{-19})^2}{(6.67\times{10}^{-11})(1.67\times{10}^{-27})}$

Rounding each input to the nearest order of magnitude

- $M=\dfrac{{(10}^{10})({10}^{-38})}{({10}^{-10})({10}^{-27})}={10}^9$ kg
