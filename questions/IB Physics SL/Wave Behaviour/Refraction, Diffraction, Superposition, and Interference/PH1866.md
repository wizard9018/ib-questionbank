# PH1866

Two loudspeakers emit sound waves with a wavelength of 20 cm. The diagram shows the positions of the two loudspeakers and a point $P$.

![Screenshot 2025-09-06 at 5.44.04 PM](<images/Screenshot 2025-09-06 at 5.44.04 PM.png>)

The waves leaving both loudspeakers are in antiphase. What is the phase difference between the waves when they reach point $P$, and what type of interference occurs at $P$?

$\\$

| | $\hspace{1.5em}$Phase difference / rad$\hspace{1.5em}$ | $\hspace{1.5em}$Type of interference$\hspace{1.5em}$ |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| 0 | Constructive |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | 0 | Destructive |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | $\pi$ | Constructive |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | $\pi$ | Destructive |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The path difference is given by:

- $1.1\textrm{ m}-1.0\textrm{ m}=0.1\textrm{ m}$

Expressing path difference in terms of number of wavelengths, we have:

- path difference $=\dfrac{0.1}{0.2}=\dfrac{1}{2}\lambda$

The phase difference due to the path difference is given by:

- phase difference $=\dfrac{2\pi(\textrm{path difference})}{\lambda}=\dfrac{2\pi(0.1)}{0.2}=\pi$ rad

The initial phase difference is $\pi$ radians so the total phase difference is given by:

- total phase difference $=\pi+\pi=2\pi$

A total phase difference of $2\pi$ corresponds to waves arriving in phase with no phase difference, so they interfere constructively at point $P$.
