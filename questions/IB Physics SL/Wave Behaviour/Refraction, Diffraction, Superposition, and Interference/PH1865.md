# PH1865

Monochromatic light passes through two slits and forms an interference pattern on a screen.

Below are three changes that can be made to the experimental arrangement:

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Increasing the distance between the slits and the screen |
  | II. | Decreasing the frequency of the light |
  | III. | Decreasing the distance between the slits |

Which of these changes, if made individually, would cause the fringe spacing to increase?

- A. $\hspace{1em}$ I and II only

- B. $\hspace{1em}$ I and III only

- C. $\hspace{1em}$ II and III only

- D. $\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The fringe spacing $s$ in a double-slit interference pattern is given by:

- $s=\dfrac{\lambda D}{d}$

where $\lambda$ is the wavelength of the light, $D$ is the distance between the slits and the screen, and $d$ is the slit separation.

Now let's consider each change:

**I. Increasing the distance between the slits and the screen**

$s\propto D$ so increasing $D$ will cause $s$ to increase

**II. Decreasing the frequency of the light**

The speed of light is constant, using $v=f\lambda$ we see that $\lambda\propto\dfrac{1}{f}$, so a decrease in frequency will lead to an increase in the wavelength of the light. Since $s\propto\lambda$ this will cause $s$ to increase.

**III. Decreasing the distance between the slits**

$s\propto\dfrac{1}{d}$ so a decrease in $d$ will lead to an increase in $s$.

All three changes I, II, and III will cause the fringe spacing to increase.
