# PS0751

According to the dual process model, identify one reason System 1 thinking might be faster than System 2.
[2 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer/s}}$:

- System 1 makes use of heuristics  (:span$\color{red}\checkmark$)  whereas System 2 does not (:span$\color{red}\checkmark$)

- System 1 is not likely to consider alternative explanations or options whereas System 2 is likely to (:span$\color{red}\checkmark$)

- System 1 is more likely to rely on hunches when making decisions (:span$\color{red}\checkmark$) whereas system 2 thinking involves conscious reasoning (which takes more time)  (:span$\color{red}\checkmark$)

$\underline{\textrm{Marking Guidance}}$:\

Marks should be awarded for any similarly worded point to a maximum of **2 marks**. If more than one reason is identified, marks should only be awarded for the first reason listed.
