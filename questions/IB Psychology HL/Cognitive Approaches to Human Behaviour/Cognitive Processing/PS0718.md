# PS0718

Define the multi-store model's concepts of capacity and duration.
[2 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:\

Capacity refers to the amount of information that can be held in a specific storage system (:span$\color{red}\checkmark$)

Duration refers to how long information can be held in a specific storage system (:span$\color{red}\checkmark$)
