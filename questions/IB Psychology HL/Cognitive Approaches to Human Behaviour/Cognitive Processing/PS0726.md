# PS0726

Describe the functions and features of long-term memory according to the multi-store model. In your response, refer to capacity, duration, retrieval, forgetting and how information is received in LTM.
[5 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:\

Long-term memory is the permanent storage location for memory. (:span$\color{red}\checkmark$)

If information is repeated or rehearsed enough in STM it moves to LTM (:span$\color{red}\checkmark$) for permanent storage. 

The capacity of LTM is potentially infinite. (:span$\color{red}\checkmark$)

The duration of LTM is potentially forever or permanent. (:span$\color{red}\checkmark$)

When we want to retrieve something from LTM it is moved to STM. (:span$\color{red}\checkmark$)

Forgetting is most likely the result of retrieval failure. (:span$\color{red}\checkmark$)
