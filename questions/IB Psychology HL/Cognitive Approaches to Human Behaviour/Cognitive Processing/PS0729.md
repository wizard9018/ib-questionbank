# PS0729

Define the term working memory (working memory model).
[2 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$:\

Working memory is the part of our memory that has a limited capacity (:span$\color{red}\checkmark$) and is responsible for holding and manipulating information in our conscious awareness at any given time. (:span$\color{red}\checkmark$)
