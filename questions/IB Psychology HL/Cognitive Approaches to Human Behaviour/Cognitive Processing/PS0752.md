# PS0752

According to the dual process model, system 1 is more likely to use heuristics. Define the term heuristics and explain how the use of heuristics can speed up the decision-making process.
[2 marks]

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample Answer}}$:\

Heuristics are mental shortcuts that allow us to focus on key elements of a problem or situation while ignoring less pertinent information.  (:span$\color{red}\checkmark$)  This speeds up decision-making because less content needs to be processed.  (:span$\color{red}\checkmark$)
