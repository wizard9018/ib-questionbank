# BI2830

The table below shows characteristics of nutrition for four unidentified microorganisms.

Which organism is **least** likely to be an archaeon?

| | Light used as an energy source | Organic compounds used as a carbon source | Inorganic chemicals used as an energy source | Carbon dioxide used as a carbon source |
| --- | :-: | :-: | :-: | :-: |
| A.$\hspace{1em}$ | No | Yes | No | No |
| B.$\hspace{1em}$ | No | No | Yes | Yes |
| C.$\hspace{1em}$ | Yes | Yes | No | No |
| D.$\hspace{1em}$ | Yes | No | No | Yes |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Archaea are highly diverse in how they obtain energy for ATP production. Some obtain energy from organic compounds, others from inorganic chemicals, and some can use light. However, known light-using archaea do not use light energy to fix carbon dioxide by photosynthesis.

**Choice D** is least likely to be an archaeon because the combination of light as the energy source and carbon dioxide as the carbon source indicates photoautotrophic nutrition. This is found among photosynthetic bacteria and eukaryotes but is not known among archaea.

**Choice A** is incorrect because some archaea use organic compounds as sources of both energy and carbon.    \
**Choice B** is incorrect because some archaea obtain energy by oxidising inorganic chemicals and use carbon dioxide as their carbon source.    \
**Choice C** is incorrect because some archaea can use light to generate ATP while obtaining carbon from organic compounds. Therefore, the use of light does not by itself make an organism unlikely to be an archaeon.
