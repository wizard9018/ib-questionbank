# BI2831

Which of the following statements illustrates coevolution between a plant and a herbivore?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Milkweed plants produce glycosides toxic to most insects and thus evolve resistance to herbivory. |
    | II. | Milkweed plants produce glycosides toxic to most insects, and monarch caterpillars feed on milkweed, sequestering its toxins to deter predators. |
    | III. | Aphids pierce phloem using stylets to avoid plant defences in leaves. |

- A.$\hspace{1em}$ II only

- B.$\hspace{1em}$ I and II

- C.$\hspace{1em}$ I and III

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is false in the context of coevolution because it only describes a plant adaptation. There is no mention of an evolutionary response by herbivores.\
**Statement II** is true because it shows a reciprocal interaction: the plant produces toxins (a defence), and the monarch caterpillar evolves the ability to tolerate and sequester them. This is a classic coevolutionary dynamic.\
**Statement III** is false as it describes only a herbivore adaptation (aphid mouthparts) without evidence of a corresponding evolutionary response in the plant.

**Choice A** is correct because only **Statement II** meets the definition of coevolution.\
**Choice B** is incorrect because **Statement I** does not show coevolution.\
**Choice C** is incorrect because neither **Statement I** nor **III** meets the full coevolution criteria.\
**Choice D** is incorrect because only **Statement II** qualifies.
