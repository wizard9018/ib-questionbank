# BI2827

Which of the following statements about holozoic nutrition is/are true?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | It occurs inside food vacuoles of all animals and involves the hydrolysis of macromolecules. |
    | II. | Absorbed nutrients are transported to cells where assimilation occurs. |
    | III. | All animals must ingest organic compounds for ATP synthesis. |

- A.$\hspace{1em}$ I and II

- B.$\hspace{1em}$ II and III

- C.$\hspace{1em}$ I and III

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is false. Food vacuoles are used for digestion in unicellular organisms (e.g., amoeba), but in multicellular animals, enzymatic hydrolysis occurs in the gut lumen or digestive tract, not inside vacuoles.

**Statement II** is true. After digestion, nutrients are absorbed and transported via the circulatory system to cells, where they are used in assimilation.

**Statement III** is true. As heterotrophs, all animals must ingest organic compounds to produce ATP through cell respiration.

**Choice B** is correct as it includes only the true **Statements II** and **III**.        \
**Choices A, C** and **D** are incorrect as they all include the false **Statement I**.
