## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

Polyunsaturated fatty acids have two or more double bonds. **Choice C** is correct.

**Choice A** is incorrect as it only contains single bonds so it is a saturated fatty acid. **Choices B** and **D** are incorrect as they each contain only one double bond, making them monounsaturated fatty acids.
