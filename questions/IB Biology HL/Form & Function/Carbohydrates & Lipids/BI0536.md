# BI0536

A polymer of beta-glucose found in plants has only 1,4-glycosidic linkages. Which molecule is described by this statement?

- A.$\hspace{1em}$ Amylopectin

- B.$\hspace{1em}$ Chitin

- C.$\hspace{1em}$ Cellulose

- D.$\hspace{1em}$ Glycogen

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Cellulose is a structural polysaccharide found in plants. Cellulose is a linear polymer of beta-glucose linked by only 1,4 glycosidic llinkages. Answer **Choice C** is therefore correct.

**Choice A**: Amylopectin is a storage polysaccharide of plants. Amylopectin consists of alpha-glucose joined primarily by 1,4 glycosidic linkages with some 1,6 glycosidic linkages, giving the polysaccharide a branched structure.

**Choice B**: Chitin is a structural polysaccharide found in animals and fungi. Chitin is a polymer of N-acetylglucosamine.

**Choice D**: Glycogen is a storage polysaccharide in animals. Like amylopectin, glycogen consists of alpha-glucose joined by 1,4 glycosidic linkages and 1,6 glycosidic linkages.
