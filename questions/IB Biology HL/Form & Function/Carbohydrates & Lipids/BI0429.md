# BI0429

Which molecule diagram is correctly matched to the name?

| | Name of molecule | Structure of molecule |
| :-: | :-: | :-: |
| $\hspace{1em}$A.$\hspace{1em}$| Glucose | ![429 a](<images/429 a.png>) |
|$\hspace{1em}$B.$\hspace{1em}$ | Ribose | ![429b](images/429b.png) |
| $\hspace{1em}$C.$\hspace{1em}$ | Deoxyribose | ![429c](images/429c.png) |
| $\hspace{1em}$D.$\hspace{1em}$ | Glycerol | ![429d](images/429d.png)|

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

**Choice A** is correct because the structure shown is cyclic glucose, a six-carbon monosaccharide (hexose). It contains a six-membered ring with one oxygen atom in the ring, a CH₂OH side group, and the arrangement of hydroxyl (–OH) groups characteristic of glucose.

**Choice B** is incorrect because ribose has a hydroxyl (–OH) group on carbon 2, but the structure shown has a hydrogen (H) at this position. Therefore, the molecule shown is deoxyribose rather than ribose.

**Choice C** is incorrect because deoxyribose lacks the hydroxyl (–OH) group on carbon 2. The structure shown contains an –OH group on carbon 2, so it represents ribose rather than deoxyribose.

**Choice D** is incorrect because glycerol is a three-carbon alcohol with the formula C₃H₈O₃. The structure shown contains four carbon atoms, so it cannot be glycerol.
