# BI0440

Which of the following is the correct composition of the named polysaccharide?

| | $\hspace{1em}$ Polysaccharide $\hspace{1em}$ | $\hspace{1em}$ Glucose molecule $\hspace{1em}$ | $\hspace{1em}$ Linkages $\hspace{1em}$ |

| :-: | :-: | :-: | :-: |

| $\hspace{1.5em}$ A. $\hspace{1.5em}$ | Starch | $\beta-$ glucose | 1,4 and 1,6 |

| $\hspace{1.5em}$ B. $\hspace{1.5em}$ | Glucagon | $\alpha-$ glucose | 1,4 |

| $\hspace{1.5em}$ C. $\hspace{1.5em}$ | Glycogen | $\alpha-$ glucose | 1,4 and 1,6 |

| $\hspace{1.5em}$ D. $\hspace{1.5em}$ | Cellulose | $\beta-$ glucose | 1,6 |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

**Choice A** is incorrect as starch is made up of $\alpha-$ glucose molecules. **Choice B**  is incorrect as glucagon is not a polysaccharide, and is therefore not made up of glucose. **Choice D**  is incorrect, as the linkages between the ꞵ- glucose molecules are 1,4 linkages only.
