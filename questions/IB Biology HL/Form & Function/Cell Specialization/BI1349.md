# BI1349

How can cells increase their surface area-to-volume ratio?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Flattening of cells |
    | II. | Microvilli |
    | III. | Invagination |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because **Statements I, II** and **III** are all true. The flattening of cells, the presence of microvilli and the invagination of the plasma membrane all increase the surface-area-to-volume ratio. **Choices A, B** and **C** are all incorrect because they do not include all statements.
