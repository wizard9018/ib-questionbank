# BI1351

Which pair of characteristics are true for cardiac muscle cells?

| | Type of fibres | Number of nuclei |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Branching fibres | Single nucleus |
| B.$\hspace{1em}$ | Branching fibres | Many nuclei |
| C.$\hspace{1em}$ | Parallel fibres | Single nucleus |
| D.$\hspace{1em}$ | Parallel fibres | Many nuclei |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because cardiac muscle cells are composed of branched fibres with a single nucleus. **Choice B** is incorrect because cardiac muscle cells do not contain multiple nuclei. **Choice C** is incorrect because cardiac muscle cells are not composed of parallel fibres. **Choice D** is incorrect because cardiac muscle cells are not composed of parallel fibres and do not contain multiple nuclei.
