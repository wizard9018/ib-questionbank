# BI0943

Which is a correct description of the cell type adapted for gas exchange in the lungs?

- A.$\hspace{1em}$ Type II pneumocytes which contain many secretory vesicles

- B.$\hspace{1em}$ Type I pneumocytes which contain many secretory vesicles

- C.$\hspace{1em}$ Type I pneumocytes which are extremely thin

- D.$\hspace{1em}$ Type II pneumocytes which are extremely thin

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** correctly describes the cell type adapted for gas exchange in the lungs.  **Choice A** is incorrect because although it is a correct description of type II pneumocytes, these cells are not adapted for gas exchange. **Choice B** is incorrect because type I pneumocytes do not contain many secretory vesicles. **Choice D** is incorrect because type II pneumocytes are not extremely thin.
