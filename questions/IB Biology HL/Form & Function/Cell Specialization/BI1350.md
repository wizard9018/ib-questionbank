# BI1350

Which of these rows shows the correct functions of type I and type II pneumocytes?

| | Type I pneumocytes | Type II pneumocytes |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Diffusion | Production of surfactants |
| B.$\hspace{1em}$ | Prevent adhesion | Diffusion |
| C.$\hspace{1em}$ | Production of surfactants | Active transport |
| D.$\hspace{1em}$ | Active transport | Prevent adhesion |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because type I pneumocytes are flattened cells, meaning the diffusion distance for gaseous exchange is reduced, and type II pneumocytes produce surfactant to prevent adhesion of the alveolar walls. **Choice B** is incorrect because type I pneumocytes do not prevent adhesion, and the function of type II pneumocytes is not diffusion. **Choice C** is incorrect because type I pneumocytes do not produce surfactants. **Choice D** is incorrect because the function of type I pneumocytes is gas exchange, and gases are not exchanged by active transport.
