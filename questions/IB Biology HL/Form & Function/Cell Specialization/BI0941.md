# BI0941

What is this cell's most likely primary function, and where could it be located in a mammal?

![BI0941](images/BI0941.png)

| | $\hspace{1em}$ Function $\hspace{1em}$ | $\hspace{1em}$ Location $\hspace{1em}$ |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | $\hspace{1em}$ absorption $\hspace{1em}$ | $\hspace{1em}$ nephron $\hspace{1em}$ |
| B.$\hspace{1em}$ | $\hspace{1em}$ absorption $\hspace{1em}$ | $\hspace{1em}$ capillary $\hspace{1em}$ |
| C.$\hspace{1em}$ | $\hspace{1em}$ immune defence $\hspace{1em}$ | $\hspace{1em}$ bone marrow $\hspace{1em}$ |
| D.$\hspace{1em}$ | $\hspace{1em}$ insulation $\hspace{1em}$ | $\hspace{1em}$ adipose tissue $\hspace{1em}$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because microvilli are present, increasing the cell's surface area for absorption. Cells of the proximal convoluted tubule in the nephron require a large surface area for selected reabsorption of substances in the filtrate. **Choice B** is incorrect because cells lining capillaries are flat (squamous epithelial tissue). **Choice C** is incorrect because cells of the immune system do not have microvilli. **Choice D** is incorrect because the function of microvilli is not insulation, and adipose cells do not have microvilli.
