# BI1714

Haematopoietic stem cells are found in the bone marrow. Which row in the table below is true of haematopoetic stem cells?

| | $\text{Pluripotent}$ | $\text{Multipotent}$ |

| --- | :-: | :-: |

| A.$\hspace{1em}$ | Yes | No |

| B.$\hspace{1em}$ | Yes | Yes |

| C.$\hspace{1em}$ | No | Yes |

| D.$\hspace{1em}$ | No | No |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

Haematopoietic stem cells (HSCs) are multipotent, meaning they can differentiate into multiple, but limited, cell types. Specifically, they can give rise to all the different types of blood cells, including red blood cells, white blood cells, and platelets. **Choice C** is correct.

**Choices A, B** and **D** are all incorrect as haematopoietic stem cells are multipotent, but nor pluripotent.
