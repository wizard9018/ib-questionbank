# BI0942

Based on the Venn diagram, which identifies cardiac muscle cells and striated muscle fibres?

![BI0942](images/BI0942.png)

| | I | II | III |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | striated muscle fibres | cardiac muscle | neither |
| B.$\hspace{1em}$ | both | striated muscle fibres | cardiac muscle |
| C.$\hspace{1em}$ |cardiac muscle | both | skeletal muscle fibres |
| D.$\hspace{1em}$ | cardiac muscle | striated muscle fibres | neither |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because only cardiac muscle cells are both branched and contain contractile muscle fibres, while only striated muscle fibres have multiple nuclei and contractile muscle fibres. **Choice A** is incorrect because striated muscle fibres are not branched and because cardiac muscle cells do not contain multiple nuclei. **Choice B** is incorrect because only cardiac muscle cells are branched and do not contain multiple nuclei. **Choice C** is incorrect because only striated muscle fibres contain multiple nuclei and are not branched.
