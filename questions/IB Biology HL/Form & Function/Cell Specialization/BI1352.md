# BI1352

Which pair of characteristics are true for striated muscle cells?

| | Type of fibres | Number of nuclei |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Branching fibres | Single nucleus |
| B.$\hspace{1em}$ | Branching fibres | Many nuclei |
| C.$\hspace{1em}$ | Parallel fibres | Single nucleus |
| D.$\hspace{1em}$ | Parallel fibres | Many nuclei |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because striated muscle cells are composed of parallel fibres with many nuclei, sarcomeres and a sarcolemma. **Choice A** is incorrect because striated muscle cells are not composed of branching fibres and do not contain a single nucleus. **Choice B** is incorrect because striated muscle cells are not branched. **Choice C** is incorrect because a striated muscle cell contains more than one nucleus.
