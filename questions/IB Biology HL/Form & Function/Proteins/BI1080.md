# BI1080

Which of the following  is/are correct for amino acid R-groups?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | R-groups can be hydrophobic or hydrophilic. |
    | II. | Hydrophobic R-groups are polar. |
    | III. | Hydrophilic R-groups can be acidic or basic.  |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because R-groups can be hydrophilic or hydrophobic (**Statement I**), and hydrophilic R-groups can be acidic or basic **(Statement III)**.

**Choice A** is incorrect as it contains only one correct statement. **Choices B** and **D** are incorrect because they contain **Statement II**, which is incorrect because hydrophobic R-groups are non-polar.
