# BI1081

Which of the following is correct for amino acid R-groups?

- A.$\hspace{1em}$ Hydrophobic R-groups can be polar

- B.$\hspace{1em}$ Hydrophobic R-groups can be acidic

- C.$\hspace{1em}$ Hydrophilic R-groups can be non-polar

- D.$\hspace{1em}$ Hydrophilic R-groups can be basic

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because hydrophilic R-groups can be basic. **Choice A** is incorrect because hydrophobic R-groups are non-polar. **Choice B** is incorrect because hydrophobic R-groups are not acidic (or basic). **Choice C** is incorrect because hydrophilic R-groups are polar or charged.
