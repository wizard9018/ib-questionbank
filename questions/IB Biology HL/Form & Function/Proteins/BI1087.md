# BI1087

Which row in the table is correct for amino acids?

| | R-Group | Property | Location |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | Polar | Hydrophobic | Exposed to the cytoplasm in integral proteins |
| B.$\hspace{1em}$ | Polar | Hydrophilic | Clustered in the centre of globular proteins |
| C.$\hspace{1em}$ | Non-Polar | Hydrophilic | Exposed to the cytoplasm in integral proteins |
| D.$\hspace{1em}$ | Non-Polar | Hydrophobic | Clustered in the centre of globular proteins |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because amino acids with non-polar R-groups have hydrophobic properties. They can be found clustered in the centre of globular proteins. **Choice A** is incorrect because amino acids with polar R-groups are not hydrophobic. **Choice B** is incorrect because hydrophilic amino acids are not found clustered in the centre of globular proteins. **Choice C** is incorrect because amino acids with non-polar R-groups are not hydrophilic.
