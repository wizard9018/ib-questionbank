# BI2325

Which statement is true for essential and non-essential amino acids?

- A.$\hspace{1em}$ Both must be synthesised from precursor molecules.

- B.$\hspace{1em}$ Essential amino acids can be synthesised in sufficient quantities by animals.

- C.$\hspace{1em}$ Non-essential amino acids cannot be synthesised by animals.

- D.$\hspace{1em}$ Non-essential amino acids can be synthesised from essential amino acids.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because non-essential amino acids can be synthesised by animals, often using essential amino acids or other precursor molecules. For example, tyrosine (a non-essential amino acid) can be synthesised from phenylalanine (an essential amino acid).

**Choice A** is incorrect because essential amino acids cannot be synthesised by animals and must be obtained through the diet. Only non-essential amino acids can be synthesised from precursor molecules.

**Choice B** is incorrect because essential amino acids cannot be synthesised by animals at all (or in sufficient quantities) and must be obtained from the diet.

**Choice C** is incorrect because non-essential amino acids can be synthesised by animals, typically using precursor molecules such as essential amino acids or intermediates from metabolic pathways.
