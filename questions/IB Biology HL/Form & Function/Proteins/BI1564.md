# BI1564

Human growth hormone (HGH) is a single-chain polypeptide 191 amino acids long. How many water molecules would be required to completely hydrolyse this substance?

- A.$\hspace{1em}$ 190

- B.$\hspace{1em}$ 191

- C.$\hspace{1em}$ 192

- D.$\hspace{1em}$ 383

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because each peptide bond must be hydrolysed by one water molecule, but a single-chain polypeptide always has one less peptide bond than the number of amino acids it contains. For HGH, this would mean 190 peptide bonds, and therefore, 190 water molecules.

**Choices B, C**, and **D** are incorrect because there are only 190 bonds to be hydrolysed, the same as the number of water molecules required.
