# BI1085

Which of the following is an example of a non-conjugated fibrous protein?

- A.$\hspace{1em}$ Haemoglobin

- B.$\hspace{1em}$ Collagen

- C.$\hspace{1em}$ Amylase

- D.$\hspace{1em}$ Insulin

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because collagen is a non-conjugated fibrous protein, as it does not contain non-protein groups. **Choice A** is incorrect because haemoglobin is a conjugated globular protein, as it contains haem groups. **Choices C** and **D** are incorrect because amylase and insulin are globular proteins.
