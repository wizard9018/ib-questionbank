# BI2838

Which of the following contributes most to the diversity of possible polypeptides?

- A.$\hspace{1em}$ The different types of peptide bonds

- B.$\hspace{1em}$ The sequence and number of amino acids

- C.$\hspace{1em}$ The strength of hydrogen bonding

- D.$\hspace{1em}$ The number of codons in a gene

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because the diversity of possible polypeptides arises from the ability to vary both the number of amino acids in a chain and the order in which the 20 different amino acids are arranged. This allows for an enormous number of possible combinations.

**Choice A** is incorrect because all peptide bonds are chemically the same; there are not different types contributing to diversity.

**Choice C** is incorrect because hydrogen bonding affects the three-dimensional folding of the polypeptide, not the diversity of the primary structure (the sequence).

**Choice D** is incorrect because while codons determine which amino acids are used, the number of codons in a single gene is limited by the gene's length and does not account for the broader combinatorial possibilities of polypeptide sequences.
