# BI1086

Which of the following are influenced by hydrogen bonding?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Protein primary structure |
    | II. | Protein secondary structure |
    | III. | Protein tertiary structure |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because only **Statements II** and **III** are correct. Hydrogen bonding can influence the secondary and tertiary structure of a protein. **Choices A** and **D** are incorrect because they contain **Statement I** which is incorrect. The primary structure of a protein is not influenced by hydrogen bonding. The primary structure is the sequence and position of the amino acids along a polypeptide chain, so the only bonds involved in this structure are the peptide bonds between the amino acids. **Choice B** is incorrect as it only contains one correct statement.
