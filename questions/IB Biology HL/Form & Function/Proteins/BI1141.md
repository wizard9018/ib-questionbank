$\underline{\textrm{Explanation}}$: \
Amino acids contain an amino group (H:sub[2]N) and a carboxyl group (COOH), which can be seen in the diagram (the diagram shows the amino acid valine).

**Choice A** is incorrect since it is a fatty acid (valeric acid). **Choice B** is a carbohydrate (fructose). **Choice D** is glycerol.
