# BI1143

Which of the following statements is true regarding peptide bonds?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Ribosomes facilitate their formation. |
    | II. | They form between an alcohol and a carboxyl group. |
    | III. | They require the addition of water. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Only **Statement I** is correct since, during translation, ribosomes position the tRNA in the correct place along the mRNA, allowing peptide bonds to form between adjacent amino acids. Therefore, **Choice A** is correct.

**Statement II** is incorrect because peptide bonds form between amino and carboxyl groups. **Statement III** is false because water is produced during the condensation reaction instead of being required. Thus, **Choices B, C** and **D** cannot be correct.
