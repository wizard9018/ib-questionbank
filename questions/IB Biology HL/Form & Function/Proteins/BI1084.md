# BI1084

Which of the following rows in the table is correct for haemoglobin or collagen?

| | Name of Protein | Conjugation | Type of Protein |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | Haemoglobin | Non-conjugated | Fibrous |
| B.$\hspace{1em}$ | Collagen | Conjugated | Fibrous |
| C.$\hspace{1em}$ | Haemoglobin | Conjugated | Globular |
| D.$\hspace{1em}$ | Collagen | Non-conjugated | Globular |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because haemoglobin is a conjugated globular protein. It is conjugated as it contains haem groups, which are non-protein groups. **Choice A** is incorrect, as haemoglobin is not a fibrous protein. **Choice B** is incorrect, as collagen is a non-conjugated protein. **Choice D** is incorrect because collagen is not a globular protein.
