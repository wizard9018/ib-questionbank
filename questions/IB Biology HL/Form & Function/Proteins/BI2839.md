# BI2839

In a sequence of 5 amino acids within a human protein, each position can be any amino acid (amino acids may repeat). How many possible sequences are there?

- A.$\hspace{1em}$ $20^5$

- B.$\hspace{1em}$ $5^{20}$

- C.$\hspace{1em}$ 5 x 20

- D.$\hspace{1em}$ 20 + 5

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
There are 20 different amino acids available to choose from for every single "slot" in the peptide chain.

The Calculation:

- For the 1st position, there are 20 choices.
- For the 2nd position, there are 20 choices.
- This continues for all 5 positions: $20 \times 20 \times 20 \times 20 \times 20
- In mathematical terms, this is expressed as $20^5$.

Therefore, **Choice A** is correct. This is equivalent to 3,200,000 possible sequences.

**Choice B** is incorrect because it reverses the number of possible amino acids and the number of positions.

**Choice C** is incorrect because multiplying 20 by 5 does not account for the 20 independent possibilities at each of the five positions.

**Choice D** is incorrect because the number of amino-acid choices and the number of positions must not simply be added.
