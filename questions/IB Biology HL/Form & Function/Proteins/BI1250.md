# BI1250

Peanuts (*Arachis hypogaea*) are high in phenylalanine, an essential amino acid. What is true regarding this amino acid?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | It can only be obtained from the diet  |
    | II. | It can be recycled following protein degradation by proteasomes  |
    | III. | It cannot be used by the body to synthesise polypeptides  |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Essential amino acids such as phenylalanine can only be obtained through the diet (**Statement I**). All amino acids can be recycled by proteasomes for further use within the cell (**Statement II**). Although the body cannot synthesise essential amino acids, it has no problem using the ones obtained from food to synthesise polypeptides such as enzymes and hormones. Thus, **Statement III** is false, and **Choice C** must be correct.

**Choice A** is incorrect as it does not include **Statement II**. **Choices B** and **D** are not correct as they contain **Statement III**.
