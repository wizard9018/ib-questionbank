# BI2689

The table below shows oxygen saturation levels at different partial pressures of oxygen in two conditions: normal $\ce{CO_2}$ and high $\ce{CO_2}$.

|Partial pressure (kPa) | % Saturation (Normal $\mathbf{CO_2}$) | % Saturation (High $\mathbf{CO_2}$) |
| :-: | :-: | :-: |
| 2.0 | 35% | 20% |
| 4.0 | 65% | 50% |
| 8.0 | 90% | 80% |

Which conclusion can be drawn from the table?

- A.$\hspace{1em}$ High $\ce{CO_2}$ increases haemoglobin's affinity for oxygen.

- B.$\hspace{1em}$ The Bohr shift reduces haemoglobin's ability to release oxygen.

- C.$\hspace{1em}$ High $\ce{CO_2}$ promotes oxygen unloading by shifting the dissociation curve right.

- D.$\hspace{1em}$ The difference in oxygen saturation is due to temperature changes, not $\ce{CO_2}$.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because the table shows that under high $\ce{CO_2}$ conditions, haemoglobin has lower oxygen saturation at each partial pressure, indicating a rightward shift of the oxygen dissociation curve. This reflects the Bohr shift, where increased $\ce{CO_2}$ lowers haemoglobin's affinity for oxygen, promoting oxygen unloading in tissues.

**Choice A** is incorrect because high $\ce{CO_2}$ lowers haemoglobin's affinity for oxygen, it doesn't increase it. \
**Choice B** is incorrect because the Bohr shift enhances, not reduces, oxygen unloading. \
**Choice D** is incorrect because the data shows the effect of $\ce{CO_2}$, not temperature.
