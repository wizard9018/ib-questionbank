# BI2684

Which of the following statements about haemoglobin and oxygen transport is/are true?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | The Bohr effect causes haemoglobin to release oxygen in tissues with high carbon dioxide concentrations. |
    | II. | Cooperative binding means that after the first oxygen binds to haemoglobin, subsequent oxygen molecules bind more easily. |
    | III. | Foetal haemoglobin has a lower affinity for oxygen than adult haemoglobin to ensure oxygen transfer from mother to fetus. |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because the Bohr effect reduces haemoglobin's  affinity for oxygen in tissues with high carbon dioxide concentrations, facilitating oxygen release where it is most needed.\
**Statement II** is true because cooperative binding means that once the first oxygen molecule binds to haemoglobin, the molecule undergoes a conformational change, making it easier for subsequent oxygen molecules to bind.\
**Statement III** is false because foetal haemoglobin has a higher affinity for oxygen than adult haemoglobin, allowing efficient oxygen transfer from the maternal to foetal blood.

**Choice A** is correct because it contains both true **Statements I** and **II**.

**Choices B, C** and **D** are incorrect because they contain the false **Statement III**.
