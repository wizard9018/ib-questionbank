# BI2687

How does haemoglobin respond to increased carbon dioxide levels?

- A.$\hspace{1em}$ It binds oxygen more strongly.

- B.$\hspace{1em}$ It shifts to a low-affinity state, releasing more oxygen.

- C.$\hspace{1em}$ It prevents $\ce{CO_2}$ from being transported in the blood.

- D.$\hspace{1em}$ It becomes saturated with oxygen more quickly.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because increased $\ce{CO_2}$ levels cause the Bohr shift, where haemoglobin adopts a lower-affinity state, promoting oxygen release in tissues with high $\ce{CO_2}$ concentrations.\
**Choice A** is incorrect because elevated $\ce{CO_2}$ reduces haemoglobin's affinity for oxygen, facilitating oxygen unloading rather than stronger binding.\
**Choice C** is incorrect because the Bohr shift does not affect $\ce{CO_2}$ transport, only oxygen affinity. **Choice D** is incorrect because haemoglobin's oxygen saturation is determined by oxygen partial pressure (p$\ce{O_2}$), not $\ce{CO_2}$ levels.
