# BI1130

Which of the following statements about foetal haemoglobin is/are correct?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Foetal haemoglobin has a higher affinity for oxygen than adult haemoglobin. |
    | II. | Foetal haemoglobin releases oxygen more readily than adult haemoglobin at the low partial pressures of oxygen found in the placenta. |
    | III. | Foetal haemoglobin binds oxygen cooperatively, so its oxygen dissociation curve is sigmoid. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because foetal haemoglobin has a higher affinity for oxygen than adult haemoglobin, so its oxygen dissociation curve lies to the left. This allows it to load oxygen in the placenta at partial pressures at which maternal haemoglobin is unloading oxygen.

**Statement II** is false because at the low partial pressures of oxygen in the placenta, foetal haemoglobin binds oxygen more readily than adult haemoglobin rather than releasing it.

**Statement III** is true because, like adult haemoglobin, foetal haemoglobin binds oxygen cooperatively, giving a sigmoid curve.

**Choice C** is correct as it only includes the two true **Statements I** and **III**. **Choice A** is incorrect because it omits **Statement III**. **Choices B** and **D** are incorrect as they include the false **Statement II**.
