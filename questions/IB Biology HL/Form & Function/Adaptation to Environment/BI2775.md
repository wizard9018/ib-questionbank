# BI2775

Which statement(s) are correct for the range of tolerance for a species?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Individuals are only found at the optimum condition. |
    | II. | Population size gradually decreases the further the environmental condition moves beyond the range of tolerance. |
    | III. | Population size varies within the range of tolerance. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement III** is true because the population is highest at the optimum condition and decreases as the condition moves away from the optimum. Population size is highest at the optimum condition but varies within the range of tolerance, because it decreases as the condition moves further from the optimum.

**Statement I** is false because organisms are found within the zone of tolerance, including, but not limited to, when the condition is optimum.

**Statement II** is false because the organism is not found beyond the range of tolerance. The range of tolerance is the range for a condition at which an organism can be found, for example, pH. When the pH is above or below this range, the organism cannot survive and will not be found.

**Choice C** is correct because only **Statement III** is correct.

**Choice A** is incorrect because **Statement III** is true. **Choices B** and **D** are incorrect because **Statement I** and **Statement II** are not true.
