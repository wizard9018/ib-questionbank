# BI0939

Which row about the different methods of membrane transport is **incorrect**?

| | Membrane transport | Requires ATP? | Is a cotransporter? | Transports ions |
| --- | :-: | :-: | :-: | :-: |
| A.$\hspace{1em}$ | Sodium potassium pump | ✓ | ✗ | ✓ |
| B.$\hspace{1em}$ | Exocytosis | ✓ | ✗ | ✗ |
| C.$\hspace{1em}$ | Sodium dependent glucose cotransporters | ✓ | ✓ | ✓ |
| D.$\hspace{1em}$ | Facilitated diffusion| ✗ | ✗ | ✓|

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Sodium-dependent glucose cotransporters (SGLTs) do not directly use ATP. Instead, they rely on the sodium ion (Na⁺) gradient, which is actively maintained by the sodium-potassium pump (a process that does require ATP). SGLTs are symporters, a type of cotransporter, as they move Na⁺ ions and glucose together in the same direction into the cell. Since row C incorrectly states that SGLTs directly require ATP, **Choice C** is the correct answer to the question.

The sodium-potassium pump is a primary active transport mechanism as it directly hydrolyses ATP to pump three sodium ions out and two potassium ions into the cell. It is not a cotransporter because it does not rely on an ion gradient to transport another substance—it actively moves ions against their concentration gradients using ATP.  Since row A is true, **Choice A** is an incorrect answer to the question.

Exocytosis requires ATP for the fusion of vesicles with the plasma membrane to release contents outside the cell. It is also a bulk transport process that does not involve cotransporters, and it does not specifically transport ions but instead releases larger molecules, like proteins or hormones. Since row B is true of exocytosis, **Choice B** is an incorrect answer to the question.

Facilitated diffusion is a passive transport process, so it does not require ATP. It does not involve cotransporters but uses specific protein channels or carriers for the movement of substances, including ions. Since row D is true of facilitated diffusion, **Choice D** is an incorrect answer to the question.
