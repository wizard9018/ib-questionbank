# BI1054

Which of the following is evidence to support the fluid mosaic model of the plasma membrane?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Membrane fusion experiments revealed membrane proteins can diffuse from one position to another in the phospholipid bilayer. |
    | II. | Analysis of membrane proteins indicated that some amino acids of membrane proteins were hydrophobic. |
    | III. | Freeze-etching studies of plasma membranes revealed no proteins embedded within the fatty acid tail region. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
In the fluid mosaic model of the plasma membrane, shows proteins are able to move within the phospholipid bilayer. The finding that proteins can move throughout the membrane supported this model and refuted earlier models. **Statement I** is true.

Additionally, the discovery that some amino acids in membrane proteins are hydrophobic further supports the fluid mosaic model. Integral membrane proteins contain hydrophobic regions, which allow them to interact with the hydrophobic fatty acid tails of phospholipids and remain embedded in the bilayer. This structural adaptation is consistent with the fluid mosaic model. Therefore, **Statement II** is true.

However, Statement III is not true. Freeze-etching studies actually provided evidence for embedded membrane proteins, rather than showing their absence. This technique, which involves rapidly freezing and fracturing the membrane, revealed integral proteins spanning the bilayer. If freeze-etching had shown no proteins within the fatty acid tail region, it would contradict the fluid mosaic model, which clearly describes integral proteins as embedded within the bilayer. Therefore, **Statement III** does not support the fluid mosaic model.

**Choice B** is correct, as only **Statements I** and **II** are true.

**Choice A** is incorrect as it is missing **Statement II**.

**Choices C** and **D** are incorrect as they include the untrue **Statement III**.
