# BI1504

Cholesterol molecules found in membranes affect the fluidity of the membrane.  Which of the following statements is/are true for cholesterol found in membranes?

- :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :-- | :-- |

    | I. | Interacts with the phosphate head and fatty acid tails |

    | II. | Stabilises membranes at high temperatures |

    | III. | Increases rigidity at lower temperatures |

| | |

| --- | :-- |

| A.$\hspace{1em}$ | I only |

| B.$\hspace{1em}$ | I and II only |

| C.$\hspace{1em}$ | II and III only |

| D.$\hspace{1em}$ | I, II and III |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

**Statement I** is true because The polar hydroxyl group of cholesterol forms hydrogen bonds with the polar phosphate heads of phospholipids, positioning cholesterol in the membrane. The nonpolar, hydrophobic four-ring steroid structure and hydrocarbon tail interact with the fatty acid tails of phospholipids. Cholesterol fits between phospholipid molecules, affecting the packing of the fatty acid tails.

**Statement II** is true because cholesterol stabilises membranes at high temperatures by reducing excessive fluidity. At elevated temperatures, lipid molecules move rapidly, increasing fluidity, which can harm the cell's integrity and function. Cholesterol disrupts the close packing of lipids, reducing their movement and overall membrane fluidity, thus maintaining membrane integrity.

**Statements I** and **II** are the only true statements, making **Choice B** the correct answer. 

**Statement III** is not true, as at lower temperatures, cholesterol maintains membrane fluidity by preventing phospholipid tails from packing too tightly. This prevents the membrane from becoming too rigid and ensures it remains flexible enough to function properly. Instead of increasing rigidity, cholesterol ensures the membrane retains its flexibility in cold conditions.

**Choice A** is missing **Statement II** so is not correct. **Choices C** and **D** both include **Statement III**, so are incorrect.
