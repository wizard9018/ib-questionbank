# BI1138

What is true about the membrane structure in the image below?

![liposome](images/liposome.png)

- :::tableoptions{col1="hide" col2="hide"}
 | | |
 | :-- | :-- |
 | I. | It is a lipid bilayer. |
 | II. | It contains cholesterol. |
 | III. | It contains both hydrophobic and hydrophilic components. |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The image depicts a liposome, which has two layers of lipids (a bilayer), each containing hydrophilic heads and hydrophobic tails.

**Choices A, B**, and **D** cannot be correct because this membrane does not include cholesterol.
