# BI0018

![BI0018](images/BI0018.png)

Which structure represents a component responsible for reducing membrane fluidity at higher temperatures?

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Structure **D** corresponds to a cholesterol molecule that can reduce membrane fluidity.

Structure **A** corresponds to a glycoprotein, structure **B** corresponds to a glycolipid and structure **C** corresponds to an integral protein. None of these reduces the fluidity of membranes.
