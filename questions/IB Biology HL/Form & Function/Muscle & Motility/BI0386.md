# BI0386

Which statement(s) are true for ATP hydrolysis during muscle contraction?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | ATP is hydrolysed by the sarcoplasmic reticulum |
    | II. | ATP hydrolysis causes myosin heads to move into the ready position |
    | III. | ATP hydrolysis causes the cross-bridges to break |

- A.$\hspace{1em}$ I, II and III

- B.$\hspace{1em}$ I only

- C.$\hspace{1em}$ II only

- D.$\hspace{1em}$ III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because **statement II** is the only correct statement. **Statement I** is incorrect because hydrolysis of ATP happens due to the ATPase enzyme in the myosin heads. **Statement II** is correct because hydrolysis of ATP does cause the myosin heads to move into the ready position. **Statement III** is incorrect because the attachment of ATP to myosin causes the cross bridges to break, not the hydrolysis of ATP.
