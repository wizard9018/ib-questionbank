# BI2821

Which of the following statements about motor units is/are correct?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | All muscle fibres in a motor unit contract simultaneously |
    | II. | The number of fibres in a motor unit determines the precision of control |
    | III. | A single muscle fibre may be stimulated by multiple motor neurons |

- A.$\hspace{1em}$ II only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
A motor unit consists of one motor neuron and all the muscle fibres it innervates. When the motor neuron sends an action potential, all the fibres in that motor unit contract together, producing a coordinated contraction; **Statement I** is true.

Motor units with fewer muscle fibres (e.g. in the fingers or eyes) allow for fine, precise control, while those with many fibres (e.g. in the legs) generate powerful but less precise movements;  **Statement II** is true.

Each muscle fibre is innervated by only one motor neuron. This ensures that signals to contract are unambiguous and coordinated. The reverse is true: one motor neuron can stimulate multiple muscle fibres; **Statement III** is false.

**Choice C** is correct because it only includes the two true **Statements I** and **II**.\
**Choice A** is incorrect as it only includes one of the true statements.\
**Choices B** and **D** are incorrect as they include the false **Statement III**.
