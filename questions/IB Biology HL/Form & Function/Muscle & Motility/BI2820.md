# BI2820

Which of the following is/are true about titin?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | It prevents overstretching of sarcomeres |
    | II. | It generates active force for contraction |
    | III. | It contributes to muscle elasticity |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Titin is a large protein that connects the Z-disc to the M-line in sarcomeres. It acts as a molecular spring, helping to maintain the structural integrity of the sarcomere and preventing overstretching during muscle contraction and relaxation; **Statement I** is true.

Titin does not generate active force for contraction. Active force during muscle contraction is primarily generated by myosin, the motor protein, interacting with actin filaments. Titin's role is structural and elastic, not force generation; **Statement II** is false.

Titin contributes to the passive elasticity of muscle fibres. It acts like a spring, which helps return the muscle to its resting length after contraction. This elastic property is essential for maintaining muscle tone and preventing damage from excessive stretch.  **Statement III** is true.

**Choice B** is correct because it only includes the two true **Statements I** and **III**.\
**Choice A** is incorrect as it only includes one of the true statements.\
**Choices C** and **D** are incorrect as they include the false **Statement II**.
