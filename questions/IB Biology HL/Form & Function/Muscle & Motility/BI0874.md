# BI0874

The diagram shows a zebra (*Equus quagga*). Which is **not** a reason for it to move?

![BI0874](images/BI0874.png)
[Source: Adapted from Katz, M. (2022, August 3). *Zebra*. Wikimedia Commons. Retrieved July 28, 2023, from URL https://commons.wikimedia.org/wiki/Zebra. Copyright free]

- A.$\hspace{1em}$ To find a mate

- B.$\hspace{1em}$ To escape grassland fires

- C.$\hspace{1em}$ To find a food source

- D.$\hspace{1em}$ To run towards predators

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because zebras run away rather than towards predators. **Choices A, B** and **C** are incorrect because zebras move to find mates, escape grassland fires and find sources of food.
