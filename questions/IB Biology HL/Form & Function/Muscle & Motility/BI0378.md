# BI0378

Which of these statements are true for synovial joints?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. |Synovial fluid lubricates the joint. |
    | II. | Synovial joints can only move in one direction (plane) |
    | III. | Ligaments connect one bone to another |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and III

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statements I** and **III** are correct. **Statement II** is incorrect because only some joints (knee and elbow) allow movement in one direction; there are other synovial joints that allow movement in additional directions (hip and shoulder).
