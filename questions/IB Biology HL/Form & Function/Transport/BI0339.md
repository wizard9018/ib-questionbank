# BI0339

Which row in the table is correct for sugar transport in phloem?

| | Direction of Sugar Transport | Flow |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Up and Down | Source → Sink |
| B.$\hspace{1em}$ | Up and Down | Sink → Source |
| C.$\hspace{1em}$ | Down ONLY | Source → Sink |
| D.$\hspace{1em}$ | Down ONLY | Sink → Source |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Sucrose is actively loaded into phloem at sites called **sources**, which are regions of the plant where photosynthesis occurs (such as the leaves) or where nutrients are stored (such as in storage organs). Sucrose is unloaded from phloem tubes in **sinks**, which are parts of the plant that can’t produce organic compounds themselves, such as the roots. The movement of sucrose in the phloem is **bidirectional**, meaning it can be transported upwards or downwards, depending on the location of the sink. This relates to **Choice A**.

**Choice B** refers to sugar being transported from sink to the source which is incorrect. **Choices C** and **D** refer to sugar transport being down only, which is incorrect.
