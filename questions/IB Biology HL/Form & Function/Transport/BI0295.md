# BI0295

Which of the following statement(s) is/are true?

-    I. $\hspace{1em}$ Cardiac muscle can contract on its own even if not stimulated by a nerve.

-    II. $\hspace{.7em}$ The left atrium of the heart has the thickest walls.
-    III. $\hspace{.4em}$ The valves in the heart prevent the backflow of blood and aid circulation.

- A. $\hspace{1em}$ I and II only

- B. $\hspace{1em}$ I and III only
- C. $\hspace{1em}$ I only
- D. $\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Specialised cells, in the sinoatrial node of the right atrium, can generate electrical impulses spontaneously, initiating the heart's rhythmic contractions without requiring external nerve stimulation, so **Statement I** is correct. \
The left ventricle has the thickest walls because it needs to produce more force so the blood can travel all over the body, **Statement II** is not correct. \
The valves function to prevent the backflow of blood, so **Statement III** is correct. \
Hence, **Choice B** is correct since **Statements I** and **III** are correct and not **Statement II**. Other choices (**Choices A**, and **C**) do not include all the correct statements. **Choice D** is incorrect because it includes **Statement II**.
