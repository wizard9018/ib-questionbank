# BI1205

Which description(s) is/are adaptations of the lymph ducts?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Valves to prevent backflow |
    | II. | Thin walls to allow for efficient diffusion |
    | III. | Many mitochondria to allow for strong muscle contractions |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct; lymph ducts contain valves to prevent backflow (**Statement I**) and have thin walls that allow for efficient transport of substances via diffusion (**Statement II**).  **Statement III** is incorrect, as lymph ducts do not need to contract strongly, so they do not contain many mitochondria. **Choices A, B** and **D**  are incorrect.
