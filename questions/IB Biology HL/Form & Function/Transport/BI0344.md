# BI0344

Which structures does sucrose pass through during phloem loading?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Plasmodesmata |
    | II. | Proton pumps |
    | III. | Co-transporter proteins |

- A.$\hspace{1em}$ III only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The active loading of phloem is brought about by **co-transport proteins**, which utilise the proton gradient created by the active transport of H:sup[+] ions out of companion cells. As companion cells pump protons out of the cell an electrochemical gradient is built up. The H:sup[+] ions therefore flow back into the cell, through **co-transporter proteins**, at the same time these proteins also carry sucrose molecules into the cell, against their concentration gradient. This builds up the concentration of sucrose in the companion cell, and the sucrose diffuses into the sieve tube elements through the **plasmodesmata**.

**Proton pumps** are used to create the proton gradient used by the co-transporter proteins but sucrose does not move through them.

**Choice A** is incorrect as it only refers to co-transporter proteins and not plasmodesmata. **Choices C** and **D** are incorrect as they both refer to proton pumps.
