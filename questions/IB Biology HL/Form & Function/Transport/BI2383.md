# BI2383

Which row of the table contains **three** correct statements about the circulatory systems of bony fish, amphibians and mammals?

| | Bony fish | Amphibians | Mammals |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | open circulation | oxygen absorbed via capillaries in the lungs and skin | oxygen absorbed via capillaries in the lungs and skin |
| B.$\hspace{1em}$ | double loop | double loop | four-chambered heart |
| C.$\hspace{1em}$ | single loop | three-chambered heart | pulmonary circulation |
| D.$\hspace{1em}$ | closed circulation | four-chambered heart | double loop |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because all three statements are correct.

**Choice A** is incorrect because all three types of organism have a closed circulation, where blood is kept separate from other body fluids. Also, mammals do not absorb oxygen through the skin (as amphibians do), just through the lungs. \
**Choice B** is incorrect because a bony fish’s circulation is a single circulation loop, not double. \
**Choice D** is incorrect because the hearts of amphibians are 3-chambered (2 atria and 1 ventricle), not 4-chambered. \
The correct statements are **highlighted** and the incorrect statements are ~struck out~ in the table below:

| | Bony fish | Amphibians | Mammals |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | ~open circulation~ | **oxygen absorbed via capillaries in the lungs and skin** | ~oxygen absorbed via capillaries in the lungs and skin~ |
| B.$\hspace{1em}$ | ~double loop~ | **double loop** | **four-chambered heart** |
| C.$\hspace{1em}$ | **single loop** | **three-chambered heart** | **pulmonary circulation** |
| D.$\hspace{1em}$ | **closed circulation** | ~four-chambered heart~ | **double loop** |
