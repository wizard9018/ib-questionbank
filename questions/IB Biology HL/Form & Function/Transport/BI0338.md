# BI0338

Which of the following is/are a feature of phloem?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Sieve plates |
    | II. | Plasmodesmata |
    | III. | High lignin content |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Sieve plates (**Statement I**) and plasmodesmata (**Statement II**) are features found in phloem. Sieve plates possess pores which allow continual flow of sap through the sieve tubes. Plasmodesmata are small channels which connect the sieve tube elements to the adjacent companion cells. A high lignin content (**Statement III**) is found in xylem vessels. It provides support to withstand hydrostatic pressure, and is also impermeable to water.
