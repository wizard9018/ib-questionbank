# BI1368

Which of the following processes is correctly described for prokaryotic and eukaryotic cells?

| | RNA splicing | Post-transcriptional modification | Translation |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | Prokaryotes only | Prokaryotes only | Both |
| B.$\hspace{1em}$ | Eukaryotes only | Eukaryotes only | Both |
| C.$\hspace{1em}$ | Eukaryotes only | Prokaryotes only | Eukaryotes only |
| D.$\hspace{1em}$ |Prokaryotes only | Eukaryotes only | Eukaryotes only |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
In eukaryotes, post-transcriptional modification is possible as transcription occurs in the nucleus. Immature mRNA is modified by removing introns in a process called RNA splicing. Then, the mature mRNA leaves the nucleus to undergo translation in the cytoplasm. In prokaryotes, transcription and translation occur simultaneously in the cytoplasm, but no post-transcriptional modification or RNA splicing can occur. **Choice B** is correct.

**Choices A, C**, and **D** are incorrect since prokaryotes do not perform post-transcriptional modification or RNA splicing, although they still carry out translation.
