# BI1267

Which of these is a correct description of free ribosomes and bound ribosomes?

| | Free ribosomes | Bound ribosomes |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Produce polypeptides to make proteins for use in the cell | Located on the smooth endoplasmic reticulum |
| B.$\hspace{1em}$ | Produce polypeptides to make proteins for release from the cell | Located on the rough endoplasmic reticulum |
| C.$\hspace{1em}$ | Produce polypeptides to make proteins for release from the cell | Located on the smooth endoplasmic reticulum |
| D.$\hspace{1em}$ | Produce polypeptides to make proteins for use in the cell | Located on the rough endoplasmic reticulum |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because free ribosomes produce polypeptides for proteins that are used in the cell, and bound ribosomes attach to the rough endoplasmic reticulum.

**Choice A** is incorrect because bound ribosomes are on the rough, not the smooth, endoplasmic reticulum.
 **Choice B** is incorrect because free ribosomes do not produce polypeptides for proteins that will be released from the cell. **Choice C** is incorrect because bound ribosomes are not bound to the smooth endoplasmic reticulum, they are bound to the rough endoplasmic reticulum.
