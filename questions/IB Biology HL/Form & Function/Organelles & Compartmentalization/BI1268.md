# BI1268

Identify the molecule that has a role in the formation of vesicles.

- A.$\hspace{1em}$ Clathrin

- B.$\hspace{1em}$ Surfactant

- C.$\hspace{1em}$ Cysteine

- D.$\hspace{1em}$ Collagen

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because clathrin is a cell membrane protein that has an important role in forming vesicles for endocytosis. **Choice B** is incorrect because type II pneumocytes produce surfactant. **Choice C** is incorrect because cysteine is an amino acid that forms disulfide bonds in the tertiary structure of proteins. **Choice D** is incorrect because collagen is a non-conjugated protein found in connective tissue.
