# BI0915

Which technique was first developed to separate cellular components and isolate organelles?

- A.$\hspace{1em}$ Separation based on adhesion, using chromatography

- B.$\hspace{1em}$ Separation based on charge, using gel electrophoresis

- C.$\hspace{1em}$ Separation based on density, using the ultracentrifuge

- D.$\hspace{1em}$ Separation based on size, using the Polymerase Chain Reaction (PCR)

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because cellular components are separated using cell fractionation, which requires the ultracentrifuge to separate the cellular components based on density.

**Choice A** is incorrect because chromatography separates mixtures of solutes, such as pigments, based on adhesion. **Choice B** is incorrect because gel electrophoresis separates molecules such as nucleic acids based on size, charge or both. **Choice D** is incorrect because PCR is used to amplify DNA fragments and is not a separation technique.
