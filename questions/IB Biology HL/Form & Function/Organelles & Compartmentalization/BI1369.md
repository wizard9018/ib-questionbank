# BI1369

The following diagram shows the results of an experiment to separate a cell fragment suspension using ultracentrifugation. Which of the following statements would not be true?

![BI1369](images/BI1369.png)

- A.$\hspace{1em}$ Thylakoid membranes are less dense than mitochondria.

- B.$\hspace{1em}$ There are more mitochondria than other organelles.

- C.$\hspace{1em}$ The cell fragment suspension must be from an organism capable of photosynthesis.

- D.$\hspace{1em}$ The cell fragment suspension must be from a eukaryotic organism.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Ultracentrifugation is a method used to separate cell components, such as organelles, based on their size and density. It does not, however, tell us much about the abundance of each organelle. **Choice B** is not true and so is the correct answer.

**Choice A** is a true statement and so an incorrect answer, since thylakoid membranes do appear higher in the column and must, therefore, be less dense than mitochondria. **Choice C** is a true statement and so an incorrect answer, since the presence of thylakoids indicates that this sample must have contained chloroplasts and was thus obtained from an organism capable of photosynthesis. **Choice D** is a true statement and therefore an incorrect answer, since mitochondria are only found in eukaryotic organisms.
