# BI0326

The image shows many ribosomes on a mRNA molecule.  How many unique polypeptide chains are being translated?

![BI0326i_7.3](images/BI0326i_7.3.png)

[Adapted from Miller, C. L. (2020, December 30). *ribosome mrna translation pt.svg*. Wikimedia Commons. Retrieved June 1, 2022, from https ://commons.wikimedia.org/wiki/File: Multiple_Ribosomes_Translation_Protein_Synthesis.png. Copyright free]

- A. $\hspace{1em}$ 1

- B. $\hspace{1em}$ 6

- C. $\hspace{1em}$ 12

- D. $\hspace{1em}$ 2

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

The image shows 6 ribosomes on a single mRNA molecule, all translating polypeptide chains, it means that each ribosome is reading the same mRNA sequence and therefore synthesising the same polypeptide chain. The number of unique polypeptide chains being translated in this scenario would be 1, because all the ribosomes are translating the same mRNA into the same polypeptide sequence. **Choice A** is correct.
