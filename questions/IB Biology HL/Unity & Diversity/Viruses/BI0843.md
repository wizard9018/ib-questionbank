# BI0843

Which feature is present in coronaviruses but absent from T4 bacteriophages?

- A.$\hspace{1em}$ Genetic information

- B.$\hspace{1em}$ A protein capsid

- C.$\hspace{1em}$ A phospholipid envelope

- D.$\hspace{1em}$ Structures for attachment to a host cell

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because coronaviruses have a phospholipid envelope derived from host-cell membranes, whereas T4 bacteriophages do not have an envelope.

**Choice A** is incorrect because both contain genetic material. T4 bacteriophages contain DNA, whereas coronaviruses contain RNA.

**Choice B** is incorrect because both have protein components that package their genetic material. In T4 bacteriophages, DNA is enclosed within the protein capsid of the head. In coronaviruses, RNA is associated with nucleocapsid proteins.

**Choice D** is incorrect because both have structures for attachment to host cells. T4 bacteriophages use tail fibres, whereas coronaviruses use spike proteins.
