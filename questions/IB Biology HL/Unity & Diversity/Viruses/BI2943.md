# BI2943

The image shows the lysogenic life cycle of a bacteriophage.

![BI2943](images/BI2943.png)

What process is occurring in Step 4?

- A.$\hspace{1em}$ The host cell divides, and the viral DNA is copied into the daughter cells.

- B.$\hspace{1em}$ Bacteriophage DNA is removed from the host cell DNA, and the cell is destroyed.

- C.$\hspace{1em}$ The host cell transfers the viral DNA into another cell using horizontal gene transfer.

- D.$\hspace{1em}$ Bacteriophage DNA is removed from the host cell DNA, ready to enter the lytic cycle.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
In the lysogenic cycle, the viral DNA is integrated into the host chromosome as a prophage. Step 4 represents induction of the lysogenic cycle. This is when the prophage (viral DNA integrated in the host genome) is excised (removed) from the host DNA, and the phage is ready to switch into the lytic cycle (viral genes become active, leading to replication and assembly). **Choice D** is, therefore, correct.

**Choice A** is incorrect because host cell division with the prophage being copied into daughter cells happens during binary fission (vertical transmission) and is represented by the dividing cell stage (Step 3), not Step 4.

**Choice B** is incorrect because, although prophage DNA can be removed during induction, the host cell is not destroyed immediately at this point. Cell destruction occurs later in the lytic cycle during lysis, after viral DNA replication and phage assembly.

**Choice C** is incorrect because this diagram shows the prophage being inherited through vertical transmission (cell division), not the host transferring viral DNA to another cell via horizontal gene transfer. Horizontal gene transfer would involve the movement of DNA between different cells (e.g., transduction), which is not what Step 4 depicts.
