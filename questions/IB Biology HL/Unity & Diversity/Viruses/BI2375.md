# BI2375

Which statement correctly describes the genetic material changes (using reverse transcriptase)  that occur in a retrovirus inside a host cell?

- A.$\hspace{1em}$ Viral DNA is used to produce viral RNA

- B.$\hspace{1em}$ Viral RNA is used to produce viral DNA

- C.$\hspace{1em}$ Viral RNA is converted directly into host cell RNA

- D.$\hspace{1em}$ Viral RNA replaces host cell DNA

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because retroviruses use reverse transcriptase to produce a DNA copy from their RNA genome. The viral RNA therefore acts as a template for the production of viral DNA inside the host cell.

**Choice A** is incorrect because this describes the production of RNA from DNA, which is transcription, not reverse transcription.

**Choice C** is incorrect because reverse transcriptase produces DNA from RNA rather than converting viral RNA directly into host cell RNA.

**Choice D** is incorrect because the viral RNA does not replace the host cell DNA. Instead, a DNA copy of the viral genome is produced and may become integrated into the host cell’s DNA.
