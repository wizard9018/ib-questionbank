# BI0229

Which of the following best describes an analogous structure?

- A. $\hspace{1em}$ A structure in two different species that serves a similar function and was inherited from a common ancestor.

- B. $\hspace{1em}$    A structure in two different species that serves a similar function but evolved independently, without a common ancestor.

- C. $\hspace{1em}$    A structure found in all members of a species that performs the same function.

- D. $\hspace{1em}$    A structure found in all members of a species but serves different functions.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Analogous structures are traits found in different species that perform similar functions but do not originate from a common ancestor. Instead, they arise through convergent evolution, where species adapt to similar environments or ecological roles independently. **Choice B** is correct as it describes analogous structures, which evolve due to similar selective pressures rather than shared ancestry.

**Choice A** is incorrect because it describes homologous structures, which share a common evolutionary origin but may have different functions (e.g., a whale's flipper and a human's arm).

**Choice C** is incorrect because this refers to universal structures within a species, which is unrelated to analogous structures.

**Choice D** is incorrect because this describes structural variation within a species, not similarities between different species.
