# BI0235

How does gradual divergence provide evidence for evolution?

- A. $\hspace{1em}$ There is variation between different species across geographical areas.

- B. $\hspace{1em}$    There is no variation between different species across geographical areas.
- C. $\hspace{1em}$    There is variation between populations of the same species across geographical areas.
- D. $\hspace{1em}$    There is no variation between populations of the same species across geographical areas.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Gradual divergence describes gradual changes in allele frequencies and phenotypes across a species' geographical range, so neighbouring populations are similar but become increasingly different with distance while still belonging to the same species. Therefore,  **Choice C** is correct: there is variation within a species across geographical areas.

**Choices B** and **D** are incorrect because “no variation” does not support gradual divergence.

**Choice A** is incorrect because gradual divergence refers to differences within a species, not variation between different species.
