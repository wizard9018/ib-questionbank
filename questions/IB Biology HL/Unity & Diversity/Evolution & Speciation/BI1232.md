# BI1232

Which of the following statement concerning analogous structures is/are correct?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | They are formed through convergent evolution |
    | II. | They perform the same or similar functions in different organisms |
    | III. | They evolve from a common ancestor |

- A.$\hspace{1em}$ II only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Analogous structures refer to structures found in different species which serve a similar function (**Statement II**) but are not the result of common ancestry, they are formed through convergent evolution (**Statement I**), which is when different organisms evolve similar structures but have not arisen from a common ancestor. **Choice B**  is correct.

Analogous structures do not evolve from a common ancestor (**Statement III**); **Choices C** and **D**  are incorrect. **Choice A**  is incorrect because it only involves **statement II**.
