# BI0863

When a horse, which has 64 chromosomes, and a donkey, which has 62 chromosomes reproduce, a mule offspring is produced.  Which are correct descriptions of mules?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Mules frequently produce offspring with other mules. |
    | II. | Cells in mules cannot undergo meiosis but can undergo mitosis. |
    | III. | Mule gametes have 63 chromosomes. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ II only

- D.$\hspace{1em}$ I and II only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement II** is correct because mules possess an odd number of chromosomes (63), which means they cannot form the homologous pairs necessary for successful meiosis. This prevents the production of viable gametes. However, mitosis can still occur because it involves the replication and separation of individual sister chromatids, which does not require the pairing of homologous chromosomes.

**Statement I** is incorrect because mules are infertile hybrids. Since they cannot produce functional gametes, they cannot reproduce with other mules.

**Statement III** is incorrect because 63 is the diploid (2n) number of chromosomes found in the mule's somatic (body) cells. If a mule were able to produce gametes, the chromosome number would be approximately half that (approx 31.5), which is impossible as chromosomes must exist as whole units.

**Choice C** is correct as it only includes the one true Statement II.

**Choices A, B** and **D** are incorrect as they include one or more of the incorrect Statements I and III.
