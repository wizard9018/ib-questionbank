# BI3207

Which of the following are differences between DNA and RNA?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | DNA contains uracil, whereas RNA contains thymine. |
    | II. | DNA contains deoxyribose, whereas RNA contains ribose.  |
    | III. | DNA is usually double-stranded, whereas RNA is usually single-stranded.  |

- A.$\hspace{1em}$ II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

**Statement I** is false because the bases have been reversed: DNA contains thymine, whereas RNA contains uracil.

**Statement II** is true because DNA nucleotides contain deoxyribose, whereas RNA nucleotides contain ribose.

**Statement III** is true because DNA is usually double-stranded, whereas RNA is usually single-stranded.

Therefore, **Choice C** is correct because it includes both true **Statements II** and **III**.

**Choice A** is incorrect because it omits the true **Statement III**.

**Choices B** and **D** are incorrect because they include the false **Statement I**.
