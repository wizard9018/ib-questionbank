# BI1171

The diagram shows loose chromatin, also termed euchromatin. Which letter represents a histone protein?

![BI1171ii](images/BI1171ii.png)

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
A histone is one of 8 proteins that DNA winds around so that it can be packaged efficiently into a cell’s nucleus. **Choice A** is correct.

Line B is pointing to the DNA wrapped around 8 histones; **Choice B** is incorrect. Line C is pointing to a short section of DNA (linker DNA) that connects one nucleosome to the next; **Choice C** is incorrect. Line D is pointing to a nucleosome, which is DNA wrapped around 8 histone proteins; **Choice D** is incorrect.
