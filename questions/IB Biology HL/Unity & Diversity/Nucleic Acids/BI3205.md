# BI3205

DNA stores genetic information using a 4-symbol system, because each position in the sequence can contain one of four bases: A, T, C, or G.

The graph compares the number of possible sequences in a 2-symbol system and a 4-symbol system at sequence lengths of 2, 5 and 10 symbols. The graph uses a logarithmic scale on the y-axis.

![BI3205](images/BI3205.png)

What does the graph suggest about the capacity of DNA for storing information?

A. $\hspace{1em}$ A two-symbol system stores more information because fewer symbols are used.

B. $\hspace{1em}$ The two systems have the same information capacity because both use a finite number of symbols.

C. $\hspace{1em}$ Using four symbols rather than two symbols produces more possible sequences of the same length, giving DNA a greater capacity for storing information.

D. $\hspace{1em}$ Using four symbols produces only four times as many possible sequences as using two symbols, regardless of sequence length.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

For a sequence of length *n*, a 2-symbol system can produce $2^n$ possible sequences, whereas a 4-symbol system can produce $4^n$. At a sequence length of 10, these systems produce 1,024 and 1,048,576 possible sequences, respectively. Therefore, the 4-symbol DNA system produces 1,024 times as many sequences of this length, demonstrating how four bases arranged in sequences give DNA an enormous capacity for storing information. **Choice C** is correct.

**Choice A** is incorrect because using fewer possible symbols at each position produces fewer, not more, possible sequences.

**Choice B** is incorrect because the number of symbols available at each position affects the number of possible sequences.

**Choice D** is incorrect because the difference increases with sequence length; the 4-symbol system produces 1,024 times as many possible sequences at a length of 10, not four times as many.
