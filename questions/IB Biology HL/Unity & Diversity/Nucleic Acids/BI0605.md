# BI0605

Which of the following is a similarity between transcription and translation?

-    A. $\hspace{1em}$ Both use DNA as a template

-    B. $\hspace{1em}$  Both occur in the 5\' to 3\' direction
-    C. $\hspace{1em}$ Both involve binding to a ribosome
-    D. $\hspace{1em}$ Both involve mRNA splicing

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Both transcription and translation synthesize strands from 5\' to 3\'. \
Only transcription uses DNA as a template, whereas translation uses mRNA as a template (**Choice A**).\
Binding to ribosomes takes place only in translation but not in transcription (**Choice C**).\
mRNA splicing takes place only during post-transcriptional modifications and not in post-translational modifications (**Choice D**).
