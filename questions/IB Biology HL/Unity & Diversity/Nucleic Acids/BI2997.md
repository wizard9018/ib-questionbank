# BI2997

Which statement correctly describes the significance of the 5' $\rarr$ 3' directionality in biological processes?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | DNA replication can only synthesise new strands in the 5' $\rarr$ 3' direction. |
    | II. | RNA polymerase moves along the template strand in the 3' $\rarr$ 5' direction during transcription. |
    | III. | Ribosomes translate mRNA by reading codons sequentially from the 5' end to the 3' end. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
DNA polymerase can only add nucleotides to the 3' hydroxyl end, meaning all new DNA strands are synthesised in the 5' $\rarr$ 3' direction. This is why the leading strand is continuous and the lagging strand forms Okazaki fragments. **Statement I** is true.

During transcription, RNA polymerase moves along the DNA template strand in the 3' $\rarr$ 5' direction, so that it can synthesise RNA in the 5' $\rarr$ 3' direction, matching the required biochemical polarity of nucleotide addition. **Statement II** is true.

Ribosomes translate an mRNA molecule by reading codons from the 5' end toward the 3' end, beginning at the start codon (AUG). This directionality ensures correct polypeptide elongation and alignment with the template. **Statement III** is true.

Since all three statements are true, **Choice D** is the correct answer.
