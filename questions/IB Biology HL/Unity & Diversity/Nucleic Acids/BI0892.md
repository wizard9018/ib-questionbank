# BI0892

What would make one DNA molecule more stable than another DNA molecule?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | More G-C base pairs than A-T base pairs |
    | II. | More hydrogen bonds between base pairs |
    | III. | Greater distance between A-T base pairs than G-C base pairs |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ III only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because the stability of the DNA helix molecule is affected by the nucleotide composition. There are 3 hydrogen bonds between the G-C base pairs, and only 2 between the A-T base pairs, therefore, more G-C pairs (**Statement I**)  means a greater number of hydrogen bonds (**Statement II**).

**Choice A** is incorrect as it does not include both correct statements.

The distance between the A-T base pairs and the G-C base pairs is equal, and even if the distance between A-T were greater, it would not add to stability (**Statement III**).  **Choices B** and **D** are therefore incorrect as they include **Statement III**.
