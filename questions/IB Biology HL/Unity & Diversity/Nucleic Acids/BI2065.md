# BI2065

How many hydrogen bonds are there between the bases in a section of a strand of DNA with the base sequence GGC TAC CAC TCT and the bases on its complementary strand?

- A.$\hspace{1em}$ 24

- B.$\hspace{1em}$ 31

- C.$\hspace{1em}$ 30

- D.$\hspace{1em}$ 36

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because a G-C base pairing uses 3 hydrogen bonds, whereas an A-T base pairing uses only 2. In GGCTACCACTCT there are $7 \times 3 = 21$ bonds between C and G, plus $5 \times 2 = 10$ bonds between A and T. 21 + 10 = 31.

**Choice A** is incorrect because it shows seven fewer than the correct number of hydrogen bonds.

**Choice C** is incorrect because it shows one fewer than the correct number of hydrogen bonds.

**Choice D** is incorrect because it shows five more than the correct number of hydrogen bonds.
