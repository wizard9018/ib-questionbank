# BI3208

One strand of a DNA molecule has the following base composition:

A = 22%, T = 36%, G = 15%, C = 27%

Which principle can be used to determine the percentage of guanine in **the other strand** of the DNA molecule, and what is this percentage?

A. $\hspace{1em}$ Antiparallel orientation; 27%

B. $\hspace{1em}$ Complementary base pairing; 27%

C. $\hspace{1em}$ Complementary base pairing; 15%

D. $\hspace{1em}$ Antiparallel orientation; 15%

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

During complementary base pairing, guanine pairs with cytosine. Because cytosine makes up 27% of the original strand, guanine must make up 27% of the other strand. Therefore, **Choice B** is correct.

**Choice A** is incorrect because it gives the correct percentage but identifies the wrong principle. Antiparallel orientation means that the two DNA strands run in opposite directions: one runs from 5′ to 3′, while the other runs from 3′ to 5′ alongside it. This describes the orientation of the sugar–phosphate backbones, not which bases pair together. Therefore, antiparallel orientation alone cannot be used to determine the percentage of guanine.

**Choice C** is incorrect because it identifies the correct principle but gives the wrong percentage. The 15% guanine in the original strand pairs with cytosine, so it determines the percentage of cytosine, not guanine, in the other strand. To determine the guanine percentage, we must use the original strand's 27% cytosine.

**Choice D** is incorrect because both the principle and the percentage are wrong. Antiparallel orientation describes strand direction rather than the relationship between base percentages. Complementary base pairing determines that guanine makes up 27% of the other strand, not 15%.
