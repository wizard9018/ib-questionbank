# BI1717

Several models of DNA were proposed before the current model was accepted in the 1950s. What was one limitation of the earlier DNA models?

- A.$\hspace{1em}$ It was composed of repeating units of four nucleotides.

- B.$\hspace{1em}$ The amount of adenine was the same as the amount of thymine.

- C.$\hspace{1em}$ The sugar-phosphate backbone was oriented outwards.

- D.$\hspace{1em}$ Early models showed the bases oriented inwards.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

**Choice A** refers to the tetranucleotide hypothesis, which proposed that DNA was made up of repeating units of four nucleotides in a fixed sequence. This model failed to explain the diversity and complexity of genetic information since it suggested a monotonous, non-variable structure for DNA.

Chargaff’s findings that the amount of adenine is equal to thymine and the amount of cytosine is equal to guanine were not a limitation.  It is a correct statement about the current model of DNA structure **(Choice B)**. 

The sugar-phosphate backbone is oriented outwards, so this is not a limitation, but rather a true statement about the structure of DNA **(Choice C)**.

The bases are oriented inwards, so this too is a true statement about the current model of DNA structure **(Choice D)**
