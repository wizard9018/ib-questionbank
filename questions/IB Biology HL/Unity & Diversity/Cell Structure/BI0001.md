# BI0001

Which of the following statements about cells are true?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | All living cells contain cytoplasm enclosed by the plasma membrane. |
  | II. | Microscopes have helped scientists understand cell structure. |
  | III. | Prokaryotes do not have genetic material. |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because living cells have a plasma membrane that encloses the cytoplasm and separates the cell's internal contents from its surroundings.

**Statement II** is true because microscopes allow scientists to observe cells and cellular structures that are too small to distinguish with the naked eye, helping them understand cell structure.

**Statement III** is false because prokaryotic cells contain DNA as their genetic material. Their chromosomal DNA is located in the nucleoid region of the cytoplasm rather than enclosed within a nucleus. Prokaryotes lack a nucleus, not genetic material.

**Choice A** is therefore correct, as it includes only the true **Statements I** and **II**.

**Choices B, C** and **D** are incorrect because they include one or more incorrect statements.
