# BI0947

Which of the following statements support the hypothesis that RNA was the first genetic material?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | RNA nucleotides can polymerise under certain prebiotic conditions. |
    | II. | RNA is chemically more stable than DNA.|
    | III. | Some RNA molecules can catalyse chemical reactions. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and III

- C.$\hspace{1em}$ II and III

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is correct because RNA nucleotides can polymerise to form RNA under certain prebiotic conditions.

**Statement II** is incorrect because RNA is generally less chemically stable than DNA. The hydroxyl group attached to the 2′ carbon of ribose makes RNA more susceptible to hydrolysis. Greater stability, therefore, helps explain why DNA subsequently became the principal long-term store of genetic information; it does not support the claim that RNA is chemically more stable.

**Statement III** is correct because some RNA molecules, called ribozymes, can catalyse chemical reactions. RNA could therefore potentially both store genetic information and catalyse reactions before DNA and protein enzymes evolved.

**Choice B** is correct because it only includes the true **Statement I** and **III**.

**Choice A** is incorrect because only one of the true statements, **Statement I** is included.
**Choices C** and **D** are incorrect because they both include the false **Statement II**.
