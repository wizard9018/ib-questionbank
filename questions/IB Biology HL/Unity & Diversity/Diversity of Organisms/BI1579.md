# BI1579

The diagram shows an unidentified species of crab.

![BI1579](images/BI1579.png)

Use the dichotomous key provided to identify this species.

| | | |
| --- | :-- | :-- |
| 1.$\hspace{1em}$ | Smooth shell … . | Go to 2. |
| | Bumps or spikes on shell … . | Go to 3. |
| 2.$\hspace{1em}$ | Eyestalks … . | Go to 4. |
| | No eyestalks … . | *Menippe mercenaria.* |
| 3.$\hspace{1em}$ | Pear-shaped shell … . | Go to 5. |
| | Non-pear-shaped shell … . | Go to 6. |
| 4.$\hspace{1em}$ | Antennae visible … . | *Birgus latro.* |
| | No antennae visible … . | *Ocypode quadrata.* |
| 5.$\hspace{1em}$ | Six walking legs … . | *Paralithodes camtschaticus.* |
| | Eight walking legs … . | *Macrocheira kaempferi.* |
| 6.$\hspace{1em}$ | Tail present … . | *Limulus polyphemus.* |
| | Tail absent … . | *Callinectes sapidus.* |

- A.$\hspace{1em}$ *Menippe mercenaria*

- B.$\hspace{1em}$ *Ocypode quadrata*

- C.$\hspace{1em}$ *Paralithodes camtschaticus*

- D.$\hspace{1em}$ *Callinectes sapidus*

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because this species has a rough, non-pear-shaped shell and no tail, making it a blue crab (*Callinectes sapidus*).

**Choices A** is incorrect because the species in the diagram has eyestalks and a rough shell. **Choice B** is incorrect because the species in the diagram has a rough shell. **Choice C** is incorrect because the species in the diagram has a non-pear-shaped shell.
