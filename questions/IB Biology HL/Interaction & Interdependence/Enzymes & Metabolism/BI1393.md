# BI1393

The following diagram shows an enzyme-catalysed reaction. Which model best describes the interaction between the enzyme and its substrate?

![BI1393](images/BI1393.png)
[Source: Adapted from TimVickers, (2006, October 11). *File: Induced fit diagram.svg - Wikimedia Commons*. Wikimedia commons. Retrieved January 2, 2024, from https://commons.wikimedia.org/wiki/File: Induced_fit_diagram.svg Copyright under public domai]

- A.$\hspace{1em}$ Lock and key model

- B.$\hspace{1em}$ End-product inhibition model

- C.$\hspace{1em}$ Davson-Danielli model

- D.$\hspace{1em}$ Induced fit model

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because he induced fit model, introduced by Daniel Koshland in 1958, proposes that an enzyme’s active site is not rigid but flexible, adjusting its shape to closely match the substrate when binding occurs. Unlike the fixed lock-and-key model, this process is dynamic, with both the enzyme and substrate undergoing slight conformational changes that facilitate catalysis

**Choice A** is incorrect because the lock and key model suggests that enzymes fit specific substrates without the need to modify their shape. **Choice B** is incorrect because end-product inhibition involves the last product in a metabolic pathway becoming an inhibitor of one of the enzymes earlier on in the sequence, which is not shown in the diagram. **Choice C** is incorrect since the Davson-Danielli model refers to a proposed model of the cell membrane and is unrelated to enzyme function.
