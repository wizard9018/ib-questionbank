# BI2702

Which row contains suitable conditions for summation?

| | Excitatory vs. inhibitory neurotransmitters | Threshold reached | Depolarisation |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | Unequal | Yes | Yes |
| B.$\hspace{1em}$ | Unequal | No | Yes |
| C.$\hspace{1em}$ | Equal | Yes | No |
| D.$\hspace{1em}$ | Equal | Yes | Yes

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because summation depends on the net effect of excitatory and inhibitory neurotransmitters. If there are more excitatory inputs than inhibitory ones, and this net excitation is strong enough to reach threshold, it will trigger depolarisation of the postsynaptic neuron.

**Choice B** is incorrect because although inputs are unequal, the threshold is not reached, so depolarisation cannot occur.

**Choices C** and **D** are incorrect because if the concentrations of excitatory and inhibitory neurotransmitters are equal, the threshold potential will not be reached.
