# BI2695

Which labelled structure facilitates saltatory conduction?

![BI2695](images/BI2695.png)

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because the nodes of Ranvier are unmyelinated sections between myelinated sheaths, where action potentials can occur. These structures facilitate saltatory conduction because the nerve impulse moves from one node to the next.

**Choice A** is incorrect because it is the axon, the structure that the nerve impulse travels along. **Choice B** is incorrect because it is the cell body that contains the nucleus which controls the activities of the neuron. **Choice D** is incorrect because this is an axon terminal that releases neurotransmitters to transfer nerve impulses from one neuron to the next.
