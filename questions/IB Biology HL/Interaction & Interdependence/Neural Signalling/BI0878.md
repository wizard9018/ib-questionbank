# BI0878

Which of the following statements correctly describe(s) the factors affecting the speed of nerve impulse conduction?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | As the diameter of axons increases, the speed at which impulses are conducted increases. |
    | II. | There is a negative correlation between animal size and the speed at which impulses are conducted. |
    | III. | Impulse conduction in myelinated neurons is slower than that in non-myelinated neurons.|

- A.$\hspace{1em}$ II and III

- B.$\hspace{1em}$ I, II and III

- C.$\hspace{1em}$ I and II

- D.$\hspace{1em}$ I only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because larger-diameter axons offer less resistance to ion flow, allowing impulses to travel faster.

**Statement II** is false because impulse speed is more influenced by axon diameter and myelination than by body size. In fact, large animals often have adaptations like highly myelinated neurons to ensure efficient conduction over longer distances.

**Statement III** is false because myelination greatly increases conduction speed via saltatory conduction, where impulses "jump" between nodes of Ranvier. This is significantly faster than continuous conduction in non-myelinated neurons.
**Choice D** is correct because only **Statement I** is correct.

**Choices A, B** and **C** are all incorrect because they include one or more false statements.
