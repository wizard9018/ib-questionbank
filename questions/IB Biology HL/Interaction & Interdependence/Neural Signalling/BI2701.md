# BI2701

Which statements correctly describe summation in synaptic transmission?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Summation results from the combined effects of excitatory and inhibitory neurotransmitters on a postsynaptic neuron. |
    | II. | Summation requires the involvement of multiple postsynaptic neurons.|
    | III. | Spatial summation involves multiple presynaptic neurons releasing neurotransmitters onto a single postsynaptic neuron. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because summation occurs when multiple excitatory (EPSPs) and inhibitory (IPSPs) neurotransmitters interact at a single postsynaptic neuron. If excitatory inputs outweigh inhibitory inputs, the neuron reaches the threshold and fires an action potential. If inhibitory inputs dominate, the neuron is less likely to fire.

**Statement II** is false because summation occurs within a single postsynaptic neuron, integrating signals from multiple presynaptic neurons or repeated signals from one. It does not involve multiple postsynaptic neurons interacting with each other.

**Statement III** is true because spatial summation occurs when multiple presynaptic neurons release neurotransmitters onto a single postsynaptic neuron, collectively bringing it to the threshold.

**Choice C** is correct because it contains both true statements.

**Choices A, B** and **D** are incorrect as they do not contain the correct combination of true statements.
