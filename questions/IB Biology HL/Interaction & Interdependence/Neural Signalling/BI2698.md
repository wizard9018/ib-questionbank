# BI2698

Which statements are true for the effect of cocaine on synapses?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Cocaine enhances synaptic activity by blocking dopamine reuptake transporters. |
    | II. | Cocaine leads to prolonged activation of postsynaptic dopamine receptors. |
    | III. | Cocaine increases dopamine production in presynaptic neurons. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because cocaine blocks dopamine reuptake transporters (DAT) on the presynaptic neuron, preventing reabsorption of dopamine. This increases dopamine levels in the synaptic cleft, enhancing synaptic transmission.

**Statement II** is true because the excess dopamine in the synaptic cleft leads to prolonged activation of postsynaptic dopamine receptors, resulting in heightened stimulation associated with euphoria and reward.

**Statement III** is false because cocaine does not increase dopamine production; it prevents dopamine from being reabsorbed into the presynaptic neuron. Over time, due to dopamine buildup in the synapse, the presynaptic neuron actually reduces dopamine synthesis to compensate, leading to withdrawal symptoms when cocaine use stops.

**Choice B** is correct because it contains both true statements.

**Choices A, C** and **D** are incorrect because they do not contain the correct combination of true statements (s).
