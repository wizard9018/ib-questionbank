# BI0629

Which is the correct definition of saltatory conduction?

-    A. $\hspace{1em}$ Electrical impulses jumping between nodes of Ranvier

-    B. $\hspace{1em}$ Neurotransmitters diffusing across the synaptic cleft
-    C. $\hspace{1em}$ Sodium and potassium ions being pumped across membranes
-    D. $\hspace{1em}$ Electrical impulses moving down an unmyelinated axon

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Saltatory conduction is when electrical impulses jump between nodes of Ranvier (the gaps between sections of the myelin sheath that surrounds axons). \
**Choice B** is incorrect because it is a description of synaptic transmission.\
**Choice C** is incorrect because it is a description of how the resting potential is maintained.\
**Choice D** is incorrect as it describes how an action potential travels down an unmyelinated neuron.
