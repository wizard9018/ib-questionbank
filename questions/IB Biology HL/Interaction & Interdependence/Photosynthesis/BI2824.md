# BI2824

Which of the following statement(s) correctly describe(s) the absorption of light by photosynthetic pigments?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Light absorption causes electrons to become excited. |
    | II. | Absorption is highest at wavelengths 550 nm to 600 nm. |
    | III. | Light energy absorbed is transformed into chemical energy. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because electrons within a pigment molecule are excited by light energy.

**Statement II** is false because absorption is lowest between 550 nm and 600 nm. It is highest between 400 nm and 500 nm and between 650 nm and 700 nm.

**Statement III** is true because the light energy, which is absorbed by photosynthetic pigments is converted to chemical energy.

**Choice C** is correct because it only includes the true **Statements I** and **III**.

**Choice A** is incorrect because is it missing the true **Statement III**. **Choices B** and **D** are incorrect because **Statement II** is false.
