# BI2822

Which row correctly describes the source and role of oxygen in photosynthesis?

| | Source | Description |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Reduction of water | By-product |
| B.$\hspace{1em}$ | Chemiosmosis | Reactant |
| C.$\hspace{1em}$ | Photolysis | By-product |
| D.$\hspace{1em}$ | Photolysis | Reactant |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because photolysis is the splitting of water using light energy. This process releases oxygen gas ($\ce{O_2}$), protons ($\ce{H^+}$), and electrons.  The oxygen originates from water and is released into the atmosphere, playing no further role in the photosynthesis process, which makes it a by-product.\
**Choice A** is incorrect because although oxygen is a by-product of photosynthesis, it is not produced by the reduction of water; it is produced by photolysis (splitting of water).\
**Choice B** is incorrect because chemiosmosis involves the synthesis of ATP driven by a proton gradient across the thylakoid membrane, and oxygen is not a reactant of photosynthesis; it is a by-product.\
**Choice D** is incorrect because although oxygen is produced by photolysis, it is a by-product, not a reactant.
