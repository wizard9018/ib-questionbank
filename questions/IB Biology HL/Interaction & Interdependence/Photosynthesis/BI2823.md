# BI2823

Table 1 shows data collected using thin-layer chromatography to separate photosynthetic pigments. Table 2 shows the retention factors for four photosynthetic pigments using the same solvent.

Use the information to identify pigment II.

| Distance travelled | mm |
| :-: | :-: |
| Solvent | 178 |
| Pigment I | 98 |
| Pigment II | 91 |
| Pigment III | 121 |

| Pigment | Retention factor ( R$\mathbf{_f}$ ) |
| :-: | :-: |
| Chlorophyll a | 0.68 |
| Chlorophyll b | 0.55 |
| Fucoxanthin | 0.51 |
| $\beta$-carotene | 0.98

- A.$\hspace{1em}$ Chlorophyll a

- B.$\hspace{1em}$ Chlorophyll b

- C.$\hspace{1em}$ Fucoxanthin

- D.$\hspace{1em}$ $\beta$-carotene

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because the retention factor ($\ce{R_f}$) for fucoxanthin is 0.51, which matches the calculated $\ce{R_f}$ value for Pigment II.

Retention factor ($\ce{R_f}$) =  $\dfrac{\ce{Distance travelled by pigment}}{\ce{Distance travelled by solvent}}$

$\ce{R_f}$ of pigment II = $\dfrac{91}{178}$  = 0.51

$\ce{R_f}$ of pigment I = $\dfrac{98}{178}$  = 0.55

$\ce{R_f}$ of pigment III = $\dfrac{121}{178}$  = 0.68

**Choices A, B** and **D** are incorrect because their $\ce{R_f}$ values do not match the calculated $\ce{R_f}$ for Pigment II.
