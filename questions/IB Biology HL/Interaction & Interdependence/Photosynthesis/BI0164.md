Which of the following structures are found in the part of a chloroplast labelled X?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. |  Photosystem I  |
  | II. | ATP Synthase |
  | III. | Ribosomes |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The part of the chloroplast labelled X is the thylakoid membrane. The membrane contains photosystem I (**Statement I**), photosystem II, ATP synthase (**Statement II**) and electron carriers which are important structures in the light-dependent reactions.

Ribosomes (**Statement III**) are found in the stroma of chloroplasts.
