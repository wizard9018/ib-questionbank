# BI0169

The following processes occur in the Calvin cycle.

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. |  Ribulose bisphosphate regeneration  |
  | II. | Carbon dioxide fixation |
  | III. | Glycerate-3-phosphate is reduced to triose phosphate |

Which is the **incorrect** sequence for these processes?

- A.$\hspace{1em}$ I. → II. → III.

- B.$\hspace{1em}$ I. → III. → II.

- C.$\hspace{1em}$ II. → III. → I.

- D.$\hspace{1em}$ III. → I. → II.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
In the Calvin cycle, there are three important stages. Firstly, the fixation of carbon dioxide (**Statement II**) where ribulose bisphosphate is carboxylated by a Rubisco enzyme.

Carbon fixation is followed by the production of triose phosphate through the reduction of glycerate-3-phosphate  (**Statement III**) using reduced NADP and ATP.

Finally, the regeneration of the acceptor compound, ribulose bisphosphate (**Statement I**) which uses triose phosphate and ATP.  The starting point in the Calvin cycle is arbitrary because it is a cyclic process. Thus all answer choices except **Choice B** show the correct order of events in the Calvin cycle.
