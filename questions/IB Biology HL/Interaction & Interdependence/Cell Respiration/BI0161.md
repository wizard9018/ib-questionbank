# BI0161

How many times are six-carbon carbohydrate intermediates phosphorylated during one complete glycolysis pathway?

- A.$\hspace{1em}$ Once

- B.$\hspace{1em}$ Twice

- C.$\hspace{1em}$ Four times

- D.$\hspace{1em}$ None

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
In glycolysis, ATP is first used to phosphorylate glucose, producing glucose-6-phosphate. This molecule is then isomerised to fructose-6-phosphate. A second ATP is then used to add another phosphate group, forming fructose-1,6-bisphosphate, a sugar molecule with two phosphate groups attached. Although ADP undergoes substrate level phosphorylation in the second part of glycolysis, ADP is not a carbohydrate so does not count towards the total. **Choice B** is correct.

**Choices A, C** and **D** are incorrect because they state the wrong number of times.
