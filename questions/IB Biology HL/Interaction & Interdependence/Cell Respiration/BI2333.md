# BI2333

The table shows data that was collected for respiring yeast. Which value is correct for the rate of cellular respiration between 30 and 60 seconds?

| Time / s | Volume of carbon dioxide / ppm |
| :-: | :-: |
| 0 | 650 |
| 30 | 910 |
| 60 | 1390 |
| 90 | 1670 |

- A.$\hspace{1em}$ 16 ppm $\ce{s^{-1}}$ .

- B.$\hspace{1em}$ 32 ppm $\ce{s^{-1}}$.

- C.$\hspace{1em}$ 480 ppm $\ce{s^{-1}}$ .

- D.$\hspace{1em}$ 16 ppm $\ce{min^{-1}}$ .

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because rate equals volume change divided by the time taken for change, \
Rate of carbon dioxide production = $\dfrac{\ce{Volume change (ppm)}}{\ce{Time for change (s)}} = \dfrac{\ce{1390-910ppm}}{\ce{30s}} = \dfrac{\ce{480 ppm}}{\ce{30 s}}= 16$ ppm $\ce{s^{-1}}$.

**Choices B, C** and **D** are incorrect because the volume change is 480, and when this is divided by 30, it does not give one of these answers.
