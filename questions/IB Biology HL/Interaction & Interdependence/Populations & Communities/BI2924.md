# BI2924

Which of the following would be considered part of a forest's ecological community?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Deer, wolves, rabbits|
    | II. | Oak trees, ferns, mosses |
    | III. | Detritus on the forest floor |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
A community comprises all the interacting populations, which are living organisms, in a given area.

**Statement I** is true because it lists living animals which are part of the community.\
**Statement II** is true because it lists living plants which are also a part of the community. \
**Statement III** is not true because detritus is dead organic matter.  Even though it originated from living organisms and is considered part of the ecosystem, it is not considered part of the community.

**Choice B** is correct because it includes true **Statements I** and **II** and does not include untrue **Statement III**.

**Choice A** is incorrect because it does not include true **Statement II**.\
**Choice C** is incorrect because it does not include true **Statement I**, and it includes untrue **Statement III**.\
**Choice D** is incorrect because it includes the untrue **Statement III**.
