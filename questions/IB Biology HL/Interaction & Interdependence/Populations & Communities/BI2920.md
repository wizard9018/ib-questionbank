# BI2920

A team of ecologists used random sampling to estimate the population of rare beetle species in a temperate deciduous forest.  Their estimated population size was 5,000 beetles.  The true population size is 5,352 beetles.
What does the difference between these two numbers represent?

- A.$\hspace{1em}$ Systematic error in the sampling method.

- B.$\hspace{1em}$ Bias introduced by non-random sampling.

- C.$\hspace{1em}$ Natural variation is expected in population density.

- D.$\hspace{1em}$ Sampling error is inherent in the estimation process.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because the difference between the estimated population size (5,000 beetles) and the true population size (5,352 beetles) represents sampling error, which is an inherent part of any estimation process using a sample. This discrepancy arises because a sample can only approximate the true population size, and the result will vary due to random chance.

**Choice A** is incorrect because systematic error refers to consistent, repeatable measurement errors due to flaws in the methodology or equipment. For example, if the measuring tape used to mark a quadrat were stretched, the quadrat size would be incorrect, leading to over- or underestimates in every measurement taken. This is not the case here, as random sampling was used.

**Choice B** is incorrect because bias arises from non-random sampling, which could skew the results by disproportionately representing certain individuals or areas. For example, if quadrats are placed only in easily accessible areas (like near a path), the sample would not represent the entire area. In this case, random sampling was used, so bias is not the issue.

**Choice C** is incorrect because natural variation refers to fluctuations in population density over time due to environmental factors (e.g., light or water availability) and is not the cause of the discrepancy between the estimated and true population sizes in a stable population. A sufficiently large sample size should help minimise the effect of such natural variation in the estimate.
