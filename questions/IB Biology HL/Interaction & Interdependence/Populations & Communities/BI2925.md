# BI2925

Which of the following statements describes the mutualistic relationship between mycorrhizal fungi and orchid plants?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | The fungi provide the orchid with nutrients essential for germination and early growth. |
    | II. | The orchid supplies the fungi with carbohydrates produced through photosynthesis. |
    | III. | The fungi perform nitrogen fixation for the orchid, converting atmospheric nitrogen into usable ammonia. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because orchid seeds are small and lack energy reserves to support germination and early development.  The seeds rely on mycorrhizal fungi to provide these initial nutrients.\
**Statement II** is true.  The orchid is photosynthetic and provides the fungi with carbohydrates in return for the nutrients and water relayed through the fungi to the orchid.\
**Statement III** is not true because nitrogen fixation is carried out primarily by bacteria like Rhizobium in legume root nodules.  While mycorrhizal fungi enhance nitrogen and phosphorus uptake, they do not perform nitrogen fixation.

**Choice C** is correct because it contains true **Statements I** and **II** and does not contain the untrue **Statement III**.\
**Choice A** is incorrect because it does not include true **Statement II**.\
**Choice B** is incorrect because it does not include true **Statement I**.\
**Choice D** is incorrect because it includes the untrue **Statement III**.
