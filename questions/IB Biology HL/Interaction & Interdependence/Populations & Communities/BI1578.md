# BI1578

Eastern Egg Rock Island, Maine is home to a population of Atlantic puffins (*Fratercula arctica*). The colony was reintroduced to the island in 1973 by translocating six chicks from Newfoundland. The Audubon society has recorded the number of breeding pairs for more than fifty years, some of the results are provided in the table.

| Year | Number of Breeding Pairs |
| :-: | :-: |
| 1981 | 4 |
| 2001 | 37 |
| 2005 | 71 |
| 2013 | 111|
| 2015 | 150 |
| 2017 | 172 |
| 2019 | 188 |
| 2021 | 180 |

Which of the following statements does the data support?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Puffins exhibit sexual selection.|
    | II. | The puffin population exhibited sigmoid growth following reintroduction.|
    | III. | The puffin population has stabilised near the carrying capacity of the environment. |

- A.$\hspace{1em}$ III only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because the puffin population has risen sharply before becoming stable in recent years, characteristic of sigmoid growth (**Statement II**). The recent slight decline in the number of breeding pairs suggests that the population has begun to stabilise near the environment’s carrying capacity, leading to the death of some puffins and an overall plateau in population growth (**Statement III**).

**Statement I** is likely to be true, but the data does not describe sexual selection taking place in the puffin population. **Choice A** is incorrect because it is missing **Statement II**. **Choices B** and **D** are incorrect because they include **Statement I**.
