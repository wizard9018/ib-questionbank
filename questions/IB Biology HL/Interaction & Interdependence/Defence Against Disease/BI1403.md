# BI1403

What features distinguish B-lymphocytes and T-lymphocytes?

| | B-lymphocytes | T-lymphocytes |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Mature in the thymus | Mature in the bone marrow |
| B.$\hspace{1em}$ | Produce antibodies | Multiply to form plasma cells |
| C.$\hspace{1em}$ | Persist as memory cells | Activate B-lymphocytes |
| D.$\hspace{1em}$ | Activate T-lymphocytes | Destroy infected cells |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because a small number of memory cells persist in the body following infections to rapidly respond to future pathogens. Helper T cells are a type of T-lymphocyte that activates B-lymphocytes to produce antibodies.

**Choice A** is incorrect because B cells mature in the bone marrow while T cells mature in the thymus. **Choice B** is incorrect because T cells do not multiply to form plasma cells. **Choice D** is incorrect because B cells do not activate T-lymphocytes.
