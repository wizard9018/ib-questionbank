# BI0654

Which statement is true about B-lymphocytes in mammals?

-    A. $\hspace{1em}$ B-lymphocytes activate phagocytes

-    B. $\hspace{1em}$ B-lymphocytes cause the release of histamine
-    C. $\hspace{1em}$ T-lymphocytes activate B-lymphocytes
-    D. $\hspace{1em}$ Antibodies activate B-lymphocytes

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because activated helper T cells activate B lymphocytes. **Choice A** is incorrect because B-lymphocytes do not activate phagocytes. **Choice B** is incorrect because B-lymphocytes do not cause the release of histamine. **Choice D** is incorrect because antibodies are produced by B lymphocytes after they are activated.
