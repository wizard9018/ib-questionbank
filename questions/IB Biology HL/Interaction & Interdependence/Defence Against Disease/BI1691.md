# BI1691

Which of the following statements is/are correct?

- :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :-- | :-- |

    | I. | The innate immune system is non-specific and responds the same way to all pathogens. |

    | II. | The adaptive immune system can improve its response after repeated exposures to the same type of pathogen. |

    | III. | The innate immune system develops memory cells after encountering a pathogen. |

    | IV. | The adaptive immune system is the first line of defence against pathogens. |

Which statements are correct?

- A.$\hspace{1em}$ I and II

- B.$\hspace{1em}$ I and III

- C.$\hspace{1em}$ II and IV

- D.$\hspace{1em}$ III and IV

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

The innate immune system is the body's first line of defence and responds the same way to all pathogen types. It provides a rapid, non-specific response that includes physical barriers, phagocytic cells, and various proteins and molecules. **Statement I** is, therefore, true of the innate immune system. 

The adaptive immune system provides a specific response to particular pathogens and involves the activation of B and T lymphocytes. It builds up a memory of pathogens encountered, allowing for a more effective and rapid response upon subsequent exposures, making **Statement II** also true. **Choice A** is, therefore, correct.

**Statement III** is not true, as it is the active immune system that develops memory after encountering a specific pathogen.

**Statement IV** is not true, as the adaptive immune system is a third line of defence, not the first.

**Choices B, C** and **D** are all incorrect as they include either **Statement III** or **Statement IV**.
