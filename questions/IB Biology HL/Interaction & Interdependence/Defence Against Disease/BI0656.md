# BI0656

Which of these is not true of antibodies?

-    A. $\hspace{1em}$ They are globular proteins

-    B. $\hspace{1em}$ Antibodies have Y-shaped structures made up of two main heavy chains
-    C. $\hspace{1em}$ They can make pathogens more detectable by phagocytes

-    D. $\hspace{1em}$ Each antibody has one binding site

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
An antibody is a Y-shaped globular protein. The two “arms” of the Y each contain a binding site that can attach to a specific antigen. Therefore, one antibody molecule can bind to two identical antigens at the same time. **Choice D** is an false statement, and so is the correct answer to this question.

**Choice A**  is a true statement, and so is an incorrect answer to this question. Antibodies are globular proteins with a compact, rounded shape. Their shape helps them dissolve and move easily in blood plasma.

**Choice B** is a true statement, and so is an incorrect answer to this question. Antibodies are made from 2 heavy chains and 2 light chains. These chains join together to form the characteristic Y shape.

**Choice C**  is a true statement, and so is an incorrect answer to this question. When antibodies bind to antigens, they help the immune system remove or destroy foreign substances in several ways. They can neutralise toxins and viruses, cause pathogens to clump together, mark cells or pathogens for phagocytes to engulf more easily, and activate the complement system, which can damage cell membranes.
