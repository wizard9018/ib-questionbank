# BI0303

Which row in the table correctly identifies substance X and the solubility of fibrinogen?

![BI0303](images/BI0303.png)

| | $\hspace{1em}$ X $\hspace{1em}$ | $\hspace{1em}$ Fibrinogen $\hspace{1em}$ |
| :-: | :-: | :-: |
| $\hspace{1em}$A.$\hspace{1em}$| Clotting factor V | Insoluble |
|$\hspace{1em}$B.$\hspace{1em}$ | Dipeptidase | Soluble |
| $\hspace{1em}$C.$\hspace{1em}$ | Thrombin | Soluble |
| $\hspace{1em}$D.$\hspace{1em}$ | Surfactant | Insoluble |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Substance X is thrombin, which converts soluble fibrinogen into insoluble fibrin; **Choice C** is correct.

**Choice A** is incorrect because clotting factors convert prothrombin to thrombin, and fibrinogen is soluble.

**Choice B** is incorrect because, although both dipeptidase and thrombin are protease enzymes, dipeptidases function in digestion by breaking down dipeptides into amino acids, whereas thrombin is involved in blood clotting by converting fibrinogen into fibrin.

**Choice D** is incorrect because surfactant is found in the alveoli, and fibrinogen is soluble.
