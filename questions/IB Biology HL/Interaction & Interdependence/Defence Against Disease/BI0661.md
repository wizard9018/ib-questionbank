# BI0661

Which human disease was the first to be eradicated by vaccination?

-    A. $\hspace{1em}$ Polio
-    B. $\hspace{1em}$ Cholera

-    C. $\hspace{1em}$ Smallpox
-    D. $\hspace{1em}$ Bubonic plague

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because smallpox was the first human disease eradicated by vaccination. **Choice A** is incorrect because polio has not been fully eradicated. **Choice B** is incorrect because cholera has not been eradicated. **Choice D** is incorrect because there is no vaccine for bubonic plague.
