# BI0355

Which statement identifies the direct effect of auxin?

- A.$\hspace{1em}$ Development of leaves

- B.$\hspace{1em}$ Stimulates meiosis

- C.$\hspace{1em}$ Inhibits flowering

- D.$\hspace{1em}$ Changes gene expression

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because auxin affects gene expression which leads to changes in growth. **Choice A** is incorrect because cell differentiation causes development of leaves and this is not a direct effect of auxin. **Choice B** is incorrect because one effect of auxin is that it stimulates mitosis, it does not stimulate meiosis. **Choice C** is incorrect because auxin stimulates flowering.
