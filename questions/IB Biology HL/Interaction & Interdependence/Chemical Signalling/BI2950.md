# BI2950

Which of the following is/are a possible effect of a ligand binding to a receptor protein?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Amplification of the signal via a second messenger|
    | II. | Facilitated diffusion of the ligand into the cell, so it can bind to transcription factors |
    | III. | Opening of a calcium ion channel|

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because when ligands bind to receptor proteins on the cell surface, this can trigger a signal transduction pathway that activates a second messenger. Second messengers amplify the original signal inside the cell.\
**Statement II**  is false because, while some non-polar ligands (like steroid hormones) diffuse across the membrane to bind to intracellular receptors, this is simple diffusion, not facilitated diffusion. Most ligands bind to extracellular receptors, initiating signal transduction. \
**Statement III**  is true because some receptor proteins are ligand-gated ion channels; binding of a ligand can open a calcium ion channel and allow $\ce{Ca^2+}$ to flow into the cell.

**Choice B** is correct because it contains only the true **Statements I** and **III**.\
**Choice A** is incorrect because it only contains one of the true statements; it is missing **Statement III**.
**Choices C** and **D** are incorrect because they contain the false **Statement II**.
