# BI0839

Which of the following is only able to trigger a response in a cell by binding to a receptor in the plasma membrane?

- A.$\hspace{1em}$ Insulin

- B.$\hspace{1em}$ Testosterone

- C.$\hspace{1em}$ Oestradiol

- D.$\hspace{1em}$ Progesterone

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because insulin is a peptide hormone, which is polar so cannot directly pass through the plasma membrane.  Instead it  binds to receptors in the plasma membrane which triggers intracellular signalling pathways.

**Choices B**, **C** and **D**  are all incorrect, as they are all non-polar steroids so can diffuse through the plasma membrane and bind directly to receptors inside the cell, affecting gene expression.
