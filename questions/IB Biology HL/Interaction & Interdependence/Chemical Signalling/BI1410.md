# BI1410

Which of the following is/are true?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Non-polar ligands have receptors in the cytoplasm  |
  | II. | Polar ligands have receptors in the nucleus |
  | III. | Insulin binds to transmembrane receptor proteins |

- A. $\hspace{1em}$ I only

- B. $\hspace{1em}$ II only

- C. $\hspace{1em}$ I and III only

- D. $\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true as non-polar ligands are lipid-soluble and so can pass through the plasma membrane into the cytoplasm, where they bind to receptors. **Statement III** is true as insulin is a protein hormone and, therefore, cannot enter the cytoplasm and has to bind to receptor proteins embedded in the phospholipid bilayer of the plasma membrane. **Choice C** is correct.

**Statement II** is not true as polar ligands cannot pass through the plasma membrane and therefore cannot enter the nucleus, therefore **Choices B** and **D** are incorrect. **Choice A** is incorrect as it only gives one of the true statements.
