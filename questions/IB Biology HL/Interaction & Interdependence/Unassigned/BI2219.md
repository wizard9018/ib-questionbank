# BI2219

**Maximum mark: 10**

The beach strawberry (*Fragaria chiloensis*) and yellow sand verbena (*Abronia latifolia*) are two plant species found in the coastal region of Oregon, USA. Some students decided to record the presence and absence of the two species in 200 quadrats and use the chi-squared test to examine whether their distributions were associated with each other. The table below shows the observed results obtained.

![BI2219a](images/BI2219a.png)

1. Outline the purpose of a Chi-Square test. [1 mark]

2. Suggest a null hypothesis for this investigation. [1 mark]

The expected results and chi-square values were calculated:

| Species absent / present | Expected value | Chi-square value |
| :-- | :-: | :-: |
| Yellow sand verbena present $\\$ Beach strawberry present(A) | 80 | 1.25 |
| Yellow sand verbena present $\\$ Beach strawberry absent | 54 | 1.85 |
| Yellow sand verbena absent $\\$ Beach strawberry present | 40 | 2.50 |
| Yellow sand verbena absent $\\$ Beach strawberry absent |26 |

3. Calculate the chi-square value for the final quadrant using the formula $\ce{χ^2}= \Sigma \dfrac{\ce{(O-E)^2}}{\ce{E}}$. [1 mark]

4. State the number of degrees of freedom for this data set to determine the critical value of chi-squared. [1 mark]

| Degrees of freedom | Critical value for p=0.05 |
| :-- | :-- |
| 1 | 3.84 |
| 2 | 5.99 |
| 3 | 7.81 |
| 4 | 9.49 |

5. Using the **total** chi-squared value, explain the conclusion that can be drawn from the calculated and critical values obtained from the data. [4 marks]

6. Suggest **two** types of additional data that could be collected to determine if there is interspecific competition between beach strawberry (*Fragaria chiloensis*) and yellow sand verbena (*Abronia latifolia*). [2 marks]
