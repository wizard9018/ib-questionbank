# BI1126

Which statement is correct if a population of Scottish wildcats (*Felis silvestris silvestris*) is **not** in Hardy Weinberg equilibrium (HW)?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | There are a few hundred wildcats in Scotland  |
    | II. | Scottish wildcats with darker fur are more likely to survive as they can camouflage themselves and hide from humans  |
    | III. | Scottish wildcats are only found in Scotland, and they only breed with each other |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
A major assumption that has to be met for a population to be in Hardy Weinberg equilibrium is an infinite or very large population (**Statement I**), however, there are only a few hundred wildcats in Scotland. Another assumption that has to be met is that no natural selection is occurring, but wildcats with darker fur have a better chance of survival (**Statement II**), therefore, they are under selection pressures. **Choice C**  is correct.

For the Scottish wildcats to be in Hardy Weinberg equilibrium, there must be no gene flow, which means that there is no movement of Scottish wildcats out of the population (**Statement III**). **Choice D**  is incorrect. **Choices A** and **B** are incorrect as they only include one of the true statements, not both.
