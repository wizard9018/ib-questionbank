# BI0709

Which are examples of directional selection?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Human babies with an average birth weight are more likely to survive than those that are below or above average |
    | II. | Black peppered moths are more likely to survive than lighter moths in industrial areas as they can camouflage better |
    | III. | Larger salmons are fished, resulting in the better survival of smaller salmons |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Both **Statements II** and **III**, describe directional selection, when one extreme in a population is selected for. **Choice C** is correct.

**Statement I** is incorrect as it describes stabilising selection, where the intermediate individuals within a population are selected for (**Choices A** and **D**). **Choice B**  is incorrect because it only describes **Statement II**.
