# BI0474

What does the phrase $\text{\textquoteleft}$the genetic code is universal$\text{\textquoteright}$ mean?

-    A. $\hspace{1em}$ Adenine always pairs with thymine, and guanine always pairs with cytosine

-    B. $\hspace{1em}$ Almost all living organisms use the same genetic code

-    C. $\hspace{1em}$ Different codons cannot code for the same amino acid

-    D. $\hspace{1em}$ Proteomes are always larger than the genomes

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Universality of the genetic code means that all organisms with very few exceptions use the same genetic code (**Choice B**). This is why gene transfer between species is possible. An example of the universality of genetic code is the production of human insulin in bacterial cells.

**Choice A** is incorrect because it is a complementarity rule and is not related to the $\text{\textquoteleft}$universal genetic code$\text{\textquoteright}$ concept.

**Choice C** is incorrect because several codons may code for the same amino acid.

**Choice D** is incorrect because the size of the genome or proteome is not related to the $\text{\textquoteleft}$universal genetic code$\text{\textquoteright}$ concept.
