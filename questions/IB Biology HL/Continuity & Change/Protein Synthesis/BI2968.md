# BI2968

How is complementary base pairing essential for accurate transcription of genetic information?

- A.$\hspace{1em}$ It ensures both DNA strands are transcribed at the same time.

- B.$\hspace{1em}$ It minimises mutations by preventing mismatched bases during replication

- C.$\hspace{1em}$ It strengthens the hydrogen bonds between DNA strands during transcription.

- D.$\hspace{1em}$ It allows RNA nucleotides to form complementary pairs with the DNA template strand.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because during transcription, complementary base pairing ensures that RNA nucleotides (A, U, C, G) are matched correctly with the DNA template strand (T, A, G, C), producing an accurate mRNA copy of the gene.

**Choice A** is incorrect because only one DNA strand (the template strand or antisense strand) is used for transcription; the other strand is non-coding. Complementary base pairing does not involve both strands being transcribed.

**Choice B** is incorrect because this refers to DNA replication, not transcription. While complementary base pairing does contribute to replication accuracy, transcription errors affect only RNA and do not cause mutations in DNA.

**Choice C** is incorrect because hydrogen bonds between DNA strands are broken, not strengthened, during transcription, so RNA polymerase can access the template strand; complementary base pairing occurs between RNA and DNA bases, not between the two DNA strands.
