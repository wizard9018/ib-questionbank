# BI0896

Which function and process are correctly matched in the table below?

| | Process | Function |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Replication | Addition of the 5’ cap and poly-A tail to the 3’ end |
| B.$\hspace{1em}$ | Transcription | RNA polymerase adds nucleotides to the 3’ end of the growing mRNA strand |
| C.$\hspace{1em}$ | Translation | DNA polymerase adds nucleotides to the 3’ end of the primer |
| D.$\hspace{1em}$ | Splicing | Ribosome moves along the mRNA from the 5’ end to the 3’ end |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because RNA polymerase adds nucleotides to the 3’ end of the growing mRNA strand in transcription.

**Choice A** is incorrect because the addition of the 5’ cap and poly-A tail takes place in splicing. **Choice C** is incorrect because the addition of nucleotides by DNA polymerase takes place during DNA replication. **Choice D** is incorrect because the movement of ribosomes along the mRNA takes place during translation.
