# BI2394

Which of the following allows a eukaryotic gene to code for multiple polypeptides?

- A.$\hspace{1em}$ Accurate A-T and C-G base pairing

- B.$\hspace{1em}$ The presence of introns

- C.$\hspace{1em}$ The degenerate code

- D.$\hspace{1em}$ Alternative splicing

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because alternative splicing allows transcribed exons to be spliced together in different orders, resulting in multiple polypeptides. These polypeptides can have a range of effects on the organism, so is a selective advantage to that organism. This is one way that a small genome can result in a large proteome.

**Choice A** is incorrect because accurate base pairing allows for stable DNA structure with relatively few mutations, but does not increase the number of polypeptides that any particular gene can code for.

**Choice B** is incorrect because introns are removed before splicing takes place; splicing is when different mRNA sequences can be translated into multiple polypeptides.

**Choice C** is incorrect because the degenerate code applies in the translation of mRNA, in which multiple codons can code for the same amino acid.
