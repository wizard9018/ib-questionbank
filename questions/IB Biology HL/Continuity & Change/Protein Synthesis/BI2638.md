# BI2638

What would be the most likely result if the A site in the ribosome was non-functional?

- A.$\hspace{1em}$ The wrong amino acids would be incorporated into the polypeptide chain

- B.$\hspace{1em}$ Only the start codon would be translated

- C.$\hspace{1em}$ The rate of translation would be slower

- D.$\hspace{1em}$ Translation would not be able to be initiated

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
During the initiation of translation, the initiator tRNA, which carries the amino acid methionine, binds to the P site of the ribosome. The next tRNA with the complementary anticodon to the next codon binds in the A site, which allows the elongation phase to start. If the A site is non-functional, then no new tRNAs can bind after the initiator tRNA, therefore only the start codon can be translated; **Choice B** is correct.

If the A site is non-functional, then no new tRNAs can be incorporated into the polypeptide chain after the initiator tRNA; **Choice A** is incorrect.

If the A site is non-functional, translation would not just slow down, it would stop completely; **Choice C** is incorrect.

The P site, not the A site, is necessary for the initiation of translation; **Choice D** is incorrect.
