# BI2815

What is/are the role(s) of RNA polymerase during transcription?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Unwinding the DNA to expose the template strand |
    | II. | Adding a short RNA primer to start transcription |
    | III. | Synthesising RNA by adding ribonucleotides to the 5' end |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true. During transcription, RNA polymerase unwinds the DNA double helix as it moves along the gene.\
**Statement II** is false. RNA polymerase does not need a primer to initiate transcription, unlike DNA polymerase during DNA replication.\
**Statement III** is false. RNA polymerase adds ribonucleotides to the 3' end of the growing RNA strand, not the 5' end. RNA synthesis always proceeds in the 5' $\rarr$ 3' direction, meaning new nucleotides are attached to the 3' end.

**Choice A** is, therefore,  the correct answer because it only includes the true **Statement I**.\
**Choices B, C** and **D** are incorrect as they include one or more of the false **Statements II** and **III**.
