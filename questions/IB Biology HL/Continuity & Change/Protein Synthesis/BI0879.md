# BI0879

A single base substitution mutation occurs and a stop codon is not produced.  Which of the following is **not** a possible consequence of this type of mutation?

- A.$\hspace{1em}$ The quaternary structure of the protein this gene codes for is altered.

- B.$\hspace{1em}$ No amino acids in the polypeptide this gene codes for are changed.

- C.$\hspace{1em}$ Two amino acids in the polypeptide this gene codes for are changed.

- D.$\hspace{1em}$ DNA repair mechanisms are activated, producing a stop codon.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because single base substitution mutations only affect one codon and therefore can only change one amino acid, not two.

**Choice A** is incorrect because a single base substitution mutation can sometimes change the amino acid sequence of a polypeptide which can then alter the quaternary structure of the protein. **Choice B** is incorrect because sometimes single base substitution mutations do not change the amino acid sequence even though a codon is changed.  This is possible because the genetic code is degenerate. **Choice D** is incorrect because it is possible for DNA repair mechanisms to repair the DNA incorrectly which could result in an alteration of the base sequence, producing a stop codon.  It is also possible the mutation occurred within a stop codon and that the DNA repair mechanisms correctly repaired the DNA, restoring the stop codon that mutated.
