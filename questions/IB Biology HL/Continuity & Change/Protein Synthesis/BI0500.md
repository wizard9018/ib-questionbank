# BI0500

A non-coding (antisense) strand of DNA consists of the following nucleotides:

GGCACATTAG

Which of the following represents the RNA transcript produced by this DNA strand?

- A.$\hspace{1em}$ GGCACAUUAG

- B.$\hspace{1em}$ CCGUGUAAUC

- C.$\hspace{1em}$ GGCACATTAG

- D.$\hspace{1em}$ CCGTGTAATC

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The non-coding, or antisense strand, is the strand that serves as a template for RNA synthesis. RNA is formed from the antisense strand through complementary base pairing:

- The base A (adenine) in DNA binds with the base U (uracil) in RNA.
- The base T (thymine) in DNA binds with the base A (adenine) in RNA.
- The base C (cytosine in DNA binds with the base G (guanine) in RNA.
- The base G (guanine) in DNA binds with the base C (cytosine) in RNA.

So, the RNA transcript produced by complementary base pairing with the DNA strand GGCACATTAG is CCGUGUAAUC.

The base thymine (T) is not found in RNA (**Choice C** and **Choice D**). **Choice A** does not show complementary base pairing, which is required for the production of mRNA.
