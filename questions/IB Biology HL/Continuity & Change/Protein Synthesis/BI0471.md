Which of the following features can be deduced from the genetic code?

-    I. $\hspace{1em}$ Codons consisting of different bases can code for the same amino acid
-    II. $\hspace{.7em}$ Codon AUG does not code for an amino acid
-    III. $\hspace{.4em}$ mRNA strands coding for a protein will always contain codons that do not code for amino acids

-    A. $\hspace{1em}$ I and II only

-    B. $\hspace{1em}$ I and III only
-    C. $\hspace{1em}$ II and III only
-    D. $\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The genetic code shows sequences of three RNA bases, each of which correspond to one amino acid to be added to a polypeptide. A sequence of three bases is known as a codon and different codons can code for the same amino acid (**Statement I**).

There are three $\text{\textquoteleft}$STOP$\text{\textquoteright}$ codons, UAA, UAG and UGA which do not code for an amino acid but code for the end of translation.  Therefore they are always included in mRNA sequences (**Statement III**).

Codon AUG is a $\text{\textquoteleft}$START$\text{\textquoteright}$ codon which also codes for the amino acid methionine (**Statement II**). **Choices A, C** and **D** are all incorrect as they include **Statement II**.
