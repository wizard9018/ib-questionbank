# BI2636

Which explains how alternative splicing affects gene expression?

- A.$\hspace{1em}$ Increases the number of genes in a genome

- B.$\hspace{1em}$ Alters the position of the promoter region of a gene

- C.$\hspace{1em}$ Increases the degeneracy of the genetic code

- D.$\hspace{1em}$ Allows different combinations of exons to be included in mRNA

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Alternative splicing is a eukaryotic post-transcriptional process where a single gene can produce multiple mRNA variants due to exons being spliced together in different combinations. The different combination of exons results in the synthesis of different polypeptides from the same gene; **Choice D** is correct.

Alternative splicing does not change the number of genes, it affects how mRNA is processed to produce different proteins from the same gene; **Choice A** is incorrect.
Alternative splicing is a post-transcriptional process. The promoter region of a gene is a DNA sequence upstream of a gene that acts as a binding site for transcription factors and RNA polymerase to bind to initiate transcription, transcription and alternative splicing are not directly linked; **Choice B** is incorrect. \
The genetic code is classed as degenerate as multiple codons can code for the same amino acid, this affects translation, not post-transcriptional processes; **Choice C** is incorrect.
