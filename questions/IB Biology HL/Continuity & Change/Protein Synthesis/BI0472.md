Which of the following shows an mRNA sequence that can be converted into a polypeptide?

-    A. $\hspace{1em}$ 5$\text{\textquoteright}$ - AUG GCC AAA AGG CCC AGU UAG - 3$\text{\textquoteright}$

-    B. $\hspace{1em}$ 5$\text{\textquoteright}$ - UAG CCG AAA AGG CCC AGU AUG - 3$\text{\textquoteright}$
-    C. $\hspace{1em}$ 5$\text{\textquoteright}$ - AAA CGG ATG ACC CTC AGT TAC - 3$\text{\textquoteright}$
-    D. $\hspace{1em}$ 5$\text{\textquoteright}$ - TAC AGT CTC ACC ATG CGG AAA - 3$\text{\textquoteright}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
A mRNA strand contains four nitrogenous bases: adenine (A), cytosine (C), guanine (G) and uracil (U). It does not contain thymine (T) (**Choice C** and **Choice D**).

Most mRNA strands which code for polypeptides begin with the $\text{\textquoteleft}$START$\text{\textquoteright}$ codon AUG and end with a `STOP$\text{\textquoteright}$ codon, UAG, UAA or UGA (**Choice A**). **Choice B** has a $\text{\textquoteleft}$STOP$\text{\textquoteright}$ codon at the beginning which would terminate translation before it begins.
