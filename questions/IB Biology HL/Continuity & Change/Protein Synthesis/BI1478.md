# BI1478

Which mRNA sequence codes for the polypeptide Ser-Ala-Pro-Asn-Ile-Phe?

![1478](images/1478.png)

- A. $\hspace{1em}$ UCAGCUCCUAACAUCUUU

- B. $\hspace{1em}$ UCGGCUCCAAAUAUGUUU

- C. $\hspace{1em}$ UCCGAUCCGAAUAUUUUU

- D. $\hspace{1em}$ UCGGCUCCCAAGAUCUUU

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer}}$: \

The amino acid code is read from the 5’ to 3’ direction. Using the diagram, UCA codes for Ser, GCU codes for Ala, CCU codes for Pro, AAC codes for Asn, AUC codes for Ile and UUU codes for Phe. **Choice A** is correct.

**Choice B** is incorrect as the fifth mRNA codon (AUG) does not code for Ile. **Choice C** is incorrect as the second mRNA codon (GAU) does not code for Ala. **Choice D** is incorrect as the fourth mRNA codon (AAG) does not code for Asn
