2. Codons need to consist of a sequence of three bases to code for one amino acid. State **one** reason why codons need to consist of three bases. [1 mark]

3. Calculate the number of nucleotides present in the mRNA strand if the polypeptide synthesised has a length of 120 amino acids. [1 mark]

2.    Any **one** of the following:

    $\ce{ -> }$ there are only four different nitrogenous bases, **WHILE** there are twenty amino acids [1 mark]

    $\ce{ -> }$ one base cannot code for one amino acid    [1 mark]

    $\ce{ -> }$ two base codons could only code for sixteen (4$^2$) amino acids **OR** two base codons are too few to code for twenty amino acids    [1 mark]

    $\ce{ -> }$ three base codons allow for (4$^3$) sixty-four possible codons **OR** combinations [1 mark]

    [1 mark]

    $\underline{\textrm{Sample Answer}}$:\
Codons need to consist of a sequence of three bases because there are **twenty types of amino acids but only four types of nucleotides** ($\checkmark$). Thus, one base cannot code for one amino acid; in this case, there would be only four possible codons. **Two nucleotide codons would lead to sixteen codons** ($\checkmark$), but **three nucleotide codons lead to 64** different codons ($\checkmark$), which is enough to code for all twenty amino acids.

3.    Show working:
$\ce{ -> }$ 363 (nucleotides) [1 mark]

    [1 mark]

    $\underline{\textrm{Sample Answer}}$:\
one amino acid is coded by three nucleotides\
120 amino acids $\times$ 3 = 360 nucleotides\
 360 + 3 nucleotides (stop codon) = **363** nucleotides ($\checkmark$)
