# BI1383

What tRNA anticodon would pair with an mRNA codon transcribed from a DNA sense strand with the sequence ACT?

- A.$\hspace{1em}$ UGA

- B.$\hspace{1em}$ ACT

- C.$\hspace{1em}$ ACU

- D.$\hspace{1em}$ TGA

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The DNA sense strand is not used to transcribe mRNA. The antisense, or template strand, is used instead. Therefore, a sense strand with a sequence of ACT would have a corresponding antisense strand of TGA. The complementary pairing created during transcription would then be ACU since uracil (U) replaces thymine (T) in RNA. This is the mRNA codon, which would then pair with the tRNA anticodon UGA. **Choice A** is correct.

DNA sense strand = ACT\
DNA antisense strand = TGA\
mRNA codon = ACU\
tRNA anticodon = UGA

**Choice B** is incorrect because ACT is the sequence for the sense strand. **Choice C** cannot be correct because this is the mRNA codon sequence as opposed to the tRNA anticodon sequence. **Choice D** cannot be correct as it represents the DNA antisense strand. Additionally, RNA does not contain thymine so **Choices B** and **D** are not possible.
