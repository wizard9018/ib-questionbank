# BI1108

Which row in the table is correct for variables affecting the timing of biological events in an arctic ecosystem?

| | Migration of Reindeer | Germination of Arctic Mouse-Ear Chickweed Seeds  |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Temperature | Temperature |
| B.$\hspace{1em}$ | Photoperiod | Temperature |
| C.$\hspace{1em}$ | Temperature | Photoperiod |
| D.$\hspace{1em}$ | Photoperiod | Photoperiod |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because Reindeer (Rangifer tarandus) use day length as a cue to begin their journey to their breeding grounds, and the Arctic mouse-ear chickweed (Cerastium arcticum) uses temperature as a cue to germinate. **Choice A, C** and **D** are incorrect because the variables do not match up correctly with the biological events.
