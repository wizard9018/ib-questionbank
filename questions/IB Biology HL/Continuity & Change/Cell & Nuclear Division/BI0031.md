# BI0031

The mitotic index of throat tissues taken from 4 different patients is shown below, calculated as a percentage. Which patient is most likely to have cancerous throat tissue?

| | Mitotic index of throat tissue / % |
| --- | :-: |
| A.$\hspace{1em}$ | 10.0 |
| B.$\hspace{1em}$ | 2.3 |
| C.$\hspace{1em}$ | 3.2 |
| D.$\hspace{1em}$ | 5.6 |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Cancerous cells have a high rate of mitosis, so would have the highest mitotic index.

**Choices B**, **C** and **D** are below 10, so are incorrect.
