# BI1148

An unfertilised egg cell belonging to the mangrove horseshoe crab (*Carcinoscorpius rotundicauda*) contains 16 chromosomes. How many chromosomes would be found in a cell from this species about to undergo meiosis?

- A.$\hspace{1em}$ 8

- B.$\hspace{1em}$ 16

- C.$\hspace{1em}$ 32

- D.$\hspace{1em}$ 64

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The diploid number for this species is 32. At the start of meiosis, each chromosome has been replicated to form two sister chromatids, held together at the centromere. Each pair of sister chromatids is still regarded as one chromosome so the total number of chromosomes after replication will still be 32; **Choice C** is correct

**Choice A**, 8 chromosomes, is incorrect as it would represent a condition not typical for any stage in the life cycle of this species. **Choice B**, 16 chromosomes, incorrectly suggests the haploid number, which is characteristic of the gametes post-meiosis, not cells about to undergo meiosis. **Choice D**, 64 chromosomes, incorrectly implies a tetraploid number, which suggests an error in chromosome number doubling beyond the typical diploid state.
