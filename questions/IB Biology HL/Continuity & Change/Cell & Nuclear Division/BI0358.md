# BI0358

The diagram below represents the structure of a shoot apical meristem. Which row in the table correctly identifies the processes occuring in the structures labeled in the diagram?

![BI0358ii](images/BI0358ii.png)

| | I | II |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Cell elongation | Cell division |
| B.$\hspace{1em}$ | Cell differentiation | Cell elongation |
| C.$\hspace{1em}$ | Cell division | Cell elongation |
| D.$\hspace{1em}$ | Cell differentiation | Cell division |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because cell division happens at the stem tip and cell elongation happens in the new cells below the stem tip. **Choice A** is incorrect because cell elongation happens below the stem tip and cell division happens in the stem tip. **Choice B** is incorrect because cell production happens in the stem tip, cell differentiation happens below the stem tip. **Choice D** is incorrect because cell division happens below the region where cell elongation happens and cell elongation and differentiation happen below the stem tip.
