# BI1179

Which of the following generate genetic variation during meiosis?

| | |
| :-- | :-- |
| I. | Crossing over during prophase I |
| II. | Independent assortment of homologous chromosomes during metaphase I |
| III. | Random fertilisation |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because crossing over occurs during prophase I when homologous chromosomes pair together. Non-sister chromatids exchange segments of DNA, producing new allele combinations and increasing genetic variation.

**Statement II** is true because homologous chromosome pairs align randomly during metaphase I. This independent assortment results in different combinations of maternal and paternal chromosomes in gametes, increasing variation.

**Statement III** is false because random fertilisation does increase genetic variation in offspring, but it does not occur during meiosis. It occurs during sexual reproduction when gametes fuse.

**Choice B** is the correct asnwer to the question as it only includes the true **Statements I** and **II**.
