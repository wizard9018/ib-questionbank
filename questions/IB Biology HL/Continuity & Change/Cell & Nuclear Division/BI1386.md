# BI1386

The gametes of a wolf (*Canis lupus*) contain 39 chromosomes. How many chromosomes would be found in the cells of a wolf as meiosis begins?

- A.$\hspace{1em}$ 156

- B.$\hspace{1em}$ 117

- C.$\hspace{1em}$ 78

- D.$\hspace{1em}$ 39

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Gametes are haploid cells that contain half the normal number of chromosomes (n). They are formed from diploid (2n) cells during meiosis, which is a reduction division. Since the wolf's gametes, which are haploid cells, contain 39 chromosomes, its diploid number must be twice that, or 78. During interphase, DNA replication takes place. This means that each of the 78 chromosomes is made up of two sister chromatids joined at the centromere. Thus there are 156 chromatids making up 78 chromosomes. The sister chromatids will then separate during meiosis to form chromosomes in their own right. **Choice C** is correct.

**Choice A**  is incorrect because even though there are 156 sister chromatids at the start of meiosis, each pair is considered a single chromosome, so the number of chromosomes remains the same as it did before replication. **Choice B** is incorrect because it would not be possible to have a cell with this number of chromosomes for this particular species. **Choice D** cannot be correct because this is the haploid chromosome number, and at the start of meiosis, homologous chromosomes have not yet been separated.
