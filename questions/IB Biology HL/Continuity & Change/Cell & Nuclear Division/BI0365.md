# BI0365

Which allele combination can result in a gamete, from the crossing over of non-sister chromatids shown in the diagram below?

![BI0365](images/BI0365.png)

- A.$\hspace{1em}$ bj

- B.$\hspace{1em}$ bJ

- C.$\hspace{1em}$ Bj

- D.$\hspace{1em}$ Jj

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct as crossing over could result in a gamete containing the “b” allele and a “j’ allele. **Choices B** and **C** are incorrect as they are the same as the original combination of alleles, so crossing over hasn’t occurred. **Choice D** is incorrect because the gamete should contain one copy of each gene.
