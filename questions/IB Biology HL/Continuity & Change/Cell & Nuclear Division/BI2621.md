# BI2621

Which of the following features of the P53 gene identify it as a tumour suppressor gene?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | The protein it codes for binds directly to DNA. |
    | II. | It converts to an oncogene in the presence of carcinogens. |
    | III. | It determines whether a cell needs to undergo apoptosis. |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ III only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because the P53 protein is a transcription factor. This binds directly to DNA and suppresses the cell cycle, preventing uncontrolled cell division. \
**Statement II** is false because this statement describes proto-oncogenes, not tumour suppressor genes. \
**Statement III** is true because when DNA is irreversibly damaged, the P53 protein initiates apoptosis (controlled cell death) to eliminate cells with badly damaged DNA that should not divide further.

**Choice C** is correct because it contains only the correct statements (**I** and **III**).\
**Choice A** is incorrect because it contains the false statement (**II**) and omits one of the true statements (**III**).\
**Choice B** is incorrect because it omits one of the true statements (**I**).\
**Choice D** is incorrect because it contains the false statement (**II**).
