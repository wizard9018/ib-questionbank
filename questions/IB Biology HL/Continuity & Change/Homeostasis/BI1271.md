# BI1271

Which set of statements is true regarding homeostasis?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | It involves the maintenance of internal conditions despite changes in the external environment  |
    | II. | Homeostatic variables are kept constant  |
    | III. | Includes the regulation of body temperature, blood pH, blood glucose concentration, and blood osmotic concentration  |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Homeostasis is the maintenance of internal conditions despite changes in the external environment (**Statement I**). It includes homeostatic variables such as body temperature, blood pH, blood glucose concentration, and blood osmotic concentration (**Statement III**). It does not, however, require that all homeostatic variables remain constant (**Statement II**), instead allowing them to fluctuate within safe limits. Thus, **Choice B** is correct.

**Choice A** is incorrect as it does not include **Statement III**. **Choices C** and **D** are incorrect as they include **Statement II**.
