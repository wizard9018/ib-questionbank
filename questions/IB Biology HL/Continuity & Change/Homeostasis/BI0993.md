# BI0993

Which statements are true of feedback mechanisms in an organism?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Negative feedback acts to reverse a change |
    | II. | An example of positive feedback is control of blood pH |
    | III. | Only the nervous system is involved in the control of feedback mechanisms |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Negative feedback is a regulatory mechanism in which the body responds to a change in order to return the homeostatic variable back to within its set points.  For example, if blood pH increases above the set point, negative feedback mechanisms will occur to bring blood pH back down. **Statement I** is therefore true and **Statement II** is therefore false. **Choices B** and **D** are not correct.

While the nervous system plays a significant role in many feedback mechanisms, it is not the only system involved. The endocrine system, which releases hormones into the bloodstream also plays a crucial role in feedback control. **Statement III** is therefore false, meaning **Choice B** is incorrect, and **Choice A** is the correct response to the question.
