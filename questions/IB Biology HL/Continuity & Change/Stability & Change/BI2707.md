# BI2707

The Amazon rainforest is a long-standing ecosystem, however, logging has caused instability. Which factors contributing to ecosystem stability are disrupted by logging?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Recycling of nutrients |
    | II. | Genetic diversity |
    | III. | Climatic variables remaining within tolerance levels |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because logging can disrupt the nutrient cycle by removing trees that would otherwise decompose and enrich the soil. \
**Statement II** is true because logging can reduce genetic diversity by removing certain species or age classes of trees, which may impact the overall genetic pool of plants and animals that rely on these species. \
**Statement III** is true because the Amazon rainforest helps to regulate atmospheric moisture (cloud formation, rainfall) through transpiration. However, deforestation disrupts this process, leading to reduced rainfall and increased temperatures.

**Choice D** is, therefore, correct because all three statements are true.
