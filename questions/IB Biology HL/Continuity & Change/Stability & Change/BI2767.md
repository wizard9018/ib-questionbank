# BI2767

In a temperate forest, periodic wildfires occur every 20–30 years, destroying most mature trees. After each fire, grasses and shrubs dominate before trees gradually return. Which of the following best describes this pattern?

- A.$\hspace{1em}$ Primary succession, since fire resets the ecosystem to its original state.

- B.$\hspace{1em}$ Linear succession, ending in a permanent climax community.

- C.$\hspace{1em}$ Cyclical succession, where disturbances restart succession repeatedly.

- D.$\hspace{1em}$ Zonal succession, with predictable changes due to climate differences.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because ​​the ecosystem undergoes repeated disturbance (wildfire) and then goes through the same successional stages again: grasses $\rarr$ shrubs $\rarr$ trees. It doesn't move toward a single, fixed climax community — instead, it cycles back to earlier stages repeatedly. This is a textbook example of cyclical succession, where recurrent events (like fire) reset the community.

**Choice A** is incorrect because primary succession occurs on newly formed or barren land where no soil exists — e.g., lava flows, glacial retreat. After a forest fire, soil remains, and the ecosystem recovers through secondary, not primary, succession. Also, primary succession isn't cyclical — it's a progression from bare substrate to climax, not a repeating loop.

**Choice B** is incorrect because linear succession suggests a one-directional path toward a stable climax. In this case, the climax community (mature trees) is regularly disrupted, so the system doesn't stabilise permanently. The repeated resetting by fire means the successional path is not linear, but repeating. The term linear succession is rarely used, and the IB syllabus focuses on the use of primary, secondary and cyclical succession.

**Choice D** is incorrect because zonal succession refers to regional patterns in vegetation due to climate zones (e.g., tundra $\rarr$ boreal forest $\rarr$ temperate forest). It's about geographical variation, not repeating patterns within the same ecosystem. The succession described in the question is caused by local disturbances, not zonal climate variation. This term is also rarely used.
