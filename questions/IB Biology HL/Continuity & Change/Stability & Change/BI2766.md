# BI2766

Which of the following statements about cyclical succession is/are true?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Cyclical succession occurs when disturbances such as fire or grazing periodically reset an ecosystem to an earlier stage.|
    | II. | Unlike primary succession, cyclical succession does not involve pioneer species recolonising an area. |
    | III. | Some ecosystems rely on cyclical succession to maintain biodiversity. |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because cyclical succession is driven by periodic disturbances like fire, grazing, or storms, which reset the community to an earlier stage. For example, in heathlands, fires remove older vegetation and allow heather to regrow.\
**Statement II** is false because cyclical succession can involve pioneer species recolonising an area after a disturbance. For example, after a fire, early-successional species (e.g., heather seedlings) recolonise the land first before it transitions to later stages of succession. \
**Statement III** is true because some ecosystems depend on cyclical succession to maintain biodiversity. Without periodic disturbances, dominant species may outcompete others, reducing overall diversity. Heathlands, for example, require periodic fires to maintain habitat diversity.

**Choice B** is the correct answer as it only includes the two true **Statements I** and **III**.\
**Choices A, C** and **D** are incorrect as they include the false **Statement II**.
