# BI2343

Which mechanism can be used by both unicellular and multicellular organisms to regulate water movement via active transport?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Control ion concentration of tissues |
    | II. | Use aquaporins to increase water movement |
    | III. | Use contractile vacuoles to release water|
     | IV. | Use membrane proteins to control ion movement|

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ IV only

- D.$\hspace{1em}$ I, II and IV only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement IV** is true because both unicellular and multicellular organisms can use membrane proteins, such as ion channels and pumps (requiring energy, and active transport) to regulate ion movement. This affects the solute concentration inside cells, influencing water movement via osmosis. For example, in multicellular organisms, the loop of Henle in mammalian kidneys uses ion transport to regulate water reabsorption. Similarly, unicellular organisms like Euglena and Chlamydomonas regulate ion movement to control water balance.

**Statement I** is false because unicellular organisms consist of a single cell and do not form tissues, so they cannot regulate ion concentration in tissues either by active or passive transport.

**Statement II** is false because aquaporins are specialised membrane proteins that facilitate water movement through passive transport rather than active transport. While used by multicellular organisms, some unicellular organisms (such as Paramecium) use aquaporins for water regulation.

**Statement III** is false because contractile vacuoles, used by some unicellular organisms like Paramecium to expel excess water, are not utilised by multicellular organisms for water regulation. However, a contractile vacuole requires energy.

**Choice C** is, therefore, the correct answer as it includes the true Statement IV.

**Choices A, B** and **D** are incorrect as they include one or more false statements.
