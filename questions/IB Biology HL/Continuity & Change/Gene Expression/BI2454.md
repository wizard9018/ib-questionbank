# BI2454

Which statement/s are true for epigenetic inheritance?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Epigenetic inheritance is not always permanent.|
    | II. | Epigenetic tags are passed on to daughter cells during mitosis. |
    | III. | Most epigenetic tags are not passed from gametes to zygotes. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I, II, and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because all three statements are true. Epigenetic tags can be removed after fertilisation, so they are not always permanent. Cells produced by mitosis can carry the pattern of epigenetic tags, but most of the epigenetic tags in gametes are removed before fertilisation.

**Choices A, C**, and **D** are incorrect because they are all missing one or more true statements.
