# BI2449

In an organism, which of the following regions has the most similar DNA sequence across all genes?

- A.$\hspace{1em}$ Poly-A tail

- B.$\hspace{1em}$ Promoter

- C.$\hspace{1em}$ Enhancer

- D.$\hspace{1em}$ Silencer

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because promoters are DNA sequences near the start of a gene where RNA polymerase binds to initiate transcription. While there is some variation, promoters generally have similar sequences.

**Choice A** is incorrect because the poly-A tail is a long sequence of adenine bases that are added to mRNA after transcription, they are not found on genes. **Choice C** and **choice D** are incorrect because the sequences of enhancers and silencers are very variable which allows precise regulation of genes.
