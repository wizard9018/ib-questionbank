# BI2296

Which of the following statements about the cell's proteome is true?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | It is larger than the transcriptome due to post-translational modifications. |
    | II. | It varies from the proteomes of other cell types.|
    | III. | It includes all proteins a cell can potentially produce.|

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Post-translational modifications (e.g., phosphorylation, glycosylation, and acetylation) create protein diversity that exceeds the number of mRNAs in the transcriptome. A single mRNA can give rise to multiple protein variants through these modifications, making the proteome larger than the transcriptome. **Statement I** is true.

The proteome differs between cell types because each cell expresses a unique subset of proteins based on its specific role. For example, muscle cells express contractile proteins like actin and myosin, while neurons express neurotransmitter-related proteins. **Statement II** is true.

The proteome refers to the actual set of proteins expressed in a cell at a given time, not the total potential protein repertoire encoded by the genome. The "potential" protein repertoire would encompass all proteins that could be produced by the genome, which is not the definition of the proteome. **Statement III** is false.

**Choice C** is the correct answer as it includes only the true **Statements I** and **II**.

**Choices A** and **B** are incorrect as they are missing one of the true statements. **Choice D** is incorrect as it includes the false **Statement III**.
