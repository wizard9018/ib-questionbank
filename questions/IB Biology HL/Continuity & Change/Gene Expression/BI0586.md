# BI0586

Which of the following best defines the term “Proteome”?

- A. $\hspace{1em}$ The total number of protein molecules present in a cell, tissue, or organism

- B. $\hspace{1em}$  The complete set of amino acids required to build proteins in a cell, tissue or organism, regardless of conditions
- C. $\hspace{1em}$ The complete set of genes present in the genome of a cell, tissue, or organism
- D. $\hspace{1em}$ The complete set of proteins expressed by a cell, tissue, or organism at a particular time and under specific conditions

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because the proteome is the complete set of proteins expressed by a cell, tissue, or organism at a particular time and under specific conditions. It can vary between cell types and change in response to conditions, because different proteins are expressed at different times.

**Choice A** is incorrect because this describes the total quantity of protein molecules, rather than the complete set of proteins expressed. The proteome concerns which proteins are present, not simply how many protein molecules there are.

**Choice B** is incorrect because this describes amino acids, which are the building blocks of proteins, rather than proteins themselves. The proteome is the set of proteins expressed, not the set of amino acids required to make them.

**Choice C** is incorrect because this describes the genome, which is the complete set of genetic material in a cell or organism. The proteome is the set of proteins expressed, not the set of genes.
