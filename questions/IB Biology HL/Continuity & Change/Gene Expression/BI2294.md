# BI2294

Which of the following contribute(s) to the differences between the transcriptome and proteome?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | RNA processing |
    | II. | Protein modification |
    | III. | Gene expression patterns |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
multiple different mRNA molecules from a single gene. These different mRNA molecules may result in the production of different proteins, contributing to differences between the transcriptome (the set of all mRNA molecules) and the proteome (the set of all proteins). **Statement I** is true.

Post-translational modifications alter the structure and function of proteins without affecting the transcriptome. This is a key factor contributing to the diversity of the proteome compared to the transcriptome. **Statement II** is true.

Gene expression patterns dictate which genes are transcribed into mRNA and, subsequently, which proteins are produced. Differences in gene expression across cell types lead to variations in both the transcriptome and proteome. **Statement III** is true.

**Choice D** is correct as it includes all the true **Statements** (**I, II** and **III**).

**Choices A, B** and **C** are all incorrect as they are missing one or more of the true statements.
