# BI2452

Which row is correct for genome, transcriptome, and proteome in a cell?

| | Genome | Transcriptome | Proteome |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | The genes in the nucleus | The genes that are transcribed | The proteins that the genes code for |
| B.$\hspace{1em}$ | All of the genetic information | The genes that can be transcribed | The entire set of proteins produced |
| C.$\hspace{1em}$ | The full set of transcribed mRNAs | All of the genetic information | The entire set of proteins produced |
| D.$\hspace{1em}$ | All of the genetic information | The full set of transcribed mRNAs | The entire set of proteins produced |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because these are the correct definitions. The genome consists of all of a cell's genetic material, including genes in the nucleus, mitochondria, and (in plants) chloroplasts. The transcriptome refers to all of the mRNA molecules transcribed from DNA in a given cell at a specific time. Not all genes are transcribed, and the transcriptome varies between cell types. The proteome is the complete set of proteins synthesized in a cell, which depends on the transcriptome and post-translational modifications.

**Choice C** is incorrect because the definitions for genome and transcriptome are incorrect. **Choice A** is incorrect because the genome includes genes in the mitochondria and chloroplasts. The transcriptome is not the genes that are transcribed, it is the strands of mRNA produced by transcription. The proteome is only the proteins that are produced by a cell, not all of the proteins that the genome has instructions for. **Choice B** is incorrect because the transcriptome is not the genes that can be transcribed, it is the mRNA strands that are produced by transcription.
