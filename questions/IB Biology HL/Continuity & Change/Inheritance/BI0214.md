# BI0214

Two individuals, heterozygous for a specific trait, were crossed in an experiment. Which row shows the expected phenotypic ratios of the offspring resulting from this cross?

| | Offspring phenotypes | Ratio |
| :-: | :-: | :-: |
| $\hspace{1em}$A.$\hspace{1em}$| All dominant | 1 |
|$\hspace{1em}$B.$\hspace{1em}$ | Dominant: Recessive | 1:1 |
| $\hspace{1em}$C.$\hspace{1em}$ | Dominant: Recessive | 3:1 |
| $\hspace{1em}$D.$\hspace{1em}$ | Dominant: Recessive | 1:3 |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Example:

- Parent 1 Genotype - Rr (heterozygous)
- Parent 2 Genotype - Rr (heterozygous)
- Gametes - R & r

| | R | r |
| :-: | :-: | :-: |
| $\hspace{.5em}$R$\hspace{.5em}$| $\hspace{.5em}$RR$\hspace{.5em}$ | $\hspace{.5em}$Rr$\hspace{.5em}$ |
|$\hspace{.5em}$r$\hspace{.5em}$ | $\hspace{.5em}$Rr$\hspace{.5em}$ | $\hspace{.5em}$rr$\hspace{.5em}$ |

The expected phenotypic ratio would be 3:1. Three individuals would display the dominant trait, as 3 of the possible combinations of alleles contain the dominant allele. One individual would display the recessive trait, as only one of the possible combinations of alleles contains two copies of the recessive trait.
