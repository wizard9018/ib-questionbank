# BI1190

A biological male with red-green colourblindness and a biological female without red-green colourblindness have a biologically female child without red-green colourblindness. What are the possible genotypes of this child?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | X:sup[B]X:sup[B] |
    | II. | X:sup[b]X:sup[b] |
    | III. | X:sup[B]X:sup[b] |

- A.$\hspace{1em}$ II only

- B.$\hspace{1em}$ I and II

- C.$\hspace{1em}$ III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Red-green colour blindness is a sex-linked recessive disorder carried on the X chromosome, X:sup[b]. Since biological males only receive one copy of the X chromosome, a biological male with red-green colour blindness must have the recessive X:sup[b] allele. A biological female without red-green colour blindness could be either homozygous dominant (X:sup[B]X:sup[B]) or heterozygous (X:sup[B]X:sup[b]). The biologically female child must inherit the biological father’s recessive allele, so will have one X:sup[b] allele (**Statement II** and **Statement III**). Since the child does not have red-green colour blindness, they must have inherited the dominant, X:sup[B], allele from the biological mother (**Statement II**). Therefore, the only possible genotype for the child is X:sup[B]X:sup[b] (**Choice C**).
