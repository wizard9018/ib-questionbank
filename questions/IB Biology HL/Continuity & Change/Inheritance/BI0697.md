# BI0697

Which of these traits is an example of continuous variation?

-    A. $\hspace{1em}$ Blood type

-    B. $\hspace{1em}$ Eye colour
-    C. $\hspace{1em}$ Adult height
-    D. $\hspace{1em}$ Colour blindness

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Continuous variation is when a particular characteristic shows a large range of phenotypes. **Choice C** is correct.

**Choices A**, **B** and **D** are incorrect as they are all examples of discrete/discontinuous variation, which is when a particular characteristic falls into distinct categories.
