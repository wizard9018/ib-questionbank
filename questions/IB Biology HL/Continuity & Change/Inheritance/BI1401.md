# BI1401

Corn snakes (*Pantherophis guttatus*) are popular pets. In this species, separate genes determine red and black colouration. A dihybrid cross is performed and the results are found in the table below. What can be concluded from this data?

| Phenotype | Number of offspring |
| :-: | :-: |
| No pigment | 0 |
| Red pigment only | 5 |
| Black pigment only | 3 |
| Red and black pigment  | 12 |
|  | N = 20 |

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | The alleles for red and black pigment are dominant. |
    | II. | One parent was black and one parent was red.|
    | III. | The phenotypic ratios suggest that gene linkage is present. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The question tells us that different genes control black and red pigments, and the data indicates that an individual with both black and red colouration is much more common than those that are just red, just black, or lacking pigmentation altogether. This suggests that the alleles for black and red colouration are dominant, or co-dominant, so **Statement I** is true. Since a dihybrid cross was performed and the red colouration is carried on a separate gene to the black colouration, both parents must be red and black. **Statement II** is false.

|  |  |
| :-- | :-- |
| R - allele for red colouration | r - allele for no colouration |
| B - allele for black colouration | b - allele for no colouration |

Dihybrid cross (heterozygous parents): RrBb $\times$ RrBb

| | RB | Rb | rB | rb |
| --- | :-: | :-: | :-: | :-: |
| **RB** | RRBB | RRBb | RrBB | RrBb |
| **Rb** | RRBb | RRbb | RrBb | Rrbb |
| **rB**| RrBB | RrBb | rrBB | rrBb |
| **rb** | RrBb | Rrbb | rrBb |rrbb |

Phenotypic outcomes:\
9 red and black pigment (RRBB, RrBb, RRBb, RrBB)\
3 red pigment only (RRbb, Rrbb)\
3 black pigment only (rrBB, rrBb)\
1 no pigment (rrbb)

For a non-linked dihybrid cross, the typical phenotypic ratios would be 9:3:3:1, however, the sample size given in this question is far too small to indicate whether or not gene linkage exists for these traits. **Statement III** would also be false. Therefore **Choice A** is correct.

**Choices B, C**, and **D** are incorrect because they include one or more untrue statements.
