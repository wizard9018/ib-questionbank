# BI0078

Which of these statements are true for alleles?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Alleles are versions of a gene |
  | II. | Alleles differ by one or more base |
  | III. | Alleles affect the same characteristic |

- A.$\hspace{1em}$ I and II

- B.$\hspace{1em}$ I only

- C.$\hspace{1em}$ I, II and III

- D.$\hspace{1em}$ II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Alleles are versions of a gene. Each allele represents a different form or variant of the same gene; **Statement I** is true.

Alleles differ by one or more bases. Variations between alleles are due to differences in the nucleotide sequence of the DNA; **Statement II** is true.

Alleles affect the same characteristics. Since they are different forms of the same gene, they contribute to variations in the expression of a particular characteristic e.g. I:sup[A], I:sup[B], and  i  are versions of the gene for blood groups; **Statement III** is true.

**Choice C** is therefore the correct answer to the question.

**Choices A, B** and **D** are not correct as they are all missing one or more true statements.
