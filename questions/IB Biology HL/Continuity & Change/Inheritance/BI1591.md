# BI1591

In chickens (*Gallus gallus domesticus*), the comb is a red crest at the top of the head. Comb type is primarily controlled by two genes, both exhibiting simple dominance. A flock of 144 chickens was produced from a single breeding pair heterozygous for both comb genes. A chi-square test was carried out to determine whether gene linkage between comb genes exists. The results are summarised in the table.

![BI1591i](images/BI1591i.png)

What can be concluded based on the results of the chi-square test at a probability of 0.05?

- A.$\hspace{1em}$ Accept alternative hypothesis, gene linkage is significant.

- B.$\hspace{1em}$ Accept null hypothesis, gene linkage is significant.

- C.$\hspace{1em}$ Accept alternative hypothesis, gene linkage is not significant.

- D.$\hspace{1em}$ Accept null hypothesis, gene linkage is not significant.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because the chi-square value of 8.33 exceeds the critical value for a 0.05 significance level with three degrees of freedom (7.82). This indicates that there is a 95% chance that the difference between the observed and expected values is not due to chance, meaning we must accept the alternative hypothesis, which suggests that there is evidence of gene linkage.

**Choice B** is incorrect because we would reject the null hypothesis, which is that the difference between the observed and expected values are simply due to chance. **Choice C** is incorrect because accepting the alternative hypothesis suggests that gene linkage is occurring. **Choice D** is incorrect because we would reject the null hypothesis based on the chi-square value obtained, suggesting significant gene linkage
