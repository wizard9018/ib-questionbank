# BI1241

Which of the following are hypotheses for the presence of highly conserved sequences in genes?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | The sequences are important for the survival of the organisms |
    | II. | The sequences have a lower rate of mutation |
    | III. | The sequences only code for proteins |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Highly conserved sequences are DNA sequences that have remained relatively unchanged far up the phylogenetic tree, indicating that they have been maintained by natural selection. **Choice B** is correct as these sequences are often important for an organism's survival (Statement I) and may be involved in processes such as cell stability, reproduction or metabolism. These sequences have been shown to have a lower rate of mutation (Statement II) as compared to other sequences, which allows them to remain relatively stable over time.

**Choices C**  and **D**  are incorrect as highly conserved sequences can be both coding and non-coding (Statement III). **Choice A**  is incorrect as it only includes statement I.
