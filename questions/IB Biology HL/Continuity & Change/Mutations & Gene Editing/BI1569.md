# BI1569

Which of the following statements regarding sickle cell anaemia is/are true?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. |  It is caused by a deletion mutation that removes glutamic acid from the amino acid sequence. |
    | II. | It affects the structure of membrane proteins on the surface of the red blood cell. |
    | III. | It causes haemoglobin to form tight bundles under low oxygen conditions.  |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ III only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice B** is correct because sickle cell disease is caused by a base substitution that changes glutamic acid to valine. This results in a change to the haemoglobin molecule that causes it to form tight chains or bundles under low oxygen conditions (**Statement III**), leading to the formation of sickle-shaped red blood cells.

**Statement I** is false because sickle cell anaemia is caused by a base substitution, not a deletion. **Statement II** is false because the HbS allele, which causes sickle cell anaemia, does not affect membrane proteins. **Choices A, C**, and **D** are incorrect because they contain one or more false statements.
