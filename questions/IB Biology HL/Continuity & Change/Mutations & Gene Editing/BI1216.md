# BI1216

Which row correctly shows a potential advantage and disadvantage of the widespread use of CRISPR-Cas9 technology?

| | Advantage | Disadvantage |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Stop the translation of defective proteins | Study the function of genes |
| B.$\hspace{1em}$ | Quickly create animal models | Off-target mutations |
| C.$\hspace{1em}$ | Loss of diversity | Unpredictable effects on future generations |
| D.$\hspace{1em}$ | Can be used to target and destroy cancer cells | Treat genetic diseases |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
CRISPR-Cas9 can be used to quickly knockout genes in animal embryos, which can be used to rapidly create animal models. However, using CRISPR-Cas9 technology can result in off-target mutations as molecular pathways are complex and knock-on effects cannot always be predicted, or Cas9 may act on the wrong target site leading to unintended consequences. **Choice B**  is correct.

Studying the function of genes is an advantage of CRISPR-Cas9 technology, not a disadvantage; **Choice A**  is incorrect. Loss of diversity can occur if CRISPR-Cas9 is used for non-therapeutic reasons or aesthetic reasons, so the loss of diversity is a disadvantage of the technology; **Choice C** is incorrect. CRISPR-Cas9 can be used to treat genetic diseases by repairing mutations in cells or destroying faulty genes. This is an advantage of CRISPR-Cas9 technology so **Choice D**  is incorrect.
