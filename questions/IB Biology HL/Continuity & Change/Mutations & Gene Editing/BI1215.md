# BI1215

Which of the following does CRISPR-Cas9 have a **direct** effect on?

- A.$\hspace{1em}$ Genome

- B.$\hspace{1em}$ Transcriptome

- C.$\hspace{1em}$ Proteome

- D.$\hspace{1em}$ Epigenome

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The genome is the complete set of genes present in an organism. **Choice A** is correct, as CRISPR-Cas9 can be used to directly edit genes by cutting out or replacing DNA sequences.

The transcriptome is the complete set of RNA molecules transcribed from the genome in a particular cell or tissue at a given moment. CRISPR-Cas9 does not directly target RNA so **Choice B** is incorrect. The proteome is all of the proteins expressed in an organism, CRISPR-Cas9 does not directly target proteins; **Choice C** is incorrect. The epigenome is all of the modifications on top of DNA that regulate the expression of genes, CRISPR-Cas9 does not directly target the epigenome; **Choice D**  is incorrect.
