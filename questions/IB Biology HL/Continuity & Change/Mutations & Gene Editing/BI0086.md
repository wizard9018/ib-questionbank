# BI0086

**Maximum mark: 5**

Different species of living organisms have different numbers of genes characteristic to them. The table shows the estimated number of genes for five species.

| Species | Estimated number of genes |
| :-- | :-- |
| *Escherichia coli* (bacteria species) | 4,000 |
| *Drosophila melanogaster* (fruit fly) | 13,000 |
| *Canis lupis familiaris* (dog) | 20,000 |
| *Homo sapiens* (humans) | 30,000 |
| *Oryza sativa* (rice) | 40,000 |

1. Using the information in the table deduce the estimated number of loci in a human genome. [1 mark]

2. Explain how a mutation can affect a characteristic. [4 marks]

---

## 评分标准 / Mark scheme

1.
$\hspace{1em}$ $\ce{ -> }$ Estimated number of loci in a human is 30,000 [1 mark]
[1 mark]

$\hspace{1em}$ :u[Sample answer]:

$\hspace{1em}$ Each gene has a specific location (locus), therefore for an estimated 30,000 genes, the **estimated number of** **loci in a human is 30,000** ($\checkmark$).

2. Any **four** of the following:

    $\ce{ -> }$ a mutation is a change in the base sequence of a gene [1 mark]

    $\ce{ -> }$ the base sequence determines the sequence of amino acids in a protein [1 mark]

    $\ce{ -> }$ if the base sequence changes, it might cause a change in the sequence of amino acids [1 mark]

    $\ce{ -> }$ a change in the sequence of amino acids produces a protein that has different properties (shape and function)  [1 mark]

    $\ce{ -> }$ proteins may not function correctly **OR** could cause harm **OR** some mutations cause cancer    [1 mark]

    **Example (or any other valid example, one mark for cause and one mark for effect):**

    $\ce{ -> }$ the allele for sickle cell anaemia is caused by a single base substitution mutation from codon GAG to GTG    [1 mark]

    $\ce{ -> }$ causes valine **OR** Val to be translated in place of glutamic acid **OR** Glu which causes haemoglobin to polymerize. [1 mark]
[4 marks]

    :u[Sample answer]:

    A **mutation is a change in the base sequence of a gene** ($\checkmark$). The sequence of bases **determines the sequence of amino acids in the protein** ($\checkmark$) that is produced by a gene. If the altered sequence of bases changes the sequence of amino acids, it will **produce a protein that has different properties, e.g.** changing **the shape and function of the protein** ($\checkmark$). **Some mutations cause cancer** ($\checkmark$) by affecting the rate of cell division. The sickle-cell allele is caused by **a single base substitution mutation** ($\checkmark$). This single base substitution changes one amino acid in haemoglobin; valine **is translated in place of glutamic acid** ($\checkmark$).
