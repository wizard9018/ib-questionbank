# BI2341

The diagram shows a section of one DNA strand before and after a mutation. Which term(s) describe this mutation?

| $\ce{Before mutation}:$ | $\ce{GTC GAG TCT AGC GCT ATC GCT}$|
| :-- | :-: |
| After mutation : | GTC GAG TCT AAG CGC TAT CGC T |

- :::tableoptions{col1="hide" col2="hide"}
 | | |
 | :-- | :-- |
 | I. | Frameshift |
 | II. | Deletion |
 | III. | Insertion|

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

| $\ce{Before mutation}:$ | $\ce{GTC GAG TCT AGC GCT ATC GCT}$|
| :-- | :-: |
| After mutation : | GTC GAG TCT A**A**G CGC TAT CGC T |

**Choice C** is correct because adding one base to this sequence is an insertion (**Statement III**). This insertion causes the genetic code to not be divisible by three, so the reading frame of the strand is shifted (**Statement I**).

Deletion removes one or more bases from the DNA sequence; **Statement II** is false.

**Choice A** is incorrect because it is missing one true statement. **Choices B** and **D** are incorrect because **Statement II** is not true.
