# BI1146

The sequence of nucleotides in a section of DNA is as follows:

ATGGCTACCTGT

Which of the following mutations would represent a substitution?

- A.$\hspace{1em}$ ATGGCTACTGT

- B.$\hspace{1em}$ ATGGCCTACCTGT

- C.$\hspace{1em}$ ATGGCACCTGT

- D.$\hspace{1em}$ ATGGCCACCTGT

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The sequence for **Choice D** contains the same number of bases as the original, but a cytosine has replaced thymine at position six, making this a substitution.

**Choices A** and **C** cannot be correct since they have each lost one base, and so represent deletions. **Choice B** cannot be correct since it has gained one base, and so represents an insertion.
