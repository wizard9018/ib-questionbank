# BI1346

What type of mutation is being shown in the diagram?

![1346i](images/1346i.png)

- A.$\hspace{1em}$ Substitution

- B.$\hspace{1em}$ Deletion

- C.$\hspace{1em}$ Insertion

- D.$\hspace{1em}$ Frame shift

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because the diagram shows thymine being replaced by guanine. This is a base substitution, which does not change the length of the gene.

A deletion removes one or more nucleotides from a gene, and an insertion adds one or more nucleotides. Both change the number of bases in the gene, which the diagram doesn't show. **Choices B** and **C** are therefore incorrect.

**Choice D** is incorrect because a frameshift happens when an insertion or deletion of a number of bases that isn't a multiple of three moves the reading frame, so every codon after that point changes. A substitution changes only one codon and leaves the reading frame unchanged.
