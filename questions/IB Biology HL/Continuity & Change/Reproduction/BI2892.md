# BI2892

Which of the following best describes the involvement of both sperm and egg chromosomes in fertilisation?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Both sperm and egg chromosomes undergo mitosis immediately after the sperm enters the egg. |
    | II. | The sperm chromosomes fuse with the egg chromosomes to restore the diploid chromosome number. |
    | III. | The sperm tail and mitochondria provide energy for the fusion of chromosomes. |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is false because mitosis occurs after fertilisation, not immediately after the sperm enters the egg. The sperm and egg chromosomes first fuse to restore the diploid chromosome number, and mitosis begins later for cell division.

**Statement II** is  true because after the sperm nucleus enters the egg, the chromosomes from both the sperm and egg combine. This fusion of genetic material forms a diploid zygote, which contains a complete set of chromosomes (half from each parent).

**Statement III** is false because the sperm’s mitochondria and tail are discarded during fertilisation. The tail is used for mobility, but it does not contribute to the embryo, and the mitochondria are typically not involved in the fusion process.

**Choice B** is correct because includes the only true **Statement II**.

**Choices A, C** and **D** are all incorrect because they include one or more of the false **Statements I** and **III**.
