# BI0659

Home pregnancy tests test for hCG in urine. Which of these binds to hCG?

-    A. $\hspace{1em}$ Monoclonal antibodies

-    B. $\hspace{1em}$ Hybridoma cells
-    C. $\hspace{1em}$ Progesterone
-    D. $\hspace{1em}$ Oxytocin

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because monoclonal antibodies in home pregnancy tests bind with hCG. **Choice B** is incorrect because hybridoma cells produce the monoclonal antibodies used in home pregnancy tests. **Choices C** and **D** are incorrect because the monoclonal antibodies in home pregnancy tests do not bind with progesterone or oxytocin.
