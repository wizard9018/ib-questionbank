# BI0679

Which structure in a seed contains a food store?

-    A. $\hspace{1em}$ Radicle

-    B. $\hspace{1em}$ Plumule
-    C. $\hspace{1em}$ Testa
-    D. $\hspace{1em}$ Cotyledon

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice D** is correct because food is stored in the cotyledon(s). **Choice A** is incorrect because the function of the radicle is to develop into the root of the seedling. **Choice B** is incorrect because the function of the plumule is to develop into the shoot of the seedling. **Choice C** is incorrect because the testa is the outer covering of the seed.
