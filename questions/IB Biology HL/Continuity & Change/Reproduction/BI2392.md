# BI2392

Which row of the table contains **three** correct statements about the transport of substances across the mammalian placenta?

| | Simple diffusion | Facilitated diffusion | Active transport |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | carbon dioxide | mineral ions | fatty acids |
| B.$\hspace{1em}$ | oxygen | glucose| amino acids |
| C.$\hspace{1em}$ | water | amino acids | mineral ions |
| D.$\hspace{1em}$ | antibodies | amino acids | glucose |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Oxygen and carbon dioxide cross maternal and placental membranes by simple diffusion. \
Water crosses maternal and placental membranes by osmosis. \
Fatty acids cross maternal and placental membranes by simple diffusion and facilitated diffusion (depending on the fatty acid’s chemical composition).\
Glucose and antibodies (immunoglobulin G) cross maternal and placental membranes by facilitated diffusion.\
Mineral ions and amino acids cross maternal and placental membranes by active transport.

**Choice B** is correct because it contains three correct statements.\
**Choice A** is incorrect because it only contains one correct statement (carbon dioxide).\
**Choice C** is incorrect because it only contains one correct statement (mineral ions).\
**Choice D** is incorrect because it contains three incorrect statements.
