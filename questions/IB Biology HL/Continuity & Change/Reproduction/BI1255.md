# BI1255

Which hormones are administered in hormone replacement therapy (HRT)?

| | Hormone 1 | Hormone 2 |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | Oestradiol | Progesterone |
| B.$\hspace{1em}$ | Follicle Stimulating Hormone | Luteinising Hormone |
| C.$\hspace{1em}$ | Oestradiol | Luteinising Hormone |
| D.$\hspace{1em}$ | Follicle Stimulating Hormone | Progesterone |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
During menopause, the production of progesterone and oestradiol is reduced by the ovaries. HRT is used to replace these hormones.

**Choices B, C**, and **D** are incorrect as follicle-stimulating hormone (FSH) and luteinising hormone (LH) no longer cause a response from the ovaries, so replacing them would have no effect.
