# BI2889

Which of the following statements best describes the relationship between sexual and asexual reproduction in terms of adaptation?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Asexual reproduction leads to offspring that are adapted to an existing environment. |
    | II. | Sexual reproduction results in offspring with new gene combinations, which may provide an advantage in adapting to a changed environment. |
    | III. | Asexual reproduction results in genetic diversity that allows for rapid adaptation to environmental changes. |

- A.$\hspace{1em}$ I and II

- B.$\hspace{1em}$ I and III

- C.$\hspace{1em}$ II and III

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because asexual reproduction generates genetically identical offspring, which are typically well-adapted to the existing environment. This is advantageous in stable environments but limits the potential for adaptation to new challenges.

**Statement II** is true because sexual reproduction introduces genetic diversity, resulting in offspring with new gene combinations. This genetic variation provides a significant advantage for adapting to environmental changes, which may be beneficial in fluctuating conditions.

**Statement III** is false because asexual reproduction produces offspring that are genetically identical to the parent, meaning there is little or no genetic diversity. As a result, asexual reproduction does not facilitate rapid adaptation to changing environments.

**Choice A** is, therefore, the correct answer as it only includes the two true **Statements I** and **II**.

**Choices B, C**, and **D** are all incorrect as they include the false **Statement III**.
