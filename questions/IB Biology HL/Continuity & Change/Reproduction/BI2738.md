# BI2738

Which of the following are functions of the placenta?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Oxygen and nutrient exchange |
    | II. | Removal of foetal waste products |
    | III. | Secretion of hormones to maintain pregnancy |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because the placenta enables the exchange of oxygen and nutrients between maternal and foetal blood. Oxygen and essential molecules like glucose and amino acids diffuse from the mother's blood to the foetus, supporting growth and development.

**Statement II** is true because the placenta also facilitates the removal of foetal waste products, such as carbon dioxide and urea, by transferring them into the maternal bloodstream for excretion through the mother's kidneys and lungs.

**Statement III** is true because the placenta secretes essential hormones, including human chorionic gonadotropin (hCG), progesterone, and oestrogen, which help maintain pregnancy by preventing uterine contractions and supporting the endometrium.

**Choice D** is correct because it includes all three true statements

**Choice A** is incorrect because it omits the true **Statement III**.    \
**Choice B** is incorrect because it omits the true **Statement II**.  \
**Choice C** is incorrect because it omits the true **Statement I**.
