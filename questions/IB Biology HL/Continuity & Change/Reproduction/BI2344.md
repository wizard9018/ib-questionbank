# BI2344

Self-incompatibility mechanisms in flowering plants prevent self-pollination. Which of these are advantage(s) of self-incompatibility mechanisms?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | Increased genetic diversity |
    | II. | Increased vigour |
    | III. | Increased number of offspring |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Cross-pollination introduces genetic variation, reducing the likelihood of harmful genetic combinations and increasing adaptability to environmental changes. **Statement I** is true.

Cross-pollination produces genetically different offspring, some of which will have characteristics that are better adapted to the environment than the parents and have more vigour. **Statement II** is true.

Self-incompatibility mechanisms prevent fertilisation by pollen from the same plant, but fertilisation is still possible by gametes from other plants, so the number of offspring is not directly affected by these mechanisms, **Statement III** is  false.

**Choice B** is correct because it includes only the two true **Statements I** and **II**.

**Choices A** and **C** are incorrect as they are missing one true statement. **Choice D** is incorrect because it includes the flase **Statement III**.
