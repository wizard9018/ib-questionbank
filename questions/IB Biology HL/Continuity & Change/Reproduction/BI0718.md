# BI0718

What processes are common to both oogenesis and spermatogenesis?

| | Type of cell division | Change in cell size | Metabolic process |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | Mitosis | Increase in size | Differentiation |
| B.$\hspace{1em}$ | Meiosis | Decrease in size | Apoptosis |
| C.$\hspace{1em}$ | Binary fission | No change | Generation of a polar body |
| D.$\hspace{1em}$ | Budding | Increase in size | Fertilization |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Both oogenesis and spermatogenesis involve mitosis, increase in cell size (cell growth), two meiotic divisions and differentiation. **Choice A** is correct.

**Choice B** is incorrect as it includes both apoptosis (cell death) and decrease in size, which does not occur in either process. **Choice C** is incorrect as binary fission occurs in prokaryotic cells and the generation of a polar body only occurs in oogenesis. **Choice D** is incorrect as budding only occurs in fungi, and fertilization (when mature sperm and egg cells fuse) occurs after both oogenesis and spermatogenesis.
