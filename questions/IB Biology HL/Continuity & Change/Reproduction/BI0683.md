# BI0683

Flowers produce male gametes, known as pollen, and female gametes, called ova. The diagram below shows an animal-pollinated flower.

Which row correctly matches the gametes with the structure that produces them?

![BI0683](images/BI0683.png)

| | Pollen | Ovum |
| :-: | :-: | :-: |
| $\hspace{1em}$A.$\hspace{1em}$ | Anther | Ovule |
|$\hspace{1em}$B.$\hspace{1em}$ | Anther | Stigma |
| $\hspace{1em}$C.$\hspace{1em}$ | Filament | Ovule |
| $\hspace{1em}$D.$\hspace{1em}$ | Filament | Style |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because pollen is produced by the anther and the ovum (plural: ova) is produced by the ovule, found inside the ovary. **Choice B** is incorrect because the stigma is where pollen lands. **Choice C** is incorrect because the filament supports the anther and does not produce pollen. **Choice D** is incorrect because the filament supports the anther and the style is the part of the flower that the pollen passes through.
