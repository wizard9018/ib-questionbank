# BI1062

Which row shows the correct functions for follicle stimulating hormone (FSH), luteinizing hormone (LH) and progesterone?

| | FSH | LH | Progesterone |
| --- | :-: | :-: | :-: |
| A.$\hspace{1em}$ | Stimulates development of follicles | Stimulates ovulation | Maintains endometrium |
| B.$\hspace{1em}$ | Stimulates development of follicles | Stimulates ovulation | Repairs endometrium |
| C.$\hspace{1em}$ | Stimulates the release of progesterone | Stimulates release of oestradiol | Maintains endometrium |
| D.$\hspace{1em}$ | Stimulates release of egg | Stimulates release of oestradiol | Repairs endometrium |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because FSH stimulates the development of follicles, LH stimulates ovulation and progesterone maintains the endometrium. **Choice B** is incorrect because progesterone does not cause the repair of the endometrium. **Choice C** is incorrect because FSH does not stimulate the production of progesterone and LH does not stimulate the release of oestradiol. **Choice D** is incorrect because FSH does not stimulate the release of an egg, LH does not stimulate the release of oestradiol, and progesterone does not repair the endometrium.
