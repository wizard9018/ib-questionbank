# BI2736

The figure below shows a home pregnancy test strip.

![BI2736](images/BI2736.png)

Which of the following is correct regarding the result of the test?

- A.$\hspace{1em}$ It is positive because the hCG in the urine is bound to mobile antibodies, allowing them to be captured at the test line.

- B.$\hspace{1em}$ It is negative because the presence of a test line only confirms that antibodies are functional, not that hCG is present.

- C.$\hspace{1em}$ It is negative because hCG must bind to the control line for a positive result.

- D.$\hspace{1em}$ It is positive because the mobile antibodies always bind to the test line, regardless of hCG presence.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice A** is correct because hCG in the urine binds to mobile monoclonal antibodies, which carry a colour-changing enzyme. As these antibody–hCG complexes move along the strip, they are captured by immobilised antibodies at the test line, producing a visible line that indicates a positive result.

**Choice B** is incorrect because the test line only appears if hCG is present, not just because antibodies are functional.\
**Choice C** is incorrect because the control line binds excess mobile antibodies but does not detect hCG presence. This is because it contains immobilised antibodies that bind to mobile antibodies regardless of hCG presence.\
**Choice D** is incorrect because mobile antibodies only bind at the test line if hCG is present. Without hCG, they pass by and only bind at the control line.
