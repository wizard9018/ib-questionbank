# BI0729

**Maximum mark: 3**

Describe how the egg cell protects itself from polyspermy. [3 marks]

---

## 评分标准 / Mark scheme

Any **three** of the following:

$\ce{->}$ polyspermy is when more than one sperm fertilizes an egg     [1 mark]

$\ce{->}$ when the sperm fuses with the egg, the egg becomes activated [1 mark]

$\ce{->}$ cortical granules **OR** vesicles near the egg membrane release enzymes     [1 mark]

$\ce{->}$ enzymes digest binding proteins  [1 mark]

$\ce{->}$ zona pellucida hardens [1 mark]
[3 marks]

$\underline{\textrm{Sample answer}}$: \
Polyspermy is when **more than one sperm fertilises an egg** ($\checkmark$). When the sperm fuses with the egg, the **egg becomes activated** ($\checkmark$), so that **cortical granules release enzymes** ($\checkmark$) which **digest binding proteins** ($\checkmark$) and also result in the **hardening of the zona pellucida** ($\checkmark$), which prevents any more sperm from fusing with the egg.
