# BI1337

During DNA replication, in which direction does DNA polymerase move along the template strand and in which direction is the new strand synthesised on the leading strand?

| | Direction that DNA polymerase moves in | Direction that the new strand is synthesised in |

| :-: | :-: | :-: |

| $\hspace{1.5em}$A.$\hspace{1.5em}$| 3' to 5' | 5' to 3' |

| $\hspace{1.5em}$B.$\hspace{1.5em}$ | 5' to 3' | 5' to 3' |

| $\hspace{1.5em}$C.$\hspace{1.5em}$  | 5' to 3' | 3' to 5 |

| $\hspace{1.5em}$D.$\hspace{1.5em}$ | 3' to 5' | 3' to 5' |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

DNA polymerase is an enzyme which attaches to the template strand to enable DNA replication. It requires a 3'-OH group to start the synthesis of a new DNA strand, and it adds the 5' end of a DNA nucleotide to the 3' end of a strand of nucleotides. This means it needs to move along the template strand in the 3' to 5' direction to synthesise the new strand in the 5' to 3' direction. **Choice A**  is correct.

**Choices B and D** are incorrect as DNA strands in a double helix run antiparallel to each other, so DNA polymerase cannot move along the template strand in the same direction that the new strand is synthesised in. **Choice C**  is incorrect as the enzyme cannot add new nucleotides to the 5' end of the new DNA strand.
