# BI0089

Which of these answers is true in relation to the polymerase chain reaction?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | High temperatures are used |
  | II. | It produces exact copies of a segment of DNA |
  | III. | It uses *Taq* polymerase |

- A.$\hspace{1em}$ I, II and III

- B.$\hspace{1em}$ I and III

- C.$\hspace{1em}$ II only

- D.$\hspace{1em}$ I and II

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The Polymerase Chain Reaction is used to amplify a  specific DNA segment (**Statement II**). High temperatures are used (**Statement I**)  to separate the two complementary DNA strands during denaturation. A heat-resistant Taq polymerase (**Statement III**) allows replication to proceed at an optimal temperature. **Choice A**  is correct because all three statements are true.

**Choices B, C** and **D** are incorrect as they are missing one or more true statements.
