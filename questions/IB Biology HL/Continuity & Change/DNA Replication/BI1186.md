# BI1186

Which of these statement(s) is/are correct concerning the Polymerase Chain Reaction (PCR)?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | It creates RNA copies of DNA |
    | II. | It uses a special DNA polymerase that can withstand high temperatures |
    | III. | It requires helicase to work |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
PCR requires high temperatures to separate the strands of the DNA molecule. Therefore, it requires a heat resistant DNA polymerase (Taq polymerase) to work (**Statement II**). **Choice B**  is correct.

During PCR, DNA is amplified to make many copies of DNA, not RNA, **Statement I**  is incorrect. The PCR reaction does not require DNA helicase to work, **Statement III**  is incorrect. **Choices A, C**  and **D**  are incorrect as they include **Statement I** and/or **Statement III**.
