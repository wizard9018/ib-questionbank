# BI1396

Which of the following correctly describes the components needed in the polymerase chain reaction (PCR)?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | The enzyme Taq polymerase is needed because it functions at low temperatures. |
    | II. | A supply of nucleotides is required to build new DNA sequences. |
    | III. | Primers are needed to specify the DNA sequences to be copied. |

- A.$\hspace{1em}$ III only

- B.$\hspace{1em}$ I and II only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
Taq polymerase is used in PCR because it continues to function efficiently even at high temperatures, not low temperatures as **Statement I** suggests. A large supply of nucleotides is necessary to build copies of the target DNA sequence as PCR can create millions or even billions of target sequences (**Statement II**). Primers are added to the reaction to allow Taq polymerase to initiate replication of the target DNA segment (**Statement III**). **Choice C** is, therefore, correct.

**Choice A** is incorrect because it does not include **Statement II**. **Choice B** is incorrect because it does not include **Statement III**. **Choice D** is incorrect because it includes **Statement I**.
