# BI1338

The diagram shows a replication fork during DNA replication. Which letter represents the leading strand?

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

DNA replication occurs simultaneously on both template strands. The leading strand is synthesised continuously in the same direction as replication fork movement, while the lagging strand is synthesised discontinuously as Okazaki fragments.

In the diagram, **Choice C** represents an Okazaki fragment on the lagging strand, so it is not the correct answer. **Choice B** represents the continuously synthesised leading strand, so it is the correct answer.

**Choices A** and **D** represent template strands, not newly synthesised DNA, so they are incorrect.
