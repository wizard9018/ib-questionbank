# BI2722

Which of the following processes require DNA replication?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | A skin cell dividing to replace damaged tissue |
    | II. | A fertilised egg undergoing its first round of mitosis |
    | III. | An *Escherichia coli* bacterium dividing in the gut |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and II

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is true because it describes mitosis. Before mitosis occurs, the cell must replicate its DNA so that both daughter cells receive a complete copy of the genetic material. \
**Statement II** is true because after fertilisation, the single-celled zygote must divide and grow into a multicellular organism. This requires DNA replication so that each new cell formed from mitosis gets an identical copy of the genome. \
**Statement III** is true; bacteria reproduce through binary fission, a process in which the bacterial chromosome is replicated and then distributed into two daughter cells.\
**Choice D** is, therefore, correct as **Statements I, II**, and **III** are true.
