# BI0317

Tandem repeats are non-coding regions of DNA which are used in DNA profiling. An example of the application of DNA profiling would be in paternity testing. The diagram below shows two chromosomal regions with tandem repeats obtained from a child.

| Locus A

| :-

| :br

| ACTACTACTACT

| :br

| ACTACTACTACTACT

| :br

| **Locus B**

| :br

| GCGCGCGCGCGC

| :br

| GCGCGC

$\small{\textrm{[\copyright\ 2022]}}$

Which of the following individuals could be a paternal match to the child?

| | $\hspace{3em}$ Locus A $\hspace{3em}$ | $\hspace{3em}$ Locus B $\hspace{3em}$ |

| :-: | :-: | :-: |

| $\hspace{1.5em}$ A. $\hspace{1.5em}$ | ACTACTACT | GCGCGC |

| | ACTACTACT | GCGCGC |

| :br

| $\hspace{1.5em}$ B. $\hspace{1.5em}$ | ACTACTACTACT | GCGCGCGC |

| | ACTACTACT | GCGCGCGCGC |

| :br

| $\hspace{1.5em}$ C. $\hspace{1.5em}$ | ACTACTACTACT | GCGCGC |

| | ACTACTACTACT | GCGCGCGCGC |

| :br

| $\hspace{1.5em}$ D. $\hspace{1.5em}$ | ACTACTACT | GCGC |

| | ACTACTACT | GCGCGCGCGC |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

The sequence of the tandem repeat found in the two alleles of the child are:\

Locus A - ACT sequence \

Allele 1 $-$ 4 repeats\

Allele 2 $-$ 5 repeats

Locus B $-$ GC sequence\

Allele 1 $-$ 6 repeats\

Allele 2 $-$ 3 repeats

One allele came from mother and one from father, potential parents have to be a match for at least one out of two alleles at each locus.

The closest paternal match to the child would be **Choice C**, because this individual has 4 repeats on locus A and 3 repeats on locus B.

**Choice A** is not a match, because it has 3 repeats on locus A.\

**Choice B** is not a match, because it has 4 and 5 repeats on locus B.\

**Choice D** is not a match, because it has 3 repeats on locus A.
