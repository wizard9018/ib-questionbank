# BI2717

The diagram below shows a DNA nucleotide bonded to an RNA primer. The dotted lines indicate possible locations for the addition of a new DNA nucleotide during replication.

Which dotted line correctly represents the site where the next nucleotide will be incorporated?

![eDIT2717](images/eDIT2717.png)

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Choice C** is correct because during DNA replication nucleotides are added to the 3' end of the growing strand from an RNA primer, which provides a hydroxyl group for DNA polymerase to extend the strand.\
**Choice A** is incorrect because it is part of the parent strand. **Choice B** is incorrect because a new nucleotide will not be added to a nitrogenous base. **Choice D** is incorrect because a new nucleotide will not attach to the 5' end.
