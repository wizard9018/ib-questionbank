# BI1339

Which of the following is/are a role of DNA polymerases during DNA replication?

- :::tableoptions{col1="hide" col2="hide"}

  | | |

  | :-- | :-- |

  | I. | Creates one RNA primer on the leading strand  |

  | II. | Synthesises the new DNA strand starting from the DNA primer |

  | III. | Builds Okazaki fragments on the lagging strand |

- A.$\hspace{1em}$ I and II only 

- B.$\hspace{1em}$ II only 

- C.$\hspace{1em}$ III only 

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \

**Statement I**  is false because DNA polymerases do not create RNA primers on the leading strand; this is the role of RNA primase. 

**Statement II** is false because, although DNA polymerases synthesise the new DNA strand, they start from an RNA primer, not a DNA primer. 

**Statement III** is true as DNA polymerase III adds nucleotides to RNA primers on the lagging strand, forming short stretches of DNA, called the Okazaki fragments. These are later joined by DNA ligase, but the synthesis of the fragments is indeed carried out by DNA polymerase III.

 

**Choice C**  is correct as it only includes the one true **Statement III**.

 **Choices A, B** and **D**  are incorrect, as they include one or both of the false **Statements I** and **II**.
