# BI2718

Which of the following statements accurately describe(s) DNA replication on the lagging strand?

- :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :-- | :-- |
    | I. | DNA is synthesised continuously in the 5’ to 3’ direction|
    | II. | Multiple RNA primers are required |
    | III. | DNA polymerase III catalyses the synthesis of new DNA |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and III only

- D.$\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
**Statement I** is false because on the lagging strand,  DNA is synthesised discontinuously in short segments called Okazaki fragments, not continuously.\
**Statement II** is true because multiple RNA primers are needed to initiate synthesis of each fragment.\
**Statement III** is true because DNA polymerase III catalyses the synthesis of new DNA on both strands.

**Choice B** is, therefore, correct as only **Statements II** and **III** are true. **Choices A, C** and **D** are incorrect as they include the false **Statement I**.
