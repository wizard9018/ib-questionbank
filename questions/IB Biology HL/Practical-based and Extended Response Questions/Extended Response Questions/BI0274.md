# BI0274

**Maximum mark: 16**

1. Outline how mitochondrial DNA can be used to construct a cladogram.     [4 marks]

2. Explain why organisms classified in the past may be reclassified. [4 marks]

3. Compare and contrast cladograms made using molecular evidence and structural evidence. [8 marks]

---

## 评分标准 / Mark scheme

1.    any **four** of the following:

    $\ce{ -> }$ mitochondrial DNA from different organisms can be sequenced [1 mark]

    $\ce{ -> }$ mutations occur at a roughly constant rate **OR** can act as a molecular clock [1 mark]

    $\ce{ -> }$ the lower the number of differences in the base sequence between organisms, the more closely related the organisms are [1 mark]

    $\ce{ -> }$ the number of differences in the base sequence can be used to determine how long ago species diverged from a common ancestor [1 mark]

    $\ce{ -> }$ which can be used to deduce where the nodes are on cladograms [1 mark]

    [4 marks]

    $\underline{\textrm{Sample Answer}}$: \
Sections of mitochondrial DNA from **different organisms can be sequenced** ($\checkmark$), which allows scientists to observe differences in the base sequence. The **lower the number of differences** in the base sequence between organisms, the **more closely related** the organisms are ($\checkmark$). The **number of differences** in the sequence of mitochondrial DNA can also be used to determine **how long ago species diverged** from a common ancestor ($\checkmark$), which can be used to deduce **position of nodes** on cladograms ($\checkmark$).

2.    any **four** of the following:

    $\ce{ -> }$ organisms (used to be) classified based on shared anatomical characteristics **OR** structures **OR** physical features [1 mark]

    $\ce{ -> }$ shared anatomical characteristics **OR** structures **OR** physical features may be analogous **OR** not due to common ancestry [1 mark]

    $\ce{ -> }$ analogous structures as a result of convergent evolution [1 mark]

    $\ce{ -> }$ organisms (are now) classified using amino acid **OR** DNA sequences [1 mark]

    $\ce{ -> }$ increased accuracy **OR** reliability of cladograms made using DNA **OR** amino acid sequences [1 mark]

    [4 marks]

    $\underline{\textrm{Sample Answer}}$: \
In the past, organisms were classified based on shared **physical features** ($\checkmark$), however **physical features could be analogous** and therefore not the result of common ancestry ($\checkmark$). Cladograms which are constructed using **DNA or amino acid sequences** ($\checkmark$) are more **reliable** ($\checkmark$) and can highlight new evolutionary relationships which would lead to organisms potentially being reclassified.

3.    any **eight** of the following:

    $\ce{ -> }$ **BOTH** seek to demonstrate **OR** deduce evolutionary relationships [1 mark]

    $\ce{ -> }$ **BOTH** contain a root **OR** ancestor common to all organisms within the cladogram [1 mark]

    $\ce{ -> }$ **BOTH** contain nodes **OR** points at which species diverged from one another [1 mark]

    $\ce{ -> }$ **BOTH** contain clades **OR** an ancestor and all of its evolutionary descendants [1 mark]

    $\ce{ -> }$ **BOTH** can contain outgroups **OR** the most distantly related species [1 mark]

    $\ce{ -> }$ species in **BOTH** may be reclassified (in response to new evidence) [1 mark]

    $\ce{ -> }$ species organised based on anatomical structures **OR** physical characteristics **WHEREAS** species are organised based on amino acid **OR** DNA sequence [1 mark]

    $\ce{ -> }$ in the past cladograms were constructed using similarities in physical features **WHEREAS** now DNA **OR** amino acid sequences are used [1 mark]

    $\ce{ -> }$ molecular evidence **OR** DNA sequences **OR** amino sequences more reliable **OR** accurate than structural evidence **OR** physical characteristics [1 mark]

    $\ce{ -> }$ analogous structures can be an issue in cladograms made using structural similarities **BUT** not in cladograms using molecular evidence **OR** DNA **OR** amino acid sequences [1 mark]

    $\ce{ -> }$ cladograms made using structural evidence require less technology **COMPARED** to cladograms using molecular evidence **OR** DNA or amino acid sequences [1 mark]

    [8 marks]

    $\underline{\textrm{Sample Answer}}$: \
Cladograms which are made using structural evidence and those made using molecular evidence have several things in common, for example, **both have** features such as a **root** ($\checkmark$), **nodes** ($\checkmark$) and **clades** ($\checkmark$), they **both** also attempt to show **evolutionary relationships** between species ($\checkmark$). There are also some differences in these cladograms. In cladograms made using structural evidence, the **physical characteristics** of species are used to organise them into groups, which **does not require much technology**. However, in cladograms using molecular evidence, which requires more **advanced technology** ($\checkmark$), scientists use the number of differences in the DNA or **amino acid sequence** ($\checkmark$), which is known to be the more **reliable** ($\checkmark$) method and is more commonly used now, compared to structural features being used more in the **past** ($\checkmark$).
