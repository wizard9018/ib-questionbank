 2. Any **two** of the following:

 *1 mark can be awarded for the correct working, but an incorrect answer*

 $\ce{ -> }$ 2.1 cm ÷ 3.4 cm **OR** Rf value = distance moved by pigment from origin ÷ distance moved by solvent [1 mark]

 $\ce{ -> }$ 0.6 **OR** 0.62 [1 mark]
 [2 marks]

 $\underline{\textrm{Sample answer}}$:

 ![BI0815ansA](images/BI0815ansA.png)

 Rf value = distance moved by pigment from origin ÷ distance moved by solvent

 Distance moved by pigment from origin = 2.7 - 0.6 = 2.1 cm \
 Distance moved by solvent front from origin = 4.0 - 0.6 = 3.4 cm

 Rf value = 2.1 ÷ 3.4 = **0.6** ($\checkmark$)
