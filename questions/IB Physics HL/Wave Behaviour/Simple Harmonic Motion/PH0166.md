# PH0166

An object undergoes simple harmonic motion with a period of $2\,s$. The amplitude of the motion is $2 \,m$ and oscillation starts from maximum negative displacement.  Which of the following represents the velocity of the motion?

- A. $\hspace{1em}$ $v=2π[cos(\pi t)]$

- B. $\hspace{1em}$ $v=π[cos(\frac{\pi}{2} t)]$

- C. $\hspace{1em}$ $v=2π[sin(\pi t)]$

- D. $\hspace{1em}$ $v=π[sin(\frac{\pi}{2} t)]$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: 

The equation for velocity can be written in the following ways;

$v=v_{max} sin(\dfrac{2\pi}{T} t)\hspace{2em}$  or  $\hspace{2em}v=v_{max} cos(\dfrac{2\pi}{T} t)$

The oscillation starts from negative amplitude; 

![PH0166](images/PH0166.png)

When $t = 0$, the object must have zero velocity. Therefore, the equation should include sine $(sin (0) = 0$ giving $v=0)$ instead of cosine. 

The maximum velocity;

$v_{max}=\omega x_0=\dfrac{2\pi}{T} x_0 \hspace{1em}$ where $T = 2\,s$ and $x_0=2\,m$. By substituting the values in the equation;

$v_{max}=(\dfrac{2\pi}{2}) 2=2\pi$

So the answer can be found by combining this information; 

$v=v_{max} sin(\dfrac{2\pi}{T} t)=2\pi sin(\dfrac{2\pi}{2} t)=2\pi sin(\pi t)$
