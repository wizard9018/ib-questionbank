# PH1108

The graph shows the displacement $x$ against time $t$ for points on two oscillating strings. The transverse motion of String A is described by the equation $x=x_0\sin(\omega_At)$.

![PH1108](images/PH1108.png)

Consider the following statements about the oscillations:

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | The transverse motion of the point on String B follows the equation $x=x_0\sin\Bigl(2\omega_At+\dfrac{\pi}{2}\Bigr)$ |
  | II. | Points on String B achieve a greater maximum transverse velocity than the points on String A |
  | III. | Points on the strings have maximum velocity when $x$ is zero |

Which statemetns are correct?

- A. $\hspace{1em}  $ I and II

- B. $\hspace{1em}  $ I and III

- C. $\hspace{1em}  $ II and III

- D. $\hspace{1em}  $ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The oscillation of String B has a phase angle of $-\dfrac{\pi}{2}$ relative to String A, as its displacement is $-x_0$ at $t = 0$. The frequency of the oscillation is $2\omega_A$, as String B completes two cycles over one period of String A’s oscillation. Hence, the transverse displacement equation of String B is $x=x_0\sin\Bigl(2\omega_At-\dfrac{\pi}{2}\Bigr)$, meaning that Statement I is incorrect.

The transverse velocity of String A is given by $v=\omega_Ax_0\cos(\omega_At)$, whilst the transverse velocity of String B can be expressed as $v=2\omega_Ax_0\cos\Bigl(2\omega_At-\dfrac{\pi}{2}\Bigr)$. Therefore, the maximum transverse velocity of String A is $\omega_Ax_0$, whereas the maximum transverse velocity of String B is $2\omega_Ax_0$. Thus, Statement II is correct.

Finally, from the equations for $x$ and $v$, $v$ is maximum when $x$ is zero. Hence, Statement III is also correct.
