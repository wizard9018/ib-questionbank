# PH0293

An object on a horizontal spring performs simple harmonic motion. The position of the object as a function of time is given by
$x=5\, \ce{cos}⁡(2t)$.

Which of the following expressions gives the acceleration of this object as a function of time?

- A. $\hspace{1em} -20 \,\sin(2t)$

- B. $\hspace{1em} -5 \,\sin  (2t)$

- C. $\hspace{1em} -5\, \cos(2t)$

- D. $\hspace{1em} -20\, \cos(2t)$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Acceleration is proportional to negative displacement, so it has to be a $(-\cos)$ function.

Acceleration is given by $a = -ω^2x$,

therefore $a = -(2^2)(5)\,\cos(2t) = -20\,\cos(2t)$
