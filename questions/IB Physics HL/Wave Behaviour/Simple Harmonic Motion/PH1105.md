# PH1105

Two horizontal, frictionless springs are set oscillating at the same instant but in opposite directions. Spring A has two times greater oscillation frequency than Spring B, but Spring B oscillates at four times greater amplitude than Spring A.

![PH1105](images/PH1105.png)

Which row of the table correctly describes the relative phase angle $\phi$ and maximum vibrational velocity $v_{max}$ of the two springs?

$\\$

| | $\hspace{2em}$ $\phi_A$  $-$ $\phi_B$ $\hspace{2em}$ | $\hspace{2em}$ $\dfrac{v_{max}\textrm{ (Spring A)}}{v_{max}\textrm{ (Spring B)}}$ $\hspace{2em}$ |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| 0 | $\dfrac{1}{2}$ |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | 0 | 2 |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | $180\degree$ | $\dfrac{1}{2}$ |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | $180\degree$ | 2 |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The springs are set in motion at the same instant but in opposite directions, meaning that at time $t = 0$, there is a phase angle difference of exactly $180\degree$ between them.

The velocities of Spring A and B are respectively given by

- $v_A=2\omega x_{0,A}\cos(2\omega t + \phi_A)$

and

- $v_B=\omega x_{0,B}\cos(\omega t + \phi_B)$

Hence, the maximum velocities of the two springs correspond to the cosine function equaling one:

- $v_{max}$ (Spring A) = $2\omega x_{0,A}$

- $v_{max}$ (Spring B) = $\omega x_{0,B}$

It is stated that

- $x_{0,B}=4x_{0,A}$

Therefore,

- $v_{max}$ (Spring B) = $4\omega x_{0,A} = 2v_{max}$ (Spring A)
