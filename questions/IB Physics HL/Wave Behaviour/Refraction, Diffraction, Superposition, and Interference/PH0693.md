# PH0693

White light is incident on a double slit and a diffraction pattern, containing multiple rainbow patterns, is observed on a distant screen.

Which of the following correctly describes these rainbow patterns?

$\\$

| | $\hspace{1.5em}$Angular width$\hspace{1.5em}$  | $\hspace{1.5em}$Color seen at central maximum$\hspace{1.5em}$ |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| Uniform | White |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | Uniform | Blue |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | Variable | White |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | Variable | Blue |

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:

As with equation:

- $n\lambda=d\sin{\theta}$

We see that the diffraction pattern spreads out with increasing wavelength.

The angular width of a rainbow pattern can be defined as the angle between the red and blue fringe. For small angles, the angular width is:

- $\dfrac{n({\lambda}_{red}-{\lambda}_{blue})}{d}={\theta}_{red}-{\theta}_{blue}$

As the order increases and the value of $n$ increases, the angular width is increasing.

The central peak is white as all wavelengths are incident here.
