# PH0879

Light is incident on a double slit and a fringe pattern is observed on a screen. Point **A** is equidistant from both slits and point **B** lies in between a dark and light fringe as shown in the diagram below.

![PH0879aaaaaa](images/PH0879aaaaaa.png)

Below are three statements about the fringe pattern.

- I. $\hspace{1em}$ The path difference of light arriving from each of the slits at B is between $0$ and $\dfrac{\lambda}{2}$.
- II. $\hspace{.7em}$ If only the distance between the double slit and the screen is increased, then the distance between adjacent bright fringes will increase
- III. $\hspace{.4em}$ If only the frequency of the light is increased, then the distance between adjacent bright fringes will decrease.

Which of the statements are correct?

- A. $\hspace{1em}$ I and II only

- B. $\hspace{1em}$ I and III only
- C. $\hspace{1em}$ II and III only
- D. $\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

**I** is incorrect. At the bright fringe closest to $A$ the path difference is $\lambda$. Between this bright fringe and the next dark fringe, the path difference varies between $\lambda$ and $\dfrac{3\lambda}{2}$.

**II** is correct. Fringe spacing is given by $s=\dfrac{\lambda D}{d}$. $D$ is the distance from the double slit to the screen. $\lambda$ (wavelength) and $d$ (slit separation) are constant. $s\ \alpha\ D$ so if $D$ increases $s$ increases.

**III** is correct. $v=f\lambda$ so if frequency increases then wavelength decreases. $s = \dfrac{\lambda D}{d}$. $\lambda\ \alpha\ s$ so if $\lambda$  decreases then $s$ decreases.
