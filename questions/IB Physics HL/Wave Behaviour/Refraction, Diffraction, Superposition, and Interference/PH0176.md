# PH0176

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

A greater slit width allows more light to reach the screen. This increases the intensity. So the peaks will be higher.
The angular width of maxima is proportional with $\dfrac{\lambda}{b}$. An increase of slit width $b$ results in a decrease in angular width of the maxima. Angular width and width of maxima are proportional. Therefore, the maxima will be narrower.
