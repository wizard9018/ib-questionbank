# PH0766

When a beam of monochromatic light falls on a single slit with a width $b$, it subsequently creates a diffraction pattern on a screen positioned at a certain distance away.

![image](images/image.png)

The screen is then moved away from the slit. Which of the following changes will be observed?

$\\$

| | $\hspace{1.5em}$Width of central maximum$\hspace{1.5em}$ | $\hspace{1.5em}$Intensity of Central Maximum$\hspace{1.5em}$ |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| Decrease |Increase |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | Increase | Increase |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | Decrease | Decrease |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | Increase | Decrease |

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

According to the diagram:

![image](images/image.png)

We see that by moving the screen further from the slit, for a given angle at which the first minimum occurs, the distance from the central peak to this minimum increases ($d_1$ becomes $d$).

Since the screen is further, this makes the central spot dimmer (same amount of light over a greater area).
