# PH0178

A single narrow slit of width $b$ is used to diffract the radiation of a microwave transmitter. A receiver is positioned at distance of $D$ from the slit. The receiver is moved from point $A$ to point $C$. At point $B$, the intensity of the radiation is minimum for the first time.

![PH0178](images/PH0178.png)

Which of the following changes could cause point C to be the first occurrence of a detected radiation minimum?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Increase D   |
  | II. | Decrease slit width |
  | III. | Replace the microwave transmitter and receiver with a radio wave transmitter and receiver |

- A. $\hspace{1em}$ Only I

- B. $\hspace{1em}$ Only II

- C. $\hspace{1em}$ I and II only

- D. $\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Since the intensity at $B$ is the first detected minimum, it should be the first diffraction minimum. The angle of diffraction for the first minimum;

- $\theta=\dfrac{\lambda}{b}$

For small angles;

- $\dfrac{S}{D}=\dfrac{\lambda}{b} \hspace{2cm}$ where $S$ is the distance between $A$ and $B$.

- $S=\dfrac{D\lambda}{b}$

$S$ should be increased to a value that equals to distance between $A$ and $C$. An increase in $D$ or a decrease in $b$ will increase $S$. Additionally, replacing microwaves with radio wave radiation is increasing the wavelength of the incident radiation which also causes an increase in $S$.
