# PH0692

A diffraction pattern is formed when monochromatic light is incident on a diffraction grating with an arbitrary number of slits. The graph below shows the variation of intensity with respect to the diffraction angle.

![image](images/image.png)

Three possible changes to the setup are:

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Increasing the number of slits.   |
  | II. | Changing the slit width. |
  | III. | Changing the distance between slits. |

Which of the possible changes, made independently, will result in all of the primary maxima reaching a similar intensity?

- A. $\hspace{1em}  $ I only.

- B. $\hspace{1em}  $ II only.

- C. $\hspace{1em}  $ III only.

- D. $\hspace{1em}  $ None of these.

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:

Point I - Increasing number of slits increases sharpness of all maxima, as it increases destructive interference between the centres of the maxima.

Point II - The single-slit diffraction pattern always acts as an envelope for the multiple-slit diffraction patterns.

According to the single-slit equation:

- $\theta = \dfrac{\lambda}{b}$

If we decrease the slit width, $b$, the angular width of the central maximum increases. Any maxima found under this envelope will therefore increase in intensity.

Point III - According to equation:

- $n\lambda=d\sin{\theta}\rarr \sin{\theta}=\dfrac{n\lambda}{d}$

Changing distance between slits, $d$, brings more/less maxima into field of view, not at same intensity, as it will not affect the single slit diffraction envelope.

Therefore, only B is correct.
