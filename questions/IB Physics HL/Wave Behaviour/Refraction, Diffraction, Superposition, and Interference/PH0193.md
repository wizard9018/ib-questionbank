# PH0193

A parallel beam of light passes through two parallel slits and an interference pattern is formed on a distant screen. The fringe separation is too small to measure. Which of the following would increase the fringe separation?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Increase the distance between slits and screen  |
  | II. | Replace the light source with one with a longer wavelength |
  | III. | Increase the slit separation |

- A. $\hspace{1em}  $ I only

- B. $\hspace{1em}  $ II only

- C. $\hspace{1em}  $ I and II only

- D. $\hspace{1em}  $ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

![PH0193](images/PH0193.png)

The path difference for constructive interference in a double-slit experiment;

- $n\lambda=d\ce{sin}\theta$ where $n$ is the order of the maximum

For small angles

- $\ce{sin}\theta=\ce{tan}\theta=\dfrac{s}{D}$

By taking $n$ = 1 for the separation between central maximum and first maximum. This also gives the fringe separation between all fringes.

- $\lambda=d\dfrac{s}{D}$

By rearranging

- $s=\dfrac{\lambda D}{d}$

Therefore, an increase in wavelength and distance between screen and slits will increase fringe separation while the increase in slit separation will result in a decrease in fringe separation.
