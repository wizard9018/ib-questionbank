# PH0361

A beam of monochromatic light is incident on a single slit of width $b$. After passing through the slit, a diffraction pattern is observed on a screen of distance $D$ from the slit.

![PH0175](images/PH0175.png)

1. What is meant by monochromatic light?   [1 mark]

2. A student wants to measure the width of the central bright fringe of the diffraction pattern observed on the screen.

    1. The width of the central bright fringe is too small to be measured.  Suggest three changes in the arrangement to solve this issue when each of them is implemented separately.  [3 marks]

    2. The width of the central bright fringe is measured as 2.4 cm after the relevant change in the arrangement is implemented. The distance $D$ between the slit and the screen is 50 cm while the wavelength of used light is 600 nm.  Estimate, in m, slit width $b$.   [3 marks]

3. The student wants to be sure of the calculated value of slit width. They therefore decide to repeat the experiment with different wavelengths.

   On the axes below, sketch a graph to show how the angle $\theta$ of the first diffraction minimum from the central maximum varies with wavelength.

   (There is no need to add values to the axes)      [2 marks]

    $\underline{\textrm{Further Explanation}}$: \
Monochromatic light is light that has only one colour. Every colour has a unique frequency and wavelength.

2. 1. Decrease slit width/$b$ $\checkmark$

      Increase distance between slit and screen/$D$ $\checkmark$

        $\ll$Replace light source with the one that has$\gg$ longer wavelength/λ $\checkmark$

        $\underline{\textrm{Further Explanation}}$: \
        The angular width of the first minimum from the central maximum;

        - $\theta=\dfrac{\lambda}{b}$

        The angular width can be also found by

        - $\theta=\dfrac{S}{D}$,  $\hspace{1cm}$where $S$ half the width of the central maximum.

        When θ from the first equation is substituted in the second equation;

        - $\dfrac{\lambda}{b}=\dfrac{S}{D}$

        By rearranging;

        - $\dfrac{D\lambda}{b}=S$

        According to the above relationship, to increase $S$, the distance $D$ between screen and slit can be increased or the light source can be changed with another one that has a longer wavelength. Additionally, slit width can be decreased.

    2.  $\theta =\dfrac{S}{D}$ $\checkmark$

        Use of $\hspace{2em}b=\dfrac{\lambda D}{S}$ $\checkmark$

        :answer[$2.5\times{10}^{-5}$]$ \ll \ce{m}\gg$ $\checkmark$

        $\underline{\textrm{Further Explanation}}$: \
        Angular width between central maximum and first minimum;

        - $\theta\ =\dfrac{S}{D}$

        By using small-angle approximation;

        - $S=\dfrac{D\lambda}{b}$

        where $S$ is half of the width of the central bright fringe.

        By rearranging to find b;

        - $b=\dfrac{D\lambda}{S}=\dfrac{(0.5)(6\times{10}^{-7})}{1.2\times{10}^{-2}}=2.5\times{10}^{-5}$ m
