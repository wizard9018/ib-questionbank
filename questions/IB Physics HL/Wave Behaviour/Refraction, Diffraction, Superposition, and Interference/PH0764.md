# PH0764

Which of the following is/are true for the diffraction pattern produced by a single slit?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | The central maximum is twice as wide as the other maxima.   |
  | II. | The minima occur at evenly spaced intervals. |
  | III. | The width of the slit affects the intensity of the diffraction pattern. |

- A. $\hspace{1em}  $ I only.

- B. $\hspace{1em}  $ II only.

- C. $\hspace{1em}  $ III only.

- D. $\hspace{1em}  $ I and III only.

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

Minima are only approximately equally spaced. In reality the model developed is based on the small angle approximation and so for larger angles the spacing of the fringes increases.

Increasing slit width lets more light pass through, and decreasing the slit width lets less light pass through. With more light passing through, the intensity of the pattern will be higher.
