# PH0686

Light of wavelength $\lambda$ is incident on a double-slit to produce a diffraction pattern on a screen some distance away with the fringes clearly resolved. Light is then blocked from travelling through one of the slits. Which of the following changes does $\bold{NOT}$ occur in the pattern on the screen?

- A. $\hspace{1em}  $ No maxima are observed.

- B. $\hspace{1em}  $ The interference pattern is less intense.

- C. $\hspace{1em}  $ The width of the maxima is larger.

- D. $\hspace{1em}  $ Fewer maxima within a given angular width are observed.

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

Covering one slit changes the interference pattern from a modulated double-slit pattern to a standard single slit diffraction pattern.

The structure is similar with maxima and minima, but with less light reaching the screen, the pattern is less intense (B), and the maxima are much wider (C, D).

Statement A is therefore incorrect and should be selected as the answer here.
