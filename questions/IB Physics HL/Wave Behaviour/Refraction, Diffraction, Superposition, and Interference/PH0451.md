# PH0451

The diagram shows a beam of light passing from medium $X$ to medium $Y$.

![PH0451](images/PH0451.png)

If the angle of incidence of the light increases, which of the following changes can be implemented to keep the angle of refraction the same?

- :::tableoptions{col1="hide" col2="hide"}

  | | |

  | :-- | :-- |

  | I. | Medium X can be replaced with another medium which has a lower refractive index. |

  | II. | Medium X can be replaced with another medium which has a higher refractive index. |

  | III. | Medium Y can be replaced with another medium which has a higher refractive index. |

- A. $\hspace{1em}$ Only I

- B. $\hspace{1em}$ I and III only

- C. $\hspace{1em}$ II and III only

- D. $\hspace{1em}$ I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: 

Snell's Law governs the angles of incidence and refraction as a wave passes between two media with different refractive indices:

- $\dfrac{\ce {sin(θi)}} {\ce{sin(θr)}} = \dfrac{n_y}{n_x}$

- $\ce {sin(\theta_r)} = (\dfrac{n_x}{n_y})\ \ce {sin(\theta_i)}$

Statements I and III are correct: If $\theta_i$ increases, $\ce {sin(\theta_i)}$ will also increase.

As a result, either $n_x$ must decrease (statement I) and/or $n_y$ must increase (statement III) to keep the angle of refraction $\theta_r$ the same.
