# PH0817

A string of length $L$ is free at both ends. The string vibrates with a frequency $f$ and a standing wave of the third harmonic is formed.

One end of the string is then fixed, and the string is shortened with the speed of waves in the string remaining unchanged. The string vibrates with the same frequency $f$ and a standing wave is formed.

Which of the following could not be the new length of the string?

- A. $\hspace{1em}$ $\dfrac{L}{6}$

- B. $\hspace{1em}$ $\dfrac{L}{3}$
- C. $\hspace{1em}$ $\dfrac{L}{2}$
- D. $\hspace{1em}$ $\dfrac{5L}{6}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:\
A string that is free at both ends will have an antinode at each end. The third harmonic can be represented as follows.

![harmonic](images/harmonic.png)

Because the frequency is kept constant, the wavelength will be the same in both situations.

A string that is free at one end and fixed at the other will have a node at one end and an antinode at the other.

We can rule out $\dfrac{L}{3}$. Three of the $\lq$free at one end fixed at one end' standing waves lined up will always have a node at one end and an antinode at the other end. So $\dfrac{L}{3}$ could not possibly be a standing wave that is free at one end and fixed at the other end given that $l$ is a standing wave for two free ends.

This is enough to determine the answer is **B**.
