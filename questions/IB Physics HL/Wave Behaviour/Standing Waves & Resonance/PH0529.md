# PH0529

**Maximum mark: 6**

1. Discuss the differences between traveling waves and standing waves [2 marks]

2. A 45 cm guitar string fixed at both ends is raised and released so that it vibrates at its fundamental mode. The midpoint of the string passes through its equilibrium position 475 times in one second. Estimate the speed of the wave on the string. [2 marks]

3. The guitar string is now gently touched 15 cm from one end such that a node is created at that point, but the entire length of the string still oscillates. Calculate the frequency of the sound generated. [2 marks]

---

## 评分标准 / Mark scheme

1. Energy is propagated in traveling waves whereas it is stored in standing waves $\checkmark$

    In a traveling wave every particle in the medium oscillates with the same amplitude, whereas in a standing wave particles oscillate with different amplitudes. $\checkmark$

2. $f = \dfrac{475}{2} = 237.5\, \ce{Hz}$ $\checkmark$

    $f = n(\dfrac{v}{2L}) \hspace{1em} n= 1$ for fundamental  

    

    $v = 2fL = (237.5)(2)(0.45)$ = :answer[$214\,\ce{m}\,\ce{s}^{-1}$] $\checkmark$

    $\underline{\textrm{Further Explanation}}$: \

    In an oscillation, the string will pass its equilibrium point twice, therefore the frequency is half of the value given

    $f = (\dfrac{475}{2}) = 237.5\,\ce{Hz}$

    In the fundamental mode for a string fixed at both ends, the length of the string is equal to one half of a wavelength

    ![PH0529](images/PH0529.png)

    Thus $\lambda = 2L = 2(0.45) = 0.90\,\ce{m}$

    Using the universal wave equation, 

    $v = f\lambda = (237.5)(0.9) = 214\,\ce{m}\,\ce{s}^{-1}$

3. Distance between nodes becomes $15\,cm$, thus wavelength is 30 cm $\checkmark$

    $f = \dfrac{v}{\lambda}$

    $\hspace{.9em} = \dfrac{214}{0.30}$

    $\hspace{.7em}$ = :answer[$712\,\ce{Hz}$] $\checkmark$

    ecf from 3(b) for MP2

    This answer can also be obtained by recognizing the frequency is $3f_o$

    $\underline{\textrm{Further Explanation}}$: \

    Creating a node at the 15 cm mark will force a node at that location and restrict the first and second harmonic oscillation modes. Thus the third harmonic frequency will be heard.

    ![PH0529-1](images/PH0529-1.png)

    Multiples of this frequency are also possible answers here, as a node would be created in the same 15 cm position for $6f_o$ , $9f_o$ etc.
