# PH0754

System **A** contains $10^{23}$ ideal gas molecules in a volume of $0.5$ m$^3$. System **B** contains one mole of ideal gas molecules in a volume of $5.0$ m$^3$. The systems are at equal temperatures.

Which system contains the most molecules, and which is at the highest pressure?

$\\$

| | Most molecules | Highest pressure |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| System A | System A |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | System A | System B |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | System B | System A |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | System B | System B |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

One mole of gas is defined as approximately $6.02 \times 10^{23}$ molecules, meaning that System B contains the most gas molecules.

Thus System B has approximately 6 times the number of molecules as System A.

System B also has $10\times$ the volume of System A.

With $T$ constant, we know that

$\hspace{1em}$ $P\ \propto\dfrac{n}{V}$

$\hspace{1em}$ $\therefore P_{B\ }\approx\ \dfrac{6}{10}P_A\\ $

And so System A has the highest pressure.

**OR**

From the ideal gas law, the pressure in System A is given by

$\hspace{1em}$ $P_A=\dfrac{Nk_BT}{V_A}$

whereas the pressure in System B can be expressed as

$\hspace{1em}$ $P_B=\dfrac{nRT}{V_B}$

Since the temperatures are equal and the volume in System A is one-tenth of the volume in System B,

$\hspace{1em}$ $\dfrac{P_B}{P_A}=\dfrac{nR}{10Nk_B}=\dfrac{8.31}{10(10^{23})\left(1.38\times 10^{-23}\right)}=\dfrac{8.31}{13.8}<1$

Thus, System A has a greater pressure than System B.
