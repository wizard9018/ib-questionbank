# PH0929

Which of the following gives the unit of electric potential in fundamental SI units?

- A. $\hspace{1em}  $ $\ce{kg\,m^2\,s^{-3}\,C^{-1}}$

- B. $\hspace{1em}  $ $\ce{kg\,m^2\,s^{-1}\,A}$

- C. $\hspace{1em}  $ $\ce{kg\,m^2\,s^{-2}\,C^{-1}}$

- D. $\hspace{1em}  $ $\ce{kg\,m^2\,s^{-3}\,A^{-1}}$

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

The 7 SI base units are:

- Meter (m)

- Second (s)

- Mass (kg)

- Mole (mol)

- Ampere (A)

- Temperature (K)

- Candela (cd)

We can immediately disregard answers A and C as they contain C (Coulomb) which is not an SI base unit.

Electric potential, $V=\dfrac{E}{Q}$. So, the units are $\ce{J\,C^{-1}}$

$W=Fd$. So, we may write $J=N\,m$

$F=ma$. So, we may write $N=kg\,m\,s^{-2}$

Putting this together gives the SI units for energy:
$\ce{J = kg\,m^2\,s^{-2}}$

$Q=It$. This tells us the SI base units for charge:
$C=As$

Therefore, the units for electric potential are $\dfrac{\ce{kg\,m^2\,s^{-2}}}{As}=\ce{kg\,m^2\,s^{-3}\,A^{-1}}$
