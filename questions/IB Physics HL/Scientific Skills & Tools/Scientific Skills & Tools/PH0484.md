# PH0484

A body moves a distance of 1.5 km in 10 ks.

Which of the following gives the correct magnitudes of both distance and time?

$\\$

| | Distance | Time |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| $\hspace{1.5em}1.5 \times 10^{-4}\, \ce{dm}\hspace{1.5em}$ | $\hspace{1.5em}10^{16}\,  \ce{ps}\hspace{1.5em}$ |
| B. | $\hspace{1.5em}1.5 \times 10^{4}\,  \ce{dm}\hspace{1.5em}$  | $\hspace{1.5em}10^{16} \, \ce{ps} \hspace{1.5em}$|
| C. | $\hspace{1.5em}1.5 \times 10^{9} \, \mu \ce{m} \hspace{1.5em}$ | $\hspace{1.5em}10^{-16}\,  \ce{ps}\hspace{1.5em}$ |
| D. | $\hspace{1.5em}1.5 \times 10^{-9}\,  \mu \ce{m} \hspace{1.5em}$ | $\hspace{1.5em}10^{-16}\,  \ce{ps}\hspace{1.5em}$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The distance is 1.5 km which is $1.5 \times10^3$ m, to convert it to dm, it will be $1.5 \times 10^4$ dm.

If we convert it to micrometers, it will be $1.5 \times 10^9\,\mu$m.

This eliminates answers A and D.

To convert the time from 10 ks to ps; it will be $10 \times 10^{15}\,\ce{ps} = 10^{16}\,\ce{ps}$

therefore, the only correct answer for both of distance and time will be B.
