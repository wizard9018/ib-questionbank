# PH0078

Express 0.04758 to 3 significant figures.

- A. $\hspace{1em}$0.04758

- B. $\hspace{1em}$0.0476

- C. $\hspace{1em}$0.048

- D. $\hspace{1em}$0.05

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Leading zeros do not count in the number of significant figures (s.f.). Therefore, option A is 4 s.f.; option B is 3 s.f.; option C is 2 s.f.; option D is 1 s.f.
