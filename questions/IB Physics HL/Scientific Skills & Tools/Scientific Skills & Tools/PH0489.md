## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: 

To get the direction of the sum, we have to rearrange these vectors. 

We can arrange them to start from the same point and complete the parallelogram, and then the diagonal from the starting point will be the sum vector.

![PH0489MS](images/PH0489MS.png)

Using any method will give the same direction of the vector, which is in the same direction as choice A.
