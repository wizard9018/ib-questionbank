# PH1758

The velocity $v$ of an object accelerating non-uniformly as a function of time $t$ is given by:

$v=5t^\frac{5}{2}$

A student plots a graph of $\ln(v)$ against $\ln(t)$.

![PH1758](images/PH1758.JPEG)

What is the gradient and $y$-intercept of the graph?

$\\$

| | $\hspace{1.5em}$Gradient$\hspace{1.5em}$ | $\hspace{1.5em}$Y-intercept$\hspace{1.5em}$ |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$ | $\dfrac{5}{2}$ | $\ln\Bigl(\dfrac{5}{2}\Bigr)$ |
| $\hspace{1.5em}$B.$\hspace{1.5em}$ | $\dfrac{5}{2}$ | $\ln(5)$ |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | 5 | $\ln\Bigl(\dfrac{5}{2}\Bigr)$ |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | 5 | $\ln(5)$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Taking the natural logarithm of both sides of the equation we have:

- $v=5t^\frac{5}{2}$

- $\ln(v) = \ln\Bigl(5t^\frac{5}{2}\Bigr)$

- $\ln(v) =\ln(5) + \ln\Bigl(t^\frac{5}{2}\Bigr)$

- $\ln(v) = \ln(5) + \dfrac{5}{2}\ln(t)$

Comparing this to the equation of a straight line $y=mx+c$ where $m$ is the gradient and $c$ is the y-intercept we have:

- $y=mx+c$

- $\ln(v) = \dfrac{5}{2}(\ln(t)) + \ln(5)$

- gradient = $\dfrac{5}{2}$

- $y$-intercept = $\ln(5)$
