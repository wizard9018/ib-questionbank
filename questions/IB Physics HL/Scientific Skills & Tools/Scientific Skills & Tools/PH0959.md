# PH0959

Which of the following is $\textbf{not}$ a unit for magnetic flux density?

- A. $\hspace{1em}$ T

- B. $\hspace{1em}$ Wb m$^2$

- C. $\hspace{1em}  $ kg s$^{-2}\,\ce{A}^{-1}$

- D. $\hspace{1em}  $ N A$^{-1}\,\ce{m}^{-1}$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:

A is correct - Tesla (T) is the unit for magnetic flux density

$\textbf{B is incorrect}$ - Weber (Wb) is the unit of magnetic flux

Magnetic flux density $= \dfrac{\text{magnetic flux}}{\text{area}}$

So 1 T = 1 Wb m$^{-2}$

C is correct (C is the SI base unit of magnetic flux density)

- $B=\dfrac{F}{IL}=\dfrac{ma}{IL}$

- $T=\dfrac{\ce{N}}{\ce{A}\,\ce{m}}=\dfrac{\ce{kg}\,\ce{m}\,\ce{s}^{-2}}{\ce{A}\,\ce{m}}=\ce{kg}\,\ce{s}^{-2}\,\ce{A}^{-1}$

D is correct

- $B=\dfrac{F}{IL}$

- $T=\dfrac{\ce{N}}{\ce{A}\,\ce{m}}=\ce{N}\,\ce{A}^{-1}\,\ce{m}^{-1}$
