# PH0838-1

Planet A orbits a star with orbital radius $r_A$ and orbital speed $v_A$. Planet B orbits the same star with an orbital radius $4r_A$.

![Screenshot 2026-01-28 at 1.05.29 PM](<images/Screenshot 2026-01-28 at 1.05.29 PM.png>)

Which of the following shows a correct expression for the speed and angular velocity of planet B?

$\\$

| | $\hspace{1.5em}$Speed of Planet B$\hspace{1.5em}$ | $\hspace{1.5em}$Angular velocity of Planet B$\hspace{1.5em}$ |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| $\dfrac{v_A}{2}$ | $\dfrac{v_A}{8r_A}$ |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | $\dfrac{v_A}{2}$| $\dfrac{v_A}{2r_A}$ |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | $4v_A$ | $\dfrac{v_A}{r_A}$ |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | $4v_A$ | $\dfrac{4v_A}{r_B}$ |

---

## 评分标准 / Mark scheme

**答案：A**

Using the data booklet formula

- $v_{orbital}=\sqrt{\dfrac{GM}{r}}$

Where $G$ and $M$ are constant so $v^2 \propto \dfrac{1}{r}$

$\begin{aligned}
\hspace{1em} v_A^2 r &= v_B^2 (4r)\\
\hspace{1em}\\
\dfrac{v_A^2}{4} &= v_B^2\\
\hspace{1em}\\
v_B &= \dfrac{v_A}{2}\\
\end{aligned}$

For $\omega$ we can use

- $\omega_B=\dfrac{v_B}{r_B}=\dfrac{v_A}{2(4r_A)}=\dfrac{v_A}{8r_A}$
