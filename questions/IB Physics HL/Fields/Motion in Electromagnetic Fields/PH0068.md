# PH0068

An object of mass $m$ and charge $q$ is dropped vertically between two parallel plates, $K$ and $L$. A magnetic field $B$ can be created perpendicular to the plane of the paper. The electric field between plates is $E$.

![PH0068](images/PH0068.png)

Which of the following is correct about the magnitude of magnetic and electric fields when the object falls vertically at a constant velocity $v$?

$\\$

| | $\qquad\underline{\mathbf{E}}\qquad$ | $\qquad\underline{\mathbf{B}}\qquad$ |
| --- | :-: | :-: |
| A.$\hspace{1em}$ | $\dfrac{mg}{q}\rule[-4mm]{0pt}{5mm}$ | $\dfrac{mg}{qv}\rule[-4mm]{0pt}{5mm}$ |
| B.$\hspace{1em}$ | ${m}{v}\rule[-4mm]{0pt}{5mm}$ | $0$ |
| C.$\hspace{1em}$ | $mg$ | $\dfrac{m}{qv}\rule[-4mm]{0pt}{5mm}$ |
| D.$\hspace{1em}$ | $\dfrac{mg}{q}\rule[-4mm]{0pt}{5mm}$ | $0$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Since the object moves vertically without deflection, the magnetic field in the region is zero.

Since object moves at a constant velocity, vertical forces are balanced and $F_e = mg$, where $F_e = Eq$.

So, $B = 0$  and $E = \dfrac{mg}{q}$.
