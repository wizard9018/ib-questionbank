# PH0806

A proton is traveling at a constant velocity downwards as shown.

![PH0806](images/PH0806.png)

Which combinations of directions of electric and magnetic fields could **not** cause a component of the proton's deflection to be to the right?

$\\$

| | Electric field| Magnetic Field |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| To the left | To the right |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | To the left | Into the page |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | To the right | To the left |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | To the right| Out of the page |

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

If either field can cause a force to the right, then we can disregard this option (as it will cause some deflection to the right).

An electric field to the right will cause a force to the right so we can disregard C and D.

Fleming's left-hand rule tells us that a magnetic field into the page will cause a force to the right (current is out of the page) so we can disregard B.

Hence the correct answer is A.
