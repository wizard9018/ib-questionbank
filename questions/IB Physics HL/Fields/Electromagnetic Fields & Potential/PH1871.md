# PH1871

Which of the following could not be the charge of a particle?

- A. $\hspace{1em}$ $3.2\times10^{-19}$ C

- B. $\hspace{1em}$ $4.0\times10^{-19}$ C

- C. $\hspace{1em}$ $3.2\times10^{-18}$ C

- D. $\hspace{1em}$ $4.0\times10^{-18}$ C

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Charge is quantised. The charge of a particle must be an integer multiple of the elementary charge:

- $e=1.6\times10^{-19}$ C

This means any valid particle charge must be:

- $q=n\times e$

Where $n$ is an integer.

Checking each option we have:

- A. $\hspace {2em}3.2\times10^{-19}$ C $=2\times e$

- B. $\hspace {2em}4.0\times10^{-19}$ C $=2.5\times e$

- C. $\hspace {2em}3.2\times10^{-18}$ C $=20\times e$

- D. $\hspace {2em}4.0\times10^{-18}$ C $=25\times e$

Therefore, option B is not a possible charge for a particle.
