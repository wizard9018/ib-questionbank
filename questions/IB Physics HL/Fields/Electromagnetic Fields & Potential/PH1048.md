# PH1048

The diagram below shows selected equipotential lines around four charges P, Q, R and S.

![image](images/image.png)
$\footnotesize{\textrm{[Copyright © 2012 - Matplotlib Development Team; All Rights Reserved]}}$

Below are three statements about the charges.

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | P and Q have the same sign   |
  | II. | P and R have the same sign |
  | III. | All the charges have the same magnitude |

Which of the statements are correct?

- A. $\hspace{1em}  $ I and II only

- B. $\hspace{1em}  $ I and III only

- C. $\hspace{1em}  $ II and III only

- D. $\hspace{1em}  $ I, II and III

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:

I is incorrect - Equipotential lines are perpendicular to field lines, the equipotential lines between P and Q tell us there is a field line connecting them. The charges must have opposite signs.

II is correct - Two charges of the same sign should have equipotential lines that enclose both charges.

III is correct - We can see this from the symmetry of the diagram horizontally and vertically about the center of the charges.
