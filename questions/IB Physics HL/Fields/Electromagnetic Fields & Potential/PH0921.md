# PH0921

The diagram below shows a charged oil drop traveling upwards at a constant velocity between two parallel plates. There is a potential difference between the plates causing an electric force to act on the oil drop.

![PH0921](images/PH0921.png)

Which of the following free body diagrams correctly shows the forces acting on the drop? It is assumed that buoyant force is negligible.

| | ![PH0921a](images/PH0921a.png) |  |  |![PH0921b](images/PH0921b.png)|
|C. |   |   | D.  ||
|  |![PH0921c](images/PH0921c.png)   |  |  |![PH0921d](images/PH0921d.png)|

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

Drag always acts in the opposite direction to motion. Drag force must point down (as drop is moving up). So we can disregard A and C.

The object is traveling at a constant velocity so net force = 0 (Newton's first law) therefore the magnitude of the upward and downward forces are the same (magnitude of force proportional to size of arrow in free body diagram) therefore the answer is D.
