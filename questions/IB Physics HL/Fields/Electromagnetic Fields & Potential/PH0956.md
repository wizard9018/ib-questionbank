# PH0956

The diagram below shows two oppositely charged parallel plates.

![PH0956Edit](images/PH0956Edit.png)

Which of the following is the correct orientation of the electric field lines and the equipotential lines between the plates?

$\\$

| | Electric field | Equipotential |
| :-: | :-: | :-: |
| $\hspace{1.5em}$A.$\hspace{1.5em}$| Horizontal | Horizontal |
|$\hspace{1.5em}$B.$\hspace{1.5em}$ | Horizontal | Vertical |
| $\hspace{1.5em}$C.$\hspace{1.5em}$ | Vertical | Horizontal |
| $\hspace{1.5em}$D.$\hspace{1.5em}$ | Vertical | Vertical |

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:

Electric field lines point in the direction a positive charge would move. On the diagram this is from +Q to $-$Q plate (vertical lines).

Equipotential lines (lines of the same electric potential) will connect points that are the same distance from the top and bottom plate (horizontal lines).
