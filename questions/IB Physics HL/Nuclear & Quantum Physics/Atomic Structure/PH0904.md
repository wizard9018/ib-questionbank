# PH0904

Which of the following corresponds to a possible value for the angular momentum of an electron according to the Bohr model for hydrogen?

- A. $\hspace{1em}  $ $\dfrac{h}{8\pi}$

- B. $\hspace{1em}  $ $\dfrac{h}{6\pi}$

- C. $\hspace{1em}  $ $\dfrac{h}{3\pi}$

- D. $\hspace{1em}  $ $\dfrac{h}{\pi}$

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

In Bohr's model for the hydrogen atom, the angular momentum of the electron is quantized having values that are multiples of $\dfrac{h}{2\pi}$.

The value given in D is the only value which is a multiple of $\dfrac{h}{2\pi}$.

- $\dfrac{h}{\pi}=2\Bigl(\dfrac{h}{2\pi}\Bigr)$

This value corresponds to the angular momentum of an electron in the first excited state ($n=2$).
