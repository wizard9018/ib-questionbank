# PH1070

A non-naturally occurring element has a nuclear notation of $\ce{^{180}_{60}X}$.  Below are three statements about the element.

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | The neutron number is twice the proton number.    |
  | II. | The nucleon number is 180.  |
  | III. | The number of protons is 60.  |

Which of the statements are correct?

- A. $\hspace{1em}  $ Only III

- B. $\hspace{1em}  $ Only I and II

- C. $\hspace{1em}  $ Only II and III

- D. $\hspace{1em}  $ I, II and III

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$

180 is the nucleon number while 60 is the proton number of the element X.  Therefore, the neutron number $n$ of the element:

- $n=180-60=120$

Hence, the neutron number is twice the number of protons and all three statements are correct.
