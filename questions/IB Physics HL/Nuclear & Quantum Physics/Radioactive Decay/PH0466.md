2. Due to background radiation. $\checkmark$ \

    Background radiation is radioactive ionizations detected when there is no radioactive source (OWTTE). $\checkmark$

    

    $\underline{\textrm{Further Explanation}}$: \

    Background radiation is always present, with radioactive sources in the environment and also in cosmic rays.

3. 

    1. :answer[10 $-$ 12 days] $\checkmark$

    

        $\underline{\textrm{Further Explanation}}$: \

        To determine the half-life from the graph, determine the maximum activity value which is 300 Bq \

        Then the half-life is the time where the activity has halved which is 150 Bq \

        From the graph find the time corresponds to this activity

        ![PH0466-3](images/PH0466-3.png)

    2. 3 half-lives. $\checkmark$ \

        :answer[30 $-$ 36 days] $\checkmark$

        

        $\underline{\textrm{Further Explanation}}$: \

        The remaining mass ratio to the initial mass is

        - $\dfrac{31}{248}=\dfrac{1}{8}$

        Which corresponds to 3 half-lives 

        - $\dfrac{1}{8}=\Bigl(\dfrac{1}{2}\Bigr)\Bigl(\dfrac{1}{2}\Bigr)\Bigl(\dfrac{1}{2}\Bigr)$

        Since the half-life is 12 days, so the time taken is $(3)(12) = 36$ days.
