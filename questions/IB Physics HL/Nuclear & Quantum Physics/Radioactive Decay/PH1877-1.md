1. 1. $\beta^-$ / Beta minus **AND** antineutrino $\checkmark$

        Allow electron / $e^-$

        $\underline{\textrm{Further Explanation}}$: \
        During this decay the nucleon number stays the same while the proton number increases by 1. This means that the neutron has decayed into a proton.

        During this process a $\beta^-$ particle (a fast-moving electron) is emitted from the nucleus, conserving electric charge.

        Whenever a $\beta^-$ particle is produced, an antineutrino is also produced.

        The full equation for $\beta^-$ decay includes the emission of a neutral electron antineutrino:

        - $\ce{^{1}_{0}n}\rightarrow\ce{^{1}_{1}p}+\ce{^{0}_{-1}\beta}+\ce{^{0}_{0}\bar{\nu}}$

    2. One correct equation for background count e.g.,

        - 8.5 = background count + initial count from source

        - 1.5 = background count + final count from source

        **OR**

        - Initial count rate from the source = 8 Bq

        **OR**

        - Final count rate from source = 1 Bq $\checkmark$

        - Background count rate = :answer[0.5 Bq] $\checkmark$

        $\underline{\textrm{Further Explanation}}$: \
        The count total rate of the detector $C_T$ is the sum of the count rate due to background radiation $C_B$ and the count rate due to the radioactive source $C_S$:

        - $C_T=C_B+C_S$

        $C_B$ remains constant while $C_S$ varies with time. Specifically, $C_S$ will half with each half life.

        If we let the initial count rate from the source be $C_S$, then the count rate after 3 half-lives is given by:

        - $C_S\left(\dfrac{1}{2}\right)\left(\dfrac{1}{2}\right)\left(\dfrac{1}{2}\right)=C_S\left(\dfrac{1}{8}\right)=\dfrac{C_S}{8}$

        The initial total count rate is given by:

        - $8.5=C_B+C_S$

        The total count rate after 3 half lives is given by:

        - $1.5=C_B+\dfrac{C_S}{8}$

        Taking these equations away from each other, we have:

        - $8.5-1.5=C_B-C_B+C_S-\dfrac{C_S}{8}$

        - $7=\dfrac{7}{8}C_S$

        Therefore, the original rate emitted by the source is:

        - $C_S=8$ Bq

        Background count rate is therefore:

        - $C_B=8.5-8=0.5$ Bq

2.  1. The detector only detects a small amount of the radiation produced by the source / The source emits radiation in all directions OWTTE $\checkmark$

        $\underline{\textrm{Further Explanation}}$: \
    The activity of a sample is the total number of decays per second occurring in the whole sample. However, the count rate recorded by a detector is typically less than this because only a fraction of the emitted radiation reaches the detector (due to the geometry of emission in all directions and possible absorption by surrounding material).

        There are other less significant reasons for this discrepancy such as:

        - The efficiency of the detector is less, meaning not every particle that hits it is counted.

        - Some radiation may be scattered or absorbed before reaching the detector.

    2. $\hspace{1.9em}$ $\lambda=\dfrac{\ln2}{T_\frac{1}{2}}=\dfrac{\ln2}{2.4\times10^5}=2.9\times10^{-6}\ll$ s$^{-1}$ $\gg$ $\checkmark$

    - $\hspace{1.9em}$ $N=\dfrac{A}{\lambda}=\dfrac{2\times10^5}{2.9\times10^{-6}}=$ :answer[$6.9\times10^{10}$] $\checkmark$

    $\underline{\textrm{Further Explanation}}$: \
    Half-life $T_\frac{1}{2}$ can be defined as the time taken for the activity of a sample to halve. To find the half-life of this sample, we can read the value of $t$ from the graph when $A=\dfrac{2\times10^5}{2}=1\times10^5$ Bq.

    We can see that the half-life of the sample is around $2.4\times10^5$.

    ![aaaScreenshoot 2025-08-28 at 8.50.21 AM](<images/aaaScreenshoot 2025-08-28 at 8.50.21 AM.png>)

    Now we can find the decay constant $\lambda$ for the sample using the following equation:

    - $T_\frac{1}{2}=\dfrac{\ln2}{\lambda}$

    Rearranging for $\lambda$ gives:

    - $\lambda=\dfrac{\ln2}{T_\frac{1}{2}}=\dfrac{\ln2}{2.4\times10^5}=2.89\times10^{-6}$ (3 sf)

    Next we can use the following equation to find the initial number of nuclei:

    - $A=\lambda N$

    Rearranging and substituting $A$ as the initial activity ($2.0\times10^5$ Bq from the graph) we get:

    - $N=\dfrac{A}{\lambda}=\dfrac{2.0\times10^5}{2.89\times10^{-6}}=6.9\times10^{10}$ (2 sf)

4. De-excitation of the nucleus / nucleus is (initially) in an excited state / gamma photons are emitted from the nucleus OWTTE $\checkmark$

    Excited states are quantized / only certain states possible so emitted energies are discrete $\checkmark$

    $E=hf$ / energy is proportional to frequency therefore frequency is discrete $\checkmark$

    $\underline{\textrm{Further Explanation}}$: \
    The emission of gamma photons occurs when a nucleus in an excited state releases excess energy and transitions to a lower energy state or its ground state. Gamma radiation originates from the nucleus and does **not** involve changes to the electron configuration of the atom.
