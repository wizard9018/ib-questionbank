# PH0948

Which of the following defines the term “isotope”?

- A. $\hspace{1em}  $ A species of atom whose nucleus contains a specified number of protons and a specified number of neutrons.

- B. $\hspace{1em}  $ A species of atom containing a specified number of protons and a specified number of electrons.

- C. $\hspace{1em}  $ Different forms of the same element having same nucleon number and a different proton number.

- D. $\hspace{1em}  $ Different forms of the same element having same proton number and a different nucleon number.

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

A defines the term $\text{\textquotedblleft}$nuclide”.

B and C are slight variations on correct definitions that do not define anything in particular.

D is the definition of an isotope. An example of two isotopes would be carbon-12 ($\ce{^{12}_{6}C}$) and carbon-14 ($\ce{^{14}_{6}C}$).
