# CH0055

**Maximum mark: 5**

The atom of element X has a mass number of 127 and has 74 neutrons. The ion derived from X has 54 electrons.

1. Calculate the number of protons of element X. [1 mark]

2. State the nuclear symbol of the ion formed (refer to the periodic table). [2 marks]

3. An isotope of X has a mass number of 132. Determine the number of neutrons in its atom. [2 marks]

---

## 评分标准 / Mark scheme

1. Number of protons = 127 – 74 = :answer[53] $\checkmark$

    $\underline{\textrm{Further Explanation:}}$
Number of protons ($Z$) = mass number($A$) – number of neutrons($N$)

2. Nuclear symbol: :answer[$_{53}^{127}\textrm{I}$ $^{-}$]  $\checkmark$ $\checkmark$

-   $\textit{Note: One mark for the charge and one mark for the nuclear symbol.}$

-   $\underline{\textrm{Further Explanation:}}$

-   The atomic number of the element X is 53 (number of protons). Therefore, it corresponds to iodine with a mass number $A= 127$ (referring to the periodic table). The number of electrons in the ion formed is 54. This means that the atom has gained one electron, and the overall charge of the ion is $(1-).$

3. Since it is an isotope, the number of protons is the same for all atoms of isotopes of the same element. $\checkmark$

    Number of $\textrm{neutrons} = 132 - 53 = \ $:answer[79 neutrons] $\checkmark$

    $\underline{\textrm{Further Explanation:}}$

    number of neutrons = mass number $-$ number of protons
