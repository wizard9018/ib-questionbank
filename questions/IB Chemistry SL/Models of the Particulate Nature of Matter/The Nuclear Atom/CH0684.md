# CH0684

**Maximum mark: 6**

$\ce{^{63}Cu}$ and $\ce{^{65}Cu}$ are the two most abundant isotopes of copper.

1.  Define isotope. [1 mark]

2.  Determine the correct numbers of subatomic particles to complete the following table. [2 marks]

    | | Copper$-$63 | Copper$-$65 |
    | :-: | :-: | :-: |
    | Number of protons |  |  |
    | Number of electrons |  |  |
    | Number of neutrons |  |  |

    $\mbox{}\\[-15pts]$

3.  Calculate the relative abundances of $\ce{^{63}Cu}$ and $\ce{^{65}Cu}$ using Section  7 of the IB Chemistry data booklet. [3 marks]

## 评分标准 / Mark scheme

1.  atoms with same atomic number different mass number \
    **OR**\
    atoms with same number of protons but different number of neutrons $\checkmark$

2. $\mbox{}\\[-25pts]$

    | | Copper$-$63 | Copper$-$65 | |
    | :-- | :-: | :-: | :-:
    | Number of protons | 29 | 29 |
    | Number of electrons | 29 | 29 | $\checkmark$
    | Number of neutrons | 34 | 36  | $\checkmark$

    $\mbox{}\\[-0pts]$
    *Award M1 for correct number of electrons and protons.*\
    *Award M2 for correct number of neutrons.*

    $\underline{\textrm{Further Explanation}}$:\
    The number of protons for both isotopes is the same as the atomic number of copper. Since both isotopes are electrically neutral, the number of electrons is the same as the number of protons. The number of neutrons is calculated by subtracting the number of protons from the mass number.

3.  $63.55 = \dfrac{63x + 65(100-x) }{100} \: \checkmark$\
    abundance $^{63}\ce{Cu}$: $x=72.5\%$ $\checkmark$\
    abundance $^{65}\ce{Cu}$: $100-x=27.5\%$ $\checkmark$

    $\underline{\textrm{Further Explanation}}$:\
     The relative atomic mass is calculated as a weighted average of the masses of each isotope:

     $A_r = \dfrac{\% \textrm{\ abundance}_1 \times \textrm{mass}_1 + \% \textrm{\ abundance}_2 \times \textrm{mass}_2 + \ldots }{100}$

     Using the data booklet, the relative atomic mass of copper is 63.55. Let $x$ be the percent abundance of copper$-$63 and $100-x$ be the percent abundance of copper$-$65.  Substituting in the values here,

    $63.55 = \dfrac{63x+65\left(100-x\right)}{100}$

    $6355 - 6500 = 63x - 65x$

    $-2x = -145$

    $\% \textrm{\,abundance of\ } 63\textrm{--Cu} = x = 72.5\%$

    $\% \textrm{\,abundance of\ } 65\textrm{--Cu} = 100-x = 27.5\%$
