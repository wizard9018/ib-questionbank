# CH0674

Which of the following statements about $\ce{^{51}_{23}V}$ are correct?

-   I.$\hspace{1.em}$It has 23 protons.
-   II.$\hspace{0.7em}$It has 51 nucleons.
-   III.$\hspace{0.4em}$It has a condensed electron configuration of [Ne]$4s^2\,3d^3.$

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$I, II and III

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:\
The subscript in the nuclear symbol gives the atomic number, which equals the number of protons. Vanadium has an atomic number of $23,$ so it has $23$ protons. Statement I is correct.

The superscript gives the mass number, which is the total number of nucleons (protons and neutrons combined). This isotope has $51$ nucleons: $23$ protons and $51 - 23 = 28$ neutrons. Statement II is correct.

The condensed electron configuration is incorrect because it uses the wrong noble gas core. Neon has $10$ electrons, so $[\textrm{Ne}]\,4\textrm{s}^2\,3\textrm{d}^3$ accounts for only $10 + 2 + 3 = 15$ electrons, not the $23$ that a neutral vanadium atom requires. The correct noble gas core is argon $(18$ electrons$),$ giving $[\textrm{Ar}]\,4\textrm{s}^2\,3\textrm{d}^3 = 18 + 2 + 3 = 23$ electrons. The noble gas core must be the one that immediately precedes the element in the periodic table, not any noble gas with fewer electrons. Statement III is incorrect.
