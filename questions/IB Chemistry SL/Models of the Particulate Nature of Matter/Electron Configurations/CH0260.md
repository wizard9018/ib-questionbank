# CH0260

Which element is represented by this ground$-$state orbital diagram?

![CH0260](images/CH0260.png)

- A.$\hspace{1em}\ce{C}$

- B.$\hspace{1em}\ce{O}$

- C.$\hspace{1em}\ce{N}$

- D.$\hspace{1em}\ce{F}$

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
The orbital diagram contains eight arrows, so the element has eight electrons and an atomic number of 8, which is oxygen. Carbon has 6 electrons, nitrogen has 7, and fluorine has 9, so none of these match the diagram. The ground$-$state configuration of oxygen is $1s^2\,2s^2\,2p^4,$ with two paired electrons filling the $1s$ and $2s$ orbitals and four electrons in the $2p$ subshell. Hund's rule requires that the three $2p$ orbitals are each occupied by one electron before any pairing occurs, giving two unpaired electrons and one paired pair in the $2p$ subshell.
