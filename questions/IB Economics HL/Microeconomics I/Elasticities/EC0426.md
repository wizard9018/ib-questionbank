# EC0426

**Figure 1**

![EC0426 fig1](<images/EC0426 fig1.png>)

1.  Using **Figure 1**, suggest a possible value for price elasticity of supply when price increases from $\mathrm{P_1}$ to $\mathrm{P_2}$. [1 mark]

2.  Using **Figure 1**, and your answer to part a, suggest a possible value for price elasticity of supply when price increases from $\mathrm{P_2}$ to $\mathrm{P_3}$. [1 mark]

---

## 评分标准 / Mark scheme

1.  $\underline{\textrm{Sample Answer}}$:\

    The PES could be 2.

    $\underline{\textrm{Solution}}$: \

    Any supply curve intersecting the Y axis is relatively elastic along its entire length.

    Therefore the change shown from point X to point Y will have a PES value greater than one. 

    For suggesting a PES value that exceeds 1. ($\checkmark$)

2.  $\underline{\textrm{Sample Answer}}$:\

    The PES could be 1.5.

    $\underline{\textrm{Solution}}$: \

    Any supply curve intersecting the Y axis is relatively elastic along its entire length. However, PES values approach unitary elasticity (1) as the price continues increasing. 

    Therefore, the change shown from point Y to point Z will have a PES value greater than one, but smaller than the PES value between point X and point Y. 

    For suggesting a PES value that exceeds 1, but is smaller than the PES value suggested in part a. ($\checkmark$)
