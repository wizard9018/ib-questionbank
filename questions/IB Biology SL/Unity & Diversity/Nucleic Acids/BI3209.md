# BI3209

A gene encoding green fluorescent protein (GFP) from a jellyfish is inserted into a bacterium by gene transfer. The bacterium's ribosomes successfully produce functional GFP.

What does this demonstrate about the genetic code?

A. $\hspace{1em}$ Bacteria and jellyfish have identical sets of genes, allowing the protein to be produced.

B. $\hspace{1em}$ The genetic code is conserved because the same codons generally specify the same amino acids in bacteria and jellyfish, supporting universal common ancestry.

C. $\hspace{1em}$ The bacterium evolved the ability to read jellyfish codons after exposure to the jellyfish gene.

D. $\hspace{1em}$ The genetic code differs between bacteria and jellyfish, but their ribosomes translate codons into the same amino acids.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The bacterium's protein-synthesis machinery can correctly translate the jellyfish gene because the same codons generally specify the same amino acids in both organisms. This conservation of the genetic code across different life forms supports the conclusion that they inherited the code from a universal common ancestor. **Choice B** is correct.

**Choice A** is incorrect because bacteria and jellyfish share the same genetic code, but they do not have identical sets of genes.

**Choice C** is incorrect because the bacterium did not acquire a new ability after exposure to the gene. Its existing translation machinery could already interpret the codons.

**Choice D** is incorrect because if the codons are translated into the same amino acids, the genetic code is conserved rather than different.
