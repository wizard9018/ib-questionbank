# BI3212

A student states, “ATP molecules and nucleic acid monomers are nucleotides.”

Which response correctly evaluates this statement?

A. $\hspace{1em}$ Correct because all nucleotides contain more than one phosphate group.

B. $\hspace{1em}$ Correct because both ATP and nucleic acid monomers consist of a nitrogenous base, a pentose sugar and one or more phosphate groups.

C. $\hspace{1em}$ Incorrect because ATP contains a hexose sugar, whereas nucleic acid monomers contain pentose sugars.

D. $\hspace{1em}$ Incorrect because ATP contains an amino acid rather than a nitrogenous base.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

ATP consists of the nitrogenous base adenine, the pentose sugar ribose and three phosphate groups. The monomers from which DNA and RNA are formed also contain a nitrogenous base, a pentose sugar and phosphate. Therefore, ATP and nucleic acid monomers can both be classified as nucleotides. **Choice B** is correct.

**Choice A** is incorrect because nucleotides do not all contain more than one phosphate group. A nucleotide consists of a nitrogenous base, a pentose sugar and one or more phosphate groups. ATP contains three phosphate groups, but the nucleotides incorporated into nucleic-acid polymers each contribute one phosphate group to the sugar–phosphate backbone.

**Choice C** is incorrect because ATP contains ribose, which is a pentose sugar rather than a hexose sugar.

**Choice D** is incorrect because ATP contains the nitrogenous base adenine, not an amino acid.
