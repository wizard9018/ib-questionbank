# BI0816

**Maximum mark: 10**

The micrograph shows an image of a plant cell taken with a light microscope.

1. Calculate the magnification of the image, showing your work. [2 marks]

2. Label, with the letter N, a nucleus in the image. [1 mark]

3. The image was taken using a light microscope. State how you deduce this from the image. [1 mark]

4. Draw and label a diagram to show how the same type of plant cell shown in the micrograph would appear when examined with an electron microscope. [3 marks]

5. State two differences that would be seen when looking at an electron micrograph of a bacterium cell compared to this plant cell. [2 marks]

6. At first, the student who took this image could not see the cell when focusing the microscope. Suggest what may have caused this problem. [1 mark]

 Magnification = Image size ÷ Actual size

 Image size = 39 - 35 = 4 mm

 1mm = 1000 µm

 4mm = 4000 µm

 Actual size = 50 µm

 Magnification = **4000 µm ÷ 50 µm** ($\checkmark$) = **80 x** ($\checkmark$)
