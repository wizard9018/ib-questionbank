# AI1073

**Maximum mark: 20**

Rover is out running in his favourite field with his owner Edwina.

Rover's position vector is given by $(2t-1)\textbf{\textit{i}}+(\frac{1}{2}(t-3)^3+1)\textbf{\textit{j}}$.

Edwina is standing at the position $(1, 2)$.

The unit vector $\bm i$ represents a $1$ metre displacement due east and $\bm j$ represents a $1$ metre displacement due north.

The time is measured in seconds, where $t\geq 0$.

1. 1. Find Rover's position when $t=2$.
    2. Find Rover's velocity vector at time $t$.[4 marks]

2. Find Rover's minimum speed.[3 marks]

3. At what time is Rover closest to Edwina? [3 marks]

Bessy is Rover's best friend.

At $t=2$ seconds Bessy runs onto the field near to where Rover is.

She is running in a straight line and has a position vector given by $(4t)\textbf{\textit{i}}+(8t-20)\textbf{\textit{j}}$, where $t\geq 2$.

4. 1. Find the time that Rover is travelling in the same direction as Bessy.
    2. Find Rover's velocity vector at this time.[6 marks]

At the time you found in part (d) Edwina shouts Rover's name.

Rover continues running for $1$ more second, maintaining a constant velocity which is equal to what was found in part (d).

After this he runs in a straight line back to Edwina with a speed of $3\,\text{ms}^{-1}$.

5. How long will it take him to return to Edwina after she has shouted his name? [4 marks]

## 评分标准 / Mark scheme

1. 1. Substitute $t=2$ into Rover's position vector.
        $$
        \begin{aligned}
        &(2t-1)\textbf{\textit{i}}+\left(\frac{1}{2}(t-3)^3+1\right)\textbf{\textit{j}}\\[3pt]
        &=(2\times2-1)\textbf{\textit{i}}+\left(\frac{1}{2}(2-3)^3+1\right)\textbf{\textit{j}}\\[3pt]
        &=3\textbf{\textit{i}}+\frac{1}{2}\textbf{\textit{j}}
        \end{aligned}
        $$
        Rover is at the position $\left(3, \frac{1}{2}\right)$ at $t=2$.

    2. If the position vector is given as $\textbf{\textit{r}}=x(t)\textbf{\textit{i}}+ y(t)\textbf{\textit{j}}$.

        Then the velocity vector is $\textbf{\textit{v}}=x'(t)\textbf{\textit{i}}+ y'(t)\textbf{\textit{j}}$.

        Therefore
        $$
        \begin{aligned}
            \textbf{\textit{v}}&=(2t-1)'\textbf{\textit{i}}+\left(\frac{1}{2}(t-3)^3+1\right)'\textbf{\textit{j}}\\[3pt]
            &=\boxed{2\textbf{\textit{i}}+\left(\frac{3}{2}(t-3)^2\right)\textbf{\textit{j}}}
        \end{aligned}
        $$

2. The speed is the magnitude of the velocity vector, $s=|\textbf{\textit{v}}|$.
    Using Pythagoras' theorem we can write the speed as a function of time
    $$
    \begin{aligned}
        s(t)&=\sqrt{2^2+\left(\frac{3}{2}(t-3)^2\right)^2}
    \end{aligned}
    $$
    Find the minimum of the graph of $s(t)$ against $t$ on GDC.

    Note, on your GDC use the variable $x$ instead of $t$.

    ![min](images/min.png)

    Rover's minimum speed is $2\,\text{ms}^{-1}$

3. We need to find a function that gives the distance ($d$) between Rover and Edwina at time $t$, then we can use a calculator to find the minimum value, $d_{min}$.

    Write the coordinates of Edwina and Rover using their position vectors, as shown below.

    ![posn vecs](<images/posn vecs.png>).]()

    Then use Pythagoras' theorem to find $d(t)$.
    $$
    \begin{aligned}
        d(t)&=\sqrt{((2t-1)-1)^2 + \left(\frac{1}{2}(t-3)^3+1-2\right)^2}\\[3pt]
        d_{min}&=2.4471...\text{ when }t= 1.8566...&[\text{by using G.D.C.}]
    \end{aligned}
    $$
    Note that $d_{min}$ was found using a graph.

    The minimum distance between Edwina and Rover occurs when $t=1.86 \text{ s}$.
4. 1. The important thing to note here is for Rover to travel in the same direction as Bessy their velocity vectors must be parallel.

        Let Rover's velocity vector be $\bm{v_R}$ and Bessy's velocity vector be $\bm{v_B}$.

        That means we can say that $\bm{v_R}=k\bm{v_B}$, where $k \in \mathbb{R}$.

        We already have $\bm{v_R}$ from part a) ii) so we need to find Bessy's velocity vector.
        $$
        \begin{aligned}
            \bm{v_B}&=(4t)'\textbf{\textit{i}}+(8t-20)'\textbf{\textit{j}}\\
            &=4\textbf{\textit{i}}+8\textbf{\textit{j}}
        \end{aligned}
        $$
        Recall $\bm{v_R}=k\bm{v_B}$, we need the value of $k$ and $t$ to make the following relationship true.
        $$
        \begin{aligned}
        2\textbf{\textit{i}}+\left(\frac{3}{2}(t-3)^2\right)\textbf{\textit{j}}&=k(4\textbf{\textit{i}}+8\textbf{\textit{j}})
        \end{aligned}
        $$
        By equating the vector components we can say in the $\bm i$ direction
        $$
        \begin{aligned}
            2&=4k\\
            k&=\frac{1}{2}
        \end{aligned}
        $$
        Now use this $k$ value and equate the components in the $\bm j$ direction to find the value of $t$
        $$
        \begin{aligned}
            \left(\frac{3}{2}(t-3)^2\right)&=\frac{1}{2}\times8\\
            t&=1.36..., 4.63... &[\text{by using G.D.C.}]
        \end{aligned}
        $$
        Reject $t=1.36...$ as Bessy is not on the field at this time. \
        The time in which Rover is travelling in the same direction as Bessy is $4.63\text{ seconds}$.

   2. Evaluate $\bm v_R$ at $t=4.63...$
        $$
        \begin{aligned}
            v_r&=2\bm i+\left(\frac{3}{2}(4.63-3)^2\right)\bm j\\[3pt]
            &=2 \bm i + 3.985...\bm j
        \end{aligned}
        $$
        Rover's velocity vector at $t=4.63...$ is $2 \bm i + 3.99\bm j$ metres per second.

5. The first thing to do is find the position (coordinates) of Rover at $t=4.63$s using Rover's position vector.
    $$
    \begin{aligned}
        \bm r &= (2\times 4.63-1)\bm i + \left(\frac{1}{2}(4.63-3)^3+1\right)\bm j\\[3pt]
        &=8.26\bm i + 3.165...\bm j
    \end{aligned}
    $$
    At $t=4.63$s Rover has coordinates $(8.26, 3.165)$.
    The diagram below shows this.

    ![ai1073a](images/ai1073a.PNG)

    Rover now maintains a constant velocity for $t=1$ which is equal to the vector found in (d)(ii). This is shown as the black dashed line on the diagram.

    This means his position changes by the amount given by the velocity vector after $1$ second.. Therefore, Rover's new position is given by
    $$
    \begin{aligned}
        \bm r &= 8.26\bm i + 3.165\bm j  + 2 \bm i + 3.99\bm j\\[3pt]
        &=10.26\bm i + 7.155\bm j
    \end{aligned}
    $$

    From this position Rover then runs in a straight line back to Edwina.

    We use Edwina's position to find the distance between them which is the red dashed line on the diagram.

    Note, this is parallel to Bessy's direction.
    $$
    \begin{aligned}
        d &= \sqrt{(10.26-1)^2+(7.155-2)^2}\\[6pt]
        &=10.598...\text{ metres}
    \end{aligned}
    $$

    Rover runs this final stage at $3\,\text{ms}^{-1}$ therefore it takes him $10.598...\div 3=3.5327...$s.

    Given that Rover started this run one second after Edwina called his name, it takes Rover $4.53$ seconds to return to Edwina.
