# AI1141

**Maximum mark: 17**

The following graph shows seven towns connected by rail. The weight on each edge represents the time, in minutes, it takes to travel between two towns by train.

![ai1141a](images/ai1141a.PNG)

1. Determine whether it is possible to complete a journey that uses each piece of rail exactly once. Justify your answer.[2 marks]

The shortest time, in minutes, between any two towns is given in the following table.

![ai1141b](images/ai1141b.PNG)

2. Find the value of

    1. $a$;

    2. $b$;

    3. $c$;

    4. $d$. [2 marks]

Katie is in town A and wants to travel to each town, then back to A, in the shortest time possible.

3. Using the nearest neighbour algorithm, starting at A, find an upper bound for Katie's trip.[3 marks]

4. 1. Sketch a minimum spanning tree for the subgraph containing vertices B, C, D, E, F and G.

    2. Write down the total weight of the MST.

    3. Hence find a lower bound for Katie's trip.

    4. State one way in which an improved lower bound might be found.[7 marks]

In fact, Katie's optimal trip is A-D-G-B-E-F-C-A.

5. Given that the time of each trip shown on the graph is given to the nearest minute, find the lower bound for the total time of Katie's optimal trip.[3 marks]
