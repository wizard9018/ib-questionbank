# AI482

**Maximum mark: 9**

A package delivery company offers $24$ hours delivery service to a
limited number of cities in close proximity. The directed graph below
shows four cities served (A-D) and the routes of delivery between them.

![8e7acaa11bcda82b33830c1f3ed97561958815b7.svg](images/8e7acaa11bcda82b33830c1f3ed97561958815b7.svg)

1.  Find an adjacency matrix $\bm{A}$ for the shipping network.
    [2 marks]

2.  Find the number of ways it is possible to ship a package from city C
    to city A using exactly three delivery routes. [2 marks]

3.
    1.  Find the matrix $\bm{S}_3$, where
        $\bm{S}_3 = \displaystyle \sum_{i = 1}^3 \bm{A}^i$.

    2.  Hence write down the number of ways it is possible to deliver a
        package from city A to city D using three or less delivery
        routes.

    3.  State all possible ways to ship a package from city A to city D
        using three or less delivery routes. [5 marks]
