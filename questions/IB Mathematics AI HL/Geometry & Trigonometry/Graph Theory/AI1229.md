# AI1229

**Maximum mark: 7**

Two friends, Chris and Kim, are visiting a park that has five attractions labelled $B$, $C$, $D$, $E$ and $F$. 

At the main entrance, labelled $A$, there is a table showing approximate walking times in minutes between the main entrance and the attractions along all available paths. The following table shows this information.

![ai1229a](images/ai1229a.png)

1. Show the direct paths between each location as a weighted graph. [2 marks]

Upon arrival, Chris decides to visit every attraction then return to the main entrance.

2. Starting at $A$, use the nearest neighbour algorithm to find an upper bound for Chris's trip, assuming that he does not stop at any attraction. [3 marks]

From the main entrance, Kim decides to walk along every path, without going along any path more than once.

3. State a reason why this is possible, and determine which attraction Kim will finish at. [2 marks]
