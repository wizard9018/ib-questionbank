# AI939

**Maximum mark: 7**

The function $f$ is defined by $f(x) = \dfrac{7x-24}{x-2}$,
 for $-3 \leq x \leq 12$,
 $x \neq 2$.

1.  Find the range of $f$. [3 marks]

2.  Find an expression for the inverse function $f^{-1}(x)$. [3 marks]

3.  Write down the range of $f^{-1}$. [1 mark]

2.  If we solve the equation $x = (f\circ f^{-1})(x)$ for
    $y = f^{-1}(x)$, we find
    $$
    \begin{aligned}
    x &= f(f^{-1}(x)) \\[12pt]
    x &= f(y) \\[12pt]
    x &= \dfrac{7y-24}{y-2} \\[12pt]
    x(y-2) &= 7y-24 \\[12pt]
    xy-2x &= 7y-24 \\[12pt]
    xy-7y &= 2x-24 \\[12pt]
    y(x-7) &= 2x-24 \\[12pt]
    y &= \dfrac{2x-24}{x-7} \\[12pt]
    &\hspace*{-3.01em}f^{-1}(x) = \dfrac{2x-24}{x-7}
    \end{aligned}
    $$

3.  The range of $f^{-1}(x)$ is equal to the domain of $f(x)$, therefore
    the\
    range of $f^{-1}(x)$ is
     $-3 \leq f^{-1}(x) \leq 12\text{ , } f^{-1}(x) \neq 2$
