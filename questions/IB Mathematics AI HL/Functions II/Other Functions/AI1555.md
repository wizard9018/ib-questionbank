# AI1555

**Maximum mark: 6**

Consider the function $f(x) = 2x + \dfrac{18}{x^2}$, $x > 0$.

1.  Find the coordinates of the local minimum point of $f$.[3 marks]

2.  State the range of $f$.[1 mark]

3.  Find the solutions to the equation $f(x) = 12$.[2 marks]
