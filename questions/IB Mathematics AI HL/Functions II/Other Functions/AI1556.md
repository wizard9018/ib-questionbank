# AI1556

**Maximum mark: 6**

Consider $f(x) = x^2\sqrt{25 - x^2}$, $-5 \leq x \leq 5$. The graph of $f$ for $0 \leq x \leq 5$ is shown on the following axes.

![AI1556q](images/AI1556q.JPEG)

1.  1. Sketch the graph of $f$, for $-5 \leq x < 0$, on the same axes.

    2. Find the maximum value of $f$.[4 marks]

2.  Write down the values of $x$ for which the maximum occurs.[1 mark]

3.  State the range of $f$.[1 mark]
