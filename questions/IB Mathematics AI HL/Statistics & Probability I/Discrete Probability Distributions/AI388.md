# AI388

**Maximum mark: 4**

A spinner has four sections; A, B, C, and D, as shown in the diagram
below. Half of the spinner is section A and the remaining half of the
spinner is split evenly among the three remaining sections.

![a7c2c695a57c76fedbd41387822dca72e0317831.svg](images/a7c2c695a57c76fedbd41387822dca72e0317831.svg)

A player has to pay US$$\$3$$ to spin each time. The prize for landing on
each section is given as follows.

![7c8859120db5346520e9195c6b675d9c656c8b77.svg](images/7c8859120db5346520e9195c6b675d9c656c8b77.svg)

Determine whether the game is fair and justify your answer.

---

## 评分标准 / Mark scheme

The game is considered fair if the expected value of the game is equal
to $0$. Let's find the expected value for this game.

We are given that half of the spinner is A. So we have
Pr$(A) = \dfrac 1 2$. The remaining half of the spinner is split evenly
among the three remaining sections. Hence the probability that the
spinner lands on each of the section B, C and D is
$\dfrac{1}{3} \cdot \dfrac{1}{2} = \dfrac 1 6$.

Let $X$ be the payout in one game. Deducting the ticket price of $$\$3$$
from the prizes, we get the payouts if the spinner lands on each of the
sections A, B, C and D as follows.

![fd2fa7cf3351a77623a53cbc5d9dda10ab708d87.svg](images/fd2fa7cf3351a77623a53cbc5d9dda10ab708d87.svg)

Using the formula of expected value
$E(X) = \sum_{i = 1}^n x_i \cdot \text{Pr}(X = x_i)$, we get

$$
\begin{aligned}
E(X) &=  (-1 \times \dfrac{1}{2}) + (1 \times \dfrac{1}{6}) + (4 \times \dfrac{1}{6}) + (-2 \times \dfrac{1}{6}) \\[3pt]
&= 0
\end{aligned}
$$

$\text{Since the expected value is \(0\), the game is considered to be fair.}$
