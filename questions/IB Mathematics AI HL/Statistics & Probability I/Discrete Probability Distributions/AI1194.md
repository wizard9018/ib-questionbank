# AI1194

**Maximum mark: 15**

Consider the function

$

f(x)=\dfrac{x^2-8x+16}{30} \enskip\text{ for } x \in \{0,1,2,3\}.

$

The following table can be constructed from $f(x)$:

![1194a](images/1194a.JPG)

1. Show that $a=16$ and $b=1$.[2 marks]

It is given that $f$ describes a discrete probability distribution for these values of $x$.

Maxine plays a game at a fair in which she throws a ball at a set of three skittles. It is known that the probability of knocking over $0$, $1$, $2$ or $3$ skittles is equal to the probability distribution described by $f(x)$.

2. Calculate the probability that Maxine

    

    1. Knocks over at least $2$ skittles;

    2. Knocks over at least one skittle, given that she knocks over less than $3$. [5 marks]

Maxine plays the game $6$ times in a row. In each game, the number of skittles knocked over is independent.

3. Calculate the probability that Maxine knocks over at least $2$ skittles in less than $3$ of the games she plays. [4 marks]

The game costs $$\$5.25$$ to play. If $0$ skittles are knocked down, the player receives nothing in return. If 1 skittle is knocked down, the player will make a profit of $$\$w$$. If $2$ skittles are knocked down, the player will make a profit of $$\$2w$$. If three skittles are knocked down, the player will make a profit of $$\$4w$$.

4. Given that the game is fair, find the value of $w$. [4 marks]

## 评分标准 / Mark scheme

1. We must substitute $x=0$ into our expression for $f(x)$ to find the value of $a$, and $x=3$ to find the value of $b$. We have

    $$

    \begin{aligned}

    f(0) &= \dfrac{0^2-8(0)+16}{30} \tag*{\textbf{M1}}\\[6pt]

    &= \frac{\color{red}{16}}{30} \\[6pt]

    f(3) &= \dfrac{3^2-8(3)+16}{30} \tag*{\textbf{M1}}\\[6pt]

    &= \dfrac{\color{red}{1}}{30} \\[6pt]

    &\hspace{-3em}\boxed{a = 16 \text{ and } b = 1} \tag*{\textbf{AG}}

    \end{aligned}

    $$

2. 1. Let the discrete random variable $X$ represent the number of skittles Maxine knocks over in a game. We are looking for $\mathrm{P}(X \geq 2)$. We have

        $$

        \begin{aligned}

        \mathrm{P}(X \geq 2) &= \mathrm{P}(X = 2) + \mathrm{P}(X = 3) \\[6pt]

        &= \dfrac{4}{30} + \dfrac{1}{30} \tag*{\textbf{(M1)}}\\[6pt]

        &\hspace{-4.3em}\boxed{\mathrm{P}(X \geq 2) = \frac{5}{30} \hspace{1em}\left(=\frac{1}{6}\right)} \tag*{\textbf{A1}}

        \end{aligned}

        $$

    2. Using the formula for conditional probability, we have

        $$

        \begin{aligned}

        \mathrm{P}(X \geq 1 \, | \, X < 3) &= \dfrac{\mathrm{P}(X \geq 1 \, \cap \, X < 3)}{\mathrm{P}(X < 3)} \\[6pt]

        &= \dfrac{\mathrm{P}(X = 1) + \mathrm{P}(X = 2)}{\mathrm{P}(X = 0)+\mathrm{P}(X = 1)+\mathrm{P}(X = 2)} \tag*{\textbf{(M1)}}\\[6pt]

        &= \dfrac{\frac{9}{30}+\frac{4}{30}}{\frac{16}{30}+\frac{9}{30}+\frac{4}{30}} \tag*{\textbf{(M1)}}\\[6pt]

        &\hspace{-7.9em}\boxed{\mathrm{P}(X \geq 1 \, | \, X < 3) = \frac{13}{29}} \tag*{\textbf{A1}}

        \end{aligned}

        $$

3. Let the discrete random variable $T$ represent the number of games in which Maxine knocks over at least $2$ skittles. We are looking for $\mathrm{P}(T<3)$. We can note the following:

    $\hspace{2em}\bullet$ Each trial is independent (given information)

    $\hspace{2em}\bullet$ There is a constant probability (from part (b)(i), $\mathrm{P}(X \geq 2)=\tfrac{1}{6}$)
