# AI297

**Maximum mark: 6**

During the recent English Premier League football season, the number of
matches in which a certain number of goals were scored were recorded in
the table below. For example, there were $18$ matches where $5$ goals
were scored.

![2997832c0bab4c3b2ed61095510f525d062d24a6.svg](images/2997832c0bab4c3b2ed61095510f525d062d24a6.svg)

The lower quartile for these results is $2$, and median is $3$.

1.  Write down the value of the upper quartile for these results.
    [2 marks]

2.  Draw a box-and-whisker diagram for these results. [2 marks]

3.  Find the probability that, in a randomly chosen match, the number of
    goals will be less than the upper quartile. Give your answer correct
    to **two decimal places**. [2 marks]

---

## 评分标准 / Mark scheme

1.  Let's create a cumulative frequency table for these results.

    ![d22b85d7b58098d1d99ff45e796f3ac4f643f246.svg](images/d22b85d7b58098d1d99ff45e796f3ac4f643f246.svg)

    The total number of data values (football matches) is $n = 135$.

    Using the formula $Q_3 = \dfrac 3 4 (n+1) \, \text{nd value}$, we
    get
    $$
    \begin{aligned}
    Q_3 &= \dfrac 3 4 (135+1) \, \text{nd value} \\[6pt]
    &= 102 \, \text{nd value}
    \end{aligned}
    $$
    The cumulative
    frequency table above shows that the $102$nd value belongs to the
    group including from the $84$nd value to the $107$nd value, which
    corresponds to $4$ goals in a match.

    Thus,
     $Q_3=4 \text{ goals}$.

2.  The five-number summary of the given data set is as follows.
    -   Min $= 0$

    -   $Q_1 = 2$

    -   Median $= 3$

    -   $Q_3 = 4$

    -   Max $= 9$

    Based off the summary above, we can draw the box-and-whisker diagram
    as follows.

    ![c5f71aecc94a43b40518a059208d1fe5c96d5b01.svg](images/c5f71aecc94a43b40518a059208d1fe5c96d5b01.svg)

3.  The cumulative frequency table above shows that there were $83$
    matches where less than $4$ goals were scored. Hence we obtain

    $$
    \begin{aligned}
    \text{Pr(less than 4 goals)} &= \dfrac{83}{135} \\[6pt]
    &\approx 0.61
    \end{aligned}
    $$
