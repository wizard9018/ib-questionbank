# AI402

**Maximum mark: 6**

A multiple choice exam consists of $20$ questions, with each question
containing four possible answers. Each question has only one correct
answer. Jack takes the exam and, for each question, randomly chooses one
of the four answers.

1.  Find the expected number of questions Jack answers correctly.
    [2 marks]

2.  Find the probability that Jack answers
$\\[6pt]$
    1.  exactly four questions correctly;

    2.  more than four questions correctly. [4 marks]

---

## 评分标准 / Mark scheme

1.  Let $X$ be the number of questions Jack answers correctly.
    We have $X \sim \mathrm{B}(20,1/4)$.

    Hence, using the formula for the expected value of $X$, we get

    $$
    \begin{aligned}
    \mathrm{E}[X] &= np \\[3pt]
    &= 20\times\dfrac{1}{4} \hspace{3em} \\[6pt]
    &= 5
    \end{aligned}
    $$

2.
    1.  The probability that Jack answers exactly four questions
        correctly is given by
        $$
        \begin{aligned}
        \mathrm{P}(X = 4) &= \text{binomPdf}\left(20,\,\dfrac 1 4,\,4\right) \hspace{1.35em} \\[6pt]
        &\approx 0.190\hspace{3em} [\text{by using G.D.C.}]
        \end{aligned}
        $$

    2.  The probability that Jack answers more than four questions
        correctly is given by
        $$
        \begin{aligned}
        \hspace{0.15em} \mathrm{P}(X > 4) &= \text{binomCdf}\left(20,\,\dfrac 1 4,\,5,\,20\right) \\[6pt]
        &\approx 0.585\hspace{3em} [\text{by using G.D.C.}]
        \end{aligned}
        $$
