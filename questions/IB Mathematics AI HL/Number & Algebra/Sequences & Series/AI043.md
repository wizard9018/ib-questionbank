# AI043

**Maximum mark: 6**

Let $u_n = 4n+1$, for $n \in \mathbb{Z}^+$.

1.
    1.  Using sigma notation, write down an expression for
        $u_1 + u_2 + u_3 + \dots + u_{20}$.

    2.  Find the value of the sum from **part (a) (i)**. [4 marks]

A geometric sequence is defined by $v_n = 9\times 4^{n-1}$, for
$n \in \mathbb{Z}^+$.

2.  Find the value of the sum of the geometric series
    $\displaystyle\sum_{k = 1}^5\hspace{0.1em}v_k$.[2 marks]

---

## 评分标准 / Mark scheme

1.
    1.  Using sigma notation, we have
        $$
        \begin{aligned}
        u_1 + u_2 + u_3 + \dots + u_{10} &= \sum_{k=1}^{20} u_k \\[6pt]
        &= \displaystyle\sum_{k=1}^{20} (4k+1) \hspace{8em}
        \end{aligned}
        $$

    2.  If we rewrite $u_n = 4n+1$ in the form $u_n = u_1 + (n-1)d$, we
        have
        $$
        \begin{aligned}
        \hspace{2.5em} u_n &= 5 + (n-1)(4)
        \end{aligned}
        $$
        Hence $u_n$ is
        an arithmetic sequence with the first term $u_1 = 5$ and\
        the common difference $d = 4$.

        Using the sum of $n$ terms formula
        $S_n = \dfrac{n}{2}(2u_1 + (n-1)d)$ with
        $n=20$

        we find
        $$
        \begin{aligned}
        \sum_{k=1}^{20} (4k+1) &= S_{20} \\[3pt]
        &= \dfrac{20}{2}(2u_1 + (20-1)d) \\[9pt]
        &= \dfrac{20}{2}(2(5) + (20-1)(4)) \\[14pt]
        &= 860
        \end{aligned}
        $$

2.  We have
    $$
    \begin{aligned}
    \hspace{8.3em} v_1 &= 9 \hspace{3em} [\text{the first term}] \\[9pt]
    r &= 4 \hspace{3em} [\text{the common ratio}] \\
    \end{aligned}
    $$

    Hence, using the sum of $n$ terms formula
    $S_n = \dfrac{v_1(r^n-1)}{r-1}$ with
    $n=5$, we get
    $$
    \begin{aligned}
    \sum_{k = 1}^5 9\times 4^{k-1} &= S_5 \\[3pt]
    &= \dfrac{v_1(r^5-1)}{r-1} \hspace{3.4em}  \\[9pt]
    &= \dfrac{9\hspace{0.05em}(4^5-1)}{4-1} \\[15pt]
    &= 3069
    \end{aligned}
    $$
