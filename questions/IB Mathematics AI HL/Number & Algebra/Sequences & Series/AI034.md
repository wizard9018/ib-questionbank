# AI034

**Maximum mark: 15**

Consider the sequence $u_1,\, u_2,\, u_3,\, \dots,\, u_n,\, \dots$ where

$$
\begin{aligned}
u_1 = 860,\hspace{0.3em} u_2 = 980,\hspace{0.3em} u_3 = 1100,\hspace{0.3em} u_4 = 1220.
\end{aligned}
$$

The sequence continues in the same manner.

1.  Find the value of $u_{50}$. [3 marks]

2.  Find the sum of the first $10$ terms of the sequence. [3 marks]

Now consider the sequence $v_1,\, v_2,\, v_3,\, \dots,\, v_n,\, \dots$
where
$$
\begin{aligned}
v_1 = 2,\hspace{0.3em} v_2 = 4,\hspace{0.3em} v_3 = 8,\hspace{0.3em} v_4 = 16.
\end{aligned}
$$

This sequence continues in the same manner.

3.  Find the exact value of $v_{13}$. [3 marks]

4.  Find the sum of the first $10$ terms of this sequence.
    [3 marks]

$k$ is the smallest value of $n$ for which $v_n$ is greater than $u_n$.

5.  Calculate the value of $k$. [3 marks]

---

## 评分标准 / Mark scheme

1.  The sequence $(u_n)$ is arithmetic with the common difference
    $d = 120$.

    Using the $n$th term formula $u_n = u_1 + (n-1)d$ with $n = 50$, we
    get
    $$
    \begin{aligned}
    u_{50} &= u_1 + (50-1)d \\[6pt]
    &= 860 + (50-1)(120) \\[6pt]
    &= 6740
    \end{aligned}
    $$

2.  Using the sum of $n$ terms formula
    $S_n = \dfrac{n}{2}(2u_1 + (n-1)d)$ with $n = 10$, we obtain

     $$
     \begin{aligned}
     \hspace{6.8em} S_{10} &= \dfrac{10}{2}(2u_1 + (10-1)d) \\[6pt]
     &= \dfrac{10}{2}(2(860) + (10-1)(120)) \\[11pt]
     &= 14\hspace{0.15em}000
     \end{aligned}
     $$

3.  The sequence $(v_n)$ is geometric with the common ratio $r = 2$.
    Using the $n$th term formula $v_n = v_1r^{n-1}$ with $n = 13$, we
    get
    $$
    \begin{aligned}
    v_{13} &= v_1r^{13-1} \\[6pt]
    &= 2(2)^{13-1} \\[7pt]
    &= 8192 \hspace{2.8em}
    \end{aligned}
    $$

4.  Using the sum of $n$ terms formula $S_n = \dfrac{v_1(r^n-1)}{r-1}$
    with $n = 10$, we obtain

    $$
    \begin{aligned}
    S_{10} &= \dfrac{v_1(r^{10}-1)}{r-1} \\[6pt]
    &= \dfrac{2(2^{10}-1)}{2-1} \\[12pt]
    &= 2046
    \end{aligned}
    $$

5.  Solving the inequality $v_n > u_n$ for the smallest value of $n$, we
    find
    $$
    \begin{aligned}
    \hspace{3.4em} v_1r^{n-1} &> u_1 + (n-1)d \\[8pt]
    2(2)^{n-1} &> 860 + (n-1)(120) \\[8pt]
    2^n &> 120n + 740 \\[8pt]
    n &> 11.009 \hspace{3em} [\text{by using G.D.C.}] \\
    \end{aligned}
    $$

    $$
    \hspace{1.2em} k=12 \hspace{7.8em}
    $$
