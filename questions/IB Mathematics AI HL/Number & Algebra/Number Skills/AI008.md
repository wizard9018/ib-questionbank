# AI008

**Maximum mark: 6**

Given $r = 2a - \dfrac{\sqrt{b}}{c}$, $a = 0.975$, $b = 4.41$ and
$c = 35$,

1.  calculate the value of $r$. [2 marks]

Albert first writes $a$, $b$ and $c$ correct to one significant figure
and then uses these values to estimate the value of $r$.

2.
    1.  Write down $a$, $b$ and $c$ each correct to one significant
        figure.

    2.  Find Albert's estimate of the value of $r$. [2 marks]

3.  Calculate the percentage error in Albert's estimate of the
    value of $r$. [2 marks]

---

## 评分标准 / Mark scheme

1.  Substituting $a = 0.975$, $b = 4.41$ and $c = 35$ in the expression
    for $r$, we get
    $$
    \begin{aligned}
    \hspace{2em} r &= 2(0.975) - \dfrac{\sqrt{4.41}}{35} \\[6pt]
    &= 1.89
    \end{aligned}
    $$

2.
    1.
        $a = 1,\, b = 4,\, c = 40$

    2.  Substituting $a = 1$, $b = 4$ and $c = 40$ in the expression for
        $r$, we get
        $$
        \begin{aligned}
        r &= 2(1) - \dfrac{\sqrt{4}}{40} \hspace{3.3em} \\[6pt]
        &= 1.95
        \end{aligned}
        $$

3.  Using the percentage error formula
    $\epsilon = \bigg|\dfrac{v_\mathrm{A} - v_\mathrm{E}}{v_\mathrm{E}}\bigg|\times 100\hspace{0.05em}\%$
    with $v_\mathrm{E} = 1.89$ and $v_\mathrm{A} = 1.95$, we obtain
    $$
    \begin{aligned}
    \hspace{3.75em} \epsilon &= \bigg|\dfrac{1.95 - 1.89}{1.89}\bigg|\times 100\hspace{0.05em}\% \\[6pt]
    &\approx 3.17\hspace{0.05em}\%
    \end{aligned}
    $$
