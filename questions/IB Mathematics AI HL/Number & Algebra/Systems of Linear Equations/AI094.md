# AI094

**Maximum mark: 6**

Data scientists, web designers and developers are paid according to an
$\text{industry}$ standard. The total annual salary spend for
three tech startups paying to the industry standard are summarised in
the table below.

![5881581baa8ab10a2984e4bc9a4c51bbabb53f5c.svg](images/5881581baa8ab10a2984e4bc9a4c51bbabb53f5c.svg)

Let $x$, $y$ and $z$ represent the salaries, in thousand dollars, for
data scientists, web designers and web developers respectively.

1.  Write down a system of three linear equations in terms of $x$, $y$
    and $z$\
    that represent the information in the table above. [2 marks]

2.  Using matrices, solve the system of linear equations from **part
    (a)**\
    to determine the salaries for the three roles. [2 marks]

Data Quant is a tech startup that also pays to the industry standard and
employs $10$ data scientists, $4$ web designers and $6$ web developers.

3.  Calculate the exact value of the total salary bill for Data
    Quant. [2 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}

    \begin{array}{rcccccl}
    x &+& 4y &+& 4z &=& 531.3 \\[3pt]
    8x &+& 2y &+& 5z &=& 1164 \\[3pt]
    4x &+& 5y &+& 10z &=& 1224.4
    \end{array}  \hspace{2em}
    \end{aligned}
    $$

2.  If we express the system of linear equations $(1)$ as a matrix
    equation, we have

    ![5bd3febb65c57b9290269b33685e039747728b41.svg](images/5bd3febb65c57b9290269b33685e039747728b41.svg)

    Hence, if we solve the matrix equation $(2)$, we get

    ![feafda106f57e3c9281f5952b79ab385ba004425.svg](images/feafda106f57e3c9281f5952b79ab385ba004425.svg)

    Hence the salaries for the three roles are
    $$
    \begin{aligned}
    \text{Data Scientist}&: \hspace{0.75em} \hspace{0.525em}\$96\hspace{0.15em}100 \\[6pt]
    \text{Web Designer}&: \hspace{0.75em} \hspace{0.525em}\$49\hspace{0.15em}600 \\[6pt]
    \text{Web Developer}&: \hspace{0.75em} \hspace{0.525em}\$59\hspace{0.15em}200
    \end{aligned}
    $$

3.  The total salary bill for Data Quant is
    $$
    \begin{aligned}
    10\times96\hspace{0.15em}100 + 4\times49\hspace{0.15em}600 + 6\times59\hspace{0.15em}200 &= \hspace{0.525em}\$1\hspace{0.15em}514\hspace{0.15em}600 \hspace{1em}
    \end{aligned}
    $$
