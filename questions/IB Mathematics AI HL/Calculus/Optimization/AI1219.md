# AI1219

**Maximum mark: 8**

The following function models a company’s profit (in thousands of dollars) over time, where $x$ is the number of weeks since launch

$P(x) = 4x^3 - 31x^2 + 68x - 27, \quad \text{for } 0 \leq x \leq 5$

1. 1. Find the derivative $P'(x)$.

    2. Hence, find the value of $x$ at which the function has a local maximum. [3 marks]

2. Calculate $P'(1)$ and interpret this value in context. [3 marks]

3. Determine the maximum profit (in thousands of dollars) over the interval $0 \leq x \leq 5$.[2 marks]
