# AI1186

**Maximum mark: 5**

The slope field for the differential equation $\dfrac{\mathrm{d}y}{\mathrm{d}x}=\sin x - y$ is shown in the following graph, for $0 \leq x \leq \pi$.

![1186a](images/1186a.JPG)

1. Sketch a curve that represents the points where $\dfrac{\mathrm{d}y}{\mathrm{d}x}=0$.[2 marks]

2. Calculate the value of $\dfrac{\mathrm{d}y}{\mathrm{d}x}$ at the point $(0, 0.5)$.     [1 mark]

3. Sketch the solution curve that passes through the point $(0,0.5)$.      [2 marks]

---
