# AI1240

**Maximum mark: 17**

The following diagram shows the slope field for $\dfrac{\mathrm{d}y}{\mathrm{d}x}=\dfrac{1}{2x^3}-\dfrac{2y}{x}$, for $0 \leq x \leq 2$.

![ai1240a](images/ai1240a.png)

The curve shown in the diagram represents the points where $\dfrac{\mathrm{d}y}{\mathrm{d}x}=0$.

1. Find the equation of this curve.

[2 marks]

2. On the diagram, sketch the solution curve that passes through the point $\left(1,\frac{1}{2}\right)$.[3 marks]

3. Use Euler's method with a step size of 0.1 to approximate the $y$-value for the solution curve found in part (b) when $x=2$.[3 marks]

It is given that the general solution to the differential equation is $y=\frac{\ln x + C}{2x^2}$.

4. By differentiating the given function, verify that this is true.

[4 marks]

5. Hence, determine the true value of $y$ when $x=2$ for the solution curve in part (b).[3 marks]

6. With reference to your answer in part (b), explain why Euler's method has underestimated the true value of $y$ when $x=2$.[2 marks]

## 评分标准 / Mark scheme

1. We have

    $$

    \begin{aligned}

    \frac{\mathrm{d}y}{\mathrm{d}x} &= \frac{1}{2x^3}-\frac{2y}{x} \\[8pt]

    0 &= \frac{1}{2x^3}-\frac{2y}{x} \tag*{\textbf{(M1)}}\\[8pt]

    \frac{2y}{x} &= \frac{1}{2x^3} \\[8pt]

    y &= \frac{x}{2(2x^3)} \\[8pt]

    &\hspace{-0.85em}\boxed{y = \frac{1}{4x^2}} \tag*{\textbf{A1}}

    \end{aligned}

    $$

2. To draw the solution curve on the slope field, we must ensure that we

    - Pass through the point $\left(1,\frac{1}{2}\right)$

    - Have a maximum at the point where the solution curve intersects the function $y=\frac{1}{4x^2}$. Any solution curve must have a stationary point on the function $y=\frac{1}{4x^2}$, and because the slope field shows positive gradients to the left and negative gradients to the right, the stationary point must be a maximum.

    - Follow the slope field to produce a smooth curve.

    The solution is shown in $\text{\color{blue}{blue}}$ on the following diagram.

    ![ai1240b](images/ai1240b.png)

    $$

    \begin{aligned}

    &\hspace{-5em}\text{Pass through the point $\left(1,\frac{1}{2}\right)$} \tag*{\textbf{A1}}\\[8pt]

    &\hspace{-5em}\text{Maximum at point where curve intersects  $y=\frac{1}{4x^2}$} \tag*{\textbf{A1}}\\[8pt]

    &\hspace{-5em}\text{Follow the slope field to produce a smooth curve.} \tag*{\textbf{A1}}

    \end{aligned}

    $$

3. We have $h=0.1$ and we can use the point given in part (b) as $(x_0,y_0)$. Therefore $x_0=1$ and $y_0=0.5$.

    Our formulae to generate the next set of values will be

    $$

    \begin{aligned}

    x_{n+1} &= x_n + h \\[8pt]

    &= x_n + 0.1 \\[20pt]

    y_{n+1} &= y_n + h \times f(x_n,y_n) \\[8pt]

    &= y_n + 0.1 \times \left(\frac{1}{2x_n^3} - \frac{2y_n}{x_n}\right) \tag*{\textbf{(M1)}}

    \end{aligned}

    $$

    Using the G.D.C., we can perform 10 iterations of Euler's method, which will take us from $x_0=1$ to $x_{10}=2$. This is shown in the following table.

    \begin{aligned}

    | 1 | 1.1 | 0.45 |

    | 2 | 1.2 | 0.4057... |

4. Using the quotient rule, we can differentiate the function we have been given. Letting $u=\ln x + C$, and $v=2x^2$, we have

    $$

    \begin{aligned}

    \frac{\mathrm{d}u}{\mathrm{d}x} &= \frac{1}{x} \\[8pt]

    \frac{\mathrm{d}v}{\mathrm{d}x} &= 4x \tag*{\textbf{A1}}

    \end{aligned}

    $$

    We can substitute these expressions into the quotient rule formula.

    $$

    \begin{aligned}

    \frac{\mathrm{d}y}{\mathrm{d}x} &= \frac{v\frac{\mathrm{d}u}{\mathrm{d}x} - u\frac{\mathrm{d}v}{\mathrm{d}x}}{v^2} \\[8pt]

    &= \frac{2x^2\left(\frac{1}{x}\right) - (\ln x + C)(4x)}{\left(2x^2\right)^2} \tag*{\textbf{M1}}\\[8pt]

    &= \frac{2x-(\ln x + C)(4x)}{4x^4} \\[8pt]

    &= \frac{2x}{4x^4} - \frac{(\ln x + C)(4x)}{4x^4} \tag*{\textbf{M1}}\\[8pt]

    &= \frac{1}{2x^3} - \frac{\ln x + C}{x^3} \\[8pt]

    \frac{\mathrm{d}y}{\mathrm{d}x} &= \frac{1}{2x^3} - \frac{2}{x} \times \color{red}{\frac{\ln x + C}{2x^2}} \tag*{\textbf{A1}}

    \end{aligned}

    $$

    In the last step, we have deliberately split the second term into two factors. The second factor, written in $\color{red}{\text{red}}$, is equal to the expression we were given for $y$ at the start of part (d). We can therefore write this as

    $$

    \begin{aligned}

    \frac{\mathrm{d}y}{\mathrm{d}x} &= \frac{1}{2x^3} - \frac{2y}{x} \tag*{\textbf{AG}}

    \end{aligned}

    $$

    This is identical to the differential equation we were given at the start of the question, therefore we have verified that $y=\frac{\ln x + C}{2x^2}$ is the general solution, as required.

5. For the solution in part (b) we have that $y=\frac{1}{2}$ when $x=1$. We can use this information to find the value of $C$. We have

    $$

    \begin{aligned}

    \frac{1}{2} &= \frac{\ln 1 + C}{2(1)^2} \\[8pt]

    \frac{1}{2} &= \frac{C}{2} \\[8pt]

    C &= 1 \tag*{\textbf{(A1)}}

    \end{aligned}

    $$

    Hence the specific solution is $y=\frac{\ln x + 1}{2x^2}$, into which we can substitute the value $x=2$. We have

    $$

    \begin{aligned}

    y(2) &= \frac{\ln 2 + 1}{2(2)^2} \tag*{\textbf{(M1)}}\\[8pt]

    &= 0.2116...

    \end{aligned}

    $$

    $$\boxed{\text{The true value is $y(2)=0.212\,$}} \hspace{1em}\text{(3 s.f.)}$$ 

    $$

    \begin{aligned}

    \tag*{\textbf{A1}}

    \end{aligned}

    $$

6. From part (c), we have an estimate of $y(2) \approx 0.2024...$ using Euler's method. 

    From part (e), we have the true value of $y(2)=0.2116...$

    If we now examine our graph of the solution curve, we could note that **it is concave up for the interval** $\bm{1 \leq x \leq 2}$, which is the domain of values we used to make our estimate using Euler's method. 

    $$

    \begin{aligned}

    \tag*{\textbf{(A1)}}

    \end{aligned}

    $$

    In fact, the graph has a point of inflexion at $x=0.8464...$ This is marked on the following diagram. (This is not required for the question, but it is useful information)

    For $\color{blue}{x < 0.8464...}$ the graph is concave down and for $\color{green}{x > 0.8464...}$ the graph is concave up.

    ![ai1240c](images/ai1240c.png)

    When we use Euler's method, we move in a straight line from our starting point, $x_0=1$, in the direction of the gradient at that point. We do not adjust our direction until we get to our second point, which is $x_2=1.1$, because our step size was $h=0.1$.

    However, the curve has been changing gradient constantly between $x=1$ and $x=1.1$, getting shallower (because it is concave up). Using Euler's method we can never compensate for the discrepancy, and will always have an estimate that is lower than the true value.

    $\text{Euler's method will always underestimate when a function is concave up.}$

    $$

    \begin{aligned}

    \tag*{\textbf{R1}}

    \end{aligned}

    $$
