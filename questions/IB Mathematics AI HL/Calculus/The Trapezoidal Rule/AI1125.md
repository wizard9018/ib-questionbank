# AI1125

**Maximum mark: 8**

 The following diagram shows the cross section of a small pond in a park.

![q1125v1](images/q1125v1.png)

The following is a table with the approximated water depths at each meter measured along the $x$ axis:

![q1125v2](images/q1125v2.png)

1.  Estimate the area of the shaded region, giving your answer to two decimal places. [2 marks]

The equation of the curve was found to be $y = \dfrac{1}{180}\left(10x^3-45x^2-120x-2\right)$.

2.  Write an integral that represents the area of the shaded region. [2 marks]

3.  Find the area of the shaded region, giving your answer to $2$ decimal places. [2 marks]

4.  Find the percentage error in the estimation.[2 marks]

---

## 评分标准 / Mark scheme

1.  Let's partition the shaded region into trapezoids using the given points as follows.

    ![a1125v1](images/a1125v1.png)

    From the diagram, we see that the strip width is $h = 1 - 0 = 1$.

    Using the formula for the trapezoidal rule, we get
    $$
    \begin{aligned}
        A &= \dfrac{1}{2}h \left( (y_0 + y_n) + 2(y_1 + y_2 + \dots + y_{n-1} ) \right) \\[8pt]
            &= \dfrac{1}{2}(1.0) \left[ (0 + -1.01) +  2 \left(-0.87 -1.90 -2.76 - 3.12 -2.65 \right)  \right] \tag*{\textbf{M1}}\\[9pt]
            &= -11.805
    \end{aligned}
    $$
    As the area is below the $x$-axis the value is negative. We can therefore ignore the negative value when evaluating the area.
    $$
    \begin{aligned}
        &\hspace{0.275em}\approx 11.81 \text{ units}^2 \tag*{\textbf{A1}}
    \end{aligned}
    $$

2.  The area of the shaded region is determined by
    $$
    \begin{aligned}
        &\hspace{-2.7mm}A = \int_0^6 \dfrac{1}{180}\left(10x^3-45x^2-120x-2\right) \, \mathrm{d}x \tag*{\textbf{A2}}
    \end{aligned}
    $$

3.  Evaluating the integral in part (b), we get
    $$
    \begin{aligned}
        A &= \int_0^6 \dfrac{1}{180}\left(10x^3-45x^2-120x-2\right)\, \mathrm{d}x \\[9pt]
        &=-12.0666...\hspace{1em}[\text{by using G.D.C.}] \tag*{\textbf{A1}}
    \end{aligned}
    $$
    We ignore the negative sign. Therefore
    $$
    \begin{aligned}
            A=&\hspace{0.575em}12.07 \text{ units}^2 \hspace{3em}  \tag*{\textbf{A1}}
    \end{aligned}
    $$

4.  The percentage error between the estimation in part (a) and the exact value in part (c) can be found using the percentage error formula
    $$
    \begin{aligned}
        \text{[\% error]} &= \left|\dfrac{V_A-V_E}{V_E}\right| \times 100\% \\[8pt]
                        &= \left|\dfrac{ 11.81...- \left(12.06...\right)}{12.06...\rule[-2mm]{0pt}{7.2mm}}\right| \times 100\% \tag*{\textbf{M1}}\\[8pt]
                        &\hspace{0.275em}\boxed{= 2.17 \%}\tag*{\textbf{A1}}
    \end{aligned}
    $$
