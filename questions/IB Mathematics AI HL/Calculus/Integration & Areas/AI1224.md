# AI1224

**Maximum mark: 10**

The following diagram shows the uniform cross-section of a building that has been designed to look like a tent when viewed from certain angles.

![ai1224a](images/ai1224a.png)

The roofline of the building is defined by the following piecewise function

$$

\begin{equation*}

f(x) = \left\{\begin{array}{lcl}

2\left(\sqrt[5]{\frac{5}{2}}\right)^x, && 0 \leq x \leq 5, \\[10pt]

ax^2+bx+c, && 5 < x < 15, \\[10pt]

2\left(\sqrt[5]{\frac{5}{2}}\right)^{p-x}, && 15 \leq x \leq 20,

\end{array} \right. \\[4pt]

\end{equation*}

$$

Where $a,b,c \in \mathbb{R}$, and $p \in \mathbb{Z}$. The width of the cross-section, $x$, and the height, $f(x)$, are measured in metres. 

1. Calculate $f(5)$. [2 marks]

The section of $f(x)$ in the domain $5 < x < 15$ is a parabola with vertex at $(10,3)$.

2. Find the values of $a$, $b$ and $c$. [3 marks]

It is given that $f(20)=2$.

3. Find the value of $p$. [2 marks]

4. Hence find the area of the cross-section. [3 marks]

---

## 评分标准 / Mark scheme

1. At $x=5$, $f(x)=2\left(\sqrt[5]{\frac{5}{2}}\right)^x$. We have

    $$

    \begin{aligned}

    f(5) &= 2\left(\sqrt[5]{\frac{5}{2}}\right)^5 \tag*{\textbf{(M1)}}\\[8pt]

    &= \boxed{5} \tag*{\textbf{A1}}

    \end{aligned}

    $$

2. From part (a), we have that $f(5)=5$. The parabola must pass through the point $(5,5)$. And, because it is symmetrical about the vertex at $(10,3)$, it must also pass through the point $(15,5)$. 

    $$

    \begin{aligned}

    \tag*{\textbf{(R1)}}

    \end{aligned}

    $$

    This information is shown in the following diagram.

    ![ai1224b](images/ai1224b.png)

    Performing a quadratic regression on the points $(5,5)$, $(10,3)$ and $(15,5)$, 

    $$

    \begin{aligned}

    \tag*{\textbf{(M1)}}

    \end{aligned}

    $$

    We find that

    $$

    \begin{aligned}

    \boxed{a = 0.08, b = -1.6, c=11} \tag*{\textbf{A1}}

    \end{aligned}

    $$

    For the domain $5 < x < 15$, $f(x)=0.08x^2-1.6x+11$.

3. Given that $f(20)=2$, we can form an equation in $p$:

    $$

    \begin{aligned}

    f(x) &= 2\left(\sqrt[5]{\frac{5}{2}}\right)^{p-x} \\[15pt]

    2 &= 2\left(\sqrt[5]{\frac{5}{2}}\right)^{p-20} \tag*{\textbf{(M1)}}

    \end{aligned}

    $$

    Using the numerical solver on the G.D.C. (or noting that $p-20$ must equal 0), 

    We find that $\boxed{p=20}$ 

    $$

    \begin{aligned}

    \tag*{\textbf{A1}}

    \end{aligned}

    $$

4. The function $f$ is now fully defined.

    $$

    \begin{equation*}

    f(x) = \left\{\begin{array}{lcl}

    2\left(\sqrt[5]{\frac{5}{2}}\right)^x, && 0 \leq x \leq 5, \\[16pt]

    0.08x^2-1.6x+11, && 5 < x < 15, \\[16pt]

    2\left(\sqrt[5]{\frac{5}{2}}\right)^{20-x}, && 15 \leq x \leq 20.

    \end{array} \right. \\[4pt]

    \end{equation*}

    $$

    The area of the cross-section will be the sum of the three areas shown below, divided by the dashed lines.

    ![ai1224c](images/ai1224c.png)

    Noting that a definite integral gives the area bound by a curve and the $x$-axis, we can form an expression for the total area of the cross-section using the sum of three integrals.

    $$

    \begin{aligned}

    A &= \color{red}{\displaystyle{\int_{0}^{5}}2\left(\sqrt[5]{\frac{5}{2}}\right)^x\,\mathrm{d}x} \, \color{darkblue}{ + \displaystyle{\int_{5}^{15}}0.08x^2-1.6x+11\,\mathrm{d}x \, + } \color{green}{\displaystyle{\int_{15}^{20}}2\left(\sqrt[5]{\frac{5}{2}}\right)^{20-x}\,\mathrm{d}x} \tag*{\textbf{(A1)}}

    \end{aligned}

    $$

    Using the G.D.C.,

    $$

    \begin{aligned}

    \tag*{\textbf{(M1)}}

    \end{aligned}

    $$

    We find that

    $$

    \begin{aligned}

    A &= 16.37... + 36.66 + 16.37... \\[8pt]

    &= 69.40... \\[8pt]

    & = \boxed{69.4\,\text{m}^2}\hspace{0.525em}\text{ (3 s.f.)} \tag*{\textbf{A1}}

    \end{aligned}

    $$
