# AI984

**Maximum mark: 16**

A particle moves along the $x$-axis so that its velocity,
$v$ m s$^{-1}$ at time
$t$ seconds, is given by the equation
$$
\begin{aligned}
v(t) &= 10\hspace{0.1em}e^{-\frac{t}{4}} - 5\\
\end{aligned}
$$

1.  Find the time at which the particle changes direction. [3 marks]

2.  Find the magnitude of the particle's acceleration at time $t = 2$
    seconds. [4 marks]

The particle starts from the origin O.

3.  Find an expression for the displacement of the particle
    from O at time
    $t$ seconds. [4 marks]

4.  Find the time at which the particle returns to the origin.
    [2 marks]

5.  Calculate the total distance travelled by the particle by
    the time it has
    returned to the origin. [3 marks]

---

## 评分标准 / Mark scheme

1.  When the particle changes direction, $v(t)$ changes sign and hence $v(t) = 0$. If we sketch $v(t)$ for $t \in [0,5]$, we get

    ![AI984a](images/AI984a.PNG)

    $$
    \begin{aligned}
    10\hspace{0.1em}e^{-\frac{t}{4}} - 5 &= 0 \\[8pt]
    t &\approx 2.773 \hspace{3em} {[\text{by using G.D.C.}]} \\
    \end{aligned}
    $$

    For $0 \leq t < 2.773$, $v(t) > 0$, and for $t > 2.773$, $v(t) < 0$.

    At $t \approx 2.773$, $v(t) = 0$ and changes sign. Therefore,

     $\text{The particle changes direction after approximately \(2.77\) seconds.}$

2.  If we dif$\text{f}$erentiate $v(t)$ with respect to $t$, we
    obtain
    $$
    \begin{aligned}
    a(t) &= v'(t) \\[11pt]
    &= \dfrac{\mathrm{d}}{\mathrm{d}t}\big[10\hspace{0.1em}e^{-\frac{t}{4}} - 5\big] \\[11pt]
    &= -2.5\hspace{0.1em}e^{-\frac{t}{4}} \\
    \end{aligned}
    $$

    Hence, evaluating $|a(t)|$ for $t = 2$, we find
    $$
    \begin{aligned}
    |a(2)| &= |-2.5\hspace{0.1em}e^{-\frac{2}{4}}| \\[12pt]
    &\approx 1.516
    \end{aligned}
    $$

     $\text{After 2 seconds, the magnitude of the acceleration is approximately \(1.52\)\hspace{0.25em}m\hspace{0.1em}s\(^{-2}\).}$

3.  If we integrate $v(t)$ with respect to $t$, we get
    $$
    \begin{aligned}
    s(t) &= \int v(t)\,\mathrm{d}t \\[11pt]
    &= \int \big[10\hspace{0.1em}e^{-\frac{t}{4}} - 5\big] \hspace{0.075em}\mathrm{d}t \\[11pt]
    &= \dfrac{10\hspace{0.1em}e^{-\frac{t}{4}}}{-\frac{1}{4}} - 5t + C \hspace{3em}{\text{$[\text{for some $C \in \mathbb{R}$}]$}} \\[11pt]
    &= -40\hspace{0.1em}e^{-\frac{t}{4}} -5t + C
    \end{aligned}
    $$
    Given
    that $s(0) = 0$,
    $$
    \begin{aligned}
    0 &= -40\hspace{0.1em}e^{-\frac{0}{4}} -5(0) + C \\[11pt]
    0 &= -40 + C \\[11pt]
    C &= 40
    \end{aligned}
    $$
    Therefore
     $s(t) = 40 - 40\hspace{0.1em}e^{-\frac{t}{4}} -5t$

4.  Solving $s(t)=0$, we obtain
    $$
    \begin{aligned}
    0 &= 40 - 40\hspace{0.1em}e^{-\frac{t}{4}} -5t \\[12pt]
    t &= 0 \text{ or } t \approx 6.374 \hspace{3em} {[\text{by using G.D.C.}]}
    \end{aligned}
    $$

     $\text{The particle returns to the origin after approximately \(6.37\) seconds.}$

5.  If we integrate $|v(t)|$ with respect to $t$ from $0$ to $6.37$, we
    find
    $$
    \begin{aligned}
    \text{total distance} &= \int_0^{6.37} |v(t)| \,\mathrm{d}t \\[11pt]
    &= \int_0^{6.37} |10\hspace{0.1em}e^{-\frac{t}{4}} - 5| \,\mathrm{d}t \hspace{2.6em} \\[11pt]
    &\approx 12.26 \hspace{3em} {[\text{by using G.D.C.}]}
    \end{aligned}
    $$

     $\text{By the time the particle has returned to the origin, it has travelled approximately \(12.3\) metres.}$
