# AI655

**Maximum mark: 6**

An object is moving along a straight line from a point P. The velocity
$v$, in m s$^{-1}$, is given by the function
$v(t) = 2 - e^{-\sin t^3}$ where $t \geq 0$ is measured in seconds.

1.  Write down the first two times $t_1,t_2 > 0$ when the object changes
    direction.[2 marks]

2.
    1.  Find the time $0 < t < t_2$ when the object has a maximum
        velocity.

    2.  Find the time $0 < t < t_2$ when the object has a minimum
        velocity. [2 marks]

3.  Find the distance travelled by the object between times $t = t_1$
    and $t = t_2$.[2 marks]

---

## 评分标准 / Mark scheme

1.  The object changes direction when
    $$
    \begin{aligned}
    v(t)    & =  0 \hspace{8.4cm}\\[4pt]
    2 - e^{-\sin t^3} & =  0 \\
    \end{aligned}
    $$

    $$
    \hspace{.275em}t  \approx  1.58 \text{ sec and } 1.77 \text{ sec} \quad \quad \quad [\text{by using G.D.C.}]
    $$

2.
    1.  Using G.D.C., we get
           $t_\text{velocity-max} \approx 1.16\hspace{0.25em}\text{sec}.$
    2.  Using G.D.C., we
        get   $t_\text{velocity-min} \approx 1.68\hspace{0.25em}\text{sec}.$

3.  The distance $d$ travelled by the object is given by
    $$
    \begin{aligned}
    d & =   \int_{1.58}^{1.77} \left|2 - e^{-\sin t^3}\right| \textrm dt  \\[12pt]
    & \hspace{.275em}\approx  0.0877\hspace{0.25em}\text{m} \quad \quad \quad [\text{by using G.D.C.}]
    \end{aligned}
    $$
