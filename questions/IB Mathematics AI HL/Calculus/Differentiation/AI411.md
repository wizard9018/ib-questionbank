# AI411

**Maximum mark: 18**

The following diagram shows the graph of the function

$$
f(x)=ax^3 + bx^2 + cx + d, \text{for } -2 \leq x \leq 2.
$$

![c2bce2d96c6c24424ea9224355d79d9f91abe8f5.svg](images/c2bce2d96c6c24424ea9224355d79d9f91abe8f5.svg)

1.  State whether the function is increasing or decreasing at
    $x = -1, 0$ and $1$. [3 marks]

2.  Write down the value of $d$. [1 mark]

The values of $a$ and $b$ are such that
$f(x) = -x^3 + \dfrac{x^2}{2} + cx + d$.

3.  Point K$(-1, -1)$ lies on the graph of $y = f(x)$. Find the
    value of $c$. [2 marks]

4.  Use your graphic display calculator to find the coordinates
    of the local maximum, M.[2 marks]

5.  Find $f'(x)$. [2 marks]

6.
    1.  Calculate $f'(0)$.

    2.  Find the equation of the tangent to the graph at the point
        $(0, -1)$.

    3.  Write down the gradient of the normal to the graph at $x = 0$.
        [5 marks]

7.  Use your graphic display calculator to find the $x$
    coordinates where $f(x) = -x$, for the given
    domain. [3 marks]

## 评分标准 / Mark scheme

1.  By inspection, we find that
    $$
    \begin{aligned}
    x = -1 &: \hspace{0.75em}\text{the function is decreasing} \\[6pt]
    x = 0 &: \hspace{0.75em}\text{the function is increasing} \\[6pt]
    x = 1 &: \hspace{0.75em}\text{the function is decreasing}
    \end{aligned}
    $$

2.  If we substitute $x = 0$ into $f(x)$, we get $f(0) = d$. Hence $d$
    is the $y$-intercept of the graph. The graph shows that the
    $y$-intercept is $-1$.

    Therefore,  $d = -1$
     .

3.  From part (b), we found that $d = -1$. So far the function can be
    written as $f(x) = -x^3 + \dfrac{x^2}{2} + cx - 1$. Substituting in
    the coordinates of K$(-1,-1)$ to find $c$, we get
    $$
    \begin{aligned}
    f(x) &= -x^3 + \dfrac{x^2}{2} + cx - 1 \\[-1.25pt]
    -1 &= -(-1)^3 + \dfrac{(-1)^2}{2} + c(-1) -1 \\[-1.25pt]
    -1 &= 1 + \dfrac{1}{2} - c -1 \\[-1.25pt]
    -1 &= \dfrac{1}{2} - c \\[6pt]
    &\hspace{-0.4em}c = \dfrac{3}{2}
    \end{aligned}
    $$

4.  Using parts (b) and (c), we have the complete function as follows.
    $$
    f(x) = -x^3 + \dfrac{x^2}{2} + \dfrac{3}{2}x - 1
    $$

    By using GDC, we get
     $\text{M}\hspace{0.1em}(0.893, 0.026)$

5.  Differentiating $f(x)$, we get
    $$
    \begin{aligned}
    f(x) &= -x^3 + \dfrac 1 2 x^2 + \dfrac 3 2 x - 1 \\[6pt]
    f'(x) &= -(3x^{2}) + \dfrac 1 2 (2x^{1}) + \dfrac 3 2 (x^{0}) \\[6pt]
    & \hspace{0.525em}= -3x^2 + x + \dfrac 3 2
    \end{aligned}
    $$

6.
    1.  Substituting $x = 0$ into $f'(x)$, we get
        $$
        \begin{aligned}
        f'(0) &= -3(0)^2 + 0 + \dfrac 3 2 \\[6pt]
        & \hspace{0.525em}= \dfrac 3 2
        \end{aligned}
        $$

    2.  The gradient of the tangent line ($m$) at point $(0,-1)$ is
        $f'(0) = \dfrac 3 2$. Using the point-slope formula for a
        straight line, we get
        $$
        \begin{aligned}
        y - y_1 &= m(x - x_1) \\[3pt]
        y - (-1) &= \dfrac 3 2 (x - 0) \\[3pt]
        y + 1 &= \dfrac 3 2 x \\[6pt]
        & \hspace{-0.6em}y = \dfrac 3 2 x - 1
        \end{aligned}
        $$

    3.  The gradient of the tangent ($m_T$) at $x = 0$ is $\dfrac 3 2$.
        We can find the gradient of the normal ($m_N$) using the
        relationship of the gradients of perpendicular lines, as follows

        $$
        \begin{aligned}
        m_N &= \dfrac{-1}{m_T} \\[3pt]
        &= \dfrac{-1}{3/2} \\[6pt]
        & \hspace{0.525em}= -\dfrac 2 3
        \end{aligned}
        $$
