# AI416

**Maximum mark: 6**

Consider the function $f(x) = x^3 - 6x^2 + 5x + 18$. Part of the graph
of $f$ is shown below.

![cb43ccf36b7c8052efb237974883947bb0183950.svg](images/cb43ccf36b7c8052efb237974883947bb0183950.svg)

1.  Find $f'(x)$. [3 marks]

2.  There are two points at which the gradient of the graph of $f$ is
    $20$. Find the $x$-coordinates of these points. [3 marks]

---

## 评分标准 / Mark scheme

1.  Differentiating $f(x)$, we get
    $$
    \begin{aligned}
    f'(x) &= \dfrac{\mathrm{d}}{\mathrm{d}(x)}(x^3 - 6x^2 + 5x+ 18) \\[3pt]
    &= 3x^{2} - 6(2x^{1}) + 5x^{0} + 0 \\[6pt]
    &\hspace{0.525em}= 3x^2 - 12x + 5
    \end{aligned}
    $$

2.  Substituting $f'(x) = 20$, we get
    $$
    \begin{aligned}
    3x^2 - 12x + 5 &= 20 \\[3pt]
    3x^2 - 12x - 15 &= 0 \\[6pt]
    &\hspace{-5.325em}x = -1 \text{ or } x = 5  \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$
