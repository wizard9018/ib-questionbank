# AI1182

**Maximum mark: 7**

A curve has equation $f(x) = ax^3 +bx^2 -7x + 3$.

1. Find an expression for $f'(x)$.     [1 mark]

It is given that when $x = 1$, the curve has a minimum. 

2. Show that $3a + 2b = 7$.      [2 marks]

It is also given that $f(1)=0$.

3. Find a second equation in terms of $a$ and $b$.          [2 marks]

4. Hence find the value of $a$ and the value of $b$.              [2 marks]
