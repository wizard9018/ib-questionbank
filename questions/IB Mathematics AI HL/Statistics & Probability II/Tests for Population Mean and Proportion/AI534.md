# AI534

**Maximum mark: 6**

A group of IB students form a study group to revise for their upcoming
IB mathematics exams. The number of questions the group solves each hour
can be modelled by a Poisson distribution.

One of the students, Julia, claims that the average number of questions
the group solves per hour is five. Another student, Roger, disagrees
with Julia and believes it is less than five.

Roger decides to set up the following test. He will record the number of
questions the group solves for one hour and if it is less than $4$
questions he will reject Julia's claim.

1.  State the null and alternative hypotheses for Roger's test.
    [1 mark]

2.  Find the probability of a Type I error. [2 marks]

The average number of questions the group solves in an hour is actually
found to be $4.2$.

3.  Find the probability of a Type II error. [3 marks]

---

## 评分标准 / Mark scheme

1.  Let $m$ represent the average number questions the group solves per
    hour. We have
    $$
    \begin{aligned}
    &\text{H}_0 : m = 5 \\[6pt]
    &\text{H}_1 : m < 5
    \end{aligned}
    $$

2.  Recall in hypothesis testing a Type I error refers to the case where
    the null hypothesis is rejected while it is true.

    Let $X$ be the number of questions the group solves per hour. The
    probability of a Type I error in this case is
    $$
    \begin{aligned}
    \mathrm{P}(\text{type I error}) &= \text{P}(X < 4 \hspace{0.15em}|\hspace{0.15em} m = 5)\\[6pt]
    &= \text{P}(X \leq 3 \hspace{0.15em}|\hspace{0.15em} m = 5) \\[3pt]
    &= \rm{poissonCdf}(5,0,3) \\[6pt]
    &= 0.265 \hspace{0.5em}\text{(3 s.f.)} \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

3.  Recall in hypothesis testing a Type II error refers to the case
    where the null hypothesis is accepted while it is false.

    Since the true value of $m$ is $4.2$, the probability of a Type II
    error in this case is
    $$
    \begin{aligned}
    \mathrm{P}(\text{type II error}) &= \text{P}(X \geq 4 \hspace{0.15em}|\hspace{0.15em} m = 4.2) \\[6pt]
    &= 1 - \text{P}(X \leq 3 \hspace{0.15em}|\hspace{0.15em} m = 4.2)\\[6pt]
    &= 1 - \rm{poissonCdf}(4.2,0,3) \\[6pt]
    &= 0.605 \hspace{0.5em}\text{(3 s.f.)} \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$
