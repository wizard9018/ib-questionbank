# AI535

**Maximum mark: 6**

James and Michael are professional surfers. James claims that the
average number of waves he catches per hour is $10$. Michael doubts this
and thinks James cannot catch that many waves per hour.

Michael conducts a test as follows. He asks James to surf for one hour
and count how many waves he catches. If James catches less than $8$
waves, Michael will reject the claim James made.

Assume that the number of waves that James catches per hour follows a
Poisson distribution.

1.  State the null and alternative hypotheses for Michael's test.
    [1 mark]

2.  Find the probability of a Type I error. [2 marks]

The average number of waves that James can catch per hour is actually
only $8.4$.

3.  Find the probability of a Type II error. [3 marks]

---

## 评分标准 / Mark scheme

1.  Let $m$ represent the average number of waves that James can catch
    per hour. We have
    $$
    \begin{aligned}
    &\text{H}_0 : m = 10 \\[6pt]
    &\text{H}_1 : m < 10
    \end{aligned}
    $$

2.  Recall in hypothesis testing a Type I error refers to the case where
    the null hypothesis is rejected while it is true.

    Let $X$ be the number of waves that James can catch per hour. If the
    null hypothesis is true, it will follow that $X \sim \rm{Po}(10)$.
    Then the probability of a Type I error in this case is

    $$
    \begin{aligned}
    \text{Pr}(X < 8 \hspace{0.15em}|\hspace{0.15em} m = 10) &= \text{Pr}(X \leq 7 \hspace{0.15em}|\hspace{0.15em} m = 10) \\[3pt]
    &= \rm{poissoncdf}(10,0,7) \\[6pt]
    &\approx 0.220 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

3.  Recall in hypothesis testing a Type II error refers to the case
    where the null hypothesis is accepted while it is false.

    Since the true value of $m$ is $8.4$, the probability of a Type II
    error in this case is
    $$
    \begin{aligned}
    \text{Pr}(X \geq 8 \hspace{0.15em}|\hspace{0.15em} m = 8.4) &= \rm{poissoncdf}(8.4,8,100) \\[6pt]
    &\approx 0.601 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$
