# AI569

**Maximum mark: 15**

Premier Pet-foods Co. has developed a new dry food for dogs. They start
to mass produce the food and the amount of inventory in the warehouse is
recorded on a monthly basis. The table below shows the data for the
amount of inventory ($I$, in tonnes) for the first ten months ($t$).

![ff429a84b88a3ab2864402cd11e6f8b6b0213841.svg](images/ff429a84b88a3ab2864402cd11e6f8b6b0213841.svg)

1.  Sketch a scatter plot to represent the given data on the axes below.
    [2 marks]

    ![806eb26aa217f19b3a9f23f040d7525d7f4a78de.svg](images/806eb26aa217f19b3a9f23f040d7525d7f4a78de.svg)

2.
    1.  State a suitable type of function that could model this set of
        data points.

    2.  Hence determine the model function for this dataset. [2 marks]

3.  Comment on the choice of model using the coefficient of
    determination. [2 marks]

4.  Sketch the model function on the scatter plot and comment on how it
    fits to the original data. [3 marks]

5.  Using your model, determine after how many months the inventory is
    at it's maximum. [2 marks]

6.  Using your model, forecast when the the company will run out of
    inventory. [2 marks]

7.  Using your model, determine the amount of inventory after $16$
    months and comment on if the model is still valid in forecasting
    inventory levels at this time. [2 marks]

3.

4.

    ![e2960f25f7aa0a0adb6a44ec0de3dcec1ca6c0b6.svg](images/e2960f25f7aa0a0adb6a44ec0de3dcec1ca6c0b6.svg)

    The graph of the quadratic model fits very closely to the data set.

5.  The maximum value of $I$ is obtained at
    $$
    \begin{aligned}
    t &= -\dfrac{b}{2a} \\[3pt]
    &= -\dfrac{7.51}{2(-0.634)} \\[3pt]
    &\approx 5.92
    \end{aligned}
    $$

     $\text{Therefore, according to the model, inventory is at a maximum after \(5.92\) months.}$

6.  The company runs out of its stock if $I(t) = 0$. Solving this
    equation we get
    $$
    \begin{aligned}
    -0.634 t^2 +7.51 t - 0.896 &= 0 \\[6pt]
    t \approx 0.121 &\text{ or } 11.7
    \end{aligned}
    $$
    We reject $t = 0.121$ since it represents the
    start of production.

    Hence, using the model, the company is forecast to run out of inventory after approximately $11.7$ months.

7.  At $t = 16$, we have
    $$
    \begin{aligned}
    I(16) &= -0.634 (16)^2 +7.51 (16) - 0.896 \\[3pt]
    &= -43.0 < 0
    \end{aligned}
    $$

    Since we can't have negative inventory, the model is no longer valid at $t=16$ months. This is an example of extrapolation of the model outside the range of the data-set used to generate the model.
