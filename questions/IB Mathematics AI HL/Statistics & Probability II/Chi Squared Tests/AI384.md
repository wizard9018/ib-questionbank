# AI384

**Maximum mark: 8**

At the Farmer Jack Super Market, there are $6$ counters available for
customers to make payment. Each counter is staffed by a cashier. The
manager wants to understand whether the customers' selection of counter
is uniformly distributed across the $6$ counters. The following table
shows the result for a sample of $180$ customers on a random day.

![18a2c3fe9f8e3124fd0b5e050e536034665fd144.svg](images/18a2c3fe9f8e3124fd0b5e050e536034665fd144.svg)

1.  Complete the table below with the expected frequencies. [2 marks]

    ![194876ddf9fec7adb3ba0c86919d69dbfb4c632b.svg](images/194876ddf9fec7adb3ba0c86919d69dbfb4c632b.svg)

2.  A $\chi^2$ goodness of fit test is performed at a $5\%$ significance
    level.

    1.  State the null and alternate hypotheses.
    2.  Write down the number of degrees of freedom.

    3.  Using your graphics display calculator, find the
        $\chi^2$-statistic and p-value. [4 marks]

3.  The critical value is $12.833$. Write down the conclusion for the
    test. [2 marks]

## 评分标准 / Mark scheme

1.  Since the manager is interested to see whether the customers are
    uniformly distributed across the counters, the expected proportion
    of customers at each counter would be $p_{0i} = \dfrac 1 6$. Using
    the formula of expected frequency $E_i = np_{0i}$, we get

    $$
    \begin{aligned}
    E_i &= 180 \times \dfrac{1}{6} \\[3pt]
    &= 30
    \end{aligned}
    $$
    Hence the expected frequencies are as follows.

    ![f899130310496046e0cb8682e0b80b9db570918b.svg](images/f899130310496046e0cb8682e0b80b9db570918b.svg)

2.
    1.

        $H_0$: The number of customers follows a uniform distribution \newline
            $H_1$: The number of customers doesn't follow a uniform distribution

    2.  Using the formula $df = k - 1$ where $k$ is the number of
        categories (in this case, the number of counters), we get

        $$
        \begin{aligned}
        df &= 6-1 \\[3pt]
        &\hspace{0.525em}= 5
        \end{aligned}
        $$

    3.
        $\chi^2 = 3.53$

        $p\text{-value} \approx 0.618$
          \[$\text{by using G.D.C.}$\]

3.  Recall that we reject the null hypothesis if the $p$-value is less
    than the significance level or if $\chi^2 > \chi^2_{\text{crit}}$.
    In this case, the significance level is given as $0.05$ and the
    critical value is $12.833$.

    Since $p$-value $= 0.6189 > 0.05$ or $\chi^2 = 3.53 < 12.833$, we do not reject $H_0$. Hence there is insufficient evidence to conclude that the customers are not uniformly distributed across the counters.
