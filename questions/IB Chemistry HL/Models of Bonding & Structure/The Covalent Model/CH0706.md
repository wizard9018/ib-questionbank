# CH0706

A neutral atom of element X has the electron configuration shown.

![CH0706](images/CH0706.png)

Element X reacts with oxygen gas ($\ce{O2}$) to produce an oxide material.

What type of bonding occurs in this oxide material?

-   A.$\hspace{1em}$Simple covalent

-   B.$\hspace{1em}$Giant covalent

-   C.$\hspace{1em}$Ionic

-   D.$\hspace{1em}$Metallic

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:\
The atom contains three electron shells, so element X must be in period 3 of the periodic table. Four electrons are in the outer shell, so the element must be in group 14. Element X is, therefore, silicon. The oxide of silicon is silicon dioxide, $\ce{SiO2}$, which has a giant covalent structure.

This question is categorized as hard, as the student must deduce an element from its electron configuration and recall the structure of its solid oxide.
