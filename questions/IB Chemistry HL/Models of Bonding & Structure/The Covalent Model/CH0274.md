# CH0274

$\ce{CH3COOH}$ has which of the following intermolecular forces?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I.| London |
  | II. | Dipole-Dipole |
  | III.$\hspace{0.3em}$ | Hydrogen bonds |

- A.$\hspace{1em}$ I only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ I, II, and III

- D.$\hspace{1em}$ II only

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:\
Carboxylic acids have hydrogen bonding due to $\ce{O-H}$ bonds, dipole$-$dipole interactions because of the difference in electronegatitivity between C, O and H, and London dispersion forces.
