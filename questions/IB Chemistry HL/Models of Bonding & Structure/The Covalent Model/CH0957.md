**Maximum mark: 10**

A mixture of amino acids need to be separated and identified using thin layer chromatography (TLC).

1.  In the first attempt to separate the amino acids with water, the following was observed.

    Describe what is not ideal about this chromatogram and what can be done to achieve better results. [2 marks]

2.  A later attempt at separation resulted in the following chromatogram. Calculate the $R_f$ for each amino acid. [2 marks]

    ![CH0957ai](images/CH0957ai.png)

3.  After successful separation, the chemist ran another chromatogram to identify the amino acids. From the following data, identify the amino acids in the unknown sample.  [1 mark]

    | Amino acid | R$\mathbf{_f}$ |
    | :-: | :-: |
    | alanine | 0.86 |
    | asparagine | 0.75 |
    | glutamic acid | 0.56 |

## 评分标准 / Mark scheme

1.  Two of the amino acids did not separate/their spots are overlapping;  $\checkmark$

    A different solvent/less polar solvent/mixture of solvents (should be attempted) $\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    If components of a mixture are overlapping in a TLC or paper chromatogram, then this means that the substances have a similar polarity. To effectively separate the components there are strategies that could be employed:
    - Try a different, less polar solvent.
    - Try a mixture of solvents where one of the solvents is less polar than the other. This requires finding solvents that are miscible.

2.  $R_f$ for spot $w = \dfrac{0.6}{2.8} = 0.21$

    $R_f$ for spot $x = \dfrac{1.2}{2.8} = 0.43$ $\checkmark$

    $R_f$ for spot $y = \dfrac{2.1}{2.8} = 0.75$

    $R_f$ for spot $z = \dfrac{2.4}{2.8} = 0.86$  $\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    To answer this question, the student needs to use the ruler to collect the following data:

    -   Distance from starting line to solvent front = 2.8 cm
    -   Distance from starting line to spot w = 0.6 cm
    -   Distance from starting line to spot x = 1.2 cm
    -   Distance from starting line to spot y = 2.1 cm
    -   Distance from starting line to spot z = 2.4 cm

    This data is then used to calculate the $\ce{R_f}$ values according to the following formula:

    $R_f = \dfrac{\mathrm{Distance\ traveled\ by\ the\ spot}}{\mathrm{Distance\ traveled\ by\ the\ solvent}}$

    Therefore:

    -   $R_f$ for spot $w = \dfrac{0.6}{2.8} = 0.21$

    -   $R_f$ for spot $x = \dfrac{1.2}{2.8} = 0.43$

    -   $R_f$ for spot $y = \dfrac{2.1}{2.8} = 0.75$

    -   $R_f$ for spot $z = \dfrac{2.4}{2.8} = 0.86$

    *Award M1 for two or three correct answers;*\
    *Award M2 for four correct answers;*\
    *Deduct one mark if units are added;*\
    *Accept answers where the measurements are off by up to 0.1*.

3.  $w$ = leucine, $x$ = glycine, $y$ = asparagine, $z$ = alanine  $\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    When run at the same time/in the same conditions, $R_f$ values can be used to identify components of a mixture. Therefore, the amino acids in the unknown can be identified by matching the $R_f$ values for the known amino acids.

4.  Amino acid, $z$, is polar because the mobile phase/water is polar $\checkmark$

    $z$ moved the furthest/has the highest $\ce{R_f}$;  $\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    Components of a mixture with the highest Rf have the greatest affinity for the mobile phase. Since water is polar, then this means that amino acid $z$ is the most polar of those in the mixture.

5.  Hexane is non-polar; $\checkmark$

    The amino acids would not separate/would remain on/near the starting line $\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    Separation on TLC is dependent upon the component's affinity for the mobile phase. Since separation was achieved with water which is polar, it can be assumed that a non-polar solvent will not result in separation. If hexane were used instead of water, then the amino acids would have a higher affinity for the stationary phase and therefore would move little, if at all, off of the starting line.

6.  Graphite/pencil will not dissolve in the solvent and move up the TLC/ink would dissolve in the solvent and move up the TLC $\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    When setting up a TLC or paper chromatography experiment, it is important to always use pencil for the starting line because anything that is ink based (or contains dyes) will likely dissolve into the solvent and move up the plate like the components that are trying to be separated.
