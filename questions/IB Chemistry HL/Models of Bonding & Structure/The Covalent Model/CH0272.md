# CH0272

Which of the below gives substances in the correct order of increasing boiling point?

- A.$\hspace{1em}\ce{Cl2} < \ce{ICl} <  \ce{Br2} < \ce{IBr}$

- B.$\hspace{1em}\ce{Cl2} < \ce{Br2} < \ce{ICl}< \ce{IBr}$

- C.$\hspace{1em}\ce{ICl} < \ce{Cl2} < \ce{IBr} < \ce{Br2}$

- D.$\hspace{1em}\ce{Cl2} <\ce{Br2} <\ce{IBr} < \ce{ICl}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The number of electrons can be linked to the molecular mass. The greater the molecular mass, the greater the number of London forces present. Br$_2$ has a greater molecular mass than Cl$_2$ therefore, greater London forces and a higher boiling point.

The iodine compounds (IBr and ICl) have permanent dipole$-$dipole interactions *and* London dispersion forces. $\ce{IBr}$ has more electrons and, therefore, stronger London forces than $\ce{ICl}$.
