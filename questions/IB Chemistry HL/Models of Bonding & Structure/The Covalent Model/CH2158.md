# CH2158

Which of the following is not an example of an expanded octet?

-   A. $\hspace{1em}\ce{ClF3}$

-   B. $\hspace{1em}\ce{SF4}$

-   C. $\hspace{1em}\ce{AlF3}$

-   D. $\hspace{1em}\ce{I3-}$

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$

An expanded octet occurs when the central atom has more than eight valence electrons. This is possible for elements in Period 3 or beyond because they have accessible d orbitals that can accommodate extra electrons.

The Lewis structures for each molecule are shown here.

![CH2158d](images/CH2158d.png)|![FCM-CH2158b](images/FCM-CH2158b.png)|![FCM-CH2158a](images/FCM-CH2158a.png)|![CH2158c](images/CH2158c.png)|

Each of these molecules violates the octet rule but $\ce{AlF3}$ does so by placing only six electrons in the valence of the electron$\text{--}$deficient central atom.
