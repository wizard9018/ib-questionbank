# CH0291

Which of the following $\textbf{cannot}$ conduct electricity in a molten state?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{PCl3}$ |
  | II. | $\ce{NaCl}$ |
  | III. | $\ce{SO2}$ |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I, II and III

- D.$\hspace{1em}$ I and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Simple molecular covalent structures cannot conduct electricity due to an absence of charged particles. $\ce{NaCl}$ is an ionic compound that has ions that are free to move when in a molten state.
