# CH0516

**Maximum mark: 10**

Gaseous aluminium chloride has the molecular formula $\ce{AlCl3}$.

1.  By counting the valence electrons of the $\ce{Al}$ atom, explain why $\ce{AlCl3}$ is described as **electron deficient**. [2 marks]

2.  Aluminium chloride changes from a gas to a solid when it is cooled. The molecules of $\ce{AlCl3}$ dimerise to form $\ce{Al2Cl6}$, which has the following structural formula.

    ![14.1-CH0516b](images/CH0516b.png)

    1.  Calculate the formal charge of each aluminium atom in $\ce{Al2Cl6}$, showing your workings. [2 marks]

    2.  State how the **molecular** geometry around each aluminium atom changes when $\ce{AlCl3}$ dimerises to form $\ce{Al2Cl6}$. [2 marks]

3.  Iodine trichloride also forms a dimeric structure. The structural formula of the $\ce{I2Cl6}$ dimer is shown.

    ![14.1-CH0516c](images/CH0516c.png)

    1.  Explain why the **electron domain** geometry of the iodine atoms in $\ce{I2Cl6}$ differs from that of the aluminium atoms in $\ce{Al2Cl6}$. [2 marks]

    2.  Explain how repulsion between the valence electron pairs determines the **molecular** geometry around each iodine atom. [2 marks]

## 评分标准 / Mark scheme

1.  There are 6 valence / outer shell / bonding electrons around the $\ce{Al}$ atom; $\checkmark$

    so, $\ce{Al}$ has fewer than 8 valence / outer shell / bonding electrons (that are required by octet rule) **OR** $\ce{Al}$ does not obey the octet rule **OR** Al does not have a full octet (of electrons). $\checkmark$

2.  1.  Formal charge = valence electrons $-$ non-bonding electrons $- \dfrac{1}{2}\, \times$ bonding electrons

        Formal charge $= 3 - 0 - \left(\left(\dfrac{1}{2}\right)(8) \right)\checkmark$

        Formal charge = $-1$ **OR** $1- \,\checkmark$

        *Award M1 if number of non-bonding electrons is omitted;*\
        *Award M1 if terms in the equation are clearly defined but one input value is incorrect;*\
        *Do **not** award M1 if more than one input value in the equation is incorrect;*\
        *Do **not** award M1 if number of bonds is not explicitly subtracted from number of valence electrons.*

    2.  Trigonal planar geometry (in $\ce{AlCl3});\, \checkmark$

        changes to tetrahedral geometry (in $\ce{Al2Cl6}).\, \checkmark$

        *Award [1] if both geometries stated but distinction between initial and final geometries is ambiguous;*\
        *Do **not** award M1 for trigonal;*\
        *Do **not** award M1 for planar.*

        $\underline{\textrm{Further explanation:}}$

        In $\ce{AlCl3}$ there are 3 electron domains around the central $\ce{Al}$ atom. In $\ce{Al2Cl6}$, there are 4 electron domains around each $\ce{Al}$ atom.

3.  1.  Iodine has (two) non-bonding / lone pairs (while aluminium does not); $\checkmark$

        so, electron domain geometry is octahedral. $\checkmark$

        *Award M1 even if number of lone pairs not stated;*\
        *Award M2 for diagram clearly illustrating octahedral geometry.*

        $\underline{\textrm{Further explanation:}}$

        Iodine is in group 17 and so has 7 valence electrons compared to aluminium's 3 (group 13).

    2.  Molecular / bonding geometry is square planar, $\checkmark$

        as repulsion is minimized by lone / non-bonding (electron) pairs occupying axial / opposite positions **OR** bonding (electron) pairs occupying equatorial positions. $\checkmark$

        *Award M1 for diagram clearly illustrating square planar geometry;*\
        *Do **not** award M1 for square;*\
        *Do **not** award M1 for planar;*\
        *Do **not** award M2 if relative positions of lone pairs or bonding pairs is not stated;*\
        *Do **not** award M2 if effect of lone pair positioning on electron repulsion is not stated.*

        $\underline{\textrm{Further explanation:}}$

        The square planar structure is derived from the octahedral shape with two axial lone pairs.
