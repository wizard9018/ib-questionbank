# CH0998

Which of the following have two equivalent resonance structures?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | benzene, $\ce{C6H6}$ |
    | II. | carbonate, $\ce{CO^2-_3}$
    | III. | ozone, $\ce{O3}$ |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$III only

-   C. $\hspace{1em}$I and III only

-   D. $\hspace{1em}$I, II and III
