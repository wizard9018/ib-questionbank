# CH0273

Which of the following substances is the most soluble in water, with the correct reason given?

- :::tableoptions{col1="hide"}
  | | Substance | Reason |
  | :-: | :-: | :-: |
  | A.$\hspace{1em}$ | $\ce{PF3}$ | The bonds are very polar |
  | B.$\hspace{1em}$ | $\ce{PF3}$ | The molecule has a permanent dipole |
  | C.$\hspace{1em}$ | $\ce{NH3}$ | It can form hydrogen bonds with itself |
  | D.$\hspace{1em}$ | $\ce{NH3}$ | $\quad$It can form hydrogen bonds with water molecules $\quad$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

All statements are correct, but only D is a reason for solubility in water.
