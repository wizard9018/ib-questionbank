# CH0955

Polycyclic aromatic hydrocarbons can be separated by thin$-$layer chromatography.

Which solvent would result in a high $R_f$ value for naphthalene, and which intermolecular forces would be present between the naphthalene and the mobile phase?

![CH0955](images/CH0955.png)

-   :::tableoptions{col1="hide"}
    | | Mobile phase (solvent) | Intermolecular forces |
    | :-: | :-: | :-: |
    | A. | $\ce{C6H14}$, hexane | London dispersion forces |
    | B. | $\ce{C6H14}$, hexane | London dispersion forces, dipole$-$dipole forces |
    | C. | $\ce{H2O}$, water| London dispersion forces |
    | D. | $\ce{H2O}$, water | London dispersion forces, dipole$-$dipole forces, hydrogen bonds |

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$\
To answer this question, the student must start by recognizing that naphthalene is non-polar and therefore would have a high $R_f$ value when it is placed with a non-polar solvent (since it would then have a higher affinity for the mobile phase).

To have a higher affinity for the mobile phase, the naphthalene would need to form intermolecular forces with the solvent, and since it is non-polar, only London dispersion forces would be possible. Between hexane and water, the hexane is non-polar.

This question is difficult because the student must put together many concepts to arrive at the correct answer. Importantly, there must be an understanding of intermolecular forces based on polarity. It is also essential that the student recognizes that a high $R_f$ value corresponds to the component having a higher affinity for the mobile phase.
