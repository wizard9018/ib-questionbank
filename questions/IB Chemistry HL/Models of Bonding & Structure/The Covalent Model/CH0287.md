# CH0287

The Lewis structure of $\ce{NCl3}$ is given below. Which type(s) of electrons does it show?

![4.2-0287](images/4.2-0287.png)

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Non-Bonding Electrons |
  | II. | Bonding Electrons |
  | III. | Innermost electrons |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I, II, and III

- C.$\hspace{1em}$ I only

- D.$\hspace{1em}$ II only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

There is a non-bonding (lone) pair of electrons on the nitrogen atom and three on each chlorine. There are three $\ce{N-Cl}$ bonding pairs of electrons. Only the outermost electrons are shown for each element
