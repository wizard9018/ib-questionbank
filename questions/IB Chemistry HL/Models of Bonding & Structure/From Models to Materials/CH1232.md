# CH1232

Which statements about AgCl are correct?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | It can be classified as purely ionic |
  | II. | It has a high covalent character |
  | III. | The melting point of KCl is expected to be higher than that of AgCl |

- A. $\hspace{1em}$I, II, and III

- B. $\hspace{1em}$I and II only

- C. $\hspace{1em}$II and III only

- D. $\hspace{1em}$I and III only

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:\
The van Arkel$-$Ketelaar triangle in the IB Chemistry Data Booklet classifies bonding by plotting compounds according to two parameters: the mean electronegativity, $\sum \chi = \frac{1}{2}(\chi_A + \chi_B),$ and the difference in electronegativity, $\Delta \chi = \vert \chi_A-\chi_B\vert.$ These values position a substance along a continuum ranging from metallic to covalent to ionic bonding.

  || AgCl | KCl |
  | :-: | :-: | :-:
  | $\sum \chi$ |  $\frac{1}{2}(1.9 + 3.2) = 2.55$ |  $\frac{1}{2}(0.9 + 3.2) = 2.05$ |
  | $\Delta \chi$ | $ \vert3.2  -  1.9 \vert = 1.3$ |  $ \vert 3.2 - 0.9 \vert = 2.3$ |

![CH1232ms](images/CH1232ms.png)

The point for AgCl lies within the covalent region, indicating significant covalent character due to the polarizing power of the small, highly charged $\ce{Ag+}$
ion.  AgCl cannot be classified as purely ionic as it lies within the covalent region and has a great covalent character (greater than 50%). Statement I is incorrect and statement II is correct.

In contrast, KCl falls clearly within the ionic region, with bonding dominated by electrostatic attraction between oppositely charged ions. Because ionic lattices feature strong Coulombic forces between oppositely charged ions, KCl is expected to have a higher melting point than AgCl. Statement III is correct.

This question is categorized as hard as students must be able to interpret the bonding triangle for these two substances and compare them.
