# CH0961

A compound has 74% covalent character where one of the atoms in the bond has an electronegativity equal to 2.3. What is a possible electronegativity value for the other atom?

-   A.$\hspace{1em}$3.3

-   B.$\hspace{1em}$1.0

-   C.$\hspace{1em}$0

-   D.$\hspace{1em}$0.1

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation:}}$\

The student must use the van Arkel$-$Ketelaar triangle to determine the difference in electronegativity between the atoms.

![CH0961](images/CH0961.png)

In this case, 75% covalent character correlates to an electronegativity difference, $\Delta \chi$, close to 1. Graphically, the electronegativity can be determined as shown in the graph above: the dotted lines are parallel to the edges of the triangle.

Alternatively, the electronegativity of the other atom can be calculated:

$\Delta \chi =  \chi (\ce{A}) - \chi (\ce{B}) $

Rearranging, the electronegativity of the other element can be determined:

$\chi(\ce{A}) =  \chi(\ce{B}) + \Delta \chi = 1.0 + 2.3 = 3.3$

This question is categorized as hard because the data for the bond triangle must be applied in an unconventional way.
