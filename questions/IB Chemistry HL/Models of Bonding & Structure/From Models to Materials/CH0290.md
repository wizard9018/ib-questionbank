# CH0290

Which of the following has a pure covalent bond?

- A.$\hspace{1em}$ $\ce{CCl4}$

- B.$\hspace{1em}$ $\ce{CO2}$

- C.$\hspace{1em}$ $\ce{H2}$

- D.$\hspace{1em}$ $\ce{H2O}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:\
There is no difference in electronegativity when an element is bonded only to itself. Therefore, the electrons in the covalent bond would be evenly distributed between the two $\ce{H}$ atoms with no polarity or ionic character.
