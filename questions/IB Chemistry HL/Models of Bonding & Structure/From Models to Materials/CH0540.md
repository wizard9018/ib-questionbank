# CH0540

Which statement best describes the properties of an alloy?

-   A.$\hspace{1em}$An alloy will have properties different from its component elements

-   B.$\hspace{1em}$An alloy will have the properties of the element which is present in the greatest percentage

-   C.$\hspace{1em}$An alloy will have properties intermediate between the properties of the component elements

-   D.$\hspace{1em}$An alloy will have the properties of the element which is present in a lesser percentage

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation:}}$\

Alloys have different properties to their constituent elements due to different structures.
