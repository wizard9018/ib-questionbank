# CH0958

What type of bonding is present in $\ce{SiO2}$, and what is the approximate percent covalent character?

- :::tableoptions{col1="hide"}

  | | Bonding type | % covalent character |

  | :-: | :-: | :-: |

  | A. | Ionic | 48% |

  | B. | Polar covalent | 48% |

  | C. | Ionic | 52% |

  | D. | Polar covalent | 52% |

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$\

The student must first collect the following information from the data booklet:

$\chi (\ce{Si}) = 1.9$\

$\chi (\ce{O}) = 3.4$

Next, the student must calculate the electronegativity difference between the atoms and the average electronegativity:

$\begin{aligned}

\text{Electronegativity difference} &= \Delta \chi = | \chi (\ce{O}) - \chi (\ce{(Si}) | = 3.4 - 1.9 = 1.5 \\

\text{Average electronegativity} &= \sum \chi = \dfrac{\chi (\ce{O}) + \chi (\ce{Si})}{2} = \dfrac{3.4 + 1.9}{2} = 2.7

\end{aligned}$

![CH0958](images/CH0958.png)

These values are then used to interpolate the bond type and percent covalent character in Section 17 of the data booklet: polar covalent and 52% covalent character. 

This question is categorized as medium difficulty because the student must combine many different types of data correctly, calculate values with accuracy and then apply this to the van Arkel$-$Ketelaar triangle.
