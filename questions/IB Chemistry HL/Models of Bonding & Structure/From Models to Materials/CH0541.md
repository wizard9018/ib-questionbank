# CH0541

Which statements regarding alloys are correct?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | Alloys are a solid solution held together with metallic bonds |

    | II. | Because the lattice contains differing-size ions, the metallic bonds are weaker |

    | III. | Alloys can have different chemical properties than their component elements |

-   A. $\hspace{1em}$I, II, and III

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$I and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Alloys are homogeneous mixtures of metals with other metals or nonmetals.
