# CH1063

The structures of the polymers Kevlar and PTFE are shown.

![CH1063_Image1](images/CH1063_Image1.png)

Which of the following statements are true?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Only one of the polymers can be produced via an addition reaction |
  | II. | Only one of the polymers can be produced via a radical reaction |
  | III. | Only one of the polymers can be produced via a reversible reaction |

- A. $\hspace{1em}$I and II only

- B. $\hspace{1em}$I and III only

- C. $\hspace{1em}$II and III only

- D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

PTFE is formed via an addition reaction. This reaction involves the formation of free radicals, which react irreversibly to form strong C-C bonds.

![CH1063_Image2](images/CH1063_Image2.png)

Kevlar is formed via a condensation reaction. Two possible synthetic methods are shown:

![CH1063_Image3](images/CH1063_Image3.png)

This is not an addition reaction, as a small molecule (water or HCl) is generated in addition to the amide. It is also not a radical reaction, as only bonding and non-bonding pairs of electrons are involved: a lone pair is donated from the nitrogen atom of an amine group to the carbon atom of a carboxylic acid group, producing a new $\ce{C-N}$ bond. The reaction is reversible, as the amide can be hydrolyzed (i.e., reacts with water) in the presence of an acid catalyst to regenerate a diamine and dicarboxylic acid.
