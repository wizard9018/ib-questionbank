# CH0959

Which of the following is the correct order for % ionic character from lowest to highest for the following compounds?

-   A.$\hspace{1em}\ce{SiO2, MgO, ZnO, Li2O}$

-   B.$\hspace{1em}\ce{Li2O, MgO, ZnO, SiO2}$

-   C.$\hspace{1em}\ce{SiO2, ZnO, MgO, Li2O}$

-   D.$\hspace{1em}\ce{ZnO, MgO, Li2O, SiO2}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$\

The student must first recognize that % ionic character can be determined by assessing the difference in electronegativity between the atoms.

To do this, the student must collect the following information from Section 9 IB Chemistry data booklet, using it to calculate $\Delta \chi$ :

Substance | $\quad \chi(X) \quad$ | $ \quad \chi(O) \quad$ | $\quad \Delta \chi \quad$ |

:-:|:-:|:-:|:-:|

$\ce{Li2O}$ |1.0 |3.4| 2.4 | 

$\ce{SiO2}$|1.9 |3.4| 1.5 | 

$\ce{MgO}$ |1.3 |3.4| 2.1 | 

$\ce{ZnO}$ |1.6 |3.4| 1.8 | 

Next, these values must be arranged from smallest to largest $\Delta \chi$:

$\ce{SiO2, ZnO, MgO, Li2O}$

This question is of medium difficulty. The student could easily be misled into fully using Section 17 by also calculating the average electronegativity and using that combined with $\Delta \chi$. This step is not needed as the question is not asking for bond type.
