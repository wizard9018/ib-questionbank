# CH0284

Which of the following has covalent bonding?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{CCl4}$ |
  | II. | $\ce{Ca3N2}$ |
  | III. | $\ce{NH3}$ |

- A.$\hspace{1em}$III only

- B.$\hspace{1em}$I and II only

- C.$\hspace{1em}$I and III only

- D.$\hspace{1em}$I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Non-metal elements bond to each other covalently. $\ce{Ca3N2}$ is made up of a metal and a nonmetal (with a large difference in electronegativity) and has ionic bonding.
