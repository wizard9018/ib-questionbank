# CH2093

The ion of a transition metal has mass number 55, electron configuration $\ce{[Ar]}3d^5,$ and a charge of $2+$. Which of the following is the symbol of the transition metal?

-   A.$\hspace{1.em}$Ni

-   B.$\hspace{1.em}$Cr
-   C.$\hspace{1.em}$Mn
-   D.$\hspace{1.em}$Fe

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$\
The given electron configuration is $\ce{[Ar]}3d^5$ for the 2+ ion, which means the element has lost two electrons. The argon core, $\ce{[Ar]}$, represents the first 18 electrons, and there are 5 more electrons in the $3d$ subshell. The neutral atom had two more electrons before ionization. The neutral atom must contain $18+5+2=25$ electrons, the element is manganes, Mn.
