# CH0060

Which compounds have an ionic lattice in the solid state?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Ammonium sulfate |
  | II. | Hydrogen chloride |
  | III. | Sodium carbonate |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:\
 Ionic bonds form between oppositely charged ions; $\ce{NH4+ and SO4^2-}$ in ammonium sulfate and $\ce{Na+ and CO3^2-}$ in sodium carbonate.

Due to a smaller difference in electronegativity and both being nonmetals, $\ce{H-Cl}$ bonds are polar covalent.
