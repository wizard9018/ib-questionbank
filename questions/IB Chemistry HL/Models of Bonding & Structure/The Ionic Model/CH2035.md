# CH2035

Which of the following is the correct order for % ionic character from lowest to highest for the following compounds?

-   A. $\hspace{1em}\ce{AlCl3, LiCl, NaCl, MgCl2}$

-   B. $\hspace{1em}\ce{MgCl2, LiCl, AlCl3, NaCl}$

-   C. $\hspace{1em}\ce{NaCl, LiCl, MgCl2, AlCl3}$

-   D. $\hspace{1em}\ce{AlCl3, MgCl2, LiCl, NaCl}$

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

The first step in this question is to recognize that % ionic character can be determined by assessing the difference in electronegativity between the atoms. To do this, data must be collected from Section 9 in the IB Chemistry data booklet, using it to calculate $\Delta \chi:$

| Compound | $\mathbf{\chi_{metal}}$ | $\mathbf{\chi_{Cl}}$ | $\mathbf{\Delta \chi}$ |
| :-: | :-: | :-: | :-: |
| $\ce{MgCl2}$ | $1.3$ | $3.2$ | $1.9$ |
| $\ce{NaCl}$ | $0.9$ | $3.2$ | 2.3 |
| $\ce{AlCl3}$ | $1.6$ | $3.2$ | 1.6 |
| $\ce{LiCl}$ | $1.0$ | $3.2$ | 2.2 |

Next, these values must be arranged from smallest to largest $\Delta \chi: \ce{AlCl3, MgCl2, LiCl, NaCl}.$

You can also consider the van Arkel$-$Ketelaar triangle to arrange the points.  The percent ionicity can be determined on the scale on the right$\text{--}$hand$\text{--}$side.
