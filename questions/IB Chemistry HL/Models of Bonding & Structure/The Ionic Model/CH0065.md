# CH0065

Which statements about the NaCl lattice are correct?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Each Na$^+$ ion is surrounded by six Cl$^-$ ions |
  | II. | The cubic lattice extends in three dimensions |
  | III. | The lattice contains NaCl molecules and electrostatic attraction operates between the molecules |

- A.$\hspace{1em}$ I and II only

- B.$\hspace{1em}$ I and III only

- C.$\hspace{1em}$ II and III only

- D.$\hspace{1em}$ I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
$\ce{NaCl}$ forms a 3D lattice structure where each ion is surrounded by six counterions in an octahedral arrangement. Statement III is incorrect as attractions are between $\ce{Na^+ and Cl-}$ ions in a 1:1 ratio giving the overall formula $\ce{NaCl},$ there are no molecules in the lattice.
