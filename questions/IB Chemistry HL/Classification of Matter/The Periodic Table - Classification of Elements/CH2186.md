# CH2186

Which statement about transition elements is correct?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | They have variable oxidation states as successive ionization energies are not close in value. |
    | II. | They have catalytic properties. |
    | III. | Their divalent ions are formed by losing $4s$ electrons first. |

-   A. $\hspace{1em}$I, II and III

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$II only

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$

The student must understand that transition metals have variable oxidation states because the successive ionization energies are close in value. Statement I is incorrect.

Transition metals act as excellent heterogeneous catalysts. Statement II is correct.

Finally, if cations are formed, the electrons in the $4s$ orbital are lost first. Statement III is correct.

This question is categorized as a medium as the student must identify characteristics of transition elements and reasons behind these characteristics.
