# CH0579

Which of the following statements regarding the periodic table are correct?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | Anions have larger ionic radii than the atomic radius of their parent atom |

    | II. | Elements in the periodic table are arranged according to their number of protons |

    | III. | Elements within the same period will have similar physical properties |

-   A. $\hspace{1em}$I, II, and III

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$I and III only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Statement III is not correct as physical properties, including melting point and metallic character, change dramatically across a period due to changes in nuclear charge for the same number of shells.

Elements in the periodic table are arranged in increased atomic number.

Anions are atoms that have gained electrons. This will increase the electron-electron repulsion in the outermost shell, and  will cause the electrons to move further apart.Therefore, the radius of the outershell will increase.
