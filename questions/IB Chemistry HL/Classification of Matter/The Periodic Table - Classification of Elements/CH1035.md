# CH1035

Which statements about transition metals are correct?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | All transition metals have an incomplete $d$ subshell. |
    | II. | Transition metals must have more than one possible oxidation state. |
    | III. | Transition metals can act as catalysts. |

-   A.$\hspace{1em}$I and II only

-   B.$\hspace{1em}$I and III only

-   C.$\hspace{1em}$I, II and III

-   D.$\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:\
Transition metals can have an incomplete $d$ subshell **or** have cations with an incomplete $d$ subshell. Statement I is not fully correct.

All the transition metals have variable oxidation states (all transition metals show $+2$ and $+3$ oxidation states). Statement II is correct.

Transition metals and their ions are important catalysts in many chemical reactions. Statement III is correct.

This question is categorized as hard as the student must recall what transition metals are and some of their properties.
