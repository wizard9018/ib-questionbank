# CH0102

The oxidation number of X is the same in all the following compounds except:    

- A.$\hspace{1em}$ $\ce{X(OH)3}$

- B.$\hspace{1em}\ce{X2O3}$

- C.$\hspace{1em}\ce{X2(SO4)3}$

- D.$\hspace{1em}\ce{XO3}$

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$\

Each formula is electrically neutral, so we can determine the oxidation state of X by summing the known charges of the common anions present and then supplying the positive charge that balances them. In these compounds the relevant anions are hydroxide $(\ce{OH-}),$ oxide $(\ce{O^{2-}}),$ and sulfate $(\ce{SO_4^{2-}}).$ For a monatomic cation, the oxidation state equals its ionic charge; therefore, once the total negative charge from the anions is known, the oxidation state of 

X is simply the equal and opposite positive charge required to make the overall charge zero.

In $\ce{X(OH)3},$ the three hydroxides contribute $-3$ so X must be $+3.$   In $\ce{X2O3},$ the three oxides contribute $-6.$ With two X atoms, the total from X must be $+6,$, giving $+3$ per X.  In $\ce{X2(SO4)3},$ the three sulfates contribute $-6;$ again, each X atom must provide $+3.$  In $\ce{XO3},$ the three oxides contribute $-6$ and there is only one X so it must be +6. 

Thus, X is $+3$ in the first three formulas but $+6$ in $\ce{XO3},$ making $\ce{XO3}$ the exception.
