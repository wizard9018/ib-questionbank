# CH0935

Which set of equations and values shows the third ionization of aluminum?

- :::tableoptions{col1="hide"}
  | | Chemical Equation | $\mathbf{\Delta H}$ |
  | :-- | :-: | :-: |
  | A. | $\ce{Al^2+(g) -> Al^3+(g) + e-}$ | $- 2744.8$ |
  | B. | $\ce{Al^2+(g) -> Al^3+(g) + e-}$ | $+ 2744.8$ |
  | C. | $\ce{Al(g) -> Al^3+(g) + 3 e-}$ | $- 2744.8$ |
  | D. | $\ce{Al(g) -> Al^3+(g) + 3 e-}$ | $+ 2744.8$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$\
One of the fundamental characteristics of ionization energy (IE) is that it is always an endothermic process, which refers to the energy needed to remove one electron from each atom present in one mole of gaseous atoms under standard conditions.

$\begin{aligned}
\textbf{\textit{First IE}}: \hspace{1.em}& \ce{Al(g) -> Al+(g) + e-} \\
\textbf{\textit{Second IE:}}\hspace{1.em}& \ce{Al+(g) -> Al^2+(g) + e-} \\
\textbf{\textit{Third IE:}} \hspace{1.em}& \ce{Al^2+(g) -> Al^3+(g) + e-}
\end{aligned}$
