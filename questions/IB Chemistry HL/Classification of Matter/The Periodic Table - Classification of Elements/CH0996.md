# CH0996

Which statement(s) about the reaction of $\ce{P4O10}$ with water is(are) correct?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | The pH of the resulting solution is below 7.00 at 25 $^\circ$C |
    | II. | The product formed is $\ce{H3PO4}$. |
    | III. | $\ce{P4O10}$ is classified as an amphoteric oxide. |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$II only

-   C. $\hspace{1em}$III only

-   D. $\hspace{1em}$I and II only

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

$\ce{P4O10}$ is an acidic oxide. The chemical reaction of this oxide with water is:

$\ce{P4O10(s) + 6 H2O(l) -> 4 H3PO4(aq)}$

The phosphoric acid formed results in a pH below 7 (acidic pH at 25 $^\circ$C, $K_w = 1.00\times 10^{-14}$).

$\ce{P4O10}$ is not an amphoteric oxide. Amphoteric oxides can react with acids and bases, which is not true for $\ce{P4O10}$.

This question is categorized as hard as students must identify $\ce{P4O10}$ as an acidic oxide. They should be able to predict the product of its reaction with water and the resulting pH.
