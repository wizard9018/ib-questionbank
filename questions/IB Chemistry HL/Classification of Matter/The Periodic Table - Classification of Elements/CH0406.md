# CH0406

**Maximum mark: 5**

Iron is a magnetic element in the first row of the $d-$block.

1. State two characteristic properties other than magnetism that allow iron to be classified as a transition metal. [2 marks]

2. State the full electron configuration for an iron atom. [1 mark]

3. Suggest why iron is more magnetic than scandium. [2 marks]
