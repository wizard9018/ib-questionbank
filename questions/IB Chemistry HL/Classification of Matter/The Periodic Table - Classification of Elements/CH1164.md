# CH1164

Which combination is correct for the oxidation number of nitrogen in each of these species?

-   :::tableoptions{col1="hide"}
    | | $\mathbf{N_2O}$ | $\mathbf{NO_2^-}$ | $\mathbf{Mg(NO_3)_2}$ |
    | :-: | :-: | :-: | :-: |
    | A. | +1 | +4 | +3 |
    | B. | +1 | +3 | +5 |
    | C. | +2 | +4 | +5 |
    | D. | +2 | +3 | +3 |

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:

In $\ce{N2O},$ the oxidation state of oxygen is $-2.$ The addition of the oxidation states must be zero.

$\begin{aligned}
2 \ce{N} + \ce{O} &= 0 \\
2 \ce{N} + (-2) &= 0 \\
\ce{N} &= +1
\end{aligned}$

In $\ce{NO2-}$ the oxidation state of oxygen is $-2.$ The addition of the oxidation states must be $-1$ (as the charge of the ion).

$\begin{aligned}
\ce{N} + 2\ce{O} &= -1 \\
\ce{N} + 2 (-2) &= -1 \\
\ce{N} &= +3
\end{aligned}$

In $\ce{Mg(NO3)2},$ the polyatomic ion $\ce{NO3-}$ is combined with $\ce{Mg^2+}.$ In nitrate, the addition of all the oxidation states must add $-1.$

$\begin{aligned}
\ce{N} + 3 \ce{O} &= -1 \\
\ce{N} + 3(-2) &= -1 \\
\ce{N} &= +5
\end{aligned}$

This question is categorized as medium difficulty, as students are expected to apply the rules to assign oxidation states.
