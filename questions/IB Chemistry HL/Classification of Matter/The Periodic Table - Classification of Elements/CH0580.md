# CH0580

Which shows the species in order of increasing ionic radius?

-   A. $\hspace{1em}\ce{O^{2-}} < \ce{F^-} < \ce{Na+} < \ce{Mg^{2+}}$

-   B. $\hspace{1em}\ce{Mg^{2+}} < \ce{Na+} < \ce{F^-} < \ce{O^{2-}}$

-   C. $\hspace{1em}\ce{Mg^{2+}} < \ce{O^{2-}} < \ce{Na+} < \ce{F^-}$

-   D. $\hspace{1em}\ce{F^-} < \ce{O^{2-}} < \ce{Mg^{2+}} < \ce{Na+}$

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\

All four species are isoelectronic: each has 10 electrons in two energy levels, the configuration of neon. With the same number of electrons and the same shielding, the radius is determined by the nuclear charge alone. Magnesium's 12 protons pull the 10 electrons in most tightly, giving the smallest radius; oxygen's 8 protons pull least, giving the largest. The order is:

$\ce{Mg^{2+}} (72\textrm{ pm}) < \ce{Na+} (102\textrm{ pm}) < \ce{F^-} (133\textrm{ pm}) < \ce{O^{2-}} (140\textrm{ pm})$
