# CH0995

The condensed electron configuration of an element is $[\ce{Ar}]3d^{10}\,4s^2\,4p^5$

Which statement is correct about this element?

-   A. $\hspace{1em}$It belongs to group 4.

-   B. $\hspace{1em}$It belongs to group 15.

-   C. $\hspace{1em}$It belongs to period 3.

-   D. $\hspace{1em}$It belongs to period 4.

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

The condensed electron configuration of an element gives information about its position in the periodic table.

Students must distinguish between periods and groups (periods are horizontal rows, and groups are vertical columns of the periodic table).

The period number $(n)$ represents the outer energy level occupied by electrons. In this case, $n = 4$, so the element is in period 4.

The group number indicates the number of valence electrons. The atom of this element has 7 valence electrons, $4s^2\,4p^5$; hence, it is located in group 17.
