# CH0548

Which of the following statements are true?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | Most of the noble gases' neutral atoms contain a complete $p$ subshell |

    | II. | Period 3 contains the most nonmetals |

    | III. | Some elements in Group 14 are metalloids |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Noble gas atoms have a complete $p$ subshell of 8 electrons, making them unreactive under most circumstances. Helium is an exception to this rule. 

 

Nonmetals are present in several periods, but Period 2 contains the most: Period 3 contains one fewer, as aluminium is a metal. Students should be aware that metalloids are found in a diagonal boundary between the nonmetals and metals beginning with boron, meaning that groups in the $p$ block other than Group 18 contain metalloids. Group 14 contains two: silicon and germanium. 

 

This question is categorised as hard as the student must recall multiple pieces of information from the syllabus and identify several named categories of elements in the periodic table.
