# CH2016

Which statement about manganese is correct?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | It has variable oxidation states because successive ionization energies are similar. |
    | II. | Its ions can be coloured due to the formation of complex ions with electrophiles. |
    | III. | The electronic configuration of $\ce{Mn^2+}$ is $[\ce{Ar}]\ 3d^5.$ |

-   A. $\hspace{1em}$I and III only

-   B. $\hspace{1em}$II and III only

-   C. $\hspace{1em}$I and II only

-   D. $\hspace{1em}$I only

---

## 评分标准 / Mark scheme

**答案：A**

$\textbf{\underline{Explanation:}}$

The student must understand that manganese is a transition element with an incomplete $d\text{--}$sublevel.

Transition elements have variable oxidation states as successive ionization energies are close in value, so many electrons can be removed. Statement I is true.

The ions of transition elements form complexes with ligands that have a characteristic colour. Ligands act as nucleophiles, not electrophiles. Statement II is false.

Transition metals tend to lose $4s$ electrons first when forming ions. As a result, the divalent ion's electronic configuration is $[\ce{Ar}]\ 3d^5.$ Statement III is true.

This question is categorized as medium as the student must understand some features of transition metals.
