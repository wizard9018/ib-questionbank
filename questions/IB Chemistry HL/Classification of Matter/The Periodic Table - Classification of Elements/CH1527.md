# CH1527

Which of these elements is a transition element?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | Cu |

    | II. | Zn |

    | III. | Ca |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$II only

-   D. $\hspace{1em}$I, II and III

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

The student must identify the properties of transition elements. These elements form at least one stable ion with a partially filled $d\text{--}$sublevel.

The electronic configurations are given below.

- Cu: $1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 4s^1\ 3d^{10}$

- Zn: $1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 4s^2\ 3d^{10}$

- Ca: $1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 4s^2$

When $\ce{Cu^2+}$ forms the electronic configuration is $1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 3d^9,$ so copper is a transition metal. However, the formation of $\ce{Zn^2+}$ occurs with the loss of the $4s$ electrons, meaning that the electronic configuration is $1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 3d^{10}$ and zinc is not considered a transition metal. In the case of calcium, it does not have $d\text{--}$electrons. Calcium is not a transition metal.

This question is categorized as easy as the student must identify transition elements.
