# CH0396

Which of the following can behave as a ligand?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{BH3}$ |
  | II. | $\ce{NH3}$ |
  | III. | $\ce{CH4}$ |

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$II only

- C. $\hspace{1em}$III only

- D. $\hspace{1em}$I and II only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$\ce{NH3}$ has a non-bonding pair of electrons it can donate to a central metal ion. $\ce{BH3}$ and $\ce{CH4}$ do not have non-bonding electrons.
