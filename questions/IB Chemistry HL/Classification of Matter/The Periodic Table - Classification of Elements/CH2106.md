# CH2106

The oxide of the Period 4 alkali metal can react with water. Which statement is correct for this reaction?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | The reaction taking place is $\ce{Na2O(s) + 2 H2O(l) -> 2 NaOH(aq)}.$ |
    | II. | The resulting pH in water is above 7.00 at $25^\circ\text{C}.$ |
    | III. | The chloride ion is isoelectronic with this alkali metal cation. |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$II only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

The student must recognize that potassium is the Period 4 alkali metal. The alkali metals are elements from Group 1 except hydrogen (Li, Na, K, *etc.*). The oxide is potassium oxide, $\ce{K2O}.$ This oxide is basic as its dissolution in water produces the strong base potassium hydroxide; the resulting solution is basic $(\text{pH}>7.00$ at $25^\circ\text{C}).$

$\ce{K2O(s) + 2 H2O(l) -> 2 KOH(aq)}$

Statement I is incorrect, as the reaction should be that of potassium oxide.

Statement II is correct.

The chloride ion is $\ce{Cl-}$ and has 18 electrons (the atomic number of chlorine is 17 and the anion has an extra electron compared to the atom). The cation of the Period 4 alkali metal is $\ce{K+}$ and it has 18 electrons (the atomic number of potassium is 19, and the potassium cation loses an electron).

Statement III is correct as $\ce{Cl-}$ and $\ce{K+}$ have the same number of electrons.

This question is categorized as a medium as the student must understand alkali metals, the nature of basic oxides, and the concept of isoelectronic species.
