# CH0633

Which of the following is the correct definition of an amphoteric compound?                

-   A.$\hspace{1em}$A compound that can react with both an acid and a base

-   B.$\hspace{1em}$A compound that can both donate and accept hydrogen ions

-   C.$\hspace{1em}$A compound that can both donate and accept hydroxide ions

-   D.$\hspace{1em}$A compound that can dissociate into both an acid and a base

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation:}}$\

An amphoteric compound can act as both an acid and a base and can therefore react with both an acid and a base. 

A compound that can both donate and accept hydrogen ions is a special class of amphoteric compounds called amphiprotic. 

This question is categorised as easy as the definition of an amphoteric compound, and the distinction from an amphiprotic compound, is covered in the syllabus.
