# CH1299

What is the correct order for increasing atomic radius?

- A. $\hspace{1em}$B < Be < Mg < Ca

- B. $\hspace{1em}$B < Mg < Be < Ca

- C. $\hspace{1em}$Ca < Mg < Be < B

- D. $\hspace{1em}$Ca < Be < Mg < B

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

The locations of the elements in the periodic table are shown below.

![CH1299](images/CH1299.png)

The atomic radius increases going to the left across a period and down a group.

As a result, B has the smallest atomic radius, followed by Be, Mg, and finally, Ca, which has the largest.

Electron configurations:

| | |
| :-- | :-- |
| B | $\hspace{1em}1s^2\,2s^2\,2p^1$ |
| Be | $\hspace{1em}1s^2\,2s^2$ |
| Mg| $\hspace{1em}1s^2\,2s^2\,2p^6\,3s^2$ |
| Ca | $\hspace{1em}1s^2\,2s^2\,2p^6\,3s^2\,3p^6\,4s^2$ |

Across a period, the number of shells is the same for all atoms of elements and the effective nuclear charge increases, exerting a greater attraction to the outermost electrons with almost no change in the interelectronic repulsion. This results in a decrease of the atomic radius across a period.

Going down a group, the number of electron shells increases. Although the nuclear charge is higher, the number of inner electrons and the repulsion exerted by these increases. As a result, the outermost electrons are less attracted to the nucleus due to the shielding effect. Therefore, going down a group, the attraction gets weaker, and the radius increases.

This question is categorized as medium difficulty as students must compare the atomic radius of atoms of elements in periods and groups.
