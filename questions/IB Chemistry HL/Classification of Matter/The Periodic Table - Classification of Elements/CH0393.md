# CH0393

Which of the following salts would form coloured solutions when dissolved in water?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{CuCl2}$ |
  | II. | $\ce{ScCl2}$ |
  | III. | $\ce{ZnCl2}$ |

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$I and II only

- C. $\hspace{1em}$I and III only

- D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$\ce{Cu^2+}$ and $\ce{Sc^2+}$ both have an incomplete $d$-subshell. $\ce{Zn^2+}$ has a $3d^{10}$ (full d-subshell)configuration, so does not show transition element behaviours.
