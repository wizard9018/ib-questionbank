# CH2105

Which oxidation states are correct?

-   :::tableoptions{col1="hide" col2="hide" col3="hide"}
    | | Oxygen in BaO$_\mathbf{2}$ | Hydrogen in LiH | Carbon in CH$_\mathbf{3}$Cl |
    | :-: | :-: | :-: | :-: |
    | A.$\hspace{1em}$ | $-1$ | $+1$ | $-4$ |
    | B. | $-2$ | $-1$ | $-2$ |
    | C. | $-2$ | $+1$ | $-4$ |
    | D. | $-1$ | $-1$ | $-2$ |

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

The student must understand that the oxidation state is a number assigned to an atom in a substance to show the number of electrons transferred in forming a bond. It can be interpreted as the “charge" that the atom would have if the compound were composed of ions.
There are some rules to assign oxidation states, given in order of relative importance.

-   $\text{1.}$ The sum of oxidation states in a compound equals zero; all elements are composed of atoms with an oxidation number of 0.

-   $\text{2.}$ The sum of oxidation states in an ion equals the charge of the ion.

-   $\text{3.}$ The oxidation state of fluorine is always $-1$ when combined.

-   $\text{4.}$ Group 1 metals have an oxidation state of +1, and group 2 metals have an oxidation state of +2 when combined.

-   $\text{5.}$ The oxidation state of hydrogen is +1.

-   $\text{6.}$ The oxidation state of oxygen is $-2$ when combined.

-   $\text{7.}$ The oxidation state of Cl, Br, and I is $-1$ when combined.

*Note:* Rule 1 will always be obeyed, but Rule 6 might be violated in order to make Rules 1$-$5 true.

**BaO$_\mathbf{2}$:**\
Barium is in Group 2, so has oxidation state $+2$ (Rule 4). To ensure that the sum of the oxidaton states is 0, we can determine the oxidation state of oxygen:

$+2 + 2x = 0 \ ; \qquad x = -1$

The oxidation state of oxygen in this compound is $-1,$ this is barium peroxide.

**LiH:**\
Lithium is in Group 1, so has oxidation state $+1$ (Rule 4). To ensure that the sum of the oxidaton states is 0, we can determine the oxidation state of hydrogen:

$+1 + x = 0 \ ; \qquad x = -1$

The oxidation state of hydrogen in this compound is $-1,$ this is lithium hydride.

**CH$_\mathbf{3}$Cl:**\
Hydogen has an oxidation state of +1 (Rule 5) and chlorine has an oxidation state of $-1$ (Rule 7). To ensure that the sum of the oxidaton states is 0, we can determine the oxidation state of carbon:

$x + 3(+1) - 1 = 0 \ ; \qquad x = -2$

The oxidation state of carbon is $-2.$
