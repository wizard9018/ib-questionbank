# CH2182

Which elements are considered transition metals?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | Zinc |
    | II. | Copper |
    | III. | Iron |

-   A. $\hspace{1em}$I, II and III

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$III only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

The student must be able to identify transition elements. Transition elements have a partially filled $d$ sublevel or can form a stable cation with a partially filled $d$ sublevel.

Zinc is not a transition metal as its electronic configuration has a completely filled $3d$ sublevel in both its neutral and ionic form:

$\begin{aligned}
\ce{Zn:} &\quad   1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 4s^2\ \textcolor{red}{3d^{10}} \\
\ce{Zn^2+:} &\quad 1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ \textcolor{red}{3d^{10}}
\end{aligned}$

Iron is a transition metal because it has a partially filled $3d$ sublevel in its neutral state (as well as its ionic forms).

$\ce{Fe:} \quad 1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 4s^2\ \textcolor{blue}{3d^6}$

Copper is a transition metal because it has a partially filled $3d$ sublevel in its most common ionic form. As a neutral element its $3d$ sublevel is completely filled.

$\begin{aligned}
\ce{Cu:} &\quad 1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ 4s^1\ \textcolor{red}{3d^{10}} \\
\ce{Cu^2+:} &\quad 1s^2\ 2s^2\ 2p^6\ 3s^2\ 3p^6\ \textcolor{blue}{3d^9}
\end{aligned}$

This question is categorized as easy as the student must recognize transition elements.
