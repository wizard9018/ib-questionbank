# CH0695

Based on periodic trends, predict the correct order of increasing radius for these isoelectronic species?

-   A.$\hspace{1em}\ce{S^2-} < \ce{Cl-} < \ce{Ar} < \ce{K+}$

-   B.$\hspace{1em}\ce{K+} < \ce{Ar} < \ce{Cl-} < \ce{S^2-}$

-   C.$\hspace{1em}\ce{Ar} < \ce{Cl-} < \ce{K+} < \ce{S^2-}$

-   D.$\hspace{1em}\ce{S^2-} < \ce{K+} < \ce{Cl-} < \ce{Ar}$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:\
The number of shells and therefore the shielding effect is the same for all of these species.  As the number of protons decreases, the attraction between the nucleus and electrons decreases, resulting in a larger radius.

  K$^+$ has the most protons (19), whereas S$^{2-}$ has the least (16).

  *Note: The radius of argon is measured differently as it does not form ionic bonds so the argon is frozen into a crystalline lattice to determine the distance between the nuclei.  In the IB data booklet, the radius of argon does not follow the periodic trend predicted here because it is measured differently.*
