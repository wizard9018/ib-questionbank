# CH2185

Which complex ion has the smallest $d$ orbital splitting?

-   :::tableoptions{col1="hide"}
    | | Complex | Colour |
    | :- | :-: | :-: |
    | A.$\hspace{1em}$ | $\ce{V(H2O)6^2+}$ | violet |
    | B. | $\ce{V(H2O)6^3+}$ | green |
    | C. | $\ce{Co(H2O)6^2+}$ | red |
    | D. | $\ce{Cu(H2O)6^2+}$ | blue |

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$

The student must identify the colour observed for the transition element complex ion as the complementary colour of that absorbed. This colour absorbed corresponds to a range of wavelengths absorbed.

![CH2185](images/CH2185.png)

| Complex | Colour observed | Colour absorbed | Wavelengths absorbed / nm |
| :-: | :-: | :-: | :-: |
| $\ce{V(H2O)6^2+}$ | violet | yellow | $575-585$ |
| $\ce{V(H2O)6^3+}$ | green | red | $647-700$ |
| $\ce{Co(H2O)6^2+}$ | red | green | $491-575$ |
| $\ce{Cu(H2O)6^2+}$ | blue | orange | $585-647$ |

The smallest $d$ splitting corresponds to the smallest energy gap. The smallest energy gap corresponds to the biggest wavelength absorbed as $\Delta E = \dfrac{hc}{\lambda}.$

The complex ions with the greatest wavelength of absorption is $\ce{V(H2O)6^3+}$ and so it presents the smallest split in the $d$ orbitals.

This question is categorized as a medium as the student must relate the given information with the magnitude of the split in the $d$ orbitals.
