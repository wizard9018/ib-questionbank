# CH0557

**Maximum mark: 8**

The period 3 elements magnesium, silicon and sulfur are found in the second, fourteenth and sixteenth columns of the periodic table.

1. State the name given to a column of elements in the periodic table. [1 mark]

2. State how the numbers of electron shells and outer shell electrons vary across period 3. [2 marks]

3. Selected physical properties of magnesium, silicon and sulfur are given in the table below:

   |Element|Appearance|Mechanical properties

   |:-:|:-:|:-:|

   |Magnesium|Shiny, grey|Ductile

   |Silicon|Shiny, grey|Brittle

   |Sulfur|Dull, yellow|Brittle

   Explain how the positions of the elements across period 3 help to explain their similarities and differences. [3 marks]

4. Period 3 contains more elements than period 1 but is equal in size to period 2.

   Suggest why the number of elements increases between periods 1 and 2 but not between periods 2 and 3. [2 marks]

## 评分标准 / Mark scheme

1.     Group $\checkmark$

2.     The number of electron shells stays the same / is equal to 3. $\checkmark$

    The number of outer shell electrons increases (from left to right). $\checkmark$

    *Award M2 if the number of outer shell electrons is stated for two or more named elements in period 3.\

    Do not award M2 if the electron configurations of elements in period 3 are stated rather than the number of electrons.*

    $\underline{\textrm{Further explanation:}}$

    The period number dictates the number of electron shells for the atom of an element. Period 3 → 3 electron shells.

    

    From left to right, the atomic number of elements increases, and therefore the number of total electrons and the number of outer shell electrons increase too.

3.  Magnesium is a metal as it is on the left $\textbf{AND}$ sulfur is a non-metal as it is on the right (of the periodic table). $\checkmark$

    Silicon is a metalloid as it lies between the metals and non-metals / near the middle of the period. $\checkmark$

    So, some properties of silicon are similar to / the same as those of a metal / magnesium and other properties are similar to / the same as those of a non-metal / sulfur. $\checkmark$

    *Do not award M1 if the positions of the elements in period 3 are not referenced.\

    Do not award M2 if the position of silicon in period 3 is not referenced.\

    Do not award M3 if the properties of silicon are described as being between those of a metal and a non-metal.*

4.     Electrons are added to more subshells / orbitals in period 2 than in period 1 $\textbf{AND}$ to the same number of subshells / orbitals in periods 2 and 3. $\checkmark$

    Only $s$ orbitals are occupied in period 1 and both $s$ and $p$ orbitals are occupied in periods 2 and 3 $\textbf{OR}$ $p$ orbitals can be filled from period 2 onwards but $3d$ orbitals are filled only from period 4 onwards / after the $4s$ orbital has been filled. $\checkmark$

    *Do not award M2 unless the names of the orbitals in all three periods are described.*
