# CH1306

Which combination is correct for the high-resolution $^1\text{H}$ NMR spectrum of 3$-$pentanone?

- :::tableoptions{col1="hide"}
 | | Number of signals | Presence of triplet | Presence of doublet |
 | :-: | :-: | :-: | :-: |
 | A. | 4 | Yes | Yes |
 | B. | 4 | No | No |
 | C. | 2 | Yes | No |
 | D. | 2 | No | Yes |

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:\
Peaks in an $^1\text{H}$ NMR spectrum correspond to groups of hydrogen atoms in different chemical environments.

3-pentanone presents two different chemical environments, as shown below.

![CH1306](images/CH1306.png)

The hydrogens in orange and green present different signals. The integration trace of these signals is proportional to the hydrogens there. The ratio should be 6 : 4.

In addition, the splitting pattern of each signal is related to the neighboring hydrogens. Splitting occurs as hydrogens in the adjacent carbon atom cause spin-spin splitting.

The splitting pattern depends on the number of hydrogens next to it and is $n+1.$

Orange hydrogens have two neighboring hydrogens that split into $2+1=3,$ presenting a triplet.

Green hydrogens have three neighboring hydrogens that split into $3+1=4,$ presenting a quartet.

There is no doublet in this $^1\text{H}$ NMR spectrum.

This question is categorized as medium difficulty as students must figure out the main features of the $^1\text{H}$ NMR spectrum of this molecule, including a clear understanding of its splitting pattern.
