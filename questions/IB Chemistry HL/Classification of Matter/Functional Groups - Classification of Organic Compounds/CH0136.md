# CH0136

Which of the following statements is not correct for the class of organic molecules?

- A.$\hspace{1em}$Alcohols contain hydroxyl groups

- B.$\hspace{1em}$Ethers contain carbonyl groups

- C.$\hspace{1em}$Carboxylic acids contain carboxyl groups

- D.$\hspace{1em}$Ketones contain carbonyl groups

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Ethers contain $\ce{C-O}$ single bonds $\textbf{not}$ the $\ce{C=O}$ carbonyl group.
