    2.  degree of unsaturation = 7 $\checkmark$

        $\underline{\textrm{Explanation:}}$\

        The degree of unsaturation can be determined by counting the number of multiple bonds and rings: in aspartame there are 6 double bonds and one ring to give an degree of unsaturation of 7.

        Alternatively, the index of hydrogen deficiency (IHD) can be calculated from the molecular formula:

        $\text{IHD} = \dfrac{1}{2}[2\ C + 2 - H - X + N]$

        The molecular formula is $\ce{C14H18N2O5}$

        $\text{IHD} = \dfrac{1}{2}[2\times 14 + 2 - 18 - 0 + 2] = 7$

    5.  $\mbox{}\\[-20pts]$

        | hydrogen | Splitting pattern | Integration trace ratio |

        | :-: | :-: | :-: |

        |at Carbon A|doublet| 2|

        |at Carbon B|triplet|1|

        

        $\underline{\textrm{Explanation:}}$\

        The intensity of an NMR signal, represented by the integration trace, is directly proportional to the number of equivalent hydrogen atoms—those in the same chemical environment. Each signal may undergo splitting due to spin-spin coupling, which occurs when hydrogen atoms that are three bonds away, known as neighboring hydrogens, interact with the observed hydrogen. Every hydrogen nucleus has a spin, acting like a tiny magnet, which can either align with or oppose the external magnetic field. This interaction with neighboring hydrogens alters the magnetic environment of the observed hydrogen, leading to a characteristic splitting pattern. To predict this pattern, we use the $n+1$ rule: if a hydrogen atom has $n$ neighboring hydrogens that are three bonds away, its NMR signal will be split into $n+1$ peaks

        ![CH1568_M_A5](images/CH1568_M_A5.png)$\\$

        Carbon A is attached to two hydrogen atoms, so the integration trace will be 2, reflecting the number of equivalent hydrogen atoms. Since there is one neighboring hydrogen atom three bonds away, the signal will split into $1+1=2$ peaks, resulting in a doublet.

    

        Carbon B is attached to one hydrogen atom, so the integration trace will be 1. This hydrogen atom has two neighboring hydrogen atoms three bonds away, causing the signal to split into $2+1=3$ peaks, resulting in a triplet.

    1.  $\dfrac{55.0\text{\ mg dm}^{-3}}{1000\frac{\textrm{mg}}{\textrm{g}} \times 0.200 \textrm {\ dm}^3}\ \checkmark$ \

        0.0110 g $\checkmark$

    

        $\underline{\textrm{Explanation:}}$\

        We can calculate the mass of aspartame as shown below.

        $m = (55.0\text{\ mg dm}^{-3})\left(\dfrac{1\text{\ g}}{1000\text{\ mg}}\right)(0.200\text{\ dm}^3) = 

        0.0110\text{\ g}$

    2.  $\left|\dfrac{0.0110\text{\ g} - 0.00900\text{\ g}}{0.0110\text{\ g}}\right|\times 100\% \: \checkmark$\

            $18.2\%\ \checkmark$

        $\underline{\textrm{Explanation:}}$\

        The percent error is determined by the difference between a theoretical value and the actual value. In this case, we assume the theoretical value is the one informed about the soft drink.

        $\% \text{\ error} = \left|\dfrac{\text{theoretical} - \text{actual}}{\text{theoretical}}\right|\times 100\%$ 

        

        $\% \text{\ error} =  \bigg|\dfrac{0.0110 \textrm{\ g} - 0.00900 \textrm{\ g}}{\textrm {0.0110 \textrm{\ g}}}\bigg|\times100\% = 18.2\%$

    3.  50.0 $\dfrac{\text{mg}}{\text{kg}}\times 40.0\text{\ kg} = 2000\text{\ mg} = 2.00\text{\ g}\ \checkmark$\

        181 cans **OR** 222 cans $\checkmark$

        $\underline{\textrm{Explanation:}}$\

        The maximum number of cans can be determined using information on the soft drink or from the gravimetrical analysis.

        We must consider that the maximum mass of aspartame for a 40.0 kg child is

        $m_{max} = \dfrac{\text{mg}}{\text{kg}}\times 40.0\text{\ kg} = 2000\text{\ mg} = 2.00\text{\ g}$

        Every can contains 0.0110 g of aspartame (or 0.00900 g if the gravimetrical analysis is considered). The number of cans, $N$ that would exceed the guideline can be calculated as shown below:

        $N = \dfrac{2.00\,\textrm{g}}{0.0110\,\frac{\textrm{g}}{\textrm{can}}} = 181$ cans

        **OR**

        $N = \dfrac{2.00\,\textrm{g}}{0.00900\,\frac{\textrm{g}}{\textrm{can}}}$ = 222 cans
