# CH1165

Given the molecule $\textbf{X}$ below.

![CH1165](images/CH1165.png)

Which compound is an isomer of molecule $\textbf{X}$?

- A. $\hspace{1em}$Pentanoic acid

- B. $\hspace{1em}$Ethyl ethanoate

- C. $\hspace{1em}$Pentanal

- D. $\hspace{1em}\ce{CH3COCH(CH3)CH2CH2OH}$

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

Molecule **X** is ethyl propanoate, and its molecular formula is $\ce{C5H10O2}.$

Isomers are molecules with the same molecular formula but different arrangements.

Pentanoic acid is $\ce{C5H10O2}$ and so it is an isomer.

Ethyl ethanoate is $\ce{C4H8O2},$ so it is not an isomer.

$\ce{CHO(CH2)3CH3}$ is pentanal, and its formula is $\ce{C5H10O};$ it is not an isomer.

$\ce{CH3COCH(CH3)CH2CH2OH}$ has the formula $\ce{C6H12O2},$ which is not an isomer.

This question is categorized as hard as students are expected to interpret the 3D model given, apply the rules to name compounds, relate them with organic molecules with different functional groups, and use the concept of isomers for comparison.
