# CH0365

For each signal in the $\ce{^1H NMR}$ spectrum of a compound, an integration trace can be calculated.\
Which property can be determined by comparing the integration traces of $\ce{NMR}$ signals?

-   A. $\hspace{1em}$The proportion of hydrogen atoms in each chemical environment

-   B. $\hspace{1em}$The total number of chemical environments

-   C. $\hspace{1em}$The charge of the hydrogen atoms in each chemical environment

-   D. $\hspace{1em}$The index of hydrogen deficiency (IHD)

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The integration trace is proportional to the number of hydrogen atoms in the chemical environment.

This question requires simple recall of information given in the syllabus, but is of moderate difficulty due to potential confusion with other features of the $\ce{NMR}$ spectrum (e.g. the number of signals or chemical shift).
