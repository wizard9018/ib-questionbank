# CH1473

What is the correct increasing order for the boiling point of these molecules? \
*Hint: The molar mass is similar for all these molecules*

-   A. $\hspace{1em}$propanone < butane < propan$\text{--}$1$\text{--}$ol

-   B. $\hspace{1em}$butane < propanone < propan$\text{--}$1$\text{--}$ol

-   C. $\hspace{1em}$propanone < propan$\text{--}$1$\text{--}$ol < butane

-   D. $\hspace{1em}$propan$\text{--}$1$\text{--}$ol < propanone < butane

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The student must figure out the structure of each molecule to deduce the possible intermolecular forces in each.

| ![CH1473a](images/CH1473a.png) | ![CH1473b](images/CH1473b.png) | ![CH1473c](images/CH1473c.png) |
| :-: | :-: | :-: |
| Butane | Propanone | Propan$\text{--}$1$\text{--}$ol |

As the molecular mass is similar, the London dispersion forces in each should not be that different. Butane will only exhibit London dispersion forces. Propanone is a polar molecule that will present London dispersion forces and dipole-dipole interactions. As dipole$\text{--}$dipole interactions are permanent forces of attraction between molecules, the boiling point of propanone is expected to be higher than that of butane. Finally, $1\text{--}$propanol presents London dispersion forces, dipole$\text{--}$dipole attractions and hydrogen bonds. Hydrogen bonds are very strong attractions, meaning that $1\text{--}$propanol will show a higher boiling point than propanone.

This question is categorized as a medium, as the student must determine the intermolecular forces in each and deduce the order of the boiling points.
