# CH1300

Which statement(s) about this molecule is(are) correct?

![CH1300](images/CH1300.png)

- :::tableoptions{col1="hide" col2="hide"}
 | | |
 | :- | :- |
 | I. | It contains a carbonyl group. |
 | II. | Its $^1\ce{H}$ NMR spectrum has three signals. |
 | III. | Its molecular ion peak corresponds to $m/z = 115.$ |

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$I and II only

- C. $\hspace{1em}$I and III only

- D. $\hspace{1em}$III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The molecule contains a $\ce{C=O}$ bond. Statement I is correct.

The $^1\ce{H}$ NMR spectrum shows the number of signals that depend on the different hydrogen environments. In this case, four different hydrogen environments exist, as indicated below.

![CH1300Ans](images/CH1300Ans.png)

Statement II is incorrect.

The molecular ion peak corresponds to $m/z = 120$ as the molecular formula is $\ce{C8H8O},$ and the molar mass is $120.16\,\text{g mol}^{-1}.$ Statement III is incorrect.

This question is categorized as medium difficulty as students must interpret the skeletal structure and apply their knowledge about organic functional groups, mass sepctrometry, and $^1\ce{H}$ NMR spectroscopy.
