# CH0527

Compound A is a nonsuperimposable mirror image of compound B.

For which of the following properties does compound A display the same values as compound B?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | Melting point |

    | II. | Solubility in water |

    | III. | $pK_a$ |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$I, II and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The student must recall that “nonsuperimposable mirror images” are enantiomers and that these display the same physical and chemical properties, unless interacting with other chiral species.

The question is of moderate difficulty as multiple chemical terms must be recognized as examples of physical properties.
