# CH1258

The following $\ce{^1H}$ NMR spectrum was obtained to identify a substance with molecular formula $\ce{C4H8O2}.$

![CH1258](images/CH1258.png)

Which of these molecules presents an $\ce{^1H}$ NMR spectrum as the one shown above?

- A. $\hspace{1em}$Propyl methanoate, $\ce{HCOOCH2CH2CH3}$

- B. $\hspace{1em}$Ethyl ethanoate, $\ce{CH3COOCH2CH3}$

- C. $\hspace{1em}$Butanoic acid, $\ce{CH3CH2CH2COOH}$

- D. $\hspace{1em}$2$-$methyl propanoic acid, $\ce{CH3CH(CH3)COOH}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The structures of the molecules are shown below.

![CH1258Ans](images/CH1258Ans.png)

We can deduce the spectra expected for each of these:

- :::tableoptions
 | Structure | Number of signals | Integration trace | multiplicity |
 | :-: | :-: | :-: | :-: |
 | A | 4 | 1 : 2 : 2 : 3 | Singlet, triplet, sextuplet, triplet |
 | B | 3 | 3 : 2 : 3 | Singlet, quadruplet, triplet |
 | C | 4 | 1 : 2 : 2 : 3 | Singlet, triplet, sextuplet, triplet |
 | D | 3 | 1 : 1 : 6 | Singlet, multiplet (septuplet) and doublet |

Spectrum analysis:

As the spectrum given has four signals we can disregard options B and D.

Both, structures A and C, present four signals.

From the given spectrum, the red line shows the increase for every signal; the integration trace indicates that the ratio is 1 : 2 : 2 : 3. This is consistent with structures A and C.

On the given spectrum:

$\delta = 11.5\,\text{ppm}$ integration trace 1 and singlet $\rarr$ an H in a COOH environment

Option A can be disregarded as it is an ester.

The correct structure is structure C.

This question is categorized as hard as students must contrast these molecules with the spectrum informed and analyze the splitting pattern, integration trace, and number of signals.
