# CH1052

Which compound exhibits optical isomerism?

-   A.$\hspace{1em}\ce{CH3CH2CH2CH2OH}$

-   B.$\hspace{1em}\ce{CH3CH2CHOHCH3}$

-   C.$\hspace{1em}\ce{(CH3)_2CHCH2OH}$

-   D.$\hspace{1em}\ce{(CH3)3COH}$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:\
Two isomers can exist in compounds if there is a chiral carbon. Chiral carbons have four different groups attached to them. Only $\ce{CH3CH2CHOHCH3}$ has a chiral carbon.
