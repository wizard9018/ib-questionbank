Which of these structures are structural isomers of hexane?

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$I and II only

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

The molecular formula of hexane is $\ce{C6H14}$. The skeletal structures in the question can be expanded into full structural formulas , as shown below.

  | | | |
  | :-- | :-- | :--
  | |  ![CH1012msa](images/CH1012msa.png) | ![CH1012a](images/CH1012a.png)
  | | ![CH1012msb](images/CH1012msb.png) | ![CH1012b](images/CH1012b.png)
  |  | ![CH1012msc](images/CH1012msc.png) | ![CH1012c](images/CH1012c.png)

Structural isomers are molecules with the same molecular formula but different arrangements of atoms. In this case, structures I and III are isomers of hexane.

This question is categorized as hard as the student must use molecular formulas and skeletal structures to compare different molecules.
