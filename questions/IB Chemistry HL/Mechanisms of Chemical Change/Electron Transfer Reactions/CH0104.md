# CH0104

Consider the following reactions:        

$\begin{aligned}

\ce{Fe(s) + Cu^{2+}(aq) &-> Fe^{2+}(aq) + Cu(s)} \\

\ce{Fe(s) + 2Ag^{+}(aq) &-> Fe^{2+}(aq) + 2Ag(s)} \\

\ce{Zn(s) + Fe^{2+}(aq) &-> Zn^{2+}(aq) + Fe(s)} \\

\ce{Cu(s) + 2Ag+(aq) &-> Cu^{2+}(aq) + 2Ag(s)}

\end{aligned}$

Which is the correct combination of strongest oxidizing agent and strongest reducing agent?

- :::tableoptions{col1="hide"}

  ||Strongest reducing agent| Strongest oxidizing agent|

  |:-:|:-:|:-:|

  |A.$\hspace{1em}$|Zn(s)|Ag(s)

  |B.$\hspace{1em}$|Zn(s)|Ag$^+$(aq)

  |C.$\hspace{1em}$|Ag(s)|Zn$^{2+}$(aq)

  |D.$\hspace{1em}$|Ag$^+$(aq)|Zn(s)

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation:}}$\

A reducing agent is the species that donates electrons (it is oxidized), while an oxidizing agent accepts electrons (it is reduced). The four spontaneous reactions given let us rank metals by how readily they donate electrons and cations by how readily they accept them.

In the spontaneous reaction

$\ce{Fe(s) + Cu^{2+}(aq) -> Fe^{2+}(aq) + Cu(s)}$

iron metal is oxidized to $\ce{Fe^{2+}}$

while $\ce{Cu^{2+}}$ is reduced to solid copper.  That tells us Fe is a stronger reducing agent than Cu, and $\ce{Cu^{2+}}$ is a stronger oxidizing agent than $\ce{Fe^{2+}}.$ Using the same logic and the four equations provided, 

Equation | Ox. Agent | Red. Agent

:-:|:-:|:-:

$\ce{Fe(s) + Cu^{2+}(aq) -> Fe^{2+}(aq) + Cu(s)}$ |$\ce{Cu^{2+}} > \ce{Fe^{2+}}$ |Fe > Cu

$\ce{Fe(s) + 2\,Ag^{+}(aq) -> Fe^{2+}(aq) + 2\,Ag(s)}$|$\ce{Ag^{+}} > \ce{Fe^{2+}}$ |Fe > Ag 

$\ce{Zn(s) + Fe^{2+}(aq) -> Zn^{2+}(aq) + Fe(s)}$ |$\ce{Fe^{2+}} > \ce{Zn^{2+}}$ |Zn > Fe 

$\ce{Cu(s) + 2\,Ag+(aq) -> Cu^{2+}(aq) + 2\,Ag(s)}$|$\ce{Ag^{+}} > \ce{Cu^{2+}}$ |Cu > Ag 

we can rank the reducing agents:

Zn > Fe > Cu > Ag

and the oxidizing agents:

$\ce{Ag+} $ > $\ce{Cu^{2+}}$ > $\ce{Fe^{2+}}$ > $\ce{Zn^{2+}}$

Thus the strongest reducing agent is Zn and the strongest oxidizing agent is $\ce{Ag^+}.$
