# CH0752

In the reaction below, which of the statements below is correct if the reaction is assumed to  be spontaneous?

$\ce{3 Cu(s) + 2 NO3-(aq) + 8 H+(aq) -> 3 Cu^2+(aq) + 2 NO(g) + 4 H2O(l)}$

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | In a voltaic cell, gas would appear at the cathode. |

    | II. | In an electrolytic cell, copper metal would appear at the cathode. |

    | III. | Hydrogen is reduced. |

-   A.$\hspace{1em}$I only

-   B.$\hspace{1em}$II only

-   C.$\hspace{1em}$I and II only

-   D.$\hspace{1em}$I and III only

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation:}}$\

In a voltaic cell, $\ce{N}$ is reduced, and reduction appears at the cathode $\ce{(NO3-(aq) + 3 e- -> NO(g))}$, $\ce{NO}$ gas is produced.

In an electrolytic cell, the power source drives the reverse, nonspontaneous reaction, so $\ce{Cu}$ is reduced rather than oxidized as the equation states.

Reduction occurs at the cathode $\ce{(Cu^2+(aq) + 2 e- -> Cu(s))}$.

$\ce{H}$ maintains an oxidation state of 1+ throughout the reaction.
