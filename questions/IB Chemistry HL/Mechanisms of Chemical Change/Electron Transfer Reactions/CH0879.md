# CH0879

Which statement(s) is(are) true for the following redox reaction?

$\ce{Au(s) + NO3-(aq) + 4 H+(aq) + 4 Cl-(aq) -> AuCl4-(aq) + 2 H2O(l) + NO(g)}$

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Nitrate is the oxidizing agent|
  | II. | Nitrate loses electrons|
  | III. | Gold is reduced|

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$II only

- C. $\hspace{1em}$II and III only

- D. $\hspace{1em}$I and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The oxidation number of nitrogen changes from a higher oxidation state $(+5)$ to a lower oxidation state $(+2)$. This reduction of the nitrate ion can only happen because another species $\ce{(Au)}$ is being oxidized and losing electrons, which allows the nitrate ion to be reduced. So, the nitrate ion $\ce{(NO3^{-})}$ acts as the oxidizing agent in the given process.
