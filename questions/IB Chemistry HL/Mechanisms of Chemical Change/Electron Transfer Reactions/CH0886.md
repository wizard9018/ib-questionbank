# CH0886

What is the coefficient of carbon dioxide when these two half equations are combined?
$\newline \ $

$\begin{aligned}
\ce{MnO4-(aq) + 8 H+(aq) + 5e- &-> Mn^2+(aq) + 4 H2O(l)} \\
\ce{C2O4^2-(aq) &-> 2 CO2(g) + 2 e-}
\end{aligned}$

-   A.$\hspace{1em}$2

-   B.$\hspace{1em}$4

-   C.$\hspace{1em}$6

-   D.$\hspace{1em}$10

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$\
In a redox reaction, the number of electrons released by the oxidized species must equal the number of electrons obtained by the reduced species. For this, both the half-equations must first be multiplied by an appropriate integer.

| | | |
| :-: | -: | :- |
| $2\times$ | $\ce{[5 e- + 8 H+(aq) + MnO4-(aq) ->}$ | $\ce{Mn^2+(aq) + 4 H2O(l)]}$ |
| $5\times$ | $\ce{[C2O4^2-(aq) ->}$ | $\ce{2 CO2(g) + 2 e-}]$ |

Add the resulting equations:

| | |
| -: | :- |
| $\ce{10 e- + 16 H+(aq) + 2 MnO4-(aq) ->}$ | $\ce{2 Mn^2+(aq) + 8 H2O(l)}$ |
| $\ce{5 C2O4^2-(aq) ->}$ | $\ce{10 CO2(g) + 10 e-}$ |
| $\hspace{1em}$ | |
| $\ce{5 C2O4^2-(aq) + 16 H+(aq) + 2 MnO4^-(aq) ->}$ | $\ce{2 Mn^2+(aq) + 8 H2O(l) + 10 CO2(g)}$ |

Thus, the coefficient of carbon dioxide is 10.
