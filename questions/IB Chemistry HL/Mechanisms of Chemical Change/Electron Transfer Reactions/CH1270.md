# CH1270

Which of these redox reactions results to be spontaneous at standard conditions?

-   A. $\hspace{1em}\ce{LiNO3(aq) + Ag(s) -> AgNO3(aq) + Li(s)}$

-   B. $\hspace{1em}\ce{Mg(NO3)2(aq) + Pb(s) -> Pb(NO3)2(aq) + Mg(s)}$

-   C. $\hspace{1em}\ce{2 Al(NO_3)_3 (aq) + 3 Pb(s) -> 3 Pb(NO3)2(aq) + 2 Al(s)}$

-   D. $\hspace{1em}\ce{2 AgNO3(aq) + Sn(s) -> Sn(NO3)2(aq) + 2 Ag(s)}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Whether a reaction is spontaneous or not can be predicted from the $E^{\minuso}$ data.

Positive values for the standard cell potential apply to spontaneous reactions.

**Option A**:

$\ce{Li+(aq) + Ag(s) -> Ag+(aq) + Li(s)}$

$E_{cell}^{\minuso} =  E_{Li^+/Li}^{\minuso} - E_{Ag^+/Ag}^{\minuso} = -3.04\,\text{V} - \left(0.80\,\text{V}\right) = -3.84\,\text{V}$

**Option B**:

$\ce{Mg^{2+}(aq) + Pb(s) -> Pb^{2+}(aq) + Mg(s)}$

$E_{cell}^{\minuso} = E_{Mg^{2+}/Mg}^{\minuso} - E_{Pb^{2+}/Pb}^{\minuso} = -2.37\,\text{V} - \left(-0.13\,\text{V}\right) = -2.24\,\text{V}$

**Option C**:

$\ce{2 Al^{3+}(aq) + 3 Pb(s) -> 3 Pb^{2+}(aq) + 2 Al(s)}$

$E_{cell}^{\minuso} = E_{Al^{3+}/Al}^{\minuso} - E_{Pb^{2+}/Pb}^{\minuso} = -1.66\,\text{V} - \left(-0.13\,\text{V}\right) = -1.53\,\text{V}$

**Option D**:

$\ce{2 Ag+(aq) + Sn(s) -> Sn^{2+}(aq) + 2 Ag(s)}$

$E_{cell}^{\minuso} = E_{Ag^+/Ag}^{\minuso} - E_{Sn^{2+}/Sn}^{\minuso} = +0.80\,\text{V} - \left(-0.14\,\text{V}\right) = +0.94\,\text{V}$
