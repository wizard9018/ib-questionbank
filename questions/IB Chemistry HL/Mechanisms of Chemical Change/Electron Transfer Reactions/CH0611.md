# CH0611

Consider the following standard electrode potentials:

| | | |

| -: | :- | :- |

| $\ce {Ca^{2+}(aq) + 2e-}$ | $\ce{-> Ca(s)}$ | $E^\ominus = -2.87 V$ |

| $\ce{\frac{1}{2}Cl2(g) + e-}$ | $\ce{-> Cl^-(aq)}$ | $E^\ominus = +1.36 V$|

Which statement is $\textbf{incorrect}$?   

-   A. $\hspace{1em}$The non-spontaneous reaction requires a minimum voltage of $4.23$ V

-   B. $\hspace{1em}$In the spontaneous reaction, $\ce{Ca^{2+}}$ is the reducing agent

-   C. $\hspace{1em}$In the spontaneous reaction, $\ce{Cl2}$ is the oxidizing agent

-   D. $\hspace{1em}$The $E^\ominus_{cell}$ for the spontaneous reaction is $+4.23$ V

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The $\ce{Cl2/Cl-}$ half cell has a more positive electrode potential and so, will proceed in the forward direction where $\ce{Cl2}$ is reduced and acts as an oxidizing agent.

Ca will therefore be oxidized to $\ce{Ca^{2+}}$ with Ca acting as the reducing agent.

$E^\ominus_{cell} = 1.36 - (-2.87) = +4.23$ V.

For the non-spontaneous reaction, more than 4.23 V should be supplied.
