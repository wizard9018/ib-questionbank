# CH0119

Which statements about the electrolysis of molten aluminium oxide are correct?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. |  Aluminium ions gain electrons at the cathode |
  | II. | Oxide ions lose electrons at the cathode |
  | III. | The cathode is the site of reduction in this cell|

- A.$\hspace{1em}$I and II only

- B.$\hspace{1em}$I and III only

- C.$\hspace{1em}$II and III only

- D.$\hspace{1em}$I, II, and III

$\underline{\textrm{Explanation}}$:
