# CH0888

Which of these is a redox reaction?

-   A.$\hspace{1em}\ce{Cr2O7^2- + H2O -> 2 CrO4^2- + 2 H+}$

-   B.$\hspace{1em}\ce{BaCl2(aq) + K2SO4(aq) -> BaSO4(s) + 2 KCl(aq)}$

-   C.$\hspace{1em}\ce{CaO + SiO2 -> CaSiO3}$

-   D.$\hspace{1em}\ce{2 Li(s) + Ag2CrO4(s) -> Li2CrO4(s) + 2 Ag(s)}$

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$\
The oxidation number of lithium changes from zero to $+1$ and that of silver from $+1$ to zero.

No changes in oxidation states in all other reactions.
