# CH0112

**Maximum mark: 6**

The equation below shows the reaction between concentrated sulfuric acid and potassium iodide.

8KI(s) + 5H$_{2}$SO$_{4}$(aq) $\rightarrow$ 4K$_{2}$SO$_{4}$(aq) + 4I$_{2}$(g) + H$_{2}$S(g) + 4H$_{2}$O(l)

1. State the oxidation state of sulfur in H$_{2}$SO$_{4}$ and H$_{2}$S. [2 marks]

2. Write the half equations for the oxidation and reduction reactions. [2 marks]

3. Define oxidizing agent in terms of electrons. [1 mark]

4. Identify the oxidizing agent in the equation. [1 mark]

---

## 评分标准 / Mark scheme

1.  Assign $x$ for oxidation state of Sulfur.

    In H$_{2}$SO$_{4}$, $x$ = +6. $\checkmark$

    In H$_{2}$S, $x$ = $-2$. $\checkmark$

    *Must have + sign for mark.*\
    *Award one mark if roman numerals or 6+ or 2- used or if + signs are missing.*

    $\underline{\textrm{Further Explanation:}}$

    In H$_{2}$SO$_{4}$ : 2(+1) + $x$ + 4(-2) = 0 , therefore $x$ = +6.

    In H$_{2}$S: 2(+1) + $x$ = 0, therefore $x$ = $-2$.

2.  Half equation of reduction:

    $\ce{SO4^{2-}(aq) + 10 H^{+}(aq) + 8 e^{-} -> H2S(g) + 4 H2O(l)}\, \checkmark$

    **OR** $\hspace{1em}$

    $\ce{H2SO4(aq) + 8 H^{+}(aq) + 8 e^{-} -> H2S(g) + 4 H2O(l)}$

    Half equation of oxidation:

    $\ce{2 I^{-}(aq) -> I2(g) + 2 e^-}\,\checkmark$

    **OR** $\hspace{1em}$

    $\ce{2 KI(s) + SO4^{2-}(aq) -> K2SO4(aq) + I2(g) + 2 e^-}$

    *Ignore state symbols.*

    $\underline{\textrm{Further Explanation:}}$

    The oxidation state of sulfur decreased from +6 to $-2$, therefore it undergoes reduction.

3.  The oxidizing agent undergoes reduction and therefore gains one or more electrons. $\checkmark$

4.  $\ce{H2SO4}$ / $\ce{SO4^{2-}}$ $\checkmark$

    *Do not accept sulfur*

    $\underline{\textrm{Further Explanation:}}$

    An oxidizing agent oxidizes another species and is itself reduced (gains electrons). The oxidation state of S changes from +6 in $\ce{H2SO4}$ to $-2$ in $\ce{H2S}. It is not elemental sulfur that is reacting but rather the sulfur within the overall compound therefore, the whole species must be quoted when identifying the oxidizing (or reducing) agent.
