# CH0615

**Maximum mark: 4**

Two electrolytic cells consisting of silver electrodes in silver nitrate solution and copper electrodes in copper(II) sulfate solution are connected in series.

A current of $1.73 \textrm{\ C s}^{-1}$ is run through the electrolytic cells for 4.25 hrs.

1.  Calculate the mass of silver produced by the current. [3 marks]

2.  Predict whether the number of moles of copper produced is less than, greater than, or the same as the number of moles of silver produced. [1 mark]

---

## 评分标准 / Mark scheme

1.  $Q = It = 1.73 \times 4.25 \times 60 \times 60 = 26469\,\text{C}\,\checkmark$\
    $n_{\ce{e-}} = n_{\ce{Ag}} = \dfrac{Q}{F} = \dfrac{26469}{96500} = 0.274\,\text{mol}\,\checkmark$\
    $m_{\ce{Ag}} = 0.274 \times 107.87 = 29.6\,\text{g}\:\checkmark$

    $\underline{\textrm{Further explanation:}}$\
    In $Q = It$, time must be given in seconds.

    $Q = 1.73 \textrm{\ C s}^{-1} \times 4.25 \textrm{\ hr} \times \dfrac{60 \textrm{\ min}}{1 \textrm{\ hr}} \times \dfrac{60 \textrm{\ s}}{1 \textrm{\ min}} = 26469\,\text{C}$

    Given Faraday's constant, the number of electrons can be determined:

    $n_{\ce{e-}} = \dfrac{Q}{F} = \dfrac{26469\,\text{C}}{96500 \textrm{\ C mol}^{-1}} = 0.274 \textrm{\ mol e}^-$

    The $\ce{Ag : e-}$ ratio is $1:1$ as the half equation is $\ce{Ag+ + e- -> Ag}$.  So the mass of silver can be calculated.

    $m_{\ce{Ag}} = 0.274 \textrm{\ mol} \times 107.87 \textrm{\ g mol}^{-1} = 29.6 \textrm{\ g}$

2.  less than $\checkmark$

    $\underline{\textrm{Further explanation:}}$\
    $\ce{Cu^2+}$ requires twice as many electrons as $\ce{Ag+}$ to form the solid metal. As a result, half the number of moles of $\ce{Cu}$ will be produced for the same number of electrons.
