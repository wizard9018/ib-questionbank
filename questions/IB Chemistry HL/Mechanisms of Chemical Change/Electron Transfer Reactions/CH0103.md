# CH0103

What is the reducing agent in this reaction?

$\ce{Zn\textrm{(s)}}+ 2\ \ce{NO3^-\textrm{(aq)}} + 4 \ce{\ H+}\textrm{(aq)} \longrightarrow \ce{Zn^{2+}}\textrm{(aq)} + 2 \ce{\ NO2}\textrm{(g)} + 2 \ce{H2O}\textrm{(l)}$

- A.$\hspace{1em}$ $\ce{Zn\textrm{(s)}}$

- B.$\hspace{1em}$ $\ce{NO3^-\textrm{(aq)}}$

- C.$\hspace{1em}$ $\ce{Zn^{2+}\textrm{(aq)}}$

- D.$\hspace{1em}$ $\ce{H+\textrm{(aq)}}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Reducing agent is a substance that is oxidized.

Oxidation state of Zn increases from 0 to +2, whereas the oxidation state of N decreases from +5 to +4.

The oxidation state of H remains +1.

The oxidation state of O remains -2.
