# CH1178

Which change(s) in carbon can be classified as an oxidation?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{C -> CO2}$  |
  | II. | $\ce{C2O4^2- -> C2O2^2-}$ |
  | III. | $\ce{C2H4 -> C2H6}$ |

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$I and II only

- C. $\hspace{1em}$I and III only

- D. $\hspace{1em}$III only

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

Oxidation can be defined as the loss of electrons.

Oxidation occurs when the oxidation number increases.

In organic compounds/ions, oxidation occurs when oxygen is added, or hydrogen is removed.

In the first equation, oxygen is added to carbon. This one is an oxidation.

In the second equation, oxygen is removed. This one is a reduction.

In the third equation, hydrogen is added. This one is a reduction.

This question is categorized as easy as students must recognize oxidation in terms of the addition of oxygen/removal of hydrogen.
