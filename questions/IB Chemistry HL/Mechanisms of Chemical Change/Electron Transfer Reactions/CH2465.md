# CH2465

Consider the following standard electrode potentials.

$\mbox{}\\[-15pts]$

| $\mathbf{Half{\text{--}}reaction}$ | $\mathbf{E^{\minuso}\,/\,\textbf{V}}$ |
|:-:|:-:|
| $\ce{Zn^{2+}}\textrm{(aq)} + 2\ce{\,e-} \rightleftharpoons \ce{Zn}\textrm{(s)}$ | $-0.76$ |
| $\ce{Fe^{2+}}\textrm{(aq)} + 2\ce{\,e-} \rightleftharpoons \ce{Fe}\textrm{(s)}$ | $-0.45$ |
| $\ce{Cu^{2+}}\textrm{(aq)} + 2\ce{\,e-} \rightleftharpoons \ce{Cu}\textrm{(s)}$ | $+0.34$ |
| $\ce{Ag+}\textrm{(aq)} + \ce{e-} \rightleftharpoons \ce{Ag}\textrm{(s)}$ | $+0.80$ |

Which reaction is spontaneous under standard conditions?

-   A.$\hspace{1.em}\ce{Cu}\textrm{(s)} + \ce{Fe^{2+}}\textrm{(aq)} \longrightarrow \ce{Cu^{2+}}\textrm{(aq)} + \ce{Fe}\textrm{(s)}$

-   B.$\hspace{1.em}\ce{Fe}\textrm{(s)} + \ce{Zn^{2+}}\textrm{(aq)} \longrightarrow \ce{Fe^{2+}}\textrm{(aq)} + \ce{Zn}\textrm{(s)}$

-   C.$\hspace{1.em}\ce{Fe}\textrm{(s)} + 2\ce{\,Ag+}\textrm{(aq)} \longrightarrow \ce{Fe^{2+}}\textrm{(aq)} + 2\ce{\,Ag}\textrm{(s)}$

-   D.$\hspace{1.em}\ce{Ag}\textrm{(s)} + \ce{Cu^{2+}}\textrm{(aq)} \longrightarrow \ce{Ag+}\textrm{(aq)} + \ce{Cu}\textrm{(s)}$

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$\
A reaction is spontaneous under standard conditions when $E^{\minuso}_{\text{cell}} > 0.$ The cell potential is

$E^{\minuso}_{\text{cell}} = E^{\minuso}_{\text{cathode}} - E^{\minuso}_{\text{anode}},$

where the cathode half$-$cell is reduced and the anode half$-$cell is oxidised.

-   ${\ce{Cu + Fe^{2+}}:}$
Cu is oxidised, $\ce{Fe^{2+}}$ is reduced.

    $E^{\minuso}_{\text{cell}} = -0.45 - (+0.34) = -0.79\textrm{ V}$

    Not spontaneous. A less active (Cu) cannot reduce the ions of a more active metal (Fe).

-   $\ce{Fe + Zn^{2+}}:$ Fe is oxidised, $\ce{Zn^{2+}}$ is reduced.

    $E^{\minuso}_{\text{cell}} = -0.76 - (-0.45) = -0.31\textrm{ V}$

    Not spontaneous. Iron is less active than zinc, so iron cannot reduce zinc ions.

-   $\ce{Fe + 2 Ag+}:$ Fe is oxidised, $\ce{Ag+}$ is reduced.

    $E^{\minuso}_{\text{cell}} = +0.80 - (-0.45) = +1.25\textrm{ V}$

    Spontaneous. Iron is more active than silver, so iron reduces silver ions.

-   $\ce{Ag + Cu^{2+}}:$ Ag is oxidised, $\ce{Cu^{2+}}$ is reduced.

    $E^{\minuso}_{\text{cell}} = +0.34 - (+0.80) = -0.46\textrm{ V}$

    Not spontaneous. Silver has the highest $E^{\minuso}$ in the table, so it has the least tendency to be oxidised.
