# CH0751

The permanganate ion, $\ce{MnO4-}$, is an excellent oxidizing agent. Which reaction will proceed in the presence of $\ce{MnO4-}$?

-   A.$\hspace{1em} \ce{Fe^3+(aq) -> Fe^2+(aq)}$

-   B.$\hspace{1em} \ce{F2(g) -> 2F-(aq)}$

-   C.$\hspace{1em} \ce{H2O2(aq) -> H2O(l)}$

-   D.$\hspace{1em} \ce{H2O2(aq)-> O2(g)}$

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:\
The oxidizing agent is the species that is reduced and causes oxidation. Only $\ce{H2O2(aq)-> O2(g)}$ represents an oxidation half$-$reaction.  The oxidation state of oxygen in $\ce{H2O2}$ is $-1$ and oxygen loses one $\ce{e-}$ to change to an oxidation state of 0 in $\ce{O2}$.
