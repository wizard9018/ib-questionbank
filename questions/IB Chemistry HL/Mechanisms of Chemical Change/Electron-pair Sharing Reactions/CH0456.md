# CH0456

Which statement is correct for the following reaction? 

$\ce{NH3(aq) + BF3(aq) → NH3BF3(aq)}$

-   A. $\hspace{1em}\ce{BF3}$ donates a lone pair to $\ce{NH3}$

-   B. $\hspace{1em}\ce{NH3}$ donates a lone pair to $\ce{BF3}$

-   C. $\hspace{1em}\ce{BF3}$ is a Lewis base

-   D. $\hspace{1em}\ce{NH3}$ donates a proton to $\ce{BF3}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

There is a lone pair of electrons on the nitrogen atom which is donated to the boron atom with an incomplete octet.
