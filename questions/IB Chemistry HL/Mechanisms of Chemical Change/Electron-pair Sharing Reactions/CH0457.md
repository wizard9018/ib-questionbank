# CH0457

Which statements are correct?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | $\ce{CH3NH2}$ is a Lewis base |

    | II. | HOOCCOOH is a Bronsted-Lowry acid |

    | III. | $\ce{CH3+}$ is a Lewis acid |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Statement I is correct because there is a lone pair of electrons on the N atom of $\ce{CH3NH2}$.

Statement II is correct as HOOCCOOH is a dicarboxylic acid with two protons that can be donated.

Statement III is correct as $\ce{CH3+}$ is electron deficient and can accept a lone pair of electrons
