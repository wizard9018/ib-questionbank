# CH1559

Consider the synthetic route described below.

![CH1559_Image1](images/CH1559_Image1.png)

Some reactants, conditions and products are missing. Which combination below would be correct?

    | | Reaction 1 | Reaction 3 | Product E |

    | --: |:-: | :-: | :-: | 

    | A.$\hspace{1em}$ | $S_N2$ | $\ce{K2Cr2O7, H+},$ heat | ethyl ethanoate |

    | B.$\hspace{1em}$ | $S_N2$ | $\ce{O2}$ | ethyl propanoate |

    | C.$\hspace{1em}$ | $S_N1$ | $\ce{K2Cr2O7, H+},$ heat | propyl ethanoate |

    | D.$\hspace{1em}$ | $S_N1$ | $\ce{O2}$ | ethyl propanoate |

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

The student must understand the synthetic route proposed. The first reaction is a nucleophilic substitution. The reactant is a primary halogenoalkane, so a bimolecular nucleophilic substitution $(S_N2)$ is favoured due to the absence of steric hindrance.

Reactions 2 and 3 are oxidations. Both steps are controlled oxidations which require an oxidizing agent such as $\ce{K2Cr2O7},$ an acidic solution $(\ce{H+}),$ and heat. To stop at the aldehyde would require distillation while continuing to the carboxylic acid is done with reflux.

Finally, the product E of Reaction 4 is an ester. The esterification is described below.

![CH1559_Image2](images/CH1559_Image2.png)

This ester is named ethyl ethanoate according to the IUPAC rules.

This question is categorized as a medium as the student must identify the different reactions and should be able to name the ester produced.
