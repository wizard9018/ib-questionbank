# CH0451

Which of the following is both a Bronsted$-$Lowry acid and a Lewis acid?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | $\ce{H2O}$ |

    | II. | $\ce{H3O+}$ |

    | III. | $\ce{NH4+}$ |

-   A.$\hspace{1em}$I and II only

-   B.$\hspace{1em}$I and III only

-   C.$\hspace{1em}$II and III only

-   D.$\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation:}}$\

Bronsted$-$Lowry acids are $\ce{H+}$ donors; Lewis acids are electron-pair acceptors.

$\ce{H2O}$ can donate an $\ce{H+}$ to form $\ce{OH-}$ but cannot accept a pair of electrons.
