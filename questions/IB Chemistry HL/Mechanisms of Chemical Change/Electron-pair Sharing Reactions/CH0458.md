# CH0458

Which statements are correct for $\ce{[Cr(NH3)4Cl2]^+}$?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | $\ce{Cr^{3+}}$ is a Lewis acid |

    | II. | $\ce{Cl-}$ is a Lewis base |

    | III. | $\ce{NH3}$ is an electrophile |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

$\ce{Cr^{3+}}$ can accept a pair of electrons ,and so, is a Lewis acid.

$\ce{Cl-}$ has lone pairs of electrons, and so, is a Lewis base.

Statement III is incorrect because $\ce{NH3}$ is a nucleophile since it has a lone pair of electrons on N atom.
