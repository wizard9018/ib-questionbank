# CH1021

Which equation represents a propagation step?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | $\ce{\text{\char"A78F}CH3 + HCl -> CH4 + Cl\text{\char"A78F}}$ |

    | II. | $\ce{\text{\char"A78F}CH3 + Cl\text{\char"A78F} -> CH3Cl}$ |

    | III. | $\ce{CH4 + Cl\text{\char"A78F} -> \text{\char"A78F}CH3 + HCl}$ |

-   A.$\hspace{1em}$I only

-   B.$\hspace{1em}$II only

-   C.$\hspace{1em}$III only

-   D.$\hspace{1em}$I and III only

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$\

The student must distinguish initiation, propagation, and termination steps. A propagation step involves no change in the number of free radicals. In propagation, highly reactive radicals collide with a molecule in the reaction mixture, a combination occurs, and a new radical is formed. In contrast, an initiation increases the number of free radicals, and a termination decreases the number of free radicals.

Let's analyze the given options:

$\ce{\text{\char"A78F}CH3 + HCl -> CH4 + Cl\text{\char"A78F}}$ | $\textrm{propagation}$

:-:|:-:

$\ce{\text{\char"A78F}CH3 + Cl\text{\char"A78F} -> CH3Cl}$| termination

$\ce{CH4 + Cl\text{\char"A78F} -> \text{\char"A78F}CH3 + HCl}$ |  propagation

This question is categorized as medium. The student must recall the radical mechanisms and steps involved.
