# CH1020

Which equation represents a homolytic fission?

-   A.$\hspace{1em}\ce{CH3I -> CH3+ + I-}$

-   B.$\hspace{1em}\ce{(CH3)3C+ + OH- -> (CH3)3OH}$

-   C.$\hspace{1em}\ce{CH3CH3 -> 2 \text{\char"A78F}CH3}$

-   D.$\hspace{1em}\ce{\text{\char"A78F}CH3 + Cl\text{\char"A78F} -> CH3Cl}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The student must recognize the radical formation in homolytic fissions. Homolytic fissions occur when one of the shared electrons goes to each atom, as shown below.

![R3.3-1020](images/R3.3-1020.png)

As a result, two free radicals are formed. In the description above, $\ce{X2}$ breaks up into two X radicals (each with an unpaired electron).

Let's analyze the given options:

-   $\ce{CH3I -> CH3+ + I-}$. This process is classified as a heterolytic fission.

-   $\ce{(CH3)3C+ + OH- -> (CH3)3OH}$. This process is the second step of an SN1 mechanism.

-   $\ce{CH3CH3 -> 2 CH3.}$. This is an initiation step of a radical mechanism. The $\ce{C-C}$ bond is broken (homolytic fission) so that the two shared electrons are separated and radicals are formed. This is the correct option.

-   $\ce{CH3. + Cl. -> CH3Cl}$. This is a termination step of a radical mechanism. These radicals combine and form a new bond ($\ce{C-Cl}$).

        

This question is categorized as medium. The student must recall the concept of homolytic fission and formulate this process in an alkane (instead of the typical halogen homolytic fission).
