# CH0874

Which statements are correct for the following reaction?
$\ \newline \ $

$\ce{HNO3(aq) + H2SO4(aq) <=> H2NO3+(aq) + HSO4-(aq)}$

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{H2SO4}$ is a stronger acid than $\ce{HNO3}.$  |
  | II. | $\ce{HSO4-}$  can donate and accept protons. |
  | III. | $\ce{HNO3}$ is acting as a Bronsted$-$Lowry base. |

- A.$\hspace{1em}$I and II only

- B.$\hspace{1em}$I and III only

- C.$\hspace{1em}$II and III only

- D.$\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Although $\ce{HNO3}$ and $\ce{H2SO4}$ are acids, $\ce{HNO3}$  can act as a base when reacted with a stronger acid such as $\ce{H2SO4}$, therefore statement I is true.

In this reaction, $\ce{H2SO4}$ has donated a proton to become $\ce{HSO4-}$ which can donate another proton to form $\ce{SO4^{2-}}$, therefore it is amphiprotic (as it can both donate or accept a proton), and statement II is true.

As seen by the reaction products, $\ce{HNO3}$  accepts a proton which means it is acting as a Bronsted-Lowry base, therefore statement III is true.
