# CH2218

The graph shows the pH change when aqueous ammonia is titrated with aqueous hydrochloric acid.

![CH2218](images/CH2218.png)

Which of the following statements about this titration are correct?

-   A. $\hspace{1em}$For ammonia, $\text{p}K_b = 9.25.$

-   B. $\hspace{1em}$Phenolphthalein is a suitable indicator for this titration.

-   C. $\hspace{1em}$This neutralization produces a basic salt.

-   D. $\hspace{1em}$An indicator whose $\text{p}K_a$ is close to 5.6 would give an accurate end point.

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

The student must understand the titration of a weak base with a strong acid.

The equivalence point occurs at $V = 20\text{ cm}^3.$ Here, the pH is near 6. A suitable indicator should have a $\text{p}K_a$ close to 6 to have the color change occur at the equivalence point. Phenolphthalein changes colors between $\text{pH} = 8$ and 10. The solution would become colorless well before the equivalence point so phenolphthalein would not be the correct choice.

At the half$\text{--}$equivalence point $(V = 10\text{ cm}^3),$ $\text{pH} = \text{p}K_a.$ For ammonia, the $\text{p}K_a = 9.25,$ so the $\text{p}K_b = 4.75.$

The salt produced in this neutralization is acidic.

$\ce{NH3(aq) + HCl(aq) -> NH4+(aq) + Cl-(aq)}$

Ammonium chloride is an acid because it donates a $\ce{H+}$ to water and forms hydronium ions:

$\ce{NH4+(aq) + H2O(l) <=> NH3(aq) + H3O+(aq)}$

This question is categorized as a medium as the student must understand the features of the titration curve of a weak base with a strong acid.
