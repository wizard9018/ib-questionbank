# CH0904

Lead(II) oxide (PbO) undergoes the following reactions.

$\begin{aligned}
\ce{PbO(s) + 2 H+(aq) ->& \ Pb^2+(aq) + H2O(l)} \\
\ce{PbO(s) + 2 OH-(aq) + H2O(l) ->& \ Pb(OH)4^2-(aq)}
\end{aligned}$

Which of the following best describes the acid$-$base behaviour of PbO?

-   A.$\hspace{1em}$PbO is not amphiprotic but is a Brønsted$-$Lowry acid

-   B.$\hspace{1em}$PbO is not amphiprotic but is a Brønsted$-$Lowry base

-   C.$\hspace{1em}$PbO is amphiprotic, and a Brønsted$-$Lowry acid

-   D.$\hspace{1em}$PbO is amphiprotic, and a Brønsted$-$Lowry base

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:\
A Brønsted$-$Lowry acid is a species that donates hydrogen $\ce{(H+)}$ ions, while a Brønsted$-$Lowry base is a species that accepts hydrogen ions. A species with both properties is termed amphiprotic.

PbO reacts with hydrogen ions in the first reaction to form water, so must be a Brønsted$-$Lowry base. It also reacts with basic hydroxide ions, making it an acid. Being both an acid and a base, PbO may be classified as ***amphoteric.*** However, the reaction with hydroxide ions does not involve hydrogen ions, so PbO is neither a Brønsted$-$Lowry acid nor amphiprotic.
