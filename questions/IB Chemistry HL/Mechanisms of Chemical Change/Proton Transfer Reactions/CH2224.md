# CH2224

Which of the following is a Lewis acid but not a Bronsted$-$Lowry acid?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | $\ce{BF3}$ |
    | II. | $\ce{FeCl3}$ |
    | III. | $\ce{CH3CH2COOH}$ |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$I and II only

-   D. $\hspace{1em}$III only

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$

A Bronsted$\text{--}$Lowry acid is defined as a proton donor, so propanoic acid $\ce{(CH3CH2COOH)}$ clearly fits this description, since it can release an $\ce{H+}$ ion from its carboxyl group. In contrast, Lewis acids are species that accept an electron pair, and this definition is broader. Both boron trifluoride and iron(III) chloride are electron$\text{--}$deficient species: $\ce{BF3}$ has an incomplete octet around boron, and $\ce{FeCl3}$ has a high positive charge density on the central metal ion. Each can therefore act as an electron$\text{--}$pair acceptor, forming coordinate bonds with suitable bases. Since neither $\ce{BF3}$ nor $\ce{FeCl3}$ donates protons, they are Lewis acids but not Bronsted$\text{--}$Lowry acids.
