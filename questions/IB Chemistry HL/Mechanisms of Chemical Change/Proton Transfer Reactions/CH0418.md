# CH0418

**Maximum mark: 6**

Hydrogen sulfide, $\ce{H2S}$, is a weak acid with a $pK_a$ of 7.04.

1.  

    1.  State the acid dissociation constant expression for $\ce{H2S}$. [1 mark]

    

    2.  Calculate $K_a$ for $\ce{H2S}$. [1 mark]

2.  

    1.  State the base dissociation constant expression for $\ce{HS-}$. [1 mark]

    2.  Calculate $K_b$ for $\ce{HS-}$ assuming a temperature of 298 K. [1 mark]

3.  Using your answers to parts (a)(i) and (b)(i), derive the equation $K_w = K_a \times K_b$. [2 marks]

---

## 评分标准 / Mark scheme

1.  

    1.  $K_a = \dfrac{\ce{[HS-][H+]}}{\ce{[H2S]}}$ $\checkmark$

        $\underline{\textrm{Further Explanation}}$:

        $K_a = \dfrac{\ce{[H+][A-]}}{\ce{[HA]}}$

    2.  $K_a = 10^{-pK_a} = 10^{-7.04} =$ :answer[$9.12 \times 10^{-8}$] $\checkmark$

2.  

    1.  $K_b = \dfrac{\ce{[H2S][OH-]}}{\ce{[HS-]}}$ $\checkmark$

        $\underline{\textrm{Further Explanation}}$:

        $K_b = \dfrac{\ce{[BH+][OH-]}}{\ce{[B]}}$, where B is $\ce{HS-}$

    2.  $K_w = K_a \times K_b$

        $\Longrightarrow K_b = \dfrac{K_w}{K_a} = \dfrac{1.00 \times 10^{-14}}{9.12 \times 10^{-8}} =$ :answer[$1.10 \times 10^{-7}$] $\checkmark$

3.  $K_w = \ce{[H+][OH-]}$ $\checkmark$

    $\ce{[H+]} = \dfrac{\ce{[H2S]}}{\ce{[HS-]}}K_a$ $\hspace{1em}$ *AND*  $\hspace{1em}$ $\ce{[OH-]} = \dfrac{\ce{[HS-]}}{\ce{[H2S]}}K_b$

    $K_w = \dfrac{\ce{[H2S]}}{\ce{[HS-]}}K_a \times \dfrac{\ce{[HS-]}}{\ce{[H2S]}}K_b = K_a \times K_b$ $\checkmark$
