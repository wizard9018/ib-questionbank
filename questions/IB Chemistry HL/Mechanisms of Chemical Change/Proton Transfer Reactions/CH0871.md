# CH0871

What is the concentration of $\ce{H+}$ and $\ce{OH-}$ ions in a 1.00 mol dm$^{-3}$ solution of $\ce{NH3}$?

- :::tableoptions{col1="hide"}
  | | [H$^\mathbf{+}$] / $\mathbf{mol\ dm}^\mathbf{-3}$ | [OH$^\mathbf{-}$] / $\mathbf{mol\ dm}^\mathbf{-3}$ |
  | :-: | :-: | :-: |
  | A. | $1.00\ \times\ 10^{-14}$| $1.00$ |
  | B. | $1.00$| $1.00\ \times\ 10^{-14}$ |
  | C. | $> 1.00\ \times\ 10^{-14}$ | $< 1.00$ |
  | D. | $ > 1.00$ | $< 1.00\ \times\ 10^{-14}$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

$\ce{NH3}$ is a weak base; it only partially dissociates in water:

$\ce{NH3 + H2O <=> NH4+ + OH-}$

If $[\ce{NH3}] = 1.00\,\text{mol dm}^{-3}$, then the $[\ce{OH-}]< 1.00\,\text{mol dm}^{-3}$; only for a strong base would the base completely hydrolyze.

Since $K_w = \ce{[H+][OH-]} = 1.00\times 10^{-14}$, this means that if $[\ce{OH-}] < 1.00\,\text{mol dm}^{-3}$,  $[\ce{H+}] > 1.00 \times 10^{-14}\,\text{mol dm}^{-3}.$
