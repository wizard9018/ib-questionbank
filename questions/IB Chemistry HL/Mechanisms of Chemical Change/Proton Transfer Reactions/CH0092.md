# CH0092

Using the following table of indicators, what could be the pH of an unknown solution with the following results? 

| | Indicator | pH range|Colour change (Acid$\textbf{--}$alkali)| Result with Unknown Solution|

| --- | :-: | :-: |:-: | :-: |

| | Methyl orange | 3.1$\text{--}$4.4 |Red$\text{--}$Orange|Orange|

| | Bromocresol green  | 3.8$\text{--}$5.4  |Yellow$\text{--}$Blue|Blue|

| | Phenolphthalein | 8.3$\text{--}$10.0|Colourless$\text{--}$Pink|Colourless|

- A.$\hspace{1em}$3.3

- B.$\hspace{1em}$4.0

- C.$\hspace{1em}$6.5

- D.$\hspace{1em}$11

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$\

The pH would be greater than 4.4, greater than 5.4, and lower than 8.3 for the above resultant colours.
