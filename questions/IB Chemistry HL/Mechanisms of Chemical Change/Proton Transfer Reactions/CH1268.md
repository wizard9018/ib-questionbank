# CH1268

Which statements about sodium ethanoate are correct?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | It is classified as a basic salt.  |
  | II. | Its parent base is sodium hydroxide. |
  | III. | Its parent acid is ethanol. |

- A. $\hspace{1em}$I, II, and III

- B. $\hspace{1em}$I and II only

- C. $\hspace{1em}$I and III only

- D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:\
Sodium ethanoate is $\ce{CH3COONa}$, formed in the neutralization reaction between sodium hydroxide and ethanoic acid, as shown below.

$\ce{CH3COOH + NaOH -> CH3COONa + H2O}$

Ethanoic acid is the parent acid, and sodium hydroxide is the parent base.

This salt is classified as a basic salt as its dissociation in water produces ethanoate ions. These ions can react with water to form ethanoic acid, taking $\ce{H+}$ from the solution. Accepting protons results in a basic behaviour for this salt.

$\ce{CH3COONa(s) -> CH3COO-(aq) + Na+(aq)}$

$\ce{CH3COO-(aq) + H2O(l) <=> CH3COOH + OH-(aq)}$

This question is categorized as medium difficulty as students must deduce the formula of the salt to figure out the parent acid and base as well as the acid-base character of the salt.
