# CH0916

**Maximum mark: 8**

When dilute hydrochloric acid is titrated against an aqueous solution of base **B**, the following pH curve is obtained.

![CH0916_Image1](images/CH0916_Image1.png)

1. State a suitable indicator for this titration, using section $22$ (*Section 18 - 2025 Syllabus*) of the data booklet. [1 mark]

2. Explain what the position of the equivalence point indicates about the $K_b$ value of base **B**. [3 marks]

3. The pH of the titrant solution is $9.24$.\
 Assuming $pK_w\ =\ 14.00$, calculate the hydroxide concentration of the solution, $\ce{[OH-]}$. [2 marks]

4. If aqueous sodium hydroxide is used as a titrant instead of the solution of base **B**, the concentration of the hydrochloric acid sample can be determined more precisely.

    Explain how the use of sodium hydroxide as a titrant alters the pH curve to produce a more precise titration result. [2 marks]

## 评分标准 / Mark scheme

1. Methyl orange **OR** bromophenol blue **OR** bromocresol green $\checkmark$

    *Award [0] if more than one indicator is named; \
Award [0] if only part of the compound name is given.*

    $\underline{\textrm{Further Explanation:}}$ \
 The colour change of the indicator should occur at the equivalence point of the reaction, where the acid and base have completely reacted and neither reagent is in excess.\
  The equivalence point is marked by a rapid change in pH, and the colour change of an indicator occurs in the range $pH\ =\ pK_a\ ±\ 1$.\
   The equivalence point of this reaction occurs at around pH $3$, since this is the steepest part of the curve. Therefore, the indicator should have a stated pH range between $2$ and $4$, or a $pK_a$ within or close to this range of values. Only methyl orange, bromophenol and bromocresol green satisfy this requirement.

2. The equivalence point is below $7$ / occurs at an acidic pH $\checkmark$ \
**B** must be a weak base / have a strong conjugate acid (since hydrochloric acid is a strong acid / has a weak conjugate base) $\checkmark$ \
so the $K_b$ is small / the $pK_b$ is large $\checkmark$

    *Award M3 but **not** M2 if $K_b$ is correctly described but **B** is stated to be a strong base; \
Award M3 but **not** M2 if the description of $K_b$ is incorrect but consistent with the description of **B**; \
Do **not** award M1 if the pH of the equivalence point is stated but not stated to be acidic or compared to a neutral solution; \
Do **not** award M3 for a specific value of $K_b$ or $pK_b$ unless the relative size of this value is described; \
Do **not** award M3 if $K_a$ or $pK_a$ are described instead of $K_b$ or $pK_b$.*

    $\underline{\textrm{Further Explanation:}}$ \
At the equivalence point, all of the acid has been converted to its conjugate base and all of the base to its conjugate acid.\
 Hydrochloric acid is a strong acid, so its conjugate base $\ce{(Cl^-)}$ is a weak base. If base **B** were a strong base, its conjugate acid would be weak and the final solution would be approximately neutral, with a pH close to $7$.\
  The pH is actually around $3$, i.e. much less than $7$, so the conjugate acid of **B** must be relatively strong. Thus, **B** must be a weak base. The value of $K_b$ increases with the strength of the base and the value, so **B** must have a small $K_b$.

3. $\hspace{1em}$ $\ce{pOH\ =\ pK_w\ –\ pH\ =\ 14\ –\ 9.24\ =\ 4.76}$ **OR** $\ce{[H+]\ =\ 10^{-9.24}\ =\ 5.75\ \times\ 10^{-10}\ (mol\ dm^{-3})}$ $\checkmark$ \
    $\hspace{1em}$ $\ce{[OH-]\ =\ 10^{-4.76}\ =\ 1.7\ (4)\ \times\ 10^{-5}\ (mol\ dm^{-3})}$ **OR** $\ce{[OH-]\ =\ \dfrac{10^{-14}}{5.75 \times\ 10^{-10}}\ =\ 1.7\ (4)\ \times\ 10^{-5}\ (mol\ dm^{-3})}$ $\checkmark$

    *Accept concentration values stated without units; \
Accept rounding errors in the second decimal place of $\ce{[OH-]}$, if present; \
Accept correct rearranged versions of expressions for $\ce{pOH}$ or $\ce{[H+]}$; \
Award M1 if workings are shown without final value of $K_{a}$ or $pK_b$; \
Award M2 for correct $\ce{[OH-]}$ with no working shown; \
Award M2 if correct method is shown but $\ce{[OH-]}$ is incorrect due to an explicit follow-through error in $\ce{pOH}$ or $\ce{[H+]}$; \
Award [1] for correct answer if it is not produced by the working given, e.g. if $\ce{pOH}$ is used but not explicitly calculated; \
Do **not** award M1 for correct $\ce{pOH}$ or $\ce{[H+]}$ with no working shown.*

    $\underline{\textrm{Further explanation:}}$ \
    $pK_w$ indicates the degree of dissociation of water into $\ce{H+}$ and $\ce{OH-}$ ions and is equal to the sum of pH and $\ce{pOH}$.\
     Thus, $\ce{pOH\ =\ pK_w\ –\ pH}$.\
      The value of $\ce{[OH-]}$ is linked to $\ce{pOH}$ via the expression $\ce{pOH\ =\ -log_{10}\ [OH-]}.$\
       Reversing the logarithm operation gives the expression $\ce{[OH-]\ =\ 10^{-pOH}}$.

     The steps of this calculation can be performed in a different order.\
      First, $K_w$ and $\ce{[H+]}$ are calculated using the expressions $K_w\ =\ 10^{-pKw}$ and $\ce{[H+]\ =\ 10^{-pH}}$. Then, the expression $\ce{K_w\ =\ [H+]\ [OH-]}$ is rearranged to give $\ce{[OH-]}\ =\ \dfrac{K_w}{\ce{[H+]}}$.

4. (Because sodium hydroxide is a strong base) the curve rises more sharply / the gradient of the curve is increased (around the equivalence point) **OR** the sharp rise in pH occurs over a narrower range of titrant volumes $\checkmark$ \
so the colour change occurs over a narrower range of titrant volumes **OR** the pH range of the indicator corresponds to a smaller range of titrant volumes $\checkmark$

    *Award M1 for similar correct descriptions of the change in the pH curve near the equivalence point; \
Do **not** award M1 if the pH curves before and after the change are not explicitly compared; \
Do **not** award M2 if the answer does not describe the correspondence between titrant volume and indicator colour change or pH range.*

    $\underline{\textrm{Further explanation:}}$ \
    The end-point of the titration is determined from the indicator colour change, which occurs over the range $pH\ =\ pK_a\ ±\ 1$.

     Sodium hydroxide is a much stronger base than **B**, with a much weaker conjugate acid, so the pH rises more sharply around the equivalence point and reaches a higher final value. A given volume of titrant added just before the equivalence point causes the pH to change by a much larger amount, so the colour change is completed over a narrower range of titrant volumes. Thus, there is less uncertainty in the measured titre or the analyte concentration calculated from this value.
