# CH1269

Which of these behaves as a buffer solution?

-   A. $\hspace{1em}100\,\text{cm}^3$ of $0.500\,\text{mol dm}^{-3}\,\ce{CH3COOH(aq)}$ and $100\,\text{cm}^3$ of $0.500\,\text{mol dm}^{-3}\,\ce{NaOH(aq)}$

-   B. $\hspace{1em}100\,\text{cm}^3$ of $0.500\,\text{mol dm}^{-3}\,\ce{CH3COOH(aq)}$ and $200\,\text{cm}^3$ of $0.500\,\text{mol dm}^{-3}\,\ce{NaOH(aq)}$

-   C. $\hspace{1em}100\,\text{cm}^3$ of $0.100\,\text{mol dm}^{-3}\,\ce{CH3COOH(aq)}$ and $50\,\text{cm}^3$ of $0.500\,\text{mol dm}^{-3}\,\ce{HCl(aq)}$

-   D. $\hspace{1em}100\,\text{cm}^3$ of $0.100\,\text{mol dm}^{-3}\,\ce{CH3COOH(aq)}$ and $200\,\text{cm}^3$ of $0.500\,\text{mol dm}^{-3}\,\ce{CH3COONa(aq)}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Buffer solutions contain both components of a conjugate acid-base pair. This allows the resistance to pH changes when small amounts of acids and bases are added.

The amount of acid and base can be deduced for every option to check if the reaction mixture contains the conjugate acid-base pair.

Determiner the amount, in moles, of the reactants using the relationship $n = CV$ where $C$ is the concentration in $\text{mol dm}^{-3}$ and $V$ is the volume in $\text{dm}^3.$

$n_\ce{CH3COOH} = 0.500\,\text{mol dm}^{-3}\times 0.100\,\text{dm}^3  = 0.0500.\,\text{mol}$

$n_\ce{NaOH} = 0.500\,\text{mol dm}^{-3}\times 0.100\,\text{dm}^3 = 0.0500\,\text{mol}$

This results in a complete reaction where all the ethanoic acid is converted into its conjugate base. Consider the table below where **S** represents the starting amount, **C** the change in that amount as the reaction goes to completion and **F** the final amounts of the reactants and products.

| | $\ce{CH3COOH(aq)}$ | + | $\ce{NaOH(aq)}$ | $\ce{<=>}$ | $\ce{CH3COO-(aq)}$ | + | $\ce{H2O(aq)}$ | + | $\ce{Na+(aq)}$ |
| :-: | --: | :-: | --: | :-: | --: | :-: | --: | :-: | --: |
**S** | 0.0500 | | 0.0500 |
**C** | $-0.0500$ | | $-0.0500$ | | +0.0500 | | +0.0500 | | +0.0500 |
**F**| 0 | | 0 | |0.0500 | | 0.0500 | | 0.0500 |

This is not a buffer solution.

$n_\ce{CH3COOH} = 0.500\,\text{mol dm}^{-3}\times 0.100\,\text{dm}^3  = 0.0500\,\text{mol}$

$n_\ce{NaOH} = 0.500\,\text{mol dm}^{-3}\times 0.200\,\text{dm}^3 = 0.100\,\text{mol}$

This results in a complete reaction where all the ethanoic acid is converted into its conjugate base and some sodium hydroxide remains in excess.

| | $\ce{CH3COOH(aq)}$ | + | $\ce{NaOH(aq)}$ | $\ce{<=>}$ | $\ce{CH3COO-(aq)}$ | + | $\ce{H2O(aq)}$ | + | $\ce{Na+(aq)}$ |
| :-: | --: | :-: | --: | :-: | --: | :-: | --: | :-: | --: |
**S** | 0.0500 | | 0.0500 |
**C** | $-0.050$ | | $-0.050$ | | +0.050 | | +0.050 | | +0.050 |
**F**| 0 | | 0.050 | |0.050 | | 0.050 | | 0.050 |

This is not a buffer solution.

$n_\ce{CH3COOH} = 0.100\,\text{mol dm}^{-3}\times 0.100\,\text{dm}^3  = 0.0100\,\text{mol}$

$n_\ce{HCl} = 0.100\,\text{mol dm}^{-3}\times 0.050\,\text{dm}^3 = 0.00500\,\text{mol}$

This is not a buffer solution, as no conjugate base will be formed.

$n_\ce{CH3COOH} = 0.100\,\text{mol dm}^{-3}\times 0.100\,\text{dm}^3  = 0.0100\,\text{mol}$

$n_\ce{CH3COONa} = 0.100\,\text{mol dm}^{-3}\times 0.200\,\text{dm}^3 = 0.0200\,\text{mol}$

This is a buffer solution as both provide the conjugate acid-base pair to the buffer solution $(\ce{CH3COOH}$ / $\ce{CH3COO-}).$

This question is categorized as easy as students must analyze each composition and figure out the one with buffering capacity.
