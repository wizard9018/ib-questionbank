# CH0639

Aluminium oxide ($\ce{Al2O3}$) undergoes the following reactions:

$\ce{Al2O3 + 2 NaOH + 3 H2O -> 2 NaAl(OH)4}$

$\ce{Al2O3 + 6 HCl -> 2 AlCl3 + 3 H2O}$

Which of the following is the best description of aluminium oxide?

-   A. $\hspace{1em}$Both a Brønsted-Lowry acid and a Brønsted-Lowry base

-   B. $\hspace{1em}$A Brønsted-Lowry acid but not a Brønsted-Lowry base

-   C. $\hspace{1em}$A Brønsted-Lowry base but not a Brønsted-Lowry acid

-   D. $\hspace{1em}$Neither a Brønsted-Lowry acid nor a Brønsted-Lowry base

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

$\ce{Al2O3}$ can accept hydrogen ions from HCl so is a Brønsted-Lowry base.

It can also react with the base NaOH, but it does not donate hydrogen ions in this reaction. It is therefore, an acid but not a Brønsted-Lowry acid. [It is a Lewis base.]

$\ce{Al2O3}$ is amphoteric but not amphiprotic. The distinction is that an amphoteric compound can act as an acid or a base while an amphiprotic compound can donate or accept a hydrogen ion (or act specicially as a Brønsted-Lowry acid or Brønsted-Lowry base.)

This question is hard as the student must recognise that HCl and NaOH are an acid and base, respectively, and deduce the reactivity of a specific compound from its reaction equations alone.
