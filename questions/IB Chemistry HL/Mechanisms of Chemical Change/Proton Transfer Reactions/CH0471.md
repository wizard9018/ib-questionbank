# CH0471

Which of the following salts form basic solutions when dissolved in water?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{NH4Cl}$ |
  | II. | $\ce{K2CO3}$ |
  | III. | $\ce{NaOOCCH3}$ |

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$I and III only

- C. $\hspace{1em}$II and III only

- D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The salts in II and III are both formed by the reaction between a weak acid ($\ce{H2CO3}$ and $\ce{CH3COOH}$ respectively) and a strong base ($\ce{KOH}$ and $\ce{NaOH}$ respectively).

$\ce{NH4Cl}$ is the product of a weak base ($\ce{NH3}$) and a strong acid ($\ce{HCl}$) resulting in an acidic solution.
