# CH2219

Which of the following salts is/are acidic?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | $\ce{AlCl3}$ |
    | II. | $\ce{CH3NH3Cl}$ |
    | III. | $\ce{KI}$ |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$II only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$

When you judge the acidity or basicity of a salt solution, compare the strengths of the parent acid and parent base that produced the salt.

| Parent acid | Parent base | Expected pH of salt solution |
| :-: | :-: | :-: |
| strong | strong | neutral (*e.g.* KI, NaCl) |
| strong | weak | acidic (*e.g.* $\ce{NH4Cl}, \ce{AlCl3})$ |
| weak | strong | basic (*e.g.* KCN, $\ce{NaNO2})$ |
| weak | weak |  depends on relative $K_a$ and $K_b$ |

Applying the rules to the three salts:

| Salt | Parent acid | Parent base | Prediction |
| :-: | :-: | :-: | :-: |
| $\ce{AlCl3}$ | HCl (strong) | $\ce{Al(OH)3}$(weak) | acidic |
| $\ce{CH3NH3Cl}$ | HCl (strong) | $\ce{CH3NH2}$ (weak) | acidic |
| KI | HI (strong) | KOH (strong) | neutral |

Therefore only $\ce{AlCl3}$ and $\ce{CH3NH3Cl}$ give acidic solutions; KI is neutral.
