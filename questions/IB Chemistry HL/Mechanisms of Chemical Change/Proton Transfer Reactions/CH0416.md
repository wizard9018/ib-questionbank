# CH0416

Which quantities are required to calculate the $\ce{pH}$ of a solution of a monoprotic weak acid?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- |:- |

    | I. | The $\textrm{p}K_a$ of the weak acid |

    | II. | The concentration of the solution |

    | III. | The value of ${K_w}$ |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

$K_a = \dfrac{{[\ce{H+}][\ce{A-}]}}{[\ce{HA}]} =\dfrac{{[\ce{H+}]^2}}{[\ce{HA}]}$

$K_a = 10^{-\textrm{p}K_a}$.

Substituting in $K_a$ and concentration of the weak acid (HA), allows the calculation of $\ce{[H+]}$ and therefore $\ce{pH}$.
