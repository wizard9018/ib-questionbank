# CH2220

An acid$\text{--}$base indicator behaves as shown below.

$\ce{\underset{\normalsize Colour A}{HIn} <=> H+ + \underset{\normalsize Colour B}{In-}}\qquad \text{p}K_a = 7.6$

Which statement is correct?

-   A. $\hspace{1em}$At $\text{pH}=7,$ the indicator is colourless

-   B. $\hspace{1em}$At $\text{pH}=7, [\ce{In-}] > [\ce{HIn}].$

-   C. $\hspace{1em}$At $\text{pH}=3,$ the indicator appears colour B

-   D. $\hspace{1em}$At $\text{pH}=8,$ the indicator appears colour B

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

When the pH is near the $\text{p}K_a$ of the indicator, there are nearly equal amounts of the protonated,  $\ce{HIn},$ and deprotonated, $\ce{In-},$ forms of the indicator. This is mathematically expressed using the Henderson$\text{--}$Hasselbalch equation:

$\text{pH} = \text{p}K_a + \log \dfrac{[\ce{In-}]}{[\ce{HIn}]}$

When the pH goes just above the $\text{p}K_a$, the color changes to the color of the protonated indicator. When the pH goes below the $\text{p}K_a$, the color changes to the color of the deprotonated indicator.

For this indicator with $\text{p}K_a = 7.6,$ when the $\text{pH} < \text{p}K_a$ the indicator will appear the protonated color A because $[\ce{HIn}] > [\ce{In-}].$ Similarly, when $\text{pH} > \text{p}K_a$, the indicator will appear the deprotonated color B because $[\ce{In-}] > [\ce{HIn}].$

We cannot guarantee that the indicator is colorless at a given pH as there is no information about the colors A and B.
