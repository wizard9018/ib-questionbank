# CH0908

The value of $K_a$ for an aqueous ammonium chloride $\ce{(NH4Cl)}$ solution is related to the concentrations of the dissolved acid and base species.

Which quantity must **increase** when a buffer solution is prepared from this aqueous solution?

-   A. $\hspace{1em}K_a$

-   B. $\hspace{1em}\ce{[NH4+]}$

-   C. $\hspace{1em}\ce{[NH3]}$

-   D. $\hspace{1em}\ce{[H3O+]}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The $K_a$ of an acid at a fixed temperature is constant.

For a weak acid such as $\ce{NH4Cl}$, the concentration of undissociated acid is large, so the concentration of the conjugate base is relatively small.

A buffer solution is prepared by increasing the concentration of the conjugate base, either by adding the base directly or reacting the acid with a strong base such as sodium hydroxide.

In an aqueous solution of $\ce{NH4Cl}$, the conjugate base is $\ce{NH3}$, so it is $\ce{[NH3]}$ that must increase. The added base reacts with $\ce{H3O+}$ ions in solution, lowering $\ce{[H3O+]}$ and raising the pH. The value of $\ce{[NH_4^{+}]}$ will increase if $\ce{NH3}$ is added directly since $\ce{NH3}$ and $\ce{H3O+}$ ions react to produce more $\ce{NH_4^{+}}$ ions. However, $\ce{[NH_4^{+}]}$ will decrease if an alternative base is used, as the increase in pH causes more $\ce{NH_4^{+}}$ ions to dissociate.
