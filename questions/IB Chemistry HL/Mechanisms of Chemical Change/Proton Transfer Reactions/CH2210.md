# CH2210

Which acid(s) fully dissociate(s) in water?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | $\ce{H2CO3}$ |
    | II. | $\ce{HI}$ |
    | III. | $\ce{CH3CH2COOH}$ |

-   A. $\hspace{1em}$None

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$II only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$

The student must understand that fully dissociated acids are strong. So, the student must identify HI as strong and $\ce{H2CO3}$ and carboxylic acids (those with the $\ce{-COOH}$ group) as weak acids.

This question is categorized as easy as the student must identify strong and weak acids.
