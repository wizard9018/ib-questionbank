# CH0877

**Maximum mark: 6**

0.517 g of unknown non-transition metal (X) reacts completely with 400 cm$^3$ of a 1.25 pH solution of $\ce{H2SO4}$ according to the following equation.

$\ce{2 X(s) + H2SO4(aq) -> H2(g) + X2SO4(aq)}$

1.  Using this balanced chemical equation, deduce the location of the metal X in the periodic table. [1 mark]

2.
    1.  Calculate the number of moles of $\ce{H2SO4}$. [3 marks]

    2.  Deduce the identity of the unknown metal X. [2 marks]

---

## 评分标准 / Mark scheme

1.  It is in group 1 of the periodic table. $\checkmark$

    $\underline{\textrm{Further Explanation:}}$\
    Since the formula of the salt produced is $\ce{X2SO4}$, the metal must form an $\ce{X^{1+}}$ ion which is typically found in group 1 metals.

2.
    1.  $\ce{[H+]} = 10^{-\text{pH}} = 10^{-1.25} = 0.0562\ \text{mol dm}^{-3}\,\checkmark$ \
        $C_{\ce{H2SO4}} = 0.5 \times 0.0562 = 0.0281\ \text{mol dm}^{-3}\,\checkmark$\
        $n_{\ce{H2SO4}} = 0.0281 \times 0.400 = 0.0112\ \text{mol}\,\checkmark$

        $\underline{\textrm{Further Explanation:}}$\
        First, we calculate the concentration of $\ce{H+}$ using the pH given in the question.

        Using this, we can find the concentration of $\ce{H2SO4}$ since it is a diprotic acid and $\ce{[H+]} = 2\ce{[H2SO4]}$.

        Finally, by using this concentration and the volume provided in the question, we can find the number of moles of $\ce{H2SO4}$.

    2.  $n{_\ce{X}} = 2 \times 0.0112 = 0.0225\,\text{mol}$
        **AND**
        $M_\ce{X} = \dfrac{m}{n} = \dfrac{0.517}{0.0225} = 22.98\,\text{g mol}^{-1}\,\checkmark$\
        Metal X is sodium. $\checkmark$

        $\underline{\textrm{Further Explanation:}}$\
        Using our answer to (i), we can find the number of moles of metal reacted. We can then find the molar mass of the metal using the mass provided in the question.

        Using the periodic table, we see that this is closest to the molar mass of sodium - a group 1 metal as expected.
