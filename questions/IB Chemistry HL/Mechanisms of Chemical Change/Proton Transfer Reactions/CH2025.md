# CH2025

Consider the titration curve below at 298 K.

![CH2025a](images/CH2025a.png)

Which statement is correct?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | The endpoint can be detected with methyl orange $(\text{p}K_a=3.7)$ |
    | II. | The $\text{p}K_b$ is approximately 4. |
    | III. | The equivalence point occurs at $20\text{ cm}^3$ of added titrant. |

-   A. $\hspace{1em}$I, II and III

-   B. $\hspace{1em}$II only

-   C. $\hspace{1em}$I and III only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

The student must be able to interpret the titration curve as a titration of a weak base with a strong acid due to the shape of the curve.

![CH2025b](images/CH2025b.png)

The titration curve represents the titration of a weak base with a strong acid, as indicated by its characteristic shape. The equivalence point occurs when the moles of acid added are stoichiometrically equal to the moles of base present. This point is identified graphically as the steepest change in pH, which occurs at $20\text{ cm}^3$ of added acid; Statement III is correct.

For a weak base$\text{--}$strong acid titration, $\text{pH} = \text{p}K_a$ at the half$\text{--}$equivalence point according to the Henderson$\text{--}$Hasselbalch equation. Since the pH at half$\text{--}$equivalence is 10, the $\text{p}K_a = 10$ for the conjugate acid of the weak base. Using the relationship $\text{p}K_a + \text{p}K_b = 14$ at 298 K, we find $\text{p}K_b = 4;$ Statement II is correct.

The endpoint of a titration is the volume at which the indicator changes color. To ensure accurate detection, the $\text{p}K_a$ of the indicator should be close to the pH at the equivalence point. Since the equivalence point occurs at pH 6, methyl orange $(\text{p}K_a = 3.7)$ is not a suitable choice, as its color change would occur after equivalence; Statement I incorrect.

This question is categorized as difficult because it requires students to analyze multiple aspects of the titration curve, including determining the equivalence point, using $\text{p}K_a$ to calculate $\text{p}K_b,$ and selecting an appropriate indicator.
