# CH2214

Sodium hydrogen carbonate reacts with sulfuric acid. Which product is formed in this reaction?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | $\ce{H2(g)}$ |
    | II. | $\ce{CO2(g)}$ |
    | III. | $\ce{Na2SO4(aq)}$ |

-   A. $\hspace{1em}$I, II and III

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$II and III only

-   D. $\hspace{1em}$III only

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$

The student must recall that carbonates react with acid to produce salt, water and carbon dioxide. The reaction between sodium hydrogen carbonate and sulfuric acid is given below.

$\ce{2 NaHCO3(s) + H2SO4(aq) -> Na2SO4(aq) + 2 H2O(l) + 2 CO2(g)}$

This question is categorized as a medium as the student must understand the chemical reaction.
