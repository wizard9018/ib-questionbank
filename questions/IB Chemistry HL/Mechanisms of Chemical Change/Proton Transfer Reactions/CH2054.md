# CH2054

Which reaction can be characterized as a Bronsted$\text{--}$Lowry acid$\text{--}$base reaction?

-   A. $\hspace{1em}\ce{CH4(g) + 2 O2(g) -> CO2(g) + 2 H2O(g)}$

-   B. $\hspace{1em}\ce{BaCl2(aq) + Na2SO4(aq) -> BaSO4(s) + 2 NaCl(aq)}$

-   C. $\hspace{1em}\ce{2 Al(s) + 3 Cl2(g) -> AlCl3(aq)}$

-   D. $\hspace{1em}\ce{NH3(l) + HCl(aq) -> NH4Cl(aq)}$

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$

A Bronsted$\text{--}$Lowry acid$\text{--}$base reaction is characterized by an acid and base on the reactant side where the acid donates a proton to the base.

The reactions in this question are characterized as follows:

| Reaction | Type |
| :-- | :-- |
| $\ce{CH4(g) + 2 O2(g) -> CO2(g) + 2 H2O(g)}$ | combustion |
| $\ce{BaCl2(aq) + Na2SO4(aq) -> BaSO4(s) + 2 NaCl(aq)}$ | double replacement |
| $\ce{2 Al(s) + 3 Cl2(g) -> AlCl3(aq)} $| synthesis/redox reaction |
| $\ce{NH3(l) + HCl(aq) -> NH4Cl(aq)}$ | Bronsted$\text{--}$Lowry $\\$ acid$\text{--}$base reaction |

Ammonia receives the proton from hydrochloric acid, so the formation of ammonium chloride is considered a Bronsted$\text{--}$Lowry acid$\text{--}$base reaction.
