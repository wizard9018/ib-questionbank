# CH0228

What is the $\ce{pH}$ of a 0.00100 mol dm$^{-3}$ aqueous solution of $\ce{KOH}$ at 298 K given that it ionizes completely?

- A.$\hspace{1em}$3

- B.$\hspace{1em}$0.001

- C.$\hspace{1em}$11

- D.$\hspace{1em}$13

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$\
$\ce{KOH}$ is a strong base and ionises completely, so $[\ce{OH^{-}}] = 0.00100 \textrm{\ mol dm}^{-3}.$

Calculate pOH:

$\textrm{pOH} = -\log(0.00100) = 3$

At $298 \textrm{\ K},$ pH $+$ pOH $= 14,$ so:

$\textrm{pH} = 14 - 3 = 11$

Alternatively, calculate $[\ce{H^{+}}]$ directly using $K_w\textrm{:}$

$[\ce{H^{+}}] = \dfrac{K_w}{[\ce{OH^{-}}]} = \dfrac{1.00 \times 10^{-14}}{0.00100} = 1.00 \times 10^{-11} \textrm{\ mol dm}^{-3}$

$\textrm{pH} = -\log(1.00 \times 10^{-11}) = 11$
