# CH1177

Which statement(s) is (are) correct about the titration reaction that occurs when calcium hydroxide is titrated with nitric acid?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Calcium nitride is formed  |
  | II. | The reaction is exothermic |
  | III. | Carbon dioxide is formed as the pH decreases |

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$I and II only

- C. $\hspace{1em}$I, II and III

- D. $\hspace{1em}$II only

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

The reaction that occurs in shown below:

$\ce{Ca(OH)2 + 2 HNO3 -> Ca(NO3)2 + 2 H2O}$

The salt formed is calcium nitrate (not calcium nitride, $\ce{Ca3N2}).$ Statement I is incorrect.

This chemical reaction is a neutralization. Neutralization reactions are always exothermic reactions as water is formed, and the bond formation releases energy to the surroundings. Statement II is correct.

Statement III is incorrect. Carbon dioxide is released if carbonates or hydrogen carbonates react with acids. Calcium nitrate is not a carbonate/hydrogen carbonate. However, it is correct that the pH decreases as titration occurs (as calcium hydroxide is basic and acid is added). Nevertheless, the statement as a whole is incorrect.

This question is categorized as hard as students must figure out the formulae, state the neutralization reaction, deduce the salt formed, and understand the chemical reactions of acids.
