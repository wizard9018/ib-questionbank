# CH0410

What is the order of increasing acid strength based on the ${\textrm{p}K_a}$ values below?

- :::tableoptions

  Acid| p***K***$\mathbf{_a}$

  |:-:|:-:|

  |$\ce{CCl3COOH}$|0.66

  $\ce{HCOOH}$|3.75

  $\ce{C6H5OH}$|9.99

  $\ce{CH3OH}$|15.5

- A. $\hspace{1em}$ $\ce{CCl3COOH} < \ce{HCOOH} < \ce{C6H5OH} < \ce{CH3OH}$

- B. $\hspace{1em}$ $\ce{C6H5OH} < \ce{HCOOH} < \ce{CCl3COOH} < \ce{CH3OH}$

- C. $\hspace{1em}$ $\ce{CH3OH} < \ce{CCl3COOH} < \ce{HCOOH} < \ce{C6H5OH}$

- D. $\hspace{1em}$ $\ce{CH3OH} < \ce{C6H5OH} < \ce{HCOOH} < \ce{CCl3COOH}$

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The lower the value of $\textrm{p}K_a$, the stronger the acid.
