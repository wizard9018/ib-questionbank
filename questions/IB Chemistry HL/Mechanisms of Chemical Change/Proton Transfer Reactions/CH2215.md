# CH2215

Zinc hydroxide dissolves in excess NaOH(aq) according to the reaction:

$\ce{Zn(OH)2(s) + 2 NaOH(aq) -> Na2Zn(OH)4(aq)}$

Which statement is correct about zinc hydroxide?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | It is amphoteric. |
    | II. | It is an alkali. |
    | III. | It is acting as an acid in the equation above. |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$II only

-   C. $\hspace{1em}$I and III only

-   D. $\hspace{1em}$I and II only

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$

Zinc hydroxide is amphoteric because it reacts with both acids and bases.

With strong acids, it behaves as a Bronsted$\text{--}$Lowry base:

$\ce{Zn(OH)2(s) + 2 HCl(aq) -> ZnCl2(aq) + 2 H2O(l)}$

With excess hydroxide, it behaves as a Lewis acid, accepting $\ce{OH-}$ to form $\ce{[Zn(OH)4]^2-},$ as shown above. Statements I and III are correct.

An alkali is a base that is readily soluble in water and produces a high concentration of hydroxide ions. Solid $\ce{Zn(OH)2}$ is only sparingly soluble, so it is not classified as an alkali. Statement II is incorrect.
