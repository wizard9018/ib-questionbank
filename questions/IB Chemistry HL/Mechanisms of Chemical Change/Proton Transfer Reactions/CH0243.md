# CH0243

Concentrated sulfuric acid behaves as a strong acid when it reacts with water:

$\begin{aligned}
\ce{H2SO4(aq) &-> H+(aq) + HSO4-(aq)} \\
\ce{HSO^-4(aq) &<=> H+(aq) + SO4^2-(aq)}
\end{aligned}$

Which of the following is (are) true for 1.0 mol dm$^{-3}$ of sulfuric acid?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{[H+]}$ is high |
  | II. | $\ce{[SO4^2-]}$ is high |
  | III. | $\ce{[SO4^2-] = [HSO4-]}$ |

- A.$\hspace{1em}$I, II and III

- B.$\hspace{1em}$I and II only

- C.$\hspace{1em}$I and III only

- D.$\hspace{1em}$I only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$\ce{H2SO4}$ is a strong acid and fully ionizes its first proton leading to a high $\ce{H+}$ concentration.

$\ce{HSO4-}$ is a weak acid that only partially dissociates to produce $\ce{SO4^2-}.$ $\ce{[SO4^2-]}$ is, therefore, low and not equal to $\ce{HSO^-_4}$.
