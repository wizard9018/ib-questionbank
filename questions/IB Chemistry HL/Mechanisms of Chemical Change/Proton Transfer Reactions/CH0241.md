# CH0241

Which of the following acids dissociates completely in water?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{HCl}$ |
  | II. | $\ce{H2CO3}$ |
  | III. | $\ce{HNO3}$ |

- A.$\hspace{1em}$I only

- B.$\hspace{1em}$I and III only

- C.$\hspace{1em}$II and III only

- D.$\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$\ce{HCl}$ and $\ce{HNO3}$ are examples of strong acids. $\ce{H2CO3}$ (carbonic acid) is a weak acid that dissociates partially in water.
