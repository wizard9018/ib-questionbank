# CH2204

Which of these compounds  is amphoteric but not amphiprotic?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | $\ce{Al2O3}$ |
    | II. | $\ce{OH-}$ |
    | III. | $\ce{H2PO4-}$ |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$II only

-   C. $\hspace{1em}$I and III only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

**答案：A**

$\textrm{\underline{Explanation: }}$\
Amphiprotic species can accept and donate a proton, so they must contain at least one transferable hydrogen.

The hydroxide ion demonstrates this by accepting a proton to form water,

$\ce{OH- + H+ -> H2O}$

and, under strongly basic conditions, donating its proton to give oxide,

$\ce{OH- -> O^2- + H+}$

Likewise, dihydrogen phosphate can gain a proton to become phosphoric acid,

$\ce{H2PO4- + H+ -> H3PO4}$

or lose a proton to become hydrogen phosphate,

$\ce{H2PO4- -> HPO4^2- + H+}$

By contrast, amphoteric compounds react with both acids and bases, and a substance can do this even if it has no protons.

Aluminium oxide fits that description: with a strong acid it forms hydrated aluminium ions,

$\ce{Al2O3 + 6 HCl -> 2 Al^3+ + 6 Cl- + 3 H2O}$

while with a strong base it forms aluminate,

$\ce{Al2O3 + 2 NaOH + 3 H2O -> 2 Na[Al(OH)4]}$

Because $\ce{Al2O3}$ lacks any hydrogen, it cannot donate or accept a proton, so it is amphoteric but not amphiprotic.

This question is categorized as a medium as the student must distinguish between amphiprotic and amphoteric.
