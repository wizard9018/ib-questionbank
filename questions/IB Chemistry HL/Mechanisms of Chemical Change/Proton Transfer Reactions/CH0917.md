## 评分标准 / Mark scheme

1.
    1.  $K_a = \dfrac{\ce{[H+][ClO-]}}{\ce{[HOCl]}}$ **OR** $K_a = \dfrac{\ce{[H3O+][ClO-]}}{\ce{[HOCl]}}$ $\checkmark$

        *Accept [chlorite], $\ce{[ClO]}$ or similar in place of $\ce{[ClO-]}$;\
        Accept $\ce{[HClO]}$, [hypochlorous acid] or similar in place of $\ce{[HOCl]}$*

        $\underline{\textrm{Further explanation}}$:

        The acid dissociation constant, $K_a$, indicates how much $\ce{HOCl}$ dissociates into $\ce{ClO-}$ and $\ce{H+}$ ions. The higher the value of $K_a$, the further the position of equilibrium is to the right and the more dissociation takes place.

        $K_a$ is calculated by multiplying the concentrations of the products, $\ce{ClO-}$ and $\ce{H+}$, and dividing by the concentration of $\ce{HOCl}$ remaining.

    2.  $\ce{[H+] = \sqrt{(K_a\times [\ce{HOCl}]}}$ $\checkmark$

        $\ce{[H+] = 5.6(2)\times 10^{-5}\,\text{mol dm}^{-3}}\,\checkmark$

        pH $= -\log_{10}\ce{[H+]} = 4.25$ **OR** $4.3$ $\checkmark$

        *Accept concentrations stated without units; \
        Award M1 if correct values are included in place of algebraic terms; \
        Award M2 if $\ce{[H+]}$ is used in the calculation of pH but not explicitly stated; \
        Award M2 and M3 if the correct value of pH is calculated but the value of $\ce{[H+]}$ is not shown; \
        Award M3 but **not** M2 if method is correct but pH is incorrect due to a follow-through error.*

        $\underline{\textrm{Further explanation}}$:

        Since $\ce{HOCl}$ dissociates to form equal numbers of $\ce{H+}$ and $\ce{ClO-}$ ions, $\ce{[ClO-] = [H+]}$ and $K_a = \dfrac{\ce{[H+]^2}}{\ce{[HOCl]}}$.

        The expression for $K_a$ can then be rearranged to give $\ce{[H+]} = \sqrt{(K_a\times [\ce{HOCl}])}$.

        Since $\ce{[HOCl]}$ is a weak acid, only a small percentage of the $\ce{HOCl}$ molecules dissociate. Thus, the concentration of $\ce{HOCl}$ at equilibrium is approximately equal to the initial concentration, allowing $\ce{[HOCl]}$ to be set to 0.100 mol dm$^{-3}$.

     Finally, the pH value is calculated using the equation pH $= -\log_{10}\ce{[H+]}$.

2.
    1.  Buffer (region) $\checkmark$

        $\underline{\textrm{Further explanation}}$:

        The buffer region is the part of the pH curve in which the change in pH is relatively gradual. It arises when one of the reactants, in this case the acid, is in excess.

    2.  The solution is a mixture of a weak acid and its salt / conjugate base / anion **OR** only some of the acid / $\ce{HOCl}$ has reacted to form its salt / conjugate base / anion $\checkmark$

        Added acid can react with the $\ce{ClO-}$ / anion / conjugate base to counteract the change (in pH) **OR** added base can react with the $\ce{HOCl}$ / (undissociated) acid to counteract the change (in pH) $\checkmark$

        *Award M2 for a reaction equation or diagram showing the change in position of equilibrium when acid or base is added; \
        Do **not** award M1 unless the solution is stated to contain both the acid and its salt; \
        Do **not** award M2 unless a description is given for the effect of the reaction on the pH change.*

        $\underline{\textrm{Further explanation}}$:

        A buffer solution is formed when a weak acid reacts with less than one equivalent of base to produce a salt. Alternatively, the salt of the acid can be added directly to the solution.

        Since the buffer solution contains a large concentration of both the acid and its conjugate base, further additions of acid or base have a relatively small effect on the pH.

        If a small amount of base is added, it can react with the remaining acid rather than the $\ce{H+}$ ions, so $\ce{[H+]}$ remains relatively constant. Likewise, added acid can react with the anion of the salt to regenerate the acid, rather than increasing the value of $\ce{[H+]}$.
