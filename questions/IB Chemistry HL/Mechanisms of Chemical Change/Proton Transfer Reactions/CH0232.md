# CH0232

Which of the three oxides of period 3 below will cause a change in the pH of the solution when they react with water?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $\ce{Na2O}$ |
  | II. | $\ce{SiO2}$ |
  | III. | $\ce{P4O10}$ |

- A.$\hspace{1em}$I, II, and III

- B.$\hspace{1em}$I and II only

- C.$\hspace{1em}$I and III only

- D.$\hspace{1em}$I only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Metal oxides produce basic solutions when dissolved in water. Non-metal oxides produce acidic solutions when dissolved in water.

Silicon dioxide does not react with water, but reacts with concentrated alkalis to form silicates:

$\ce{SiO2(s) + 2OH–(aq) → SiO3^{2–}(aq) + H2O(l)}$
