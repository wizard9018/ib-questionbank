# CH1047

Consider the $\textrm{p}K_b$ values informed below.

| Name | $\qquad \mathbf{pK_b} \qquad $ |
| :-: | :-: |
| methylamine | 3.34 |
| ethylamine | 3.35 |
| dimethylamine |3.27 |

What is the correct order of increasing basic strength?

-   A.$\hspace{1em}$ethylamine < methylamine < dimethylamine

-   B.$\hspace{1em}$dimethylamine < methylamine < ethylamine

-   C.$\hspace{1em}$ethylamine < dimethylamine < methylamine

-   D.$\hspace{1em}$methylamine < dimethylamine < ethylamine

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$pK_b = -\log K_b$ or $K_b = 10^{-pK_b}$

The smaller the value of $pK_b$, the greater the magnitude of $K_b$. $K_b$ is related to the strength of the base as it is a measure of the extent of the dissociation of the base.

Ethylamine has the greatest $pK_b$ and the smallest $K_b$, meaning it is the weakest base. In contrast, dimethylamine is the strongest base because it has the smallest $pK_b$.

This question is categorized as hard as students must understand the relationship between $pK_b$ and $K_b$ and use $K_b$ as a criterion for strength.
