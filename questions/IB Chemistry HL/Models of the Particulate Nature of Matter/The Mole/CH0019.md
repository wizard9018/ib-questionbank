# CH0019

Which compound has the largest molar mass?

- A.$\hspace{1em}\ce{FeSO4}$

- B.$\hspace{1em}\ce{K2Cr2O7}$

- C.$\hspace{1em}\ce{KMnO4}$

- D.$\hspace{1em}\ce{(NH4)3PO4}$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$: \
The molar masses can be determined from the periodic table:

$M(\ce{FeSO4}) = 55.85 + 32.07 + 4(16.00) = 151.92 \textrm{\ g mol}^{-1}$

$M(\ce{K2Cr2O7}) = 2(39.10) + 2(52.00) + 7(16.00) = 294.20 \text{\ g mol}^{-1}$

$M(\ce{KMnO4}) = 39.10 + 54.94 + 4(16.00) = 158.04 \textrm{\ g mol}^{-1}$

$M(\ce{(NH4)3PO4}) = 3(14.01 + 4(1.01)) + 30.97+4(16.00) = 149.04 \textrm{\ g mol}^{-1}$

Potassium dichroamate has the highest molar mass.
