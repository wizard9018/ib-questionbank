# CH2432

Which variable is incorrectly measured?

-   A.$\hspace{1.em}$Pressure $= 101.3\textrm{\ kPa}$

-   B.$\hspace{1.em}$Amount $= 1.532\textrm{\ g}$

-   C.$\hspace{1.em}$Density $= 0.894\textrm{\ kg dm}^{-3}$

-   D.$\hspace{1.em}$Temperature $= 25.5\textrm{\ }{}^\circ\textrm{C}$

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
Amount is defined as the number of moles of a substance and has the SI unit mol. A measurement of $1.532\textrm{ g}$ is a mass, not an amount. The correct way to express an amount would be, for example, $0.0255\textrm{ mol.}$

Pressure in kPa is a standard SI$-$derived unit. Density in $\textrm{kg dm}^{-3}$ is equivalent to $\textrm{g cm}^{-3}$ and is a valid unit for density. Temperature in $^\circ\textrm{C}$ is a standard laboratory unit.
