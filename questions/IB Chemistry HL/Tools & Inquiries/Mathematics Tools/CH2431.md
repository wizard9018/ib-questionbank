# CH2431

A student carries out a titration and records the following titres.

| Trial | Titre / cm$^3$ |
|:-:|:-:|
| 1 (rough) | 25.50 |
| 2 | 24.80 |
| 3 | 24.75 |
| 4 | 25.40 |
| 5 | 24.85 |

What value should be reported for the titre?

-   A.$\hspace{1.em}25.06 \pm 0.38\textrm{ cm}^3$

-   B.$\hspace{1.em}24.80 \pm 0.05\textrm{ cm}^3$

-   C.$\hspace{1.em}25.06 \pm 0.05\textrm{ cm}^3$

-   D.$\hspace{1.em}24.95 \pm 0.33\textrm{ cm}^3$

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
In a titration, only concordant titres are used to calculate the mean. Concordant titres are those that agree within $\pm 0.10\textrm{ cm}^3$ of each other. The rough titre (Trial 1) is always discarded because it is used only to find the approximate end point.

Trials 2, 3, and 5 $(24.80,$ $24.75,$ and $24.85\textrm{ cm}^3)$ are concordant: they all fall within a range of $0.10\textrm{ cm}^3.$ Trial 4 $(25.40\textrm{ cm}^3)$ is not concordant with these three and is excluded.

The mean of the concordant titres is:

$\bar{V} = \dfrac{(24.80 + 24.75 + 24.85)\textrm{\ cm}^3}{3} = \dfrac{74.40\textrm{\ cm}^3}{3} = 24.80\textrm{\ cm}^3$

The uncertainty is estimated by halving the range of the concordant titres:

$\textrm{uncertainty} = \dfrac{(24.85 - 24.75)\textrm{\ cm}^3}{2} = 0.05\textrm{\ cm}^3$

The reported titre is therefore $24.80 \pm 0.05\textrm{ cm}^3.$
