# CH1561

Which of these measurements has the smallest percentage uncertainty?

-   A. $\hspace{1em}2.33\pm 0.01\text{\ g}$

-   B. $\hspace{1em}100.0\pm 0.1\text{\ cm}^3$

-   C. $\hspace{1em}25.0\pm 0.5^\circ\text{C}$

-   D. $\hspace{1em}10.0\pm 0.1\text{\ cm}$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:

The student must be able to estimate the percentage uncertainty and compare.

$\% \text{\ Uncertainty} = \dfrac{\text{absolute uncertainty}}{\text{measurement}}\times 100\%$

| % Uncertainty|

|:-:|

$\dfrac{0.01 \textrm{\ g}}{2.33 \textrm{\ g}} \times 100\%  = 0.4\%$|

|

$\dfrac{0.1 \textrm{\ cm}^3}{100.0 \textrm{\ cm}^3} \times 100\% = 0.1\%$

|

$\dfrac{0.5 ^\circ\textrm{C}}{25.0 ^\circ\textrm{C}} \times 100\% = 2\%$

|

$\dfrac{0.1 \textrm{\ cm}}{10.0 \textrm{\ cm}} \times 100\% = 1\%$

This question is categorized as easy as the student must estimate the percentage uncertainties and compare.

$\underline{\textrm{Further Explanation}}$:

It could be easier to make the uncertainties the same in each case, 0.1 seems convenient.

||||

|:-:|:-:|:-:|

$2.33 ± 0.01 \textrm{\ g} $|$\xrightarrow{\times 10}$| $23.3 ± 0.1$|

|

$100.0 ± 0.1 \textrm{\ cm}^3$|$\xrightarrow{\times 1}$|$100.0 ± 0.1$

|

$25.0 ± 0.5 ^\circ\textrm{C}$|$ \xrightarrow{\div 5} $|$5.0 ± 0.1$

|

$10.0 ± 0.1 \textrm{\ cm}$|$\xrightarrow{\times 1}$|$ 10.0 ± 0.1$

The smallest percentage uncertainty will be for the largest measured value.
