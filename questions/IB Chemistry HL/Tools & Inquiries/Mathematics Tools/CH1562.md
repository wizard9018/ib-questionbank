# CH1562

An experiment was performed to determine absolute zero. The volume of a gas was measured at different temperatures, and the results are shown below.

![CH1562_Image](images/CH1562_Image.png)

Which statement is correct?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | The experimental absolute zero is $-280\text{\ K}.$ |

    | II. | The percentage error can be calculated as $\bigg \vert \dfrac{280-273.15}{273.15}\bigg \vert \times 100\%$ |

    | III. | The volume can be negative at extremely low temperatures. |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I, II and III

-   C. $\hspace{1em}$I and III only

-   D. $\hspace{1em}$II only

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

The student must understand that the absolute zero is $-273.15\text{\ K}$ or $0\text{\ K}$ in the absolute scale. The estimation from the experiment suggests the absolute zero is $-280^\circ\text{C}.$ Statement I is incorrect as the scale is $^\circ\text{C}.$

The percentage error allows us to evaluate the inaccuracy of this result.

$\% \text{\ error} = \left| \dfrac{\text{experimental value} - \text{literature value}}{\text{literature value}} \right| \times 100 \% = \left|\dfrac{280-273.15}{273.15}\right| \times 100\%$

Statement II is correct.

Finally, absolute zero is a theoretical value that can not be experimentally achieved. It is the lowest temperature possible. A gas can never present a negative volume. Its theoretical volume at 0 K is zero (although this is just a theoretical magnitude).

This question is categorized as a medium as the student must evaluate the given graph, apply his knowledge about the absolute zero and understand how to determine the percentage error.
