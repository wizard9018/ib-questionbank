# CH2428

Which experimental strategy increases the systematic error in a titration?

-   A.$\hspace{1.em}$Performing only one trial instead of multiple replicates

-   B.$\hspace{1.em}$Consistently reading the meniscus of the burette from above eye level

-   C.$\hspace{1.em}$Excluding outliers when calculating the mean titre

-   D.$\hspace{1.em}$Overshooting the end point in a preliminary rough titration and discarding this value

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
A systematic error is one that shifts every measurement in the same direction by roughly the same amount. It cannot be reduced by repeating the experiment.

Reading a burette from above eye level introduces a parallax error. The observer consistently reads the meniscus at a position that is slightly too low on the scale, so every recorded volume is shifted in the same direction. Because the error is the same sign and similar magnitude each time, it is systematic.

Performing only one trial reduces precision because there is no way to identify scatter in the data, but it does not introduce a bias in a particular direction. This is a limitation related to random error, not systematic error.

Excluding outliers is accepted practice when sufficient concordant data has been collected. Removing a value that deviates significantly from the other titres does not introduce a bias in one direction, so it does not increase systematic error.

Overshooting in a rough titration is expected procedure. The rough titre is used only to establish an approximate end-point volume and is always excluded from the final mean, so it has no effect on the reported result.
