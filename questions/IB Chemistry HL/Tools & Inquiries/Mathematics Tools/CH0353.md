# CH0353

Determine the type of variable and correct axis for $\Delta H$ in a graph to show how $\Delta H$ is affected by the length of the carbon chain.

- :::tableoptions{col1="hide"}
  | | $\quad$Type of Variable $\quad$ | $\quad$Axis $\quad$ |
  | :-: | :-: | :-: |
  | A.$\hspace{1em}$ | Independent | $x$ |
  | B.$\hspace{1em}$ | Independent | $y$ |
  | C.$\hspace{1em}$ | Dependent | $x$ |
  | D.$\hspace{1em}$ | Dependent | $y$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

“Affected by” means that $\Delta H$ is dependent on the length of the carbon chain. The $y$-axis is labelled with the dependent variable.
