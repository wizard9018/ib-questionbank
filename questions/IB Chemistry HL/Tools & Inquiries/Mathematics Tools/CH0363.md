# CH0363

**Maximum mark: 7**

The feasibility of a reaction proceeding spontaneously can be predicted using the following equation:\

$\Delta G = -T\Delta S + \Delta H$

Where $\Delta G$ is the change in Gibb's free energy, $\Delta S$ is the change in entropy, and $\Delta H$ is the change in enthalpy.

![11.2-CH0363](images/CH0363.png)

1. When $\Delta G < 0$, a reaction can be described as spontaneous. Use the graph above to deduce the lowest temperature at which the reaction becomes spontaneous. [1 mark]

2. Calculate the gradient of the line and state its units. [2 marks]

3. Use your answer to part (b) to deduce the value and correct units for $\Delta S$. [1 mark]

4. Use the graph to determine the value for $\Delta G$ when the temperature is raised to $675$ K. [1 mark]

5. Calculate a value for $y$-intercept and state the correct units. [2 marks]
