# CH0619

A voltmeter reading is recorded as 100.0 V $\pm\, 2\%$. Which of the following could be the actual value?

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | 98.0 V |

    | II. | 97.2 V |

    | III. | 101.3 V |

-   A. $\hspace{1em}$I, II, and III

-   B. $\hspace{1em}$I and III only

-   C. $\hspace{1em}$I and II only

-   D. $\hspace{1em}$II and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The highest possible value is 102.0 V while the lowest is 98.0 V. Any values within this range are possible voltages.
