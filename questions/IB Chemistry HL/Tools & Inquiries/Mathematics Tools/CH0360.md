# CH0360

The half$-$life of a second order reaction can be expressed according to the equation below.

$t_{\frac12} = \dfrac{1}{k[\text{A}]_0}$

Where $t_{\frac12}$ = half$-$life, $[\textrm{A}]_0$ is the initial concentration of reactant A, and $k$ is a constant.\
Which two variables plotted against each other would produce a straight line?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $t_{\frac12}$ *vs.* $\dfrac{1}{k}$ |
  | II. | $t_{\frac12}$ *vs.* $[A]_0$ |
  | III. | $t_{\frac12}$ *vs.* $\dfrac{1}{[A]_0}$ |

- A. $\hspace{1em}$I and II only

- B. $\hspace{1em}$I and III only

- C. $\hspace{1em}$II only

- D. $\hspace{1em}$I only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The equation of a straight line is $y = mx + c,$ where $m$ is the slope and $c$ is the $y-$intercept.

For the equation above, $y = t_{\frac12}$ and $x$ could equal $\dfrac{1}{k}$ or $\dfrac{1}{[\textrm{A}]_0}$ and satisfy the straight line equation $(c=0)$.
