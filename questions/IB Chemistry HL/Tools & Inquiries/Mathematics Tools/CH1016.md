# CH1016

A student conducted an experiment to find the enthalpy change of a chemical reaction, and obtained $-56.0 \textrm{\ kJ mol}^{-1}.$ The literature value is $-98.0 \textrm{\ kJ mol}^{-1}.$

What is the percentage error?

-   A.$\hspace{1em}\dfrac{98.0 - 56.0}{56.0} \times 100\%$

-   B.$\hspace{1em}\dfrac{98.0 - 56.0}{98.0} \times 100\%$

-   C.$\hspace{1em}\dfrac{98.0}{56.0} \times 100\%$

-   D.$\hspace{1em}\dfrac{56.0}{98.0} \times 100\%$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:

$\textrm{Percentage\ error} = \left| \dfrac{\textrm{literature\ value} - \textrm{experimental\ value}}{\textrm{literature\ value}} \right| \times 100\%$

$\textrm{Percentage\ error} = \left| \dfrac{(-98.0)-(-56.0)}{(-98.0)} \right| \times 100\% = \dfrac{98.0 - 56.0}{98.0} \times 100\%$

This question is categorized as medium difficulty as the student must formulate the calculation for the percentage error from given data.
