# CH0356

Which of the below features must be included in a sketched graph?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  |I. | Labelled axes |
  |II. | Scaled axes |
  |III. | Plotted points |

- A. $\hspace{1em}$I and II only

- B. $\hspace{1em}$I and III only

- C. $\hspace{1em}$II only

- D. $\hspace{1em}$I only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

A sketched graph is used to show qualitative relationships between variables. Scaled axes and plotted points are required for drawn graphs only.
