# CH0805

The relationship between energy, $E$, and wavelength, $\lambda$, is shown according to the equation below.

$E = \dfrac{hc}{\lambda}$

![CH0805](images/CH0805.png)

Which of the below statements are correct for the graph below representing $E = \dfrac{hc}{\lambda}$?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | Energy and wavelength are directly proportional. |
    | II. | The units for the gradient are J m$^{-1}.$ |
    | III. | The $y-$intercept has the units J. |

-   A.$\hspace{1em}$I and III only

-   B.$\hspace{1em}$II and III only

-   C.$\hspace{1em}$III only

-   D.$\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

Energy and wavelength are inversely proportional. Energy is directly proportional to $\dfrac{1}{\lambda}$.

The units for the gradient (slope) are $\dfrac{Units \ for \ y}{Units \ for \ x} = \dfrac{\text{J}}{\text{m}^{-1}} = \text{J m}$.

The y-intercept has the same units as the y-axis which is J.
