# CH0621

A reaction is known to take 128.55 s to be completed. Student A uses a digital stopwatch to measure the reaction time and identified the reaction time to be 122.35 s. Student B uses an analog wristwatch and the same reaction was observed to be completed in 128.6 s. Which of the following statement is true and why? 

- A.$\hspace{1em}$Student B's measurement is more precise because it is closer to the true reaction time

- B.$\hspace{1em}$Student B's measurement is more precise because an analog watch has fewer sources of error

- C.$\hspace{1em}$Student A's measurement is more precise because a digital stopwatch is more reliable than an analog wristwatch

- D.$\hspace{1em}$Student A's measurement is more precise because a digital stopwatch can measure to 0.01 s

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$\

Precision, in this context, is about the number of significant figures. A digital stopwatch records more to 0.01 s and, thus, is more precise.
