# CH2425

A volumetric pipette reading is recorded as $10.00 \pm 0.02\textrm{\ cm}^3.$ Which statement is correct?

-   I.$\hspace{1em}$The actual reading could be $10.97\textrm{\ cm}^3.$
-   II.$\hspace{0.7em}$The percentage uncertainty is $0.2\%.$
-   III.$\hspace{0.4em}$A volumetric pipette delivers a more accurate volume than a graduated pipette.

-   A.$\hspace{1.em}$I, II and III

-   B.$\hspace{1.em}$II and III only

-   C.$\hspace{1.em}$II only

-   D.$\hspace{1.em}$III only

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
The absolute uncertainty of $\pm 0.02\textrm{\ cm}^3$ defines the range within which the true value is expected to lie. For a recorded value of $10.00\textrm{\ cm}^3,$ this range is $9.98\textrm{\ cm}^3$ to $10.02\textrm{\ cm}^3.$ A value of $10.97\textrm{\ cm}^3$ falls well outside this range, so Statement I is incorrect.

The percentage uncertainty is calculated from the absolute uncertainty and the measured value:

$\%\textrm{\ uncertainty} = \dfrac{0.02\textrm{\ cm}^3}{10.00\textrm{\ cm}^3} \times 100 = 0.2\%$

Statement II is correct.

A volumetric pipette is designed to deliver one fixed volume, calibrated to a single mark. Because it is built for that single volume, its manufacturing tolerance is very small. A graduated pipette can measure variable volumes but requires two scale readings (start and end), each introducing uncertainty. The cumulative uncertainty of a graduated pipette is therefore larger, making it less accurate for delivering a known volume. Statement III is correct.
