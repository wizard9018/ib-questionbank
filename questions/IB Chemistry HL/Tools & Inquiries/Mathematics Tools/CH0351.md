# CH0351

The ideal gas equation allows pressure to be calculated according to the equation,

$P = \dfrac{nRT}{V}$

This allows a straight line to be drawn for the effect of $\dfrac{1}{V}$ on $P$.

![11.2CH0351](images/CH0351.png)

For the sketched graph above, which components of the equation $P = \dfrac{nRT}{V}$, relate to the gradient and $y$-intercept of the straight line?

- :::tableoptions{col1="hide"}
 | | $\quad$ Gradient $\quad$ | $\quad$ ***y*** - intercept $\quad$ |
 | :-: | :-: | :-: |
 | A.$\hspace{1em}$ | $nRT$ | $V$ |
 | B.$\hspace{1em}$ | $nRT$ | 0 |
 | C.$\hspace{1em}$ | $\dfrac{1}{V}$ | $P$ |
 | D.$\hspace{1em}$ | $\dfrac{nRT}{V}$ | $P$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The equation of a straight line is $y = mx + c$, where $m$ is the slope and $c$ is the $y$-intercept.

For the graph above, $y = P$ and $x = \dfrac{1}{V}.$ As a result, m is $x$'s coefficient ($nRT$), and the line intercepts the $y$-axis at $c=0$.
