# CH1081

The graph below represents the variation in temperature of a reaction over time. Which of the following statement(s) is (are) true about it?

![CH1081_Image1](images/CH1081_Image1.png)

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | The reactants have higher enthalpy than the products |
  | II. | The reactants have lower enthalpy than the products |
  | III. | This graph corresponds to a neutralization reaction |

- A. $\hspace{1em}$I and III only

- B. $\hspace{1em}$II and III only

- C. $\hspace{1em}$I only

- D. $\hspace{1em}$II only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The graph shows that the temperature of the surroundings decreases as the reaction progresses. This means that the reaction is endothermic; it absorbs energy from the surroundings. Endothermic reactions have products with higher enthalpy than reactants. This is because the energy that is absorbed from the surroundings is used to break bonds in the reactants and form bonds in the products.

Neutralization reactions are typically exothermic, which release energy to the surroundings. So, the statement that this graph corresponds to a neutralization reaction is incorrect.

Therefore, the only statement correct for an endothermic reaction is statement II.
