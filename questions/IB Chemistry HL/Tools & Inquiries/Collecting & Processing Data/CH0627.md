# CH0627

**Maximum mark: 4**

Distinguish between the following terms:

1.  Precision and accuracy. [2 marks]

2.  Systematic error and random error. [2 marks]

---

## 评分标准 / Mark scheme

1.  Accuracy is the closeness of agreement between a measured value and a true value.$\checkmark$

    Precision is a measure of the degree of consistency and agreement among independent measurements of the same quantity. $\checkmark$

2.  Random error refers to the random fluctuations of the measured data above and/or below the true value. $\checkmark$

    Systematic error refers to reproducible fluctuations of the measured data consistently in the same direction. $\checkmark$
