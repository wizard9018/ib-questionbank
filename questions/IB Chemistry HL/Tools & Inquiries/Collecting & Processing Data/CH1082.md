# CH1082

Which of the following errors are systematic?

- :::tableoptions{col1="hide" col2="hide"}
  | ||
  | :-- | :-- |
  | I. | Using a wrongly calibrated weighing scale |
  | II. | Using a calorimeter that is not insulated |
  | III. | When using a measuring cylinder, read the volume from the top of the meniscus |

- A. $\hspace{1em}$I and II only

- B. $\hspace{1em}$I and III only

- C. $\hspace{1em}$II and III only

- D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Systematic errors are consistent in one direction. This means they will always cause the measurements to be too high or too low. Whereas random errors are unpredictable errors. This means they can cause the measurements to be too high, too low, or anywhere in between.
-    Using a wrongly calibrated weighing scale will always cause the measurements to be too high or too low.

-    A calorimeter not insulated well will always allow the heat to escape to the surroundings, causing the measurements to be always lower than actual values.

-    Taking the reading from the top of the meniscus when using a measuring cylinder will always cause the measurements to be too high.

Thus, **all** of the errors listed above are systematic errors.
