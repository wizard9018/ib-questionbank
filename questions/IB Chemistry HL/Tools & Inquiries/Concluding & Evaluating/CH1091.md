# CH1091

**Maximum mark: 5**

A student determined a combustion enthalpy experimentally and obtained $-900\pm 100\,\text{kJ mol}^{-1}.$ The literature values suggest the same enthalpy to be $-1600\,\text{kJ mol}^{-1}.$

1.  Calculate the percentage error. [1 mark]

2.  Comment on the accuracy of the result. [2 marks]

3.  Another student in the same class did the same experiment. His result was $-1300\pm 400\,\text{kJ mol}^{-1}.$ Evaluate the accuracy and precision of the result of this student. [2 marks]

---

## 评分标准 / Mark scheme

1. $\ce{Percentage error} = \left( \dfrac{-1600 + 900}{-1600} \right) (100) = 44 \%\,\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    $\left| \dfrac{\ce{Literature value - experimental value}}{\ce{Literature value}}\ \right| (100)$

2.  Enthalpy value $-900\pm 100\,\text{kJ mol}^{-1}$/ between $-1000$ and $-800\,\text{kJ mol}^{-1}$ and does not include the literature value $(-1600\,\text{kJ mol}^{-1})\,\checkmark$

    Inaccurate result $\checkmark$

3.  Enthalpy value $-1300\pm 400\,\text{kJ mol}^{-1}$ / between $-1700$ and $-900\,\text{kJ mol}^{-1}$ **and** does include the literature value $(-1600\,\text{kJ mol}^{-1})$ **so accurate**; $\checkmark$

    **Low precision** / high uncertainty $\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    The result of the second student has a good accuracy as it includes the literature value in its range. However, the uncertainty informed is high ($±400$ for a magnitude of $1300$), meaning its precision is poor.
