# CH0323

**Maximum mark: 6**

Enthalpy changes can be calculated experimentally using calorimetry or theoretically using Hess's law. Consider the combustion of methanol:

$\ce{CH3OH(l) + 3/2 O2(g) -> CO2(g) + 2 H2O(l)}$

Simon calculated the enthalpy of combustion of methanol to be $-$425 kJ mol$^{-1}$ through calorimetry.

Nathan calculated the enthalpy of combustion of methanol to be $-$650 kJ mol$^{-1}$ using average bond enthalpies.

The theoretical value is $-$726 kJ mol$^{-1}$.

1. 1. Calculate Simon's percentage error. [1 mark]

   2. Calculate Nathan's percentage error. [1 mark]

2. 1. Suggest one source of error in Simon's calculation. [1 mark]

   2. Suggest one source of error in Nathan's calculation. [1 mark]

3. Simon claims that his method is more accurate because it is experimental. Using your answers in part (a), comment on the validity of Simon's claim. [2 marks]
