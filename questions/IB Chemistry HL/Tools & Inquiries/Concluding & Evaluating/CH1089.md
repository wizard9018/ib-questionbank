# CH1089

An unknown substance is investigated. Students were given a sample in the lab. They intended to determine its melting point to identify it. The heating curve was plotted with the collected data and is displayed below.

![CH1089_Image1](images/CH1089_Image1.png)

Some melting points from scientific sources were compared with the processed data.

| Substance | Melting point $\mathbf{(^\circ C)}$ |
| :-: | :-: |
| Benzoic acid | $121$ |
| Benzamide | $129$ |
| Cinnamic acid | $133$ |

Which statement(s) about the experiment is(are) correct?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | The sample has pure benzamide |
  | II. | The sample could correspond to impure cinnamic acid |
  | III. | The melting point determination can be conducted with a hot water bath |

- A. $\hspace{1em}$I only

- B. $\hspace{1em}$II only

- C. $\hspace{1em}$I and III only

- D. $\hspace{1em}$III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The melting point can be used as a purity criterion.

When solids are heated, they increase their temperature till they reach their melting point. At this point, heat is provided, but the temperature remains constant as all the energy given to the system is used for the solid-liquid transition. A flat section in heating curves is observed as the solid-to-liquid change occurs. Pure substances have a sharp melting point. In this case, the melting point is not sharp; we can see a curve rather than a flat section in the middle of the heating curve. The melting point range is approximately $123 - 133\,{}^\circ\text{C}$. Statement I is incorrect.

In addition, the presence of impurities lowers the melting point, and the process occurs over a range of temperatures. Taking this into account, statement II is correct. Pure cinnamic acid would have a sharp melting point at $133\,{}^\circ\text{C}$, but impure cinnamic acid would present a range of temperatures for the solid-to-liquid transition below $133\,{}^\circ\text{C}$ (as shown in the graph).

Finally, water baths would only work to determine melting points below $100\,{}^\circ\text{C}$ as water boils at this temperature. As a result, a melting point near $123 - 133\,{}^\circ\text{C}$ should be determined with other baths, such as glycerin.

This question is categorized as hard as students should examine the heating curve, interpret the results, compare with data tables, and recall how the melting point determination procedure works.
