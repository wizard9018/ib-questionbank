# CH1092

**Maximum mark: 3**

A student collected data to determine the rate of a chemical reaction at different temperatures. He aimed to investigate the effect of temperature on the reaction rate. He experimented at $25\,{}^\circ\text{C},$ $37\,{}^\circ\text{C}$ and $46\,{}^\circ\text{C},$ performing one trial at every temperature.

1.  Identify one methodological weakness of his procedure. [1 mark]

2.  State two assumptions he must consider to draw conclusions. [2 marks]

---

## 评分标准 / Mark scheme

1.  *Any of the following:*

    Only three temperatures tested $\checkmark$

    No repetitions $\checkmark$

2.  *Any two of the following:*

    If there is a catalyst involved, the same catalyst is used in all the trials; $\checkmark$ \
    The chemical reaction is conducted using the same conditions/materials; $\checkmark$ \
    If there is an aqueous solution involved, the concentration is constant; $\checkmark$ \
    If there is a solid reactant, its mass is constant/the particle size is constant. $\checkmark$
