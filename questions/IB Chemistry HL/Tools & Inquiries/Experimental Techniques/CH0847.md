# CH0847

Which of the following changes could be monitored over time to determine the rate of the reaction below?

$\ce{BaCl2(aq) + K2SO4(aq) -> BaSO4(s) + 2 KCl(aq)}$

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | Turbidity |
    | II. | pH |
    | III. | Mass|

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$III only

-   C. $\hspace{1em}$I and III only

-   D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$\ce{BaSO4}$ is an insoluble solid and will form a (white) precipitate within the reaction mixture, increasing the turbidity (reducing the transparency).

This reaction between salts would not result in a change in pH.

No species are entering or leaving the system, so there is no change in mass.
