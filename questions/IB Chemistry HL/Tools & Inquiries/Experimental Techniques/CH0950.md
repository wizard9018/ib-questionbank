# CH0950

Food dye is analyzed using paper chromatography. Calculate the retardation factor value for each different type of dye in the sample.

![CH0950v2](images/CH0950v2.png)

$\mbox{}\\[-15pts]$

|$\hspace{0.95em}$||$\hspace{0.1em}$|$\mathbf{R_f({x})}$|$\mathbf{R_f(y)}$|
:-:|:-:|:-:|:-:|:-:|
||A.||$\ \ \ $0.43 cm$\ \ \ $ |$\ \ \ $ 0.86 cm$\ \ \ $|
||B.||0.43 |0.86|
||C.||1.2| 2.4|
||D.||2.33|1.17|

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:\
To answer this question, the student needs to use the ruler to collect the following data:

-   Distance from starting line to solvent front = $2.8\,\text{cm}$
-   Distance from starting line to spot $x = 1.2\,\text{cm}$
-   Distance from starting line to spot $y = 2.4\,\text{cm}$

This data is then used to calculate the $R_f$ values according to the following formula:

$R_f$ $= \dfrac{\mathrm{Distance\ traveled\ by\ the\ spot}}{\mathrm{Distance\ traveled\ by\ the\ solvent}}$

Therefore:

$R_f(x) = \dfrac{1.2\,\text{cm}}{2.8\,\text{cm}} = 0.43$

$R_f(y) = \dfrac{2.4\,\text{cm}}{2.8\,\text{cm}} = 0.86$

Importantly, the student must recognize that $R_f$ values are unitless as they are a ratio of two distances.

This question is medium complexity because the student needs to make careful measurements and calculations but these calculations are not overly complicated.
