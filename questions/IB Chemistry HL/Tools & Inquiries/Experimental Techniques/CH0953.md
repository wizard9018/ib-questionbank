# CH0953

Which of the following solvents would be suitable choices for the mobile phase in paper chromatography to ensure that a polar dye has a high $R_f$ value?

-   A.$\hspace{1.em}$methylbenzene, $\ce{C6H5CH3}$

-   B.$\hspace{1.em}$methanol, $\ce{CH3OH}$

-   C.$\hspace{1.em}$ ethoxyethane, $\ce{CH3CH2OCH2CH3}$

-   D.$\hspace{1.em}$ benzene, $\ce{C6H6}$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation:}}$\

To answer this question, the student must recall that substances will have a higher $R_f$ value when they have a higher affinity for the mobile phase.

Higher affinity implies that the substance and the solvent will form stronger intermolecular bonds, and therefore they must either be both polar or both non-polar to allow for the higher $R_f$ value. Since the dye is polar, the mobile phase must also be polar for the $R_f$ value to be higher.

Both methylbenzene and benzene are nonpolar solvents so they would not be good choices for a polar dye.

Ethoxyethane is an ether which is very weakly polar. This solvent would likely allow the polar dye to move off of the starting line, but it would not have a high $R_f$ value.

Methanol is a polar solvent that would form stronger intermolecular forces (specifically hydrogen bonds) with a polar dye, thereby allowing for a higher $R_f$ value.

This question is difficult as the student must combine multiple concepts together and assess each molecule separately. Having an understanding of the link between intermolecular forces and affinity is essential.
