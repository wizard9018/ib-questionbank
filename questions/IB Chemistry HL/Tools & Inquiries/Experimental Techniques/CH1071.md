# CH1071

Which option accurately identifies the separation technique and the physical property it relies on to isolate methanol and ethanol from a mixture?

-   :::tableoptions{col1="hide"}
    | | Separation Technique | Physical property it relies on |
    | :-: | :-: | :-: |
    | A. | Filtration | Difference in boiling point |
    | B.| Filtration | Difference in solubility |
    | C. | Distillation | Difference in boiling point |
    | D. | Distillation | Difference in solubility |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Distillation is a process of separating the components of a liquid mixture by selectively boiling and condensing the vapors.

The property this separation technique depends on is the difference in the boiling point of the respective components, whereas, in the case of filtration, substances are separated on the basis of their ability to pass through a filter (particle size). Filtration separates solid and liquid from a mixture using a filter through which only the liquid can pass.
