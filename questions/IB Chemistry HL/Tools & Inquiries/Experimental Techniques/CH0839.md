# CH0839

Which of the reactions below could be monitored using colorimetry?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | $\ce{H2O2(aq) + 2 H+(aq) + 2 I-(aq) -> I2(aq) + H2O(l)}$ |
    | II. | $\ce{NaBr(aq) + Cl2(aq) -> NaCl(aq) + Br2(aq)}$ |
    | III. | $\ce{Mg(OH)2(aq) + HCl(aq) -> MgCl2(aq) + H2O(l)}$ |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I, II, and III

-   C. $\hspace{1em}$I only

-   D. $\hspace{1em}$II only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

In reaction **I**, $\ce{I-}$ is oxidized to $\ce{I2}$ resulting in the formation of brown solution (from colorless).

A displacement reaction in reaction **II** results in a pale green solution (due to $\ce{Cl2}$) gradually becoming brown-orange (due to $\ce{Br2}$).

There are no colored species in reaction **III**.
