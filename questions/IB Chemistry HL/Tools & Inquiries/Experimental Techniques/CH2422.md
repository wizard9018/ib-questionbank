# CH2422

The diagram below shows the separation of a two$-$component mixture by liquid column chromatography.

![CH2422_column](images/CH2422_column.png)

Which statement is correct?

-   I.$\hspace{1em}$Component B has the greater affinity for the mobile phase.
-   II.$\hspace{0.7em}$The sample is placed at the top of the column and the stationary phase is poured through.
-   III.$\hspace{0.4em}$The greater the column length, the better the separation of the components.

-   A.$\hspace{1.em}$I only

-   B.$\hspace{1.em}$I and II only

-   C.$\hspace{1.em}$I and III only

-   D.$\hspace{1.em}$II and III only

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$\
In liquid column chromatography, the stationary phase (typically silica) is packed into a vertical column. The mixture is loaded at the top of the column and the mobile phase (solvent) is poured through continuously. As the solvent flows down, each component partitions between the stationary phase and the mobile phase according to its relative affinity for each.

A component with a greater affinity for the mobile phase spends more time dissolved in the solvent and travels down the column faster. Component B moves ahead of component A and elutes first, so component B has the greater affinity for the mobile phase. Statement I is correct.

Statement II is incorrect because it is the mobile phase (solvent) that is poured through the column, not the stationary phase. The stationary phase remains fixed in the column throughout the experiment. The sample is indeed placed at the top, but the second part of the statement reverses the roles of the two phases.

A longer column provides more stationary phase for the components to interact with, which increases the number of partitioning steps and improves the resolution between bands. Statement III is correct.
