# CH1072

A sample interacts with ultraviolet light. Which technique(s) is(are) most suitable to determine the identity of this sample?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | Calorimetry |
  | II. | Colorimetry |
  | III. | Spectrophometry |

- A. $\hspace{1em}$II only

- B. $\hspace{1em}$III only

- C. $\hspace{1em}$I and II only

- D. $\hspace{1em}$I and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Calorimetry is a technique best used to determine the molar enthalpy of a reaction.

Both spectrophotometry and colorimetry are analytical techniques based on the substance's interaction with light. But colorimetry is limited to wavelengths of visible light, whereas spectrophotometry uses a range of UV, visible, and IR radiation. Therefore, spectrophotometry is most suitable to determine the identity of this sample.
