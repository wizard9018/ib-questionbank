# CH1043

A graph of $\ln k$ against $\dfrac{1}{T}$ is given below.

![CH1043](images/CH1043.png)

What is the correct expression for the activation energy in $\text{kJ mol}^{-1}?$

-   A.$\hspace{1em}22345\times 8.31$

-   B.$\hspace{1em}\dfrac{22345\times 8.31}{1000}$

-   C.$\hspace{1em}\dfrac{22345}{8.31}$

-   D.$\hspace{1em}\dfrac{22345}{8.31\times 1000}$

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:\
The Arrhenius equation, $k = Ae^{-{E_a/RT}},$ can be linearized by taking the natural log as

$\ln k = - \dfrac{E_a}{RT} + \ln A $

When $\ln k$ is plotted against $\dfrac{1}{T}$, the gradient is $-\dfrac{E_a}{R}$ and the $y-$intercept is $\ln A.$

From the graph, $y = -22345x + 25.337.$ Using the gradient,

$m = \dfrac{-E_a}{R} = -22345\,\text{K}$\
$E_a = 22345\,\text{K}\times R = 22345\,\text{K}\times 8.31\,\text{J mol}^{-1}\,\text{K}^{-1} = \ $:answer[$
\dfrac{22345\times 8.31}{1000}\,\text{kJ mol}^{-1}$]

This question is categorized as hard as the student must interpret the graph, apply the Arrhenius equation and calculate the $E_a$ with specific units.
