# CH0737

Identify the intermediate and catalyst, respectively, for the following proposed reaction mechanism.

| | | | |
| :- | -: | :- | :- |
| Step 1: | $\ce{Cl(g) + O3(g) ->}$ | $\ce{O2(g) + ClO(g)}$ | (slow) |
| Step 2: | $\ce{O3(g) + ClO(g) ->}$ | $\ce{2 O2(g) + Cl(g)}$ | (fast) |

-   A.$\hspace{1em}\ce{ClO}$, Cl

-   B.$\hspace{1em}\ce{O2}$, Cl

-   C.$\hspace{1em}$Cl, ClO

-   D.$\hspace{1em}$Cl, $\ce{O2}$

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation:}}$\
ClO is an intermediate because it is produced in one step and consumed in a subsequent step.

Cl is a catalyst because it is present at the beginning and end of the reaction but does not appear in the overall equation.
