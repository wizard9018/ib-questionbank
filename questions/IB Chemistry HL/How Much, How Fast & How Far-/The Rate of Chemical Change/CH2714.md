# CH2714

1. A student determined the activation energy of the reaction between peroxodisulfate and iodide ions,

    $\ce{S2O8^{2-}}\textrm{(aq)} + 2\ce{\,I^-}\textrm{(aq)} \longrightarrow 2\ce{\,SO4^{2-}}\textrm{(aq)} + \ce{I2}\textrm{(aq)},$

    using a clock method. Every mixture contained identical initial concentrations of all species, including a small, fixed amount of sodium thiosulfate and starch, and was thermostatted in a water bath. The time, $t,$ for the blue$-$black colour to appear was recorded at five temperatures.

    | $\mathbf{Temperature\textrm{ / }{}^\circ\textbf{C}}$ | $\mathbf{t\textbf{ / s} \pm 0.5}$ | $\mathbf{\dfrac{1}{T}\textrm{ / }10^{-3}\textbf{ K}^\mathbf{-1}}$ | $\textbf{ln}{\left(\dfrac{\mathbf{1}}{\mathbf{t}}\right)}$ |

    | 25.0 | 51.0 | 3.356 | $-3.932$ |

## 评分标准 / Mark scheme

1.
    1. concentrations equal in every trial, rate $\propto k\: \checkmark$\
    same fixed amount reacts before the colour appears, rate $\propto \dfrac{1}{t}$ $\checkmark$

        $\textrm{\underline{Further Explanation:}}$\
        The rate equation for the reaction is

        $\textrm{rate} = k[\ce{S2O8^{2-}}]^m[\ce{I^-}]^n$

        Every mixture starts with the same concentrations, so the term $[\ce{S2O8^{2-}}]^m[\ce{I^-}]^n$ has the same value in every trial. The rate changes between trials only because $k$ changes with temperature, so rate $\propto k.$

        The rate can also be written as the change in concentration of a reactant divided by the time taken:

        $\textrm{rate} = -\dfrac{\Delta[\ce{S2O8^{2-}}]}{t}$

        The thiosulfate removes iodine as fast as it forms, so the blue$-$black colour appears only when the thiosulfate is used up. The amount of thiosulfate is the same in every mixture, so the same amount of peroxodisulfate has reacted each time the colour appears, and $\Delta[\ce{S2O8^{2-}}]$ is constant. The rate is therefore proportional to $\dfrac{1}{t}.$ This amount is small, so the reactant concentrations barely change before the colour appears, and the measured rate is effectively the initial rate.

        Since rate $\propto k$ and rate $\propto \dfrac{1}{t},$ it follows that $\dfrac{1}{t} \propto k.$

    2. $\dfrac{1}{T} = 3.247 \times 10^{-3} \textrm{\ K}^{-1}\: \checkmark$\
    $\ln\left(\dfrac{1}{t}\right) = -3.243$ $\checkmark$

        $\textrm{\underline{Further Explanation:}}$\
        The temperature must first be converted to kelvin:

        $35.0 + 273 = 308 \textrm{\ K}$

        as in the rest of the table.  The two values are

        $\dfrac{1}{T} = 3.247 \times 10^{-3} \textrm{\ K}^{-1}$

        $\ln\left(\dfrac{1}{25.6}\right) = -\ln 25.6 = -3.243$

    3. $\ln\left(\dfrac{1}{t}\right) = \textrm{constant} - \dfrac{E_a}{R} \times \dfrac{1}{T}$  $\checkmark$ \
        gradient $= -\dfrac{E_a}{R}$ $\checkmark$

        $\textrm{\underline{Further Explanation:}}$\
        The linearized version of the Arrhenius equation

        $\ln k = \ln A - \dfrac{E_a}{R}\left(\dfrac{1}{T}\right)$

        can be rewritten using the proportionality found in part (a)(i), $k = C \times \dfrac{1}{t},$ where $C$ is a constant with the same value in every trial. Taking the natural logarithms,

        $\ln k = \ln C + \ln \left(\dfrac{1}{t}\right)$

        $\ln\left(\dfrac{1}{t}\right) = (\ln A - \ln C) - \dfrac{E_a}{R}\left(\dfrac{1}{T}\right) $

        This has the form $y = c + mx,$ with $y = \ln\left(\dfrac{1}{t}\right)$ and $x = \dfrac{1}{T},$ so the plot is a straight line with gradient $-\dfrac{E_a}{R}.$ The constant $C$ appears only in the intercept, so $E_a$ can be found from the gradient without measuring $k$ itself.

2.
    1.  two points far apart on the line of best fit $\checkmark$ \
        gradient $= -6.3 \times 10^{3} \textrm{\ K}$ $\checkmark$

        *Accept values from -6.1 $\times$ 10$^\mathit{3}$ to $-$6.5 $\times$ 10$^\mathit{3}$ K.*

        ![CH2714ms](images/CH2714ms.png)

        $\textrm{\underline{Further Explanation:}}$\
        The gradient is found from two points on the line of best fit, chosen far apart, such as $(3.08 \times 10^{-3},\ -2.20)$ and $(3.40 \times 10^{-3},\ -4.20):$

        $\textrm{gradient} = \dfrac{-4.20 - (-2.20)}{(3.40 - 3.08) \times 10^{-3} \textrm{\ K}^{-1}} = \dfrac{-2.00}{0.32 \times 10^{-3} \textrm{\ K}^{-1}} = -6.3 \times 10^{3} \textrm{\ K}$

        Neither point is a data point: both are read from the line, not taken from the table. The line is drawn through all five trials, so it averages out the random error in each measurement. Points far apart give a large rise and run, so the small error in reading each value from the graph has less effect on the gradient.

    2. $E_a = 52 \textrm{\ kJ mol}^{-1}$ $\checkmark$

        *Accept 41.6 kJ mol$^\mathit{\,-1}$ from the value $-$5.00 $\times$ 10$^\mathit{\,3}$  K.*\
        *Accept values from 51 to 54 kJ mol$^\mathit{\,-1}.$*

        $\textrm{\underline{Further Explanation:}}$\
        The gradient equals $-\dfrac{E_a}{R},$ so the activation energy is $E_a = -R \times \textrm{gradient}$

        $E_a = -(-6.3 \times 10^{3} \textrm{\ K}) \times 8.31 \textrm{\ J K}^{-1}\textrm{ mol}^{-1} = 5.2 \times 10^{4} \textrm{\ J mol}^{-1} = 52 \textrm{\ kJ mol}^{-1}$

    3. $55.0\,{}^\circ\textrm{C}:$ $6.8\%$ **AND** $15.0\,{}^\circ\textrm{C}:$ $0.47\%$ $\checkmark$ \
        $55.0\,{}^\circ\textrm{C}$ trial, as its percentage uncertainty is larger $\checkmark$

        *Do not award M2 without a valid reason.*

        $\textrm{\underline{Further Explanation:}}$\
        The same $\pm 0.5 \textrm{\ s}$ uncertainty is small compared with a time of $106.1 \textrm{\ s},$ but large compared with a time of $7.4 \textrm{\ s}:$

        $\dfrac{0.5 \textrm{\ s}}{7.4 \textrm{\ s}} \times 100\% = 6.8\% \qquad \dfrac{0.5 \textrm{\ s}}{106.1 \textrm{\ s}} \times 100\% = 0.47\%$

        The $55.0\,{}^\circ\textrm{C}$ point lies at one end of the line, so its uncertainty has the greatest effect on the gradient and therefore on $E_a.$

    4. any **one** of the following:
        $\mbox{}\\[-10pts]$

        -   increase the fixed amount of thiosulfate «so every clock time is longer» $\checkmark$
        -   lower all the reactant concentrations by the same factor $\checkmark$
        -   use a light sensor/colorimeter to stop the timer $\checkmark$

        $\textrm{\underline{Further Explanation:}}$\
        More thiosulfate means more peroxodisulfate must react before the colour appears, so every clock time is longer and the $\pm 0.5 \textrm{\ s}$ uncertainty is a smaller percentage of each time. The improvement is greatest for the hottest trial, which has the shortest time. The amount that reacts is still fixed and still small, so $\dfrac{1}{t}$ remains proportional to $k.$ A light sensor or colorimeter that stops the timer when the solution darkens reduces the uncertainty in each time, because it does not depend on the student's reaction time.
