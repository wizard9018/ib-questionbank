# CH0326

The Maxwell$-$Boltzmann distribution plot below is for the same substance with the same concentration at different temperatures. Which statement is correct about the total number of molecules for each temperature? 

![CH0326](images/CH0326.png)

-   A.$\hspace{1em}$There are more molecules at low temperatures

-   B.$\hspace{1em}$There are more molecules at high temperatures

-   C.$\hspace{1em}$The number of molecules depends on the temperature

-   D.$\hspace{1em}$The number of molecules remains the same

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The number of molecules remains constant. Temperature only changes the particles' kinetic energy; when temperature increases, the kinetic energy of the particles also increases.
