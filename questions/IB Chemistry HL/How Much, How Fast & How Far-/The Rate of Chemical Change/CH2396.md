# CH2396

A student investigates the rate of the following reaction using the set up shown in the diagram below.

$\ce{Na_2S_2O_3}\textrm{(aq)} + 2\ce{\,HCl}\textrm{(aq)} \longrightarrow \ce{SO_2}\textrm{(aq)} + \ce{S}\textrm{(s)} + \ce{H_2O}\textrm{(l)} + 2\ce{\,NaCl}\textrm{(aq)}$

 ![CH2397](images/CH2397.png)
 $\footnotesize{\textrm{Diagram  created with Chemix (2025). Retrieved from https://chemix.org}}$

$\mbox{}\\[-5pts]$
Which of the following will decrease the validity of the investigation?

-   I.$\hspace{1em}$Rinsing the flask with hydrochloric acid before each trial.
-   II.$\hspace{0.7em}$Using a magnetic stirrer to stir the solution throughout each experiment.
-   III.$\hspace{0.4em}$Using different measuring cylinders to measure the volumes of each reactant.

-   A.$\hspace{1.em}$I only

-   B.$\hspace{1.em}$II only

-   C.$\hspace{1.em}$II and III only

-   D.$\hspace{1.em}$I, II and III

---

## 评分标准 / Mark scheme

**答案：A**

$\textrm{\underline{Explanation:}}$\
In the thiosulfate cross experiment, the rate of reaction is measured by timing how long it takes for a cross drawn beneath the flask to disappear as sulfur precipitate forms and makes the solution opaque. For results to be valid, all variables other than the one being investigated must be controlled.

Rinsing the flask with hydrochloric acid before each trial introduces an unmeasured quantity of acid into the reaction mixture. This residual acid reacts with the thiosulfate solution as soon as it is added, altering the effective concentration of both reactants in a way that cannot be accounted for. The results become unreliable because the actual amount of acid in each trial is unknown. The flask should be rinsed with distilled water instead.

Using a magnetic stirrer throughout each experiment ensures the solution is uniformly mixed, so the reaction proceeds evenly and the sulfur precipitate forms consistently. As long as the stirring is applied in the same way for every trial, this is good experimental practice that supports fair testing.

Using different measuring cylinders for each reactant is also good practice. Dedicating a separate cylinder to the acid and the thiosulfate solution prevents cross-contamination between reagents, which would otherwise introduce a systematic error.
