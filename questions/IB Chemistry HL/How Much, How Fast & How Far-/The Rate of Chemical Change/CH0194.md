# CH0194

A reaction involving X and Y shows the following data:

| Trial | [X] (mol dm$\mathbf{^{-3}}$) | [Y] (mol dm$\mathbf{^{-3}}$) | Rate (s$\mathbf{^{-1}}$) |

| :-: | :-: | :-: | :-: |

| 1 | 0.10 | 0.50 | 0.20 |

| 2 | 0.20 | 0.50 | 0.40 |

| 3 | 0.20 | 0.25 | 0.40 |

What possible mechanism is consistent with the data? 

-   :::tableoptions{col1="hide"}

    | | $\hspace{1em}$ Step 1 $\hspace{1em}$ | $\hspace{1em}$ Step 2 $\hspace{1em}$ |

    | :-: | :-: | :-: |

    | A. | $\ce{X + X -> I}$ (slow) | $\ce{I + Y -> Z}$ (fast) |

    | B. | $\ce{X + Y <=> I}$ (fast) | $\ce{I -> Z}$ (slow) |

    | C. | $\ce{X -> I}$ (slow)  | $\ce{I + Y -> Z}$ (fast) |

    | D. | $\ce{X -> I}$ (fast) | $\ce{I + Y -> Z}$ (slow)  |

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:\

Using trials 1 and 2, as [X] doubles, rate also doubles therefore first order with respect to [X].

Using trials 2 and 3, as [Y] halves, rate stays the same and so, zero order with respect to [Y].

$\textrm{rate} = k[\ce{X}]^1[\ce{Y}]^0$

The proposed mechanisms would have us arrive at the following rate laws.

$\ce{X + X -> I}$ $\textrm{(slow)}$ $\newline$ $\ce{I + Y -> Z}$ $\textrm{(fast)}$ | $\textrm{rate} = k[\ce{X}]^2$

:-:|:-:

$\ce{X + Y <=> I}$ (fast) $\newline$ $\ce{I -> Z}$ (slow) | $\textrm{rate} = k[\ce{I}]=k[\ce{X}][\ce{Y}]$

$\ce{X -> I}$ (slow)  $\newline$ $\ce{I + Y -> Z}$ (fast) | $\textrm{rate} = k[\ce{X}]$

$\ce{X -> I}$ (fast) $\newline$ $\ce{I + Y -> Z}$ (slow)  | $\textrm{rate} = k[\ce{I}][\ce{Y}] = k[\ce{X}][\ce{Y}]$

When the unimolecular transformation of X into the intermediate is the slow step, the observed rate law matches the predicted mechanism.
