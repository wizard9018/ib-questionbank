# CH1197

Consider the following data for the chemical reaction at 25 $°C$:

$\ce{A + 2 B -> C + 2 D}$

|Experiment | [A] / $\mathbf{mol\ dm^{-3}}$ | [B] / $\mathbf{mol\ dm^{-3}}$ | Rate / $\mathbf{mol\ dm^{-3}\ s^{-1}}$ |
| :-: | :-: | :-: | :-: |
| 1 | 0.450 | 0.300 | $1.0 \times 10^{-3}$ |
| 2 | 0.450 | 0.100 | $3.3 \times 10^{-4}$ |
| 3 | 0.900 | 0.600 | $2.0 \times 10^{-3}$ |

Which is the correct rate equation at $25\,{}^\circ \text{C}?$

- A. $\hspace{1em}rate = k \ce{[A][B]}^2$

- B. $\hspace{1em}rate = k \ce{[A][B]}$

- C. $\hspace{1em}rate = k \ce{[A]}$

- D. $\hspace{1em}rate = k \ce{[B]}$

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:

Rate equations can be experimentally determined.

In this case, we can compare experiments 1 and 2. When the concentration of A is kept constant, if the concentration of B is divided by three, the reaction rate is also divided by three.

![CH1197](images/CH1197.png)

We can deduce that there is a direct proportionality between the concentration of B and the rate, so the B rate order is one.

To deduce the order for A, we need to consider variations in the concentration of A. This comparison is harder as no trials with variations in [A] keeping [B] constant.

If we compare experiments 1 and 3, we observe that both [A] and [B] are doubled. We already know that B is order one, so its effect would be to double the rate. However, we should check if there is an additional effect as [A] is doubled.

![CH1197B](images/CH1197B.png)

By comparing the rates, we can see that the rate is doubled, meaning that the change in the A concentration had no effect at all. We can deduce that A is order zero.

The rate law is $rate = k \ce{[B][A]}^0$ or $rate = k \ce{[B]}.$

This question is categorized as hard as students should deduce the orders and the rate equation from the given data.
