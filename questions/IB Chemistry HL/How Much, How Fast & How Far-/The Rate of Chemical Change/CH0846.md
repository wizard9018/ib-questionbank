# CH0846

For the reaction below, which changes would result in an increased rate of reaction:

$\ce{MnO4-(aq) + 5 Fe^2+(aq) + 8 H+(aq) -> Mn^2+(aq) + 5 Fe^3+(aq) + 4 H2O(aq)}$

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | Increasing [$\ce{Fe^{2+}}$] |
    | II. | Decreasing particle size |
    | III. | Increasing pressure |

-   A. $\hspace{1em}$I and II only

-   B. $\hspace{1em}$I, II, and III

-   C. $\hspace{1em}$I only

-   D. $\hspace{1em}$I and III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

All three factors can increase the rate of a chemical reaction; however, as there are no solid or gaseous reactants, concentration is the only of the above factors that would increase the frequency of particle collisions.
