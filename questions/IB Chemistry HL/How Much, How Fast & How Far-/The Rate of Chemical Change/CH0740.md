# CH0740

Given enthalpy diagrams for reactions A, B, and C, which of the following statements is correct?

![PE-740SL](images/PE-740SL.png)

-   :::tableoptions{col1="hide" col2="hide"}

    | | |

    | :- | :- |

    | I. | Diagrams B and C could represent a catalyst added to reaction A |

    | II. | Reaction A has the greatest activation energy |

    | III. | All reactions are exothermic |

-   A. $\hspace{1em}$I, II, and, III

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$I only

-   D. $\hspace{1em}$II only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

While both diagrams B and C have lower activation energies than diagram A, diagram B has to represent a different reaction as it is endothermic and the addition of a catalyst does not change the enthalpy of the reaction.

Diagram A has the greatest activation energy.

Only diagrams A and C show exothermic reactions.
