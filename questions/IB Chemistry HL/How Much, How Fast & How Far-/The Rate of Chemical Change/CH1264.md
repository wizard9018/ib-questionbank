# CH1264

Consider the chemical equation:

$\ce{2 A + B -> D}$

The corresponding rate equation is: $\textrm{rate} = k[\ce{A}]^2[\ce{B}] \text{ at } 25\,{}^\circ\text{C}.$

Which mechanism is consistent with this rate equation?

- :::tableoptions{col1="hide" col2="hide" col3="hide" col4="hide"}
  | | |  | |
  | :-: | :-- | :-- | :-- |
  | A. | First step: | $\hspace{1em}\ce{A + B -> C}$ | $\hspace{1em}$ slow |
  | | Second step: | $\hspace{1em}\ce{C + A -> D}$ | $\hspace{1em}$ fast |
  | B. | First step: | $\hspace{1em}\ce{2 A -> C}$ | $\hspace{1em}$ slow|
  | | Second step: | $\hspace{1em}\ce{C + B  ->  D}$ | $\hspace{1em}$ fast |
  | C. | First step: | $\hspace{1em}\ce{2 B -> C}$ | $\hspace{1em}$ slow |
  | | Second step: | $\hspace{1em}\ce{C + A -> D}$ | $\hspace{1em}$ fast |
  | D. | First step: | $\hspace{1em}\ce{A + B -> C}$ | $\hspace{1em}$ fast |
  | | Second step: | $\hspace{1em}\ce{C + A -> D}$ | $\hspace{1em}$ slow |

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:\
Each mechanism is tested two ways: its steps must add to the overall equation $\ce{2A + B -> D},$ and its slow (rate$-$determining) step must give the observed $\textrm{rate} = k[\ce{A}]^2[\ce{B}].$ In every case the intermediate C cancels when the steps are added.

For the mechanism

$\ce{A + B -> C}$ (slow)\
$\ce{C + A -> D}$ (fast)

Adding the steps gives $\ce{2A + B + C -> C + D};$ C cancels to leave $\ce{2A + B -> D},$ so the overall equation is correct. The slow step involves $\ce{A + B},$ giving $\textrm{rate} = k[\ce{A}][\ce{B}].$ This does not match the observed rate law, so the mechanism is rejected.

For the mechanism

 $\ce{\textcolor{white}{B\ }2A -> C}$ (slow)\
 $\ce{C + B -> D}$ (fast)

Adding the steps gives $\ce{2A + B + C -> C + D};$ C cancels to leave $\ce{2A + B -> D},$ so the overall equation is correct. The slow step involves $\ce{2A},$ giving $\textrm{rate} = k[\ce{A}]^2.$ This does not match, so the mechanism is rejected.

For the mechanism

$\ce{\textcolor{white}{A\ \,}2B -> C}$ (slow)\
$\ce{C + A -> D}$ (fast)

Adding the steps gives $\ce{A + 2B + C -> C + D};$ C cancels to leave $\ce{A + 2B -> D}.$ This is not the overall equation, so the mechanism is rejected without testing the rate law.

For the mechanism

$\ce{A + B -> C}$ (fast)\
$\ce{C + A -> D}$ (slow)

Adding the steps gives $\ce{2A + B + C -> C + D};$ C cancels to leave $\ce{2A + B -> D},$ so the overall equation is correct. The slow step is $\ce{C + A},$ giving $\textrm{rate} = k_2[\ce{A}][\ce{C}].$ C is an intermediate, formed from A and B in the fast first step, so $[\ce{C}] = k_1[\ce{A}][\ce{B}].$ Substituting:

$\textrm{rate} = k_2[\ce{A}](k_1[\ce{A}][\ce{B}]) = k[\ce{A}]^2[\ce{B}]$

Both the overall equation and the rate law match, so this mechanism is correct.
