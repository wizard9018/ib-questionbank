# CH0734

The rate law for the reaction $\ce{2NO(g) + O2(g) -> 2 NO2(g)}$, is determined to be second-order with respect to $\ce{NO}$ and first order with respect to $\ce{O2}$.

Which of the mixtures below would create the fastest initial rate?

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

Diagram B contains 7 $\ce{NO}$ and 4 $\ce{O2}$, according to the rate law, rate = k[NO]$^2$ $\ce{[O2]}$, the initial rate would be the fastest, rate = k(7)$^2$(4) = 196k. 

-   A:     rate = k(4)$^2$(6) = 96k

-   C:    rate = k(6)$^2$(5) = 180k

-   D:    rate = k(5)$^2$(4) = 100k
