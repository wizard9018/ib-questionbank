# CH0207

**Maximum mark: 6**

Aqueous perchlorate $\ce{(ClO4^-)}$ and hydrogen $\ce{(H+)}$ ions react at high temperature and pressure to produce chlorine, oxygen and water.

$\ce{4 ClO4^-}\textrm{(aq)} + 4 \ce{\,H+}\textrm{(aq)} \longrightarrow 2 \ce{\,Cl2}\textrm{(g)} + 7 \ce{\,O2}\textrm{(g)} + 2 \ce{\,H2O}\textrm{(l)}$

1.  The rate of reaction was measured for different reactant concentrations at $300.0\,{}^\circ \mathrm{C}$.

    |$\enskip \mathbf{Initial \ [ClO_4^-] / mol\,dm^{-3}}\enskip$ | $\enskip \mathbf{Initial\  [H^+] / mol\,dm^{-3}}\enskip$ |$\enskip \mathbf{Initial\  reaction \ rate / mol\,dm^{-3}\,s^{-1}}\enskip$ |
    | :---: | :---: | :---: |
    | 1.13 | 0.55 | $3.45 \times 10^{-7}$ |
    | 2.26 | 0.55 | $1.38 \times 10^{-6}$ |
    | 2.26 | 2.20 | $5.52 \times 10^{-6}$ |

    $\mbox{}\\[-20pts]$
    1.  Deduce the order of reaction with respect to $\ce{ClO4-}$ and $\ce{H+}$.  [2 marks]

    2.  Using your answers from (i) and the data in the table, calculate the rate constant $k$ at $300.00\,{}^\circ \mathrm{C}$ and state its units.  [2 marks]

2.  When the temperature is increased to $305.4\,{}^\circ \mathrm{C}$, the rate constant doubles. Calculate the activation energy of the reaction, in kJ mol$^{-1}$, using sections 1 and 2 of the data booklet. [3 marks]

## 评分标准 / Mark scheme

1.  1.  $\ce{ClO4-}$: 2 / second order $\checkmark$\
        $\ce{H+}$: 1 / first order$\checkmark$

        $\underline{\textrm{Further explanation:}}$\
        Using trials 1 and 2, as $\ce{[ClO4-]}$ doubles, rate quadruples.  The reaction is second order in chlorate(VII) ion.

        Using trials 2 and 3, as $\ce{[H+]}$ quadruples, rate also quadruples. The reaction is first order in hydrogen ion.

    2.  $k = \dfrac{\textrm{rate}}{\ce{[H+][ClO4-]^2}} = \dfrac{5.52 \times 10^{-6}}{(2.20)(2.26)^2} = 4.91 \times 10^{-7} \: \checkmark$\
         dm$^6$ mol$^{-2}$ s$^{-1}$  $\checkmark$

        $\underline{\textrm{Further explanation:}}$\
        Based on the rate law, $\textrm{rate} = k\ce{[H+][ClO4-]^2},$ we can solve for the value and units of $k$.  Any of the trials can be used to calculate $k,$ all give the same value.

        $k = \dfrac{\textrm{rate}}{\ce{[H+][ClO4-]^2}} = \dfrac{5.52 \times 10^{-6}}{(2.20)(2.26)^2} = 4.91 \times 10^{-7}$

        The units for $k$ are calculated as

        $[k] = \dfrac{\textrm{mol\,dm}^{-3}\,\textrm{s}^{-1}}{\left(\textrm{mol}\textrm{\,dm}^{-3}\right)^3} = \textrm{mol}^{-2}\textrm{dm}^6\textrm{\,s}^{-1}$

2.  $T_1 = 578.4 \textrm{\ K}$ **AND** $T_2 = 573.0 \textrm{\ K} \: \checkmark$\
    $E_a = \dfrac{R \ln\left(\dfrac{k_1}{k_2}\right)}{\left(\dfrac{1}{T_2} - \dfrac{1}{T_1}\right)}\, \checkmark$

    $E_a = \dfrac{8.31 \times \ln(2)}{\left(\dfrac{1}{573.0} - \dfrac{1}{578.4}\right)} = 353521.3\,\text{J mol}^{-1} =  {354\,\text{kJ mol}^{-1}}\, \checkmark$

    $\underline{\textrm{Further explanation:}}$\
    The linear form of the Arrhenius equation $\ln k = -\dfrac{E_a}{R}\left(\dfrac{1}{T}\right) + \ln A$ can be specifically rewritten for two points:

    $\ln\left(\dfrac{k_1}{k_2}\right) = \left(\dfrac{E_a}{R}\right) \left(\dfrac{1}{T_2} - \dfrac{1}{T_1}\right)$

    where $R= 8.31\,\text{J K}^{-1}\,\text{mol}^{-1}$, the ratio of the rate constants is 2, and the temperature must be in Kelvin.

    $T_1 = 578.4 \textrm{\ K}$ and $T_2 = 573.0 \textrm{\ K}$

     Substitution and rearrangement to find $E_a$.

    $E_a = \dfrac{8.31 \textrm{\ J mol}^{-1}\textrm{\,K}^{-1} \times \ln(2)}{\left(\dfrac{1}{573.0 \textrm{\ K}} - \dfrac{1}{578.4\textrm{\ K}}\right)} = 353521.3\,\text{J mol}^{-1} =  354\,\text{kJ mol}^{-1}$
