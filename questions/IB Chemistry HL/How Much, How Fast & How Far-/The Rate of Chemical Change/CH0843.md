# CH0843

Based on the data in the table below, which row gives the correct initial rate of depletion of bromide and initial rate of production of bromine?

$\ce{5Br-(aq) + BrO3-(aq) + 6 H+(aq) -> 3 Br2(aq) + 3 H2O(l)}$

| Time (s) | Bromide concentration (mol dm$\mathbf{^{-3}}$)
| :-: | :-: |
| 0 | 0.30 |
| 1 | 0.26 |
| 2 | 0.22 |

-   :::tableoptions{col1="hide"}
    | | Rate of bromide depletion (mol dm$\mathbf{^{-3}}$ s$\mathbf{^{-1}}$) | Rate of bromine production (mol dm$\mathbf{^{-3}}$ s$\mathbf{^{-1}}$) |
    | :-: | :-: | :-: |
    | A.| $4 \times 10^{-2}$ | $2.4 \times 10^{-2}$ |
    | B. | $2 \times 10^{-1}$ | $6 \times 10^{-1}$ |
    | C. | $4 \times 10^{-2}$ | $1.2 \times 10^{-1}$ |
    | D. | $4 \times 10^{-2}$ | $4 \times 10^{-2}$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The concentration of bromide ions ($\ce{Br-}$) decreases by 0.04 ($4 \times 10^{-2}$) mol dm$^{-3}$ each second.

The bromide ($\ce{Br-}$) ratio to bromine ($\ce{Br2}$) is 5 : 3, meaning that bromine is produced at a $rate = 4\times 10^{-2}\times \dfrac{3}{5} = 2.4\times 10^{-2}\,\text{mol dm}^{-3}\,\text{s}^{-1}$.
