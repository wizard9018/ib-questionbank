# CH1005

Hydrogen peroxide decomposes as described below.

$\ce{2 H2O2 (aq) ->[MnO2] H2O(l) + O2(g)}$

Which statement(s) is(are) correct?

-   :::tableoptions{col1="hide" col2="hide"}
    | | |
    | :- | :- |
    | I. | $\ce{MnO2}$ is a catalyst. |
    | II. | The use of $\ce{MnO2}$ provides an alternative pathway for the chemical reaction to occur. |
    | III. | $\ce{MnO2}$ is used up in the chemical reaction. |

-   A. $\hspace{1em}$I only

-   B. $\hspace{1em}$I and II only

-   C. $\hspace{1em}$I, II and III

-   D. $\hspace{1em}$I and III

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation}}$:

$\ce{MnO2}$ is used as a catalyst in the decomposition reaction. Catalysts provide an alternative pathway for the chemical reaction to occur. However, catalysts remain chemically unchanged; they are not consumed in the chemical reaction.

This question is categorized as medium difficulty as students are expected to recall their knowledge of catalysts for this specific chemical reaction.
