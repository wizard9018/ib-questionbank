# CH0088

When balanced, what is the sum of the correct coefficients for the following reaction?

$\ce{\_\_ LiOH(aq) + \_\_ H2SO4(aq) -> \_\_ Li2SO4(aq)  + \_\_ H2O(l)}$

- A.$\hspace{1em}$4 

- B.$\hspace{1em}$5

- C.$\hspace{1em}$6

- D.$\hspace{1em}$7

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation:}}$

The correct balanced equation is: 

$\ce{2LiOH + H2SO4 -> Li2SO4 + 2H2O}$ 

$2 + 1 + 1 + 2 = 6$
