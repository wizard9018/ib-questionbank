# CH2376

Which of the following is the correct balanced equation for the combustion of methane $(\ce{CH_4})$ in excess oxygen, including state symbols?

-   A.$\hspace{1.em}\ce{CH_4}\textrm{(g)} + 2\ce{\,O_2}\textrm{(g)} \longrightarrow \ce{CO_2}\textrm{(g)} + 2\ce{\,H_2O}\textrm{(l)}$

-   B.$\hspace{1.em}2\ce{\,CH_4}\textrm{(g)} + 3\ce{\,O_2}\textrm{(g)} \longrightarrow 2\ce{\,CO}\textrm{(g)} + 4\ce{\,H_2O}\textrm{(g)}$

-   C.$\hspace{1.em}\ce{CH_4}\textrm{(g)} + 2\ce{\,O_2}\textrm{(g)} \longrightarrow \ce{CO_2}\textrm{(g)} + 2\ce{\,H_2O}\textrm{(g)}$

-   D.$\hspace{1.em}\ce{CH_4}\textrm{(g)} + \ce{O_2}\textrm{(g)} \longrightarrow \ce{CO_2}\textrm{(g)} + 2\ce{\,H_2O}\textrm{(g)}$

---

## 评分标准 / Mark scheme

**答案：A**

$\textrm{\underline{Explanation:}}$\
Complete combustion occurs when a hydrocarbon burns in excess oxygen. The carbon is fully oxidised to $\ce{CO_2}$ and the hydrogen to $\ce{H_2O}.$ State symbols are assigned at SATP $(25\,{}^\circ\textrm{C},$ $100\textrm{ kPa}),$ so water is written as $\ce{H_2O}\textrm{(l)}.$

The general equation for complete combustion of any hydrocarbon $\ce{C}_x\ce{H}_y$ is:

$\ce{C}_x\ce{H}_y\textrm{(g)} + \left(x + \dfrac{y}{4}\right)\ce{\,O_2}\textrm{(g)} \longrightarrow x\ce{\,CO_2}\textrm{(g)} + \dfrac{y}{2}\ce{\,H_2O}\textrm{(l)}$

For methane, $x = 1$ and $y = 4$:

$\ce{C}_1\ce{H}_4\textrm{(g)} + \left(1 + \dfrac{4}{4}\right)\ce{\,O_2}\textrm{(g)} \longrightarrow 1\ce{\,CO_2}\textrm{(g)} + \dfrac{4}{2}\ce{\,H_2O}\textrm{(l)}$

$\ce{CH_4}\textrm{(g)} + 2\ce{\,O_2}\textrm{(g)} \longrightarrow \ce{CO_2}\textrm{(g)} + 2\ce{\,H_2O}\textrm{(l)}$

Note that *excess oxygen* rules out incomplete combustion, which would (also) produce $\ce{CO}$  or carbon soot.
