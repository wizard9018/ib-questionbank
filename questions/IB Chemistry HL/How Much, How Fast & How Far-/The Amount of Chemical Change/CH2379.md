# CH2379

Sulfuric acid and sodium hydroxide react according to the equation below.

$\ce{H_2SO_4}\textrm{(aq)} + 2\ce{\,NaOH}\textrm{(aq)} \longrightarrow \ce{Na_2SO_4}\textrm{(aq)} + 2\ce{\,H_2O}\textrm{(l)}$

A $250\textrm{\ cm}^3$ solution of sulfuric acid contains $0.49\textrm{\ g}$ of $\ce{H_2SO_4} \ (M_r = 98).$ This solution is completely neutralised by sodium hydroxide. Calculate the volume of $0.2\textrm{\ mol dm}^{-3}$ sodium hydroxide solution required to neutralise the acid.

-   A.$\hspace{1.em}12.5\textrm{\ cm}^3$

-   B.$\hspace{1.em}25\textrm{\ cm}^3$

-   C.$\hspace{1.em}50\textrm{\ cm}^3$

-   D.$\hspace{1.em}100\textrm{\ cm}^3$

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$\
Neutralisation problems linking mass to volume of solution follow the path:

mass $\longrightarrow$ moles $\longrightarrow$ mole ratio $\longrightarrow$ moles $\longrightarrow$ volume.

Convert the mass of $\ce{H_2SO_4}$ to moles.

$n(\ce{H_2SO_4}) = \dfrac{0.49 \textrm{\ g}}{98 \textrm{\ g mol}^{-1}} = 0.0050\textrm{\ mol}$

Apply the mole ratio. The balanced equation shows $1\textrm{\ mol } \ce{H_2SO_4}$ reacts with $2\textrm{\ mol } \ce{NaOH},$ so:

$n(\ce{NaOH}) = 0.0050\textrm{\ mol\ } \ce{H_2SO_4} \times \dfrac{2\textrm{\ mol\ } \ce{NaOH}}{1\textrm{\ mol\ } \ce{H_2SO_4}} = 0.010\textrm{\ mol\ } \ce{NaOH}$

Convert moles to volume using $V = \dfrac{n}{C}$:

$V(\ce{NaOH}) = \dfrac{0.010\textrm{\ mol}}{0.2\textrm{\ mol dm}^{-3}} = 0.050\textrm{\ dm}^3 = 50\textrm{\ cm}^3$
