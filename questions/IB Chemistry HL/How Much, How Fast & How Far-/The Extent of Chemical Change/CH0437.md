# CH0437

Which of the following are required to determine the equilibrium concentrations for a reversible reaction?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | The equilibrium constant |
  | II. | The initial concentrations of reactants and products |
  | III. | The balanced equation and equilibrium expression |

- A. $\hspace{1em}$I and II only

- B. $\hspace{1em}$I and III only

- C. $\hspace{1em}$II and III only

- D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

For the reaction $\ce{a A + b B <=> c C + d D}$,

$K_c =\dfrac{[C]^c[D]^d}{[A]^a[B]^b}$, where all concentrations are at equilibrium.

To determine the concentrations at equilibrium, the initial concentrations are used and substituted in the rearranged equation.
