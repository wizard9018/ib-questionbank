# CH0080

What is the reaction quotient of the following reaction, and in which direction will the reaction proceed?

  $\ce{N2}\textrm{(g)} + \ce{O2}\textrm{(g)} \ \ce{<=>} \ \ce{2\ NO}\textrm{(g)} \ \ \ \ \ \ K_c = 7.5 \times 10^{-9}$

| Compound | Concentration $\\$ (mol dm$^{\mathbf{-3}})$|
| :---: | :---: |
| $\ce{N2}$ | $2.0$ |
| $\ce{O2}$ | $3.0 $ |
| $\quad \ce{NO} \quad$ | $\quad 1.0 \times 10^{-3} \quad$ |

$\mbox{}$

- :::tableoptions{col1="hide"}
  | | $\quad$Reaction quotient$\quad$ | $\quad$Direction of reaction$\quad$ |
  | --- | :-: | :-: |
  | A.$\hspace{1em}$ | $\dfrac{\left(1 \times 10^{-3}\right)^{2}}{2\times3}$ | Towards the reactants |
  | B.$\hspace{1em}$ | $\dfrac{\left(1 \times 10^{-3}\right)^2}{2 \times 3}$ | Towards the products |
  | C.$\hspace{1em}$ | $\dfrac{2 \times 3}{\left(1\times 10^{-3}\right)^2}$ | Towards the reactants |
  | D.$\hspace{1em}$ | $\dfrac{2 \times 3}{\left(1\times 10^{-3}\right)^2}$ | Towards the products |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:
For a reaction $a\,\textrm{A} + b\,\textrm{B} ⇌  c\,\textrm{C} + d\,\textrm{D}$

$Q= \dfrac{[\textrm{C}]^c[\textrm{D}]^d} {[\textrm{A}]^a[\textrm{B}]^b}$

  As in this case, $Q > K_c$, the equilibrium shifts toward the reactants.
