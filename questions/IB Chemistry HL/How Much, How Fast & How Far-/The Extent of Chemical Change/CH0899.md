# CH0899

The indicator alizarin yellow (AlYH) functions according to the equilibrium below.

$\ce{\underset{\large yellow}{AlYH(aq)} <=> \underset{\large orange/red}{AlY^-(aq)} + H+(aq)}$

$K_c$ was calculated at two different temperatures:

| Temperature / K | $\mathbf{K_c}$ |
| :-: | :-: |
| 313 | $1.23\times 10^{-3}$ |
|373 | $2.75\times 10^{-4}$ |

Which of the below statements are correct?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :- | :- |
  | I. | The forward reaction is exothermic   |
  | II. | The color deepens as temperature increases |
  | III. | The color lightens on addition of sulfuric acid |

- A. $\hspace{1em}$II and III only

- B. $\hspace{1em}$I and II only

- C. $\hspace{1em}$I and III only

- D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$K_c$ decreases with increasing temperature, so the forward reaction is exothermic.

As temperature increases, the equilibrium shifts to favor the reactants (endothermic direction), making the color lighter (more yellow).

As acid $\ce{(H+)}$ is added, the equilibrium shifts to favor the reactants to oppose this change, and so the color gets lighter (more yellow).
