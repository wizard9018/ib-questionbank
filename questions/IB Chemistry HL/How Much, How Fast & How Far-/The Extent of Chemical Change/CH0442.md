# CH0442

1.0 mol of each $\ce{CH4}, \ce{H2O}$, and $\ce{CO}$ are placed in a 1.0 dm$^3$ container and allowed to equilibrate.  What is the equilibrium concentration of $\ce{H2}$ and $\ce{CO}$ if there are 0.5 mol of $\ce{H2O}$ at equilibrium?

$\ce{CH4(g) + H2O(g) <=> 3 H2(g) + CO(g)}$

- :::tableoptions{col1="hide"}
  | | $\enskip \mathbf{[H_2]} / \mathbf{mol\ dm}^{\mathbf{-3}}$ $\enskip$ | $\enskip \mathbf{[CO] / mol\, dm^{-3}} \enskip$ |
  | :-: | :-: | :-: |
  | A.$\hspace{1em}$ | 0.5 | 0.5 |
  | B.$\hspace{1em}$ | 1.5 | 0.5 |
  | C.$\hspace{1em}$ | 0.5 | 1.5 |
  | D.$\hspace{1em}$ | 1.5 | 1.5 |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

We can set up a RICE table where we insert the initial concentrations.  Using the stoichiometric ratio of the reactants and products, we can include the change that will occur as the reaction moves toward equilibrium.  The equilibrium concentrations will then be the sum of the initial concentration and the change.

|R|$\ce{CH4(g)}$ | + | $\ce{H2O(g)}$ |$\ce{<=>}$ | $\ce{3H2(g)}$ | + | $\ce{CO(g)}$|
|:-:|:-: | :-: | :-: | :-: | :-: | :-: | :-:|
$\textbf{I}$|1.0 | | 1.0 || 0.0 || 1.0 |
$\textbf{C}$|$-x$ || $-x$ || $+3x$ || $+x$
$\textbf{E}$|$1.0-x$ | | $1.0-x$ || $3x$| | $1.0+x$|

We are told that there are 0.5 mol (in 1.0 dm$^3$) of water vapor at equilibrium, so

$1.0 - x = 0.5 ; \hspace{2em} x = 0.5$

The equilibrium concentrations are [CO]$\ = 1.0 + x = 1.5$ mol dm$^{-3}$ and [$\ce{H2}$]$\ = 3x = $ 1.5 mol dm$^{-3}$
