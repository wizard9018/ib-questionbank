# CH0077

Which row of the table correctly states the changes that occur when the temperature is increased for the following reaction:

$\ce{PbO2(s) <=> PbO (s) + 1/2 O2 (g)}    \qquad\Delta \ce{H} = +ve$

- :::tableoptions{col1="hide"}
  | | $\quad$Value of the equilibrium constant | Position of equilibrium $\quad$ |
  | :-: | :-: | :-: |
  | A.$\hspace{1em}$ | Changes | Shifts towards the products |
  | B.$\hspace{1em}$ | Changes | Shifts towards the reactants |
  | C.$\hspace{1em}$ | Stays the same | $\quad$Shifts towards the products $\quad$ |
  | D.$\hspace{1em}$ | Stays the same | Shifts towards the reactants |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:
 The equilibrium shifts to favor the endothermic reaction (forward) when the temperature is increased to resist that change (Le Chatelier's principle).\
Temperature is the only factor that changes the value of the equilibrium constant.
