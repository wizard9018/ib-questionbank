# CH2369

The graph below shows the variation in amounts as a system in a $2.00 \textrm{ dm}^3$ vessel reaches equilibrium at $300 \textrm{ K}$.

$\ce{N_2}\textrm{(g)} + 2\ce{\,O_2}\textrm{(g)} \rightleftharpoons 2\ce{\,NO_2}\textrm{(g)}$

 ![CH2369](images/CH2369.png)

What is the equilibrium constant at $300 \textrm{ K}$?

- A.$\hspace{1.em}8.53$

- B.$\hspace{1.em}4.27$

- C.$\hspace{1.em}2.67$

- D.$\hspace{1.em}5.33$

---

## 评分标准 / Mark scheme

**答案：A**

$\textrm{\underline{Explanation:}}$\
The equilibrium amounts are read from the flat region of each curve:

$n(\ce{NO_2}) = 0.800 \textrm{ mol}$ $\hspace{2em}$
$n(\ce{N_2}) = 0.600 \textrm{ mol}$ $\hspace{2em}$
$n(\ce{O_2}) = 0.500 \textrm{ mol}$

These must be converted to concentrations using $C = \dfrac{n}{V}$ with $V = 2.00 \textrm{ dm}^3$:

$[\ce{NO_2}] = 0.400 \textrm{ mol dm}^{-3}$ $\hspace{2em}$ $[\ce{N_2}] = 0.300 \textrm{ mol dm}^{-3}$ $\hspace{2em}$ $[\ce{O_2}] = 0.250 \textrm{ mol dm}^{-3}$

$K = \dfrac{[\ce{NO_2}]^2}{[\ce{N_2}][\ce{O_2}]^2} = \dfrac{(0.400)^2}{(0.300)(0.250)^2} = 8.53$
