# CH0902

**Maximum mark: 9**

Chloroethanoic acid is a weak acid.

$\ce{ClCH2COOH(aq) + H2O(l) <=> ClCH2COO-(aq) + H3O+(aq)}\qquad \Delta H = -3.90\,\text{kJ mol}^{-1}$

1.  Write the $K_c$ expression for this reaction. [1 mark]

2.  25.0 g of solid anhydrous chloroethanoic acid was dissolved in 150.0 cm$^3$ distilled water at 310 K. At equilibrium, $\text{pH} = 1.65$. Calculate $K_c.$ [4 marks]

3.  Use your answer to part (bi) and Section 1 of the data booklet to calculate the entropy change, $\Delta S$, for this reaction in J K$^{-1}$ mol$^{-1}$. [3 marks]

    *(If you do not have an answer to part (b), use $K_c = 3.50\times 10^{-4}$)*.

4.  Explain how $K_c$  would change if the temperature was increased.  [1 mark]

---

## 评分标准 / Mark scheme

1.     $K_c = \dfrac{\ce{[ClCH2COO-][H3O+]}}{\ce{[ClCH2COOH]}}\,\checkmark$

    $\underline{\textrm{Further Explanation}}$:

    For the equation $\ce{a A + b B <=> c C + d D}$, $K_c = \dfrac{[\ce{C}]^c[\ce{D}]^d}{[\ce{A}]^a[\ce{B}]^b}$.

    As this reaction takes place in solution, the water is considered in a large excess and essentially constant, only the aqueous species are included in the $K_c$ expression.

2.  $n(\ce{ClCH2COOH}) = \dfrac{25.0\,\text{g}}{94.5\,\text{g mol}^{-1}} = 0.264\,\text{mol}\,\checkmark$

    $\ce{[H3O+]}_{eq} = 10^{-\text{pH}} = 10^{-1.65} = 0.0224\,\text{mol dm}^{-3}\,\checkmark$

    $n(\ce{H3O+}) = n(\ce{ClCH2COO-})  = \dfrac{0.0224\,\text{mol dm}^{-3}}{0.150\,\text{dm}^3} = 3.36\times 10^{-3}\,\text{mol}\,\checkmark$

    $[\ce{ClCH2COOH}]_{eq} = \dfrac{0.264\,\text{mol} - 3.36\times 10^{-3}\,\text{mol}}{0.150\,\text{dm}^3} =  1.74\,\text{mol dm}^{-3}\,\checkmark$

    $K_c = \dfrac{(0.0224)^2}{1.74} = 2.89\times 10^{-4}\,\checkmark$

    $\underline{\textrm{Further Explanation:}}$

    | | ClCH$\mathbf{_2}$COOH | ClCH$\mathbf{_2}$COO$\mathbf{^-}$ | H$\mathbf{_3}$O$\mathbf{^+}$ |
    | :-- | :-: | :-: | :-: |
    | Initial moles | 0.264 | 0 | 0 |
    | Change in moles | $0.264 - 3.36\times 10^{-3}$ | $+3.36\times 10^{-3}$ | $+3.36\times 10^{-3}$ |
    | Equilibrium moles | 0.261 | $3.36\times 10^{-3}$ | $3.36\times 10^{-3}$ |

    $\mbox{}\\[-15pts]$

3.  $\Delta G = -RT \ln K = - \dfrac{8.31\times 310 \ln(2.89\times 10^{-4})}{1000} = 21.0\,\text{kJ mol}^{-1}\,\checkmark$

    **OR**

    $\Delta G = -RT \ln K = - \dfrac{8.31\times 310 \ln(3.50\times 10^{-4})}{1000} = 20.5\,\text{kJ mol}^{-1}$

    $\Delta S = \dfrac{\Delta H - \Delta G}{T}\,\checkmark$

    $\Delta S = \dfrac{-3900 - 20993}{310} = -80\,\text{J K}^{-1}\,\text{mol}^{-1}\,\checkmark$

    **OR**

    $\Delta S = \dfrac{-3900 - 20500}{310} = -60\,\text{J K}^{-1}\,\text{mol}^{-1}$

    $\underline{\textrm{Further Explanation:}}$

    Using $\Delta G = -RT \ln K$, $\Delta G$ is in J mol$^{-1}$ (as units for $R$ are J K$^{-1}$ mol$^{-1}$).

    Rearranging $\Delta G = \Delta H - T \Delta S$ then allows you to calculate $\Delta S$.

    Both $\Delta H$ and $\Delta G$ must be substituted in as J mol$^{-1}$ or both $\Delta H$ and $\Delta G$ in kJ mol$^{-1}$ and then divided by 1000 to give $\Delta S$ in J K$^{-1}$ mol$^{-1}$.

 4. $K_c$ would decrease **AND** forward direction is exothermic/equilibrium shifts to the left/endothermic direction.$\checkmark$

    $\underline{\textrm{Further Explanation:}}$

    Applying Le Chatelier's Principle, the equilibrium will shift in the direction to oppose any change placed upon it. If temperature is increased, the endothermic (backward) reaction would be favored thus increasing the denominator of the $K_c$ expression and decreasing $K_c$.
