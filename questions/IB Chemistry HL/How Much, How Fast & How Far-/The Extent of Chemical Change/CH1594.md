# CH1594

Consider the following reaction.

$\ce{2 NO2(g) <=> N2O4(g)}\qquad K_c = 0.380$

What is the $K_c$ value of the following reaction at the same temperature? 

$\ce{3 N2O4(g) <=> 6 NO2(g)}$ 

$\ $

$\mbox{}\\[-20pts]$

-   A. $\hspace{1em}(0.380)^3$

-   B. $\hspace{1em}\dfrac{ 3}{0.380}$

-   C. $\hspace{1em}\dfrac{1}{(0.380)^3}$

-   D. $\hspace{1em}\dfrac{1}{3 \times 0.380}$

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:

This question requires analysis of how the value of $K_c$ changes when a reaction is reversed and the coefficients in the balanced equation are changed.

Comparing the two equations, the following two operations can be identified in the second equation.

-   coefficients in the balanced equation are multiplied by 3

-   equation has been reversed

The equilibrium constant for the first equation can be written as 

$K_c = \dfrac{\big[\ce{N_2O_4}\big]}{\big[\ce{NO_2}\big]^2}$

When the coefficients in the second equation are multiplied by 3, the equilibrium constant expression for the reaction 

$\ce{6 NO2(g) <=> 3 N2O4(g)}$

can be written as 

$K = \dfrac{\ce{[N_2O_4]^3}}{\ce{[NO_2]^6}}$

Notice that $K = K_c^3.$

When the equation is reversed,

$\ce{3 N2O4(g) <=> 6 NO2(g)}$    

the equilibrium constant expression is flipped: the numerator and the denominator change places (or the equilibrium constant for the reverse reaction is the reciprocal). This can be represented as below. 

$K = \dfrac{1}{K_c^3}$
