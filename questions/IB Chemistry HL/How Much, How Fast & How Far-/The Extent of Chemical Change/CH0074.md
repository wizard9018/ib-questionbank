# CH0074

Which statements about the equilibrium constant for a reversible reaction are correct?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | If $K_c > 1,$ the products are favoured |
  | II. | If $K_c < 1,$ the reactants are favoured |
  | III. | If $K_c = 1,$ neither products nor reactants are favoured |

- A.$\hspace{1em}$I and II only

- B.$\hspace{1em}$I and III only

- C.$\hspace{1em}$II and III only

- D.$\hspace{1em}$I, II and III

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$: \
 The value of $K_c$ depends on the reaction and the temperature at which it occurs. Products, reactants, or neither could be favored dependent on the given reaction and conditions.

For a reaction

$a\textrm{A} + b\textrm{B} ⇌  c\textrm{C} + d\textrm{D}$

 $K_c = \dfrac{[\textrm{C}]^c[\textrm{D}]^d} {[\textrm{A}]^a[\textrm{B}]^b}$

If $K_c > 1,$ this shows that the numerator value is greater than the denominator. Therefore, products are favored.

If $K_c < 1,$ this shows that the denominator value is greater than the numerator. Therefore, reactants are favored.
