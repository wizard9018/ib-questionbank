# CH0759

Which of the below gives the correct expression for $K_c$?

$\ce{\underset{orange}{Cr2O7^{2-}(aq)} + H2O(l) <=> 2 \underset{yellow}{CrO4^{2-}(aq)} + 2H+(aq)}$

$\mbox{}\\[-20pts]$

-   A.$\hspace{1em}\dfrac{[\ce{Cr2O7^{2-}}][\ce{H2O}]}{[\ce{CrO4^{2-}}] ^2[\ce{H+}]^2}$

-   B.$\hspace{1em}\dfrac{[\ce{CrO4^{2-}}]^2[\ce{H+}]^2}{[\ce{Cr2O7^{2-}}][\ce{H2O}]}$

-   C.$\hspace{1em}\dfrac{[\ce{Cr2O7^{2-}}]}{[\ce{CrO4^{2-}}]^2[\ce{H+}]^2}$

-   D.$\hspace{1em}\dfrac{[\ce{CrO4^{2-}}]^2[\ce{H+}]^2}{[\ce{Cr2O7^{2-}}]}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

For the equation, $\ce{a A + b B <=> c C + d D}$, $\ce{K_c = \dfrac{[\ce{C}]^c [\ce{D}]^d}{[\ce{A}]^a [\ce{B}]^b}}$.

Only the aqueous species are included in the $\ce{K_c}$ expression, liquid water is not included.
