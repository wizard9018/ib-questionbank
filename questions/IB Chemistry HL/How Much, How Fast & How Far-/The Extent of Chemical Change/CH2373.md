# CH2373

Which statement is correct about the equilibrium constant?

-   I.$\hspace{1em}$It depends on the temperature.
-   II.$\hspace{0.7em}$It depends on pressure.
-   III.$\hspace{0.4em}$It depends on concentrations.

- A.$\hspace{1.em}$I, II and III

- B.$\hspace{1.em}$I and II only

- C.$\hspace{1.em}$I only

- D.$\hspace{1.em}$II only

---

## 评分标准 / Mark scheme

**答案：C**

$\textrm{\underline{Explanation:}}$\
The equilibrium constant depends only on temperature.

Changing the temperature changes the value of the equilibrium constant. For an exothermic reaction, increasing temperature decreases $K$; for an endothermic reaction, increasing temperature increases $K$. Statement I is correct.

Changes in pressure may shift the position of equilibrium (if the reaction involves unequal moles of gas), but the equilibrium constant itself is unaffected. Statement II is incorrect.

Changes in concentration shift the reaction forward or backward to reachieve equilibrium, but the value of $K$ does not change. Statement III is incorrect.
