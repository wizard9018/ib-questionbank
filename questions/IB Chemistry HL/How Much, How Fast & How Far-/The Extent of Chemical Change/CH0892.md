# CH0892

Which expression below is equal to the equilibrium concentration of $\ce{[Cu(H2O)6]^2+}$?

$\ce{[Cu(H2O)6]^2+(aq) + 4 NH3(aq) <=> [Cu(H2O)2(NH3)4]^2+(aq) + 4 H2O(l)}$

-   A. $\hspace{1em}\dfrac{\ce{[[Cu(H2O)_2(NH3)_4]^2+]}}{\ce{[NH3]^{4}}{K_c}}$

-   B. $\hspace{1em}\dfrac{\ce{[[Cu(H2O)_2(NH3)_4]^{2+}][H2O]^{4}}}{\ce{[NH3]^{4}}{K_c}}$

-   C. $\hspace{1em}\dfrac{\ce{[NH3]^{4}}{K_c}}{\ce{[[Cu(H2O)_2(NH3)_4]^{2+}][H2O]^{4}}}$

-   D. $\hspace{1em}\dfrac{\ce{[NH3]^{4}}{K_c}}{\ce{[[Cu(H2O)_2(NH3)_4]^{2+}]}}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

For the general equation $\ce{a A + b B <=> c C + d D}$,

$K_c = \dfrac{[\ce{C}]^{c}[\ce{D}]^{d}}{[\ce{A}]^{a}[\ce{B}]^{b}}$

So for the equation here,

$\ce{[Cu(H2O)6]^2+(aq) + 4 NH3(aq) <=> [Cu(H2O)2(NH3)4]^2+(aq) + 4 H2O(l)}$

$K_c = \dfrac{\ce{[[Cu(H2O)2(NH3)4]^2+]}}{\ce{[[Cu(H2O)6]^2+][NH3]^4}}$

Rearranging gives:

$\ce{[[Cu(H2O)6]^2+]} = \dfrac{\ce{[[Cu(H2O)2(NH3)4]^2+]}}{K_c\ce{[NH3]^4}}$

As this equilibrium takes place in solution, the water is considered in a large excess and essentially constant. Only the aqueous species are included in the $K_c$ expression.
