# CH0760

Colorimetry was used to determine the change in color for the system below at equilibrium as temperature increases.
Which statement(s) is/are correct for the following reaction?
$\newline\ $

$\underset{\normalsize{\textrm{blue}}}{\ce{[Cu(H2O)6]^2+}} + \ce{4Cl-} \rightleftharpoons   \underset{\normalsize{\textrm{yellow}}}{\ce{[CuCl4]^2-}} \ce{+ 6H2O}$

$\mbox{}\\[-40pts]$

$\newline \ $
| Temperature (K) | Wavelength (nm) |
| :-: | :-: |
| 280 | 665 |
| 300 | 652 |
| 320 | 649 |
| 340 | 636 |

- I.$\hspace{1em}$The forward reaction is exothermic.
- II.$\hspace{.7em}$The backward reaction absorbs energy.
- III.$\hspace{.4em}K$ decreases with increasing temperature.

- A.$\hspace{1em}$I only

- B.$\hspace{1em}$II only

- C.$\hspace{1em}$I and III only

- D.$\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation}}$:\
At low temperature, the solution absorbs the highest wavelength red light and should appear yellow$-$green.  At higher temperature, the solution absorbs orange light and should appear blue.  As temperature increases, the equilibrium shifts to the left hand side. The backward reaction is therefore endothermic and absorbs energy, whereas the forward reaction is exothermic. As equilibrium shifts to the left, $K$ decreases as the temperature increases.
