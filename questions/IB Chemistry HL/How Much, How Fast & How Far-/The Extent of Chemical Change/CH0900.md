# CH0900

Ethanamine is a weak base.

$\ce{CH3CH2NH2(aq) + H2O(l) <=> CH3CH2NH3+(aq) + OH-(aq)}\qquad K = 0.12$

At a point in a reaction, concentrations were found to be $\ce{[CH3CH2NH2]} = 0.5\,\text{mol dm}^{-3}$, $\ce{[CH3CH2NH3+]} = 0.1\,\text{mol dm}^{-3}$, and $\ce{[OH-]} = 1.0\,\text{mol dm}^{-3}$.

Which row is correct as the reaction proceeds at a constant temperature?

-   :::tableoptions{col1="hide"}
    | | pH | shift |
    | :-: | :-: | :-: |
    | A. | Increases | Forward |
    | B. | Increases | Backward |
    | C. | Decreases | Forward |
    | D. | Decreases | Backward |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$: \
The reaction quotient is:

$Q = \dfrac{\ce{[CH3CH2NH3+][OH-]}}{\ce{[CH3CH2NH2]}} = \dfrac{(0.1)(1.0)}{0.5} = 0.2$

$Q > K$, which means that the reaction will proceed in the backward direction as it approaches equilibrium.

This would reduce the $\ce{OH-}$ concentration and decrease the pH.
