# CH0211

Which of the following refers to the conditions for the standard enthalpy change measurements?

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :-- | :-- |
  | I. | $298 \textrm{\ K}$ |
  | II. | $100 \textrm{\ kPa}$ |
  | III.$\hspace{1em}$ | Concentrations of $1 \textrm{\ mol dm}^{-3}$ for all solutions |

- A.$\hspace{1em}$ I, II and III

- B.$\hspace{1em}$ II and III only

- C.$\hspace{1em}$ I and II only

- D.$\hspace{1em}$ III only

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:\
Standard enthalpy changes are measured under the following conditions:
- $100 \textrm{\ kPa}$
- Concentrations of $1 \textrm{\ mol dm}^{-3}$ for all solutions
- Substances in their standard state

Typically, reactions are set to occur at $298 \textrm{\ K}$ but it is not required.  For example, in biology, it is common to use a reference temperature of 310 K.
