# CH0312

Which row represents the enthalpy change for condensation and sublimation phase changes?

- :::tableoptions{col1="hide"}

  |  |Condensation|Sublimation| 

  |:-:|:-:|:-:|

  |A.$\hspace{1em}$|Endothermic|Exothermic

  |B.$\hspace{1em}$|Endothermic|Endothermic

  |C.$\hspace{1em}$|Exothermic|Exothermic

  |D.$\hspace{1em}$|Exothermic|Endothermic

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$

Condensation (gas $\longrightarrow$ liquid) involves particles coming closer together as intermolecular forces are formed. This process releases energy to the surroundings because the system becomes more stable as these attractive forces develop.

Sublimation (solid $\longrightarrow$ gas) requires overcoming intermolecular forces completely to separate particles into the gaseous state. This requires an input of energy, which is absorbed from the surroundings.
