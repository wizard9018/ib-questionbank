# CH1193

Consider the Born-Haber cycle below.

![CH1193](images/CH1193.png)

Which calculation represents the lattice enthalpy of $MX_{2}$?

- A. $\hspace{1em}\ce{- F + G + H + I + J + K}$

- B. $\hspace{1em}\ce{- F + G + H + I + J - K}$

- C. $\hspace{1em}\ce{- F + G + H + I + J + K - L}$

- D. $\hspace{1em}\ce{- G - H - I - J - K + L}$

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation}}$:

Lattice enthalpy is defined as the standard enthalpy change that takes place when gaseous ions are formed from one mole of formulae units of an ionic compound.

In the given Born-Haber cycle, L represents the lattice enthalpy as it represents this change.

$\ce{MX2(s) -> M^2+(g) + 2 X^-(g)}$

The value of L can be determined with the cycle, as shown below in red.

![CH1193Ans](images/CH1193Ans.png)

Except for L, all the enthalpies should be added except for F, which should be reversed.

This question is categorized as medium difficulty as students must recall what is meant by lattice enthalpy and should interpret the Born-Haber cycle presented to determine the expression for its calculation.
