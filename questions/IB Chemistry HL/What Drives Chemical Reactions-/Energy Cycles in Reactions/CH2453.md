# CH2453

Consider the chemical equations below.

$\ce{F} + \ce{G} \longrightarrow \ce{H}$|$\Delta H^{\minuso} = +273\textrm{ kJ mol}^{-1}$
:-:|:--
$2\ce{\,G} + 2\ce{\,I} \longrightarrow 6\ce{\,J} $|$ \Delta H^{\minuso} = -120\textrm{ kJ mol}^{-1}$

What is the correct expression for the enthalpy change, in $\textrm{kJ mol}^{-1},$ for $\ce{H} + \ce{I} \longrightarrow 3\ce{\,J} + \ce{F}?$

-   A.$\hspace{1.em}273 + \frac{1}{2} ( 120)$

-   B.$\hspace{1.em}2 ( 273 ) + 120$

-   C.$\hspace{1.em}-120 + 2  (-273)$

-   D.$\hspace{1.em}\frac{1}{2}(-120) + (-273)$

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$\
The target reaction has $\ce{H}$ as a reactant. In the first given equation, $\ce{H}$ is a product. Reversing the first equation changes the sign of $\Delta H:$

$\ce{H} \longrightarrow \ce{F} + \ce{G} \hspace{3em} \Delta H = -273\textrm{ kJ mol}^{-1}$

The target produces $3\ce{\,J},$ but the second equation produces $6\ce{\,J}.$ Halving the second equation halves $\Delta H:$

$\ce{G} + \ce{I} \longrightarrow 3\ce{\,J} \hspace{3em} \Delta H = \frac{1}{2}(-120 \textrm{\ kJ mol}^{-1})$

Adding the two modified equations:

$\ce{H} + \ce{I} \longrightarrow 3\ce{\,J} + \ce{F}$

$\Delta H = \frac{1}{2}(-120) -273    = -333\textrm{ kJ mol}^{-1}$

Two key rules apply when manipulating thermochemical equations. Reversing a reaction changes the sign of $\Delta H.$ Multiplying (or dividing) the coefficients by a factor applies the same factor to $\Delta H.$ Both rules follow from Hess's law: the enthalpy change depends only on the initial and final states.
