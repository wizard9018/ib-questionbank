# CH2484

The Born$-$Haber cycle for $\ce{BaF2}$ is shown below.

![CH2484](images/CH2484.png)

What is the lattice enthalpy, in $\textrm{kJ mol}^{-1},$ of $\ce{BaF2}?$

-   A.$\hspace{1.em}-1200 + 180 + 159 + 503 + 965 - 656$

-   B.$\hspace{1.em}1200 + 180 + 159 + 503 + 965 - 656$

-   C.$\hspace{1.em}1200 + 180 + 159 + 503 + 965 + 656$

-   D.$\hspace{1.em}-1200 + 180 + 159 + 503 + 965 + 656$

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$\
The lattice enthalpy is the enthalpy change for:

$\ce{BaF2}\textrm{(s)} \longrightarrow \ce{Ba^{2+}}\textrm{(g)} + 2\ce{\,F-}\textrm{(g)}$

By Hess's law, the Born$-$Haber cycle provides an alternative route from $\ce{BaF2}\textrm{(s)}$ to the gaseous ions. The enthalpy of formation takes the elements to the compound, so reversing it takes the compound back to the elements. From the elements, the remaining steps convert them to gaseous ions:

| $\mathbf{Step}$ | $\mathbf{\Delta H\textbf{ / kJ mol}^{-1}}$ |
|:--|:-:|
| $\ce{BaF2}\textrm{(s)} \longrightarrow \cancel{\ce{Ba}\textrm{(s)}} + \cancel{\ce{F2}\textrm{(g)}}$ | $+1200$ |
| $\cancel{\ce{Ba}\textrm{(s)}} \longrightarrow \cancel{\ce{Ba}\textrm{(g)}}$ | $+180$ |
| $\cancel{\ce{F2}\textrm{(g)}} \longrightarrow \cancel{2\ce{\,F}\textrm{(g)}}$ | $+159$ |
| $\cancel{\ce{Ba}\textrm{(g)}} \longrightarrow \cancel{\ce{Ba+}\textrm{(g)}} + \cancel{\ce{e^-}}$ | $+503$ |
| $\cancel{\ce{Ba+}\textrm{(g)}} \longrightarrow \ce{Ba^{2+}}\textrm{(g)} + \cancel{\ce{e^-}}$ | $+965$ |
| $\cancel{2\ce{\,F}\textrm{(g)}} + \cancel{2\ce{\,e^-}} \longrightarrow 2\ce{\,F-}\textrm{(g)}$ | $-656$ |

Summing all steps:

$\Delta H_{latt}^{\minuso} = (1200 + 180 + 159 + 503 + 965 - 656)\textrm{ kJ mol}^{-1} = 2351\textrm{ kJ mol}^{-1}$
