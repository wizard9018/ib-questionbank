# CH1260

Consider the enthalpies of formation in the table below.

| Substance | $\mathbf{\Delta H^{\minuso}_f / kJ\, mol^{-1}}$ |
| :-: | :-: |
| $\ce{SiCl4(l)}$ | $-640$ |
| $\ce{SiO2(s)}$ | $-911$ |
| $\ce{HCl(aq)}$ | $-167$ |
| $\ce{HCl(g)}$ | $-92$ |
| $\ce{H2O(l)}$ | $-286$ |
| $\ce{H2O(g)}$ | $-242$ |

What is the standard enthalpy change for the chemical reaction below?
$\\[10pts]$

$\ce{SiCl4(l) + 2 H2O(l) -> SiO2(s) + 4 HCl(g)}$

-   A. $\hspace{1em}-67\,\text{kJ mol}^{-1}$

-   B. $\hspace{1em}+69\,\text{kJ mol}^{-1}$

-   C. $\hspace{1em}-78\,\text{kJ mol}^{-1}$

-   D. $\hspace{1em}-155\,\text{kJ mol}^{-1}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

The standard enthalpy change for the reaction is:

$\begin{aligned}
\Delta H^{\minuso}_R &= \sum \Delta H^{\minuso}_f \text{of products} - \sum \Delta H^{\minuso}_f \text{of reactants} \\
\Delta H^{\minuso}_R &= \sum \Delta H^{\minuso}_f\,\ce{SiO2(s)} + (4)\sum \Delta H^{\minuso}_f\,\ce{HCl(g)} - \sum \Delta H^{\minuso}_f\,\ce{SiCl4(l)} - (2)\sum \Delta H^{\minuso}_f\,\ce{H2O(l)}
\end{aligned}$

$\\[10pts]$

| Substance | $\mathbf{\Delta H^{\minuso}_f / kJ\, mol^{-1}}$ |
| :-: | :-: |
| $\ce{SiCl4(l)}$ | $-640$ |
| $\ce{SiO2(l)}$ | $-911$ |
| $\sout{\ce{HCl(aq)}}$ | $\sout{-167} $ |
| $\ce{HCl(g)}$ | $-92$ |
| $\ce{H2O(l)}$ | $-286$ |
| $\sout{\ce{H2O(g)}}$ | $\sout{-242}$ |

$\Delta H^{\minuso}_R = (-911) + 4 (-92) - (-640 + 2(-286)) = -67\,\text{kJ mol}^{-1}$

This question is categorized as easy as students must use the data given (only those with correct states of matter) and apply the equation for the enthalpy change determination.
