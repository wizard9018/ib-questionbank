# CH0162

Refer to the Born$\text{--}$Haber cycle for potassium chloride below

![CH0162](images/CH0162.png)

Which expression represents the lattice enthalpy in kJ mol$^{-1}$?

-   A.$\hspace{1em}- 438 + 89 + 122 + 419 - 355$

-   B.$\hspace{1em}438 + 89 + 122 + 419 - 355$

-   C.$\hspace{1em}- 438 + 89 + 122 + 419 + 355$

-   D.$\hspace{1em}438 + 89 + 122 + 419 + 355$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

By applying Hess's Law, the enthalpy change is independent of the route taken.

![CH0162ans](images/CH0162ans.png)

$\begin{aligned}
\Delta H_{latt}(\ce{KCl}) &= -\Delta H_f(\ce{KCl}) + \Delta H_{atom}(\ce{K}) + \Delta H_{IE}(\ce{K}) + \Delta H_{atom}(\ce{Cl2}) + \Delta H_{EA}(\ce{Cl}) \\
\Delta H_{latt}(\ce{KCl}) &=  438 + 89 + 419 + 122 - 355
\end{aligned}$
