# CH0938

Which reaction has a positive entropy change?

-   A. $\hspace{1em}\ce{CaCO3(s) -> CaO(s) + CO2(g)}$

-   B. $\hspace{1em}\ce{N2(g) + O2(g) -> 2 NO(g)}$

-   C. $\hspace{1em}\ce{Ag+(aq) + Cl-(aq) -> AgCl(s)}$

-   D. $\hspace{1em}\ce{2 SO2(g) + O2(g) -> 2 SO3(g)}$

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation:}}$\
Entropy increases when a system becomes more disordered. In a chemical reaction, two key indicators of a positive $\Delta S$ are:
-   An increase in the number of moles of gas from reactants to products.
-   A solid dissolving or melting, freeing particles to move more randomly.

Considering each reaction:

-   $\ce{CaCO3(s) -> CaO(s) + CO2(g)}$:\
    Moles of gas increase from 0 to 1, so $\Delta S > 0.$

-   $\ce{N2(g) + O2(g) -> 2 NO(g)}$:\
    Moles of gas remain at 2, so $\Delta S \approx 0.$

-   $\ce{Ag+(aq) + Cl-(aq) -> AgCl(s)}$:\
    Aqueous ions form a solid precipitate, so $\Delta S < 0.$

-   $\ce{2 SO2(g) + O2(g) -> 2 SO3(g)}$:\
    Moles of gas decrease from 3 to 2, so $\Delta S < 0.$
