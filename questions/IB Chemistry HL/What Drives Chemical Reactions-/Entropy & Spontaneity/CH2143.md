# CH2143

What is the entropy change for the reaction below?

$\ce{H2(g) + I2(g) <=> 2 HI(g)}$

$\ $

| Substance | S$^{\minuso}$ / J K$^{\mathbf{-1}}$ mol$^\mathbf{-1}$ |
| :-: | :-: |
| $\ce{H2(g)}$ | 131 |
| $\ce{I2(g)}$ | 261 |
| $\ce{HI(g)}$ | 206 |

-   A. $\hspace{1em}131 + 261 - 2\times 206$

-   B. $\hspace{1em}2\times 206 - 131 - 261$

-   C. $\hspace{1em}131 + 261 - 206$

-   D. $\hspace{1em}206 - 131 - 261$

---

## 评分标准 / Mark scheme

**答案：B**

$\textrm{\underline{Explanation:}}$

The student must deduce the change in entropy, as shown below.

$\Delta S^{\minuso} = \sum S^{\minuso}_{products}- \sum S^{\minuso}_{reactants}$

$\Delta S^{\minuso}=2S^{\minuso}_\ce{HI} -S^{\minuso}_\ce{H2} - S^{\minuso}_\ce{I2}$

$\Delta S^{\minuso} = 2\times 206 - 131 - 261$

This question is categorized as easy as the student must apply the absolute entropy values to deduce an overall entropy change for the reaction.
