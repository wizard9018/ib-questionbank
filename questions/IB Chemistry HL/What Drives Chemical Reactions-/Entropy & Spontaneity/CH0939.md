# CH0939

Calculate the standard entropy change for the halogenation of methane to form chloromethane, given the data in the table below:

| Substance| S$\mathbf{^{\minuso}}$ / J K$\mathbf{^{-1}}$mol$\mathbf{^{-1}}$ |
| :-:| :-: |
| $\ce{CH4}\textrm{(g)}$ | $186$ |
| $\ce{CH3Cl}\textrm{(g)}$ | $235$ |
| $\ce{HCl}\textrm{(g)}$ | $187$ |
| $\ce{Cl2}\textrm{g)}$ | $223$ |

-   A. $\hspace{1em}13\,\text{J K}^{-1}\,\text{mol}^{-1}$

-   B. $\hspace{1em}-13\,\text{J K}^{-1}\,\text{mol}^{-1}$

-   C. $\hspace{1em}243\,\text{J K}^{-1}\,\text{mol}^{-1}$

-   D. $\hspace{1em}- 243\,\text{J K}^{-1}\,\text{mol}^{-1}$

---

## 评分标准 / Mark scheme

**答案：A**

$\underline{\textrm{Explanation:}}$

The equation for the reaction is:

$\ce{CH4}\textrm{(g)} + \ce{Cl2}\textrm{(g)} \longrightarrow \ce{CH3Cl}\textrm{(g)} + \ce{HCl}\textrm{(g)}$

The change in entropy is calculated as the difference in the absolute entropies of the products and reactants.

$\Delta S^{\minuso} = \sum \Delta S^{\minuso}_{products} - \sum \Delta S^{\minuso}_{reactants}$

$\Delta S^{\minuso} = (235 + 187) - (186 + 223)= $ :answer[**$13\,\text{J K}^{-1}\,\text{mol}^{-1}$**]
