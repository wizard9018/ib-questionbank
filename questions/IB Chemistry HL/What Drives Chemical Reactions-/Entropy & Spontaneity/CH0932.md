# CH0932

Which statements are true for the following reaction?
$\newline \ $

$\ce{Cl2(g) -> 2 Cl(g)}\qquad \Delta H = + 242\,\text{kJ mol}^{-1}$

- :::tableoptions{col1="hide" col2="hide"}
  | | |
  | :- | :- |
  | I. | The entropy of the system is increasing. |
  | II. | Its standard enthalpy of atomization is 121 kJ mol$^{-1}.$ |
  | III. | The temperature of the surroundings will decrease. |

- A. $\hspace{1em}$I and II only

- B. $\hspace{1em}$I and III only

- C. $\hspace{1em}$II and III only

- D. $\hspace{1em}$I, II, and III

---

## 评分标准 / Mark scheme

**答案：D**

$\underline{\textrm{Explanation:}}$\
Statement I is correct because there is an increase in the system's entropy when 1 mole of gas is converted to 2 moles of gas.

Statement II is correct because when one mole of gaseous atoms forms from an element under standard conditions, it is known as the standard enthalpy of atomization, which is half the bond enthalpy value in this case.

Lastly, statement III is correct because the $\Delta H$ value indicates that this reaction is endothermic, absorbing energy as it progresses. This will cause a decrease in the temperature of the surroundings.
