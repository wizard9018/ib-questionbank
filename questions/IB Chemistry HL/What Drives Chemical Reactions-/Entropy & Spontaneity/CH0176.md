# CH0176

Which expression represents the entropy change in $\textrm{J K}^{-1}\textrm{ mol}^{-1}$ for the following reaction:

$\ce{CaCO3(s) -> CaO(s) + CO2(g)}$

-   :::tableoptions{}
    | Compound | S$^\ominus$ $\newline$ (J mol$^\mathbf{-1}$ K$^\mathbf{-1}$) |
    | :---: | :---: |
    | $\ce{CaCO3}$ | $+93$ |
    | $\ce{CaO}$ | $+38$ |
    | $\ce{CO2}$ | $+214$ |

-   A.$\hspace{1em} 93 - 38 - 214$

-   B.$\hspace{1em} 93 + 38 + 214$

-   C.$\hspace{1em} -93 + 38 + 214$

-   D.$\hspace{1em} -93 - 38 - 214$

---

$\underline{\textrm{Explanation}}$:

$\Delta S_{reaction} = \sum \Delta S_{products} - \sum \Delta S_{reactants}$
