# CH1534

Which reaction has the greatest increase in entropy? 

 

- A.$\hspace{1em}\ce{Na2CO3}\textrm{(s)} \longrightarrow$ Na$_2$O(s) + CO$_2$(g)

- B.$\hspace{1em}\textrm{N}_2\textrm{(g)} + 3\  \textrm{H}_2\textrm{(g)} \longrightarrow 2\ \textrm{NH}_3\textrm{(g)}$ 

- C.$\hspace{1em}2 \textrm{\ SO}_2\textrm{(g)} + \textrm{O}_2\textrm{(g)} \longrightarrow 2 \textrm{\ SO}_3\textrm{(g)}$

- D.$\hspace{1em}2 \ \ce{H2O}\textrm{(l)} \longrightarrow \ce{O_2}\textrm{(g)} + 2 \ \ce{H2}\textrm{(g)}$

---

## 评分标准 / Mark scheme

**答案：D**

 $\underline{\textrm{Explanation}}$: \

The student must understand that entropy depends on the number of ways the available energy can be distributed among the particles in the system. Entropy is associated with the disorder of the system and $S_{solid} \lt S_{liquid} \ll S_{gas}$.

To predict the entropy change sign, we can think about it in terms of disorder. An increase in the number of moles of gas produces an increase in the entropy, $\Delta S \gt 0$.

Let's examine the given options:

||||||

| :-: | --: | :-: | :-- | :-: 

||Na$_2$CO$_3$(s)      | $\longrightarrow$ |Na$_2$O(s) + CO$_2$(g)|

|  |     0 mol gas   |     | 1 mol gas | $\Delta S > 0$

| $\textrm{\footnotesize{\ } }$

||$\textrm{N}_2\textrm{(g)} + 3\  \textrm{H}_2\textrm{(g)}$     | $\longrightarrow$ |$2\ \textrm{NH}_3\textrm{(g)}$|

|  |     4 mol gas   |     | 2 mol gas | $\Delta S < 0$

| $\textrm{\small{\ } }$

||$2 \textrm{\ SO}_2\textrm{(g)} + \textrm{O}_2\textrm{(g)}$     | $\longrightarrow$ |$2 \textrm{\ SO}_3\textrm{(g)}$|

|  |     3 mol gas   |     | 2 mol gas | $\Delta S < 0$

| $\textrm{\small{\ } }$

||$2 \ \ce{H2O}\textrm{(l)}$   | $\longrightarrow$ |$\ce{O_2}\textrm{(g)} + 2 \ \ce{H2}\textrm{(g)}$|

|  |     0 mol gas   |     | 3 mol gas | $\Delta S > 0$

During the decomposition of water, more moles of gas are formed, meaning a greater entropy change.

This question is categorized as medium as the student must compare changes in the number of moles of gas and correlate them with the change in entropy of a reaction.
