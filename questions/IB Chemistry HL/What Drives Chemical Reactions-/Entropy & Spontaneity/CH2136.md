# CH2136

The following data is given for a chemical reaction.

$\Delta H=-10\textrm{\ kJ mol}^{-1} \hspace{2.em} \Delta S=-50\textrm{\ J\,K}^{-1}\textrm{mol}^{-1}$

Which statement is correct?

-   A.$\hspace{1.em}$The reaction is spontaneous at any temperature.

-   B.$\hspace{1.em}$The reaction is spontaneous above 0.2 K.
-   C.$\hspace{1.em}$The reaction is spontaneous above 200 K.
-   D.$\hspace{1.em}$The reaction is spontaneous below 200 K.

---

## 评分标准 / Mark scheme

**答案：D**

$\textrm{\underline{Explanation:}}$ \
The student must understand that reactions are spontaneous if $\Delta G<0.$
The temperature range where the reaction is spontaneous can be deduced from this inequality:

$\Delta G=\Delta H-T\Delta S < 0$

$-10 \textrm{\ kJ mol}^{-1} \times -T(-50\textrm{\ J\,K}^{-1}\textrm{mol}^{-1})<0 $

Converting from kJ to J, and rearranging,

$T <\dfrac{10000 \textrm{\ J mol}^{-1}}{50 \textrm{\ J\,mol}^{-1}\textrm{K}^{-1}} = 200 \textrm{\ K}$

This question is categorized as hard as the student must be careful with the calculations and the units to deduce the correct temperature condition.
