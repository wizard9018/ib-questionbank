# CH0171

Which of the following reactions will have the greatest decrease in entropy?

- A.$\hspace{1em}\ce{N2(g) + 3 H2(g) -> 2 NH3(g)}$

- B.$\hspace{1em}\ce{H2(g) + I2(g) -> 2 HI(g)}$

- C.$\hspace{1em}\ce{2 SO2(g) + O2(g) -> 2 SO3(g)}$

- D.$\hspace{1em}\ce{N2(g) + O2(g) -> 2 NO(g)}$

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

A has the greatest decrease in number of moles of gas $(\ce{4 -> 2})$.
