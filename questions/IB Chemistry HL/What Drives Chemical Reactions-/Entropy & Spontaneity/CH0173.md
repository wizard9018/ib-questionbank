# CH0173

Which of the following combinations of $\Delta H$ and $\Delta S$ results in the most spontaneous reaction at $298\,\text{K}$?

- :::tableoptions{col1="hide"}
  | | $\enskip \Delta H\enskip$ | $\enskip \Delta S\enskip$ |
  | :-: | :-: | :-: |
  | A.$\hspace{1em}$ | $+\,ve$ | $+\,ve$ |
  | B.$\hspace{1em}$ | $+\,ve$ | $-\,ve$ |
  | C.$\hspace{1em}$ | $-\,ve$ | $+\,ve$ |
  | D.$\hspace{1em}$ | $-\,ve$ | $-\,ve$ |

---

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:

$\Delta G = \Delta H - T\Delta S$

Negative $\Delta H$ values result in spontaneous reactions.

Negative $\Delta H$ and positive $\Delta S$ values result in a negative $\Delta G$ value at all temperatures.
