# CH2021

Which reaction causes the greatest increase in entropy in the system?

-   A. $\hspace{1em}$condensation

-   B. $\hspace{1em}$sublimation

-   C. $\hspace{1em}$deposition

-   D. $\hspace{1em}$vaporization

---

## 评分标准 / Mark scheme

**答案：B**

$\underline{\textrm{Explanation:}}$

The student must understand the changes in the state of matter to identify the one with the greatest change in the system's entropy.
The entropy is associated with the disorder of the system, so we can summarize that states of matter of a substance can be compared as shown below.

$S_\text{solid} < S_\text{liquid} \ll S_\text{gas}$

The entropy is greater as particles are freer.
The changes described are given below.

| Phase change | Reaction | Entropy change |
| :-: | :-: | :-: |
| condensation | $\ce{A(g) -> A(l)}$ | $\Delta S < 0$ |
| sublimation | $\ce{A(s) -> A(g)}$ | $\Delta S > 0$ |
| deposition | $\ce{A(g) -> A(s)}$ | $\Delta S < 0$ |
| vaporization | $\ce{A(l) -> A(g)}$ | $\Delta S > 0$ |

The greatest increase occurs for that with the most positive change in entropy $(\Delta S).$
It corresponds to the sublimation because the entropy is additive, the total entropy change for sublimation is the sum of the positive entropy change for melting and the positive entropy change for vaporization. It must be more positive than the entropy change of vaporization alone.

This question is categorized as a medium as the student must identify the changes in the state of matter.
