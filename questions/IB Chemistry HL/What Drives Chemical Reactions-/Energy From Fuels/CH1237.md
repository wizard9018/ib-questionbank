# CH1237

Commercial hydrogen fuel cells are used to convert chemical energy into electrical energy directly. Which are the chemical reactions taking place at each electrode?

- :::tableoptions{col1="hide" col2="hide" col3="hide"}
  | | |  |
  | :-- | :-- | :-- |
  | A. | Anode: | $\ce{2 H+(aq) + 2 e- -> H2(g)}$ |
  |  | Cathode: | $\ce{2 H2O(l) -> O2(g) + 4 H+(aq) + 4 e-}$ |
  | | |  |
  | B. | Anode: | $\ce{2 H+(aq) + 2 e- -> H2(g)}$ |
  |  | Cathode: | $\ce{O2(g) + 4 H+(aq) + 4 e- -> 2 H2O(l)}$ |
  | | |  |
  | C. | Anode: | $\ce{H2(g) -> 2 H+(aq) + 2 e-}$ |
  |  | Cathode: | $\ce{O2(g) + 4 H+(aq) + 4 e- -> 2 H2O(l)}$ |
  | | |  |
  | D. | Anode: | $\ce{H2(g) -> 2 H+(aq) + 2 e-}$ |
  |  | Cathode: | $\ce{2 H2O(l) -> O2(g) + 4 H+(aq) + 4 e-}$ |

---

## 评分标准 / Mark scheme

**答案：C**

$\underline{\textrm{Explanation}}$:\
The hydrogen fuel cell is an electrochemical cell that uses hydrogen as fuel. Combining hydrogen with oxygen produces water and releases chemical energy that is converted to electrical energy.

Hydrogen gas is oxidized at the anode, and electrons move through a proton exchange membrane that selectively allows hydrogen ions to diffuse from the anode to the cathode. At the cathode, oxygen gets reduced in the presence of hydrogen ions, and water is formed.
