# FA0139

[Note maximale : 15\] 

**Utilisez, en fonction des propositions, le type de texte le plus $\textbf{appropri\'{e}}$. $\textbf{\'{E}crivez}$ entre 30 et 60 mots.**

Vous $\text{\^{e}}$tes en vacances et vous participez $\text{\`{a}}$ une activit$\text{\'{e}}$ int$\text{\'{e}}$ressante. Vous voulez encourager les jeunes de votre ville $\text{\`{a}}$ essayer cette activit$\text{\'{e}}$. $\text{\'{E}}$crivez un texte pour pr$\text{\'{e}}$senter cette activit$\text{\'{e}}$.

| $\textrm{Annonce publicitaire}$ | $\textrm{Courriel}$ | $\textrm{Message}$ |

| :-----------------------------: | :-----------------: | :----------------: |

|          $\hspace{9em}$         |    $\hspace{9em}$   |   $\hspace{9em}$   |

**Conventions du type de texte** :

**Annonce publicitaire** : titre accrocheur (catchy title) + slogan + phrases courtes (short sentences) + appel $\text{\`{a}}$ l'action (call to action) + informations pratiques (practical information): lieu (venue), heure (time) + informations de contact (contact information): email, site internet (website), num$\text{\'{e}}$ro de t$\text{\'{e}}$l$\text{\'{e}}$phone (phone number), etc. + images.

**Courriel** : exp$\text{\'{e}}$diteur (sender) + destinataire (recipient) + objet (subject line) + salutations de d$\text{\'{e}}$but (opening salutation) + corps du courriel (email body) + formule de fin (closing salutation) + signature.

**Message** : salutations de d$\text{\'{e}}$but (opening salutation) + nom du destinataire (recipient's name) + corps du message (message body) + salutations de fin (closing salutation) + signature.

$\underline{\textrm{Marking Criteria Feedback}}$

**Criterion A (Language)**:

* Use the present tense to describe the activity: *c'est une activit$\textit{\'{e}}$ amusante, c'est facile $\textit{\`{a}}$ apprendre*.

* Use the imperative to engage the reader: *d$\textit{\'{e}}$couvre, viens essayer*.

* Use adjectives to develop ideas: *amusante, sportive, facile*.

* Common errors include incorrect verb forms (*viens* not *vient*) or missing infinitive after modal structures (*facile $\textit{\`{a}}$ apprendre*).

**Criterion B (Message)**:

* There is one content point only: presenting a holiday activity.

* A strong response includes:\

  $1.\hspace{1em}$the activity (*le surf*)\

  $2.\hspace{1em}$at least one detail (*tous les jours, $\textit{\`{a}}$ la plage centrale*)\

  $3.\hspace{1em}$simple development (*amusante, sportive, facile $\textit{\`{a}}$ apprendre*).

* The model answer include these: $\text{\textquotedblleft}$Tous les jours $\text{\`{a}}$ la plage centrale... activit$\text{\'{e}}$ amusante et sportive... facile $\text{\`{a}}$ apprendre”.

* Use *et* to add ideas.

* Weak answers only mention the activity without adding detail or development, or include very short sentences without connectors.

**Criterion C (Conceptual understanding**):

* **Annonce publicitaire** is the most appropriate text type. The audience is a wide public, and the purpose is to promote an activity. A good advert includes: a title (*D$\textit{\'{e}}$couvre le surf cet $\textit{\'{e}}$t$\textit{\'{e}}$ !*), a slogan (*Surf, soleil et sensations fortes !*), practical details (*Tous les jours,10h, plage centrale*), contact information (*surf@ville.com*), and a call to action (*$\textit{\`{A}}$ ne pas manquer !)*.

* **Message** is generally appropriate. It allows informal communication and encouragement, but it is usually directed to one person or a small group, not a wide public.

* **Courriel** is generally inappropriate because the message is not addressed to one specific person.
