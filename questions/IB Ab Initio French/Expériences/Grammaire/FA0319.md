# FA0319

**Complete the sentences. Use the correct perfect tense form of each verb in brackets.** [3 marks]

Pendant leurs vacances $\text{\`{a}}$ Nantes, $\text{In\`{e}s}$ et sa soeur **\[-1-]** *(arriver)* le vendredi. Le lendemain, elles **\[-2-]** *(voir)* une exposition. Leur cousin Malik **\[-3-]** *(venir)* les retrouver le dimanche.

**The sentence below contains one perfect tense error. Find the error and write the correct words.**

$4.$ $\hspace{1em}$Pendant le $\text{s\'{e}jour}$, tu n’es pas $\text{nag\'{e}}$ dans la piscine.    [1 mark]

**The sentences below each contain one perfect tense error. The errors are underlined. Write the correct words.**

$5.$ $\hspace{1em}\text{Apr\`{e}s}$ le voyage, mes amies $\underline{\textrm{ont retourn\'{e}es}}$ chez elles.    [1 mark]

$6.$ $\hspace{1em}\text{\`{A}}$ la plage, vous $\underline{\textrm{\^{e}tes jou\'{e}}}$ au volley.    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{sont arriv\'{e}es}$    [1 mark]

* *Arriver* takes *$\textit{\^{e}tre}$*. *$\textit{In\`{e}s}$ et sa soeur* refers to *elles*, so it requires *sont*. *$\textit{Arriv\'{e}es}$* agrees with the feminine plural subject.

$2.$ $\hspace{1em}$ $\textrm{ont vu}$    [1 mark]

* *Voir* takes *avoir*. *Elles* refers to $\text{In\`{e}s}$ and her sister, so it requires *ont*. The irregular past participle is *vu*.

$3.$ $\hspace{1em}$ $\textrm{est venu}$    [1 mark]

* *Venir* takes *$\textit{\^{e}tre}$*. *Leur cousin Malik* refers to *il*, so it requires *est*. The irregular past participle *venu* is masculine singular.\

  \

  **Model answer**:  Pendant leurs vacances $\text{\`{a}}$ Nantes, $\text{In\`{e}s}$ et sa $\text{s\oeur}$ sont $\text{arriv\'{e}es}$ le vendredi. Le lendemain, elles ont vu une exposition. Leur cousin Malik est venu les retrouver le dimanche.

$4.$ $\hspace{1em}$ $\textrm{as}$    [1 mark]

* *Nager* takes *avoir*. The subject *tu* requires *as*.\

  \

  **Model answer**: Pendant le $\text{s\'{e}jour}$, tu n'as pas $\text{nag\'{e}}$ dans la piscine.

$5.$ $\hspace{1em}$ $\textrm{sont retourn\'{e}es}$    [1 mark]

* *Retourner* takes *$\textit{\^{e}tre}$*. *Mes amies* refers to *elles*. The past participle *$\textit{retourn\'{e}es}$* is already correct.\

  \

  **Model answer**: $\text{Apr\`{e}s}$ le voyage, mes amies sont $\text{retourn\'{e}es}$ chez elles.

$6.$ $\hspace{1em}$ $\textrm{avez jou\'{e}}$    [1 mark]

* *Jouer* takes *avoir*. The subject *vous* requires *avez*. The past participle *$\textit{jou\'{e}}$* is correct.\

  \

  **Model answer**: $\text{\`{A}}$ la plage, vous avez $\text{jou\'{e}}$ au volley.
