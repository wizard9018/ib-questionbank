# FA0350

**Choose the correct time to complete each sentence.**

$\hspace{1em}$Le train pour Lyon part $\text{\`{a}}$ 8 h 15. Le train part **\[-1-]**    [1 mark]

* A.$\hspace{1em}\text{\`{a}}$ huit heures et quart.

* C.$\hspace{1em}\text{\`{a}}$ huit heures et demie.

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* 8:15 is *huit heures et quart*. Use *$\textit{\`{a}}$* to indicate when the train leaves.

* *Options incorrectes :* B, C, D

* **B** : This expression corresponds to 8:45, not 8:15.

* **C** : This expression corresponds to 8:30, not 8:15.

* **D** : This expression corresponds to 7:45, not 8:15.

$2.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* 11:30 is *onze heures et demie*.

* *Options incorrectes :* B, C, D

* **B** : *Demie* is used with the feminine *heure(s)*.

* **C** : This expression corresponds to 11:45, not 11:30.

* **D** : This expression corresponds to 11:15, not 11:30.

$3.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* 22:45 is fifteen minutes before 23:00, so it is expressed as *onze heures moins le quart*.

* *Options incorrectes :* A, B, D

* **A** : This expression corresponds to 22:15, not 22:45.

* **B** : This expression corresponds to 22:30, not 22:45.

* **D** : Use *le* in *moins le quart*.

$3.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* 22:45 is fifteen minutes before 23:00, so it is expressed as *onze heures moins le quart*.

* *Options incorrectes :* A, B

* **A** : This expression corresponds to 22:15, not 22:45.

* **B** : This expression corresponds to 22:30, not 22:45.

$4.$ $\hspace{1em}$ $\textrm{sept heures et quart}$    [1 mark]

* 7:15 is expressed as *sept heures et quart*. A quarter of an hour after the hour is *et quart*.

$5.$ $\hspace{1em}$ $\textrm{deux heures et demie}$    [1 mark]

* 14:30 is expressed as *deux heures et demie*. Thirty minutes after the hour is *et demie*. It ends in *-e* because it agrees with *heure*, which is feminine.

$6.$ $\hspace{1em}$ $\textrm{dix heures moins le quart}$    [1 mark]

* 21:45 is fifteen minutes before 22:00, so it is expressed as *dix heures moins le quart*. A quarter of an hour before the hour is *moins le quart*.\
