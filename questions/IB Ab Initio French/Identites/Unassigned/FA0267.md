# FA0267

**The sentences below each contain one error related to the verb *avoir* in the present tense. Find the error and write the correct word.**

$1.$ $\hspace{1em}$Mon meilleur ami as seize ans.    [1 mark]

$2.$ $\hspace{1em}$Ma sœur et moi ont les cheveux $\text{boucl\'{e}s}$.    [1 mark]

$3.$ $\hspace{1em}$Lucas et toi avons des cheveux de couleur $\text{diff\'{e}rente}$.    [1 mark]

**Complete the sentences using the correct present tense form of the verb *avoir* in the present tense.** [3 marks]

Mes deux sœurs **[-4-]** les yeux bleus. Moi, j'**[-5-]** les cheveux courts et bruns. Notre $\text{p\`{e}re}$ **\[-6-]** quarante-cinq ans.

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{a}$    [1 mark]

- *Mon meilleur ami* corresponds to *il*, so the correct form is *a*. We use *avoir* to express age.\

\

**Model answer**: Mon meilleur ami a seize ans.

$2.$ $\hspace{1em}$ $\textrm{avons}$    [1 mark]

- *Ma sœur et moi* includes the speaker and therefore corresponds to *nous*. The correct form is *avons*. We use *avoir* here to describe a physical feature.\

\

**Model answer**: Ma sœur et moi avons les cheveux $\text{boucl\'{e}s}$.

$3.$ $\hspace{1em}$ $\textrm{avez}$    [1 mark]

- *Lucas et toi* includes the person being addressed and therefore corresponds to *vous*. The correct form is *avez*. We use *avoir* here to describe a physical feature.\

\

**Model answer**: Lucas et toi avez des cheveux de couleur $\text{diff\'{e}rente}$.

$4.$ $\hspace{1em}$ $\textrm{ont}$    [1 mark]

- *Mes deux sœurs* corresponds to *elles*, so the correct form is *ont*. We use *avoir* here to describe a physical feature.

$5.$ $\hspace{1em}$ $\textrm{ai}$    [1 mark]

- The subject is *je*, so the correct form is *ai*. We use *avoir* here to describe a physical feature.

$6.$ $\hspace{1em}$ $\textrm{a}$    [1 mark]

* *Notre $\textit{p\`{e}re}$* corresponds to *il*, so the correct form is *a*. We use *avoir* to express age.\

\

**Model answer**: Mes deux sœurs ont les yeux bleus. Moi, j'ai les cheveux courts et bruns. Notre $\text{p\`{e}re}$ a quarante-cinq ans.
