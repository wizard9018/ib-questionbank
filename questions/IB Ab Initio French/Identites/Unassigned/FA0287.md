# FA0287

**Rewrite each sentence with the adjective in the correct form. Write the complete sentence.**

$1.$ $\hspace{1em}$Mon $\text{grand-p\`{e}re}$ porte une chemise *(bleu)*.    [1 mark]

$2.$ $\hspace{1em}$Mes cousines sont $\text{tr\`{e}s}$ *(intelligent)*.    [1 mark]

**Complete the sentences with the correct form of the adjectives in brackets.** [2 marks]

Ma soeur porte une chemise **\[-3-]** *(vert)* et des chaussures **\[-4-]** *(blanc)*. Elle aime porter des $\text{v\^{e}tements}$ $\text{color\'{e}s}$.

**Each sentence contains one adjective-agreement error. Find the error and rewrite the complete sentence correctly.**

$5.$ $\hspace{1em}$Mes tantes ont les cheveux $\text{tr\`{e}s}$ long.    [1 mark]

$6.$ $\hspace{1em}$Mon voisin est une personne $\text{tr\`{e}s}$ $\text{g\'{e}n\'{e}reux}$.    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{Mon grand-p\`{e}re porte une chemise bleue.}$    [1 mark]

* *Bleue* is correct because it describes *une chemise*, which is feminine singular.

$2.$ $\hspace{1em}$ $\textrm{Mes cousines sont tr\`{e}s intelligentes.}$    [1 mark]

* *Intelligentes* is correct because it describes *mes cousines* which is feminine plural.

$3.$ $\hspace{1em}$ $\textrm{verte}$    [1 mark]

* *Verte* is correct because it describes *une chemise*, which is feminine singular.

$4.$ $\hspace{1em}$ $\textrm{blanches}$    [1 mark]

* *Blanches* is correct because it describes *des chaussures*, which is feminine plural.\

  \

  **Model answer**: Ma cousine porte une chemise verte et des chaussures blanches. Elle aime porter des $\text{v\^{e}tements}$ $\text{color\'{e}s}$.

$5.$ $\hspace{1em}$ $\textrm{petits}$    [1 mark]

* *Longs* is correct because it describes *les cheveux*, which is masculine plural.\

  \

  **Model answer**: Mes tantes ont les cheveux $\text{tr\`{e}s}$ longs.

$4.$ $\hspace{1em}$ $\textrm{g\'{e}n\'{e}reuse}$    [1 mark]

* *$\textit{G\'{e}n\'{e}reuse}$* is correct because it describes *une personne*, which is feminine singular. It agrees with *personne*, not with *mon voisin*.\

  \

  **Model answer**: Mon voisin est une personne $\text{tr\`{e}s}$ $\text{g\'{e}n\'{e}reuse}$.
