# FA0347

**The sentence below contains one question word error. Find the error and write the correct word.**

$1.$ $\hspace{1em}$Quelle est ton plat $\text{pr\'{e}f\'{e}r\'{e}}$ ?    [1 mark]

**The sentences below each contain one question word or expression error. The errors are underlined. Write the correct words.**

$2.$ $\hspace{1em}$Vous servez $\underline{\textrm{quels}}$ boissons avec le repas ?    [1 mark]

$3.$ $\hspace{1em}$Tu $\text{ach\`{e}tes}$ combien $\underline{\textrm{de}}$ oranges ?    [1 mark]

**Complete the paragraph. Use the correct question word.** [3 marks]

Pour organiser le $\text{d\'{e}jeuner}$, je pose trois questions $\text{\`{a}}$ mon $\text{fr\`{e}re}$ : « **\[-4-]** de personnes viennent ? », « Tu $\text{pr\'{e}f\`{e}res}$ **\[-5-]** $\text{l\'{e}gumes}$ ? » et « **\[-6-]** tu ne manges pas de fromage ? » Il $\text{r\'{e}pond}$ dans le $\text{m\^{e}me}$ ordre : « Cinq, les carottes et les courgettes, parce que je n'aime pas le fromage. » Nous $\text{pr\'{e}parons}$ ensuite la liste des courses.

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{Quel}$    [1 mark]

* *Plat* is masculine singular, so the question needs *quel*. The adjective *$\textit{pr\'{e}f\'{e}r\'{e}}$* and the possessive *ton* also refer to this masculine singular noun.\

  \

  **Model answer**: Quel est ton plat $\text{pr\'{e}f\'{e}r\'{e}}$ ?

$2.$ $\hspace{1em}$ $\textrm{quelles}$    [1 mark]

* *Boissons* is feminine plural, so the question word must be *quelles*. The question asks which drinks are served with the meal.\

  \

  **Model answer**: Vous servez quelles boissons avec le repas ?

$3.$ $\hspace{1em}$ $\textrm{d'}$    [1 mark]

* The quantity expression is *combien de*, but de becomes *d'* before the vowel at the beginning of *oranges*. The correct expression is *combien d'oranges*.\

  \

  **Model answer**: Tu $\text{ach\`{e}tes}$ combien d'oranges ?

$4.$ $\hspace{1em}$ $\textrm{Combien}$    [1 mark]

* *Cinq* gives a number of people. The question therefore needs *combien de personnes*. The word *de* is already in the text.

$5.$ $\hspace{1em}$ $\textrm{quels}$    [1 mark]

* *Les carottes et les courgettes* identify which vegetables the brother prefers. *$\textit{L\'{e}gumes}$* is masculine plural, so *quels* agrees with it.

$6.$ $\hspace{1em}$ $\textrm{Pourquoi}$    [1 mark]

* *Parce que je n'aime pas le fromage* gives a reason. *Pourquoi* asks why the brother does not eat cheese.\

  \

  **Model answer**: Pour organiser le $\text{d\'{e}jeuner}$, je pose trois questions $\text{\`{a}}$ mon $\text{fr\`{e}re}$ : « Combien de personnes viennent ? », « Tu $\text{pr\'{e}f\`{e}res}$ quels $\text{l\'{e}gumes}$ ? » et « Pourquoi tu ne manges pas de fromage ? » Il $\text{r\'{e}pond}$ dans le $\text{m\^{e}me}$ ordre : « Cinq, les carottes et les courgettes, parce que je n'aime pas le fromage. » Nous $\text{pr\'{e}parons}$ ensuite la liste des courses.
