# FA0290

**Each sentence contains one  verb error in the present tense. Find the error and write the correct word.**

$1.$ $\hspace{1em}$J'aides mon $\text{fr\`{e}re}$ avec ses devoirs.    [1 mark]

$2.$ $\hspace{1em}$Ma soeur parlent avec mes grands-parents.    [1 mark]

$3.$ $\hspace{1em}$Nous mangons une pizza le vendredi soir.    [1 mark]

**Put the words in the correct order. Write the full sentence.**

$4.$ $\hspace{1em}$tous les jours / ma soeur et moi / parlons    [1 mark]

$5.$ $\hspace{1em}\text{\`{a}}$ sa $\text{grand-m\`{e}re}$ / Lucas / le dimanche / $\text{t\'{e}l\'{e}phone}$     [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{aide}$    [1 mark]

* The subject is *je* (here *j'*). With *je*, regular *-er* verbs end in *-e*, so the correct form is *aide*.\

  \

  **Model answer**: J'aide mon $\text{fr\`{e}re}$ avec ses devoirs.

$2.$ $\hspace{1em}$ $\textrm{parle}$    [1 mark]

* *Ma soeur* refers to *elle*. With *elle*, regular *-er* verbs end in *-e*, so the correct form is *parle*.\

  \

  **Model answer**: Ma soeur parle avec mes grands-parents.

$3.$ $\hspace{1em}$ $\textrm{mangeons}$    [1 mark]

* The subject is *nous*. *Manger* is a *-ger* verb, so before *-ons* it takes an extra *e* to keep the soft *$\text{\textquotedblleft}$j"* sound: *mangeons*.\

  \

  **Model answer**: Nous mangeons une pizza le vendredi soir.

$4.$ $\hspace{1em}$Ma soeur et moi parlons tous les jours. / Tous les jours, ma soeur et moi parlons.     [1 mark]

* *Ma soeur et moi* refers to *nous*, so the correct form is *parlons*. The time expression *tous les jours* can appear at the beginning or end.

$5.$ $\hspace{1em}$Lucas $\text{t\'{e}l\'{e}phone}$ $\text{\`{a}}$ sa $\text{grand-m\`{e}re}$ le dimanche. / Le dimanche, Lucas $\text{t\'{e}l\'{e}phone}$ $\text{\`{a}}$ sa $\text{grand-m\`{e}re}$.     [1 mark]

* *Lucas* refers to *il*, so the correct form is *$\textit{t\'{e}l\'{e}phone}$*. The time expression *le dimanche* can appear at the beginning or end.
