# FA0277

**Choose the correct plural noun form.** 

$\hspace{1em}$Aya porte deux **[-1-]**. *(bracelet)*    [1 mark]

- A.$\hspace{1em}$bracelet

- B.$\hspace{1em}$bracelets

- C.$\hspace{1em}$braceletx

- D.$\hspace{1em}$braceletsx

$\hspace{1em}$Idriss a trois **[-2-]** pour l'hiver. *(manteau)*    [1 mark]

- A.$\hspace{1em}$manteaus

- B.$\hspace{1em}$manteau

- C.$\hspace{1em}$manteauxs

- D.$\hspace{1em}$manteaux

**Match each singular noun to the correct plural form. There are more options than nouns.** [3 marks]

| $\hspace{1em}$Singular noun | $\hspace{4em}$Options|

| :- | :- |

| $\hspace{1em}$**\[-3-]** un chapeau | $\hspace{4em}$A.$\hspace{1em}$nezs |

| $\hspace{1em}$**\[-4-]** un sac | $\hspace{4em}$B.$\hspace{1em}$sacs |

| $\hspace{1em}$**\[-5-]** un nez | $\hspace{4em}$C.$\hspace{1em}$chapeaus |

| | $\hspace{4em}$D.$\hspace{1em}$nez |

| | $\hspace{4em}$E.$\hspace{1em}$sacx |

| | $\hspace{4em}$F.$\hspace{1em}$chapeaux |

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

- *Deux* requires a plural noun. *Bracelet* follows the regular rule: add *-s* to form *bracelets*.

- *Options incorrectes :* A, C, D

- **A** : *Bracelet* is singular, whereas *deux* means two.

- **C** : *Braceletx* adds *-x* to a regular noun that takes *-s*.

- *D* : *Braceletsx* adds both *-s* and *-x*; this regular noun needs only *-s*.

$2.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

- *Trois* requires the plural. Nouns ending in *-eau* take *-x*, so *manteau* becomes *manteaux*.

- *Options incorrectes :* A, B, C

- **A** : *Manteaus* applies the regular *-s* rule, but *manteau* ends in *-eau* and takes *-x*.

- **B** : *Manteau* is singular, whereas *trois* means *three*.

- **C** : *Manteauxs* adds two plural endings; *-x* alone marks the plural here.

$3.$ $\hspace{1em}$ $\textrm{F}$    [1 mark]

- The singular noun is *chapeau*. Its ending *-eau* takes *-x* in the plural: *chapeaux*.

- *Options incorrectes :* A, B, C, D, E

- **A** : *Nezs* adds an unnecessary *-s* to *nez* and does not match *chapeau*.

- **B** : *Sacs* is the plural of *sac*, not *chapeau*.

- **C** : *Chapeaus* adds *-s*, but nouns in *-eau* take *-x*.

- *D* : *Nez* stays unchanged in the plural, but it is a different noun.

- **E** : *Sacx* incorrectly forms the plural of *sac* with *-x*; it does not match *chapeau*.

$4.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

- The singular noun is *sac*. Add the regular plural ending *-s*: *sacs*.

- *Options incorrectes :* A, C, D, E, F

- **A** : *Nezs* adds an unnecessary *-s* to *nez* and does not match *sac*.

- **C** : *Chapeaus* is an incorrect plural of *chapeau*, a different noun.

- *D* : *Nez* can be plural, but it is not a form of *sac*.

- **E** : *Sacx* uses *-x*, whereas *sac* takes regular *-s*.

- **F** : *Chapeaux* is the plural of *chapeau*, not *sac*.

$5.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

- The singular noun *nez* already ends in *-z*. Nouns ending in *-s*, *-x* or *-z* keep the same spelling in the plural, so write *nez*.

- *Options incorrectes :* A, B, C, E, F

- **A** : *Nezs* adds *-s* unnecessarily; the final *-z* stays unchanged.

- **B** : *Sacs* is the plural of *sac*, not *nez*.

- **C** : *Chapeaus* is an incorrect plural of *chapeau*, a different noun.

- **E** : *Sacx* is an incorrect plural of *sac*, a different noun.

- **F** : *Chapeaux* is the plural of *chapeau*, not *nez*.

**Grammar Reminder**

$1.$ $\hspace{1em}$The usual rule is to add *-s* \

Keep the singular spelling and add *-s*: *une chemise → des chemises* (shirts).

$2.$ $\hspace{1em}$When to add *-x* 

|$\hspace{1em}$Singular ending |$\hspace{1em}$Plural rule |$\hspace{1em}$Example |

|:--|:--|:--|

|$\hspace{1em}$*-eau* |$\hspace{1em}$Add *-x* |$\hspace{1em}$*un manteau → des manteaux* (coats) |

|$\hspace{1em}$*-eu* |$\hspace{1em}$Usually add *-x* |$\hspace{1em}$*un cheveu → des cheveux* (hairs) |

|$\hspace{1em}$*-al* |$\hspace{1em}$Usually replace *-al* with *-aux*. |$\hspace{1em}$*un animal → des animaux* (animals) |

|$\hspace{1em}$*-ail* |$\hspace{1em}$Usually add *-s*. |$\hspace{1em}$*un détail → des détails* (details) |

$3.$ $\hspace{1em}$Exceptions

- Some *-au* and *-eu* nouns take *-s* instead: *un pneu → des pneus* (tyres); *un bleu → des bleus* (bruises).

- Some *-al* nouns take *-s*: *un festival → des festivals* (festivals); *un carnaval → des carnavals* (carnivals).

- Some *-ail* nouns change *-ail* to *-aux*: *un travail → des travaux* (pieces of work).

- Nouns in *-ou* usually take *-s*: *un trou → des trous* (holes) but these words take *-x*:

*bijou → bijoux* (pieces of jewellery)\

*caillou → cailloux* (pebbles)\

*chou → choux* (cabbages)\

*genou → genoux* (knees)\

*hibou → hiboux* (owls)\

*joujou → joujoux* (toys)\

*pou → poux* (lice)

$4.$ $\hspace{1em}$ Already ending in *-s, -x* or *-z*\

Add nothing: *un bras → des bras, une croix → des croix, un nez → des nez* (arms, crosses, noses).

**Common mistake**: Do not use *-s* for a noun that takes *-x* ; Write *des manteaux*, not *des manteaus*.
