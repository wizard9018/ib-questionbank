# FA0270

**Complete the sentences. Use the correct form of *$\textbf{\textit{\^{e}tre}}$* or *avoir* in the present tense.**

Ma $\text{soeur}$ **[-1-]** $\text{tr\`{e}s}$ sportive.    [1 mark]

Paul et moi **[-2-]** seize ans.    [1 mark]

$\text{Apr\`{e}s}$ le $\text{d\'{e}jeuner}$, vous n'**[-3-]** plus faim.    [1 mark]

**Put the words in the correct order. Write the complete sentence.**

$4.$ $\hspace{1em}$les / mon / verts / yeux / $\text{fr\`{e}re}$ / a    [1 mark]

$5.$ $\hspace{1em}\text{tr\`{e}s}$ / mes / sont / aujourd'hui / $\text{fatigu\'{e}s}$ / parents    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{est}$    [1 mark]

* *Ma sœur* corresponds to *elle* and we use *$\textit{\^{e}tre}$* to describe a personal characteristic, so the correct form is *est*.

$2.$ $\hspace{1em}$ $\textrm{avons}$    [1 mark]

* *Paul et moi* includes the speaker and corresponds to *nous* and we use *avoir* to express age, so the correct form is *avons*.

$3.$ $\hspace{1em}$ $\textrm{avez}$    [1 mark]

* The subject is *vous* and *avoir faim* is a fixed expression in French, so the correct form is *avez*.

$4.$ $\hspace{1em}$ $\textrm{Mon fr\`{e}re a les yeux verts.}$    [1 mark]

* *Mon $\textit{fr\`{e}re}$* is a singular subject that corresponds to *il*, so the correct form of *avoir* is *a*. We use *avoir* to describe physical features. The physical feature *les yeux verts* comes after the verb.

$5.$ $\hspace{1em}$ $\textrm{Mes parents sont tr\`{e}s fatigu\'{e}s aujourd'hui.}$    [1 mark]

* *Mes parents* is a plural subject that corresponds to *ils*, so the correct form of *$\textit{\^{e}tre}$* is *sont*. We use *$\textit{\^{e}tre}$* with the adjective *$\textit{fatigu\'{e}s}$* to describe a state. The adjective *$\textit{fatigu\'{e}s}$* comes after the verb. The time expression *aujourd'hui* comes last here.
