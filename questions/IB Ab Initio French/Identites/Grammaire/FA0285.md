## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* *Patiente* is correct because it describes *ma soeur*, which is feminine singular.

* *Options incorrectes :* A, C, D

* **A** : *Patient* is masculine singular.

* **C** : *Patients* is masculine plural.

* **D** : *Patientes* is feminine plural.

$2.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* *$\textit{Organis\'{e}s}$* is correct because it refers to a mixed-gender group, *mes parents*, so the adjective takes the masculine plural form.

* *Options incorrectes :* A, B, D

* **A** : *$\textit{Organis\'{e}}$* is masculine singular.

* **B** : *$\textit{Organis\'{e}e}$* is feminine singular.

**Grammar reminder**

In French, an adjective agrees with the noun it describes in gender (masculine or feminine) and number (singular or plural).

**Masculine/Feminine**

Most adjectives add *-e* in the feminine: *grand → grande*.\

Adjectives already ending in *-e* stay the same: *un ami sympathique → une amie sympathique*.

Some adjectives change their ending in the feminine:

* *-f → -ve*: *sportif → sportive*

* *-x → -se*: *heureux → heureuse*

* *-eur → -euse*: *travailleur → travailleuse*

* *-s*, *-n*, *-l* → double the consonant and add *-e*: *gros → grosse* / *bon → bonne* / *traditionnel → traditionnelle*

* *-eau → -elle*: *beau → belle*

* *-c → -che* or *-que*: *blanc → blanche* / *public → publique*

* A few adjectives have their own feminine form: *vieux → vieille* / *doux → douce*, *faux → fausse* / *long → longue* / *frais → $\textit{fra\^{\i}che}$* / *fou → folle*

**Singular/Plural**

* Most adjectives add *-s* in the plural, so the feminine plural ends in *-es*: *grands, grandes*

* Masculine adjectives already ending in *-s* or *-x* stay the same in the masculine plural: *un homme $\textit{g\'{e}n\'{e}reux}$ → des hommes $\textit{g\'{e}n\'{e}reux}$*

* Masculine adjectives ending in *-eau* add *-x*: *beau → beaux*

* If one of the people or things described is masculine, use the masculine plural, even if all the others are feminine: *Patrick, Jeanne et Ludivine sont gentils*.

**Adjectives that never change**

* Some colour adjectives stay the same in the feminine and plural: *des chaussures marron* / *des robes orange* / *des yeux noisette*

* Colours made of two words never change: *une veste bleu marine*

**Word Order**

* Most adjectives come after the noun: un film $\text{int\'{e}ressant}$

* Some common adjectives come before the noun (*petit, grand, beau, bon, gros, joli, long, mauvais, vieux*): une petite maison

**Common mistake:** the adjective agrees with the noun it describes, not with the person being talked about: *Mon ami a une voiture bleue.*
