# FA0264

**The text below contains three errors related to the verb *$\textbf{\textit{\^{e}tre}}$* in the present tense. Find the errors and write the correct words.** 

Dans ma famille, nous $\text{\^{e}tes}$ tous assez $\text{diff\'{e}rents}$. Ma sœur Clara es $\text{tr\`{e}s}$ sociable et adore sortir avec ses amis. Mes parents est plus calmes, mais nous aimons tous passer du temps ensemble.    [3 marks]

**Complete the paragraph using the correct form of the verb *$\textbf{\textit{\^{e}tre}}$* in the present tense.** [6 marks]

Dans mon groupe d'amis, nous avons des $\text{personnalit\'{e}s}$ $\text{tr\`{e}s}$ $\text{diff\'{e}rentes}$. $\text{L\'{e}a}$ et Sophie **\[-4-]** $\text{tr\`{e}s}$ sociables, tandis que Thomas **\[-5-]** $\text{plut\^{o}t}$ $\text{r\'{e}serv\'{e}}$. Moi, je **\[-6-]** $\text{g\'{e}n\'{e}ralement}$ calme, mais mes amis disent que je **\[-7-]** aussi $\text{tr\`{e}s}$ $\text{dr\^{o}le}$. $\text{Malgr\'{e}}$ nos $\text{diff\'{e}rences}$, nous **\[-8-]** $\text{tr\`{e}s}$ proches. Et toi, comment **\[-9-]**-tu avec tes amis ?

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{sommes}$    [1 mark]

* The subject is *nous* so the correct form is *sommes*.

$2.$ $\hspace{1em}$ $\textrm{est}$    [1 mark]

* *Ma $\textit{sœur}$ Clara* corresponds to *elle*, so the correct form is *est*.

$3.$ $\hspace{1em}$ $\textrm{sont}$    [1 mark]

* *Mes parent*s is plural and corresponds to *ils*, so the correct form is *sont*.\

  \

  **Model answer**: Dans ma famille, nous sommes tous assez $\text{diff\'{e}rents}$. Ma sœur Clara est $\text{tr\`{e}s}$ sociable et adore sortir avec ses amis. Mes parents sont plus calmes, mais nous aimons tous passer du temps ensemble.

$4.$ $\hspace{1em}$ $\textrm{sont}$    [1 mark]

* *$\textit{L\'{e}a}$ et Sophie* refers to two people and corresponds to *elles*, so the correct form is *sont*. We use *$\textit{\^{e}tre}$* here to describe a personal characteristic.

$5.$ $\hspace{1em}$ $\textrm{est}$    [1 mark]

* *Thomas* corresponds to *il*, so the correct form is *est*. We use *$\textit{\^{e}tre}$* here to describe a personal characteristic.

$6.$ $\hspace{1em}$ $\textrm{suis}$    [1 mark]

* The subject *je* requires *suis*. We use *$\textit{\^{e}tr}$*&#x65; here to describe a personal quality.

$7.$ $\hspace{1em}$ $\textrm{suis}$    [1 mark]

* The subject is *je* again, so the correct form remains *suis*. We use *$\textit{\^{e}tre}$* here to describe a personal quality.

$8.$ $\hspace{1em}$ $\textrm{sommes}$    [1 mark]

* The subject *nous* requires *sommes*. We use *$\textit{\^{e}tre}$* here to describe the relationship between the friends.

$9.$ $\hspace{1em}$ $\textrm{es}$    [1 mark]

* In the inverted question *comment es-tu...?*, the subject is *tu*, so the correct form is *es*. We use *$\textit{\^{e}tre}$* here to ask about someone's personality.\

  \

  **Model answer**: Dans mon groupe d'amis, nous avons des $\text{personnalit\'{e}s}$ $\text{tr\`{e}s}$ $\text{diff\'{e}rentes}$. $\text{L\'{e}a}$ et Sophie sont $\text{tr\`{e}s}$ sociables, tandis que Thomas est $\text{plut\^{o}t}$ $\text{r\'{e}serv\'{e}}$. Moi, je suis $\text{g\'{e}n\'{e}ralement}$ calme, mais mes amis disent que je suis aussi $\text{tr\`{e}s}$ $\text{dr\^{o}le}$. $\text{Malgr\'{e}}$ nos $\text{diff\'{e}rences}$, nous sommes $\text{tr\`{e}s}$ proches. Et toi, comment es-tu avec tes amis ?
