# FA0266

**Complete the sentence. Use the correct form of *avoir* in the present tense.**

$\hspace{1em}$Mon $\text{fr\`{e}re}$ **[-1-]** dix-sept ans.    [1 mark]

$\hspace{1em}\text{L\'{e}a}$ et moi **[-2-]** les yeux verts.    [1 mark]

$\hspace{1em}$Vous **[-3-]** trois enfants, madame ?    [1 mark]

$\hspace{1em}$Mes cousins **[-4-]** froid aujourd'hui.     [1 mark]

**Put the words in the correct order. Write the complete sentence.**

$5.$ $\hspace{1em}$a / cheveux / ma / les / sœur / bruns    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{a}$    [1 mark]

* *Mon $\textit{fr\`{e}re}$* corresponds to *il*, so the correct form is *a*. We use *avoir* to express age.

$2.$ $\hspace{1em}$ $\textrm{avons}$    [1 mark]

* *$\textit{L\'{e}a}$ et moi* includes the speaker and therefore corresponds to *nous*. The correct form is *avons*. We use *avoir* here to describe a physical feature.

$3.$ $\hspace{1em}$ $\textrm{avez}$    [1 mark]

* The subject is *vous*, so the correct form is *avez*. We use *avoir* here to talk about family.

$4.$ $\hspace{1em}$ $\textrm{ont}$    [1 mark]

* *Mes cousins* is plural and corresponds to *ils*, so the correct form is *ont*. We use *avoir* to express a physical state.

$5.$ $\hspace{1em}$ $\textrm{Ma soeur a les cheveux bruns.}$    [1 mark]

* *Ma sœur* is a singular subject that corresponds to *elle*, so it is followed by *a*. The physical features *les cheveux bruns* come after the verb.
