# FA0124

[Note maximale : 15\] 

Vous avez un nouvel ami francophone. $\textrm{\'Ecrivez}$ un message pour $\textrm{pr\'esenter}$ votre famille. $\textrm{\'Ecrivez}$ entre 30 et 50 mots. 

**Type de texte** : message

**Conventions  du type de texte** : salutations de $\textrm{d\'ebut}$ (opening salutation) + nom du destinataire (recipient's name) + corps du message (message body) + salutations de fin (closing salutation) + signature.

---

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer:}}$

Salut Amine,

Je veux te parler de ma famille. Nous sommes quatre : mon $\textrm{p\`ere}$, ma $\textrm{m\`ere}$, ma $\textrm{s{\oe}ur}$ et moi. Mes parents sont gentils. Ma petite $\textrm{s{\oe}ur}$ a quatorze ans et elle est $\textrm{tr\`es}$ amusante. J'aime passer du temps avec ma famille.

$\textrm{\`A}$ $\textrm{bient\^ot}$,

Lina 

$\underline{\textrm{Marking Criteria Feedback}}$

**Criterion A (Language)**:

- Use the present tense throughout: *Nous sommes quatre, elle a quatorze ans, elle est $\textit{tr\`es}$ amusante, j'aime passer du temps.*

- Key structures to get right: *nous sommes* + number ; *il/elle a* + *$\textit{\^age}$*; *il/elle est* + adjectif.

- Use vocabulary of the family: *$\textit{p\`ere}$, $\textit{m\`ere}$, $\textit{s{\oe}ur}$, famille, parents*.

- Common errors: *ma famille est quatre* instead of *nous sommes quatre*; missing agreement (*ma $\textit{s{\oe}ur}$ est amusant* instead of *ma soeur est amusante*); missing accents (*$\textit{p\`ere}$, $\textit{m\`ere}$*).

**Criterion B (Message)**:

- There is only one content point here, so develop it well.

-  A complete answer includes:

    - a description of the family: $\text{\textquotedblleft}$Nous sommes quatre : mon $\textrm{p\`ere}$, ma $\textrm{m\`ere}$, ma $\textrm{s{\oe}ur}$ et moi”

    - at least one detail about a family member: $\text{\textquotedblleft}$Ma petite $\textrm{s{\oe}ur}$ a quatorze ans et elle est $\textrm{tr\`es}$ amusante”; and a personal comment: $\text{\textquotedblleft}$J'aime passer du temps avec ma famille”.

- Use *et* to add ideas. 

- A weak answer just lists family members without any detail or personal comment.

**Criterion C (Conceptual understanding**):

- Include an opening salutation (*Salut Amine,*).

- Speak directly to the recipient (*Je veux te parler de ma famille*).

- Include a short personal message.

- Include a closing salutation (*$\textit{\`A}$ $\textit{bient\^ot}$,*).

- Include the sender's name (*Lina*).
