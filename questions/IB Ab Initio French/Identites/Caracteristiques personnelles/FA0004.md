## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* The word *styl$\textit{\'{e}}$e* is correct because the text says: $\text{\textquotedblleft}$Nous pr$\text{\'{e}}$f$\text{\'{e}}$rons une personne $\text{\'{e}}$l$\text{\'{e}}$gante." ($\text{\textquotedblleft}$We prefer an elegant person.") The wor&#x64; *$\textit{\'{e}}$l$\textit{\'{e}}$gante* describes someone who looks stylish or well-dressed, and *styl$\textit{\'{e}}$e* has a similar meaning in this context.

* *Option incorrecte :* A

* **A**: *Belle* (*beautiful*) is not correct because it refers to physical beauty. In the text, *$\textit{\'{e}}$l$\textit{\'{e}}$gante* describes style or appearance, not only beauty.

$2.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* The word *tranquille* is correct because the text says: $\text{\textquotedblleft}$La personne doit $\text{\^{e}}$tre sympa, calme et responsable." ($\text{\textquotedblleft}$The person must be nice, calm and responsible.") The word *calme* refers to a person who is relaxed and not stressed, and *tranquille* expresses the same idea.

* *Option incorrecte :* F

* **F**: *Nerveuse* (*nervous*) is not correct because it is the opposite of *calme*. The text describes the person as calm, not anxious.

$3.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

* The word *organis$\textit{\'{e}}$e* is correct because the text says: $\text{\textquotedblleft}$La personne doit $\text{\^{e}}$tre sympa, calme et responsable." ($\text{\textquotedblleft}$The person must be nice, calm and responsible.") The word *responsable* describes a person who is reliable and serious, and *organis$\textit{\'{e}}$e* matches this idea because an organised person is usually responsible.

* *Option incorrecte :* E

* **E**: *Paresseuse* (*lazy*) is not correct because it is the opposite of *responsable*. The text is looking for someone reliable, not lazy.

$4.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* The text says: $\text{\textquotedblleft}$Nous cherchons un mannequin pour une campagne de v$\text{\^{e}}$tements pour jeunes." ($\text{\textquotedblleft}$We are looking for a model for a youth clothing campaign.") an&#x64; *$\textit{\'{e}}$cris-nous pour participer* (*write to us to participate*) The text describes the type of person they need and invites people to contact them, which is typical of *une annonce* (*an announcement*).

* *Options incorrectes :* A, B, D

* **A**: *Un d$\textit{\'{e}}$pliant* (*a pamphlet*) is not correct because a pamphlet usually gives general information or opinions about a topic. This text is looking for a person.

* **B**: *Une note* (*a note*) is not correct because a note usually gives short information or instructions. This text is inviting people to participate in a casting.

* **D**: *Un rapport* (*a report*) is not correct because a report is usually formal and presents detailed information or analysis. This text is an invitation to apply.

$5.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

* The text says: $\text{\textquotedblleft}$Nous cherchons un mannequin pour une campagne de v$\text{\^{e}}$tements pour jeunes." ($\text{\textquotedblleft}$We are looking for a model for a youth clothing campaign.") The text clearly explains that they want to find a model, which matches *recruter un mannequin* (*to recruit a model*).

* *Options incorrectes :* A, B, C

* **A**: $\text{\textquotedblleft}$Informer sur les derni$\text{\`{e}}$res tendances" ($\text{\textquotedblleft}$to inform about the latest trends") is not correct because the text does not talk about fashion trends.

* **B**: $\text{\textquotedblleft}$Annoncer une marque de v$\text{\^{e}}$tements" ($\text{\textquotedblleft}$to announce a clothing brand") is not correct because the text does not mention a specific brand.

* **C**: $\text{\textquotedblleft}$Soutenir des cr$\text{\'{e}}$ateurs de mode" ($\text{\textquotedblleft}$to support fashion designers") is not correct because the text only explains that they want to find a model.
