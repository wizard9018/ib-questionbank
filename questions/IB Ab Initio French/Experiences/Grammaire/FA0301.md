# FA0301

**Choose the correct reflexive verb.**

$\hspace{1em}$Mon $\text{grand-p\`{e}re}$ **\[-1-]** $\text{\`{a}}$ six heures du matin.    [1 mark]

* A.$\hspace{1em}$me $\text{l\`{e}ve}$

* B.$\hspace{1em}\text{l\`{e}ves}$

* C.$\hspace{1em}$se $\text{l\`{e}ve}$

* D.$\hspace{1em}\text{l\`{e}ve}$

$\hspace{1em}$Mes soeurs **\[-2-]** $\text{apr\`{e}s}$ le sport.    [1 mark]

* A.$\hspace{1em}$se douchent

* B.$\hspace{1em}$vous douchez

* C.$\hspace{1em}$douchons

* D.$\hspace{1em}$douchent

**Complete the sentences. Use the reflexive verbs *m'habille*, *se lave*, *nous $\textbf{\textit{r\'{e}veillons}}$*, or *te couches*.** [4 marks]

Nous **\[-3-]** $\text{\`{a}}$ sept heures pour aller au $\text{lyc\'{e}e}$. Le matin, je **\[-4-]** avant de prendre le $\text{petit-d\'{e}jeuner}$. Tu **\[-5-]** $\text{apr\`{e}s}$ le $\text{d\^{\i}ner}$. Le soir, ma $\text{m\`{e}re}$ **\[-6-]** avant de dormir.

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* *Se $\textit{l\`{e}ve}$* is correct because *mon $\textit{grand-p\`{e}re}$* refers to *il*. The reflexive pronoun for *il* is *se*, so the correct form is *se $\textit{l\`{e}ve}$*.

* *Options incorrectes :* A, B, D

* **A** : *Me $\textit{l\`{e}ve}$* is the *je* form, but *mon $\textit{grand-p\`{e}re}$* refers to *il*.

* **B** : *$\textit{L\`{e}ves}$* is the *tu* form and does not include the reflexive pronoun.

* **D** : *$\textit{L\`{e}ve}$* has the correct verb form, but the reflexive pronoun *se* is missing.

$2.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* *Se douchent* is correct because *mes soeurs* refers to elles. The reflexive pronoun for *elles* is *se*, so the correct form is *se douchent*.

* *Options incorrectes :* B, C, D

* **B** : *Vous douchez* is the *vous* form, but *mes soeurs* refers to *elles*.

* **C** : *Douchons* is the *nous* form and does not include the reflexive pronoun.

* **D** : *Douchen*t has the correct verb form, but the reflexive pronoun *se* is missing.

$3.$ $\hspace{1em}$ $\textrm{nous r\'{e}veillons}$    [1 mark]

* *Nous* refers to more than one person including the speaker. The reflexive pronoun is *nous*, so the correct form is *nous $\textit{r\'{e}veillons}$*.

$4.$ $\hspace{1em}$ $\textrm{m'habille}$    [1 mark]

* The subject is *je*. The reflexive pronoun is *me*, which shortens to *m'* before a vowel, so the correct form is *m'habille*.

$5.$ $\hspace{1em}$ $\textrm{te couches}$    [1 mark]

* The subject is *tu*. The reflexive pronoun is *te*, so the correct form is *te couches*.

$6.$ $\hspace{1em}$ $\textrm{se lave}$    [1 mark]

* *Ma $\textit{m\`{e}re}$* refers to *elle*. The reflexive pronoun is *se*, so the correct form is *se lave*.\

  \

  **Model answer**: Nous nous $\text{r\'{e}veillons}$ $\text{\`{a}}$ sept heures pour aller au $\text{lyc\'{e}e}$. Le matin, je m'habille avant de prendre le $\text{petit-d\'{e}jeuner}$. Tu te couches $\text{apr\`{e}s}$ le $\text{d\^{\i}ner}$. Le soir, ma $\text{m\`{e}re}$ se lave avant de dormir.

**Grammar reminder**

In French, reflexive verbs (*verbes pronominaux*) are used when the subject performs an action on themselves. The reflexive pronoun (*me, te, se, nous, vous, se*) changes depending on the subject and is placed directly before the conjugated verb. *Me, te* and *se* shorten to *m', t'* and *s'* before a vowel sound.

| $\hspace{1em}$Subject pronoun$\hspace{1.5em}$ | $\hspace{1em}$Reflexive pronoun$\hspace{1.5em}$ | $\hspace{1em}$Example:  Se $\textbf{r\'{e}veiller}\hspace{1.5em}$ |

| :- | :- | :- |

| $\hspace{1em}$Je | $\hspace{1em}$me /m' | $\hspace{1em}$Je me $\text{r\'{e}veille}$ |

| $\hspace{1em}$Tu | $\hspace{1em}$te /t' | $\hspace{1em}$Tu te $\text{r\'{e}veilles}$ |

| $\hspace{1em}$Il/elle/on | $\hspace{1em}$se/s' | $\hspace{1em}$Il/elle/on se $\text{r\'{e}veille}$ |

| $\hspace{1em}$Nous | $\hspace{1em}$nous | $\hspace{1em}$Nous nous $\text{r\'{e}veillons}$ |

| $\hspace{1em}$Vous | $\hspace{1em}$vous | $\hspace{1em}$Vous vous $\text{r\'{e}veillez}$ |

| $\hspace{1em}$Ils/elles$\hspace{1em}$ | $\hspace{1em}$se/s' | $\hspace{1em}$Ils/Elles se $\text{r\'{e}veillent}$ |

Here is a list of common reflexive verbs:

**Daily routine**

* *se $\textit{r\'{e}veiller}$* : to wake up

* *se lever* : to get up

* *se laver* : to wash oneself

* *se doucher* : to shower

* *se brosser les dents* : to brush one's teeth

* *se coiffer/se brosser les cheveux* : to brush one's hair

* *se raser* : to shave

* *s'habiller* : to get dressed

* *se $\textit{pr\'{e}parer}$* : to get ready

* *se coucher* : to go to bed

**Free time**

* *se promener/se balader* : to go for a walk

* *s'amuser* : to have fun

* *se $\textit{d\'{e}tendre}$* : to relax

* *se reposer* : to rest

* *se baigner* : to swim

**Feelings and emotions**

* *se sentir* : to feel

* *s'$\textit{inqui\'{e}ter}$* : to worry

* *se $\textit{f\^{a}cher}$* : to get angry

**Relationships**

* *se retrouver* : to meet up

* *s'entendre* : to get along

* *se disputer* : to argue
