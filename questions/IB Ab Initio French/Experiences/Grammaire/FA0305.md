# FA0305

**Match each sentence to the correct form of *aller* to express the near future. There are more options than sentences.** [3 marks]

| $\hspace{1em}$Sentence | $\hspace{4em}$Options |

| :- | :- |

| $\hspace{1em}$Ce week-end, je ****\[-1-]**** voir un film. | $\hspace{4em}$A.$\hspace{1em}$allons |

| $\hspace{1em}$Tu ****\[-2-]**** visiter un $\text{mus\'{e}e}$ samedi ? | $\hspace{4em}$B.$\hspace{1em}$vas |

| $\hspace{1em}$Mon $\text{fr\`{e}re}$ ****\[-3-]**** faire du shopping demain. | $\hspace{4em}$C.$\hspace{1em}$vais |

| $\hspace{1em}$ | $\hspace{4em}$D.$\hspace{1em}$va |

| $\hspace{1em}$ | $\hspace{4em}$E.$\hspace{1em}$vont |

| $\hspace{1em}$ | $\hspace{4em}$F.$\hspace{1em}$allez |

**Complete the sentences to express the near future. Use *vais*, *vas* or *va*.**

$4.$ $\hspace{1em}$Demain, je **\[-4-]** $\text{pr\'{e}parer}$ ma valise.    [1 mark]

$5.$ $\hspace{1em}$Tu **\[-5-]** visiter le centre-ville ?    [1 mark]

$6.$ $\hspace{1em}$Ma soeur **\[-6-]** jouer au basket avec ses amies.    [1 mark]

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* The *je* form is *vais*. The structure *aller + infinitif* is used to express a future plan: *vais voir*.

* *Options incorrectes :* A, B, D, E, F

* **A** : *Allons* is incorrect because it corresponds to *nous*, not *je*.

* **B** : *Vas* is incorrect because it corresponds to *tu*, not *je*.

* **D** : *Va* is incorrect because it corresponds to *il*, *elle* or *on*, not *je*.

* **E** : *Vont* is incorrect because it corresponds to *ils* or *elles*, not *je*.

* **F** : *Allez* is incorrect because it corresponds to *vous*, not *je*.

$2.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* The *tu* form is *vas*. The structure *aller + infinitif* is used to express a future plan: *vas visiter*.

* *Options incorrectes :* A, C, D, E, F

* **A** : *Allons* is incorrect because it corresponds to *nous*, not *tu*.

* **C** : *Vais* is incorrect because it corresponds to *je*, not *tu*.

* **D** : *Va* is incorrect because it corresponds to *il*, *elle* or *on*, not *tu*.

* **E** : *Vont* is incorrect because it corresponds to *ils* or *elles*, not *tu*.

* **F** : *Allez* is incorrect because it corresponds to *vous*, not *tu*.

$3.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

* *Mon $\textit{fr\`{e}re}$* refers to *il*, so the correct form is *va*. The structure *aller + infinitif* is used to express a future plan: *va faire*.

* *Options incorrectes :* A, B, C, E, F

* **A** : *Allons* is incorrect because it corresponds to *nous*, not *il*.

* **B** : *Vas* is incorrect because it corresponds to *tu*, not *il*.

* **C** : *Vais* is incorrect because it corresponds to *je*, not *il*.

* **E** : *Vont* is the *ils/elles* form, but *mon $\textit{fr\`{e}re}$* is singular and refers to *il*.

* **F** : *Allez* is incorrect because it corresponds to *vous*, not *il*.

$4.$ $\hspace{1em}$ $\textrm{vais}$    [1 mark]

* The subject is *je*, so the correct form is *vais*. The complete structure is *vais $\textit{pr\'{e}parer}$*.

$5.$ $\hspace{1em}$ $\textrm{vas}$    [1 mark]

* The subject is *tu*, so the correct form is *vas*. The complete structure is *vas visiter*.

$6.$ $\hspace{1em}$ $\textrm{va}$    [1 mark]

* *Ma soeur* refers to *elle*, so the correct form is *va*. The complete structure is *va jouer*.

**Grammar Reminder**

In French, *aller + infinitif* (le futur proche) is used to talk about future plans and intentions. The form of *aller* changes depending on the subject. The infinitive does not change.

| $\hspace{1em}$Subject pronoun$\hspace{1.5em}$ | $\hspace{1em}$Aller$\hspace{1.5em}$ | $\hspace{1em}$**+ infinitif**$\hspace{1.5em}$ |

| :- | :- | :- |

| $\hspace{1em}$Je | $\hspace{1em}$vais | $\hspace{1em}$+ infinitif$\hspace{1em}$ |

| $\hspace{1em}$Tu | $\hspace{1em}$vas | $\hspace{1em}$+ infinitif$\hspace{1em}$ |

| $\hspace{1em}$Il/elle/on | $\hspace{1em}$va | $\hspace{1em}$+ infinitif$\hspace{1em}$ |

| $\hspace{1em}$Nous | $\hspace{1em}$allons | $\hspace{1em}$+ infinitif$\hspace{1em}$ |

| $\hspace{1em}$Vous | $\hspace{1em}$allez | $\hspace{1em}$+ infinitif$\hspace{1em}$ |

| $\hspace{1em}$Ils/elles$\hspace{1em}$ | $\hspace{1em}$vont | $\hspace{1em}$+ infinitif$\hspace{1em}$ |
