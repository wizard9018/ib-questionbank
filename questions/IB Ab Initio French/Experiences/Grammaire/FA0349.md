# FA0349

**Choose the correct time to complete each sentence.**

$1.$ $\hspace{1em}$L'horloge de l'$\text{h\^{o}tel}$ indique 3 h 00. Quelle heure est-il ?    [1 mark]

* A.$\hspace{1em}$Il est trois heures.

* B.$\hspace{1em}$Elle est trois heures.

* C.$\hspace{1em}$Il est trois.

* D.$\hspace{1em}$Il est trois heure.

$2.$ $\hspace{1em}$Pendant les vacances, nous $\text{d\'{e}jeunons}$ $\text{\`{a}}$ 12 h 00. Nous $\text{d\'{e}jeunons}$...    [1 mark]

* A.$\hspace{1em}\text{\`{a}}$ minuit.

* B.$\hspace{1em}\text{\`{a}}$ midi.

* C.$\hspace{1em}\text{\`{a}}$ douze heure.

* D.$\hspace{1em}$à midi heures.

$3.$ $\hspace{1em}$L'excursion en bateau commence $\text{\`{a}}$ 9 h 00. Elle commence...    [1 mark]

* A.$\hspace{1em}$neuf heures.

* B.$\hspace{1em}\text{\`{a}}$ neuf.

* C.$\hspace{1em}\text{\`{a}}$ neuf heures.

* D.$\hspace{1em}$dans neuf heures.

**Complete each sentence with *il est*, *heure* or *heures*.**

$\hspace{1em}$Le magasin de souvenirs ferme $\text{\`{a}}$ une **\[-4-]**.    [1 mark]

$\hspace{1em}$Le train pour Marseille part $\text{\`{a}}$ huit **\[-5-]**.    [1 mark]

$\hspace{1em}$Quelle heure est-il ? **\[-6-]** cinq heures.    [1 mark]

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* Use *il est* + the hour to tell the time: *il est trois heures* for 3:00.

* *Options incorrectes :* B, C, D

* **B** : Use *il est*, not *elle est*, even though *heure* is a feminine word.

* **C** : Use *heures* after the number when telling the time.

* **D** : Use the plural *heures* after *trois*.

$2.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* Use *$\textit{\`{a}}$* before *midi* to indicate when an activity takes place. *Midi* is midday.

* *Options incorrectes :* A, C, D

* **A** : *Minuit* is midnight.

* **C** : Use the plural *heures* with *douze*.

* **D** : Use the plural *heures* after *trois*.

$3.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* Use *$\textit{\`{a}}$* before *neuf heures* to indicate when an activity takes place.

* *Options incorrectes :* A, B, D

* **A** : *Neuf heures* tells the time, but without *$\textit{\`{a}}$* it does not indicate when the excursion begins.

* **B** : Use *heures* after *neuf* when giving the time.

* **D** : *Dans neuf heures* means “in nine hours' time”, not “at 9:00”.

$4.$ $\hspace{1em}$ $\textrm{heure}$    [1 mark]

* Use the singular *heure* with *une* for 1:00.

$5.$ $\hspace{1em}$ $\textrm{heures}$    [1 mark]

* Use the plural *heures* with *huit* and all numbered hours other than one.

$6.$ $\hspace{1em}$ $\textrm{Il est}$    [1 mark]

* Use *il est* before numbered hours when telling the time.

**Grammar reminder**

- Use *il est* + the hour to tell the time: *il est trois heures*. 

- *Une heure* is singular. All other hours take *heures*: *il est une heure, il est deux heures*.

- Use *à* + the time to say when an activity takes place: *le train part à huit heures*.

- *Midi* is midday and *minuit* is midnight.

- Use *du matin*, *de l'après-midi* or *du soir* to specify the part of the day. Example: *sept heures du matin, trois heures de l'après-midi, neuf heures du soir*.

- Say the hour first, then the minutes. Example: *il est huit heures dix* (8:10).
