# FA0133

[Note maximale : 15\] 

**Utilisez, en fonction des propositions, le type de texte le plus $\textbf{appropri\'e}$. $\textbf{\'Ecrivez}$ entre 50 et 60 mots.** 

Un(e) ami(e) francophone veut savoir comment vous organisez votre temps $\textrm{apr\`es}$ $\textrm{l'\'ecole}$. $\textrm{\'Ecrivez}$ un texte pour lui expliquer ce que vous faites $\textrm{apr\`es}$ les cours.

**Conventions du type de texte** :

**Blog** :  adresse internet du blog (blog URL) + titre (title) + date + heure (time) + nom/pseudo du blogueur (blogger's name/username) + formule d'appel (opening salutation) + texte $\textrm{adress\'e}$ aux lecteurs (text addressed to readers) + formule de fin (closing salutation) + espace commentaires (comments section). 

**Discours** :  salutations au public (greeting to the audience) + $\textrm{r\'ef\'erence}$ directe au public (direct reference to the audience) + texte $\textrm{structur\'e}$ (structured text) + questions $\textrm{rh\'etoriques}$/$\textrm{r\'ep\'etition}$ (rhetorical questions/repetition) + formule de conclusion (concluding sentence). 

**Message** : salutations de $\textrm{d\'ebut}$ (opening salutation) + nom du destinataire (recipient's name) + corps du message (message body) + salutations de fin (closing salutation) + signature.

## 评分标准 / Mark scheme

$\underline{\textrm{Sample answer:}}$

Salut Emma,

$\textrm{Apr\`es}$ les cours, $\textrm{\`a}$ 16h, je prends le bus et j'arrive chez moi. Ensuite, je prends un $\textrm{go\^uter}$ et je me repose un peu. Puis, je fais mes devoirs dans ma chambre. Le soir, vers 19h, je regarde une $\textrm{s\'erie}$ ou je parle avec ma famille. Parfois, $\textrm{j'\'ecoute}$ de la musique pour me $\textrm{d\'etendre}$.

$\textrm{\`A}$ $\textrm{bient\^ot}$ !

Lucas 

$\underline{\textrm{Marking Criteria Feedback}}$

**Criterion A (Language)**:

- Use the present tense throughout: *je prends, j'arrive, je fais, je regarde*.

- Use pour + infinitive to express purpose: $\text{\textquotedblleft}\textrm{j'\'ecoute}$ de la musique pour me $\textrm{d\'etendre}$".

- Use time expressions to situate activities: $\text{\textquotedblleft}\textrm{\`a}$ 16h", $\text{\textquotedblleft}$le soir, vers 19h"

- Common errors: forgetting reflexive verbs (*je repose* instead of  *je me repose*); missing prepositions (*je vais maison* instead of *je vais $\textit{\`a}$ la maison*); incorrect verb forms after *je* (*je prend* instead of  *je prends*).

**Criterion B (Message)**:

- There is only one content point here, so develop it well - don't just list activities. 

- A complete answer includes a clear description of what you do after school, with several activities presented in a logical order.

- The model answer does this naturally: $\text{\textquotedblleft}$Je prends le bus... je prends un $\textrm{go\^uter}$... je fais mes devoirs... je regarde une $\textrm{s\'erie}$... $\textrm{j'\'ecoute}$ de la musique pour me $\textrm{d\'etendre}$.” 

- Use *et* and *ou* to add and alternate ideas, and *ensuite* and *puis* to show sequence.

- A weak answer only gives one or two actions without order or detail (for example: *je fais mes devoirs et je regarde la $\textit{t\'el\'e}$*).

**Criterion C (Conceptual understanding**):

- **Message** is the most appropriate choice. The task is short, personal, and written to a friend. A strong response includes all the conventions of a message, as in the model answer: an opening salutation (*Salut*), the recipient's name (*Emma*), a message body (*$\textit{Apr\`es}$ les cours...*), a closing salutation (*$\textit{\`A}$ $\textit{bient\^ot}$ !*), and a signature (*Lucas*). 

- **Blog** is generally appropriate but less suitable: it is written for a general audience, not for a single friend.

- **Discours** is generally inappropriate: it is designed for a public audience.
