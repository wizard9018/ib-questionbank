# FA0374

**Complete the sentences. Use the correct partitive article. Use *du*, *de la* or *de l'*.**

$\hspace{1em}$Pour $\text{pr\'{e}parer}$ le $\text{d\^{\i}ner}$, je mets **\[-1-]** farine dans un saladier.    [1 mark]

$\hspace{1em}$Pendant le repas, nous buvons **\[-2-]** eau.    [1 mark]

**Match each sentence to the correct article or form of *de*. There are more options than sentences.**    [3 marks]

| Sentence$\hspace{4em}$ | $\hspace{3em}$Options |

| :- | :- |

| $\text{Apr\`{e}s}$ le repas, je ne prends pas **\[-3-]** $\text{caf\'{e}}$. | $\hspace{3em}$A.$\hspace{1em}$de l' |

| Pour cette sauce, nous n'utilisons pas **\[-4-]** ail. | $\hspace{3em}$B.$\hspace{1em}$du |

| Pour le $\text{d\^{\i}ner}$, elle $\text{ach\`{e}te}$ **\[-5-]** $\text{\'{e}pinards}$. | $\hspace{3em}$C.$\hspace{1em}$d' |

| $\hspace{1em}$ | $\hspace{3em}$D.$\hspace{1em}$de la |

| $\hspace{1em}$ | $\hspace{3em}$E.$\hspace{1em}$des |

| | $\hspace{3em}$F.$\hspace{1em}$de |

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{de la}$    [1 mark]

* *Farine* is feminine singular and begins with a consonant. The sentence describes an unspecified amount of flour.

$2.$ $\hspace{1em}$ $\textrm{de l'}$    [1 mark]

* *Eau* is singular and begins with a vowel. The partitive article is therefore de *l'*.

$3.$ $\hspace{1em}$ $\textrm{F}$    [1 mark]

* *Je ne prends pas* means that the speaker does not drink any coffee. In this ordinary negative sentence, the partitive becomes *de*. Since *$\textit{caf\'{e}}$* begins with a consonant, write *pas de $\textit{caf\'{e}}$*.

* *Options incorrectes :* A, B, C, D, E

* **A** : *De l'* does not fit the consonant at the start of *$\textit{caf\'{e}}$*.

* **B** : *Du* would fit an affirmative sentence with *$\textit{caf\'{e}}$*, but this negative sentence requires *de*.

* **C** : *D'* is used before a vowel or silent *h*, but *$\textit{caf\'{e}}$* begins with a consonant.

* **D** : *De la* is feminine and does not make the required negative change.

* **E** : *Des* is plural and does not make the required negative change.

$4.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* *Nous n'utilisons pas* means that no garlic is used. The ordinary negative construction requires *de*, which becomes *d'* before the vowel in *ail*.

* *Options incorrectes :* A, B, D, E, F

* **A** : *De l'* would fit an affirmative sentence with *ail*, but this negative sentence requires *d'*.

* **B** : *Du* does not make the negative change and cannot be used before the vowel in *ail*.

* **D** : *De la* is feminine, while *ail* is masculine, and it does not make the required negative change.

* **E** : *Des* is plural, while *ail* is singular, and it does not make the required negative change.

* **F** : *De* must become *d'* before the vowel in *ail*.

$5.$ $\hspace{1em}$ $\textrm{E}$    [1 mark]

* *$\textit{\'{E}pinards}$* is a plural food noun. The affirmative sentence refers to an unspecified amount.

* *Options incorrectes :* A, B, C, D,  F

* **A** : *De l'* is singular, but *$\textit{\'{e}pinards}$* is plural.

* **B** : *Du* is singular, but *$\textit{\'{e}pinards}$* is plural.

* **C** : *D'* would be used after a quantity expression.

* **D** : *De la* is singular, but *$\textit{\'{e}pinards}$* is plural.

* **F** : *De* alone does not express this unspecified amount.
