## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* *Je m'appelle Lina* gives a name. The question uses the expression *Comment t'appelles-tu ?* to ask someone's name.

* *Options incorrectes :* A, C, D

* **A** : *Quand* asks about a time, but Lina is a name.

* **C** : *Combien* asks about a quantity.

* **D** : *$\textit{O\`{u}}$* asks about a place, not a name.

$2.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* *$\textit{\`{A}}$ Lyon* gives a place. *$\textit{O\`{u}}$* asks where the person lives.

* *Options incorrectes :* A, B, D

* **A** : *Qui* asks about a person, but *$\textit{\`{a}}$ Lyon* names a place.

* **B** : *Pourquoi* asks for a reason.

* **D** : *Quand* asks about a time.

$3.$ $\hspace{1em}$ $\textrm{C}$    [1 mark]

* *$\textit{Nationalit\'{e}}$* is feminine singular, so the question uses *quelle*. The reply *Je suis suisse* gives the nationality requested.

* *Options incorrectes :* A, B, D, E, F

* **A** : *Quel* is masculine singular, but *$\textit{nationalit\'{e}}$* is feminine singular.

* **B** : *Qui* asks about a person's identity, not which nationality they have.

* **D** : *Combien* asks about a quantity, not a nationality.

* **E** : *Quel $\textit{\^{a}ge}$* asks about age.

* **F** : *Pourquoi* asks for a reason, but the reply gives a nationality.

$4.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* *$\textit{Pr\'{e}nom}$* is masculine singular, so the question uses *quel*. The reply *Mon $\textit{pr\'{e}nom}$ est Amir* provides the first name requested.

* *Options incorrectes :* B, C, D, E, F

* **B** : *Qui* asks about a person, whereas this question asks which first name the person has.

* **C** : *Quelle* is feminine singular, but *$\textit{pr\'{e}nom}$* is masculine singular.

* **D** : *Combien* asks about a quantity, not a first name.

* **E** : *Quel $\textit{\^{a}ge}$* asks about age.

* **F** : *Pourquoi* asks for a reason.

$5.$ $\hspace{1em}$ $\textrm{E}$    [1 mark]

* *J'ai quinze ans* gives an age. We use *avoir* in the question *Quel $\textit{\^{a}ge}$ as-tu ?*

* *Options incorrectes :* A, B, C, D, F

* **A** : *Quel* alone needs a noun here; the age question requires *quel $\textit{\^{a}ge}$*.

* **B** : *Qui* asks about a person, not an age.

* **C** : *Quelle* alone does not form the age question with *as-tu*.

* **D** : *Combien* asks about a quantity.

* **F** : *Pourquoi* asks for a reason, not an age.

**Grammar Reminder**

Choose the question word according to the information you need:

| Information | Question word or expression | Translation |

| :- | :- | :- |

| $\hspace{1em}$Person | $\hspace{1em}$qui | $\hspace{1em}$who |

| $\hspace{1em}$Thing or action | $\hspace{1em}$que/quoi | $\hspace{1em}$what |

| $\hspace{1em}$Place | $\hspace{1em}\text{o\`{u}}$ | $\hspace{1em}$where |

| $\hspace{1em}$Time | $\hspace{1em}$quand | $\hspace{1em}$when |

| $\hspace{1em}$Reason | $\hspace{1em}$pourquoi | $\hspace{1em}$why |

| $\hspace{1em}$Way or method | $\hspace{1em}$comment | $\hspace{1em}$how |

| $\hspace{1em}$Quantity or price | $\hspace{1em}$combien | $\hspace{1em}$how many or how much |

| $\hspace{1em}$Choice or identification | $\hspace{1em}$quel / quelle / quels / quelles | $\hspace{1em}$which or what |

| $\hspace{1em}$Age | $\hspace{1em}$quel $\text{\^{a}ge}$ | $\hspace{1em}$how old |

* *Que* and *quoi* both mean $\text{\textquotedblleft}$what”, but they are used in different question patterns. After a preposition, use *quoi*, not *que*: *Tu parles de quoi ?* (What are you talking about?) When the question word comes after the verb, use *quoi*: *Tu fais quoi ?*(What are you doing?)

* *Quel* agrees with the noun:

* * *quel $\textit{pr\'{e}nom}$* (masculine singular)

* * *quelle $\textit{nationalit\'{e}}$* (feminin singular)

* * *quels aliments* (masculine plural)

* * *quelles habitudes* (feminin plural)

- Keep the necessary preposition: *$\textit{\`{a}}$ qui* (to whom), *avec qui* (with whom), *de quoi* (about what or of what).

- Use *combien de* before a noun. Use *combien d'* before a vowel or a silent *h*: *combien de repas, combien d'oranges, combien d'heures*.

- Use *est-ce que* before the subject and verb to form a yes/no question: *Est-ce que tu aimes le sport ?* (Do you like sport?) You can also place it after a question word: *$\textit{O\`{u}}$ est-ce que tu habites ?* (Where do you live?)

- Use *qu'est-ce* que to ask $\text{\textquotedblleft}$what” about a thing or an action: *Qu'est-ce que tu aimes ?* (What do you like?) / *Qu'est-ce que tu fais ?* (What are you doing?).

  With *est-ce que* and *qu'est-ce que* keep the subject before the verb: *tu aimes, tu habites, tu fais*.

**Common mistake**: do not leave out *de* after *combien* when a noun follows. Write *Tu as combien de cousins ?* (How many cousins do you have?), not *Tu as combien cousins ?*
