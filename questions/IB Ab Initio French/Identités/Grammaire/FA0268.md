# FA0268

**The paragraph below contains three errors related to the verb *avoir* in the present tense. Find the errors and write the correct words.** [3 marks]

Dans ma famille, nous avez tous les cheveux assez $\text{fonc\'{e}s}$. Ma $\text{m\`{e}re}$ a les yeux verts, mais mon $\text{p\`{e}re}$ et moi avons les yeux marron. Mes deux sœurs a les yeux bleus comme notre $\text{grand-m\`{e}re}$. Elles ont dix-sept et vingt ans, tandis que moi, j'as quinze ans.

**Complete the paragraph using the correct form of the verb *avoir* in the present tense.** [5 marks]

Dans mon groupe d'amis, nous sommes cinq et nous **\[-4-]** tous des $\text{personnalit\'{e}s}$ $\text{diff\'{e}rentes}$. Clara **\[-5-]** un $\text{caract\'{e}re}$ $\text{\'{e}nergique}$ et elle est toujours active. Paul et Mehdi **\[-6-]** le $\text{m\^{e}me}$ $\text{\^{a}ge}$, mais ils sont $\text{tr\`{e}s}$ $\text{diff\'{e}rents}$. Moi, j'**\[-7-]** un $\text{caract\`{e}re}$ $\text{plut\^{o}t}$ calme. Et toi, quelle $\text{personnalit\'{e}}$ **\[-8-]**-tu ?

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{avons}$    [1 mark]

* The subject is *nous*, so the correct form is *avons*. We use *avoir* here to describe a physical feature.

$2.$ $\hspace{1em}$ $\textrm{ont}$    [1 mark]

* *Mes deux $\textit{sœurs}$* corresponds to *elles*, so the correct form is *ont*. We use *avoir* here to describe a physical feature.

$3.$ $\hspace{1em}$ $\textrm{ai}$    [1 mark]

* The subject is *je*, so the correct form is *ai*. We use *avoir* to express age.\

  \

  **Model answer**: Dans ma famille, nous avons tous les cheveux assez $\text{fonc\'{e}s}$. Ma $\text{m\`{e}re}$ a les yeux verts, mais mon $\text{p\`{e}re}$ et moi avons les yeux marron. Mes deux sœurs ont les yeux bleus comme notre $\text{grand-m\`{e}re}$. Elles ont dix-sept et vingt ans, tandis que moi, j'ai quinze ans.

$4.$ $\hspace{1em}$ $\textrm{avons}$    [1 mark]

* The subject is *nous*, so the correct form is *avons*. We use *avoir* here to talk about the personalities of the group.

$5.$ $\hspace{1em}$ $\textrm{a}$    [1 mark]

* Clara corresponds to *elle*, so the correct form is *a*. We use *avoir* with un $\text{caract\`{e}re}$ to describe personality.

$6.$ $\hspace{1em}$ $\textrm{ont}$    [1 mark]

* *Paul et Mehdi* refers to two people and corresponds to *ils*, so the correct form is *ont*. We use *avoir* to express age.

$7.$ $\hspace{1em}$ $\textrm{ai}$    [1 mark]

* The subject is *je*, so the correct form is *ai*. We use *avoir* here to describe personality.

$8.$ $\hspace{1em}$ $\textrm{as}$    [1 mark]

* In the inverted question *quelle $\textit{personnalit\'{e}}$ as-tu ?*, the subject is *tu*, so the correct form is *as*. We use *avoir* here to ask about someone's personality.\

  \

  **Model answer**: Dans mon groupe d'amis, nous sommes cinq et nous avons tous des $\text{personnalit\'{e}s}$ $\text{diff\'{e}rentes}$. Clara a un $\text{caract\'{e}re}$ $\text{\'{e}nergique}$ et elle est toujours active. Paul et Mehdi ont le $\text{m\^{e}me}$ $\text{\^{a}ge}$, mais ils sont $\text{tr\`{e}s}$ $\text{diff\'{e}rents}$. Moi, j'ai un $\text{caract\`{e}re}$ $\text{plut\^{o}t}$ calme. Et toi, quelle $\text{personnalit\'{e}}$ as-tu ?
