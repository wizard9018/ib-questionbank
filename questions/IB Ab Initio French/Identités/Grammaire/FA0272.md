## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{a}$    [1 mark]

- The subject is *elle*, so the correct form is *a*. *Avoir froid* is a fixed expression in French.

$2.$ $\hspace{1em}$ $\textrm{suis}$    [1 mark]

* The subject is *je*, so the correct form is *suis*. We use *$\textit{\^{e}tre}$* with the adjective *nerveux* to describe a state.

$3.$ $\hspace{1em}$ $\textrm{sont}$    [1 mark]

* *Mes parents* corresponds to *ils*, so the correct form is *sont*. We use *$\textit{\^{e}tre}$* with *calmes* to describe a characteristic.\

  \

  **Model answer**: Aujourd'hui, ma soeur est malade et elle a $\text{tr\`{e}s}$ froid. Moi, je suis en forme, mais je suis un peu nerveux parce que j'ai un examen demain. Heureusement, mes parents sont $\text{tr\`{e}s}$ calmes et ils m'aident beaucoup.

$4.$ $\hspace{1em}$ $\textrm{avons}$    [1 mark]

* The subject is *nous*, so the correct form is *avons*. We use *avoir* with *un $\textit{caract\`{e}re}$* to talk about personality.

$5.$ $\hspace{1em}$ $\textrm{sont}$    [1 mark]

* *Mes parents* corresponds to *ils*, so the correct form is *sont*. We use *$\textit{\^{e}tre}$* to describe a personal characteristic.

$6.$ $\hspace{1em}$ $\textrm{a}$    [1 mark]

* *Mon $\textit{fr\`{e}re}$* corresponds to *il*, so the correct form is *a*. We use *avoir* to describe physical features.

$7.$ $\hspace{1em}$ $\textrm{avons}$    [1 mark]

* *Mon $\textit{fr\`{e}re}$ et moi* includes the speaker and corresponds to *nous*, so the correct form is *avons*. *Avoir faim* is a fixed expression in French.

$8.$ $\hspace{1em}$ $\textrm{sont}$    [1 mark]

* *Nos parents* corresponds to *ils*, so the correct form is *sont*. We use *$\textit{\^{e}tre}$* to express location.\

  \

  **Model answer**: Dans ma famille, nous avons tous des $\text{caract\`{e}res}$ assez $\text{diff\'{e}rents}$. Mes parents sont $\text{tr\`{e}s}$ sociables, tandis que mon $\text{fr\`{e}re}$ est $\text{plut\^{o}t}$ $\text{r\'{e}serv\'{e}}$. Il a les cheveux courts et les yeux verts. $\text{Apr\`{e}s}$ le sport, mon $\text{fr\`{e}re}$ et moi avons souvent faim, mais nos parents sont $\text{g\'{e}n\'{e}ralement}$ encore au travail.

$9.$ $\hspace{1em}$ $\textrm{il a les yeux verts}$    [1 mark]

* *Est* is correct because *$\textit{\^{e}tre}$* is used with *grand* to describe a physical characteristic. The second verb must be *a* because *il* is the subject and we use *avoir* to describe eye colour.

$10.$ $\hspace{1em}$ $\textrm{ nous sommes toujours très détendus}$    [1 mark]

- *Avons* is correct because *avoir* is used with *temps*. The second verb must be *sommes* because *nous* is the subject and we use *$\textit{\^{e}tre}$* with *$\textit{d\'{e}tendus}$* to describe a state.\
