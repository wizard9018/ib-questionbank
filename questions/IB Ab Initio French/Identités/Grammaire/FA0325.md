# FA0325

**Choose the correct possessive adjective.**

$\hspace{1em}$J’ai une soeur. **\[-1-]** soeur s’appelle Anouk.    [1 mark]

* A.$\hspace{1em}$Ma

* B.$\hspace{1em}$Mon

* C.$\hspace{1em}$Ta

* D.$\hspace{1em}$Ton

$\hspace{1em}$Tu as deux $\text{fr\`{e}res}$. **\[-2-]** $\text{fr\`{e}res}$ parlent $\text{fran\c{c}ais}$.    [1 mark]

* A.$\hspace{1em}$Ton

* B.$\hspace{1em}$Tes

* C.$\hspace{1em}$Mes

* D.$\hspace{1em}$Son

**Match each sentence to the correct possessive adjective. There are more options than sentences.** [3 marks]

| $\hspace{1em}$Sentence | $\hspace{4em}$Options |

| :- | :- |

| $\hspace{1em}$Nous avons deux amis : **\[-3-]** amis. | $\hspace{4em}$A.$\hspace{1em}$notre |

| $\hspace{1em}$Tu as une grand-$\text{m\`{e}re}$ : **\[-4-]** grand-$\text{m\`{e}re}$. | $\hspace{4em}$B.$\hspace{1em}$nos |

| $\hspace{1em}\text{B\'{e}a}$ a un cousin : **\[-5-]** cousin. | $\hspace{4em}$C.$\hspace{1em}$sa |

| | $\hspace{4em}$D.$\hspace{1em}$son |

| | $\hspace{4em}$E.$\hspace{1em}$ta |

| | $\hspace{4em}$F.$\hspace{1em}$ma |

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* *Ma* is correct because the speaker says *J’* and *soeur* is feminine and singular.

* *Options incorrectes :* B, C, D

* **B** : *Mon* is masculine, but *soeur* is feminine.

* **C** : *Ta* is feminine but does not refer to the speaker.

* **D** : *Ton* does not refer to the speaker.

$2.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* *Tes* is correct because the owner is *Tu* and *$\textit{fr\`{e}res}$* is plural.

* *Options incorrectes :* A, C, D

* **A** : *Ton* is singular, but *$\textit{fr\`{e}res}$* is plural.

* **C** : *Mes* is plural but it does not refer to *tu*.

* **D** : *Son* does not refer to *tu*.

$3.$ $\hspace{1em}$ $\textrm{B}$    [1 mark]

* *Nos* is correct because it is used before plural nouns, the speaker says *nous* and *amis* is plural.

* *Options incorrectes :* A, C, D,E, F

* **A** : *Notre* refers to *nous*, but it is used for singular nouns, and *amis* is plural.

* **C** : *Sa* is feminine and it is used with to *il* or *elle*.

* **D** : *Son* is masculine and it is used with *il* or *elle*.

* **E** : *Ta* is feminine and it is used with *tu*.

* **F** : *Ma* is feminine and it is used with *je*.

$4.$ $\hspace{1em}$ $\textrm{E}$    [1 mark]

* *Ta* is correct because it is used before feminine and singular nouns, the owner is *tu* and *$\textit{grand-m\`{e}re}$* is feminine and singular.

* *Options incorrectes :* A, B, C, D F

* **A** : *Notre* is singular and it is used with *nous*.

* **B** : *Nos* is plural and it is used with *nous*.

* **C** : *Sa* is feminine and it is used with *il* or *elle*.

* **D** : *Son* is masculine and it is used with *il* or *elle*.

* **F** : *Ma* is feminine and it is used with *je*.

$5.$ $\hspace{1em}$ $\textrm{D}$    [1 mark]

* *Son* is correct because it is used before masculine and singular nouns, the owner is *$\textit{B\'{e}a}$* and *cousin* is masculine and singular.

* *Options incorrectes :* A, B, C,E, F

* **A** : *Notre* is singular and it is used with *nous*.

* **B** : *Nos* is plural and it is used with *nous*.

* **C** : *Sa* is feminine and it is used with *il* or *elle*.

* **E** : *Ta* is feminine and it is used with *tu*.

* **F** : *Ma* is feminine and it is used with *je*.

**Grammar reminder**

Possessive adjectives show who a person or thing belongs to.

* They go before the noun: *ma maison, sa famille*.

* They agree with what is possessed, not with the owner.

| $\hspace{1em}$Before singular nouns$\hspace{1.5em}$ | $\hspace{1em}$Before plural nouns$\hspace{1.5em}$ | $\hspace{1em}$English$\hspace{1.5em}$ |

| :- | :- | :- |

| $\hspace{1em}$Mon (for masculine nouns)$\newline\hspace{1em}$Ma (for feminine nouns) | $\hspace{1em}$Mes | $\hspace{1em}$My |

| $\hspace{1em}$Ton (for masculine nouns)$\newline\hspace{1em}$Ta (for feminine nouns) | $\hspace{1em}$Tes | $\hspace{1em}$Your (singular, familiar) |

| $\hspace{1em}$Son (for masculine nouns)$\newline\hspace{1em}$Sa (for feminine nouns) | $\hspace{1em}$Ses | $\hspace{1em}$His/Her |

| $\hspace{1em}$Notre | $\hspace{1em}$Nos | $\hspace{1em}$Our |

| $\hspace{1em}$Votre | $\hspace{1em}$Vos | $\hspace{1em}$Your (singular or plural, formal) |

| $\hspace{1em}$Leur | $\hspace{1em}$Leurs | $\hspace{1em}$Their |

Note: *mon* is used before a feminine noun that begins with a vowel or a silent *h*.
