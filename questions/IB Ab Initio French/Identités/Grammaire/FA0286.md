# FA0286

**Choose the correct adjective.**

$\hspace{1em}$Mon ami est ****\[-1-]****.    [1 mark]

* A.$\hspace{1em}$travailleur

* B.$\hspace{1em}$travailleuse

* C.$\hspace{1em}$travailleurs

* D.$\hspace{1em}$travailleuses

**Complete each sentence with the correct form of the adjective in brackets.** [2 marks]

$\hspace{1em}$Les filles sont **\[-2-]** *($\textit{fatigu\'{e}}$)*.

$\hspace{1em}$Ses copains sont $\text{tr\`{e}s}$ **\[-3-]** *($\textit{int\'{e}ressant}$)*.

**Each sentence contains one adjective-agreement error. Write the correct word.**

$4.$ $\hspace{1em}$Ma soeur est assez amusant.    [1 mark]

$5.$ $\hspace{1em}$Ma $\text{m\`{e}re}$ est $\text{tr\`{e}s}$ patientes.    [1 mark]

---

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{A}$    [1 mark]

* *Travailleur* is correct because it describes *mon ami*, which is masculine singular.

* *Options incorrectes :* B, C, D

* **B**: *Travailleuse* is feminine singular.

* **C**: *Travailleurs* is masculine plural.

* **D**: *Travailleuses* is feminine plural.

$2.$ $\hspace{1em}$ $\textrm{fatigu\'{e}es}$    [1 mark]

* *$\textit{Fatigu\'{e}es}$* is correct because it describes *les filles*, which is feminine plural.

$3.$ $\hspace{1em}$ $\textrm{int\'{e}ressants}$    [1 mark]

* *$\textit{Int\'{e}ressants}$* is correct because it describes *ses copains*, which is masculine plural.

$4.$ $\hspace{1em}$ $\textrm{amusante}$    [1 mark]

* *Amusante* is correct because it describes *ma soeur*, which is feminine singular.

$5.$ $\hspace{1em}$ $\textrm{patiente}$    [1 mark]

* *Patiente* is correct because it describes *ma $\textit{m\`{e}re}$* which is singular.
