# FA0279

**The sentence below contains one plural noun error. Find the error and write the correct word.**

$1.$ $\hspace{1em}$Sur cette photo, Farah porte deux collier et une bague.    [1 mark]

**The sentences below each contain one plural noun error. The errors are underlined. Write the correct words.**

$2.$ $\hspace{1em}$Pour cacher ses $\underline{\textrm{genous}}$, Hugo porte un pantalon long.    [1 mark]

$3.$ $\hspace{1em}$Sur ce dessin, les deux personnages ont des $\underline{\textrm{cousx}}$ $\text{tr\`{e}s}$ longs.    [1 mark]

**Complete the paragraph. Use the correct singular or plural form of each noun in brackets.** [3 marks]

Pour $\text{d\'{e}crire}$ mon style, je $\text{pr\'{e}pare}$ une page avec plusieurs photos. On y voit mes **\[-4-]** *(pull)* $\text{pr\'{e}f\'{e}r\'{e}s}$ $\text{\`{a}}$ $\text{c\^{o}t\'{e}}$ de ma jupe. J'aime aussi les **\[-5-]** *(bandeau)* de couleurs $\text{diff\'{e}rentes}$. Tous ces accessoires sont faits dans le $\text{m\^{e}me}$ **\[-6-]** *(tissu)*.

## 评分标准 / Mark scheme

$1.$ $\hspace{1em}$ $\textrm{colliers}$    [1 mark]

* *Deux* requires the plural of *collier*. Add regular *-s*: *colliers*.\

  \

  **Model answer**: Sur cette photo, Farah porte deux colliers et une bague.

$2.$ $\hspace{1em}$ $\textrm{genoux}$    [1 mark]

* *Ses* requires a plural noun. *Genou* is an exception to the usual *-ou* + *-s* rule: it takes *-x*.\

  \

  **Model answer**: Pour cacher ses genoux, Hugo porte un pantalon long.

$3.$ $\hspace{1em}$ $\textrm{cous}$    [1 mark]

* *Des* and *$\textit{tr\`{e}s}$ longs* require the plural of *cou*. This noun follows the regular *-ou* + *-s* rule.\

  \

  **Model answer**: Sur ce dessin, les deux personnages ont des cous $\text{tr\`{e}s}$ longs.

$4.$ $\hspace{1em}$ $\textrm{pulls}$    [1 mark]

* *Mes* requires a plural noun. Pull takes regular *-s*, giving pulls; the following *$\textit{pr\'{e}f\'{e}r\'{e}s}$* also refers to more than one item.

$5.$ $\hspace{1em}$ $\textrm{bandeaux}$    [1 mark]

* *Les* requires the plural. *Bandeau* ends in *-eau*, so add *-x*.

$6.$ $\hspace{1em}$ $\textrm{tissu}$    [1 mark]

* *Le $\textit{m\^{e}me}$* refers to one shared fabric, so use the singular form: *tissu*. \

  \

  **Model answer**: Pour $\text{d\'{e}crire}$ mon style, je $\text{pr\'{e}pare}$ une page avec plusieurs photos. On y voit mes pulls $\text{pr\'{e}f\'{e}r\'{e}s}$ $\text{\`{a}}$ $\text{c\^{o}t\'{e}}$ de ma jupe. J'aime aussi les bandeaux de couleurs $\text{diff\'{e}rentes}$. Tous ces accessoires sont faits dans le $\text{m\^{e}me}$ tissu.
