# AA742

**Maximum mark: 5**

The area, $A$, of a given square can be represented by the function

$$
\begin{aligned}
A(P) &= \dfrac{P^2}{16}, \hspace{0.5em} P \geq 0,
\end{aligned}
$$
where
$P$ is the perimeter of the square.

The graph of the function $A$, for $0 \leq P \leq 20$, is shown below.

![8c2c1a298c1b79e92e64f94fe2b4a4d452e488ad.svg](images/8c2c1a298c1b79e92e64f94fe2b4a4d452e488ad.svg)

1.  Find the value of $A(20)$. [1 mark]

2.  On the grid above, draw the graph of the inverse function, $A^{-1}$.
    [3 marks]

3.  In the context of the question, explain the meaning of
    $A^{-1}(4) = 8$. [1 mark]
