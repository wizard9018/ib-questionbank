# AA009

**Maximum mark: 7**

In an arithmetic sequence, the third term is $41$ and the ninth term is
$23$.

1.  Find the common difference. [2 marks]

2.  Find the first term. [2 marks]

3.  Find the smallest value of $n$ such that $S_n < 0$. [3 marks]

---

## 评分标准 / Mark scheme

1.  We have $u_3 = 41$ and $u_9 = 23$.
    Hence, using the $n$th term formula $u_n = u_3 + (n-3)d$ with
    $n = 9$, we get
    $$
    \begin{aligned}
    u_9 &= u_3 + (9-3)d \\[6pt]
    23 &= 41 + (9-3)d \hspace{1.8em} \\[6pt]
    -18 &= 6d
    \end{aligned}
    $$

    $$
    d = -3 \hspace{5em}
    $$

2.  Using the $n$th term formula $u_n = u_3 + (n-3)d$ with $n = 1$, we
    obtain
    $$
    \begin{aligned}
    \hspace{0.5em} u_1 &= u_3 + (1-3)d \\[6pt]
    &= 41 + (1-3)(-3) \\[6pt]
    &= 47
    \end{aligned}
    $$

3.  We have
    $$
    \begin{aligned}
    S_n &< 0 \\[10pt]
    \dfrac{n}{2}(2u_1 + (n-1)d) &< 0 \\[6pt]
    \hspace{0.7em} \dfrac{n}{2}(2(47) + (n-1)(-3)) &< 0 \\[6pt]
    \dfrac{n}{2}(97-3n) &< 0 \\[8pt]
    32.333 &< n \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

    Hence the smallest value of $n$ such that $S_n < 0$ is
     $n=33$
