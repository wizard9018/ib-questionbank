# AA026

**Maximum mark: 6**

Given a sequence of integers, between $20$ and $300$, which are
divisible by $9$.

1.  Find their sum. [2 marks]

2.  Express this sum using sigma notation. [2 marks]

An arithmetic sequence has first term $-500$ and common difference of
$8$. The sum of the first $n$ terms of this sequence is negative.

3.  Find the greatest value of $n$. [2 marks]

---

## 评分标准 / Mark scheme

1.  We have an arithmetic sequence $27,\, 36,\, 45,\,\dots,\, 297$ with
    $u_1 = 27$ and $d = 9$.

    The number of terms in the sequence is
    $$
    \begin{aligned}
    \hspace{2.8em} n &= \floor*{\dfrac{300}{9}} - 2 \\[6pt]
    & = 31
    \end{aligned}
    $$
    Hence, using the sum of $n$ terms formula
    $S_n = \dfrac{n}{2}(u_1 + u_n)$ with $n = 31$, $u_1 = 27$ and
    $u_n = 297$, we get
    $$
    \begin{aligned}
    \hspace{3em} S_{31} &= \dfrac{31}{2}(27 + 297) \\[5pt]
    &= 5022
    \end{aligned}
    $$
    Alternatively,
    using the sum of $n$ terms formula
    $S_n = \dfrac{n}{2}(2u_1 + (n-1)d)$ with $n = 31$, $u_1 = 27$ and
    $d = 9$, we get
    $$
    \begin{aligned}
    \hspace{7.6em} S_{31} &= \dfrac{31}{2}(2(27) + (31-1)(9)) \\[5pt]
    &= 5022
    \end{aligned}
    $$

2.  Since $u_1 = 27$, $d = 9$ and $n = 31$, we have
    $$
    \begin{aligned}
    \hspace{3em} S_{31}  &= 27 + (27 + 9) + (27 + 2\cdot9) + \cdots + (27 + 30\cdot9) \\[8pt]
    &= \displaystyle{\sum_{n = 1}^{31}} (27 + (n-1)(9)) \\[5pt]
    &\hspace{0.3em}\text{or} \\[5pt]
    &= \displaystyle{\sum_{n = 1}^{31}} 9(n+2)
    \end{aligned}
    $$

3.  Using the sum of $n$ terms formula
    $S_n = \dfrac{n}{2}(2u_1 + (n-1)d)$ with $u_1 = -500$ and $d = 8$,
    we have
    $$
    \begin{aligned}
    S_n &< 0 \\[6pt]
    \hspace{4em} \dfrac{n}{2}(2(-500) + (n-1)(8)) &< 0 \\[6pt]
    n(-500 + (n-1)(4)) &< 0 \\[8pt]
    n &< 126 \hspace{3em} [\text{by using G.D.C}]
    \end{aligned}
    $$
    Hence
    the greatest value of $n$ is
     $125$
