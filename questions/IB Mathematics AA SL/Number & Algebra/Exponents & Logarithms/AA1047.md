# AA1047

**Maximum mark: 5**

Find the range of possible values for $p$ such that $$e^{2x}+2\ln p = 4e^x$$ has at least one real solution.

---

## 评分标准 / Mark scheme

The equation is a hidden quadratic. Let $k=e^x$
$$
\begin{aligned}
k^2 - 4k + 2 \ln p &= 0  \tag*{\textbf{R1}}
\end{aligned}
$$

Using the discriminant we can say a quadratic equation has at least one real solution if $ b^2-4ac\geq 0$.

Therefore, we have at least one real solution for $k$ if
$$
\begin{aligned}
(-4)^2-4(2\ln p) &\geq 0 \tag*{\textbf{M1A1}}\\[7pt]
16-8\ln p &\geq 0 \\[7pt]
8\ln p &\leq 16  \\[7pt]
\ln p &\leq 2 \\[6pt]
&\hspace{-2.33em}\boxed{0 < p \leq e^2} \hspace{3em} \text{($\ln p > 0$)} \tag*{\textbf{A1A1}}\\[-11pt]
\end{aligned}
$$
