# AA050

**Maximum mark: 6**

Let $\log_2 a = p$, $\log_2 b = q$, $\log_2 c = r$. Write down the
following expressions in terms of $p$, $q$ and $r$.

1.  $\log_2\Big(\dfrac{ab}{c}\Big)$ [2 marks]

2.  $\log_2\Big(\dfrac{a^2c}{b^3}\Big)$
    [2 marks]

3.  $\log_a b$ [2 marks]

---

## 评分标准 / Mark scheme

1.  Using the properties of logarithms, we get

     $$
     \begin{aligned}
     \log_2\Big(\dfrac{ab}{c}\Big) &= \log_2 (ab) - \log_2 c \\[6pt]
     &= (\log_2 a + \log_2 b) - \log_2 c  \\[10pt]
     &= p + q - r
     \end{aligned}
     $$

2.  Using the properties of logarithms, we find

     $$
     \begin{aligned}
     \hspace{0.9em} \log_2\Big(\dfrac{a^2c}{b^3}\Big) &= \log_2 \big(a^2c\big) - 3\log_2 b \\[6pt]
     &= (2\log_2 a + \log_2 c) - 3\log_2 b \\[10pt]
     &= 2p + r - 3q
     \end{aligned}
     $$

3.  Using the properties of logarithms, we obtain

     $$
     \begin{aligned}
     \log_a b &= \dfrac{\log_2 b}{\log_2 a} \hspace{2em}  \\[6pt]
     &= \dfrac{q}{p}
     \end{aligned}
     $$
