# AA1043

**Maximum mark: 7**

![q1043](images/q1043.png)

A boat is moored to a wooden pier. The boat travels up and down as the tide rises and falls.

The height of the boat above the sea floor is modelled by the following function
$$
\begin{aligned}
    h(t)=30+10\cos{\left(\tfrac{1}{2}t-1\right)}
\end{aligned}
$$
Where $t$ is measured in hours and $t\geq0$.

1.  Find the initial height, velocity and acceleration of the boat. [3 marks]

After $k$ hours the boat has travelled up and down a total distance of  $60\,$metres.

2.  Find $k$. [2 marks]

There is an interval of time,  $a\leq t \leq b$ within the first $8$ hours, for which the speed of the boat is increasing.

3.  Find $a$ and $b$. [2 marks]

---

## 评分标准 / Mark scheme

1.  Using the formula we recall
    $$
    \begin{aligned}
        v(t)&=h'(t) &a(t)=h''(t)
    \end{aligned}
    $$
    Hence, we can use a G.D.C. to sketch $h$, $v$ and $a$.

    ![a1043-1](images/a1043-1.png)

    Evaluating each function for $t=0$, we get
    $$
    \begin{aligned}
        h(0)=35.4\, m \hspace{2em} v(0)=4.21\, ms^{-1} \hspace{2em} a(0)=-1.35\, ms^{-2} \tag*{\textbf{A1A1A1}}
    \end{aligned}
    $$

2.  Using the formula for the total distance travelled we can write the following equation.
    $$
    \begin{aligned}
        \int_{0}^{k} |v(t)|dt&=60 \tag*{\textbf{(M1)}}\\[4pt]
        k&=18.8495...\hspace{2em}\text{[by using G.D.C.]}\\[6pt]
        &=\hspace{0.525em}\boxed{18.8\,\text{hours}}  \tag*{\textbf{A1}}
    \end{aligned}
    $$

3.  If the velocity and the acceleration have the same sign then the speed of the boat is increasing.

    Here is a graph showing the first $8$ hours.

    ![a1043-2](images/a1043-2.png)

    The blue dashed line shows the only region in which the acceleration and velocity have the same sign, i.e. they are both negative.

    Using the G.D.C. we can identify $a$, this is when $v(t)=0$ and $b$, when $a(t)=0$.
    $$
     \tag*{\textbf{M1}}
    $$
    $\textcolor{white}{gap}$

    Therefore the speed increases in the following region
    $$
    \begin{aligned}
        2<t<5.14 \tag*{\textbf{A1}}
    \end{aligned}
    $$
