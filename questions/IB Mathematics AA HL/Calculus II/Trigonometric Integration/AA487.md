# AA487

**Maximum mark: 6**

Using the substitution $u = e^x - 4$, find
$\displaystyle \int \dfrac{e^x}{e^{2x} - 8e^x + 25}\,\textrm dx$.

---

## 评分标准 / Mark scheme

Using the substitution $u = e^x - 4$, we get
$$
\begin{aligned}
\int \dfrac{e^x}{e^{2x} - 8e^x + 25}\,\textrm dx & =  \int \dfrac{e^x}{(e^x - 4)^2 - 16 + 25}\,\textrm dx \\[6pt]
& =  \int \dfrac{\textrm du}{u^2 + 9} \\[6pt]
%& =  \dfrac{1}{9} \int \dfrac{\textrm du}{\left(\frac{u}{3}\right)^2 + 1} \\[6pt]
& =  \dfrac{1}{3}\left[\arctan\left(\dfrac{u}{3}\right) + C_1\right] \\[8pt]
& \hspace{.275em} =  \dfrac{1}{3}\arctan\left(\dfrac{e^x - 4}{3}\right) + C_2
\end{aligned}
$$

  where $C_2 = \dfrac{1}{3}C_1$.
