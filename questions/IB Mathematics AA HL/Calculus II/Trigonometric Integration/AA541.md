# AA541

**Maximum mark: 6**

Let $f(x) = e^x\sin (\pi x) + 4$, for $0 \leq x \leq 2$. The graph of
$f$ is given below.

![8d8079cd938bd3fee8ac06dc5fe6de258f4e43d9.svg](images/8d8079cd938bd3fee8ac06dc5fe6de258f4e43d9.svg)

There is an $x$-intercept at the point P, a local maximum point at A,
where $x = a$, and a local minimum point at B, where $x = b$.

1.  Write down the $x$-coordinate of P.[1 mark]

2.  Find the value of $a$ and the value of $b$.[2 marks]

3.  Find $\displaystyle \int_a^b f(x)\, \mathrm{d}x$. Explain why this
    is not the area of the shaded region. [3 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    e^x\sin (\pi x) + 4 & = 0\\[6pt]
    &\hspace{-2mm} x = 1.42
    \qquad\quad \mbox{[by using G.D.C.]}\hspace{1cm}
    \end{aligned}
    $$

2.  We know that $a$ and $b$ are $x$-coordinates of the min/max. Hence
    we can graph the function and find the minimum and maximum points on
    the curve.

    We find that
      $a = 0.598 \mbox{ and } b = 1.60$

3.  We have
    $$
    \int_{0.598}^{1.60} (e^x\sin (\pi x) + 4)\,\textrm d x  = 2.81
    \qquad\quad \mbox{[by using G.D.C.]}
    $$

    The shaded area is given by the integral
    $\displaystyle\int_a^b |f(x)|\, \textrm d x$ which is not equal to
    $\displaystyle\int_a^b f(x)\, \textrm d x$.
