# AA479

**Maximum mark: 17**

Consider the function
$f(x) = \dfrac{\sqrt{x}}{2\cos x}$,
$\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$.

1.
    1.  Show that the $x$-coordinate of the maximum point on the curve
        $y = f(x)$ satisfies the equation $1 + 2x\tan x = 0$.

    2.  Determine the values of $x$ for which $f(x)$ is an increasing
        function. [7 marks]

2.  Sketch the graph of $y = f(x)$, showing clearly the maximum point
    and any asymptotic behaviour. [3 marks]

3.  Find the coordinates of the point on the curve $y = f(x)$ where the
    normal to the curve is perpendicular to the line $y = x$. Give your
    answers correct to two decimal places. [4 marks]

Consider the region bounded by the curve $y = f(x)$, the $x$-axis and
the lines

$x = \dfrac{3\pi}{4}$, $x = \dfrac{4\pi}{3}$.

4.  The region is now rotated through $2\pi$ radians about the
    $x$-axis. Find the volume of
    revolution, giving your answer correct to two
    decimal places. [3 marks]

## 评分标准 / Mark scheme

1.
    1.  Using the quotient rule, we have
        $$
        \begin{aligned}
        f'(x) &= \dfrac{\mathrm{d}}{\mathrm{d}x}\bigg[\dfrac{\sqrt{x}}{2\cos x}\bigg] \\[6pt]
        &= \dfrac{\big[\frac{1}{2\sqrt{x}}\big](2\cos x) - (\sqrt{x})\big[\hspace{-0.15em}-2\sin x\big]}{4\cos^2 x} \hspace{2.5em} \\[10pt]
        &= \dfrac{\cos x + 2x\sin x}{4\sqrt{x}\cos^2x}
        \end{aligned}
        $$

- Hence, solving the equation $f'(x) = 0$ for $x$ in the
    interval $\Big(\dfrac{\pi}{2},\dfrac{3\pi}{2}\Big)$, we get

    $$
    \begin{aligned}
    \hspace{7em} \dfrac{\cos x + 2x\sin x}{4\sqrt{x}\cos^2x} &= 0 \\[6pt]
    \cos x + 2x \sin x &= 0 \\[12pt]
    1 + 2x \tan x &= 0  \\[12pt]
    x &\approx 2.98 \hspace{3em} [\text{by using G.D.C.}] \\
    \end{aligned}
    $$

    Hence $2.98$ is the only critical number of $f$.
    Using the ID Test, we have

    ![99904fa2a1440839a3eeb2c7207c2691008819a6.svg](images/99904fa2a1440839a3eeb2c7207c2691008819a6.svg)

    The sign of $f'$ changes from positive to negative at $2.98$.
    Therefore, by the First Derivative Test, $f$ has a local maximum at
    $2.98$.
    Hence $x = 2.98$ is the $x$-coordinate of the maximum point that
    satisfies the equation $(1)$.

     $\dfrac{\pi}{2} < x < 2.98$

    Hence, solving the equation $f'(x) = 1$ for $x$ in the interval
    $\Big(\dfrac{\pi}{2},\dfrac{3\pi}{2}\Big)$, we get
    $$
    \begin{aligned}
    \hspace{7em} \dfrac{\cos x + 2x\sin x}{4\sqrt{x}\cos^2x} &= 1 \\[6pt]
    \cos x + 2x\sin x&= 4\sqrt{x}\cos^2x \\[12pt]
    1 + 2x\tan x &= 4\sqrt{x}\cos x \\[12pt]
    x &\approx 2.31 \hspace{3em} [\text{by using G.D.C.}] \\
    \end{aligned}
    $$

    Evaluating $y = f(x)$ for $x = 2.31$, we obtain
    $$
    \begin{aligned}
    f(2.31) &= \dfrac{\sqrt{2.31}}{2\cos\hspace{0.05em}(2.31)} \hspace{2em} \\[8pt]
    &\approx -1.13 \\
    \end{aligned}
    $$
    Hence the coordinates of such point
    are  $(2.31,-1.13)$

4.  Using the volume of revolution formula, we find
    $$
    \begin{aligned}
    \hspace{7.9em} V &= \int_\frac{3\pi}{4}^\frac{4\pi}{3} \pi y^2\,\mathrm{d}x \\[6pt]
    &= \int_\frac{3\pi}{4}^\frac{4\pi}{3} \pi \bigg[\dfrac{x}{4\cos^2 x}\bigg]\hspace{0.05em}\mathrm{d}x \\[15pt]
    &\approx 7.28  \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$
