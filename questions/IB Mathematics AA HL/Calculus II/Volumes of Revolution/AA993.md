# AA993

**Maximum mark: 15**

The function $f$ is defined by $f(x)=-\dfrac{2^x}{x+1}+8$, where $x \geq 0$.

1. Find $f'(x)$. [4 marks]

2. Find the gradient of $f(x)$ when $x=3$. [1 mark]

The region enclosed by the curve $y=f(x)$, the $x$-axis and the $y$-axis is rotated through $2\pi$ radians about the $x$-axis to form a solid of revolution.

3. Find the volume of this solid. [4 marks]

Consider a function $g$ such that $g(6)=2$ and $g'(6)=7$.

4. Find the value of

    $$\\[1em]$$

    1. $(g\circ f)(3)$

    2. $(g \circ f)'(3)$ [6 marks]

---

## 评分标准 / Mark scheme

1. Use the quotient rule
    $$
    \begin{aligned}
        f'(x)&=\dfrac{\mathrm{d}(-\frac{2^x}{x+1}+8)}{\mathrm{d}x}\\[10pt]
        &=-\dfrac{\ln 2 \times 2^x\times(x+1)-2^x}{(x+1)^2}\\[10pt]
        &= \dfrac{2^x-\ln 2 \times 2^x\times(x+1)}{(x+1)^2}\\[10pt]
        &=\dfrac{2^x(1-(x+1)\ln2)}{(x+1)^2}\hspace{0.525em}\\[10pt]
    \end{aligned}
    $$
2. Use the function from (a)
    $$
    \begin{aligned}
        f'(3) &= -0.886294...
    \end{aligned}
    $$
    The gradient at $x=3$ is $-0.886$.

3. Consider the following diagram which shows the part of the curve which will be rotated.

    ![ans](images/ans.png)

    We need to find, $b$, the $x$-axis intercept.
    Using G.D.C. the value of $b=5.75621...$
    Now use the formula for the volume of revolution
    $$
    \begin{aligned}
        V&=\pi\int_{0}^{5.75621...} \left(-\dfrac{2^x}{x+1}+8\right)^2 \,\mathrm{d}x\\[6pt]
        &=578.460...\\[6pt]
    \end{aligned}
    $$
    The volume of the rotated shape is $578$ units$^3$.
4. 1. First use G.D.C. to find the value of $f(3)=6$. Then use composite functions
        $$
        \begin{aligned}
            (g\circ f)(3)&=g(f(3))\\[3pt]
            &=g(6)\\[3pt]
            &=2\\[3pt]
        \end{aligned}
        $$
    2. Use chain rule and the answer from part (b)
        $$
        \begin{aligned}
            (g \circ f)'(3)&=g'(f(3))\times f'(3)\\[3pt]
            &=g'(6)\times  -0.886294...\\[3pt]
            &=7\times  -0.886294...\\[3pt]
            &=-6.20
        \end{aligned}
        $$
