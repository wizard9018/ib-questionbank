# AA131

**Maximum mark: 11**

Consider $f(x) = \dfrac{1}{2} - \ln\left(\sqrt{x^2-4}\right)$.

1.  Find the largest possible domain $D$ for $f$ to be a function.
    [2 marks]

The function $f$ is defined by
$f(x) = \dfrac{1}{2} - \ln\left(\sqrt{x^2-4}\right)$, for $x \in D$.

2.  Sketch the graph of $y = f(x)$, showing clearly the
    equations of asymptotes and the coordinates of any intercepts with
    the axes. [3 marks]

3.  Explain why $f$ is an even function. [1 mark]

4.  Explain why the inverse function $f^{-1}$ does not exist.
    [1 mark]

The function $g$ is defined by
$g(x) = \dfrac{1}{2} - \ln\left(\sqrt{x^2-4}\right)$, for
$x \in (2,\infty)$.

5.  Find the inverse function $g^{-1}$ and state its domain.
    [4 marks]

## 评分标准 / Mark scheme

1.  The square root function is defined on $[0,\infty)$ and natural
    logarithm function is defined on $(0,\infty)$.

    Hence $f$ is a function if
    $$
    \begin{aligned}
    \textstyle \sqrt{x^2-4} &> 0 \hspace{2em} \\[6pt]
    x^2-4 &> 0 \\[6pt]
    x^2 &> 4 \\[6pt]
    |x| &> 2 \\[6pt]
    x < -2 \hspace{0.5em}&\hspace{0.2em}\text{or}\hspace{0.7em} x > 2
    \end{aligned}
    $$

    Hence the largest possible domain for $f$ to be a function is

     $$
     \begin{aligned}
     D = (-\infty,-2)\cup(2,\infty)
     \end{aligned}
     $$

3.
    $\text{The function \(f\) is even because its graph is symmetric about the \(y\)-axis.}$

    OR

    $\text{The function \(f\) is even because it satisfies \(f(x) = f(-x)\) for all \(x \in D\).}$

4.
    $\text{The inverse function \(f^{-1}\) does not exist because \(f\) is not bijective.}$

5.  If we solve the equation $(g\circ g^{-1})(x) = x$ for
    $y = g^{-1}(x)$, we get
    $$
    \begin{aligned}
    g(g^{-1}(x)) &= x \\[15pt]
    g(y) &= x \\[10pt]
    \dfrac{1}{2} - \textstyle \ln\hspace{-0.1em}\big(\sqrt{y^2-4}\big) &= x \\[6pt]
    \textstyle \ln\hspace{-0.1em}\big(\sqrt{y^2-4}\big) &= \dfrac{1}{2} - x  \\[9pt]
    \textstyle \sqrt{y^2-4} &= e^{\left(\frac{1}{2} - x\right)} \\[12pt]
    y^2-4 &= e^{2\left(\frac{1}{2} - x\right)} \\[14pt]
    y^2 &= e^{1 - 2x} + 4 \\[13pt]
    y &= \textstyle \sqrt{e^{1 - 2x} + 4} \hspace{2.7em} \\
    \end{aligned}
    $$

    Hence an expression for $g^{-1}$ is
     $g^{-1}(x) = \sqrt{e^{1 - 2x} + 4}$

    The domain of $g^{-1}$ is
     $\mathbb{R}$
