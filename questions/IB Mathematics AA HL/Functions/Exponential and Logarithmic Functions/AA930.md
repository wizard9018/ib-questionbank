# AA930

**Maximum mark: 6**

Consider the function $f(x)=\dfrac{e^x-e^{-x}}{2}$, $x\in \mathbb{R}$.

1. Show that $f$ is an odd function. [2 marks]

Now, consider the function $g$ given by $g(x) = \dfrac{x^4+2}{2x}$ , $x\in \mathbb{R}, x \neq 0$.

2. By considering the graph of $y=f(x)-g(x)$, solve $f(x)>g(x)$ for $x\in \mathbb{R}$. [4 marks]

---

## 评分标准 / Mark scheme

1. Evaluating $f(-x)$, we get 

    $$

    \begin{aligned}

    f(-x) &= \dfrac{e^{-x}-e^{-(-x)}}{2} \\[10pt]

    &= \dfrac{e^{-x}-e^{x}}{2} \\[10pt]

    &= -\dfrac{e^{x}-e^{-x}}{2} \\[10pt]

    &= -f(x) \\[-8pt]

    \end{aligned}

    $$

    

    $$\text{Therefore, $f(x)$ is an odd function}$$

2. If $f(x)-g(x)>0$, then $f(x)>g(x)$. Using G.D.C., we get

    ![AA930a](images/AA930a.PNG)

    We see that $f(x)-g(x)>0$ for $-4.55 < x < 0$ and $x > 4.55$.

    Therefore $f(x)>g(x)$ over the intervals

    $-4.55 < x < 0 \text{ and } x > 4.55$
