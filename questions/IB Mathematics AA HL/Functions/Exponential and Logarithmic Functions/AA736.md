# AA736

**Maximum mark: 6**

The number of users on a new social network on January 1st $2018$ was $320\hspace{0.15em}000$. One year later, on January 1st $2019$, the number of users on this network is estimated to be $350\hspace{0.15em}000$. The number
of the users on this network, $N$, can be modelled by the function

$$
\begin{aligned}
N(t) = 320\hspace{0.15em}000\times b^t, \hspace{0.5em} t\geq0,
\end{aligned}
$$

where $t$ is the number of years since January 1st $2018$ and $b$ is a constant.

1.  Find the **exact** value of $b$. [2 marks]

2.  Estimate the number of the users on this network there will be in
    $2023$.[2 marks]

3.  Determine the year during which the number of the social network users
    reaches one million. [2 marks]

---

## 评分标准 / Mark scheme

1.  If we solve the equation $N(1) = 350\hspace{0.15em}000$ for $b$, we get
    $$
    \begin{aligned}
    320\hspace{0.15em}000\times b &= 350\hspace{0.15em}000 \hspace{4.4em} \tag*{\textbf{(M1)}} \\[9pt]
    b &= \dfrac{350\hspace{0.15em}000}{320\hspace{0.15em}000} \\[-9pt]
    \end{aligned}
    $$
    $$
    \begin{equation*}
    \hspace{2.7em}\boxed{b = \dfrac{35}{32} \text{ or } 1.09375} \tag*{\textbf{A1}}
    \end{equation*}
    $$

2.  If we evaluate $N(t)$ for $t = 5$, we obtain
    $$
    \begin{aligned}
    \hspace{2.6em} N(5) &= 320\hspace{0.15em}000\times \left(\dfrac{35}{32}\right)^5 \tag*{\textbf{(M1)}} \\[4pt]
    &\approx 500\hspace{0.15em}887.6... \\[10pt]
    &\hspace{0.275em}\boxed{\approx 501\hspace{0.15em}000 \text{ users}}\hspace{1em}\text{(3 s.f.)} \tag*{\textbf{A1}}
    \end{aligned}
    $$

3. Solving the equation $N(t) = 1\hspace{0.15em}000\hspace{0.15em}000$ for $t$, we find
    $$
    \begin{aligned}
    \hspace{4.75em} 320\hspace{0.15em}000\times \left(\dfrac{35}{32}\right)^t &= 1\hspace{0.15em}000\hspace{0.15em}000 \tag*{\textbf{M1}}\\[6pt]
    t &\approx 12.71... \text{ years} \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$
