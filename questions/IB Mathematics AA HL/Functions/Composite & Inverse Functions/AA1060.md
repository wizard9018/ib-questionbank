        $$

        &\boxed{f(2)=5} \tag*{\textbf{A1}}

        $$

        

    2. Using our previous answer and the point $(5, 3)$ on $g(x)$ we can write

        $$

        \begin{aligned}

        &g(f(2))=g(5) \tag*{\textbf{(M1)}}\\[3pt]

        &\hspace{0.525em}\boxed{g(f(2))=3} \tag*{\textbf{A1}}

        \end{aligned}

        $$

2. We can evaluate $g(2)=4$ using the graph.

    $$

    \begin{aligned}

    \tag*{\textbf{(A1)}}

    \end{aligned}

    $$

    Recall the definition of an inverse function if $f(a)=b$ then $f^{-1}(b)=a$.

    From the table we can see that $f(3)=4$, therefore 

    $$

    \begin{aligned}

    f^{-1}(g(x))=f^{-1}(4)\\[6pt]

    \boxed{f^{-1}(4)=3} \tag*{\textbf{A1}}

    \end{aligned}

    $$
