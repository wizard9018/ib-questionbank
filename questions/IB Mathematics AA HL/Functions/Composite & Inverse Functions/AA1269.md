# AA1269

**Maximum mark: 5**

The graph of $y=f(x)$ for $-3\leq x\leq 4$ is shown in the following diagram.

![AA1269-q](images/AA1269-q.JPEG)

1.  Write down the value of $f(2)$. [1 mark]

Let $g(x)=2f(x)-1$ for $-3\leq x\leq 4$. 

2.  On the axes above, sketch the graph of $g$. [2 marks]

3.  Hence determine the value of $(g\circ f)(2) $. [1 mark]

4.  Hence solve the equation $(f\circ g)(x)=0$ when $x>0$. [1 mark]

4.  We have the equation $(f\circ g)(x)=0$. The L.H.S. is a composite function which can be rewritten

    $$

    \begin{aligned}

        (f\circ g)(x)&= f(\textcolor{red}{g(x)})

    \end{aligned} 

    $$

    

    Here we can see that $\textcolor{red}{g(x)}$ is the inner function and $f(x)$ is the outer function, meaning that the output of $g$ will be the input of $f$.

    By considering the graph of $f(x)$ we see that when $x=3$ then $f(x)=0$.

    ![AA1269-a5](images/AA1269-a5.JPEG)

    This means in order to have an output of $0$, the input must be $3$.

    

    $$

    \begin{aligned}

        f(\textcolor{red}{g(x)})=0\\[6pt]

        f(\textcolor{red}{3})=0

    \end{aligned}

    $$

    Therefore we need to find the value of $x$, where $x>0$, such that $g(x)=3$. 

    From part (c), we know that $g(1)=3$, and we can see that this is the only possible solution when $x>0$.

    Hence if $x>0$ and $(f\circ g)(x)=0$ then $x=1$.

    $$

    \begin{aligned}

         \tag*{\textbf{A1}}

    \end{aligned}

    $$
