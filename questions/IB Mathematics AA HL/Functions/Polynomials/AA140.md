# AA140

**Maximum mark: 13**

It is given that $f(x) = 2x^4 + 5x^3 + ax^2 + bx + 4$, for
$x \in \mathbb{R}$, where $a,b \in \mathbb{Z}$.

1.  Given that $x^2 + x - 2$ is a factor of $f(x)$, find the values of
    $a$ and $b$. [4 marks]

2.  Factorise $f(x)$ into a product of linear factors. [4 marks]

3.  Sketch the graph of $y = f(x)$, labeling the maximum and minimum
    points and the $x$ and $y$ intercepts. [3 marks]

4.  Using your graph, state the range of values of $c$ for which
    $f(x) = c$ has exactly four real roots. [2 marks]

## 评分标准 / Mark scheme

1.  Factorising $x^2 + x - 2$ into a product of linear factors, we have
    $$
    \begin{aligned}
    x^2 + x - 2 = (x-1)(x+2)
    \end{aligned}
    $$
    Hence $(x-1)$ and $(x+2)$
    are both factors of $f(x)$.

    Hence, using the factor theorem, we get
    $$
    \begin{aligned}
    f(1) &= 0 \\[6pt]
    2(1)^4 + 5(1)^3 + a(1)^2 + b(1) + 4 &= 0 \\[6pt]
    2 + 5 + a + b + 4 &= 0 \\[6pt]
    a + b &= -11 \hspace{3em}
    \end{aligned}
    $$

    Using the factor theorem again, we obtain
    $$
    \begin{aligned}
    f(-2) &= 0 \hspace{4em} \\[6pt]
    2(-2)^4 + 5(-2)^3 + a(-2)^2 + b(-2) + 4 &= 0 \\[7pt]
    32 - 40 + 4a - 2b + 4 &= 0 \\[7pt]
    4a - 2b &= 4 \\[7pt]
    2a - b &= 2 \hspace{3em}
    \end{aligned}
    $$
    Hence, solving the system of
    two linear equations $(1)-(2)$ for $a$ and $b$, we find

    $$
    \begin{aligned}
    a = -3\hspace{0.525em}\text{ and }\hspace{0.525em}b = -8
    \end{aligned}
    $$
