# AA979

**Maximum mark: 5**

Let $f(x)=\sin(x+c)$, where $0\leq x \leq a$ and $a,c \in \mathbb{R}^+$.

1. By sketching a suitable graph, or otherwise, find the largest value of $a$ for which the inverse function $f^{-1}$ exists in the case where $c=\dfrac{\pi}{2}$. [2 marks]

2. Find the largest value of $a$ for which the inverse function $f^{-1}$ exists in the case where $c=\pi$. [1 mark]

3. Find the largest value of $a$ for which the inverse function $f^{-1}$ exists in the case where $\dfrac{\pi}{2} < c < \pi$. Give your answer in terms of $c$. [2 marks]

---

## 评分标准 / Mark scheme

1. By sketching the graph of $\sin x$ under a horizontal shift $\dfrac{\pi}{2}$ units to the left, we have

    ![aa979a](images/aa979a.PNG)

    Note that a function must be one-to-one for its inverse to exist. The diagram shows that $f$ is one-to-one if its domain is restricted to $\left[0,\pi\right]$.

    Therefore, $\boxed{a = \pi}.$

2. By sketching the graph of $\sin x$ under a horizontal shift $\pi$ units to the left, we have

    ![aa979b](images/aa979b.PNG)

    The diagram shows that $f$ is one-to-one if its domain is restricted to $\left[0,\dfrac{\pi}{2}\right]$. 

    Therefore, $\boxed{a = \dfrac{\pi}{2}}.$

3. This time the graph of $f$ is an intermediate graph between the previous two:

    ![aa979c](images/aa979c.PNG)

    Hence, we can see that $f$ is one-to-one over the interval $\left[0,\dfrac{3\pi}{2}-c\right]$. 

    Therefore, $\boxed{a=\dfrac{3\pi}{2}-c}$
