# AA126

**Maximum mark: 4**

A rational function is defined by $f(x) = a + \dfrac{b}{x-c}$, for
$x \neq c$, where $a,b,c \in \mathbb{Z}$.

The following diagram represents the graph of $y = f(x)$.

![174d0bc6234e556e44492ded9dca1f7d93a7be93.svg](images/174d0bc6234e556e44492ded9dca1f7d93a7be93.svg)

Using the information on the graph,

1.  state the value of $a$ and the value of
    $c$ ; [2 marks]

2.  find the value of $b$. [2 marks]

---

## 评分标准 / Mark scheme

1.
    $a = -4$  and
     $c = 4$

2.  The point P lies on the graph of $y = f(x)$.
    Hence, using the coordinates of P, we get
    $$
    \begin{aligned}
    \hspace{2.5em} 0 &= f(6) \\[6pt]
    0 &= -4 + \dfrac{b}{6-4} \\[2pt]
    4 &= \dfrac{b}{2} \\
    \end{aligned}
    $$

    $$
    b = 8 \hspace{1.9em}
    $$
