# AA380

**Maximum mark: 8**

A continuous random variable $X$ has a probability density function $f$
given by
$$
f(x) = \left\{\begin{array}{cl}
\dfrac{1}{72}(-x^2 + 12x - 20), & 4 < x < 10, \\[9pt]
0, & \text{otherwise}.
\end{array}\right.
$$

1.  Find $\mathrm{E}[X]$. [2 marks]

2.  Find $\mathrm{Var}(X)$. [3 marks]

3.  Find $\mathrm{P}(\mu - \sigma < X < \mu)$. [3 marks]

---

## 评分标准 / Mark scheme

1.  Using the formula for the expected value of $X$, we get
    $$
    \begin{aligned}
    \hspace{2.4em} \mathrm{E}[X] &= \int_{-\infty}^{\infty} xf(x)\,\mathrm{d}x \\[6pt]
    &=  \int_4^{10} x\bigg[\dfrac{1}{72} (-x^2+12x-20)\bigg]\hspace{0.05em}\mathrm{d}x \\[6pt]
    &= \dfrac{1}{72}\int_4^{10} \hspace{-0.2em}\big[\hspace{-0.2em}-x^3+12x^2-20x\big]\hspace{0.1em}\mathrm{d}x \\[14pt]
    &= 6.5 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

2.  Using the formula for the expected value of $X^2$, we have
    $$
    \begin{aligned}
    \hspace{2.3em} \mathrm{E}[X^2] &= \int_{-\infty}^{\infty} x^2f(x)\,\mathrm{d}x \\[6pt]
    &=  \int_4^{10} x^2\bigg[\dfrac{1}{72} (-x^2+12x-20)\bigg]\hspace{0.05em}\mathrm{d}x \\[6pt]
    &= \dfrac{1}{72}\int_4^{10} \hspace{-0.2em}\big[\hspace{-0.2em}-x^4+12x^3-20x^2\big]\hspace{0.1em}\mathrm{d}x \\[14pt]
    &= 44.4 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$
    Hence,
    using the formula for the variance of $X$, we obtain

    $$
    \begin{aligned}
    \hspace{0.55em} \mathrm{Var}(X) &= \mathrm{E}[X^2] - (\mathrm{E}[X])^2 \\[6pt]
    &= 44.4 - (6.5)^2 \\[7pt]
    &= 2.15
    \end{aligned}
    $$

3.  We have $\mu = 6.5$ and
    $\mu - \sigma = 6.5 - \sqrt{2.15} \approx 5.034$. Hence we find

    $$
    \begin{aligned}
    \hspace{1.5em} \mathrm{P}(\mu - \sigma < X < \mu) &= \mathrm{P}(5.034 < X < 6.5) \\[11pt]
    &= \int_{5.034}^{6.5} f(x)\,\mathrm{d}x \\[6pt]
    &=  \int_{5.034}^{6.5} \dfrac{1}{72}(-x^2+12x-20)\,\mathrm{d}x \\[12pt]
    &\approx 0.321 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$
