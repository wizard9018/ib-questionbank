# AA456

**Maximum mark: 7**

A continuous random variable $X$ has a probability density function $f$
given by
$$
f(x) = \left\{
\begin{array}{ccl}
\dfrac{\pi x}{16}\sin\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big), & 0 \leq x \leq 4, \\[9pt]
0, & \text{otherwise}.
\end{array} \right.
$$
Find $\mathrm{P}(0 \leq X \leq 2)$.

---

## 评分标准 / Mark scheme

Using the integration by parts formula, we get
$$
\begin{aligned}
\mathrm{P}(0 \leq X \leq 2) &= \int_0^2 \dfrac{\pi x}{16}\sin\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big)\hspace{0.05em}\mathrm{d}x \\[6pt]
&= \int_0^2 u\,\mathrm{d}v \hspace{2em} \Big[u = \dfrac{\pi x}{16},\hspace{0.5em} \mathrm{d}v = \sin\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big)\hspace{0.05em}\mathrm{d}x\Big] \\[6pt]
&= \Big[uv\Big]\Big|_0^2 - \int_0^2 v\,\mathrm{d}u \hspace{2em} \Big[v = -\dfrac{4}{\pi}\cos\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big),\hspace{0.5em} \mathrm{d}u = \dfrac{\pi}{16}\,\mathrm{d}x\Big] \\[8pt]
&= \Big[\hspace{-0.15em}-\dfrac{x}{4}\cos\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big)\Big]\Big|_0^2 + \dfrac{1}{4}\int_0^2 \cos\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big)\hspace{0.05em}\mathrm{d}x \\[10pt]
&= \Big[\hspace{-0.15em}-\dfrac{x}{4}\cos\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big)\Big]\Big|_0^2 + \dfrac{1}{\pi}\Big[\sin\hspace{-0.15em}\Big(\dfrac{\pi x}{4}\Big)\Big]\Big|_0^2 \\[12pt]
&= 0 + \dfrac{1}{\pi}\Big[1 - 0\Big] \\[12pt]
\mathrm{P}(0 \leq X \leq 2)&=\dfrac{1}{\pi}
\end{aligned}
$$
