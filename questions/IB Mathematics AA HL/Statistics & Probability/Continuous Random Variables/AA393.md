# AA393

**Maximum mark: 13**

The continuous random variable $X$ has probability density function $f$
given by
$$

f(x) = \left\{\begin{array}{cl}
3p\hspace{0.025em}x, & 0 \leq x < 1, \\[6pt]
p(4-x), & 1 \leq x < 4, \\[6pt]
0, & \text{otherwise}.
\end{array} \right.
$$

1.  Show that $p = \dfrac{1}{6}$.  [3 marks]

2.  Find $\mathrm{P}(X < 2)$.  [3 marks]

3.  Given that
    $\mathrm{P}(a < X < 2) = 3\hspace{0.05em}\mathrm{P}(3\hspace{0.02em}a < X < 2)$,
    where $\dfrac{1}{3} < a < \dfrac{2}{3}$,

    find the value of $a$. [7 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    \int_{-\infty}^\infty f(x) \,\mathrm{d}x &= 1 \\[6pt]
    \int_0^1 3px\,\mathrm{d}x + \int_1^4p(4-x)\,\mathrm{d}x &= 1 \\[6pt]
    p\bigg[\int_0^1 3x\,\mathrm{d}x + \int_1^4(4-x)\,\mathrm{d}x\bigg]\hspace{-0.2em} &= 1 \\[13pt]
    6p &= 1 \hspace{3em} [\text{by using G.D.C.}] \hspace{1.6em} \\
    \end{aligned}
    $$

    $$
    p = \dfrac{1}{6}
    $$

2.  We have
    $$
    \begin{aligned}
    \hspace{4.1em} \mathrm{P}(X < 2) &= 1 - \mathrm{P}(X \geq 2) \\[9pt]
    &= 1 - \dfrac{1}{6}\int_2^4 (4-x)\, \mathrm{d}x \\[6pt]
    &= \dfrac{2}{3} \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

3.  We have
    $$
    \begin{aligned}
    \hspace{5.8em} \mathrm{P}(a < X < 2) &= \dfrac{1}{2}\int_a^1x\, \mathrm{d}x + \dfrac{1}{6}\int_1^2(4-x)\, \mathrm{d}x \hspace{2.5em} [\text{since $a < 1$}] \\[6pt]
    &= \dfrac{1}{2}\bigg[\dfrac{x^2}{2}\bigg]\bigg|_a^1\hspace{-0.15em} + \dfrac{5}{12} \hspace{3em} [\text{by using G.D.C.}] \\[6pt]
    &= \dfrac{1}{2}\bigg[\dfrac{1}{2} - \dfrac{a^2}{2}\bigg]\hspace{-0.15em} + \dfrac{5}{12} \\[6pt]
    &= \dfrac{2}{3} - \dfrac{a^2}{4}
    \end{aligned}
    $$
    and

    $$
    \begin{aligned}
    \hspace{2.6em} \mathrm{P}(3a < X < 2) &= \dfrac{1}{6}\int_{3a}^2(4-x)\, \mathrm{d}x \hspace{3em} [\text{since $1 < 3a < 2$}] \\[6pt]
    &= \dfrac{1}{6}\bigg[4x - \dfrac{x^2}{2}\bigg]\bigg|_{3a}^2 \\[6pt]
    &= \dfrac{1}{6}\bigg[6 - \bigg(12a - \hspace{-0.25em}\dfrac{9a^2}{2}\bigg)\hspace{-0.1em}\bigg] \\[6pt]
    &= 1 - 2a + \dfrac{3a^2}{4}
    \end{aligned}
    $$
    Hence, solving the
    equation
    $\mathrm{P}(a < X < 2) = 3\hspace{0.05em}\mathrm{P}(3a < X < 2)$ for
    $a$, we get
    $$
    \begin{aligned}
    \dfrac{2}{3} - \dfrac{a^2}{4} &= 3\bigg[1 - 2a + \dfrac{3a^2}{4}\bigg] \\[5pt]
    \dfrac{2}{3} - \dfrac{a^2}{4} &= 3 - 6a + \dfrac{9a^2}{4} \\[7pt]
    \hspace{1.1em} \dfrac{5a^2}{2} - 6a + \dfrac{7}{3} &= 0 \\
    \end{aligned}
    $$

    $$
    \hspace{3em} a \approx 0.488 \hspace{3em} [\text{since $a < 1$}] \hspace{0.8em}
    $$
