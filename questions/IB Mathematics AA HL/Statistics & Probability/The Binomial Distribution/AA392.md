# AA392

**Maximum mark: 7**

The random variable $X$ has a binomial distribution with parameters $n$
and $p$.

It is given that $\mathrm{E}(X) = 4.5$.

1.  Find the least possible value of $n$. [2 marks]

It is further given that $\mathrm{P}(X \leq 1) = 0.03683$, correct to
$4$ significant figures.

2.  Determine the value of $n$ and the value of $p$.
    [5 marks]

---

## 评分标准 / Mark scheme

1.  Using the formula for the expected value of
    $X \sim \mathrm{B}(n,p)$, we have
    $$
    \begin{aligned}
    \hspace{4.9em} \mathrm{E}(X) &= np \\[6pt]
    4.5 &= np \\[6pt]
    4.5 &\leq n \hspace{3em} [\text{since $p \leq 1$}]
    \end{aligned}
    $$

    Hence the least possible value of $n$ is
     $5$

2.  We have
    $$
    \begin{aligned}
    np &= 4.5  \\[6pt]
    n &= \dfrac{4.5}{p} \hspace{1.35em}
    \end{aligned}
    $$
    Using
    the probability mass function of $X \sim \mathrm{B}(n,p)$, we get

    $$
    \begin{aligned}
    \mathrm{P}(X \leq 1) &= \mathrm{P}(X = 0) + \mathrm{P}(X = 1) \\[8pt]
    0.03683 &= (1-p)^n + np\hspace{0.05em}(1-p)^{n-1} \\[6pt]
    (1-p)^{\frac{4.5}{p}}\hspace{-0.2em} + 4.5(1-p)^{\frac{4.5}{p}-1} &= 0.03683 \hspace{3em} [\text{by $(1)$ and $(2)$}] \hspace{0.4em} \\
    \end{aligned}
    $$

    $$
    \hspace{10.85em} p \approx 0.281 \hspace{3.1em} [\text{by using G.D.C.}]
    $$
    Hence we obtain
    $$
    \begin{aligned}
    \hspace{11.1em} n &= \dfrac{4.5}{p} \\[6pt]
    &= \hspace{-0.2em}\bigg\lfloor\dfrac{4.5}{0.281}\bigg\rfloor\hspace{-0.2em} \hspace{3em} [\text{since $p > 0.281$}]\\[12pt]
    &= 16
    \end{aligned}
    $$
