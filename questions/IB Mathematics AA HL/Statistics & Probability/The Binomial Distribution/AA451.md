# AA451

**Maximum mark: 6**

A bag contains $8$ blue marbles, $12$ green marbles and $m$ red marbles.
A marble is selected at random and replaced. This
is performed three times.

1.  Write down the probability that the first marble selected is blue.
    [1 mark]

Let $X$ be the number of blue marbles selected.

2.  Find the smallest value of $m$ for which
    $\mathrm{Var}(X) < 0.5$. [5 marks]

---

## 评分标准 / Mark scheme

1.
    $\mathrm{P}(\text{blue}) = \dfrac{8}{20+m}$

2.  We have $X \sim \mathrm{B}(3, 8/(20+m))$.
    Hence, using the formula for the variance of $X$, we get

    $$
    \begin{aligned}
    \hspace{2em} \mathrm{Var}(X) &= np(1-p) \\[11pt]
    &= 3\bigg[\dfrac{8}{20+m}\bigg]\hspace{-0.1em}\bigg[1-\dfrac{8}{20+m}\bigg] \\[6pt]
    &= \dfrac{24(12+m)}{(20+m)^2}
    \end{aligned}
    $$
    Hence, solving the
    inequality $\mathrm{Var}(X) < 0.5$ for $m > 0$, we obtain
    $$
    \begin{aligned}
    \hspace{7.5em} \dfrac{24(12+m)}{(20+m)^2} &< \dfrac{1}{2} \\[6pt]
    48(12+m) &< (20+m)^2 \\[12pt]
    m &> 17.9 \hspace{2.7em} [\text{by using G.D.C.}] \\
    \end{aligned}
    $$

    Hence the smallest value of $m \in \mathbb{Z}^+$ for which
    $\mathrm{Var}(X) < 0.5$ is
     $18$
