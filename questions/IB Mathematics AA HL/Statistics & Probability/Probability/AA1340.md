# AA1340

**Maximum mark: 6**

Valeria sells jewellery online. There is an $p\%$ chance that a customer returns the jewellery. 

If the customer returns the jewellery there is an $87\%$ chance that they will leave a review.

If the customer does not return the jewellery there is a $68\%$ chance the customer will leave a review. 

This is shown in the following tree diagram. 

![AA1340a1](images/AA1340a1.JPEG)

1.    Complete the tree diagram. [2 marks]

The probability that a customer returns the jewellery given that they left a review is $0.3$.

2.    Find the value of $p$. [4 marks]

2. The probability a customer returns the jewellery $\textit{given}$ that they left a review is $0.3$.

    This is a conditional probability so we need the conditional probability formula.

    $$

    \begin{aligned}

    \mathrm{P}(A|B)&=\frac{\mathrm{P}(A\cap B)}{\mathrm{P}(B)}

    \end{aligned}

    $$

    Writing the formula in the context of the situation we have

    $$

    \begin{aligned}

    \mathrm{P}(\text{return }|\text{ review})&=\frac{\mathrm{P}(\text{return }\cap \text{ review})}{\mathrm{P}(\text{review})}\\[9pt]

    0.3&=\frac{\mathrm{P}(\text{return }\cap \text{ review})}{\mathrm{P}(\text{review})}

    \end{aligned}

    $$

    We can use the tree diagram from part (a) to find the necessary probabilities.

    The probability of a return $\textbf{and}$ a review is the top branch so we multiply those probabilities.

    $$

    \begin{aligned}

    \mathrm{P}(\text{return }\cap \text{ review})&=0.87p\tag*{\textbf{{(M1)}}}

    \end{aligned}

    $$

    The probability that the customer leaves a review comes from two branches. We need to multiply both branches and then add the probabilities.

    $$

    \begin{aligned}

    \mathrm{P}(\text{review})&=\mathrm{P}(\text{return }\cap \text{ review})+\mathrm{P}(\text{no return }\cap \text{ review})\\[6pt]

    &=p(0.87)+(1-p)(0.68)\\[6pt]

    &=0.87p+0.68(1-p)\tag*{\textbf{{(A1)}}}

    \end{aligned}

    $$

    As this is a calculator question we can substitute these results into the formula without simplifying and then use the G.D.C. to solve for $p$.

    $$

    \begin{aligned}

    0.3&=\frac{0.87p}{0.87p+0.68(1-p)}\tag*{\textbf{{(M1)}}}\\[9pt]

    p&=0.2509...

    \end{aligned}

    $$

    Recall that $p$ is a percentage. Hence our final answer is

    $$

    \begin{aligned}

    p&=0.2509...\times100\%\\[6pt]

    &=25.1\,\%\tag*{\textbf{{A1}}}

    \end{aligned}

    $$
