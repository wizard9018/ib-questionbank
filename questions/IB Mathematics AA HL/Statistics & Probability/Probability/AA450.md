# AA450

**Maximum mark: 15**

Bag $A$ contains $4$ red balls and $3$ green balls. Bag $B$ contains $4$
red balls and $1$ green ball.

1.  A ball is randomly chosen from both bags. Find the probability they
    are of different colours. [4 marks]

A biased coin is flipped. If heads is shown, a ball is randomly selected
from bag $A$. If tails is shown, a ball is randomly selected from bag
$B$.

2.  Complete the tree diagram below. [4 marks]

![b943e8259f3fec832b0d2065d55ebab352b7eca7.svg](images/b943e8259f3fec832b0d2065d55ebab352b7eca7.svg)

3.  The biased coin is flipped and a ball is randomly selected.
    Find the probability the ball is red. [4 marks]

4.  Given that a red ball is selected, find the probability the
    biased coin showed heads. [3 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    \mathrm{P}(\text{different colours}) &= \mathrm{P}(\text{red}\hspace{0.15em}|\hspace{0.1em}A \text{ \& } \text{green}\hspace{0.1em}|\hspace{0.15em}B) + \mathrm{P}(\text{green}\hspace{0.1em}|\hspace{0.15em}A \text{ \& } \text{red}\hspace{0.15em}|\hspace{0.1em}B) \\[12pt]
    &= \dfrac{4}{7}\times\dfrac{1}{5} + \dfrac{3}{7}\times\dfrac{4}{5} \\[8pt]
    &= \dfrac{4}{35} + \dfrac{12}{35} \\[9pt]
    &= \dfrac{16}{35}
    \end{aligned}
    $$

2.  If we complete the tree digram below, we get

    ![fa250012019075c6bf4a146817ce9c01f4cb174d.svg](images/fa250012019075c6bf4a146817ce9c01f4cb174d.svg)

3.  Using the tree diagram, we obtain
    $$
    \begin{aligned}
    \hspace{3.5em} \mathrm{P}(\text{red}) &= \mathrm{P}(\text{heads})\hspace{0.05em}\mathrm{P}(\text{red}\hspace{0.15em}|\hspace{0.15em}\text{heads}) + \mathrm{P}(\text{tails})\hspace{0.05em}\mathrm{P}(\text{red}\hspace{0.15em}|\hspace{0.15em}\text{tails}) \\[10pt]
    &= \dfrac{2}{3}\times\dfrac{4}{7} + \dfrac{1}{3}\times\dfrac{4}{5} \\[6pt]
    &= \dfrac{8}{21} + \dfrac{4}{15} \\[6pt]
    &= \dfrac{68}{105}
    \end{aligned}
    $$

4.  Using the conditional probability formula, we find
    $$
    \begin{aligned}
    \hspace{2em} \mathrm{P}(\text{heads}\hspace{0.15em}|\hspace{0.15em}\text{red}) &= \dfrac{\mathrm{P}(\text{heads})\hspace{0.05em}\mathrm{P}(\text{red}\hspace{0.15em}|\hspace{0.15em}\text{heads})}{\mathrm{P}(\text{red})} \\[9pt]
    &= \dfrac{\raisebox{0.6em}{$\dfrac{2}{3}\times\dfrac{4}{7}$}}{\raisebox{-0.75em}{$\dfrac{68}{105}$}} \\[9pt]
    &= \dfrac{10}{17}
    \end{aligned}
    $$
