# AA419

**Maximum mark: 7**

The following Venn diagram shows two events $A$ and $B$, where
$\mathrm{P}(A) = 0.3$, $\mathrm{P}(A\cap B) = 0.2$ and
$\mathrm{P}(A\cup B) = 0.7$. The values of $p$, $q$, $r$ and $s$ are
$\text{probabilities}$.

![8ca7dc69310d14eee80cfb8fc216080fc079bcf5.svg](images/8ca7dc69310d14eee80cfb8fc216080fc079bcf5.svg)

1.  Write down the value of $r$. [1 mark]

2.  Find the value of:
    1.  $p$;

    2.  $q$;
    3.  $s$. [4 marks]

3.  Find $\mathrm{P}(B)$. [2 marks]

---

## 评分标准 / Mark scheme

1.
    $r = 0.2$

2.
    1.  Using the Venn diagram, we get
        $$
        \begin{aligned}
        \mathrm{P}(A) &= p + \mathrm{P}(A \cap B) \hspace{2.2em} \\[6pt]
        0.3 &= p + 0.2 \\
        \end{aligned}
        $$

        $$
        p = 0.1 \hspace{5.1em}
        $$

    2.  Using the Venn diagram, we get
        $$
        \begin{aligned}
        \mathrm{P}(A \cup B) &= \mathrm{P}(A) + q \hspace{6.1em} \\[6pt]
        0.7 &= 0.3 + q \\
        \end{aligned}
        $$

        $$
        q = 0.4 \hspace{5.1em}
        $$

    3.  Using the Venn diagram, we get
        $$
        \begin{aligned}
        \mathrm{P}(U) &= \mathrm{P}(A \cup B) + s \hspace{2.3em} \\[6pt]
        1 &= 0.7 + s \\
        \end{aligned}
        $$

        $$
        s = 0.3 \hspace{5.1em}
        $$

3.  Using the Venn diagram, we find
    $$
    \begin{aligned}
    \mathrm{P}(B) &= \mathrm{P}(A \cap B) + q \\[6pt]
    &= 0.2 + 0.4 \\[6pt]
    &= 0.6
    \end{aligned}
    $$
