# AA357

**Maximum mark: 6**

Consider two events $A$ and $B$ such that $\mathrm{P}(A) = 3k$,
$\mathrm{P}(B) = k$, $\mathrm{P}(A \cap B) = \dfrac{k^2}{2}$ and
$\mathrm{P}(A \cup B) = 0.78$. Find:

1.  the value of $k$; [3 marks]

2.  $\mathrm{P}(A' \cap B)$. [3 marks]

---

## 评分标准 / Mark scheme

1.  Using the combined events formula, we get
    $$
    \begin{aligned}
    \hspace{2.7em} \mathrm{P}(A \cup B) &= \mathrm{P}(A) + \mathrm{P}(B) - \mathrm{P}(A \cap B) \\[6pt]
    0.78 &= 3k + k - \dfrac{k^2}{2} \hspace{2.9em} [0 < k < 1] \\
    \end{aligned}
    $$

    $$
    \hspace{6.2em} k = 0.2 \hspace{4em} [\text{by using G.D.C.}]
    $$

2.  Using the equality
    $A' \cap B = B\hspace{-0.05em}\setminus\hspace{-0.1em}(A \cap B)$,
    we obtain
    $$
    \begin{aligned}
    \mathrm{P}(A' \cap B) &= \mathrm{P}(B) - \mathrm{P}(A \cap B) \\[6pt]
    &= 0.2 - \dfrac{(0.2)^2}{2} \\[10pt]
    &= 0.18
    \end{aligned}
    $$
