# AA412

**Maximum mark: 6**

A bag contains $7$ blue and $5$ red marbles. Two marbles are selected at
random without replacement.

1.  Complete the tree diagram below. [3 marks]

![865fd050d3db84e24416b401670caec65ade51d0.svg](images/865fd050d3db84e24416b401670caec65ade51d0.svg)

2.  Find the probability that exactly one of the selected
    marbles is blue. [3 marks]

---

## 评分标准 / Mark scheme

1.  If we complete the tree digram below, we have

    ![de30fd1a308a84cd300cf6c87259b0d420284f80.svg](images/de30fd1a308a84cd300cf6c87259b0d420284f80.svg)

2.  Hence, using the tree diagram from part (a), we get

     $$
     \begin{aligned}
     \hspace{2.1em} \mathrm{P}(\text{exactly one is blue}) &= \mathrm{P}(\text{blue \& red}) + \mathrm{P}(\text{red \& blue}) \\[15pt]
     &= \mathrm{P}(\text{blue})\hspace{0.05em}\mathrm{P}(\text{red\hspace{0.15em}|\hspace{0.15em}blue}) + \mathrm{P}(\text{red})\hspace{0.05em}\mathrm{P}(\text{blue\hspace{0.15em}|\hspace{0.15em}red}) \\[10pt]
     &= \dfrac{7}{12}\times\dfrac{5}{11} + \dfrac{5}{12}\times\dfrac{7}{11} \\[7pt]
     &= \dfrac{70}{132} \\[8pt]
     &= \dfrac{35}{66}
     \end{aligned}
     $$
