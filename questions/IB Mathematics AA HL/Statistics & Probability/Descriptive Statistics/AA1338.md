# AA1338

**Maximum mark: 6**

The average daily water usage, $w$ (in litres), of 200 households in a city was recorded. The households were grouped based on their average daily consumption. The data is shown in the following table.

| **Water usage ($w$ litres)** | **Frequency** |

|:---:|:---: |

| $100 < w \leq 150$ | 10 |

| $150 < w \leq 200$ | 20 |

| $200 < w \leq 250$ | 88 |

| $250 < w \leq 300$ | 46 |

| $300 < w \leq 350$ | $p$ |

| $350 < w \leq 400$ | 8 |

1.    

    1.    Find the value of $p$. 

    2.    Write down the modal class. [2 marks]

The table has been used to create the following cumulative frequency curve.

![AA1338q1](images/AA1338q1.JPEG)

2.    Use the cumulative frequency curve to estimate the interquartile range. [2 marks]

3.    Given that $15\%$ of these families use more than $q$ litres per day, find the value of $q$. [2 marks]

## 评分标准 / Mark scheme

1.  1.  As the table shows data for $200$ households, the total frequency must be $200$.

        Hence, using the frequencies for each class, we can form an equation to solve for $p$.

        $$

        \begin{aligned}

        200&=10+20+88+46+p+8\\[6pt]

        200&=172+p\\[6pt]

        p&=28\tag*{\textbf{{A1}}}

        \end{aligned}

        $$

    2. The modal class is the class with the highest frequency.

        

        We can see that

        | **Water usage ($w$ litres)** | **Frequency** |

        | :---: | :---: |

        | $100 < w \leq 150$ | 10 |

        | $150 < w \leq 200$ | 20 |

        | $\textcolor{red}{200 < w \leq 250}$ | $\textcolor{red}{88}$ |

        | $250 < w \leq 300$ | 46 |

        | $300 < w \leq 350$ | $p$ |

        | $350 < w \leq 400$ | 8 |

        Since $88$ is the class with the highest frequency, the modal class is

        $$

        \begin{aligned}200<w \leq 250\tag*{\textbf{{A1}}}

        \end{aligned}

        $$

        Note, you must give the full inequality as your answer, not the associated frequency!

2. The interquartile range (IQR) is given by

    $$

    \begin{aligned}

    \text{IQR}&=Q_3-Q_1

    \end{aligned}

    $$

    Hence we need to find the lower quartile ($Q_1$) and the upper quartile  ($Q_3$).

    Let's start with $Q_1$, which is the 25th percentile — the value of $w$ below which $25\%$ of the data lies.

    

    Working out $25\%$ of 200 we get

    $$

    \begin{aligned}

    0.25 \times 200 &=50

    \end{aligned}

    $$

    which means that $Q_1$ is the $50$th household's usage.

    

    Similarly, $Q_2$ is the 75th percentile — the value of $w$ below which $75\%$ of the data lies.

    

    Finding $75\%$ of 200 we get

    $$

    \begin{aligned}

    0.75 \times 200 &=150

    \end{aligned}

    $$

    which means that $Q_3$ is the $150$th household's usage

    

    We can identify these two values on our graph and then read off the corresponding values of $w$.

    $$

    \begin{aligned}

    \tag*{\textbf{{(M1)}}}

    \end{aligned}

    $$

    ![AA1338a1](images/AA1338a1.JPEG)

    $Q_1=210$ and  $Q_3=280$.

    

    Using the formula for I.Q.R. we get an estimate of

    $$

    \begin{aligned}

    \text{I.Q.R.}&=Q_3-Q_1\\[6pt]

    &=280-210\\[6pt]

    &=70\,L\tag*{\textbf{{A1}}}

    \end{aligned}

    $$
