# AA1303

**Maximum mark: 7**

A market research survey asked $200$ teenagers for the number of minutes

they spend on their phones on a daily basis. The results were recorded

in the following box-and-whisker diagram.

![AA1303q](images/AA1303q.JPEG)

1.  Write down the median. [1 mark]

 

The following incomplete table shows the distribution of the responses

from these $200$ teenagers. 

|Number of minutes spent on phones daily ($x$)|Number of teenagers|

| :---: | :---: |

|$0\leq x \leq 40$|5|

|$40< x \leq 80$||

|$80< x \leq 120$|42|

|$120 < x \leq 160$|58|

|$160 < x \leq 200$|30|

|$200 < x \leq 240$||

2.  Complete the table. [2 marks]

3.  

    1.  Write down the mid-interval value for the $80 < x \leq 120$

        group.

    2.  Using the table, calculate an estimate for the mean number of

        minutes spent on phones daily by these $200$ teenagers.

        [3 marks]

    

The 200 teenages were chosen for the survey by randomly selecting

student ID numbers in a school, using a random number generator.

4.  Identify the sampling method used. [1 mark]

## 评分标准 / Mark scheme

1.  Let's label the five summary numbers on the given box-and-whisker

    diagram. Note that these numbers divides the whole range into four

    intervals of the same percentage.

    ![AA1303q1](images/AA1303q1.JPEG)

    The median is always the vertical line in the center of the box which separates the lower $50\%$ of the data from the upper $50\%$ of the data.

    Hence the median $145\text{ minutes.}$

2.  We can see from the labeled box-and-whisher diagram that the

    interval $0 < x \leq 80$ makes up $25\%$ of the sample. This

    interval includes the first two rows of the table. Hence the number

    of teenagers in the $40 < x \leq 80$ group is 

    $$

    \begin{aligned}

    \text{[number of teenagers, $40 < x \leq 80$]} &= 0.25 \times 200 - 5\\

    &= 45
    \end{aligned}

    $$

    

    

    Similarly, the interval $160 < x \leq 240$ makes up $25\%$ of the

    sample. This interval includes the last two rows of the table. Hence

    the number of teenagers in the $200 < x \leq 240$ group is

    

    $$

    \begin{aligned}

    \text{[number of teenagers, $200 < x \leq 240$]} &= 0.25 \times 200 - 30\\

    &= 20
    \end{aligned}

    $$

    

    Therefore, the complete table is as follows.

    |Number of minutes spent on phones daily ($x$)|Number of teenagers|

    | :---: | :---: |

    |$0\leq x \leq 40$|5|

    |$40< x \leq 80$|$\boxed{45}$|

    |$80< x \leq 120$|42|

    |$120 < x \leq 160$|58|

    |$160 < x \leq 200$|30|

    |$200 < x \leq 240$|$\boxed{20}$|

    

3.  

    1.  We calculate the mid-interval value by taking the average of the upper and lower boundaries. 

    

        $$

        \begin{aligned}

            \text{Mid-interval } &= \dfrac{80+120}{2} \\[6pt]

            & \hspace{0.525em}= 100

        \end{aligned}

        $$

    2.  Finding the mid-interval values of the other classes we have the following table. 

    |Number of minutes spent on phones daily ($x$)|Number of teenagers|

    | :---: | :---: |

    |$20$|5|

    |$60$|45|

    |$100$|42|

    |$140$|58|

    |$180$|30|

    |$220$|20|

    

    By entering these values into the G.D.C. we can find the mean.

    Hence $\mkern 1.5mu\overline{\mkern-1.5mux\mkern-1.5mu}\mkern 1.5mu \approx 125 \text{ minutes}$

    

4.  As all members of the population have an equal chance of being selected, this is an example of $\text{Simple Random Sampling}$.
