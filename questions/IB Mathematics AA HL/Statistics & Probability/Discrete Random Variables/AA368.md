# AA368

**Maximum mark: 6**

The faces of a fair six-sided die are numbered $2,4,4,4,6,6$. Let $X$ be
the discrete random variable that models the sum of scores obtained when
two such dice are rolled.

1.  Complete the probability distribution table for $X$. [3 marks]

    ![18726b7af4542fa7241b38af8ca727b997fa4361.svg](images/18726b7af4542fa7241b38af8ca727b997fa4361.svg)

2.  Find the expected value of $X$. [3 marks]

2.  Using the formula for the expected value of $X$, we get
    $$
    \begin{aligned}
    \mathrm{E}[X] &= \sum x\hspace{0.05em}\mathrm{P}(X=x) \\[10pt]
    &= 4\times\dfrac{1}{36} + 6\times\dfrac{6}{36} + 8\times\dfrac{13}{36} + 10\times\dfrac{12}{36} + 12\times\dfrac{4}{36} \\[10pt]
    &= \dfrac{4 + +36 + 104 + 120 + 48}{36} \\[10pt]
    &= \dfrac{312}{36} \\[10pt]
    &= \dfrac{26}{3}
    \end{aligned}
    $$
