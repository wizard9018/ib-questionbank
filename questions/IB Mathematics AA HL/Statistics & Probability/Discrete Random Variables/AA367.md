# AA367

**Maximum mark: 6**

A random variable $X$ has a probability distribution given in the
following table.

![f6a399c4b7f03138d76ff9f0562ae2dafad093bc.svg](images/f6a399c4b7f03138d76ff9f0562ae2dafad093bc.svg)

1.  Find the value of $p$. [1 mark]

2.  Determine the value of $\mathrm{E}[X^2]$. [2 marks]

3.  Hence find the value of $\mathrm{Var}(X)$. [3 marks]

---

## 评分标准 / Mark scheme

1.  Using the probability distribution table for $X$, we get
    $$
    \begin{aligned}
    \sum \mathrm{P}(X=x) &= 1 \hspace{11em} \\[6pt]
    0.1 + 0.2 + 0.3 + p + 0.1 + 0.05 &= 1 \\
    \end{aligned}
    $$

    $$
    \hspace{13.95em} p = 0.25 \hspace{3em} [\text{by using G.D.C.}]
    $$

2.  Using the formula for the expected value of $X^2$, we obtain
    $$
    \begin{aligned}
    \hspace{3em} \mathrm{E}[X^2] &= \sum x^2\hspace{0.05em}\mathrm{P}(X=x) \\[6pt]
    &= (-2)^2\hspace{-0.1em}\times0.1 + (-1)^2\hspace{-0.1em}\times0.2 + 0^2\hspace{-0.1em}\times0.3 + 1^2\hspace{-0.1em}\times0.25 + \cdots \\[8pt]
    &\phantom{= (-2)^2\hspace{-0.1em}\times0.1 + (-1)^2\hspace{-0.1em}\times0.2 \hspace{0.275em}} + 2^2\hspace{-0.1em}\times0.1 + 3^2\hspace{-0.1em}\times0.05 \\[9pt]
    &= 1.7
    \end{aligned}
    $$

3.  Using the formula for the expected value of $X$, we have
    $$
    \begin{aligned}
    \hspace{1.85em} \mathrm{E}[X] &= \sum x\hspace{0.05em}\mathrm{P}(X=x) \\[6pt]
    &= (-2)(0.1) + (-1)(0.2) + (0)(0.3) + (1)(0.25) + \cdots \\[6pt]
    &\phantom{= (-2)(0.1) + (-1)(0.2) \hspace{0.275em}} + (2)(0.1) + (3)(0.05) \\[9pt]
    &= 0.2
    \end{aligned}
    $$
    Hence, using the formula for the variance of
    $X$, we find
    $$
    \begin{aligned}
    \mathrm{Var}(X) &= \mathrm{E}[X^2] - (\mathrm{E}[X])^2 \hspace{0.5em}  \\[6pt]
    &= 1.7 - (0.2)^2 \\[7pt]
    &= 1.66
    \end{aligned}
    $$
