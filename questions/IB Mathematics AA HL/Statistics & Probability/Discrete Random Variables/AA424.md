# AA424

**Maximum mark: 6**

A random variable $X$ has a probability distribution given in the
following table.

![32fd72e5f84528f6d3185f34f3568275a692567d.svg](images/32fd72e5f84528f6d3185f34f3568275a692567d.svg)

1.  Find the value of $q$. [3 marks]

2.  Find $\mathrm{E}[X]$. [3 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    \sum \mathrm{P}(X = x) &= 1 \hspace{10.3em} \\[8pt]
    \dfrac{3}{10} + q + \dfrac{1}{10} + \dfrac{3}{20} + \dfrac{1}{4} &= 1 \\
    \end{aligned}
    $$

    $$
    \hspace{10.5em} q = 0.2 \hspace{3em} [\text{by using G.D.C.}]
    $$

2.  Using the formula for the expected value of $X$, we get
    $$
    \begin{aligned}
    \mathrm{E}[X] &= \sum x\hspace{0.05em}\mathrm{P}(X = x) \\[9pt]
    &= 0\times\dfrac{3}{10} + 1\times0.2 + 2\times\dfrac{1}{10} + 3\times\dfrac{3}{20} + 4\times\dfrac{1}{4} \\[12pt]
    &= 1.85
    \end{aligned}
    $$
