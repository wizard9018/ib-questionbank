# AA439

**Maximum mark: 6**

A random variable $X$ has a probability distribution given in the
following table.

![35887a4c5f30670cad47400b994b9e045edaade9.svg](images/35887a4c5f30670cad47400b994b9e045edaade9.svg)

1.  Find the value of $p$. [3 marks]

2.  Find $\mathrm{E}[X]$. [3 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    \sum \mathrm{P}(X = x) &= 1 \\[6pt]
    p + 5p^2 + 0.35 + 0.15 + 0.1 &= 1 \\[6pt]
    5p^2 + p - 0.4 &= 0 \hspace{9.15em} \\
    \end{aligned}
    $$

    $$
    \hspace{1em} [\text{by using G.D.C.}] \hspace{3em} p = 0.2 \hspace{3.5em} [\text{since $p > 0$}]
    $$

2.  Using the formula for the expected value of $X$, we get
    $$
    \begin{aligned}
    \mathrm{E}[X] &= \sum x\hspace{0.05em}\mathrm{P}(X = x) \\[6pt]
    &= (-2)(0.2) + (-1)\big[5(0.2)^2\big] + (0)(0.35) + \cdots \\[6pt]
    &\phantom{= (-2)(0.2) + (-1)\big[5(0.2)^2\big] \hspace{0.28em}} + (1)(0.15) + (2)(0.1) \\[9pt]
    &= -0.25
    \end{aligned}
    $$
