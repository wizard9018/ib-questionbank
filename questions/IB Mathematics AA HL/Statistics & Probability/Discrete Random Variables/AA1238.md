# AA1238

**Maximum mark: 8**

The discrete random variable $X$ has the following probability distribution

|$\textrm{x}$|$\textrm{1}$|$\textrm{2}$|$\textrm{3}$|

|:-:|:-:|:-:|:-:|

|$\hspace{0.5em}\mathrm{P}(X=x)\hspace{0.5em}$|$\hspace{0.5em}0.6-2a\hspace{0.5em}$|$\hspace{0.5em}0.4-2a\hspace{0.5em}$|$\hspace{0.5em}4a\hspace{0.5em}$|

1. Find the range of possible values of $a$.[2 marks]

2. In the case where $a=0.1$, determine $\mathrm{Var}(3-2X)$.[6 marks]

---

## 评分标准 / Mark scheme

1. Since probabilities must be non-negative, we can form 3 inequalities

    $$

    \begin{aligned}

        0.6-2a &\geq 0&&&0.4-2a &\geq 0 &&&0& \leq 4a \leq 1

    \end{aligned}

    $$

    Solving those we get

    $$

    \begin{aligned}

        a &\leq 0.3 &&&a &\leq 0.2 &&&0& \leq a \leq 0.25\tag*{\textbf{(M1)}}

    \end{aligned}

    $$

    Therefore, solving all inequalities simultaneously we find the range of possible values of $a$ is 

    $$

    \begin{aligned}

        0 \leq a \leq 0.2\tag*{\textbf{A1}}

    \end{aligned}

    $$

2. When $a=0.1$, the distribution becomes

    |$\textrm{x}$|$\textrm{1}$|$\textrm{2}$|$\textrm{3}$|

    |:-:|:-:|:-:|:-:|

    |$\hspace{0.5em}\mathrm{P}(X=x)\hspace{0.5em}$|$\hspace{0.5em}0.4\hspace{0.5em}$|$\hspace{0.5em}0.2\hspace{0.5em}$|$\hspace{0.5em}0.4\hspace{0.5em}$|

    Using the formula for the **linear transform of a single random variable (4.14)**

    $$

    \begin{aligned}

        \mathrm{Var}(aX+b)=a^2\mathrm{Var}(X)

    \end{aligned}

    $$

    We can write

    $$

    \begin{aligned}

        \mathrm{Var}(3-2X)&=(-2)^2\mathrm{Var}(X)\\[6pt]

        &=4\mathrm{Var}(X) \tag*{\textbf{(M1)}}

    \end{aligned}

    $$

    Therefore, we need to find $\mathrm{Var}(X)$.

    For this we can use the formula for the **variance (4.14)** 

    $$

    \begin{aligned}

        \mathrm{Var}(X)=\mathrm{E}(X^2)-[\mathrm{E}(X)]^2

    \end{aligned}

    $$

    Hence we need to find the expected value of $x$ and $x^2$.

    Let's add a row to our table for $x^2$

    |$\textrm{x}$|$\textrm{1}$|$\textrm{2}$|$\textrm{3}$|

    |:-:|:-:|:-:|:-:|

    |$x^2$|$1$|$4$|$9$|

    |$\hspace{0.5em}\mathrm{P}(X=x)\hspace{0.5em}$|$\hspace{0.5em}0.4\hspace{0.5em}$|$\hspace{0.5em}0.2\hspace{0.5em}$|$\hspace{0.5em}0.4\hspace{0.5em}$|

    Let's first find the expected value of $X$

    $$

    \begin{aligned}

        \mathrm{E}(X) &= 1(0.4)+2(0.2)+3(0.4) \\[6pt]

        &= 2 \tag*{\textbf{A1}}

    \end{aligned}

    $$

    Next let's find the expected value of $X^2$

    $$

    \begin{aligned}

        \mathrm{E}(X^2) &= 1^2(0.4)+2^2(0.2)+3^2(0.4) \tag*{\textbf{(M1)}} \\[6pt]

        &= 0.4+0.8+3.6 \\[6pt]

        &= 4.8 \tag*{\textbf{A1}}

    \end{aligned}

    $$

    Putting those results together we get

    $$

    \begin{aligned}

    \mathrm{Var}(X) &= \mathrm{E}(X^2)-[\mathrm{E}(X)]^2 \\[6pt]

    &= 4.8 - 2^2 \\[6pt]

    &= 0.8 \tag*{\textbf{A1}}

    \end{aligned}

    $$

    Finally, we get

    $$

    \begin{aligned}

        \mathrm{Var}(3-2X) &= 4 \times 0.8 \\[6pt]

        &=\hspace{0em}3.2\tag*{\textbf{A1}}

    \end{aligned}

    $$
