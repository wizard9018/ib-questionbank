# AA399

**Maximum mark: 6**

A random variable $X$ has a probability distribution given in the
following table.

![07354adced4a4b4d082c64348179d6c79f0b6ca7.svg](images/07354adced4a4b4d082c64348179d6c79f0b6ca7.svg)

1.  Given that $\mathrm{P}(X > 2) = 0.6$, find the value of $r$.
    [2 marks]

2.  Given that $\mathrm{E}[X] = 2.9$, find the value of $p$ and the
    value of $q$. [4 marks]

---

## 评分标准 / Mark scheme

1.  Using the probability distribution table for $X$, we get
    $$
    \begin{aligned}
    \mathrm{P}(X > 2) &= 0.6 \hspace{4em} \\[6pt]
    \mathrm{P}(X = 3) + \mathrm{P}(X = 4) + \mathrm{P}(X = 5) &= 0.6 \\[6pt]
    0.2 + 0.1 + r &= 0.6 \\
    \end{aligned}
    $$

    $$
    \hspace{10.55em} r = 0.3
    $$

2.  Using the formula for the expected value of $X$, we have
    $$
    \begin{aligned}
    \hspace{8em} \mathrm{E}[X] &= \sum x\hspace{0.05em}\mathrm{P}(X = x) \\[10pt]
    2.9 &= (0)(p) + (1)(q) + (2)(0.1) + (3)(0.2) + \cdots \\[12pt]
    &\phantom{= (0)(p) + (1)(q)\hspace{0.28em}} + (4)(0.1) + (5)(0.3) \\[12pt]
    2.9 &= q + 2.7 \\
    \end{aligned}
    $$

    $$
    q = 0.2 \hspace{6.9em}
    $$
    Hence we obtain

    $$
    \begin{aligned}
    \sum \mathrm{P}(X = x) &= 1 \hspace{2.7em} \\[10pt]
    p + 0.2 + 0.1 + 0.2 + 0.1 + 0.3 &= 1 \\[12pt]
    p + 0.9 &= 1 \\
    \end{aligned}
    $$

    $$
    \hspace{10.55em} p = 0.1
    $$
