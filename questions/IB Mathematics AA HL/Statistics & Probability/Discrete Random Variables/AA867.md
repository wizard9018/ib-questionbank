# AA867

**Maximum mark: 15**

Bag A contains a large number of tokens. Each token is numbered 1, 2, 3
or 4. A token is selected from the bag and the following table shows the
probability distribution of the score, $X$, obtained.

![8dd8bde68056b203a1b2f58c0da5310bf6cb4b04.svg](images/8dd8bde68056b203a1b2f58c0da5310bf6cb4b04.svg)

1.  Find the value of $p$. [2 marks]

2.  Hence, find the value of $\mathrm{E}(X)$. [2 marks]

Bag B also contains a large number of tokens, each numbered 1, 2, 3 or
4. A token is selected from the bag and the following table shows the
probability distribution of the score, $Y$, obtained. It is given that $q>0$ and $s>0$.

![ae133462540d402546323ba2a46a473c9b42e747.svg](images/ae133462540d402546323ba2a46a473c9b42e747.svg)

3.  State the range of possible values of $s$. [3 marks]

4.  Hence, find the range of possible values of
    $\mathrm{E}(Y)$. [3 marks]

A token is selected simultaneously from Bag A and Bag B. The probability
of obtaining tokens showing the same score is equal to $0.24$.

5.  Calculate $\mathrm{E}(Y)$. [5 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    \displaystyle \sum \mathrm{P}(X = x) &= 1 \\[6pt]
    p + p + 0.3 - p^2 + 0.4 - 0.7p  &= 1 \\[8pt]
    -p^2 + 1.3p - 0.3 &= 0 \hspace{3em} [\text{multiplying by $10$}]\\[8pt]
    -10p^2 + 13p - 3 &= 0 \\[8pt]
    (10p - 3)(1-p) &= 0 \\[10pt]
    &\hspace{-0.5em}p = 0.3 \hspace{3em} [\text{since $p < 1$}] \hspace{8em}
    \end{aligned}
    $$

2.  Substituting $p = 0.3$ in the probability distribution table, we
    have

    ![121d7cd425024b8578b63329e29f87f2a80b01a9.svg](images/121d7cd425024b8578b63329e29f87f2a80b01a9.svg)

    Using the formula for the expected value of $X$, we get

    $$
    \begin{aligned}
    \hspace{9em} \mathrm{E}(X) &= \displaystyle \sum x \mathrm{P}(X = x) \\[6pt]
    &= 1 \times 0.3 + 2 \times 0.3 + 3 \times 0.21 + 4 \times 0.19 \\[10pt]
    &= 2.29
    \end{aligned}
    $$

3.  We have
    $$
    \begin{aligned}
    \displaystyle \sum \mathrm{P}(Y = y) &= 1 \\[6pt]
    q + q + s + s &= 1 \\[6pt]
    2q + 2s &= 1 \\[6pt]
    q + s &= \dfrac{1}{2} \hspace{1.75em}
    \end{aligned}
    $$

    Since $q > 0$ and $s > 0$, we obtain
     $0 < s < \dfrac{1}{2}$

4.  Using the formula for the expected value of $Y$, we have
    $$
    \begin{aligned}
    \hspace{7.75em} \mathrm{E}(Y) &= \displaystyle \sum y \mathrm{P}(Y = y) \\[6pt]
    &= 1 \times q + 2 \times q + 3 \times s + 4 \times s \\[8pt]
    &= 3q + 7s \\[6pt]
    &= 3(q+s) + 4s \\[6pt]
    &= 3 \left( \dfrac 1 2 \right) + 4s \hspace{3em} [\text{by equation $(1)$}]\\[6pt]
    &= \dfrac 3 2 + 4s
    \end{aligned}
    $$
    Since
    $0 < s < \dfrac{1}{2}$, we obtain
    $$
    \begin{aligned}
    \dfrac 3 2 + 4(0)  &< \dfrac 3 2 + 4s < \dfrac 3 2 + 4\left( \dfrac 1 2 \right) \\[10pt]
    &\hspace{-0.7em}\dfrac 3 2 < \hspace{0.3em} \mathrm{E}(Y) \hspace{0.3em} < \dfrac 7 2
    \end{aligned}
    $$

5.  We have

    ![8408cd9bad2f3692c5b4de2432ab7f0001289544.svg](images/8408cd9bad2f3692c5b4de2432ab7f0001289544.svg)

    Hence, the probability of obtaining equal scores on the two tokens
    is
    $$
    \begin{aligned}
    0.30q + 0.30q + 0.21s + 0.19s & = 0.24 \\[6pt]
    0.6q + 0.4s &= 0.24 \\[6pt]
    6q + 4s &= 2.4 \hspace{10.25em}
    \end{aligned}
    $$
    If we
    solve the equations (1) and (2) for $q$ and $s$, we obtain

    $$
    \begin{aligned}
    \hspace{2em}q = 0.2  \\[6pt]
    s = 0.3
    \end{aligned}
    $$
    Hence we get

    $$
    \begin{aligned}
    \hspace{3.5em} \mathrm{E}(Y) &= \dfrac 3 2 + 4(0.3) \\[8pt]
    &= 2.7
    \end{aligned}
    $$
