# AA777

**Maximum mark: 5**

The random variable $X$ is normally distributed with a mean of $120$.
The following diagram shows the normal curve for $X$.

![1f917f7113a014d3ccaee4eed959663d9ba5b3cb.svg](images/1f917f7113a014d3ccaee4eed959663d9ba5b3cb.svg)

Let $R$ be the shaded region under the curve between $105$ and $135$.
The area of $R$ is $0.4$.

1.  Write down $\mathrm{P}(105 < X < 135)$. [1 mark]

2.  Find $\mathrm{P}(X < 135)$. [2 marks]

3.  Find $\mathrm{P}(X > 105\hspace{0.25em}|\hspace{0.25em} X < 135)$.
    [2 marks]

---

## 评分标准 / Mark scheme

1.
    $\mathrm{P}(105 < X < 135) = 0.4$

2.  We have
    $$
    \begin{aligned}
    \mathrm{P}(X < 135) &= \mathrm{P}(X < 120) + \dfrac{R}{2} \\[12pt]
    &= 0.5 + 0.2 \\[12pt]
    &= 0.7
    \end{aligned}
    $$

3.  Using the conditional probability formula, we obtain
    $$
    \begin{aligned}
    \mathrm{P}(X > 105\hspace{0.25em}|\hspace{0.25em} X < 135) &= \dfrac{\mathrm{P}(105 < X < 135)}{\mathrm{P}(X < 135)}  \\[12pt]
    &= \dfrac{0.4}{0.7} \\[12pt]
    &= \dfrac{4}{7}
    \end{aligned}
    $$
