# AA459

**Maximum mark: 6**

The following table below shows the marks scored by six job candidates
on two aptitude tests.

![4385fab6f0a22eb1414db34b1a91764663e8e9c3.svg](images/4385fab6f0a22eb1414db34b1a91764663e8e9c3.svg)

Let $L_1$ be the regression line of $x$ on $y$. The equation of the line
$L_1$ can be written in the form $x = ay + b$.

1.  Find the value of $a$ and the value of $b$. [2 marks]

Let $L_2$ be the regression line of $y$ on $x$. The lines $L_1$ and
$L_2$ both pass through the same point with coordinates $(p,q)$.

2.  Find the value of $p$ and the value of $q$. [2 marks]

3.  Chelsea missed the first aptitude test but scored $101$
    marks on the second aptitude test. Use an appropriate regression
    equation to estimate Chelsea's mark on the first aptitude test.
    [2 marks]

---

## 评分标准 / Mark scheme

1.
    $a \approx 0.800$
    and  $b \approx 28.2$
      \[$\text{by using G.D.C.}$\]

2.  Both lines pass through the mean point of the data given in the
    table.

    Hence we get
    $$
    \begin{aligned}
    \hspace{8.1em} p &= \bar{x} \\[6pt]
    &\approx 105 \hspace{3em} [\text{by using G.D.C.}] \\[12pt]
    q &= \bar{y} \\[6pt]
    &\approx 95.8 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

3.  Evaluating $x = 0.800y + 28.2$ for $y = 101$, we find
    $$
    \begin{aligned}
    \hspace{0.6em} x &= 0.800(101) + 28.2 \\[6pt]
    &= 109 \text{ marks}
    \end{aligned}
    $$
