# AA421

**Maximum mark: 6**

The following table shows the amount of fuel ($y$ litres) used by a car
to travel certain distances ($x$ km).

|$\hspace{0.5em}\text{Distance travelled }(x\text{ km})\hspace{1em}$|$\hspace{1em}14\hspace{1em}$|$\hspace{1em}35\hspace{1em}$|$\hspace{1em}80\hspace{1em}$|$\hspace{1em}115\hspace{1em}$|$\hspace{1em}145\hspace{1em}$|$\hspace{1em}170\hspace{1em}$|
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
|Fuel used ($y$) litres|2.5|6.2|10.8|13.6|15.4|19.7|

1.  Find the correlation coefficient. [2 marks]

The data can be modelled by the regression line with equation
$y = ax + b$.

2.  Write down the value of $a$ and the value of $b$.
    [2 marks]

3.  Use the model to estimate the amount of fuel the car would
    use if it has driven
    $55$ km. [2 marks]

---

## 评分标准 / Mark scheme

1.
    $r \approx 0.991$
    \[$\text{by using G.D.C.}$\]

2.
    $a \approx 0.101$
    and  $b \approx 1.96$
      \[$\text{by using G.D.C.}$\]

3.  Evaluating $y = 0.101x + 1.96$ for $x = 55$, we get
    $$
    \begin{aligned}
    y &= 0.101(55) + 1.96 \hspace{0.5em} \\[6pt]
    &\approx 7.52 \text{ litres}
    \end{aligned}
    $$
