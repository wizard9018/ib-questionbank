# AA398

**Maximum mark: 13**

Each day, a factory records the number $(x)$ of memory foam pillows it
produces and the total production cost $(y)$ dollars. The results for
ten days are shown in the following table.

![ccbb2774e6db3c56443c9907e3979b82f8681a91.svg](images/ccbb2774e6db3c56443c9907e3979b82f8681a91.svg)

1.  Write down the equation of the regression line in the form $y=ax+b$
    [2 marks]

Use your regression line as a model to answer the following.

2.  Interpret the meaning of:
    1.  the gradient;

    2.  the $y$-intercept. [2 marks]

3.  Estimate the cost of producing $100$ pillows. [2 marks]

The factory sells the pillows for \$ $29.99$
each.

4.  Find the least number of pillows that the factory should
    produce in one day in order to make a profit. [3 marks]

5.  Comment on the appropriateness of using your model to
    estimate:

    1.  the cost of producing $1000$ pillows;
    2.  the number of pillows produced when the total production cost is
        $$\$\hspace{0.02em}1940$$.[4 marks]

## 评分标准 / Mark scheme

1.
    $y = 18.2x + 410$
    \[$\text{by using G.D.C.}$\]

2.
    1.
        $$\text{\(18.2\)\hspace{0.025em};\hspace{0.25em} the cost to produce each additional pillow is \(\$18.20\)}$$
    2.
        $$\text{\(410\);\hspace{0.25em} the initial cost before any pillows have been produced is \(\$410\)}$$

3.  Evaluating $y = 18.2x + 410$ for $x = 100$, we get
    $$
    \begin{aligned}
    y &= 18.2(100) + 410 \hspace{0.6em} \\[8pt]
    &= \$2230
    \end{aligned}
    $$

4.  Solving the equation $y = \text{"sales revenue"}$ for $x$, we have
    $$
    \begin{aligned}
    \hspace{5em} 18.2x + 410 &= 29.99x \\[8pt]
    x &\approx 34.8 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

    Hence the least number of pillows that the factory should produce is
     $35$
