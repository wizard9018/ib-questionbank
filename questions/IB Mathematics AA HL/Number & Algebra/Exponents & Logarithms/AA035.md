# AA035

**Maximum mark: 5**

Solve the equation $\log_2(x^2-2x+1) = 1 + \log_2(x-1)$.

---

## 评分标准 / Mark scheme

Using the properties of logarithms, we get
$$
\begin{aligned}
\log_2(x^2-2x+1) &= 1 + \log_2(x-1) \\[6pt]
\log_2(x^2-2x+1) &= \log_2 2 + \log_2(x-1) \\[6pt]
\log_2(x^2-2x+1) &= \log_2(2x-2) \\[6pt]
x^2-2x+1 &= 2x-2 \\[6pt]
x^2-4x+3 &= 0 \\[7pt]
(x-1)(x-3) &= 0 \\[7pt]
x-3 &= 0 \hspace{3em} [\text{$x\neq1$, since $\log_20$}]
\end{aligned}
$$

$$
x = 3 \hspace{3.15em}
$$
