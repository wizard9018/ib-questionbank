# AA045

**Maximum mark: 5**

Find the integer values of $a$ and $b$ for which
$$
\begin{aligned}
a + b\log_4 7 + 60\log_{8} 14 &= 0.
\end{aligned}
$$

---

## 评分标准 / Mark scheme

Using the properties of logarithms, we have
$$
\begin{aligned}
a + b\log_4 7 + 60\log_{8} 14 &= 0 \\[13pt]
a + \dfrac{b\ln 7}{2\ln 2} + \dfrac{60\ln 14}{3\ln 2} &= 0 \\[9pt]
a\ln 2 + \dfrac{b}{2}\ln 7 + 20\ln (2\cdot7) &= 0 \\[9pt]
a\ln 2 + \dfrac{b}{2}\ln 7 + 20(\ln 2 + \ln 7) &= 0 \\[9pt]
(a + 20)\ln 2 + \bigg(\dfrac{b}{2}+20\bigg)\ln 7 &= 0
\end{aligned}
$$

Hence we get
 $a = -20$
and  $b = -40$
