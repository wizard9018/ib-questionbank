# AA1012

**Maximum mark: 11**

Consider three planes represented by the following system of equations: 

$$

\begin{aligned}

\Pi_1: -2x + ay + 4z &= 2 \\[6pt]

\Pi_2: x + by - 2z &= -1 \\[6pt]

\Pi_3: 2x - y + cz &= 3

\end{aligned}

$$

Where $a,b,c \in \mathbb{R}$.

1. State the values of $a$, $b$ and $c$ for which

    1. The system has infinite solutions.

    2. The system is inconsistent. [7 marks]

2. In the case where the system has infinite solutions, describe the geometric relationship between the three planes. [2 marks]

3. In the case where the system is inconsistent, identify one of the geometric relationships that could exist between the three planes.  [2 marks]

    1. From row 2, if the system has infinite solutions, we must have $a + 2b = 0$. 

        This implies that if $a = -2b$, there are infinite solutions to the system.

        However, we also note from row 3, that if $a - 1 = 0$ and $c + 4 = 0$, then the system is inconsistent. In this case we have $a = 1$ and $c = -4$.

        There are infinite solutions to the system if $a = -2b$, $c \in \mathbb{R}$ unless $a=1$, $b=-0.5$ and $c=-4$.

    2.  As noted in part (i), if $a = 1$ and $c = -4$, the system is inconsistent. 

        However, we also note that if $a \neq 1$ and $c = -4$, Gaussian Elimination leads to

        In this case, we can also have an inconsistent system. 

        From part (a), if $a = -2b$ then the system is consistent (has infinite solutions), however consider when $a \neq -2b$.

        It follows that $a+2b =k$, where $k \neq 0$, this leads to

        Using row 2

        $$

        \begin{aligned}

        ky &=0 \\

        \intertext{As $k \neq 0$ then}

        y &= 0 

        \end{aligned}

        $$

        Using row 3, this value of $y$ shows an inconsistency as shown below.

        $$

        \begin{aligned}

        (a-1)y &=5 \\

        (a-1)\times0 &= 5 \\

        0 &= 5 

        \end{aligned}

        $$

        Hence...

        $\text{The system is inconsistent if } a = 1 \text{ and } c = -4, b \in \mathbb{R} \text{ or if } a \neq 1, a \neq -2b \text{ and } c = -4.$

2. From (a) (i), we note that $\Pi_1$ is a multiple of $\Pi_2$. They are therefore equations representing the same plane.

    $\Pi_1 \text{ and } \Pi_2 \text{ are coincidental, }\Pi_3 \text{ intersects both planes in a straight line.}$

3. In total there are 4 different geometric realtionships between the planes when the system is inconsistent.

    First, from part (a) (i) we note that the system is inconsistent if $a=1$, $b=-0.5$ and $c=-4$. In this case,

    $\hspace{0.525em}\boxed{\Pi_1 \text{ and } \Pi_2 \text{ are coincidental and } \Pi_3 \text{ is parallel to both planes.}}\hspace{0.525em}$

    Second, from (a) (ii), we have one scenario where $a=1$, $b \neq -0.5$ and $c=-4$. In this case, 

    $\hspace{0.525em}\boxed{\Pi_1 \text{ and } \Pi_3 \text{ are parallel and } \Pi_2 \text{ intersects both planes.}}\hspace{0.525em}$

    Thirdly, if $a \neq 1$, $b=-0.5$ and $c=-4$,

    $\hspace{0.525em}\boxed{\Pi_2 \text{ and } \Pi_3 \text{ are parallel and } \Pi_1 \text{ intersects both planes.}}\hspace{0.525em}$    

    Finally, if $a \neq 1$, $a \neq -2b$ and $c=-4$, then $\Pi_1$ intersects $\Pi_2$ on a line, $\Pi_1$ intersects $\Pi_3$ on a different line and $\Pi_2$ intersects $\Pi_3$ on another different line. Additionally,$\hspace{0.525em}\boxed{\text{All three of these lines of intersection are parallel.}}\hspace{0.525em}$
