# AA106

**Maximum mark: 8**

Consider the following system of equations:
$$
\begin{aligned}
x + y + z &= -1 \\[6pt]
4x + 2y + z &= 3 \\[6pt]
9x + 3y &= p
\end{aligned}
$$
where $p \in \mathbb{R}$.

1.  Show that this system does not have a unique solution for any value
    of $p$. [4 marks]

2.
    1.  Determine the value of $p$ for which the system is consistent.

    2.  For this value of $p$, find the general solution of the system.
        [4 marks]

    If $p \neq 12$, the system is inconsistent and has no solutions. For otherwise, the~system is consistent and $z$ is a free variable. Hence, for any given value of $p$, the system either has no solutions or it has infinite number of solutions.

2.
    1.
        $p = 12$

    2.  For $p = 12$, we have

        ![bd86febfa147c1cf21b65e965d8b671ce0dbd029.svg](images/bd86febfa147c1cf21b65e965d8b671ce0dbd029.svg)

        Letting $z = t$ and using the method of back-substitution, we
        obtain
        $$
        \begin{aligned}
        -2y - 3z &= 7 \\[11pt]
        -2y - 3t &= 7 \\[5pt]
        y &= -\dfrac{7}{2} - \dfrac{3t}{2}
        \end{aligned}
        $$
        and

        $$
        \begin{aligned}
        x + y + z &= -1 \\[5pt]
        x +\left[-\dfrac{7}{2} - \dfrac{3t}{2}\right] + t &= -1 \\[1pt]
        x &= \dfrac{5}{2} + \dfrac{t}{2} \hspace{5.5em}
        \end{aligned}
        $$

        Hence the general solution of the system in parametric form is

         $$
         \begin{aligned}
         &x = \dfrac{5}{2} + \dfrac{t}{2}, \hspace{0.5em} y = -\dfrac{7}{2} - \dfrac{3t}{2}, \hspace{0.5em} z = t
         \end{aligned}
         $$

        where $t \in \mathbb{R}$.
