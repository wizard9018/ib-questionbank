# AA633

**Maximum mark: 6**

Consider the sum $\displaystyle S = \sum_{k = 4}^l (2k-3)$, where $l$ is
a positive integer greater than $4$.

1.  Write down the first three terms of the series. [2 marks]

2.  Write down the number of terms in the series. [1 mark]

3.  Given that $S = 725$, find the value of $l$. [3 marks]

---

## 评分标准 / Mark scheme

1.
    $5,\, 7,\, 9$

2.
    $l-3$

3.  From part (a), we have an arithmetic sequence with the first term
    $u_1 = 5$ and the common difference $d = 2$.

    Hence, using the sum of $n$ terms formula
    $S_n = \dfrac{n}{2}(2u_1 + (n-1)d)$ with $n = l-3$, we get

    $$
    \begin{aligned}
    S &= S_{l-3} \\[11pt]
    \hspace{4.5em}725 &= \bigg[\dfrac{l-3}{2}\bigg](2u_1 + ((l-3)-1)d) \\[6pt]
    725 &= \bigg[\dfrac{l-3}{2}\bigg](2(5) + (l-4)(2)) \\[6pt]
    725 &= \bigg[\dfrac{l-3}{2}\bigg](2 + 2l) \\[12pt]
    725 &= (l-3)(l+1) \\
    \end{aligned}
    $$

    $$
    \hspace{4.65em} l = 28 \hspace{3em} [\text{by using G.D.C.}]
    $$
