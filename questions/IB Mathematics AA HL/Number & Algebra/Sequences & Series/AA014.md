# AA014

**Maximum mark: 7**

In a geometric sequence, $u_2 = 6$, $u_5 = 20.25$.

1.  Find the common ratio, $r$. [2 marks]

2.  Find $u_1$. [2 marks]

3.  Find the greatest value of $n$ such that $u_n < 200$. [3 marks]

---

## 评分标准 / Mark scheme

1.  Using the $n$th term formula $u_n = u_2r^{n-2}$ with $n = 5$, we get
    $$
    \begin{aligned}
    u_5 &= u_2r^{5-2} \hspace{3em} \\[6pt]
    20.25 &= 6r^{5-2} \\[6pt]
    r^3 &= 3.375
    \end{aligned}
    $$

    $$
    \hspace{7.75em} r = 1.5 \hspace{3em} [\text{by using G.D.C.}]
    $$

2.  Using the $n$th term formula $u_n = u_2r^{n-2}$ with $n = 1$, we
    obtain
    $$
    \begin{aligned}
    u_1 &= u_2r^{1-2} \\[6pt]
    &= 6(1.5)^{1-2}  \hspace{0.7em} \\[6pt]
    &= 4
    \end{aligned}
    $$

3.  We have
    $$
    \begin{aligned}
    \hspace{8.7em} u_n &< 200 \\[6pt]
    u_1r^{n-1} &< 200 \\[6pt]
    4(1.5)^{n-1} &< 200 \\[6pt]
    n &< 10.648 \hspace{3em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

    Hence the greatest value of $n$ such that $u_n < 200$ is
     $n=10$
