# AA556

**Maximum mark: 6**

Consider $f(x) = x^3 - \dfrac p x$, $x \neq 0$, where $p$ is a constant.

1.  Find $f'(x)$. [3 marks]

2.  There is a minimum value of $f(x)$ when $x = 1$. Find the value of
    $p$. [3 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    f'(x)  = 3x^2 + \dfrac p {x^2}\hspace{.8cm}
    $$

2.  A minimum occurs when $f'(x) = 0$. Using $f'(1) = 0$, we get
    $$
    \begin{aligned}
    0   & = 3(1^2) + \dfrac p {1^2}\\[6pt]
    0   & = 3 + p\\[6pt]
    & \hspace{-1.5mm}p = -3
    \end{aligned}
    $$
