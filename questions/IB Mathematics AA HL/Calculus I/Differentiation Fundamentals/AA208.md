# AA208

**Maximum mark: 8**

The function $f$ is defined by $f(x) = e^{2x}-4e^x+2$, for
$x \in \mathbb{R}$, $x \leq a$, where $a \in \mathbb{R}$.

Part of the graph of $y = f(x)$ is shown in the following diagram.

![dc14321f698d30780f4ecaf20c082a22181a9565.svg](images/dc14321f698d30780f4ecaf20c082a22181a9565.svg)

1.  Find the largest value of $a$ such that $f$ has an inverse function.
    [3 marks]

2.  For this value of $a$, find an expression for $f^{-1}(x)$, stating
    its domain. [5 marks]

---

## 评分标准 / Mark scheme

1.  From the diagram, we see that the $x$-coordinate of the local
    minimum point on the graph of $y = f(x)$ is the largest value of $a$
    such that $f$ has an inverse function.

    We have
    $$
    \begin{aligned}
    f'(x) &= \dfrac{\mathrm{d}}{\mathrm{d}x}\big[e^{2x}-4e^x+2\big] \\[6pt]
    &= 2e^{2x}-4e^x \\[9pt]
    &= \big[2e^x\big]\big[e^x - 2\big]
    \end{aligned}
    $$

    If we solve the equation $f'(x) = 0$ for $x$, we get

    $$
    \begin{aligned}
    \big[2e^x\big]\big[e^x - 2\big] &= 0 \hspace{5.2em} \\[6pt]
    e^x - 2 &= 0 \\[7pt]
    e^x &= 2 \\[7pt]
    x &= \ln 2
    \end{aligned}
    $$
    Hence we find
     $a = \ln 2$

2.  If we solve the equation $(f\circ f^{-1})(x) = x$ for
    $y =  f^{-1}(x)$, we obtain
    $$
    \begin{aligned}
    f(f^{-1}(x)) &= x \hspace{3em} [\text{where $-2 \leq x < 2$}] \\[9pt]
    f(y) &= x \hspace{3em} [\text{where $y \leq \ln 2$}] \\[7pt]
    e^{2y}-4e^y+2 &= x \\[7pt]
    \big[(e^y)^2-4e^y\big]+2 &= x \\[7pt]
    \hspace{7.1em} \big[(e^y-2)^2 - 4\big]+2 &= x \hspace{3em} [\text{by completing the square}] \\[7pt]
    (e^y-2)^2 &= x+2 \\[7pt]
    e^y-2 &= \pm\sqrt{x+2} \\[7pt]
    e^y-2 &= -\sqrt{x+2} \hspace{3em} [\text{since $y \leq \ln 2$}] \\[7pt]
    e^y &= 2-\sqrt{x+2} \\[7pt]
    y &= \ln (2-\sqrt{x+2})
    \end{aligned}
    $$
    Hence we find
     $f^{-1}(x) = \ln (2-\sqrt{x+2}), \text{ for } x \in \mathbb{R}, -2 \leq x < 2$
