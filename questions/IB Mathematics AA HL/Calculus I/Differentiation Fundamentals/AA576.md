# AA576

**Maximum mark: 14**

Let $f(x) = \dfrac {5x} {e^{3x}}$, for $0 \leq x \leq 10$.

1.  Sketch the graph of $f$. [3 marks]

    ![bcb38cd407da88a3ed46eea88b881a18ac54f09f.svg](images/bcb38cd407da88a3ed46eea88b881a18ac54f09f.svg)

2.
    1.  Write down the $x$-coordinate of the maximum point on the graph
        of $f$.

    2.  Write down the interval where $f$ is increasing. [3 marks]

3.  Find $f'(x)$ using the quotient rule. [4 marks]

4.  Find the interval where the rate of change of $f$ is increasing.
    [4 marks]
