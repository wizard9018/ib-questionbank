# AA1404

**Maximum mark: 7**

Use L'Hópital's rule to determine the value of 

$$

\begin{aligned} 

    \lim_{x\to 0} \dfrac{5\left(x-\arctan(x)\right)}{x^3}

\end{aligned} 

$$

---

## 评分标准 / Mark scheme

As we have been told to use L'Hópital's rule, we can go ahead and use it straight away.

Using L'Hópital's rule and independently differentiating the numerator and denominator, we get 

$$

\begin{aligned}

    \lim_{x\rightarrow0} \dfrac{5\left(x-\arctan(x)\right)}{x^3}  &= \lim_{x\rightarrow0} \dfrac{5\left(1-\dfrac{1}{1+x^2}\right)}{3x^2}\tag*{\textbf{{(M1)}}} \\[6pt]

    &= \lim_{x\rightarrow0} \dfrac{5\left(\dfrac{x^2}{1+x^2}\right)}{3x^2} \tag*{\textbf{{A1A1}}}\\[-10pt]

\end{aligned}

$$

Now through direct substitution we get 

$$

\begin{aligned}

    \lim_{x\rightarrow 0} \dfrac{5x^2}{1+x^2} &= 0 \\[7pt]

    \lim_{x\rightarrow 0} 3x^2 &= 0 \\[-12pt]

\end{aligned}

$$

Which leads to $\frac{0}{0}$ which is indeterminate form, hence, we can use L'Hópital's rule again with the quotient rule to obtain $$\\[-2.3em]$$

$$

\begin{aligned}

\tag*{{\textbf{M1}}}

\end{aligned}

$$

$$

\begin{aligned}

    \lim_{x\rightarrow0} \dfrac{\dfrac{5x^2}{1+x^2}}{3x^2}  &= \lim_{x\rightarrow0} \dfrac{\dfrac{(1+x^2)10x-5x^2(2x)}{(1+x^2)^2}}{6x} \tag*{\textbf{{A1A1}}}\\[6pt]

    &= \lim_{x\rightarrow0} \dfrac{\dfrac{10x+10x^3-10x^3}{(1+x^2)^2}}{6x} \\[6pt]

    &= \lim_{x\rightarrow0} \dfrac{\dfrac{10x}{(1+x^2)^2}}{6x} \\[6pt]

    &= \lim_{x\rightarrow0} \dfrac{10}{6(1+x^2)^2} \\[6pt]

    &= \dfrac{10}{6} \\[8pt]

    \lim_{x\rightarrow0} \dfrac{5\left(x-\arctan(x)\right)}{x^3} &=\hspace{0.2em}\dfrac{5}{3} \tag*{\textbf{{A1}}}

\end{aligned}

$$
