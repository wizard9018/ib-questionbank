# AA601

**Maximum mark: 9**

1.  Use L'Hôpital's rule to determine the value of
    $\displaystyle \lim_{x\rightarrow0} \dfrac{e^{-5x^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5x) + 1}{4x^2}$.
    [6 marks]

2. Hence find $\displaystyle \lim_{x\rightarrow 0} \dfrac{{\displaystyle \int_0^x \hspace{-0.2em}\big(e^{-5t^2} - 2\cos\hspace{0.05em}(5t) + 1\big) \hspace{0.05em}\mathrm{d}t}}{{\displaystyle \int_0^x 4t^2\,\mathrm{d}t}}$. [3 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    \lim_{x\rightarrow 0} \big[e^{-5x^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5x) + 1\big] &= 0 \\[9pt]
    \lim_{x\rightarrow 0} \big[4x^2\big] &= 0
    \end{aligned}
    $$
    Hence,
    using L'Hôpital's rule, we get
    $$
    \begin{aligned}
    \lim_{x\rightarrow0} \dfrac{e^{-5x^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5x) + 1}{4x^2}  &= \lim_{x\rightarrow0} \dfrac{\big[e^{-5x^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5x) + 1\big]'}{\big[4x^2\big]'} \\[6pt]
    &= \lim_{x\rightarrow0} \dfrac{-10xe^{-5x^2} \hspace{-0.2em} + 10\sin\hspace{0.05em}(5x)}{8x} \\
    \end{aligned}
    $$

    We have
    $$
    \begin{aligned}
    \lim_{x\rightarrow 0} \big[\hspace{-0.2em}-10xe^{-5x^2} \hspace{-0.2em} + 10\sin\hspace{0.05em}(5x)\big] &= 0 \\[9pt]
    \lim_{x\rightarrow 0} \big[8x\big] &= 0 \hspace{1.3em}
    \end{aligned}
    $$

    Hence, using L'Hôpital's rule, we obtain
    $$
    \begin{aligned}
    \lim_{x\rightarrow0} \dfrac{-10xe^{-5x^2} \hspace{-0.2em} + 10\sin\hspace{0.05em}(5x)}{8x}  &= \lim_{x\rightarrow0} \dfrac{\big[\hspace{-0.2em}-10xe^{-5x^2} \hspace{-0.2em} + 10\sin\hspace{0.05em}(5x)\big]'}{\big[8x\big]'} \\[6pt]
    &= \lim_{x\rightarrow0} \dfrac{-10e^{-5x^2} \hspace{-0.2em} + 100x^2e^{-5x^2} + 50\cos\hspace{0.05em}(5x)}{8} \\[15pt]
    &= \dfrac{-10(1) + 100(0)(1) + 50(1)}{8} \\[19pt]
    &= 5
    \end{aligned}
    $$

2.  We have
    $$
    \begin{aligned}
    \lim_{x\rightarrow 0} \bigg[\int_0^x \hspace{-0.2em}\Big(e^{-5t^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5t) + 1\Big) \hspace{0.05em}\mathrm{d}t\bigg] &= 0 \\[6pt]
    \lim_{x\rightarrow 0} \bigg[\int_0^x 4t^2\,\mathrm{d}t\bigg] &= 0
    \end{aligned}
    $$

    Hence, using L'Hôpital's rule, we find
    $$
    \begin{aligned}
    \lim_{x\rightarrow 0} \dfrac{\raisebox{0.7em}{$\displaystyle \int_0^x \hspace{-0.2em}\left(e^{-5t^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5t) + 1\right) \hspace{0.05em}\mathrm{d}t$}}{\raisebox{-0.7em}{$\displaystyle \int_0^x 4t^2\,\mathrm{d}t$}} &=  \lim_{x\rightarrow 0} \dfrac{\raisebox{0.7em}{$\displaystyle \dfrac{\mathrm{d}}{\mathrm{d}x}\bigg[\int_0^x \hspace{-0.2em}\left(e^{-5t^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5t) + 1\right) \hspace{0.05em}\mathrm{d}t\bigg]$}}{\raisebox{-0.7em}{$\displaystyle \dfrac{\mathrm{d}}{\mathrm{d}x}\bigg[\int_0^x 4t^2\,\mathrm{d}t\bigg]$}} \\[10pt]
    &= \lim_{x\rightarrow0} \dfrac{e^{-5x^2} \hspace{-0.2em} - 2\cos\hspace{0.05em}(5x) + 1}{4x^2} \hspace{2em} [\text{by FTC}] \\[24pt]
    &= 5 \hspace{2.75em} [\text{by part (a)}]
    \end{aligned}
    $$
