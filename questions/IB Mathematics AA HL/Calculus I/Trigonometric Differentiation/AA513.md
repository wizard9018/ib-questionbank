# AA513

**Maximum mark: 8**

A curve is given by the equation $y = \cos(2\pi \cos x)$.

Find the coordinates of all the points on the curve for which
$\dfrac{\mathrm{d}y}{\mathrm{d}x} = 0$,  $0\leq x \leq \pi$.

---

## 评分标准 / Mark scheme

Applying the chain rule, we get
$$
\begin{aligned}
\dfrac{\mathrm{d}y}{\mathrm{d}x} & =  -\sin(2\pi \cos x)\cdot(-2\pi\sin x) \\[3pt]
& =  2\pi \sin x\hspace{0.05em}\sin(2\pi \cos x).
\end{aligned}
$$
Hence
we obtain
$\dfrac{\mathrm{d}y}{\mathrm{d}x} = 2\pi \sin x \sin(2\pi \cos x) = 0$
$\Longrightarrow$ either $\sin x = 0$ or

$\sin(2\pi \cos x) = 0$. Then:
$$
\begin{aligned}
\sin x = 0 &\Longrightarrow  x = 0, \pi; \\[18pt]
\sin(2\pi \cos x) = 0 &\Longrightarrow \text{either } 2\pi \cos x = 0 \text{ or } 2\pi \cos x = \pm \pi; \\[18pt]
2\pi \cos x = 0 &\Longrightarrow \cos x = 0 \\[12pt]
&\Longrightarrow x = \dfrac{\pi}{2}; \\[8pt]
2\pi \cos x = \pm \pi &\Longrightarrow \cos x = \pm \dfrac{1}{2} \\[3pt]
&\Longrightarrow  x = \dfrac{\pi}{3}, \dfrac{2\pi}{3}.
\end{aligned}
$$

Hence the coordinates of all points on the curve for which
$\dfrac{\mathrm{d}y}{\mathrm{d}x} = 0$ are

$$
\Big(0,1\Big),\, \bigg(\dfrac{\pi}{3},-1\bigg),\, \bigg(\dfrac{\pi}{2},1\bigg), \,\bigg(\dfrac{2\pi}{3},-1\bigg), \,\Big(\pi,1\Big)
$$
