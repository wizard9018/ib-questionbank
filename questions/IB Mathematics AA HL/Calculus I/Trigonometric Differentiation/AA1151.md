# AA1151

**Maximum mark: 6**

Consider the curve $y=e^x\sin{x}$.

1.  Show that when $x=\pi$ the gradient of the curve is $-e^{\pi}$[3 marks]

2.  Hence, find the equation of the normal to the curve when $x=\pi$.[3 marks]

---

## 评分标准 / Mark scheme

1.  To find the gradient we need the derivative, and for this function we must use **the product rule formula (5.6)** to find the derivative.

    $$
    \begin{aligned}
    \frac{\mathrm{d}y}{\mathrm{d}x}&=u\frac{\mathrm{d}v}{\mathrm{d}x}+v\frac{\mathrm{d}u}{\mathrm{d}x}
    \end{aligned}
    $$

    If we let $u=e^x$ and $v= \sin x$, then $\dfrac{\mathrm{d}u}{\mathrm{d}x}=e^x$ and $\dfrac{\mathrm{d}v}{\mathrm{d}x}=\cos x$, using **the standard derivatives for $\bm{e^x}$ and $\bm{\sin x}$ (5.6)**. We have

    $$
    \begin{aligned}
    \frac{\mathrm{d}y}{\mathrm{d}x}&=e^x\sin{x}+e^x\cos{x}\tag*{\textbf{M1A1}}
    \end{aligned}
    $$

    Now we should evaluate the derivative when $x=\pi$

    $$
    \begin{aligned}
        \frac{\mathrm{d}y}{\mathrm{d}x}&=e^{\pi}\sin{\pi}+e^{\pi}\cos{\pi}\\[12pt]
       &=e^{\pi}\times 0+e^{\pi}\times (-1)\tag*{\textbf{A1}}\\[12pt]
       \frac{\mathrm{d}y}{\mathrm{d}x}&=\boxed{-e^{\pi}} \hspace{0.5em}\text{... as required.}\tag*{\textbf{AG}}
    \end{aligned}
    $$
2.  The normal is perpendicular to the tangent which means we can use the fact that $m_1\times m_2=-1$.

    Using the gradient value from part (a) we can solve for the gradient of the normal at $x=\pi$.

    $$
    \begin{aligned}
        -e^{\pi}\times m_2 &= -1\\[12pt]
        m_2&=\frac{1}{e^\pi}\tag*{\textbf{(A1)}}
    \end{aligned}
    $$
    To use the line equation, we must also find the $y$-coordinate of the point when $x=\pi$
    $$
    \begin{aligned}
        y&=e^\pi\sin{\pi}\\[6pt]
        &=0
    \end{aligned}
    $$
    Therefore we can use the point $(\pi, 0)$, the gradient $m_2$, and **the formula for the equation of a straight line (2.1)**.
    $$
    \begin{aligned}
    y - y_1 &= m(x - x_1) \\[6pt]
        y-0&=\frac{1}{e^\pi}(x-\pi)\tag*{\textbf{M1}}\\[12pt]
        &\hspace{-0.9em}\boxed{\displaystyle y=\frac{x-\pi}{e^\pi}}\tag*{\textbf{A1}}
    \end{aligned}
    $$
