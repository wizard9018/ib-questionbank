# AA465

**Maximum mark: 7**

A curve is given by the equation $y = \cos\hspace{0.05em}(2\pi \sin x)$.

Find the coordinates of all the points on the curve for which
$\dfrac{\mathrm{d}y}{\mathrm{d}x} = 0$,
$0\leq x \leq \pi$.

---

## 评分标准 / Mark scheme

Using the chain rule, we have
$$
\begin{aligned}
\dfrac{\mathrm{d}y}{\mathrm{d}x} &= \dfrac{\mathrm{d}}{\mathrm{d}x}\big[\hspace{-0.1em}\cos\hspace{0.05em}(2\pi \sin x)\big] \\[6pt]
&= \big[\hspace{-0.15em}-\sin\hspace{0.05em}(2\pi \sin x)\big]\big[2\pi\cos x\big] \\[10pt]
&= - 2\pi \cos x \sin\hspace{0.05em}(2\pi \sin x)
\end{aligned}
$$
Hence
we deduce
$$
\begin{aligned}
\hspace{5em} \dfrac{\mathrm{d}y}{\mathrm{d}x} = 0 &\hspace{0.5em}\Leftrightarrow\hspace{0.5em} \cos x = 0 \hspace{0.5em}\text{or}\hspace{0.5em} \sin\hspace{0.05em}(2\pi \sin x) = 0 \\[7pt]
&\hspace{0.5em}\Leftrightarrow\hspace{0.5em} \cos x = 0 \hspace{0.5em}\text{or}\hspace{0.5em} \sin x = 0 \hspace{0.5em}\text{or}\hspace{0.5em} \sin x = \dfrac{1}{2} \\[6pt]
&\hspace{0.5em}\Leftrightarrow\hspace{0.5em} x = 0,\hspace{0.25em}\dfrac{\pi}{6},\hspace{0.25em}\dfrac{\pi}{2},\hspace{0.25em}\dfrac{5\pi}{6},\hspace{0.25em}\pi \hspace{2em} [\text{since $0\leq x \leq \pi$}]
\end{aligned}
$$

Evaluating $y = \cos\hspace{0.05em}(2\pi \sin x)$ for the values of $x$
given by $(1)$, we get
$$

\hspace{2em} \begin{array}{rcccccl}
y &=& \cos\hspace{0.05em}(2\pi \sin 0) &=& \cos 0 &=& 1 \\[6pt]
y &=& \cos\hspace{0.05em}(2\pi \sin \textstyle \frac{\pi}{6}) &=& \cos \pi &=& -1 \\[6pt]
y &=& \cos\hspace{0.05em}(2\pi \sin \frac{\pi}{2}) &=& \cos 2\pi &=& 1 \\[6pt]
y &=& \cos\hspace{0.05em}(2\pi \sin \frac{5\pi}{6}) &=& \cos \pi &=& -1 \\[6pt]
y &=& \cos\hspace{0.1em}(2\pi \sin \textstyle \pi) &=& \cos 0 &=& 1
\end{array}
$$
Hence we obtain

$$
\begin{aligned}
\hspace{2em} (0,1),\hspace{0.25em} \Big(\dfrac{\pi}{6},-1\Big),\hspace{0.25em} \Big(\dfrac{\pi}{2},1\Big),\hspace{0.25em} \Big(\dfrac{5\pi}{6},-1\Big),\hspace{0.25em} (\pi,1)
\end{aligned}
$$
