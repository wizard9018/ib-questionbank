# AA342

**Maximum mark: 6**

Let $\mathbf{u} = 3\mathbf{i} - 2\mathbf{j} + \mathbf{k}$ and
$\mathbf{v} = 4\mathbf{i} - 5\mathbf{j} + 6\mathbf{k}$. The vector
$\mathbf{v} - p\hspace{0.025em}\mathbf{u}$ is
perpendicular to $\mathbf{u}$.

Find the value of $p$.

---

## 评分标准 / Mark scheme

We have
$$
\begin{aligned}
\hspace{2em} \mathbf{v} - p\hspace{0.025em}\mathbf{u} &= (4\mathbf{i} - 5\mathbf{j} + 6\mathbf{k}) - p(3\mathbf{i} - 2\mathbf{j} + \mathbf{k}) \\[6pt]
&= (4-3p)\mathbf{i} + (-5+2p)\mathbf{j} + (6-p)\mathbf{k}
\end{aligned}
$$

Hence, using the scalar product formula, we get
$$
\begin{aligned}
(\mathbf{v} - p\hspace{0.025em}\mathbf{u})\cdot\mathbf{u} &= 0 \hspace{2em} [\text{since $(\mathbf{v} - p\hspace{0.025em}\mathbf{u}) \perp \mathbf{u}$}] \\[6pt]
\hspace{2em} ((4-3p)\mathbf{i} + (-5+2p)\mathbf{j} + (6-p)\mathbf{k})\cdot(3\mathbf{i} - 2\mathbf{j} + \mathbf{k}) &= 0 \\[6pt]
(4-3p)(3) + (-5+2p)(-2) + (6-p)(1) &= 0 \\[6pt]
(12-9p) + (10-4p) + (6-p) &= 0 \\[6pt]
28 - 14p &= 0 \\
\end{aligned}
$$

$$
\hspace{12.8em} p= 2
$$
