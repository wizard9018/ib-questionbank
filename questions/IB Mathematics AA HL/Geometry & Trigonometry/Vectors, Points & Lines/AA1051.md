# AA1051

**Maximum mark: 10**

The following diagram shows parallelogram ABCD with $\overrightarrow{\mathrm{AB}}=\boldsymbol{u}$, $\overrightarrow{\mathrm{AD}}=\boldsymbol{v}$ and $|\boldsymbol{u}|=\dfrac{|\boldsymbol{v}|}{2}$, where $|\boldsymbol{u}|\neq 0$.

![1051aaa - Copy](<images/1051aaa - Copy.JPEG>)

The angle between sides $\mathrm{AB}$ and $\mathrm{AD}$ is $\alpha$, where $0< \alpha < \pi$.

Point $\mathrm{X}$ is on side $\mathrm{BC}$ such that $\mathrm{BX}=c\mathrm{BC}$ for $0\leq c \leq 1$.

1.  A vector expression for $\overrightarrow{\mathrm{XA}}$ is $-c\boldsymbol{v}-\boldsymbol{u}$. Find a similar expression for $\overrightarrow{\mathrm{XD}}$. [3 marks]

The angle between $\overrightarrow{\mathrm{XA}}$ and $\overrightarrow{\mathrm{XD}}$ is $\tfrac{\pi}{2}$.

2.  Use the scalar product to show that $\lvert \boldsymbol{v} \lvert^2(2c-1)\left[2\cos\alpha + (2c-1)\right]=0$. [4 marks]

3. Find the range of possible values for $\alpha$ such that there are two possible positions for $\mathrm{X}$. [3 marks]

## 评分标准 / Mark scheme

1. Because we have a parallelogram, $\overrightarrow{\mathrm{AB}}=\overrightarrow{\mathrm{DC}}=\boldsymbol{u}$ and $\overrightarrow{\mathrm{AD}}=\overrightarrow{\mathrm{BC}}=\boldsymbol{v}$.

    Further, we must have that $\overrightarrow{\mathrm{BC}}=\overrightarrow{\mathrm{BX}}+\overrightarrow{\mathrm{XC}}$.

    Substituting in $\overrightarrow{\mathrm{BC}}=\boldsymbol{v}$ and the given information that $\overrightarrow{\mathrm{BX}}=c\overrightarrow{\mathrm{BC}}$, we have

    $$
    \begin{aligned}
    \overrightarrow{\mathrm{BC}}&=\overrightarrow{\mathrm{BX}}+\overrightarrow{\mathrm{XC}} \\[6pt]
    &= c\overrightarrow{\mathrm{BC}}+\overrightarrow{\mathrm{XC}} \\[6pt]
    \boldsymbol{v} &= c\boldsymbol{v} + \overrightarrow{\mathrm{XC}} \tag*{\textbf{(M1)}}\\[6pt]
    \boldsymbol{v} - c\boldsymbol{v} &= \overrightarrow{\mathrm{XC}} \\[6pt]
    \overrightarrow{\mathrm{XC}} &= (1-c)\boldsymbol{v} \tag*{\textbf{(A1)}}
    \end{aligned}
    $$

    We require a vector expression for $\overrightarrow{\mathrm{XD}}$, and from the diagram, we can see that $\overrightarrow{\mathrm{XD}}=\overrightarrow{\mathrm{XC}}+\overrightarrow{\mathrm{CD}}$. We have

    $$
    \begin{aligned}
    \overrightarrow{\mathrm{XD}}&=\overrightarrow{\mathrm{XC}}+\overrightarrow{\mathrm{CD}} \\[6pt]
    &= \overrightarrow{\mathrm{XC}}-\overrightarrow{\mathrm{DC}} \\[6pt]
    \overrightarrow{\mathrm{XD}}&= \boxed{(1-c)\boldsymbol{v} - \boldsymbol{u}} \tag*{\textbf{A1}}
    \end{aligned}
    $$

2. Given that the angle between $\overrightarrow{\mathrm{XA}}$ and $\overrightarrow{\mathrm{XD}}$ is $\tfrac{\pi}{2}$, their scalar product must be 0.

    Using our expressions for $\overrightarrow{\mathrm{XA}}$ and $\overrightarrow{\mathrm{XD}}$ from part (a), we obtain

    $$
    \begin{aligned}
    \overrightarrow{\mathrm{XA}} \cdot \overrightarrow{\mathrm{XD}} &= 0 \tag*{\textbf{M1}}\\[7pt]
    (-c\boldsymbol{v}-\boldsymbol{u})\cdot ((1-c)\boldsymbol{v}-\boldsymbol{u}) &= 0
    \end{aligned}
    $$

    Using the property of the scalar product that $\boldsymbol{u}\cdot(\boldsymbol{v}+\boldsymbol{w})=\boldsymbol{u}\cdot\boldsymbol{v} + \boldsymbol{u} \cdot \boldsymbol{w}$, we can expand this expression.

    $$
    \begin{aligned}
    -c\boldsymbol{v}\cdot (1-c)\boldsymbol{v} + c\boldsymbol{v}\cdot\boldsymbol{u}-\boldsymbol{u}\cdot(1-c)\boldsymbol{v} + \boldsymbol{u}\cdot\boldsymbol{u} &= 0
    \end{aligned}
    $$

    Now using the properties that $(k\boldsymbol{v})\cdot\boldsymbol{w}=k(\boldsymbol{v}\cdot\boldsymbol{w})$ and $\boldsymbol{v}\cdot\boldsymbol{v}=|\boldsymbol{v}|^2$, we can simplify further.

    $$
    \begin{aligned}
    -c(1-c)|\boldsymbol{v}|^2 + (c-(1-c))\boldsymbol{v}\cdot\boldsymbol{u} + |\boldsymbol{u}|^2 &= 0 \tag*{\textbf{M1}}
    \end{aligned}
    $$

    Next, we note that $|\boldsymbol{u}|=\dfrac{|\boldsymbol{v}|}{2}$, and the question has asked for an expression in terms of $|\boldsymbol{v}|$, $c$ and $\alpha$.

    $$
    \begin{aligned}
    -c(1-c)|\boldsymbol{v}|^2 + (c-(1-c))\boldsymbol{v}\cdot\boldsymbol{u} + \left(\dfrac{|\boldsymbol{v}|}{2}\right)^2 &= 0
    \end{aligned}
    $$

    Finally, we need a substitution for $\boldsymbol{v}\cdot\boldsymbol{u}$. Using **the scalar product formula (3.13)**

    $$
    \begin{aligned}
    \boldsymbol{v}\cdot\boldsymbol{u} &= |\boldsymbol{v}||\boldsymbol{u}|\cos \alpha \\[6pt]
    &= |\boldsymbol{v}|\left(\dfrac{|\boldsymbol{v}|}{2}\right)\cos \alpha
    \end{aligned}
    $$

    We can manipulate our expression to the form required. We have

    $$
    \begin{aligned}
    -c(1-c)|\boldsymbol{v}|^2 + (c-(1-c))|\boldsymbol{v}|\left(\dfrac{|\boldsymbol{v}|}{2}\right)\cos \alpha + \left(\dfrac{|\boldsymbol{v}|}{2}\right)^2 &= 0 \tag*{\textbf{A1}}\\[6pt]
    -c(1-c)|\boldsymbol{v}|^2 + (c-(1-c))\dfrac{|\boldsymbol{v}|^2}{2}\cos \alpha + \dfrac{|\boldsymbol{v}|^2}{4} &= 0 \\[6pt]
    -4c(1-c)|\boldsymbol{v}|^2 + 2(c-(1-c))|\boldsymbol{v}|^2\cos \alpha + |\boldsymbol{v}|^2 &= 0 \\[6pt]
    |\boldsymbol{v}|^2\left(-4c+4c^2+2(2c-1)\cos \alpha +1\right) &= 0 \\[6pt]
    |\boldsymbol{v}|^2\left(2(2c-1)\cos \alpha + 4c^2-4c+1\right) &= 0 \tag*{\textbf{M1}}\\[6pt]
    |\boldsymbol{v}|^2\left(2(2c-1)\cos \alpha + (2c-1)^2\right) &= 0 \\[6pt]
    &\hspace{-13.5em}\lvert \boldsymbol{v} \lvert^2(2c-1)\left[2\cos\alpha + (2c-1)\right] = 0\hspace{0.5em}...\text{ as required} \tag*{\textbf{AG}}
    \end{aligned}
    $$

3. Firstly, we note that the equation found in part (b) must be satisfied for the angle at X to be a right angle. Since $\boldsymbol{u}\neq \boldsymbol{0}$, we have $|\boldsymbol{v}|=2|\boldsymbol{u}|\neq0$, so we require

    $$
    \begin{aligned}
    2c-1=0 \hspace{2em}\text{or}\hspace{2em}2\cos{\alpha}+(2c-1)=0
    \end{aligned}
    $$

    Solving each equation for $c$ gives the two values of $c$ for which the angle at X is a right angle.

    $$
    \begin{aligned}
    c=\tfrac{1}{2} \hspace{2em}\text{and}\hspace{2em}c=\frac{1-2\cos{\alpha}}{2}
    \end{aligned}
    $$

    For $\mathrm{X}$ to have two distinct positions, these two values of $c$ must be different.

    $$
    \begin{aligned}
    \tfrac{1}{2}&\neq\frac{1-2\cos{\alpha}}{2}\\[6pt]
    1&\neq1-2\cos{\alpha}\\[6pt]
    \cos{\alpha}&\neq0\\[6pt]
    \alpha&\neq\tfrac{\pi}{2} \tag*{\textbf{(A1)}}
    \end{aligned}
    $$

    Both values of $c$ must also lie in the given range $0\leq c \leq 1$. The first value, $c=\tfrac{1}{2}$, always satisfies this. For the second value, this gives an inequality in $\alpha$.

    $$
    \begin{aligned}
    0\leq&\frac{1-2\cos{\alpha}}{2}\leq1 \tag*{\textbf{(M1)}}\\[6pt]
    0\leq&1-2\cos{\alpha}\leq2\\[6pt]
    -\tfrac{1}{2}\leq&\cos{\alpha}\leq\tfrac{1}{2}
    \end{aligned}
    $$

    ![1051bbb](images/1051bbb.JPEG)

    Recall that $0< \alpha < \pi$, this is shown in red in the above sketch. Hence

    $$
    \begin{aligned}
    \tfrac{\pi}{3}\leq \alpha \leq \tfrac{2\pi}{3}
    \end{aligned}
    $$

    Combining this with the earlier requirement that $\alpha\neq\tfrac{\pi}{2}$, we obtain

    $$
    \begin{aligned}
    &\hspace{-0.65em}\boxed{\tfrac{\pi}{3}\leq \alpha \leq \tfrac{2\pi}{3}, \hspace{1em}\alpha \neq \dfrac{\pi}{2}} \tag*{\textbf{A1}}
    \end{aligned}
    $$
