# AA310

**Maximum mark: 4**

Given that
$2(\mathbf{a}\times\mathbf{b}) = - 3(\mathbf{b}\times\mathbf{c})$, prove
that $2\mathbf{a} - 3\mathbf{c} = t\mathbf{b}$ where $t$ is a scalar.

---

## 评分标准 / Mark scheme

Using the properties of vector product, we have
$$
\begin{aligned}
2(\mathbf{a}\times\mathbf{b}) &= - 3(\mathbf{b}\times\mathbf{c}) \hspace{2em} \\[6pt]
2(\mathbf{a}\times\mathbf{b}) + 3(\mathbf{b}\times\mathbf{c}) &= 0 \\[6pt]
2(\mathbf{a}\times\mathbf{b}) - 3(\mathbf{c}\times\mathbf{b}) &= 0 \\[6pt]
[(2\mathbf{a})\times\mathbf{b}] + [(-3\mathbf{c})\times\mathbf{b}] &= 0 \\[6pt]
(2\mathbf{a} - 3\mathbf{c})\times\mathbf{b} &= 0
\end{aligned}
$$
Hence
$2\mathbf{a} - 3\mathbf{c}$ is parallel (or anti-parallel) to
$\mathbf{b}$.

Therefore, we deduce $2\mathbf{a} - 3\mathbf{c} = t\mathbf{b}$, for some
$t \in \mathbb{R}$.
