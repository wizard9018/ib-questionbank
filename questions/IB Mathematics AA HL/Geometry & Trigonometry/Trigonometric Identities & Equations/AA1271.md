# AA1271

**Maximum mark: 7**

1.  Show that $4-3\cos2x=6\sin^2x+1$.[1 mark]

2.  Hence or otherwise solve $4-3\cos(4\theta+\tfrac{2\pi}{3})-9\sin (2\theta+\tfrac{\pi}{3})=-2$ for $0\leq \theta<\pi$. [6 marks]

---

## 评分标准 / Mark scheme

1.  In a $'$show that$'$ question we should work from the L.H.S. to the R.H.S.

    $$

    \begin{aligned}

       \text{L.H.S.}&=4-3\cos2x&

    \end{aligned}

    $$

    The cosine double angle identity that contains only $\sin \theta$ is $\cos2\theta=1-2\sin^2\theta$.

    Substituting this we obtain

    $$

    \begin{aligned}

    &=4-3(1-2\sin^2x)\tag*{\textbf{\textcolor{black}{M1}}}\\[6pt]

    &=4-3+6\sin^2x\\[6pt]   &=6\sin^2x+1\hspace{2em}\text{...as required}\\[6pt]

    &=\text{R.H.S.}

    \end{aligned}

    $$

2.  By considering a substitution $x=2\theta+\tfrac{\pi}{3}$ we can write the equation in part (b) so that contains the expression from part (a).

    $$

    \begin{aligned}

    4-3\cos(4\theta+\tfrac{2\pi}{3})-9\sin(2\theta+\tfrac{\pi}{3})=-2\\[6pt]

    \textcolor{red}{4-3\cos2x}-9\sin x=-2

    \end{aligned}

    $$

    Hence we can substitute the R.H.S. of the equation from part (a) so that the equation is in terms of sine.

    $$

    \begin{aligned}

    \textcolor{red}{6\sin^2x+1}-9\sin x&=-2\tag*{\textbf{\textcolor{black}{(M1)}}}\\[6pt]

    6\sin^2x-9\sin x+3&=0\\[6pt]

    2\sin^2x-3\sin x+1&=0

    \end{aligned}

    $$

    Notice that this is a quadratic equation. We can factorise it using grouping which gives

    $$

    \begin{aligned}

    2\sin^2x-3\sin x+1&=0\\[6pt]

    2\sin^2x-2\sin x-\sin x+1&=0\\[6pt]

    2\sin x(\sin x-1)-1(\sin x - 1)&=0\\[6pt]

    (2\sin x-1)(\sin x-1)&=0

    \end{aligned}

    $$

    Applying the null factor theorem we get

    $$

    \begin{aligned}

      2\sin x-1&=0&&\sin x-1=0\\[6pt]

       \sin x&=\tfrac{1}{2}&&\sin x=1\tag*{\textbf{\textcolor{black}{A1}}}

    \end{aligned}

    $$

    Using the unit circle, we know that $\sin x=1$ when $\textcolor{red}{x=\frac{\pi}{2}}$ and $\sin x=\frac{1}{2}$ when $x=\frac{\pi}{6}$ and $\textcolor{blue}{x=\frac{5\pi}{6}}$.  This is represented in the diagram below. 

    ![AA1271](images/AA1271.JPEG)

    Hence the answers for $x$ are $\frac{\pi}{6},\,\frac{\pi}{2}\text{, and }\frac{5\pi}{6}$

    $$

    \begin{aligned}

         \tag*{\textbf{(A1)}}

    \end{aligned}

    $$

    Recall that we are solving for $\theta$ and we used a substitution.  

    Hence we can find values of $\theta$ that satisfy the equation

    $$

    \begin{aligned}

    2\theta+\tfrac{\pi}{3}&=\tfrac{\pi}{6}\\[6pt]

    \theta&=-\tfrac{\pi}{12}

    \end{aligned}

    $$

    

    The first value we have found is outside of the given domain $(0 \leq \theta < \pi)$ hence we need to add (or subtract!) $\textcolor{red}{2\pi}$ to the value we found from the unit circle to obtain other values that could be in the domain

    $$

    \begin{aligned}

    2\theta+\tfrac{\pi}{3}&=\tfrac{\pi}{6}+\textcolor{red}{2\pi}\\[6pt]

    &=\tfrac{13\pi}{6}\\[6pt]

    2\theta&=\tfrac{13\pi}{6}-\tfrac{2\pi}{6}\\[6pt]

    \theta&=\tfrac{11\pi}{12}\tag*{\textbf{\textcolor{black}{A1}}}

    \end{aligned}

    $$

    This value is now in the given domain.

    Let's find the remaining values

    $$

    \begin{aligned}

    2\theta+\tfrac{\pi}{3}&=\tfrac{\pi}{2}\\[6pt]

    \theta&=\tfrac{\pi}{12}\tag*{\textbf{\textcolor{black}{A1}}}\\[6pt]

    2\theta+\tfrac{\pi}{3}&=\tfrac{5\pi}{6}\\[6pt]

    \theta&=\tfrac{\pi}{4}\tag*{\textbf{\textcolor{black}{A1}}}

    \end{aligned}

    $$

    We have found three solutions. Although not required by the question we can view the values on a graph.

    ![AA1274-a2](images/AA1274-a2.JPEG)

    Notice three solutions, one in red and two in blue.

    The solution identified with the black dot is the value we found which was not in the desired domain.
