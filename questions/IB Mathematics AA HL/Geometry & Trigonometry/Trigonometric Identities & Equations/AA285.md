# AA285

**Maximum mark: 7**

The expression $8\sin x \cos x$ can be written in the form $p\sin qx$.

1.  Find the value of $p$ and the value of $q$. [3 marks]

2.  Hence, or otherwise, solve the equation
    $8\sin x \cos x = 2\sqrt{3}$, for
    $\dfrac{\pi}{4} \leq x \leq \dfrac{\pi}{2}$. [4 marks]

---

## 评分标准 / Mark scheme

1.  Using the double angle identity for sine, we have
    $$
    \begin{aligned}
    \sin 2x &= 2\sin x \cos x \\[6pt]
    \hspace{1.3em} 4\sin 2x &= 8\sin x \cos x
    \end{aligned}
    $$
    Hence we
    find
     $p = 4$
    and  $q = 2$

2.  Solving the equation $8\sin x \cos x = 2\sqrt{3}$ for
    $\pi\hspace{-0.05em}/4 \leq x \leq \pi\hspace{-0.05em}/2$, we get

     $$
     \begin{aligned}
     \hspace{8.1em} 4\sin 2x &= 2\sqrt{3} \\[7pt]
     \sin 2x &= \dfrac{\sqrt{3}}{2} \\[6pt]
     2x &= \dfrac{\pi}{3} + 2n\pi,\hspace{0.25em} \dfrac{2\pi}{3} + 2n\pi \\[9pt]
     x &= \dfrac{\pi}{6} + n\pi,\hspace{0.25em} \dfrac{\pi}{3} + n\pi \hspace{3em} [\text{for $n \in \mathbb{Z}$}] \\
     \end{aligned}
     $$

    $$
    \hspace{9.1em} x = \dfrac{\pi}{3} \hspace{3em} [\text{since $\pi\hspace{-0.05em}/4 \leq x \leq \pi\hspace{-0.05em}/2$}]
    $$
