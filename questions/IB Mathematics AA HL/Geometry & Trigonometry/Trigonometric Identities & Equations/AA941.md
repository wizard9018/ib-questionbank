# AA941

**Maximum mark: 8**

Consider the function $f(x)=\sin\left(\dfrac{\pi}{12}-\dfrac{x}{4}\right)$ for $x \in \mathbb{R}$.

1. Show that the $y$-intercept of $f(x)$ is $\dfrac{\sqrt{6}-\sqrt{2}}{4}$ [3 marks]

2. Find the least positive value of $x$ for which $f(x) = \dfrac{\sqrt{3}}{2}$. [5 marks]

---

## 评分标准 / Mark scheme

1. Substituting $x=0$ into $f(x)$, we find that the $y$-intercept is at $\sin\left(\dfrac{\pi}{12}\right)$. 

    Noting that $\dfrac{\pi}{12} = \dfrac{\pi}{3} - \dfrac{\pi}{4}$, and using the compound angle identity for sine, we have 

    $$

    \begin{aligned}

    \sin(A - B) &= \sin\,A\,\cos\,B - \cos\,A\,\sin\,B \\[10pt]

    \sin\left(\dfrac{\pi}{3} - \dfrac{\pi}{4}\right) &= \sin\left(\dfrac{\pi}{3}\right)\cos\left(\dfrac{\pi}{4}\right) - \cos\left(\dfrac{\pi}{3}\right)\sin\left(\dfrac{\pi}{4}\right)\\[10pt] 

    &= \dfrac{\sqrt{3}}{2} \times \dfrac{1}{\sqrt{2}} - \dfrac{1}{2} \times \dfrac{1}{\sqrt{2}} \\[10pt]

    &= \dfrac{\sqrt{6}}{4} - \dfrac{\sqrt{2}}{4} \\[10pt]

    \sin\left(\dfrac{\pi}{12}\right) &= \dfrac{\sqrt{6}-\sqrt{2}}{4}

    \end{aligned}

    $$

    The $y$-intercept of $f(x)$ is $\hspace{0.525em}\boxed{\dfrac{\sqrt{6}-\sqrt{2}}{4}}\,\,$ as required.

2. Let $\theta = \dfrac{\pi}{12} - \dfrac{x}{4}$ so that the equation becomes $\sin{\theta} = \dfrac{\sqrt{3}}{2}$. We have

    $$

    \begin{aligned}

    \theta &= \dfrac{\pi}{12} - \dfrac{x}{4} \\[10pt]

    \dfrac{x}{4} &= \dfrac{\pi}{12} - \theta \\[10pt]

    x &= \dfrac{\pi}{3} - 4\theta

    \end{aligned}

    $$

    We want $x$ to be as small as possible while still being positive, hence we need the largest value for $\theta$ such that $\dfrac{\pi}{3} - 4\theta > 0$. We have

    $$

    \begin{aligned}

    \dfrac{\pi}{3} - 4\theta &> 0 \\[10pt]

    - 4\theta &> - \dfrac{\pi}{3} \\[10pt]

    \theta &< \dfrac{\pi}{12}

    \end{aligned}

    $$

    Hence we require the largest value of $\theta < \dfrac{\pi}{12}$ that satisfies the equation $\sin{\theta} = \dfrac{\sqrt{3}}{2}$. 

    Using the fact that $\sin\left(\dfrac{\pi}{3}\right)=\dfrac{\sqrt{3}}{2}$, we have a principal value for $\theta$ in quadrant 1, $\theta = \dfrac{\pi}{3}$, as shown in the following diagram.

    ![AA941a](images/AA941a.PNG)

    But $\dfrac{\pi}{3} > \dfrac{\pi}{12}$. 

    Using the properties of the sine function, the largest value of $\theta < \dfrac{\pi}{12}$ for which $\sin\theta = \dfrac{\sqrt{3}}{2}$ is $-\pi - \dfrac{\pi}{3} = -\dfrac{4\pi}{3}$. Hence $\theta = -\dfrac{4\pi}{3}$ and we have

    $$

    \begin{aligned}

    x &= \dfrac{\pi}{3} - 4\theta \\[10pt]

    &= \dfrac{\pi}{3} - 4\left(-\dfrac{4\pi}{3}\right) \\[10pt]

    &= \dfrac{\pi}{3} + \dfrac{16\pi}{3} \\[10pt]

   &\hspace{-0.535em}\boxed{x = \dfrac{17\pi}{3}}

    \end{aligned}

    $$
