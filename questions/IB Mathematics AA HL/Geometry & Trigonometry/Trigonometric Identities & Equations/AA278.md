# AA278

**Maximum mark: 8**

Given that $\sin x = \dfrac{2}{3}$, for
$\dfrac{\pi}{2} \leq x \leq \pi$, find the value of:

1.  $\cos x$; [3 marks]

2.  $\tan 2x$. [5 marks]

---

## 评分标准 / Mark scheme

1.  Using the Pythagorean identity, we get
    $$
    \begin{aligned}
    \cos^2 x + \sin^2 x &= 1 \\[9pt]
    \cos^2 x + \bigg(\dfrac{2}{3}\bigg)^2 &= 1 \\[6pt]
    \cos^2 x &= 1 - \dfrac{4}{9} \hspace{6.9em} \\[9pt]
    \cos^2 x &= \dfrac{5}{9} \\
    \end{aligned}
    $$

    $$
    \hspace{8.7em} \cos x = -\dfrac{\raisebox{-0.15em}{$\sqrt{5}$}}{3} \hspace{3em} [\text{since $\pi\hspace{-0.1em}/2 < x < \pi$}]
    $$

2.  Using the double angle identities for sine and cosine, we obtain
    $$
    \begin{aligned}
    \tan 2x &= \dfrac{\sin 2x}{\cos 2x} \\[10pt]
    &= \dfrac{2\sin x\cos x}{1 - 2\sin^2 x} \\[6pt]
    &= \dfrac{2\big(\frac{2}{3}\big)\hspace{-0.1em}\big(\hspace{-0.2em}-\frac{\sqrt{5}}{3}\big)}{1 - 2\big(\frac{2}{3}\big)^2} \hspace{0.2em} \\[2pt]
    &= -\dfrac{\frac{4\sqrt{5}}{9}}{\frac{1}{9}} \\[10pt]
    &= -4\sqrt{5}
    \end{aligned}
    $$
