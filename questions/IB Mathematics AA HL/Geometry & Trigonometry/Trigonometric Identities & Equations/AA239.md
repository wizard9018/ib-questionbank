# AA239

**Maximum mark: 6**

Solve the equation $\cos 2x - \sin^2 x = \cos^2 x + 3\cos x$, for
$0 \leq x \leq 2\pi$.

---

## 评分标准 / Mark scheme

Using the Pythagorean identity and double angle identity for cosine, we
get
$$
\begin{aligned}
\cos 2x - \sin^2 x &= \cos^2 x + 3\cos x \\[12pt]
\cos 2x - 3\cos x &= \cos^2 x + \sin^2 x  \\[13pt]
\cos 2x - 3\cos x &= 1 \\[12pt]
(2\cos^2 x - 1) - 3\cos x &= 1 \\[12pt]
2\cos^2 x - 3\cos x - 2 &= 0 \\[13pt]
\hspace{2em} (2\cos x + 1)(\cos x - 2) &= 0 \\[13pt]
2\cos x + 1 &= 0 \hspace{3em} [\text{since $\cos x - 2 \neq 0$}] \\[8pt]
\cos x &= -\dfrac{1}{2}  \\
\end{aligned}
$$

$$
\hspace{2.5em} x = \dfrac{2\pi}{3},\hspace{0.25em} \dfrac{4\pi}{3}
$$
