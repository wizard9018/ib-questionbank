# AA228

**Maximum mark: 7**

Solve the equation $\cos 2x + \cos x = 1 + \sin 2x - \sin x$, for
$x \in [-\pi,\pi]$.

---

## 评分标准 / Mark scheme

Using double angle identities, we have
$$
\begin{aligned}
\cos 2x + \cos x &= 1 + \sin 2x - \sin x \\[6pt]
(1- 2\sin^2x) + \cos x &= 1 + 2\sin x \cos x - \sin x \hspace{3em} \\[6pt]
\sin x - 2\sin^2x + \cos x - 2\sin x \cos x &= 0 \\[7pt]
\sin x\hspace{0.05em}(1 - 2\sin x) + \cos x\hspace{0.05em}(1 - 2\sin x) &= 0 \\[7pt]
(\sin x + \cos x)(1 - 2\sin x) &= 0
\end{aligned}
$$
Hence we get

$$
\begin{aligned}
\hspace{6.8em} \sin x + \cos x &= 0 \\[11pt]
\tan x &= -1 \\[11pt]
x &= \arctan(-1),\hspace{0.25em} \pi+\arctan(-1) \\
\end{aligned}
$$

$$
\hspace{3em} x = -\dfrac{\pi}{4},\hspace{0.25em} \dfrac{3\pi}{4}
$$

and
$$
\begin{aligned}
\hspace{7.8em} 1 - 2\sin x &= 0 \\[6pt]
\sin x &= \dfrac{1}{2} \\[6pt]
x &=\arcsin(1/2),\hspace{0.25em}\pi-\arcsin(1/2) \\
\end{aligned}
$$

$$
\hspace{2.25em}  x = \dfrac{\pi}{6},\hspace{0.25em} \dfrac{5\pi}{6}
$$
