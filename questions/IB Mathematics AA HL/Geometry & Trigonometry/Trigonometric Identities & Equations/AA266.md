# AA266

**Maximum mark: 6**

Solve $\dfrac{\sin 2x}{\cos x} - 1 = 0$, for
$\dfrac{\pi}{2} < x \leq \pi$.

---

## 评分标准 / Mark scheme

Applying the **double angle identity (3.6)**, to rewrite $\sin 2x$.
$$
\begin{aligned}
    \dfrac{\sin 2x}{\cos x} - 1 &= 0 \\[6pt]
    \dfrac{2\sin x \hspace{0.1em}\cancel{\cos x}}{\cancel{\cos x}} - 1 &= 0 \tag*{\textbf{(M1)}}
\end{aligned}
$$

> In this case, it is valid to cancel $\cos x$, because in the specified domain, $\frac{\pi}{2} < x \leq \pi$, $\cos x \neq 0$. Hence we have

$$
\begin{aligned}
    2\sin x - 1 &= 0 \tag*{\textbf{R1}} \\[9pt]
    \sin x &= \dfrac{1}{2} \tag*{\textbf{A1}} \\[8pt]
    \hspace{6.5em} [\text{for } n \in \mathbb{Z}] \hspace{3em} x &= \dfrac{\pi}{6} + 2n\pi, \hspace{1em} x = \dfrac{5\pi}{6} + 2n\pi \tag*{\textbf{A1}} \\[9pt]
    x &= \dfrac{5\pi}{6} + 2n\pi \hspace{3em} \left[\text{since } \dfrac{\pi}{2} < x \leq \pi\right] \tag*{\textbf{R1}}
\end{aligned}
$$

$$
\begin{aligned}
 x=   \boxed{ \dfrac{5\pi}{6}} \tag*{\textbf{A1}}
\end{aligned}
$$
