# AA243

**Maximum mark: 6**

Find all solutions to the equation $\tan x - \sin 2x = 0$ where
$\ang{0} \leq x \leq \ang{360}$.

---

## 评分标准 / Mark scheme

Using the double angle identity, we have
$$
\begin{aligned}
\tan x - \sin 2x &= 0 \\[9pt]
\dfrac{\sin x}{\cos x} - 2\sin x \cos x &=  0 \\[5pt]
\hspace{2em} \dfrac{\sin x - 2 \sin x \cos^2 x}{\cos x} &= 0 \\[11pt]
\sin x - 2 \sin x \cos^2 x &= 0 \\[14pt]
\sin x \hspace{0.05em}(1 - 2\cos^2 x) &= 0 \\[8pt]
\sin x =  0 \hspace{0.55em}&\hspace{0.3em}\text{or}\hspace{0.6em} \cos x = \pm\dfrac{1}{\sqrt{2}}
\end{aligned}
$$

Hence we get
$$
\begin{aligned}
\hspace{3.1em} \sin x =  0 &\hspace{0.5em}\text{when}\hspace{0.5em} x =\hspace{0.525em}\ang{0},\hspace{0.25em} \ang{180},\hspace{0.25em} \ang{360}
\end{aligned}
$$

and
$$
\begin{aligned}
\cos x = \dfrac{1}{\sqrt{2}} &\hspace{0.5em}\text{when}\hspace{0.5em} x =\hspace{0.525em}\ang{45},\hspace{0.25em} \ang{315} \hspace{0.1em} \\
\end{aligned}
$$

and
$$
\begin{aligned}
\cos x = -\dfrac{1}{\sqrt{2}} &\hspace{0.5em}\text{when}\hspace{0.5em} x =\hspace{0.525em}\ang{135},\hspace{0.25em} \ang{225} \hspace{0.4em}
\end{aligned}
$$
