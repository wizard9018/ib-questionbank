# AA272

**Maximum mark: 7**

Given that $\sin x = \dfrac{4}{5}$, where $x$ is an obtuse angle, find
the value of:

1.  $\cos x$; [2 marks]

2.  $\cos 2x$; [2 marks]

3.  $\tan 2x$. [3 marks]

---

## 评分标准 / Mark scheme

1.  Using the Pythagorean identity, we get
    $$
    \begin{aligned}
    \cos^2 x + \sin^2 x &= 1 \\[9pt]
    \cos^2 x + \bigg(\dfrac{4}{5}\bigg)^2 &= 1 \\[6pt]
    \cos^2 x &= 1 - \dfrac{16}{25} \hspace{3.8em} \\[9pt]
    \cos^2 x &= \dfrac{9}{25} \\
    \end{aligned}
    $$

    $$
    \hspace{10.5em} \cos x = -\dfrac{3}{5} \hspace{3em} [\text{since $\pi\hspace{-0.1em}/2 < x < \pi$}]
    $$

2.  Using the double angle identity for cosine, we obtain
    $$
    \begin{aligned}
    \cos 2x &= 1 - 2\sin^2 x \\[8pt]
    &= 1 - 2\bigg(\dfrac{4}{5}\bigg)^2 \\[6pt]
    &= 1 - \dfrac{32}{25} \\[9pt]
    &= -\dfrac{7}{25}
    \end{aligned}
    $$

3.  Using the double angle identity for sine, we find
    $$
    \begin{aligned}
    \hspace{0.1em} \tan 2x &= \dfrac{\sin 2x}{\cos 2x} \\[9pt]
    &= \dfrac{2\sin x\cos x}{\cos 2x} \\[7pt]
    &= \dfrac{2\big(\frac{4}{5}\big)\hspace{-0.1em}\big(\hspace{-0.2em}-\frac{3}{5}\big)}{\big(\hspace{-0.2em}-\frac{7}{25}\big)} \\[6pt]
    &= \dfrac{24}{7}
    \end{aligned}
    $$
