# AA262

**Maximum mark: 6**

Solve $\sqrt{3}\tan x + 1 = 0$, for $0 \leq x \leq \pi$.

---

## 评分标准 / Mark scheme

We have

![eea28ea6dc26969cf5c008612e865ae5046a04ef.svg](images/eea28ea6dc26969cf5c008612e865ae5046a04ef.svg)

Using the right triangle above, we get
$$
\begin{aligned}
\hspace{8em} \sqrt{3}\tan x + 1 &= 0 \\[9pt]
\tan x &= -\dfrac{1}{\sqrt{3}} \\[6pt]
x &= -\dfrac{\pi}{6} + n\pi \hspace{2.5em} [\text{for $n \in \mathbb{Z}$}] \\[9pt]
x &= -\dfrac{\pi}{6} + \pi \hspace{3em} [\text{since $0 \leq x \leq \pi$}] \\
\end{aligned}
$$

$$
\hspace{0.4em} x = \dfrac{5\pi}{6}
$$
