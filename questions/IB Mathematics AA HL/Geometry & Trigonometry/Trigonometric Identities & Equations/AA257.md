# AA257

**Maximum mark: 7**

Given that $\sin x = \dfrac{3}{5}$, where $x$ is an acute angle, find:

1.  $\cos x$; [3 marks]

2.  $\sin 2x$; [2 marks]

3.  $\cos 2x$. [2 marks]

---

## 评分标准 / Mark scheme

1.  Using the Pythagorean identity, we get
    $$
    \begin{aligned}
    \cos^2 x + \sin^2 x &= 1 \\[8pt]
    \cos^2 x + \bigg(\dfrac{3}{5}\bigg)^2 &= 1 \\[5pt]
    \cos^2 x &= 1 - \dfrac{9}{25} \hspace{6.1em} \\[8pt]
    \cos^2 x &= \dfrac{16}{25} \\
    \end{aligned}
    $$

    $$
    \hspace{7.3em} \cos x = \dfrac{4}{5} \hspace{3em} [\text{since $0 < x < \pi\hspace{-0.1em}/2$}]
    $$

2.  Using the double angle identity for sine, we obtain
    $$
    \begin{aligned}
    \sin 2x &= 2\sin x \cos x \\[9pt]
    &= 2\bigg(\dfrac{3}{5}\bigg)\hspace{-0.1em}\bigg(\dfrac{4}{5}\bigg) \hspace{0.3em} \\[7pt]
    &= \dfrac{24}{25}
    \end{aligned}
    $$

3.  Using the double angle identity for cosine, we find
    $$
    \begin{aligned}
    \cos 2x &= 1 - 2\sin^2 x \hspace{0.4em} \\[8pt]
    &= 1 - 2\bigg(\dfrac{3}{5}\bigg)^2 \\[6pt]
    &= 1 - \dfrac{18}{25} \\[10pt]
    &= \dfrac{7}{25}
    \end{aligned}
    $$
