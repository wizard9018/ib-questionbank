# AA1295

**Maximum mark: 6**

A group of designers are creating a knife holder.

The diagram on the left shows a knife inside the holder and the diagram on the right shows the empty holder.

![1295q](images/1295q.JPEG)

The lengths of the holder, $AB=28$, $AD=20$ and $CD=20$ are measured in centimeters and $\angle CXB = \theta $ radians.

It is also given that $AB$ is parallel to $CD$ and that both are perpendicular to $AD$.

The designers can move the vertex $X$ anywhere along the line $AD$.

Market research suggests that the most appealing design is such that the value of $\theta$ is maximised.

Find the length $AX$ which maximises the value of $\theta$.

---

## 评分标准 / Mark scheme

This is an optimisation question. 

We need to use the information given to obtain the angle $\theta$ as a function of the length $AX$. We can then sketch the function and find the value of $x$ for which $\theta$ is maximised.

We can begin by introducing a variable for the length $AX$, we'll call this $x$.

![1295a1](images/1295a1.JPEG)

The trick to this question, and ones similar, is to use the diagram to spot a way to relate the two variables. In our case $\theta$ and $x$.

The triangle $\triangle BXC$ contains the angle $\theta$. We can write the side lengths of this triangle in terms of in terms of $x$. 

Hence we can use the cosine rule to relate the variables.

$$

\begin{aligned}

\tag*{\textbf{(M1)}}

\end{aligned}

$$

$$

\begin{aligned}

\cos{A}&=\frac{b^2+c^2-a^2}{2 b c}

\end{aligned}

$$

Note that angle $A$ and side length $a$ are opposite each other.

In our example $a=BC$ and $A=\theta$. The other two sides, $b$ and $c$, are $BX$ and $CX$.

Hence we get

$$

\begin{aligned}

\cos{\theta}&=\frac{BX^2+CX^2-BC^2}{2\times BX \times CX}\\[12pt]

\theta&=\arccos{\left(\frac{BX^2+CX^2-BC^2}{2\times BX \times CX}\right)}

\end{aligned}

$$

Now we need to write the side lengths in terms of $x$.

Let's first consider triangle $\triangle ABX$. Using Pythagoras' theorem we can write

$$

\begin{aligned}

    BX^2&=AX^2+AB^2\\[6pt]

    BX^2&=28^2+x^2\tag*{\textbf{\textcolor{black}{(A1)}}}

\end{aligned}

$$

Similarly, using the length $AX=20-x$, we get for triangle $\triangle CDX$

$$

\begin{aligned}

    CX^2&=CD^2+XD^2\\[6pt]

    CX^2&=20^2+(20-x)^2\tag*{\textbf{\textcolor{black}{(A1)}}}

\end{aligned}

$$

And finally, to find length $BC$, using the diagram below

![1295a2](images/1295a2.JPEG)

We can see that 

$$

\begin{aligned}

    BC^2&=8^2+20^2\\[6pt]

    BC^2&=464

\end{aligned}

$$

Substituting all of these results into the cosine rule we get

$$

\begin{aligned}

\theta&=\arccos{\left(\frac{BX^2+CX^2-BC^2}{2\times BX \times CX}\right)}\\[12pt]

&=\arccos{\left(\frac{28^2+x^2+20^2+(20-x)^2-464}{2 \sqrt{28^2+x^2}\sqrt{20^2+(20-x)^2}}\right)}\tag*{\textbf{\textcolor{black}{A1}}}

\end{aligned}

$$

Notice, we haven't simplified/expanded anything. We don't need to, we can simply let the calculator do the work.

This type of technique not only reduces the chance of making mistakes it also saves time! So it is an important exam technique.

We should now sketch the function on our G.D.C. and find the maximum point.

$$

\begin{aligned}

\tag*{\textbf{(M1)}}

\end{aligned}

$$

![1295a3](images/1295a3.JPEG)

Hence we can see that when $AX=6.28\,\text{cm}$ the value of $\theta$ is maximised.

$$

\begin{aligned}

\tag*{\textbf{A1}}

\end{aligned}

$$

Note, the maximum value of $\theta$ is $0.822$ radians, however the question does not require us to state this.

Final note. You may've used this alternate (simpler?) method

![AA1295-a3](images/AA1295-a3.JPEG)

We can see that $\alpha + \beta +\theta = \pi$.

If we let the length $AX=x$ then we can use the tangent ratio to write 

$$

\begin{aligned}

    &&\tan{\alpha}&=\dfrac{28}{x}&&\hspace{2em}&&&\tan{\beta}&=\dfrac{20}{20-x}&\\[12pt]

    &&\alpha&=\arctan{\left(\dfrac{28}{x}\right)}&&\hspace{2em}&&&\beta&=\arctan{\left(\dfrac{20}{20-x}\right)}&

\end{aligned}

$$

Therefore using the relation above we get a function for $\theta$ in terms of $x$.

$$

\begin{aligned}

    \arctan{\left(\dfrac{28}{x}\right)} + \arctan{\left(\dfrac{20}{20-x}\right)} +\theta &= \pi\\[12pt]

    \theta &=\pi-\arctan{\left(\dfrac{28}{x}\right)} - \arctan{\left(\dfrac{20}{20-x}\right)}

\end{aligned}

$$

Optimising the above function yields the correct answer.
