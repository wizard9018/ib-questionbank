# AA1164

**Maximum mark: 6**

There is a triangle $ABC$ such that $AB=7\,$cm and $\angle{BAC}=50^\circ$.

Find the lengths of $BC$ such that it is possible to draw two triangles $ABC$.

As we continue to decrease the length of $BC$ we still observe $2$ triangles until $BC$ is perpendicular to $AC$ and then we go back to only being able to draw $1$ triangle.

![AA1164_e](images/AA1164_e.JPEG)

We can use trigonometric ratios to find $BC$ at this time.

$$
\begin{aligned}
    \sin{50^\circ}&=\frac{BC}{7}\tag*{\textbf{M1}}\\[6pt]
    BC&=5.3623...\\[6pt]
    &=5.36\,\text{cm}\tag*{\textbf{A1}}
\end{aligned}
$$

Notice that if $BC<5.36...$ then we cannot draw any triangles.

![AA1164_f](images/AA1164_f.JPEG)

Hence, we can draw two triangles when $\hspace{0.5252em}\boxed{5.36\,\text{cm}<BC<7\,\text{cm}}$
