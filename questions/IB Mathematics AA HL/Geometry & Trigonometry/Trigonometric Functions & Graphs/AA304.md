# AA304

**Maximum mark: 13**

A function, $f$, is defined by
$f(x)= 6.2\sin\hspace{-0.15em}\Big(\dfrac{\pi}{9}(x-7.5)\Big)\hspace{-0.15em}+c$,
for $0\leq x \leq 15$,

where $c \in \mathbb{R}$.

1.  Find the period of $f$. [2 marks]

The function $f$ has a minimum at A$(3,11.8)$ and a maximum at
B$(12,24.2)$.

2.
    1.  Find the value of $c$.

    2.  Hence find the value of $f(9)$. [4 marks]

A second function, $g$, is defined by
$g(x) = a\sin\hspace{-0.15em}\Big(\dfrac{2\pi}{15}(x+2.25)\Big)\hspace{-0.15em}+b$,
for $0 \leq x \leq 15$,

where $a, b \in \mathbb{R}$.

The function $g$ passes through the points P$(1.5,14.5)$ and
Q$(14,10.2)$.

3.  Find the value of $a$ and the value of $b$. [5 marks]

4.  Find the value of $x$ for which the functions have the
    greatest difference. [2 marks]

---

## 评分标准 / Mark scheme

1.  We have
    $$
    \begin{aligned}
    \hspace{2em} \dfrac{\pi}{9} &= \dfrac{2\pi}{\text{period}} \\
    \end{aligned}
    $$

    $$
    \text{period} = 18 \hspace{1.95em}
    $$

2.
    1.  We have
        $$
        \begin{aligned}
        c &= \dfrac{f_{\text{max}} + f_{\text{min}}}{2} \hspace{2.5em} \\[6pt]
        &= \dfrac{24.2 + 11.8}{2} \\[10pt]
        &= 18
        \end{aligned}
        $$

    2.  Evaluating $f(x)$ for $x = 9$, we get
        $$
        \begin{aligned}
        \hspace{2.6em} f(9) &= 6.2\sin\hspace{0.05em}((\pi\hspace{-0.05em}/9)(9-7.5)) + 18 \\[8pt]
        &= 21.1
        \end{aligned}
        $$

3.  Using the coordinates of points P and Q, we have
    $$
    \begin{aligned}
    g(1.5) &= 14.5 \\[6pt]
    g(14) &= 10.2
    \end{aligned}
    $$
    or

    $$
    \begin{aligned}
    a\sin\hspace{0.05em}((2\pi\hspace{-0.05em}/15)(1.5+2.25)) + b &= 14.5  \\[6pt]
    a\sin\hspace{0.05em}((2\pi\hspace{-0.05em}/15)(\hspace{0.135em}14\hspace{0.135em}+2.25)) + b &= 10.2
    \end{aligned}
    $$

    Hence, solving the system of linear equations $(1)$-$(2)$ for $a$
    and $b$, we obtain
    $$
    \begin{aligned}
    \hspace{12em} a = 8.6 \hspace{0.525em}\text{ and }\hspace{0.525em} b = 5.9 \hspace{3.5em} [\text{by using G.D.C.}]
    \end{aligned}
    $$

4.  We have
    $$
    \begin{aligned}
    \hspace{1.25em} h(x) &= |f(x) - g(x)| \\[6pt]
    &= |(6.2\sin\hspace{0.05em}((\pi\hspace{-0.05em}/9)(x-7.5)) + 18) - (8.6\sin\hspace{0.05em}((2\pi\hspace{-0.05em}/15)(x+2.25)) + 5.9)| \\[1pt]
    \end{aligned}
    $$

    If we sketch the graph of $y = h(x)$ for $0 \leq x \leq 15$ \[by
    using G.D.C.\], we have

    ![8c38b2efba89a030c57601dc7e7f553e8facba37.svg](images/8c38b2efba89a030c57601dc7e7f553e8facba37.svg)

    Hence the (absolute) maximum value of $h$ occurs when
     $x \approx 9.96$
