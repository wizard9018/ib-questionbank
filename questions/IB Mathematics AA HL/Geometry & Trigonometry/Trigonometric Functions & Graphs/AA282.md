# AA282

**Maximum mark: 13**

Let
$f(x) = \sin\hspace{-0.15em}\Big(\dfrac{\pi}{3}x\Big) + \cos\hspace{-0.15em}\Big(\dfrac{\pi}{3}x\Big)$,
for $0 \leq x \leq 8$.

1.  Find the values of $x$ where $f$ has a positive rate of change.
    [4 marks]

The function $f$ can be written in the form
$f(x) = a\cos\hspace{-0.15em}\Big(\dfrac{\pi}{3}(x - d)\Big)$ where
$6 \leq d \leq 9$.

2.  Find the value of:
    1.  $a$;

    2.  $d$. [5 marks]

3.  Solve $f(x) = 1$, for $0 \leq x \leq 8$. [4 marks]

2.
    1.  Using the $y$-coordinates of A and B, we get
        $$
        \begin{aligned}
        \hspace{1em} a &= \dfrac{f_{\text{max}} - f_{\text{min}}}{2} \\[4pt]
        &= \dfrac{1.41-(-1.41)}{2} \\[10pt]
        &= 1.41
        \end{aligned}
        $$

    2.  Using the coordinates of A, we have
        $$
        \begin{aligned}
        f(0.75) &= 1.41 \\[9pt]
        1.41\cos\hspace{0.05em}((\pi\hspace{-0.05em}/3)(0.75 - d)) &= 1.41 \\[10pt]
        \cos\hspace{0.05em}((\pi\hspace{-0.05em}/3)(0.75 - d)) &= 1 \\[6pt]
        \dfrac{\pi}{3}(0.75 - d) &= 2n\pi \\[6pt]
        0.75 - d &= 6n \\[10pt]
        d &= 0.75 - 6n \hspace{3em} [\text{for $n \in \mathbb{Z}$}] \hspace{4.1em}
        \end{aligned}
        $$

        Hence we obtain
        $$
        \begin{aligned}
        d &= 0.75 - 6(-1) \\[6pt]
        &= 6.75
        \end{aligned}
        $$

3.  Solving the equation $f(x) = 1$ for $0 \leq x \leq 8$, we

    \begin{aligned}
    1.41\cos\hspace{0.05em}((\pi\hspace{-0.05em}/3)(x - 6.75)) &= 1 \hspace{13.1em} \\
    \end{aligned}
    $$
