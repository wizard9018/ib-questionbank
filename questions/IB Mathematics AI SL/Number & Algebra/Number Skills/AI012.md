# AI012

**Maximum mark: 6**

After solving a problem, John has an **exact** answer of $z = 0.1475$.

1.  Write down the **exact** value of $z$ in the form $a\times10^k$,
    where $1 \leq a < 10, k\in \mathbb{Z}$.[2 marks]

2.  State the value of $z$ given correct to $2$ significant figures.
    [1 mark]

3.  Calculate the percentage error if $z$ is given correct to $2$
    significant figures. [3 marks]

---

## 评分标准 / Mark scheme

1.
    $1.475\times10^{-1}$

2.
    $0.15$

3.  Using the percentage error formula
    $\epsilon = \bigg|\dfrac{v_\mathrm{A} - v_\mathrm{E}}{v_\mathrm{E}}\bigg|\times 100\hspace{0.05em}\%$
    with $v_\mathrm{E} = 0.1475$ and $v_\mathrm{A} = 0.15$, we obtain
    $$
    \begin{aligned}
    \epsilon &= \bigg|\dfrac{0.15 - 0.1475}{0.1475}\bigg|\times 100\hspace{0.05em}\% \\[6pt]
    &\approx 1.69\hspace{0.05em}\%
    \end{aligned}
    $$
