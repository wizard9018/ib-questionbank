# AI1015

**Maximum mark: 8**

The graph below shows the amount of money $M$ (in thousands of dollars), in the account of a contractor,  where $t$ is the time in months since he opened the account.

![AI1015a](images/AI1015a.PNG)

1. Write down one characteristic of the graph which suggests that a cubic function might be an appropriate model for the amount of money in the account. [1 mark]

The equation of the model can be expressed as $M(t)=at^3+bt^2+ct+d$, where $a$, $b$, $c$ and $d \in \mathbb{R}$. It is given that the graph of the model passes through the following points.

![AI1015b](images/AI1015b.PNG)

2. 1. State the value of $d$.

    2. Using the values in the table, write down three equations in $a$, $b$, and $c$.

    3. By solving the system of equations from part (ii), find the values of $a$, $b$ and $c$. [4 marks]

If $M$ has a negative value, the contractor is in debt.

3. Use the model from part (b) to find the number of months the contractor expects to be in debt. Give your answer to the nearest month. [3 marks]

---

## 评分标准 / Mark scheme

1. :::answer

    The graph of $M$ has exactly one maximum point and one minimum point.

2. 1. From the table, we have $M(0)=1$. Substituting the value $t=0$ into the model we have

        $$

        \begin{aligned}

        M(0)&= a(0)^3+b(0)^2+c(0)+d = d

        \end{aligned}

        $$

        We have $M(0)=1$ and $M(0)=d$ and therefore $d=1$

    2. Using the values given in the table, and part (i), we have

        $$

        \begin{aligned}

        M(1)&= a(1)^3+b(1)^2+c(1)+1 = 2 \\[11pt]

        M(2) &= a(2)^3+b(2)^2+c(2)+1 = -3 \\[11pt]

        M(3) &= a(3)^3+b(3)^2+c(3)+1 = 4  \\[-11pt]

        \end{aligned}

        $$

        Hence, the linear system for variables $a$, $b$ and $c$ is

        $$

        \begin{aligned}

        &\boxed{\begin{cases}

        a+b+c = 1 \\[6pt]

        8a+4b+2c = -4 \\[6pt]

        27a+9b+3c = 3

        \end{cases}}

        \end{aligned}

        $$

    3. Using G.D.C. to solve the linear system found in part (ii), we get

        $$

        \begin{aligned}

        &\boxed{a=3,\, b=-12, \text{ and } c=10}

        \end{aligned}

        $$

3. Using the G.D.C. to graph the polynomial $M(t)=3t^3-12t^2+10t+1$, we have

    ![AI1015c](images/AI1015c.PNG)

    Hence, the time the contractor is in debt equals the time between point A and point B:

    $$

    \begin{aligned}

    \text{Time in debt} &= 2.738 - 1.352 \\[11pt]

    &= 1.386\\[-10pt]

    \end{aligned}

    $$

    To the nearest month, the contractor expects to be in debt for $\text{one month.}$
