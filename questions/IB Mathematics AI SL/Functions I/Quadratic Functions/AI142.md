# AI142

**Maximum mark: 6**

The axis of symmetry of the graph of a quadratic function has equation
$x = \dfrac{3}{2}$.

1.  Draw the axis of symmetry on the grid below. [1 mark]

    ![095afe930760d162dfc8b9c36b42836af719a0ca.svg](images/095afe930760d162dfc8b9c36b42836af719a0ca.svg)

The graph of the quadratic function intersects the $x$-axis at the point
P$(-1,0)$. There is a second point, Q , at
which the graph of the quadratic function intersects the $x$-axis.

2.  Mark and label P and Q on the grid above. [1 mark]

The graph of the quadratic function has equation $y = -x^2+bx+c$, where
$b,c \in \mathbb{Z}$.

3.
    1.  Find the value of $b$ and the value of $c$.

    2.  Find the coordinates of the vertex, M.
    3.  Draw the graph of the quadratic function on the grid above.
        [4 marks]

2.  The $x$-coordinate of $Q$ is
    $$
    \begin{aligned}
    x &= \dfrac{3}{2} + \left[\dfrac{3}{2}-(-1)\right] \\[6pt]
    &= 4
    \end{aligned}
    $$
    Hence, if we mark and label P and Q on the grid
    below, we have

    ![1fa563586fbd8e498bbc0f6a90199f2a3a99e7f7.svg](images/1fa563586fbd8e498bbc0f6a90199f2a3a99e7f7.svg)

3.
    1.  Using the coordinates of P, we have
        $$
        \begin{aligned}
        \hspace{3.1em} 0 &= -(-1)^2 + b(-1) + c \\[6pt]
        0 &= -1 - b + c \\[6pt]
        1 &= -b + c
        \end{aligned}
        $$
        Using the coordinates of
        Q, we have
        $$
        \begin{aligned}
        \hspace{1.6em} 0 &= -(4)^2 + b(4) + c \\[6pt]
        0 &= -16 + 4b + c \\[6pt]
        16 &= 4b + c
        \end{aligned}
        $$
        Hence, solving the system
        of linear equations $(1)$-$(2)$ for $b$ and $c$, we find

        $$
        \begin{aligned}
        \hspace{10em} b = 3\hspace{0.75em}\text{ and }\hspace{0.75em}c = 4\hspace{3em} [\text{by using G.D.C.}]
        \end{aligned}
        $$

    2.  Evaluating $y = -x^2 + 3x + 4$ for $x = 3/2 = 1.5$, we have
        $$
        \begin{aligned}
        \hspace{3.2em} y &= -(1.5)^2 + 3(1.5) + 4 \\[6pt]
        &= 6.25
        \end{aligned}
        $$
        Hence the coordinates of M are
         $(1,5,6.25)$
