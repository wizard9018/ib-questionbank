# AI1115

**Maximum mark: 7**

In the realm of Artificial Intelligence (AI), machine learning models are trained using data sets. The time taken to train a machine learning model is directly proportional to the size of the training data set. This is shown by the following:

$$

\begin{aligned}

t &\propto x

\end{aligned}

$$

Where $t$ is training time in hours, and $x$ is the size of the training data set in gigabytes.

It is known that a certain machine learning model takes $15$ hours to train using a data set of size $100$ gigabytes.

1. Find an equation for $t$ in terms of $x$. [2 marks]

2. If a dataset of 250 gigabytes is used, determine the expected training time. [2 marks]

The larger the data set that is used for training, the more effective the machine learning model is deemed to be.

A new and improved training model has been developed, so that a machine learning model can be trained in the same amount of time as the previous model, using larger data sets. The equation for the new model is $t=0.1x$.

3. Given a training time of $20$ hours, determine the difference in the size of the data sets between the first and second machine learning models. [3 marks]

---

## 评分标准 / Mark scheme

1. We have

    $$

    \begin{aligned}

    t &= kx

    \end{aligned}

    $$

    And if $x=100$, then $t=15$:

    $$

    \begin{aligned}

    15 &= 100k \tag*{\textbf{(M1)}}

    \end{aligned}

    $$

    Hence $k=0.15$ and we have $t = 0.15x$

    $$                    

    \begin{aligned}            

    \tag*{\textbf{A1}}
    \end{aligned}  

    $$

2. Substituting $x=250$ into our equation from part (a), we have

    $$

    \begin{aligned}

    t &= 0.15 \times 250 \tag*{\textbf{(M1)}} 

    \end{aligned}

    $$

    $$\text{The expected training time is $37.5$ hours.}$$

    $$                    

    \begin{aligned}            

    \tag*{\textbf{A1}}
    \end{aligned}  

    $$

3. Using the first model, with $t=20$, we have

    $$

    \begin{aligned}

    20 &= 0.15x \tag*{\textbf{(M1)}} \\[8pt]

    x&\approx 133 \text{ gigabytes}

    \end{aligned}

    $$

    Using the second model, with $t=20$, we have

    $$

    \begin{aligned}

    20 &= 0.1x \tag*{\textbf{(M1)}} \\[8pt]

    x&= 200 \text{ gigabytes}

    \end{aligned}

    $$

    $$\text{The difference in data set sizes is approximately $67$ gigabytes.}$$

    $$                    

    \begin{aligned}            

    \tag*{\textbf{A1}}
    \end{aligned}  

    $$
