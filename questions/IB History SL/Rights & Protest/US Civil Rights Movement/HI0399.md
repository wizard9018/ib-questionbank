# HI0399

What does the source suggest about the NAACP?
[2 marks]

$\\$

| |  | |

## 评分标准 / Mark scheme

$\underline{\textrm{Explanation}}$:
\
Any **two** of the following:
- It is a nationwide organization
- It represents the people of the country
- It needs more support
\
[2 marks]

$\underline{\textrm{Sample Answer}}$:
\
From the source we can learn that the NAACP was a nationwide organization since we can see in the poster the map of the continental United States ($\checkmark$). We can also learn that the NAACP needed more members since the poster calls for people to “join the NAACP” ($\checkmark$).
